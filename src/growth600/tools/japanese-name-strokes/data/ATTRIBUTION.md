# KanjiVG stroke-count data

Character stroke paths are derived from KanjiVG, release `r20250816` (https://github.com/KanjiVG/kanjivg), © Ulrich Apel and contributors. The source is licensed under Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0): https://creativecommons.org/licenses/by-sa/3.0/.

This project extracts the number of SVG path elements for each included Unicode character from the `kanji/` SVG files and redistributes the resulting character-to-count dataset under CC BY-SA 3.0. Source diagrams and ordering conventions are not reproduced. Stroke counts can differ by character variant and writing convention; this dataset is not a name-fortune reference.
