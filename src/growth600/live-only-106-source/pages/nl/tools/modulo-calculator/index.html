Modulocalculator

Bereken het Euclidische quotiënt en de rest voor gehele getallen. Negatieve input wordt consequent verwerkt en de divisie-identiteit laat zien hoe het antwoord wordt gevormd.

Het getal dat moet worden gedeeld; het kan negatief zijn.

Gebruik een geheel getal dat niet nul is; de absolute waarde ervan definieert de modulus.

Controleer of deze waarde congruent is met het deeltal modulo de deler.

Accepteert ondertekende gehele getallen tot 50 cijfers. Geen breuken of decimalen. Het resultaat maakt gebruik van Euclidische modulo; sommige programmeertalen gebruiken een andere restregel voor negatieven.

Resultaat

Hoe bereken je een modulo met een negatief getal?

Deze rekenmachine gebruikt een niet-negatieve rest die kleiner is dan de absolute deler. −7 mod 3 is bijvoorbeeld 2 omdat −7 = (−3 × 3) + 2.

Veelgestelde vragen

Hoe bereken je een modulo met een negatief getal?

Deze rekenmachine gebruikt een niet-negatieve rest die kleiner is dan de absolute deler. −7 mod 3 is bijvoorbeeld 2 omdat −7 = (−3 × 3) + 2.

Worden mijn nummers geüpload?

Nee. De exacte berekening wordt in deze browser uitgevoerd. Nummers worden niet geüpload of opgeslagen.

Wat is −7 mod 3?

Volgens de Euclidische conventie is −7 mod 3 2: −7 = (−3 × 3) + 2, en 0 ≤ 2 < 3.

Wat betekent congruent modulo m?

Twee gehele getallen zijn congruent modulo m als hun verschil deelbaar is door |m|. De optionele vergelijking controleert dit precies.

Waarom kan dit verschillen van de %-operator van een programmeertaal?

Sommige talen behouden in de rest het teken van een negatief dividend. Deze rekenmachine retourneert in plaats daarvan een rest van 0 tot, maar niet inclusief, de absolute deler.
