Bcrypt-generator

Genereer een standaard bcrypt-hash of controleer een wachtwoord aan de hand van een bestaande bcrypt-hash. Het werk wordt uitgevoerd in een lokale browserwerker en het wachtwoord wordt na elke controle gewist.

Bcrypt gebruikt alleen de eerste 72 UTF-8 bytes. Deze tool verwerpt langere waarden in plaats van ze stilzwijgend af te korten. Kosten 8–14 verhogen het werk exponentieel; hogere kosten kunnen langer duren, vooral op telefoons. Een lokale medewerker zorgt ervoor dat de pagina responsief blijft, maar uw apparaat doet het werk.

Gebruik een testwachtwoord, geen echt inlogwachtwoord. Het resultaat is voor leer- en compatibiliteitscontroles; gebruik deze browserpagina niet als een productieaccountopslagsysteem.

Plak een standaard bcrypt-hash van 60 tekens. Verificatie ondersteunt bcrypt-kosten 4–14; ongewoon dure hashes worden geweigerd om grenzeloos werk op uw apparaat te voorkomen.

Resultaat

Wat doet een bcrypt-hash?

Bcrypt is een functie voor het hashen van wachtwoorden, geen encryptie. Het combineert een one-way hash met een willekeurig zout en een configureerbare werkfactor. Een hash kan worden vergeleken met een kandidaatwachtwoord, maar kan niet worden gedecodeerd om het origineel te onthullen.

Veelgestelde vragen

Wat doet een bcrypt-hash?

Bcrypt is een functie voor het hashen van wachtwoorden, geen encryptie. Het combineert een one-way hash met een willekeurig zout en een configureerbare werkfactor. Een hash kan worden vergeleken met een kandidaatwachtwoord, maar kan niet worden gedecodeerd om het origineel te onthullen.

Wordt mijn wachtwoord of hash geüpload of opgeslagen?

Nee. Hashing en verificatie worden in deze browser uitgevoerd. De pagina verzendt het ingevoerde wachtwoord of hash niet naar een server en slaat deze ook niet op; het wachtwoordveld wordt gewist wanneer de bewerking is voltooid. Gebruik voor de veiligheid een testwachtwoord in plaats van een echt accountwachtwoord.

Versleutelt bcrypt mijn wachtwoord?

Nee. Bcrypt is een eenrichtingswachtwoord-hash, geen omkeerbare codering. Het is ontworpen om software een kandidaatwachtwoord te laten controleren zonder het originele wachtwoord op te slaan.

Waarom heeft bcrypt een 72-bytelimiet?

Het bcrypt-formaat verwerkt maximaal 72 UTF-8 bytes. Deze tool weigert langere invoer, zodat verschillende wachtwoorden nooit stilzwijgend als dezelfde ingekorte waarde worden behandeld.

Moet ik deze hash opslaan voor een echt account?

Gebruik deze pagina niet als productiereferentiesysteem. Echte diensten moeten wachtwoorden op hun vertrouwde server hashen met onderhouden authenticatiebibliotheken, geschikte parameters, snelheidslimieten en accountbeveiligingen.
