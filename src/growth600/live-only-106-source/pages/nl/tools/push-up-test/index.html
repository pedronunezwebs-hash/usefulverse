Push-uptest en sets bijhouden

Neem een enkele set op als eenvoudige test of log meerdere sets met de rest ertussen. Je telt en voert herhalingen in; deze tool gebruikt je camera niet en beoordeelt je kracht niet.

Voer maximaal 20 gehele getallen in, van 0 tot 500. Lege regels worden genegeerd en tellen niet als sets. Tel alleen herhalingen die u hebt voltooid met het door u gekozen formulier.

Houd notities algemeen; dit is geen medisch dossier.

Kies een comfortabel bewegingsbereik en stop als u pijn, duizeligheid of ongewone kortademigheid voelt. Het aantal herhalingen is afhankelijk van vorm, tempo en testomstandigheden; deze tool biedt geen fitnessbeoordeling, diagnose of trainingsvoorschrift.

Opslaan is optioneel en maakt alleen gebruik van deze browser. Haal het vinkje weg om te berekenen zonder op te slaan, of wis de opgeslagen geschiedenis hieronder.

Uw sessie

Hoeveel herhalingen telt de push-up testtracker?

Voegt de gehele aantal herhalingen toe die zijn ingevoerd voor elke niet-lege set. Lege regels worden genegeerd, een set van nul blijft nul en de restschatting is rust per pauze vermenigvuldigd met het aantal pauzes.

Veelgestelde vragen

Hoeveel herhalingen telt de push-up testtracker?

Voegt de gehele aantal herhalingen toe die zijn ingevoerd voor elke niet-lege set. Lege regels worden genegeerd, een set van nul blijft nul en de restschatting is rust per pauze vermenigvuldigd met het aantal pauzes.

Zijn mijn push-upsets geüpload?

Nee. De berekening wordt in deze browser uitgevoerd. Sessiegeschiedenis wordt pas naar dit apparaat geschreven nadat u zich heeft aangemeld; je kunt het hier verwijderen.

Tellen lege regels als een set of als herhaling?

Nee. Lege regels worden genegeerd. Een regel met 0 registreert een set met nul herhalingen en voegt geen herhalingen toe aan het totaal.

Kan ik dit voor één maximale set of voor meerdere sets gebruiken?

Ja. Voer één regel in voor een enkele handmatig getelde set, of meerdere regels om sets en de rest daartussen samen te vatten. De testomstandigheden zijn aan jou; resultaten worden niet vergeleken met populatienormen.

Wordt mijn trainingsgeschiedenis geüpload?

Nee. Geschiedenis is optioneel en blijft in deze browser op dit apparaat. Wis het met de verwijderknop wanneer je maar wilt.
