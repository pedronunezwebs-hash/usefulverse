Trình xác thực sơ đồ trang web

Dán tài liệu XML sơ đồ trang web để kiểm tra cấu trúc, mục nhập URL, ngày tháng và các trường chung của nó. XML chỉ được phân tích cú pháp trong trình duyệt này; các trang được liệt kê không bao giờ được tìm nạp.

Hỗ trợ urlset hoặc sitemapindex tiêu chuẩn. Tối đa 1.000.000 ký tự và 5.000 mục nhập trực tiếp.

Chỉ kiểm tra XML cục bộ: việc này không yêu cầu các URL được liệt kê, thu thập dữ liệu trang web, gửi sơ đồ trang web hoặc đảm bảo lập chỉ mục.

Kết quả

    Trình xác thực sơ đồ trang web này kiểm tra những gì?

    Nó kiểm tra các mục nhập urlset hoặc sitemapindex, vị trí HTTP hoặc HTTPS tuyệt đối, các URL được chuẩn hóa trùng lặp, ngày sửa đổi cuối cùng, tần số thay đổi tùy chọn và giá trị ưu tiên cũng như không gian tên sơ đồ trang web. Cảnh báo và lỗi được liệt kê theo số mục.

    Câu hỏi thường gặp

    Trình xác thực sơ đồ trang web này kiểm tra những gì?

    Nó kiểm tra các mục nhập urlset hoặc sitemapindex, vị trí HTTP hoặc HTTPS tuyệt đối, các URL được chuẩn hóa trùng lặp, ngày sửa đổi cuối cùng, tần số thay đổi tùy chọn và giá trị ưu tiên cũng như không gian tên sơ đồ trang web. Cảnh báo và lỗi được liệt kê theo số mục.

    Nó có tải lên hoặc gửi sơ đồ trang web của tôi không?

    Không. XML được xử lý cục bộ trong trình duyệt của bạn. Công cụ này không thu thập dữ liệu URL, tìm nạp tệp sơ đồ trang web từ xa, gửi bất kỳ thứ gì tới công cụ tìm kiếm hoặc xác nhận lập chỉ mục.

    Điều này có kiểm tra xem URL sơ đồ trang web có hoạt động không?

    Không. Nó kiểm tra cú pháp URL và các bản sao trong XML được dán nhưng cố tình không yêu cầu URL hoặc thu thập dữ liệu trang web.

    Sơ đồ trang web hợp lệ có nghĩa là Google đã lập chỉ mục các trang của nó phải không?

    Không. Xác thực XML không phải là báo cáo lập chỉ mục hoặc gửi công cụ tìm kiếm. Gửi sơ đồ trang web thông qua công cụ quản trị trang web của công cụ tìm kiếm có liên quan và kiểm tra trạng thái của chính nó.

    Tôi có thể xác thực chỉ mục sơ đồ trang web không?

    Có. Công cụ này kiểm tra các mục nhập QZINDEX trực tiếp cũng như các trường loc và Lastmod của chúng, nhưng không tải xuống hoặc kiểm tra đệ quy các tệp sơ đồ trang web được tham chiếu.
