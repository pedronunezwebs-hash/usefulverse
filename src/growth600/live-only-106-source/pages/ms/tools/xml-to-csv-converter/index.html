XML to CSV Converter

Tukar senarai rekod XML mudah menjadi jadual CSV, atau bina rekod XML daripada teks fail CSV. Pilih arah, tampal data anda, kemudian salin atau muat turun hasilnya. Tiada apa-apa yang dimuat naik.

Menyokong senarai ringkas elemen rekod dengan nama yang sama, atau satu rekod rata. Kanak-kanak elemen mestilah nilai skalar; medan bersarang dan berulang tidak diratakan.

Gunakan baris pertama untuk nama lajur. Pengepala seperti @id menjadi atribut XML. Gunakan #text untuk teks rekod.

Ini ialah penukaran jadual mudah, bukan penukaran format XML tanpa kerugian. Ruang nama, struktur bersarang, kandungan bercampur, komen dan pemformatan XML tidak dipelihara. Teks tidak sedar jenis. Nilai CSV seperti formula hamparan diberi awalan dengan apostrof untuk keselamatan.

Keputusan

Semak output sebelum mengimportnya ke dalam aplikasi lain.

Bagaimanakah cara menukar XML kepada CSV?

Pilih XML ke CSV dan tampal XML dengan senarai rekod mudah. Elemen rekod terus berulang menjadi baris. Nama elemen menjadi lajur; atribut menggunakan @name. Pilih CSV kepada XML untuk mencipta rekod XML mudah daripada pengepala dan baris.

Soalan lazim

Bagaimanakah cara menukar XML kepada CSV?

Pilih XML ke CSV dan tampal XML dengan senarai rekod mudah. Elemen rekod terus berulang menjadi baris. Nama elemen menjadi lajur; atribut menggunakan @name. Pilih CSV kepada XML untuk mencipta rekod XML mudah daripada pengepala dan baris.

Adakah XML atau CSV saya dimuat naik?

Tidak. Penghuraian dan penukaran dijalankan dalam penyemak imbas ini. Input dihadkan kepada 200,000 aksara, 5,000 baris, 64 lajur dan 20,000 sel. DTD dan pengisytiharan entiti disekat dan sumber luaran tidak diambil.

Bagaimanakah atribut XML ditunjukkan dalam CSV?

Atribut seperti id="101" menjadi lajur bernama @id. Apabila menukar kembali, pengepala CSV yang bermula dengan @ menjadi atribut XML.

Bolehkah ia menukar XML bersarang kepada jadual rata?

Tidak. Struktur anak bersarang, medan berulang dalam rekod dan teks bercampur ditolak dan bukannya diratakan atau hilang secara senyap. Gunakan aliran kerja XML-ke-JSON khusus untuk data bersarang.

Adakah CSV akan mengekalkan jenis dan pemformatan XML?

No. CSV menyimpan teks sel, bukan jenis XML, ruang nama atau pemformatan. Nilai sel seperti formula mendapat awalan apostrof apabila dieksport untuk mengurangkan risiko pelaksanaan formula hamparan.
