Kalkulator Modulo

Kira hasil bahagi Euclidean dan baki untuk nombor bulat. Input negatif dikendalikan secara konsisten, dan identiti bahagian menunjukkan cara jawapan dibentuk.

Nombor untuk dibahagi; ia mungkin negatif.

Gunakan sebarang nombor bulat bukan sifar; nilai mutlaknya mentakrifkan modulus.

Semak sama ada nilai ini adalah kongruen dengan modul dividen pembahagi.

Menerima nombor bulat yang ditandatangani sehingga 50 digit. Tiada pecahan atau perpuluhan. Hasilnya menggunakan modulo Euclidean; sesetengah bahasa pengaturcaraan menggunakan peraturan baki yang berbeza untuk negatif.

Hasilnya

Bagaimanakah anda mengira modulo dengan nombor negatif?

Kalkulator ini menggunakan baki bukan negatif yang lebih kecil daripada pembahagi mutlak. Sebagai contoh, −7 mod 3 ialah 2 kerana −7 = (−3 × 3) + 2.

Soalan lazim

Bagaimanakah anda mengira modulo dengan nombor negatif?

Kalkulator ini menggunakan baki bukan negatif yang lebih kecil daripada pembahagi mutlak. Sebagai contoh, −7 mod 3 ialah 2 kerana −7 = (−3 × 3) + 2.

Adakah nombor saya dimuat naik?

No. Pengiraan tepat dijalankan dalam penyemak imbas ini. Nombor tidak dimuat naik atau disimpan.

Apakah itu −7 mod 3?

Menggunakan konvensyen Euclidean, −7 mod 3 ialah 2: −7 = (−3 × 3) + 2, dan 0 ≤ 2 < 3.

Apakah maksud modulo m kongruen?

Dua integer ialah modulo m kongruen apabila perbezaannya boleh dibahagi dengan |m|. Perbandingan pilihan menyemak ini dengan tepat.

Mengapa ini boleh berbeza daripada operator % bahasa pengaturcaraan?

Sesetengah bahasa mengekalkan tanda dividen negatif dalam bakinya. Kalkulator ini sebaliknya mengembalikan baki dari 0 hingga, tetapi tidak termasuk, pembahagi mutlak.
