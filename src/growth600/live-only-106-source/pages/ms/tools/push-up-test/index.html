Ujian tekan tubi dan penjejak set

Rekod satu set sebagai ujian mudah atau log beberapa set dengan selebihnya di antara mereka. Anda mengira dan memasukkan ulangan; alat ini tidak menggunakan kamera anda atau menilai kekuatan anda.

Masukkan sehingga 20 kiraan nombor bulat dari 0 hingga 500. Baris kosong diabaikan dan tidak dikira sebagai set. Kira hanya ulangan yang anda lengkapkan dengan borang pilihan anda.

Simpan nota umum; ini bukan rekod perubatan.

Pilih julat pergerakan yang selesa dan berhenti jika anda berasa sakit, pening atau sesak nafas yang luar biasa. Kiraan wakil bergantung pada bentuk, kepantasan dan keadaan ujian; alat ini tidak memberikan penilaian kecergasan, diagnosis atau preskripsi senaman.

Saving adalah pilihan dan menggunakan penyemak imbas ini sahaja. Nyahtanda untuk mengira tanpa menyimpan, atau kosongkan sejarah yang disimpan di bawah.

Sesi anda

Bagaimanakah jumlah ulangan penjejak ujian tekan tubi?

Ia menambah ulangan nombor bulat yang dimasukkan untuk setiap set bukan kosong. Garis kosong diabaikan, set sifar kekal sifar, dan anggaran selebihnya ialah rehat setiap rehat didarab dengan bilangan rehat.

Soalan lazim

Bagaimanakah jumlah ulangan penjejak ujian tekan tubi?

Ia menambah ulangan nombor bulat yang dimasukkan untuk setiap set bukan kosong. Garis kosong diabaikan, set sifar kekal sifar, dan anggaran selebihnya ialah rehat setiap rehat didarab dengan bilangan rehat.

Adakah set tekan tubi saya dimuat naik?

No. Pengiraan dijalankan dalam penyemak imbas ini. Sejarah sesi ditulis pada peranti ini hanya selepas anda ikut serta; anda boleh memadamnya di sini.

Adakah garisan kosong dikira sebagai set atau ulangan?

No. Baris kosong diabaikan. Baris dengan 0 merekodkan set ulangan sifar dan tidak menambah ulangan kepada jumlah keseluruhan.

Bolehkah saya menggunakan ini untuk satu set maksimum atau untuk beberapa set?

Ya. Masukkan satu baris untuk satu set yang dikira secara manual, atau berbilang baris untuk meringkaskan set dan selebihnya di antara mereka. Syarat ujian terpulang kepada anda; keputusan tidak dibandingkan dengan norma penduduk.

Adakah sejarah latihan saya dimuat naik?

No. Sejarah adalah pilihan dan kekal dalam penyemak imbas ini pada peranti ini. Kosongkannya dengan butang padam bila-bila masa anda mahu.
