Tiada isian semula dilog lagi.

Ini adalah pengiraan daripada penyertaan anda, bukan penilaian kenderaan rasmi. Bacaan odometer, tutup pam, rupa bumi, lalu lintas, cuaca, muatan, gaya pemanduan dan jenis bahan api boleh mengubah hasil dunia sebenar.

Bagaimanakah cara saya mengira penjimatan bahan api daripada isian semula?

Masukkan jarak yang dipandu sejak tangki penuh sebelumnya, bahan api yang ditambah semasa isi semula ini dan jumlah harga yang dibayar. Untuk hasil yang berguna, mulakan dan tamatkan setiap selang dengan tangki penuh. Kalkulator menukar masukan yang sama kepada L/100 km, km/L, US MPG dan imperial MPG.

Untuk hasil yang berguna, mulakan dan tamatkan setiap selang dengan tangki penuh. Kalkulator menukar masukan yang sama kepada L/100 km, km/L, US MPG dan imperial MPG.

Adakah log bahan api meninggalkan halaman ini?

Tidak. Entri kekal dalam tab penyemak imbas ini dan dikosongkan apabila anda mengosongkannya atau menutup halaman. Eksport sendiri CSV jika anda mahukan salinan berasingan. Tiada akaun, muat naik atau perkhidmatan harga bahan api digunakan.

Apakah maksud L/100 km?

Ia adalah liter bahan api yang digunakan untuk perjalanan sejauh 100 kilometer. Nombor yang lebih rendah bermakna kurang bahan api untuk jarak yang sama.

Bagaimanakah cara saya menukar penjimatan bahan api kepada US MPG?

Pilih jarak dan unit bahan api untuk kemasukan anda. Kalkulator menukar selang terukur yang sama kepada US MPG dan imperial MPG; saiz gelen itu berbeza.

Mengapa saya perlu menggunakan isi semula penuh hingga penuh?

Bermula dan berakhir dengan tangki penuh menjadikan bahan api ditambah ukuran yang lebih dekat daripada apa yang digunakan sepanjang jarak itu. Satu isi semula separa boleh menjadikan selang kurang tepat.
