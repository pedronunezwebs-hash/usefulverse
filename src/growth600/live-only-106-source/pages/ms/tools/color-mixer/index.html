Bagaimanakah cara saya mencampurkan dua warna dalam talian?

Pilih dua atau lebih warna, tetapkan setiap berat dan pilih sRGB atau campuran cahaya linear. Hasilnya menunjukkan nilai HEX, RGB dan HSL.

Soalan lazim

Bagaimanakah cara saya mencampurkan dua warna dalam talian?

Pilih dua atau lebih warna, tetapkan setiap berat dan pilih sRGB atau campuran cahaya linear. Hasilnya menunjukkan nilai HEX, RGB dan HSL.

Adakah warna saya dimuat naik?

Tidak. Pengiraan warna dijalankan secara setempat dalam penyemak imbas anda. Tiada akaun atau muat naik imej diperlukan.

Mengapa sRGB dan campuran cahaya linear kelihatan berbeza?

sRGB meratakan nilai saluran skrin yang dikodkan. Mod cahaya linear menukarnya kepada nilai cahaya dahulu, bercampur, kemudian menukar semula. Kaedah yang dipilih mengubah hasilnya.

Bolehkah ini meramalkan warna cat campuran?

Tidak. Ini adalah matematik warna digital untuk skrin, bukan model pigmen fizikal. Cat sebenar bergantung pada sifat pigmen, ketelusan, kepekatan, pencahayaan, dan permukaan.

Apakah format warna yang boleh saya salin?

Hasilnya memaparkan HEX, RGB dan HSL. Anda boleh menyalin nilai HEX atau memuat turun palet warna CSS kecil.
