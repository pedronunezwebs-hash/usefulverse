Calculadora de programação linear

Insira um objetivo linear e até oito restrições para resolver um programa linear de duas variáveis com x e y não negativos. O método simplex de duas fases relata um ótimo, inviabilidade ou ilimitação e mostra cada pivô.

Coeficientes objetivos (x, y)

Um por linha: a,b <= rhs, a,b >= rhs ou a,b = rhs

Usa no máximo oito restrições e coeficientes/lado direito dentro de ±1.000.000. Ambas as variáveis ​​de decisão têm x ≥ 0 e y ≥ 0. Use uma vírgula entre os coeficientes x e y; insira uma inequação ou igualdade por linha.

Um solucionador simplex primal bifásico para duas variáveis. A tolerância numérica é usada para pivôs de ponto flutuante; problemas quase degenerados podem ser sensíveis ao arredondamento. Casos inviáveis, ilimitados e com limite de iteração são relatados em vez de um ótimo inventado.

Resultados do programa linear

O resultado é apenas para o modelo matemático inserido. Não valida se o objetivo, as restrições, as unidades ou os pressupostos são apropriados para uma decisão real.

    Como funciona a calculadora simplex de duas variáveis?

    Converte restrições em um quadro viável, usa um objetivo da Fase I quando necessário e, em seguida, aplica pivôs simplex primais para otimizar o objetivo solicitado. As variáveis ​​​​x e y são restritas para serem não negativas.

    Perguntas frequentes

    Como funciona a calculadora simplex de duas variáveis?

    Converte restrições em um quadro viável, usa um objetivo da Fase I quando necessário e, em seguida, aplica pivôs simplex primais para otimizar o objetivo solicitado. As variáveis ​​​​x e y são restritas para serem não negativas.

    Meu objetivo e restrições foram carregados?

    Não. O solucionador é executado neste navegador. Seu objetivo e restrições não são enviados para um servidor ou salvos por esta ferramenta.

    Que formato devo usar para restrições?

    Insira uma linha por linha, como 1,1 <= 5 ou 2,1 >= 4. O primeiro número multiplica x, o segundo multiplica y e ambas as variáveis devem ser não negativas.

    O que significa inviável e ilimitado?

    Inviável significa que nenhum ponto satisfaz todas as restrições inseridas. Ilimitado significa que uma direção viável permite que o objetivo solicitado continue melhorando sem um ótimo finito.

    O resultado prova que meu modelo do mundo real está correto?

    Não. Ele resolve apenas as equações que você inseriu. Verifique unidades, suposições e se as restrições descrevem adequadamente sua decisão.
