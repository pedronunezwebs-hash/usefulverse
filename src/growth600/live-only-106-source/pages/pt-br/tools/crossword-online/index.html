Palavras cruzadas on-line

Resolva palavras cruzadas novas geradas localmente a partir de um pequeno conjunto de pistas originais. Selecione uma pista ou quadrado, digite com o teclado e verifique ou revele as respostas quando precisar de ajuda.

As respostas ignoram espaços e letras maiúsculas. O conjunto de pistas é finito e original; um novo tabuleiro reorganiza suas entradas, mas não promete um feed diário ilimitado de quebra-cabeças.

: digite uma letra, use as setas para mover e pressione Backspace para limpar um quadrado.

      Como jogo essas palavras cruzadas?

      Escolha uma pista transversal ou inferior e digite letras nos quadrados selecionados. Use as setas do teclado para navegar pela resposta. Verifique uma palavra ou o quebra-cabeça inteiro, revele uma letra ou a resposta completa ou comece um novo tabuleiro embaralhado.

      Perguntas frequentes

      Como jogo essas palavras cruzadas?

      Escolha uma pista transversal ou inferior e digite letras nos quadrados selecionados. Use as setas do teclado para navegar pela resposta. Verifique uma palavra ou o quebra-cabeça inteiro, revele uma letra ou a resposta completa ou comece um novo tabuleiro embaralhado.

      Minhas respostas foram carregadas ou salvas?

      Não. O quebra-cabeça, as respostas e a pontuação ficam nesta aba do navegador. Não há conta, upload, processamento de servidor ou histórico de jogo salvo.

      Estas palavras cruzadas incluem um feed diário ilimitado de quebra-cabeças?

      Não. A página constrói tabuleiros embaralhados a partir de um conjunto pequeno e finito de pares originais de pistas e respostas. Ele não busca nem reivindica uma biblioteca diária ilimitada de quebra-cabeças.

      Posso usar essas palavras cruzadas sem fazer upload de nada?

      Sim. O quadro e suas respostas são executados nesta guia do navegador. A ferramenta não carrega sua peça nem requer uma conta.

      Este é um criador de palavras cruzadas?

      Não. Esta página é para jogar pistas. Use o Crossword Maker separado quando quiser organizar seus próprios pares de respostas e pistas.

      Início

      Ferramentas gratuitas no navegador. Seus dados permanecem no seu dispositivo, conforme permitido pela ferramenta.
