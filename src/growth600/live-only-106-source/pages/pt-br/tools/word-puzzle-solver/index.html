Solucionador de quebra-cabeças de palavras

Encontre palavras que você pode soletrar em blocos de letras, resolva anagramas ou combine um padrão de palavras cruzadas. Use a lista inicial compacta integrada ou cole uma lista de palavras maior; tudo é pesquisado nesta aba.

Insira apenas letras. Usar ? para um ladrilho em branco. A menos que “usar todas as peças” esteja marcado, o resultado poderá usar apenas algumas letras.

Insira letras conhecidas e use ? ou . para cada posição desconhecida. Cada espaço reservado corresponde a uma letra.

Cole uma palavra por linha. Somente essas palavras são usadas no modo somente personalizado. Máximo de 250.000 caracteres e 50.000 palavras.

Qualquer palavra que contenha uma destas letras será removida.

O vocabulário inicial multilíngue incluído é intencionalmente pequeno, não é um dicionário completo ou uma lista oficial de palavras cruzadas/Scrabble. Cole uma lista maior quando precisar de ampla cobertura.

Todo o processamento permanece nesta aba do navegador. As palavras coladas não são armazenadas após sair da página.

Palavras correspondentes

    Como funciona esse localizador de palavras?

    Escolha o modo anagrama para encontrar palavras que podem ser formadas a partir de suas letras ou o modo padrão para combinar letras fixas e ? ou . espaços reservados. Os resultados vêm apenas da lista integrada compacta selecionada e/ou da lista de palavras que você cola.

    Perguntas frequentes

    Como funciona esse localizador de palavras?

    Escolha o modo anagrama para encontrar palavras que podem ser formadas a partir de suas letras ou o modo padrão para combinar letras fixas e ? ou . espaços reservados. Os resultados vêm apenas da lista integrada compacta selecionada e/ou da lista de palavras que você cola.

    Minhas letras ou lista de palavras foram carregadas?

    Não. As pesquisas são executadas localmente nesta página. Suas letras e lista de palavras coladas não são carregadas, salvas em uma conta ou enviadas a um servidor.

    Posso usar blocos em branco em um anagrama?

    Sim. Digitar ? para cada ladrilho em branco. Cada ? pode representar uma letra. “Usar todas as peças de letras” requer uma correspondência para usar todas as peças inseridas.

    Isso pode resolver uma pista de palavras cruzadas pelo significado?

    Não. Ele apenas corresponde a padrões de letras e filtra palavras na lista selecionada; ele não entende os significados das pistas nem fornece respostas semânticas.

    A lista interna contém todas as palavras?

    Não. É um pequeno vocabulário inicial multilíngue, não um dicionário completo ou uma lista oficial de palavras do jogo. Cole sua própria lista de palavras para uma cobertura mais ampla.
