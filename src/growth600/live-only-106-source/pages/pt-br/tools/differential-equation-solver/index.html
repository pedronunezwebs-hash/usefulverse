Solucionador de equações diferenciais

Aproxime um problema de valor inicial de primeira ordem y′ = f(x,y) com passo fixo Runge–Kutta 4. Insira a derivada, ponto inicial e valor, ponto final e contagem de passos. Tudo roda neste navegador.

Use xey, números, + − × ÷ e ^. Funções suportadas: sin, cos, tan, exp, ln, log, sqrt e abs. Escreva a multiplicação explicitamente, como x*y.

RK4 clássico de passo fixo apenas para uma EDO de valor inicial de primeira ordem. Suporta até 10.000 passos; x deve ficar dentro de ±1.000.000 ey dentro de ±1.000.000.000.000. O gráfico e o CSV mostram até cerca de 101 pontos amostrados. Os resultados numéricos podem ser imprecisos perto de descontinuidades, singularidades ou para equações rígidas. Não encontra soluções gerais simbólicas nem certifica erros.

Solução numérica

Como funciona o solucionador de equações diferenciais RK4?

RK4 estima a solução usando quatro avaliações de inclinação por etapa. Passos menores muitas vezes melhoram a precisão de soluções suaves, mas esta estimativa numérica não é uma solução simbólica ou exata.

Perguntas frequentes

Como funciona o solucionador de equações diferenciais RK4?

RK4 estima a solução usando quatro avaliações de inclinação por etapa. Passos menores muitas vezes melhoram a precisão de soluções suaves, mas esta estimativa numérica não é uma solução simbólica ou exata.

Minha equação e valores foram carregados?

Não. O cálculo, o gráfico e o CSV são criados neste navegador. Esta ferramenta não carrega nem salva suas entradas.

O que o método Runge – Kutta calcula?

Ele estima o caminho de uma solução a partir de um ponto inicial usando repetidamente várias amostras derivadas em cada etapa. Esta página usa o método RK clássico de quarta ordem.

Quantas etapas devo usar?

Comece com o exemplo e compare os resultados usando mais etapas. Um passo menor pode melhorar uma solução suave, mas não pode fixar uma singularidade ou tornar uma equação rígida adequada para este método básico.

Ele consegue resolver todas as equações diferenciais com exatidão?

Não. Aproxima numericamente problemas de valor inicial de primeira ordem suportados. Não fornece uma solução geral simbólica, não prova a unicidade nem garante um limite de erro.
