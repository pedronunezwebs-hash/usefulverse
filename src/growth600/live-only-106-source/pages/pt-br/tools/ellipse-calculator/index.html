Calculadora de elipse

Insira os dois semieixos de uma elipse para encontrar sua área, distância focal, excentricidade e uma aproximação de perímetro claramente identificada.

Insira comprimentos de semieixos positivos na mesma unidade, até 1.000.000.000. Área usa o quadrado dessa unidade. O perímetro utiliza a segunda aproximação de Ramanujan, não uma fórmula elementar exata.

Propriedades da elipse

Área = πab. Distância centro-foco c = √(A² − B²), onde A é o semieixo maior e B é o semieixo menor. Excentricidade e = c/A. O perímetro usa Ramanujan II com h = ((A − B)/(A + B))².

O que uma calculadora de elipse pode encontrar?

Dados dois semieixos positivos, identifica os eixos maior e menor, calcula a área e a distância do foco e estima o perímetro usando a segunda aproximação de Ramanujan.

Perguntas frequentes

O que uma calculadora de elipse pode encontrar?

Dados dois semieixos positivos, identifica os eixos maior e menor, calcula a área e a distância do foco e estima o perímetro usando a segunda aproximação de Ramanujan.

Minhas medições foram carregadas?

Não. A geometria é calculada neste navegador. Seus valores não são enviados para um servidor ou armazenados por esta ferramenta.

Como calculo a área de uma elipse?

Multiplique π pelo semieixo maior e pelo semieixo maior. Se aeb são os semieixos, a área é πab.

O perímetro da elipse é exato?

Não. Não existe uma forma fechada elementar simples para um perímetro de elipse geral. Esta ferramenta usa a segunda aproximação de Ramanujan e a rotula como aproximada.

O que significam os focos e a excentricidade?

Os dois focos estão no eixo maior, a distâncias iguais do centro. A excentricidade varia de 0 para um círculo a 1 para elipses cada vez mais alongadas.
