Calculadora de potência estatística

Planeje uma comparação de médias entre dois grupos. Estime o poder a partir de um tamanho de amostra ou estime os participantes necessários para um poder alvo.

d de Cohen é a diferença esperada entre as médias dos grupos dividida pelo desvio padrão compartilhado. Use uma estimativa defensável a partir de evidências anteriores ou um efeito mínimo significativo – não um resultado escolhido depois de ver os dados.

Aproximação para dois grupos independentes e de tamanhos iguais comparando médias com um modelo normal (z). Não é o cálculo exato do teste t para pequenas amostras.

Estimativa de planejamento

A estimativa do tamanho da amostra é arredondada para um participante inteiro. O subsídio de recrutamento é calculado separadamente da amostra analisada.

O que significa poder estatístico?

Potência é a chance de um teste planejado detectar o efeito especificado quando esse efeito for real. Depende do tamanho do efeito, do tamanho da amostra e do nível de significância.

Perguntas frequentes

O que significa poder estatístico?

Potência é a chance de um teste planejado detectar o efeito especificado quando esse efeito for real. Depende do tamanho do efeito, do tamanho da amostra e do nível de significância.

Os pressupostos do meu estudo foram carregados?

Não. O cálculo é executado neste navegador. Suas suposições não são carregadas ou salvas por esta ferramenta.

O que significa 80% de potência?

De acordo com as suposições inseridas, uma estimativa de 80% significa que o teste planejado detectaria o efeito especificado cerca de 80% das vezes se esse efeito fosse real. Não há 80% de chance de que um resultado seja verdadeiro.

O que é d de Cohen?

d de Cohen é uma diferença padronizada entre duas médias: a lacuna esperada dividida pelo desvio padrão comum. O resultado depende fortemente do efeito que você escolher.

Isso substitui uma análise de potência completa?

Não. Esta estimativa do navegador cobre uma comparação equilibrada de médias de dois grupos com uma aproximação normal. Ele não modela tamanhos de grupos desiguais, dados pareados, proporções, ANOVA, medidas agrupadas ou repetidas, covariáveis, testes t exatos, testes múltiplos ou restrições de projeto específicas do estudo.
