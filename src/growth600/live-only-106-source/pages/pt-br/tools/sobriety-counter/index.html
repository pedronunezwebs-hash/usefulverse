Contador de dias de sobriedade

Escolha uma data de início para contar os dias corridos decorridos e ver os próximos marcos. Este contador privado não é um tratamento, um conselho de recuperação ou uma medida de saúde.

Insira a data a partir da qual deseja contar. Uma data hoje é o dia zero; datas futuras não são permitidas. O padrão é hoje e pode ser alterado para revisar uma data anterior, mas não uma data anterior ao início.

Até 280 caracteres. Mantenha detalhes confidenciais fora de dispositivos compartilhados.

Trata-se apenas de aritmética de data. Não avalia o uso de substâncias, a saúde, o risco, o progresso ou as necessidades de tratamento. A recuperação é pessoal; considere suporte qualificado se quiser ajuda.

Salvar é opcional e usa apenas o armazenamento local deste navegador; nada é carregado. Limpe os dados salvos abaixo.

Sua contagem de dias

Como funciona o contador de dias de sobriedade?

Conta dias corridos inteiros a partir da data inserida até hoje. A data de início selecionada é o dia zero; datas posteriores usam aritmética somente de data, portanto, o horário de verão não adiciona ou remove um dia.

Perguntas frequentes

Como funciona o contador de dias de sobriedade?

Conta dias corridos inteiros a partir da data inserida até hoje. A data de início selecionada é o dia zero; datas posteriores usam aritmética somente de data, portanto, o horário de verão não adiciona ou remove um dia.

Minha data de sobriedade foi carregada ou salva?

Nenhum dado foi carregado. Suas datas são usadas apenas neste navegador. Uma nota ou data só poderá ser salva neste dispositivo se você aceitar explicitamente, e você poderá limpar o registro local a qualquer momento.

A data de início conta como o primeiro dia?

Não. A data de início escolhida é o dia zero. A próxima data do calendário é um dia decorrido depois.

Este contador pode fornecer recuperação ou aconselhamento médico?

Não. Conta dias corridos e exibe apenas marcos. Não avalia a saúde, o uso de substâncias, o tratamento ou o progresso pessoal.

As datas e notas são enviadas para um servidor?

Não. Os cálculos são executados no seu navegador. Salvar é opcional e armazena um pequeno registro neste navegador neste dispositivo; você pode limpá-lo aqui.
