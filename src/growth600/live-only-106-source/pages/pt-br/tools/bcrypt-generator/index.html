Gerador Bcrypt

Gere um hash bcrypt padrão ou verifique uma senha em um hash bcrypt existente. O trabalho é executado em um navegador local e a senha é apagada após cada verificação.

Bcrypt usa apenas os primeiros bytes 72 UTF-8. Esta ferramenta rejeita valores mais longos em vez de truncá-los silenciosamente. O custo 8–14 aumenta o trabalho exponencialmente; custos mais elevados podem demorar mais, especialmente em telefones. Um trabalhador local mantém a página responsiva, mas o seu dispositivo executa o trabalho.

Use uma senha de teste, não uma senha de login real. O resultado é para verificações de aprendizagem e compatibilidade; não use esta página do navegador como um sistema de armazenamento de contas de produção.

Cole um hash bcrypt padrão de 60 caracteres. A verificação suporta custos de bcrypt 4–14; Hashes de custo incomumente alto são recusados ​​para evitar trabalho ilimitado em seu dispositivo.

Resultado

O que um hash bcrypt faz?

Bcrypt é uma função de hash de senha, não de criptografia. Ele combina um hash unidirecional com um sal aleatório e um fator de trabalho configurável. Um hash pode ser verificado em relação a uma senha candidata, mas não pode ser descriptografado para revelar a original.

Perguntas frequentes

O que um hash bcrypt faz?

Bcrypt é uma função de hash de senha, não de criptografia. Ele combina um hash unidirecional com um sal aleatório e um fator de trabalho configurável. Um hash pode ser verificado em relação a uma senha candidata, mas não pode ser descriptografado para revelar a original.

Minha senha ou hash foram carregados ou salvos?

Não. Hashing e verificação são executados neste navegador. A página não envia a senha ou hash digitado para um servidor nem os salva; o campo de senha é limpo quando a operação termina. Por segurança, use uma senha de teste em vez de uma senha de conta real.

bcrypt criptografa minha senha?

Não. Bcrypt é um hash de senha unidirecional, não uma criptografia reversível. Ele foi projetado para permitir que o software verifique uma senha candidata sem armazenar a senha original.

Por que bcrypt tem um limite de 72 bytes?

O formato bcrypt processa no máximo bytes 72 UTF-8. Esta ferramenta recusa entradas mais longas para que senhas diferentes nunca sejam tratadas silenciosamente como o mesmo valor truncado.

Devo armazenar esse hash para uma conta real?

Não utilize esta página como um sistema de credenciais de produção. Os serviços reais devem fazer hash de senhas em seus servidores confiáveis ​​com bibliotecas de autenticação mantidas, parâmetros adequados, limites de taxa e proteções de conta.
