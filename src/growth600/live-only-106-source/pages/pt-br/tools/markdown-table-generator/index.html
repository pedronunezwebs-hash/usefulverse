Insira uma linha de cabeçalho e linhas de dados, escolha o alinhamento de cada coluna e copie o Markdown gerado. Os tubos são escapados e as linhas importadas irregulares são preenchidas.

Perguntas frequentes

Como faço uma tabela Markdown?

Insira uma linha de cabeçalho e linhas de dados, escolha o alinhamento de cada coluna e copie o Markdown gerado. Os tubos são escapados e as linhas importadas irregulares são preenchidas.

Minha tabela foi carregada?

Não. Sua tabela é processada nesta guia do navegador. Importações, edições e Markdown gerados não são enviados para um servidor nem salvos automaticamente.

Posso importar CSV ou TSV?

Sim. Cole valores separados por vírgula, ponto e vírgula ou separados por tabulação e importe-os para a grade editável. Campos CSV entre aspas e separadores entre aspas são suportados.

Como são tratadas as quebras de tubos e linhas?

Um canal dentro de uma célula tem escape para não dividir a tabela Markdown. As barras invertidas também têm escape e as quebras de linha de célula são representadas com <br>.
