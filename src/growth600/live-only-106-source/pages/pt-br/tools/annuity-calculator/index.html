DE USO GRATUITO, SEM CONTA

Calculadora de Anuidade

Modele um fluxo de pagamentos iguais com valor inicial, taxa e cronograma. Os resultados são estimativas, não uma cotação ou aconselhamento financeiro.

Assume uma taxa anual nominal fixa dividida pela frequência de pagamento; exclui taxas, impostos e alterações de taxas.

Resultado

Como funciona uma calculadora de anuidade?

Aplica uma taxa anual nominal fixa dividida pela frequência de pagamento a uma série de pagamentos iguais. Os pagamentos normais acontecem no final de cada período; os pagamentos de anuidades devidas acontecem no início. Não modela taxas, impostos, taxas variáveis ​​ou contrato de uma seguradora específica.

Perguntas frequentes

Como funciona uma calculadora de anuidade?

Aplica uma taxa anual nominal fixa dividida pela frequência de pagamento a uma série de pagamentos iguais. Os pagamentos normais acontecem no final de cada período; os pagamentos de anuidades devidas acontecem no início. Não modela taxas, impostos, taxas variáveis ​​ou contrato de uma seguradora específica.

Meus valores foram carregados?

Não. O cálculo é executado nesta guia do navegador e os valores não são carregados ou salvos por esta ferramenta.

Qual é a diferença entre valor presente e valor futuro?

O valor presente estima quanto vale um fluxo de pagamento agora. O valor futuro estima como o saldo inicial e as contribuições recorrentes podem se acumular ao final do cronograma.

Isso prevê o pagamento de um contrato de anuidade?

Não. É aritmética geral com as suposições inseridas. Os produtos reais podem incluir taxas, garantias, impostos e termos que esta calculadora não modela.
