Gerador de palavras aleatórias

Encontre palavras para escrever, jogar em sala de aula ou despertar ideias. Escolha uma categoria e o tamanho, depois copie ou baixe a lista.

Use a mesma semente para repetir a lista.

A lista é pequena de propósito; não é um dicionário de tradução nem de frequência.

Suas palavras

    Como gerar palavras aleatórias?

    Escolha uma categoria, defina o intervalo de tamanho e a quantidade de resultados e selecione Gerar. Deixe a semente vazia para obter uma nova lista ou reutilize-a para repetir a seleção.

    Perguntas frequentes

    Como gerar palavras aleatórias?

    Escolha uma categoria, defina o intervalo de tamanho e a quantidade de resultados e selecione Gerar. Deixe a semente vazia para obter uma nova lista ou reutilize-a para repetir a seleção.

    Minhas palavras são enviadas?

    Não. A lista é escolhida em um pequeno dicionário integrado ao navegador. Nada é enviado ou salvo.

    Posso receber uma lista diferente a cada vez?

    Sim. Deixe a semente vazia para criar uma nova lista. Reutilize uma semente para repetir a seleção com os mesmos filtros e o mesmo dicionário.

    O gerador inclui todas as palavras?

    Não. Ele usa uma lista pequena e escolhe de forma uniforme entre as palavras que correspondem aos filtros.

    Início

    Ferramentas gratuitas no navegador. Seus dados permanecem no seu dispositivo, conforme permitido pela ferramenta.
