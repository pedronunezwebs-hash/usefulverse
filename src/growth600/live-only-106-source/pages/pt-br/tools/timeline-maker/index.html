Como faço um cronograma de evento?

Adicione pelo menos dois eventos nomeados e escolha uma data de início para cada um. Adicione uma data de término por um período ou deixe em branco para um evento de um único dia. Crie a linha do tempo para classificar eventos por data, ajustar o zoom e baixar arquivos SVG ou CSV.

Perguntas frequentes

Como faço um cronograma de evento?

Adicione pelo menos dois eventos nomeados e escolha uma data de início para cada um. Adicione uma data de término por um período ou deixe em branco para um evento de um único dia. Crie a linha do tempo para classificar eventos por data, ajustar o zoom e baixar arquivos SVG ou CSV.

Os eventos da minha linha do tempo foram carregados?

Não. Nomes e datas são processados nesta guia do navegador. O SVG e CSV são gerados no seu dispositivo; nada é carregado ou salvo automaticamente.

Um evento pode durar mais de um dia?

Sim. Insira uma data de início e de término. O gráfico inclui ambas as datas de término; deixe o final em branco para um evento de um dia.

Esta linha do tempo cria dependências de tarefas?

Não. Mostra eventos datados e intervalos em ordem cronológica. Use uma ferramenta de cronograma de projeto para tarefas, durações e dependências.

Posso salvar ou compartilhar a linha do tempo?

Faça download de um SVG para uma imagem escalável ou de um CSV para a tabela de eventos. A página não carrega nem salva automaticamente os dados do seu evento.
