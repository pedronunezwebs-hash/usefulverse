Conversor XML para CSV

Transforme uma lista de registros XML simples em uma tabela CSV ou crie registros XML a partir do texto de um arquivo CSV. Escolha a direção, cole seus dados e copie ou baixe o resultado. Nada é carregado.

Suporta uma lista simples de elementos de registro com o mesmo nome ou um registro simples. Os elementos filhos devem ser valores escalares; campos aninhados e repetidos não são nivelados.

Utilize a primeira linha para nomes de colunas. Um cabeçalho como @id torna-se um atributo XML. Utilize #text para texto de registro.

Esta é uma conversão de tabela simples, não uma conversão de formato XML sem perdas. Namespaces, estruturas aninhadas, conteúdo misto, comentários e formatação XML não são preservados. O texto não reconhece o tipo. Os valores CSV semelhantes a fórmulas de planilha são prefixados com um apóstrofo por segurança.

Resultado

Verifique a saída antes de importá-la para outro aplicativo.

Como faço para converter XML em CSV?

Escolha XML para CSV e cole XML com uma lista de registros simples. Elementos de registro direto repetidos tornam-se linhas. Os nomes dos elementos tornam-se colunas; atributos usam @name. Escolha CSV para XML para criar registros XML simples a partir de cabeçalhos e linhas.

Perguntas frequentes

Como faço para converter XML em CSV?

Escolha XML para CSV e cole XML com uma lista de registros simples. Elementos de registro direto repetidos tornam-se linhas. Os nomes dos elementos tornam-se colunas; atributos usam @name. Escolha CSV para XML para criar registros XML simples a partir de cabeçalhos e linhas.

Meu XML ou CSV foi carregado?

Não. A análise e a conversão são executadas neste navegador. A entrada é limitada a 200.000 caracteres, 5.000 linhas, 64 colunas e 20.000 células. As declarações de DTD e de entidade são bloqueadas e os recursos externos não são obtidos.

Como os atributos XML são mostrados em CSV?

Um atributo como id="101" torna-se uma coluna chamada @id. Ao converter novamente, um cabeçalho CSV que começa com @ se torna um atributo XML.

É possível converter XML aninhado em uma tabela simples?

Não. Estruturas filho aninhadas, campos repetidos dentro de um registro e texto misto são rejeitados em vez de serem nivelados ou perdidos silenciosamente. Use um fluxo de trabalho XML para JSON dedicado para dados aninhados.

O CSV preservará os tipos e a formatação XML?

Não. O CSV armazena texto de célula, não tipos XML, namespaces ou formatação. Os valores de células semelhantes a fórmulas recebem um prefixo de apóstrofo quando exportados para reduzir o risco de execução de fórmulas de planilhas.
