Verificador de acessibilidade de PDF

Inspecione um PDF localmente em busca de alguns sinais de acessibilidade detectáveis por máquina, incluindo tags de documentos, metadados, texto selecionável, figuras sem texto alternativo e saltos de nível de título. Este é apenas um verificador de primeira passagem, não um validador de PDF/UA ou um substituto para testes de tecnologia assistiva.

Máximo de 25 MiB e 300 páginas. A inspeção pode usar a memória do dispositivo; um computador é recomendado para arquivos grandes.

é executada no seu dispositivo depois que você escolhe um arquivo. Sem upload, conta, API, salvamento automático ou processamento de servidor.

Essas verificações são heurísticas. Eles não podem confirmar a ordem de leitura correta, descrições significativas, contraste de cores, uso do teclado, rótulos de formulário, relações de cabeçalho de tabela ou conformidade com PDF/UA/Seção 508/WCAG. Revise manualmente e teste com tecnologia assistiva.

Inspection report

O que este verificador de acessibilidade de PDF pode detectar?

Informa se o PDF apresenta tags de estrutura, título e idioma do documento, texto selecionável em cada página, figuras com texto alternativo e possíveis saltos nos níveis de cabeçalho. Ele não pode decidir se a ordem de leitura ou o texto alternativo são significativos.

Perguntas frequentes

O que este verificador de acessibilidade de PDF pode detectar?

Informa se o PDF apresenta tags de estrutura, título e idioma do documento, texto selecionável em cada página, figuras com texto alternativo e possíveis saltos nos níveis de cabeçalho. Ele não pode decidir se a ordem de leitura ou o texto alternativo são significativos.

Meu PDF foi carregado para verificação?

Não. O PDF selecionado é inspecionado nesta guia do navegador. O arquivo e seu texto não são carregados, salvos automaticamente ou enviados para um servidor.

Um resultado positivo significa que o PDF está acessível?

Não. Estes são apenas sinais automatizados limitados. Um PDF marcado ainda pode ter ordem de leitura incorreta, descrições ruins, formulários inacessíveis, baixo contraste ou outras barreiras. Testes manuais e de tecnologia assistiva ainda são necessários.

É possível confirmar a conformidade com PDF/UA ou WCAG?

Não. Este verificador de primeira passagem não testa todos os requisitos e não pode certificar PDF/UA, WCAG, Seção 508 ou conformidade legal.
