Perguntas frequentes

Como configurar um alarme online?

Escolha uma data e hora futuras no fuso horário local do seu dispositivo e selecione Definir alarme. O som é opcional. Você pode testá-lo primeiro, adiar por cinco minutos ou interrompê-lo quando tocar.

Esse alarme envia dados ou funciona após fechar a página?

Nenhum dado é enviado ou salvo. O alarme é executado apenas nesta página e não pode alertá-lo de forma confiável se a guia fechar, o navegador pausar ou o dispositivo entrar em suspensão.

O alarme tocará se eu fechar a aba?

Não. Este é um alarme na página, não um alarme ou notificação do sistema operacional. Mantenha a página aberta e o dispositivo ativo; para lembretes importantes, use o aplicativo de alarme do seu dispositivo.

Posso suspender o alarme?

Sim. Quando tocar, escolha Suspender 5 minutos para agendá-lo novamente a partir do horário atual.

O alarme usa minha localização ou economiza meu tempo?

Não. Utiliza a hora local configurada no seu dispositivo. O alarme é mantido apenas na página aberta e não é carregado ou salvo.
