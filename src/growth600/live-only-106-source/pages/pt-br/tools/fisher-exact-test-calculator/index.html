Quando devo usar o teste exato de Fisher?

É um teste exato de associação para uma tabela 2×2, frequentemente usado quando as contagens esperadas são pequenas. O resultado depende do desenho do estudo e não prova a causalidade.

Perguntas frequentes

Quando devo usar o teste exato de Fisher?

É um teste exato de associação para uma tabela 2×2, frequentemente usado quando as contagens esperadas são pequenas. O resultado depende do desenho do estudo e não prova a causalidade.

Minhas contagens foram carregadas?

Não. O cálculo é executado neste navegador. As contagens não são carregadas ou armazenadas por esta ferramenta.

Qual é a hipótese nula?

O teste avalia se as classificações de linhas e colunas são independentes, condicionadas às margens observadas. Não explica por que uma associação pode existir.

Como é calculado um valor p bilateral?

Esta calculadora adiciona probabilidades de todas as tabelas possíveis com as mesmas margens cuja probabilidade condicional não é maior que a da tabela observada. Outras convenções de software podem ser diferentes.

Um valor p pequeno prova um efeito?

Não. Um valor p não é um tamanho de efeito ou prova de causalidade. Revise a razão de chances, o desenho do estudo, a qualidade dos dados, a incerteza e qualquer plano de testes múltiplos.
