Paciência Spider

Construa sequências descendentes no mesmo naipe de cartas, do Rei ao Ás, revele as cartas viradas para baixo e complete todas as oito sequências. Escolha um, dois ou quatro naipes de cartas.

Deixe em branco para um novo jogo aleatório. Reutilize a mesma semente para reproduzir a mesma distribuição embaralhada; fica apenas nesta página.

Sequências concluídas: 0/8

Move: 0

Apenas grupos descendentes virados para cima do mesmo naipe podem se mover juntos. Uma única carta virada para cima pode mover-se sozinha. As cartas viradas para baixo viram quando expostas.

As execuções concluídas são removidas automaticamente. Colunas vazias aceitam qualquer carta virada para cima ou corrida válida.

Como você joga Paciência Spider?

Move sequências descendentes viradas para cima do mesmo naipe de cartas para a próxima classificação mais alta ou para uma coluna vazia. Revele cartas ocultas, compre dez cartas da pilha de estoque quando todas as colunas estiverem ocupadas e complete oito sequências King-to-Ace do mesmo naipe para vencer.

Perguntas frequentes

Como você joga Paciência Spider?

Revele cartas ocultas, compre dez cartas da pilha de estoque quando todas as colunas estiverem ocupadas e complete oito sequências King-to-Ace do mesmo naipe para vencer.

O Paciência Spider salva meu jogo?

Não. O jogo roda nesta aba e não salva jogo, usa conta, carrega movimentos ou os envia para um servidor. Iniciar um novo acordo substitui o jogo atual.

Qual é a diferença entre um, dois e quatro naipes?

Um naipe de cartas é o modo mais relaxado, dois naipes adicionam outro naipe e quatro naipes exigem a correspondência do naipe em um quadro de naipes mistos.

Quando posso comprar cartas da pilha de estoque?

Compre dez cartas, uma para cada coluna, enquanto restar o estoque. Cada coluna do tabuleiro deve conter pelo menos uma carta antes de ser retirada da pilha de estoque.

Como funciona o desfazer?

Desfazer restaura o estado exato do jogo anterior para uma movimentação, negociação de ações ou remoção de execução concluída. Até 100 ações recentes são mantidas somente nesta aba.
