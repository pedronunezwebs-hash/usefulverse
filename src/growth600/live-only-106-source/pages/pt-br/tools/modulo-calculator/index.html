Calculadora de Módulo

Calcule o quociente euclidiano e o resto para números inteiros. As entradas negativas são tratadas de forma consistente e a identidade da divisão mostra como a resposta é formada.

O número a ser dividido; pode ser negativo.

Use qualquer número inteiro diferente de zero; seu valor absoluto define o módulo.

Verifique se este valor é congruente com o módulo do dividendo do divisor.

Aceita números inteiros assinados com até 50 dígitos. Sem frações ou decimais. O resultado usa módulo euclidiano; algumas linguagens de programação usam uma regra de resto diferente para negativos.

Resultado

Como você calcula um módulo com um número negativo?

Esta calculadora usa um resto não negativo menor que o divisor absoluto. Por exemplo, −7 mod 3 é 2 porque −7 = (−3 × 3) + 2.

Perguntas frequentes

Como você calcula um módulo com um número negativo?

Esta calculadora usa um resto não negativo menor que o divisor absoluto. Por exemplo, −7 mod 3 é 2 porque −7 = (−3 × 3) + 2.

Meus números foram carregados?

Não. O cálculo exato é executado neste navegador. Os números não são carregados ou salvos.

O que é −7 mod 3?

Usando a convenção euclidiana, −7 mod 3 é 2: −7 = (−3 × 3) + 2 e 0 ≤ 2 < 3.

O que significa módulo m congruente?

Dois inteiros são congruentes módulo m quando sua diferença é divisível por |m|. A comparação opcional verifica isso exatamente.

Por que isso pode ser diferente do operador % de uma linguagem de programação?

Algumas línguas mantêm o sinal de dividendo negativo no restante. Em vez disso, esta calculadora retorna um resto de 0 até, mas não incluindo, o divisor absoluto.
