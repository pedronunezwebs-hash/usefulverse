Calculadora de tamanho de efeito

Insira estatísticas resumidas para dois grupos independentes para calcular sua diferença média padronizada assinada, desvio padrão agrupado e g de Hedges corrigido para amostras pequenas.

Para grupos independentes, esta versão utiliza a definição convencional de SD agrupado e assume uma variância populacional partilhada. Insira os desvios padrão da amostra (n−1), não os erros padrão.

Cada tamanho de amostra deve ser de 2 a 1.000.000; médias e SDs são limitados a ±1.000.000.000 (SDs não podem ser negativos). Pelo menos um SD deve estar acima de zero.

Resultados do tamanho do efeito

d = (média₁ - média₂) / DP agrupado. Hedges 'g = J (df) × d, com df = n₁ + n₂ − 2. O sinal depende da ordem do grupo. Uma magnitude não é automaticamente “pequena”, “média” ou “grande”; interpretá-lo na área temática e no desenho do estudo.

O que uma calculadora de tamanho de efeito mede?

Expressa a diferença entre duas médias de grupos em unidades agrupadas de desvio padrão. d de Cohen é a diferença padronizada não corrigida; O g de hedge aplica uma correção para amostras pequenas.

Perguntas frequentes

O que uma calculadora de tamanho de efeito mede?

Expressa a diferença entre duas médias de grupos em unidades agrupadas de desvio padrão. d de Cohen é a diferença padronizada não corrigida; O g de hedge aplica uma correção para amostras pequenas.

As estatísticas do meu estudo são carregadas?

Não. O cálculo é executado neste navegador. Suas estatísticas resumidas não são enviadas para um servidor nem salvas por esta ferramenta.

Qual é a diferença entre o d de Cohen e o g de Hedges?

Ambos padronizam a diferença média por um desvio padrão combinado. O g de hedge multiplica d por uma correção para amostras pequenas, o que reduz o viés quando as amostras são pequenas.

Posso inserir erros padrão em vez de desvios padrão?

Não. Esta calculadora espera o desvio padrão da amostra de cada grupo. Um erro padrão descreve a incerteza em uma estimativa amostral e não é intercambiável com o SD aqui.

Um tamanho de efeito maior prova que um resultado é importante?

Não. O tamanho do efeito descreve uma diferença padronizada, não significância estatística, causalidade ou importância prática. O contexto, a incerteza, o desenho do estudo e a escala de medição são importantes.
