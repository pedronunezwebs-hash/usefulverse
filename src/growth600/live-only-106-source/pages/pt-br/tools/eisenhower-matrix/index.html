Uso gratuito, sem necessidade de conta

Matriz de Eisenhower

Transforme uma lista de tarefas em quatro opções claras: fazer, agendar, delegar ou descartar. Você decide o que é importante e urgente; datas são lembretes, não julgamentos automáticos.

Classifique tarefas usando seu próprio contexto; a matriz não decide a importância para você. Os dados permanecem na memória nesta guia e são apagados quando você os fecha ou recarrega, a menos que você exporte um backup. A importação aceita apenas backup JSON desta ferramenta, até 1 MB e 300 tarefas.

Importante significa que afeta significativamente uma meta, responsabilidade ou resultado de seu interesse.

Urgente significa que precisa de atenção logo devido a um prazo ou consequência real; a data de vencimento por si só não decide a importância.

Faça primeiro

Urgente e importante: aja agora.

    Schedule

    Importante, não urgente: reserve tempo antes que se torne urgente.

      Delegado

      Urgente, menos importante: entregue quando apropriado e acompanhe o acompanhamento.

        Considere descartar

        Nem urgente nem importante: remova-o ou deixe-o fora do seu plano.

          Como você usa a Matriz de Eisenhower?

          Escolha um dos quatro quadrantes para cada tarefa: urgente e importante para fazer, importante mas não urgente para agendar, urgente mas menos importante para delegar ou nenhum dos dois para considerar abandonar. Você pode alterar o quadrante de uma tarefa a qualquer momento.

          Perguntas frequentes

          Como você usa a Matriz de Eisenhower?

          Escolha um dos quatro quadrantes para cada tarefa: urgente e importante para fazer, importante mas não urgente para agendar, urgente mas menos importante para delegar ou nenhum dos dois para considerar abandonar. Você pode alterar o quadrante de uma tarefa a qualquer momento.

          Minhas tarefas da Matriz Eisenhower são privadas?

          As tarefas permanecem nesta guia do navegador e não são carregadas ou salvas automaticamente. Exporte um backup JSON se quiser mantê-lo e importe esse arquivo posteriormente neste dispositivo.

          O que se passa em cada quadrante da Matriz de Eisenhower?

          Faça primeiro o trabalho urgente e importante. Agende trabalhos importantes que não sejam urgentes. Delegue trabalhos urgentes que são menos importantes quando outra pessoa pode cuidar deles. Considere abandonar tarefas que não são urgentes nem importantes.

          Uma data de vencimento torna automaticamente uma tarefa urgente ou importante?

          Não. Uma data de vencimento pode ajudá-lo a avaliar a urgência, mas você decide a urgência e a importância com base em prazos, consequências e metas reais.

          Início

          Ferramentas gratuitas no navegador. Seus dados permanecem no seu dispositivo, conforme permitido pela ferramenta.
