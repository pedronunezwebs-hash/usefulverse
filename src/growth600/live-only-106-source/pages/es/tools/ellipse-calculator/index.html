Calculadora de elipses

Ingrese los dos semiejes de una elipse para encontrar su área, distancia focal, excentricidad y una aproximación del perímetro claramente etiquetada.

Introduzca longitudes de semieje positivas en la misma unidad, hasta 1.000.000.000. El área utiliza el cuadrado de esa unidad. El perímetro utiliza la segunda aproximación de Ramanujan, no una fórmula elemental exacta.

Propiedades de la elipse

Área = πab. Distancia centro-foco c = √(A² − B²), donde A es el semieje mayor y B es el semieje menor. Excentricidad e = c/A. El perímetro usa Ramanujan II con h = ((A - B)/(A + B))².

¿Qué puede encontrar una calculadora de elipses?

Dados dos semiejes positivos, identifica los ejes mayor y menor, calcula el área y la distancia de enfoque y estima el perímetro utilizando la segunda aproximación de Ramanujan.

Preguntas frecuentes

¿Qué puede encontrar una calculadora de elipses?

Dados dos semiejes positivos, identifica los ejes mayor y menor, calcula el área y la distancia de enfoque y estima el perímetro utilizando la segunda aproximación de Ramanujan.

¿Están cargadas mis medidas?

No. La geometría se calcula en este navegador. Esta herramienta no envía sus valores a un servidor ni los almacena.

¿Cómo calculo el área de una elipse?

Multiplica π por el semieje mayor y el semieje menor. Si a y b son los semiejes, el área es πab.

¿Es exacto el perímetro de la elipse?

No. No existe una forma cerrada elemental simple para el perímetro de una elipse general. Esta herramienta utiliza la segunda aproximación de Ramanujan y la etiqueta como aproximada.

¿Qué significan los focos y la excentricidad?

Los dos focos se encuentran en el eje mayor a distancias iguales del centro. La excentricidad varía desde 0 para un círculo hasta 1 para elipses cada vez más alargadas.
