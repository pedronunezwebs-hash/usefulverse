Crucigrama en línea

Resuelva un nuevo crucigrama generado localmente a partir de un pequeño conjunto de pistas originales. Seleccione una pista o un cuadrado, escriba con su teclado y verifique o revele respuestas cuando necesite ayuda.

Las respuestas ignoran los espacios y las letras mayúsculas. El conjunto de pistas es finito y original; un nuevo tablero reorganiza sus entradas pero no promete una alimentación diaria ilimitada de rompecabezas.

: escriba una letra, use las flechas para moverse y presione Retroceso para borrar un cuadrado.

    Abajo

      ¿Cómo juego este crucigrama?

      Elija una pista transversal o inferior, luego escriba letras en los cuadrados seleccionados. Utilice las teclas de flecha para moverse dentro de la respuesta. Comprueba una palabra o todo el rompecabezas, revela una letra o la respuesta completa, o comienza un nuevo tablero barajado.

      Preguntas frecuentes

      ¿Cómo juego este crucigrama?

      Elija una pista transversal o inferior, luego escriba letras en los cuadrados seleccionados. Utilice las teclas de flecha para moverse dentro de la respuesta. Comprueba una palabra o todo el rompecabezas, revela una letra o la respuesta completa, o comienza un nuevo tablero barajado.

      ¿Se cargan o guardan mis respuestas?

      No. El acertijo, las respuestas y la puntuación permanecen en esta pestaña del navegador. No hay cuenta, carga, procesamiento del servidor ni historial de juego guardado.

      ¿Este crucigrama incluye un feed de rompecabezas diario ilimitado?

      No. La página crea tableros barajados a partir de un conjunto pequeño y finito de pares originales de pistas y respuestas. No busca ni reclama una biblioteca de acertijos diaria ilimitada.

      ¿Puedo usar este crucigrama sin subir nada?

      Sí. El tablero y sus respuestas se ejecutan en esta pestaña del navegador. La herramienta no carga tu juego ni requiere una cuenta.

      ¿Es este un creador de crucigramas?

      No. Esta página es para jugar pistas. Utilice el Creador de crucigramas independiente cuando desee organizar sus propios pares de respuestas y pistas.
