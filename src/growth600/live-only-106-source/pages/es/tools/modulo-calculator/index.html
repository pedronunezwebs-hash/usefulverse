Calculadora de módulo

Calcular el cociente y resto euclidiano para números enteros. Las entradas negativas se manejan de manera consistente y la identidad de división muestra cómo se forma la respuesta.

El número a dividir; puede ser negativo.

Utilice cualquier número entero distinto de cero; su valor absoluto define el módulo.

Compruebe si este valor es congruente con el módulo del dividendo del divisor.

Acepta números enteros con signo de hasta 50 dígitos. Sin fracciones ni decimales. El resultado utiliza el módulo euclidiano; Algunos lenguajes de programación utilizan una regla de resto diferente para los negativos.

Resultado

¿Cómo se calcula un módulo con un número negativo?

Esta calculadora utiliza un resto no negativo más pequeño que el divisor absoluto. Por ejemplo, −7 mod 3 es 2 porque −7 = (−3 × 3) + 2.

Preguntas frecuentes

¿Cómo se calcula un módulo con un número negativo?

Esta calculadora utiliza un resto no negativo más pequeño que el divisor absoluto. Por ejemplo, −7 mod 3 es 2 porque −7 = (−3 × 3) + 2.

¿Están cargados mis números?

No. El cálculo exacto se ejecuta en este navegador. Los números no se cargan ni guardan.

¿Qué es −7 mod 3?

Usando la convención euclidiana, −7 mod 3 es 2: −7 = (−3 × 3) + 2, y 0 ≤ 2 < 3.

¿Qué significa módulo m congruente?

Dos números enteros son congruentes módulo m cuando su diferencia es divisible por |m|. La comparación opcional comprueba esto exactamente.

¿Por qué puede diferir del operador % de un lenguaje de programación?

Algunos idiomas mantienen el signo de dividendo negativo en el resto. En cambio, esta calculadora devuelve un resto desde 0 hasta el divisor absoluto, pero sin incluirlo.
