Calculadora de programación lineal

Introduzca un objetivo lineal y hasta ocho restricciones para resolver un programa lineal de dos variables con xey no negativos. El método simplex de dos fases informa un óptimo, inviabilidad o ilimitación y muestra cada pivote.

Coeficientes objetivos (x, y)

Uno por línea: a,b <= rhs, a,b >= rhs o a,b = rhs

Utiliza como máximo ocho restricciones y coeficientes/lados derechos dentro de ±1.000.000. Ambas variables de decisión tienen x ≥ 0 e y ≥ 0. Utilice una coma entre los coeficientes xey; ingrese una desigualdad o igualdad por línea.

Un solucionador simplex primario de dos fases para dos variables. La tolerancia numérica se utiliza para pivotes de punto flotante; Los problemas casi degenerados pueden ser sensibles al redondeo. Se informan casos inviables, ilimitados y con límite de iteración en lugar de un óptimo inventado.

Resultados del programa lineal

El resultado es sólo para el modelo matemático que ingresó. No valida si el objetivo, las restricciones, las unidades o los supuestos son apropiados para una decisión real.

    ¿Cómo funciona la calculadora simplex de dos variables?

    Convierte las restricciones en un cuadro factible, utiliza un objetivo de Fase I cuando es necesario y luego aplica pivotes simples primarios para optimizar el objetivo solicitado. Las variables xey están obligadas a ser no negativas.

    Preguntas frecuentes

    ¿Cómo funciona la calculadora simplex de dos variables?

    Convierte las restricciones en un cuadro factible, utiliza un objetivo de Fase I cuando es necesario y luego aplica pivotes simples primarios para optimizar el objetivo solicitado. Las variables xey están obligadas a ser no negativas.

    ¿Están cargados mi objetivo y mis limitaciones?

    No. El solucionador se ejecuta en este navegador. Su objetivo y sus limitaciones no se envían a un servidor ni se guardan mediante esta herramienta.

    ¿Qué formato debo usar para las restricciones?

    Introduzca una fila por línea, como 1,1 <= 5 o 2,1 >= 4. El primer número multiplica x, el segundo multiplica y y ambas variables deben ser no negativas.

    ¿Qué significan infactibles e ilimitados?

    Inviable significa que ningún punto satisface todas las restricciones ingresadas. Ilimitado significa que una dirección factible permite que el objetivo solicitado siga mejorando sin un óptimo finito.

    ¿El resultado prueba que mi modelo del mundo real es correcto?

    No. Resuelve solo las ecuaciones que ingresaste. Verifique las unidades, los supuestos y si las restricciones describen adecuadamente su decisión.
