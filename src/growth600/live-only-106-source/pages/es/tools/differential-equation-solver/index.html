Solucionador de ecuaciones diferenciales

Aproxima un problema de valor inicial de primer orden y′ = f(x,y) con Runge-Kutta de paso fijo 4. Ingresa la derivada, el punto y valor inicial, el punto final y el recuento de pasos. Todo se ejecuta en este navegador.

Utilice x e y, números, + − × ÷ y ^. Funciones admitidas: sin, cos, tan, exp, ln, log, sqrt y abs. Escribe la multiplicación explícitamente, como x*y.

RK4 clásico de paso fijo solo para una EDO de valor inicial de primer orden. Admite hasta 10.000 pasos; x debe permanecer dentro de ±1.000.000 y y dentro de ±1.000.000.000.000. El gráfico y el CSV muestran hasta aproximadamente 101 puntos de muestra. Los resultados numéricos pueden ser inexactos cerca de discontinuidades, singularidades o ecuaciones rígidas. No encuentra soluciones generales simbólicas ni certifica error.

Solución numérica

¿Cómo funciona el solucionador de ecuaciones diferenciales RK4?

RK4 estima la solución utilizando cuatro evaluaciones de pendiente por paso. Los pasos más pequeños a menudo mejoran la precisión para obtener soluciones fluidas, pero esta estimación numérica no es una solución simbólica o exacta.

Preguntas frecuentes

¿Cómo funciona el solucionador de ecuaciones diferenciales RK4?

RK4 estima la solución utilizando cuatro evaluaciones de pendiente por paso. Los pasos más pequeños a menudo mejoran la precisión para obtener soluciones fluidas, pero esta estimación numérica no es una solución simbólica o exacta.

¿Están cargados mi ecuación y mis valores?

No. El cálculo, el gráfico y el CSV se crean en este navegador. Esta herramienta no carga ni guarda sus entradas.

¿Qué calcula el método Runge-Kutta?

Estima la ruta de una solución desde un punto de partida utilizando repetidamente varias muestras derivadas en cada paso. Esta página utiliza el método RK clásico de cuarto orden.

¿Cuántos pasos debo utilizar?

Comience con el ejemplo y compare los resultados usando más pasos. Un paso más pequeño puede mejorar una solución fluida, pero no puede arreglar una singularidad ni hacer que una ecuación rígida sea adecuada para este método básico.

¿Puede resolver exactamente todas las ecuaciones diferenciales?

No. Se aproxima numéricamente a los problemas de valor inicial de primer orden admitidos. No proporciona una solución general simbólica, no prueba la unicidad ni garantiza un límite de error.
