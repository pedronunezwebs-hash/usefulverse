Preguntas frecuentes

¿Cómo configuro una alarma en línea?

elija una fecha y hora futuras en la zona horaria local de su dispositivo, luego seleccione Establecer alarma. El sonido es opcional. Puedes probarlo primero, posponerlo durante cinco minutos o detenerlo cuando suene.

¿Esta alarma envía datos o funciona después de cerrar la página?

No se envían ni guardan datos. La alarma se ejecuta solo en esta página y no puede avisarle de manera confiable si la pestaña se cierra, el navegador la pausa o el dispositivo duerme.

¿Sonará la alarma si cierro la pestaña?

No. Esta es una alarma en la página, no una alarma o notificación del sistema operativo. Mantenga la página abierta y el dispositivo activo; para recordatorios importantes, use la aplicación de alarma de su dispositivo.

¿Puedo posponer la alarma?

Sí. Cuando suene, elija Posponer 5 minutos para programarlo nuevamente desde la hora actual.

¿La alarma utiliza mi ubicación o me ahorra tiempo?

No. Utiliza la hora local configurada en tu dispositivo. La alarma se mantiene solo en la página abierta y no se carga ni se guarda.
