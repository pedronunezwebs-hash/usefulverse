Solitario FreeCell

Mueve las 52 cartas a las bases de su palo. Usa las cuatro celdas libres como espacio temporal, forma columnas descendentes alternando colores y planifica cada supermovimiento según las celdas y columnas vacías.

Déjalo vacío para un reparto aleatorio. Usa el mismo código para repetirlo; solo permanece en esta página.

Mueve: 0

Las tarjetas del cuadro se construyen hacia abajo en colores alternos. Una carrera seleccionada ya debe alternar colores y descender un rango. Un supermovimiento está limitado por las celdas libres y las columnas auxiliares actualmente vacías.

Las bases se construyen desde el As hasta el Rey del mismo palo. Sólo se puede mover la carta superior de una columna o una carta en una celda libre.

¿Cómo se juega FreeCell?

Construye cada base desde el As hasta el Rey en un solo palo. En el cuadro, construya hacia abajo alternando colores. Una celda libre puede contener una tarjeta. Puede mover una ejecución descendente de color alternativo válida como supermovimiento solo cuando las celdas vacías y las columnas auxiliares disponibles puedan soportarlo.

Preguntas frecuentes

¿Cómo se juega FreeCell?

Construye cada base desde el As hasta el Rey en un solo palo. En el cuadro, construya hacia abajo alternando colores. Una celda libre puede contener una tarjeta. Puede mover una ejecución descendente de color alternativo válida como supermovimiento solo cuando las celdas vacías y las columnas auxiliares disponibles puedan soportarlo.

¿FreeCell guarda mi juego?

No. El juego se ejecuta en esta pestaña del navegador. No utiliza una cuenta, no carga movimientos ni guarda un juego automáticamente. Una semilla de repetición es opcional y permanece solo en esta página.

¿Cuántas cartas puede mover un supermovimiento FreeCell?

El límite superior es (celdas libres vacías + 1) multiplicado por 2 elevado a la potencia de las columnas auxiliares vacías. La columna de destino no se cuenta como auxiliar cuando está vacía. El recorrido también debe ser descendente y alternar rojo y negro.

¿Puedo mover una secuencia directamente en FreeCell?

Sí, si las tarjetas ya forman una serie descendente de colores alternos y su tamaño no excede la capacidad proporcionada por las celdas libres vacías y las columnas auxiliares. El juego impone este límite.

¿Se pueden reproducir las ofertas de FreeCell?

Sí. Ingrese la misma semilla opcional y elija una nueva oferta para recrear su diseño en este navegador. Deje la semilla en blanco para realizar una mezcla aleatoria. No se envía ninguna semilla ni juego a un servidor.
