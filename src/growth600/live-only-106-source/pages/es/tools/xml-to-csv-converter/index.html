Convertidor de XML a CSV

Convierta una lista de registros XML simple en una tabla CSV o cree registros XML a partir del texto de un archivo CSV. Elija la dirección, pegue sus datos y luego copie o descargue el resultado. No se carga nada.

Admite una lista simple de elementos de registro con el mismo nombre o un registro plano. Los elementos secundarios deben ser valores escalares; Los campos anidados y repetidos no se aplanan.

Utilice la primera fila para los nombres de las columnas. Un encabezado como @id se convierte en un atributo XML. Utilice #text para grabar texto.

Esta es una conversión de tabla simple, no una conversión de formato XML sin pérdidas. No se conservan los espacios de nombres, las estructuras anidadas, el contenido mixto, los comentarios ni el formato XML. El texto no reconoce el tipo. Los valores CSV similares a fórmulas de hojas de cálculo tienen el prefijo un apóstrofe por seguridad.

¿Cómo convierto XML a CSV?

Elija XML a CSV y pegue XML con una lista de registros simple. Los elementos de registro directo repetidos se convierten en filas. Los nombres de los elementos se convierten en columnas; Los atributos utilizan @name. Elija CSV a XML para crear registros XML simples a partir de encabezados y filas.

Preguntas frecuentes

¿Cómo convierto XML a CSV?

Elija XML a CSV y pegue XML con una lista de registros simple. Los elementos de registro directo repetidos se convierten en filas. Los nombres de los elementos se convierten en columnas; Los atributos utilizan @name. Elija CSV a XML para crear registros XML simples a partir de encabezados y filas.

¿Está cargado mi XML o CSV?

No. El análisis y la conversión se ejecutan en este navegador. La entrada está limitada a 200.000 caracteres, 5.000 filas, 64 columnas y 20.000 celdas. Las declaraciones de entidades y DTD se bloquean y no se recuperan recursos externos.

¿Cómo se muestran los atributos XML en CSV?

Un atributo como id="101" se convierte en una columna denominada @id. Al volver a convertir, un encabezado CSV que comienza con @ se convierte en un atributo XML.

¿Puede convertir XML anidado en una tabla plana?

No. Las estructuras secundarias anidadas, los campos repetidos dentro de un registro y el texto mixto se rechazan en lugar de aplanarse o perderse silenciosamente. Utilice un flujo de trabajo de XML a JSON dedicado para datos anidados.

¿El CSV conservará los tipos y el formato XML?

No. CSV almacena texto de celda, no tipos XML, espacios de nombres o formato. Los valores de celda similares a fórmulas obtienen un prefijo de apóstrofe cuando se exportan para reducir el riesgo de ejecución de fórmulas de hojas de cálculo.
