Creador de árboles genealógicos

Crea un cuadro familiar a partir de información que ya conoces. Agregue personas, conecte enlaces principales y luego exporte un diagrama o un archivo GEDCOM. La página no busca registros ni guarda datos de su familia.

    Preguntas frecuentes

    ¿Cómo hago un árbol genealógico?

    agregue a cada persona una vez y luego conecte a un padre con un niño. El gráfico bloquea enlaces duplicados, más de dos padres enumerados y ciclos de ascendencia. Exporte un diagrama SVG o un archivo de texto GEDCOM cuando esté listo.

    ¿Se carga o guarda la información de mi familia?

    No. El gráfico permanece en esta sesión de página. No se carga ni se guarda en el almacenamiento del navegador. Un archivo exportado es suyo para almacenarlo y compartirlo, así que verifíquelo primero para obtener detalles privados.

    ¿Esta herramienta puede encontrar familiares o registros públicos?

    No. Solo organiza los datos que ingresas. No busca registros, verifica identidades ni establece relaciones jurídicas.

    ¿Qué es un archivo GEDCOM?

    GEDCOM es un formato de texto utilizado para mover registros de historia familiar entre programas genealógicos compatibles. Verifique un archivo exportado antes de compartirlo.

    ¿El cuadro admite más de dos padres?

    Esta versión permite hasta dos padres listados por persona. Una relación familiar puede ser más compleja de lo que este cuadro puede representar.
