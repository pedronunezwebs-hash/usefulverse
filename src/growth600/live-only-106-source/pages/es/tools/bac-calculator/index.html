Estimador BAC

Introduce el peso y las bebidas para ver un escenario matemático muy incierto. No mide ni predice de forma fiable el alcohol en sangre.

No uses esta estimación para decidir si puedes conducir, manejar maquinaria o tomar decisiones médicas o legales. No es una prueba ni una predicción fiable. Cualquier cantidad de alcohol puede afectar a la conducción. Si has bebido, no conduzcas: busca un transporte sobrio. Ante pérdida de consciencia, convulsiones o respiración lenta o irregular, llama a emergencias.

Introduzca un peso aproximado actual. La herramienta convierte libras a kilogramos cuando se selecciona. Ingrese hasta 8 tipos de bebidas. Utilice la cuenta 0 para no consumir alcohol; cada fila asume porciones y fuerza idénticas.

¿Cómo funciona este escenario BAC?

Convierte las entradas de bebidas a gramos de etanol, aplica una estimación de distribución simplificada estilo Widmark con suposiciones amplias y luego resta un amplio rango de eliminación ilustrativo basado en el tiempo transcurrido. Asume una absorción inmediata y no puede modelar su cuerpo ni el momento de cada bebida.

Preguntas frecuentes

¿Cómo funciona este escenario BAC?

Convierte las entradas de bebidas a gramos de etanol, aplica una estimación de distribución simplificada estilo Widmark con suposiciones amplias y luego resta un amplio rango de eliminación ilustrativo basado en el tiempo transcurrido. Asume una absorción inmediata y no puede modelar su cuerpo ni el momento de cada bebida.

¿Están cargadas mis entradas?

No. El cálculo se ejecuta en este navegador. Las entradas no se cargan, almacenan ni envían a un servidor.

¿Esto puede decirme si puedo conducir con seguridad?

No. Nunca uses una calculadora para tomar esa decisión. Las estimaciones de BAC tienen una incertidumbre sustancial, el deterioro puede comenzar por debajo de los límites legales y el alcohol aún puede absorberse después del último trago. Si bebió, no conduzca; organizar un viaje sobrio.

¿El resultado es mi nivel real de alcohol en sangre?

No. Es una ilustración simplificada al estilo de Widmark, no una prueba ni una predicción confiable. A partir de estas entradas no se conocen la composición corporal, la absorción, la alimentación, la salud, los medicamentos, el horario de bebida y muchos otros factores.

¿Por qué muestra una amplia gama?

Los supuestos de distribución y eliminación varían ampliamente entre personas. El rango es ilustrativo y no puede garantizar que una medida real caiga dentro del mismo.
