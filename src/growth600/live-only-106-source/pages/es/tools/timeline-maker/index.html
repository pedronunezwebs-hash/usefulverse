¿Cómo hago una línea de tiempo de un evento?

Agregue al menos dos eventos con nombre y elija una fecha de inicio para cada uno. Agregue una fecha de finalización para una duración o déjela en blanco para un evento de un solo día. Cree la línea de tiempo para ordenar eventos por fecha, ajustar el zoom y descargar archivos SVG o CSV.

Preguntas frecuentes

¿Cómo hago una línea de tiempo de un evento?

Agregue al menos dos eventos con nombre y elija una fecha de inicio para cada uno. Agregue una fecha de finalización para una duración o déjela en blanco para un evento de un solo día. Cree la línea de tiempo para ordenar eventos por fecha, ajustar el zoom y descargar archivos SVG o CSV.

¿Se han subido mis eventos de la línea de tiempo?

No. Los nombres y las fechas se procesan en esta pestaña del navegador. El SVG y el CSV se generan en su dispositivo; nada se carga ni se guarda automáticamente.

¿Puede un evento durar más de un día?

Sí. Introduzca una fecha de inicio y de finalización. El gráfico incluye ambas fechas finales; deje el final en blanco para un evento de un solo día.

¿Esta línea de tiempo crea dependencias de tareas?

No. Muestra eventos fechados y rangos en orden cronológico. Utilice una herramienta de programación de proyectos para tareas, duraciones y dependencias.

¿Puedo guardar o compartir la línea de tiempo?

Descargue un SVG para una imagen escalable o un CSV para la tabla de eventos. La página no carga ni guarda automáticamente los datos de su evento.
