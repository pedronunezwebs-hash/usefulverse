Buscador de palabras

Encuentra palabras con tus letras, resuelve anagramas o busca patrones para crucigramas. Usa la pequeña lista incluida o pega una lista mayor. Todo se procesa en esta pestaña.

Escribe letras. Usa ? como ficha comodín. Si no marcas «Usar todas las fichas», el resultado puede usar solo algunas.

Escribe las letras conocidas y usa ? o . para cada posición desconocida. Cada símbolo representa una letra.

Pega una palabra por línea. En el modo de lista propia solo se usan estas palabras. Máximo: 250.000 caracteres y 50.000 palabras.

Se quitan las palabras que contengan cualquiera de estas letras.

La lista multilingüe incluida es pequeña. No es un diccionario completo ni una lista oficial de crucigramas o Scrabble. Pega una lista mayor si necesitas más opciones.

Todo se procesa en esta pestaña. La lista pegada no se guarda al salir.

Palabras coincidentes

    ¿Cómo funciona este buscador de palabras?

    Elija el modo de anagrama para buscar palabras que se puedan formar a partir de sus letras, o el modo de patrón para unir letras fijas y ? o . marcadores de posición. Los resultados provienen únicamente de la lista integrada compacta seleccionada y/o de la lista de palabras que pegue.

    Preguntas frecuentes

    ¿Cómo funciona este buscador de palabras?

    Elija el modo de anagrama para buscar palabras que se puedan formar a partir de sus letras, o el modo de patrón para unir letras fijas y ? o . marcadores de posición. Los resultados provienen únicamente de la lista integrada compacta seleccionada y/o de la lista de palabras que pegue.

    ¿Están cargadas mis letras o mi lista de palabras?

    No. Las búsquedas se ejecutan localmente en esta página. Sus letras y su lista de palabras pegadas no se cargan, guardan en una cuenta ni se envían a un servidor.

    ¿Puedo usar mosaicos en blanco en un anagrama?

    Sí. Ingresar ? para cada mosaico en blanco. Cada ? puede representar una letra. "Usar cada mosaico de letras" requiere una coincidencia para usar todos los mosaicos ingresados.

    ¿Puede esto resolver una pista de crucigrama por su significado?

    No. Solo coincide con patrones de letras y filtra palabras en la lista seleccionada; no comprende significados clave ni proporciona respuestas semánticas.

    ¿La lista integrada contiene todas las palabras?

    No. Es un pequeño vocabulario inicial multilingüe, no un diccionario completo ni una lista oficial de palabras del juego. Pegue su propia lista de palabras para una cobertura más amplia.
