Prueba de flexiones y seguimiento de series

Registre un único conjunto como una prueba simple o registre varios conjuntos con el resto entre ellos. Cuentas e ingresas repeticiones; Esta herramienta no utiliza su cámara ni clasifica su fuerza.

Introduzca hasta 20 recuentos de números enteros del 0 al 500. Las líneas en blanco se ignoran y no cuentan como conjuntos. Cuente solo las repeticiones que completó con la forma elegida.

Mantener notas generales; Este no es un registro médico.

Elija un rango de movimiento cómodo y deténgase si siente dolor, mareos o dificultad para respirar inusual. El número de repeticiones depende de la forma, el ritmo y las condiciones de la prueba; Esta herramienta no proporciona una calificación de condición física, un diagnóstico ni una prescripción de ejercicio.

Guardar es opcional y utiliza este navegador únicamente. Desmarque para calcular sin guardar o borre el historial guardado a continuación.

Tu sesión

¿Cómo totaliza las repeticiones el rastreador de pruebas de flexiones?

Suma las repeticiones enteras introducidas para cada conjunto no vacío. Las líneas en blanco se ignoran, un conjunto de ceros sigue siendo cero y la estimación de descanso es el descanso por descanso multiplicado por el número de descansos.

Preguntas frecuentes

¿Cómo totaliza las repeticiones el rastreador de pruebas de flexiones?

Suma las repeticiones enteras introducidas para cada conjunto no vacío. Las líneas en blanco se ignoran, un conjunto de ceros sigue siendo cero y la estimación de descanso es el descanso por descanso multiplicado por el número de descansos.

¿Están cargados mis conjuntos de flexiones?

No. El cálculo se ejecuta en este navegador. El historial de sesiones se escribe en este dispositivo solo después de que usted opte por registrarse; Puedes eliminarlo aquí.

¿Las líneas en blanco cuentan como un conjunto o una repetición?

No. Las líneas vacías se ignoran. Una línea con 0 registra un conjunto sin repeticiones y no agrega repeticiones al total.

¿Puedo usar esto para un conjunto máximo o para varios conjuntos?

Sí. Ingrese una línea para un único conjunto contado manualmente, o varias líneas para resumir los conjuntos y el resto entre ellos. Las condiciones de la prueba dependen de usted; Los resultados no se comparan con las normas de la población.

¿Se ha subido mi historial de entrenamiento?

No. El historial es opcional y permanece en este navegador en este dispositivo. Bórralo con el botón eliminar cuando quieras.
