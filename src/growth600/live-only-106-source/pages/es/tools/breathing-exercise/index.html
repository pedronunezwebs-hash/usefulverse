Preguntas frecuentes

¿Cómo uso este ejercicio de respiración?

Elige un patrón o ajusta cada fase, selecciona la duración de la sesión y pulsa Iniciar. Puedes pausar o reiniciar cuando quieras. El sonido es opcional y comienza al iniciar.

¿Se sube mi sesión de respiración?

No. El temporizador funciona en esta página. No se usan cuentas, cargas, API ni almacenamiento de sesiones.

¿Puedo usar la respiración en caja o 4-7-8?

Sí. Elige un patrón o ajusta la duración de las fases. Son ritmos de respiración, no tratamientos médicos.

¿Seguirá funcionando si cierro la pestaña?

No se garantiza. El navegador puede pausar pestañas en segundo plano y el dispositivo puede suspenderse. Mantén esta página abierta y el dispositivo activo para un tiempo más fiable.

¿Puedo apagar el sonido o detenerme antes?

Sí. El sonido es opcional y puedes desactivarlo. Pausar o Reiniciar detiene el temporizador activo.
