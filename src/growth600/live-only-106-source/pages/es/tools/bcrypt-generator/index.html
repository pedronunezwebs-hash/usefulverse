Generador Bcrypt

Genere un hash bcrypt estándar o verifique una contraseña con un hash bcrypt existente. El trabajo se ejecuta en un navegador local y la contraseña se borra después de cada verificación.

Bcrypt utiliza solo los primeros bytes 72 UTF-8. Esta herramienta rechaza valores más largos en lugar de truncarlos silenciosamente. El costo 8-14 aumenta el trabajo exponencialmente; Los costos más altos pueden llevar más tiempo, especialmente en los teléfonos. Un trabajador local mantiene la página receptiva, pero su dispositivo realiza el trabajo.

Utilice una contraseña de prueba, no una contraseña de inicio de sesión real. El resultado es para comprobaciones de aprendizaje y compatibilidad; No utilice esta página del navegador como sistema de almacenamiento de cuentas de producción.

Pegue un hash bcrypt estándar de 60 caracteres. La verificación admite costos bcrypt de 4 a 14; Se rechazan los hashes de costo inusualmente alto para evitar el trabajo ilimitado en su dispositivo.

Resultado

¿Qué hace un hash bcrypt?

Bcrypt es una función de hash de contraseñas, no de cifrado. Combina un hash unidireccional con una sal aleatoria y un factor de trabajo configurable. Un hash se puede comparar con una contraseña candidata, pero no se puede descifrar para revelar el original.

Preguntas frecuentes

¿Qué hace un hash bcrypt?

Bcrypt es una función de hash de contraseñas, no de cifrado. Combina un hash unidireccional con una sal aleatoria y un factor de trabajo configurable. Un hash se puede comparar con una contraseña candidata, pero no se puede descifrar para revelar el original.

¿Se cargan o guardan mi contraseña o hash?

No. El hash y la verificación se ejecutan en este navegador. La página no envía la contraseña o hash ingresado a un servidor ni los guarda; el campo de contraseña se borra cuando finaliza la operación. Por seguridad, utilice una contraseña de prueba en lugar de una contraseña de cuenta real.

¿bcrypt cifra mi contraseña?

No. Bcrypt es un hash de contraseña unidireccional, cifrado no reversible. Está diseñado para permitir que el software verifique la contraseña de un candidato sin almacenar la contraseña original.

¿Por qué bcrypt tiene un límite de 72 bytes?

El formato bcrypt procesa como máximo bytes 72 UTF-8. Esta herramienta rechaza entradas más largas, por lo que las diferentes contraseñas nunca se tratan silenciosamente como el mismo valor truncado.

¿Debo almacenar este hash para una cuenta real?

No utilice esta página como sistema de credenciales de producción. Los servicios reales deben codificar las contraseñas en su servidor de confianza con bibliotecas de autenticación mantenidas, parámetros adecuados, límites de velocidad y protecciones de cuenta.
