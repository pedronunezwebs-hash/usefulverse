Generador de tablas de rebajas

Cree una tabla Markdown en una pequeña cuadrícula editable. Importe texto separado por comas, punto y coma o tabulaciones, elija la alineación de las columnas y copie Markdown sin formato con tuberías con escape seguro.

Se admiten campos CSV entrecomillados. Importar reemplaza la cuadrícula actual; hasta 100 filas, 20 columnas y 250.000 caracteres.

La primera fila se convierte en el encabezado de Markdown. Agregue al menos una fila y una columna.

Celdas de tabla editables

Crea una tabla de tuberías estándar con un encabezado y una fila separadora. Las rupturas de líneas celulares se convierten en <br>; Se escapan las barras de descuento y las barras invertidas.

Todo el procesamiento permanece en esta pestaña. Sin carga, cuenta, API, guardado automático ni procesamiento del servidor.

¿Cómo hago una tabla de Markdown?

Ingrese una fila de encabezado y filas de datos, elija la alineación de cada columna y luego copie el Markdown generado. Se escapan las tuberías y se rellenan las filas importadas irregulares.

Preguntas frecuentes

¿Cómo hago una tabla de Markdown?

Ingrese una fila de encabezado y filas de datos, elija la alineación de cada columna y luego copie el Markdown generado. Se escapan las tuberías y se rellenan las filas importadas irregulares.

¿Está cargada mi tabla?

No. Su tabla se procesa en esta pestaña del navegador. Las importaciones, las ediciones y el Markdown generado no se envían a un servidor ni se guardan automáticamente.

¿Puedo importar CSV o TSV?

Sí. Pegue valores separados por comas, puntos y comas o tabulaciones y luego impórtelos a la cuadrícula editable. Se admiten campos CSV entre comillas y separadores entre comillas.

¿Cómo se manejan las tuberías y roturas de líneas?

Se escapa una tubería dentro de una celda para que no divida la tabla Markdown. Las barras invertidas también se escapan y los saltos de línea celular se representan con <br>.
