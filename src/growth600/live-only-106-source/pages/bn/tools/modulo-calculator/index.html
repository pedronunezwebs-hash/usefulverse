মডিউল ক্যালকুলেটর

পূর্ণ সংখ্যার জন্য ইউক্লিডীয় ভাগফল এবং অবশিষ্টাংশ গণনা করুন। নেতিবাচক ইনপুট ধারাবাহিকভাবে পরিচালনা করা হয়, এবং বিভাজন পরিচয় দেখায় কিভাবে উত্তর গঠিত হয়।

যে সংখ্যাটি ভাগ করতে হবে; এটা নেতিবাচক হতে পারে।

যেকোনো অ-শূন্য পূর্ণ সংখ্যা ব্যবহার করুন; এর পরম মান মডুলাসকে সংজ্ঞায়িত করে।

এই মানটি ভাজকের লভ্যাংশের সাথে সঙ্গতিপূর্ণ কিনা তা পরীক্ষা করুন।

50 সংখ্যা পর্যন্ত স্বাক্ষরিত পূর্ণ সংখ্যা গ্রহণ করে। কোন ভগ্নাংশ বা দশমিক নেই. ফলাফল ইউক্লিডীয় মডিউল ব্যবহার করে; কিছু প্রোগ্রামিং ভাষা নেতিবাচক জন্য একটি ভিন্ন অবশিষ্ট নিয়ম ব্যবহার করে।

আমার নম্বরগুলি কি আপলোড করা হয়েছে?

নং। সঠিক হিসাব এই ব্রাউজারে চলে। নম্বর আপলোড বা সংরক্ষণ করা হয় না.

−7 মোড 3 কি?

ইউক্লিডীয় কনভেনশন ব্যবহার করে, −7 মোড 3 হল 2: −7 = (−3 × 3) + 2, এবং 0 ≤ 2 < 3.
