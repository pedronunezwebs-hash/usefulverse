XML থেকে CSV রূপান্তরকারী

একটি সাধারণ XML রেকর্ড তালিকাকে একটি CSV টেবিলে পরিণত করুন, অথবা একটি CSV ফাইলের পাঠ্য থেকে XML রেকর্ড তৈরি করুন৷ দিক নির্বাচন করুন, আপনার ডেটা পেস্ট করুন, তারপর ফলাফল কপি বা ডাউনলোড করুন। কিছুই আপলোড করা হয় না.

একই নামের রেকর্ড উপাদানগুলির একটি সাধারণ তালিকা বা একটি ফ্ল্যাট রেকর্ড সমর্থন করে। উপাদান শিশুদের স্কেলার মান হতে হবে; নেস্টেড এবং পুনরাবৃত্তি ক্ষেত্র সমতল করা হয় না.

কলামের নামের জন্য প্রথম সারি ব্যবহার করুন। একটি হেডার যেমন @id একটি XML বৈশিষ্ট্য হয়ে যায়। রেকর্ড টেক্সট জন্য #text ব্যবহার করুন.

এটি একটি সাধারণ টেবিল রূপান্তর, একটি ক্ষতিহীন XML ফর্ম্যাট রূপান্তর নয়। নেমস্পেস, নেস্টেড স্ট্রাকচার, মিশ্র বিষয়বস্তু, মন্তব্য এবং XML বিন্যাস সংরক্ষিত নেই। পাঠ্য টাইপ-সচেতন নয়। স্প্রেডশীট সূত্রের মতো CSV মানগুলি সুরক্ষার জন্য একটি অ্যাপোস্ট্রোফের সাথে উপসর্গযুক্ত।

ফলাফল

অন্য অ্যাপ্লিকেশনে আমদানি করার আগে আউটপুট পরীক্ষা করুন।

আমি কিভাবে XML কে CSV তে রূপান্তর করব?

XML থেকে CSV চয়ন করুন এবং একটি সাধারণ রেকর্ড তালিকা সহ XML পেস্ট করুন৷ বারবার সরাসরি রেকর্ড উপাদান সারি হয়. উপাদানের নাম কলামে পরিণত হয়; গুণাবলী @name ব্যবহার করে। শিরোনাম এবং সারি থেকে সাধারণ XML রেকর্ড তৈরি করতে CSV থেকে XML বেছে নিন।

সচরাচর জিজ্ঞাসিত প্রশ্নাবলী

আমি কিভাবে XML কে CSV তে রূপান্তর করব?

XML থেকে CSV চয়ন করুন এবং একটি সাধারণ রেকর্ড তালিকা সহ XML পেস্ট করুন৷ বারবার সরাসরি রেকর্ড উপাদান সারি হয়. উপাদানের নাম কলামে পরিণত হয়; গুণাবলী @name ব্যবহার করে। শিরোনাম এবং সারি থেকে সাধারণ XML রেকর্ড তৈরি করতে CSV থেকে XML বেছে নিন।

আমার XML বা CSV আপলোড করা হয়েছে?

নং পার্সিং এবং রূপান্তর এই ব্রাউজারে চলে। ইনপুট 200,000 অক্ষর, 5,000 সারি, 64টি কলাম এবং 20,000 কক্ষের মধ্যে সীমাবদ্ধ। DTD এবং সত্তা ঘোষণা ব্লক করা হয়েছে, এবং বাহ্যিক সম্পদ আনা হয় না।

CSV-এ XML বৈশিষ্ট্যগুলি কীভাবে দেখানো হয়?

একটি অ্যাট্রিবিউট যেমন id="101" @id নামের একটি কলামে পরিণত হয়। আবার রূপান্তর করার সময়, @ দিয়ে শুরু হওয়া একটি CSV হেডার একটি XML অ্যাট্রিবিউটে পরিণত হয়।

এটি কি নেস্টেড এক্সএমএলকে একটি ফ্ল্যাট টেবিলে রূপান্তর করতে পারে?

নং নেস্টেড চাইল্ড স্ট্রাকচার, রেকর্ডের ভিতরে বারবার ক্ষেত্র এবং মিশ্র পাঠ্য সমতল বা নীরবে হারিয়ে যাওয়ার পরিবর্তে প্রত্যাখ্যান করা হয়। নেস্টেড ডেটার জন্য একটি ডেডিকেটেড XML-টু-JSON ওয়ার্কফ্লো ব্যবহার করুন।

CSV কি XML প্রকার এবং বিন্যাস সংরক্ষণ করবে?

নং CSV সেল টেক্সট সঞ্চয় করে, XML প্রকার, নামস্থান বা বিন্যাস নয়। স্প্রেডশীট সূত্র কার্যকর করার ঝুঁকি কমাতে রপ্তানি করা হলে সূত্র-সদৃশ কক্ষের মানগুলি একটি অ্যাপোস্ট্রফি উপসর্গ পায়।
