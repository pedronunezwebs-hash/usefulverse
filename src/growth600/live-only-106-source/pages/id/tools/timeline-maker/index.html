Garis waktu hanya memvisualisasikan tanggal yang Anda masukkan. Itu tidak memverifikasi keakuratan acara atau menyimpulkan tanggal yang hilang.

Bagaimana cara membuat timeline acara?

Tambahkan setidaknya dua acara bernama dan pilih tanggal mulai untuk masing-masing acara. Tambahkan tanggal akhir untuk suatu durasi atau biarkan kosong untuk acara satu hari. Buat garis waktu untuk mengurutkan acara berdasarkan tanggal, menyesuaikan zoom, dan mengunduh file SVG atau CSV.

Pertanyaan umum

Bagaimana cara membuat timeline acara?

Tambahkan setidaknya dua acara bernama dan pilih tanggal mulai untuk masing-masing acara. Tambahkan tanggal akhir untuk suatu durasi atau biarkan kosong untuk acara satu hari. Buat garis waktu untuk mengurutkan acara berdasarkan tanggal, menyesuaikan zoom, dan mengunduh file SVG atau CSV.

Apakah acara timeline saya diunggah?

No. Nama dan tanggal diproses di tab browser ini. SVG dan CSV dibuat di perangkat Anda; tidak ada yang diunggah atau disimpan secara otomatis.

Bisakah suatu acara berlangsung lebih dari satu hari?

Ya. Masukkan tanggal mulai dan berakhir. Bagan tersebut mencakup kedua tanggal titik akhir; biarkan bagian akhir kosong untuk acara satu hari.

Apakah garis waktu ini membuat ketergantungan tugas?

No. Ini menunjukkan peristiwa dan rentang tanggal dalam urutan kronologis. Gunakan alat jadwal proyek untuk tugas, durasi, dan ketergantungan.

Bisakah saya menyimpan atau membagikan timeline?

Unduh SVG untuk gambar yang dapat diskalakan atau CSV untuk tabel acara. Halaman tidak mengunggah atau menyimpan data acara Anda secara otomatis.
