Pemeriksa Aksesibilitas PDF

Periksa PDF secara lokal untuk beberapa sinyal aksesibilitas yang dapat dideteksi mesin, termasuk tag dokumen, metadata, teks yang dapat dipilih, gambar tanpa teks alternatif, dan lompatan tingkat judul. Ini hanyalah pemeriksa tingkat pertama, bukan validator PDF/UA atau pengganti pengujian teknologi bantu.

Maksimum 25 MiB dan 300 halaman. Inspeksi mungkin menggunakan memori perangkat; komputer direkomendasikan untuk file besar.

berjalan pada perangkat Anda setelah Anda memilih file. Tidak ada unggahan, akun, API, penyimpanan otomatis, atau pemrosesan server.

Pemeriksaan ini bersifat heuristik. Mereka tidak dapat mengonfirmasi urutan pembacaan yang benar, deskripsi yang bermakna, kontras warna, penggunaan keyboard, label formulir, hubungan header tabel, atau kesesuaian PDF/UA/Bagian 508/WCAG. Tinjau secara manual dan uji dengan teknologi bantu.

Inspection report

Apa yang dapat dideteksi oleh pemeriksa aksesibilitas PDF ini?

Ini melaporkan apakah PDF memperlihatkan tag struktur, judul dan bahasa dokumen, teks yang dapat dipilih pada setiap halaman, gambar dengan teks alternatif, dan kemungkinan lompatan dalam level judul. Ia tidak dapat memutuskan apakah urutan bacaan atau teks alternatif bermakna.

Apakah PDF saya diunggah untuk diperiksa?

Tidak. PDF yang dipilih diperiksa di tab browser ini. File dan teksnya tidak diunggah, disimpan secara otomatis, atau dikirim ke server.

Apakah hasil positif berarti PDF dapat diakses?

Tidak. Ini hanya sinyal otomatis terbatas. PDF yang diberi tag mungkin masih memiliki urutan pembacaan yang salah, deskripsi yang buruk, formulir yang tidak dapat diakses, kontras rendah, atau hambatan lainnya. Pengujian manual dan teknologi bantu masih diperlukan.

Dapatkah mengonfirmasi kepatuhan PDF/UA atau WCAG?

Tidak. Pemeriksa tingkat pertama ini tidak menguji setiap persyaratan dan tidak dapat mengesahkan PDF/UA, WCAG, Bagian 508, atau kepatuhan hukum.
