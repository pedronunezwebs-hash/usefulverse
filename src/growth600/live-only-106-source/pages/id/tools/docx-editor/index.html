Akankah file yang diedit tetap mempertahankan format yang ada?

Gaya teks dan konten bagian paket lainnya dipertahankan. Saat segmen teks diganti, format proses yang ada akan dipertahankan; alat ini tidak menawarkan kontrol pemformatan teks kaya atau menjamin bahwa setiap fitur Word ditampilkan secara identik.

Tidak. Editor terfokus mengubah teks yang berjalan di dokumen utama saja. Alur kerja perubahan terlacak, header dan footer, makro, dan file yang ditandatangani secara digital tidak didukung.
