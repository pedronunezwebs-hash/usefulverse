Bcrypt Generator

Buat hash bcrypt standar atau periksa kata sandi terhadap hash bcrypt yang ada. Pekerjaan berjalan di pekerja browser lokal, dan kata sandi dihapus setelah setiap pemeriksaan.

Bcrypt hanya menggunakan byte 72 UTF-8 pertama. Alat ini menolak nilai yang lebih panjang daripada memotongnya secara diam-diam. Biaya 8–14 meningkatkan pekerjaan secara eksponensial; biaya yang lebih tinggi bisa memakan waktu lebih lama, terutama pada ponsel. Pekerja lokal menjaga halaman tetap responsif, namun perangkat Anda melakukan pekerjaannya.

Gunakan kata sandi percobaan, bukan kata sandi login asli. Hasilnya untuk pembelajaran dan pemeriksaan kompatibilitas; jangan gunakan halaman browser ini sebagai sistem penyimpanan akun produksi.

Hasil

Apa fungsi hash bcrypt?

Bcrypt adalah fungsi hashing kata sandi, bukan enkripsi. Ini menggabungkan hash satu arah dengan garam acak dan faktor kerja yang dapat dikonfigurasi. Sebuah hash dapat diperiksa terhadap calon kata sandi tetapi tidak dapat didekripsi untuk mengungkapkan kata sandi aslinya.

Pertanyaan umum

Apa fungsi hash bcrypt?

Bcrypt adalah fungsi hashing kata sandi, bukan enkripsi. Ini menggabungkan hash satu arah dengan garam acak dan faktor kerja yang dapat dikonfigurasi. Sebuah hash dapat diperiksa terhadap calon kata sandi tetapi tidak dapat didekripsi untuk mengungkapkan kata sandi aslinya.

Apakah kata sandi atau hash saya diunggah atau disimpan?

No. Hashing dan verifikasi dijalankan di browser ini. Halaman tersebut tidak mengirimkan kata sandi atau hash yang dimasukkan ke server atau menyimpannya; bidang kata sandi dihapus ketika operasi selesai. Demi keamanan, gunakan kata sandi percobaan, bukan kata sandi akun asli.

Apakah bcrypt mengenkripsi kata sandi saya?

No. Bcrypt adalah hash kata sandi satu arah, bukan enkripsi yang dapat dibalik. Ini dirancang agar perangkat lunak dapat memeriksa calon kata sandi tanpa menyimpan kata sandi asli.

Mengapa bcrypt memiliki batas byte 72?

Format bcrypt memproses paling banyak 72 UTF-8 byte. Alat ini menolak input yang lebih panjang sehingga kata sandi yang berbeda tidak pernah diperlakukan secara diam-diam sebagai nilai terpotong yang sama.

Haruskah saya menyimpan hash ini untuk akun nyata?

Jangan gunakan halaman ini sebagai sistem kredensial produksi. Layanan nyata harus melakukan hashing kata sandi di server tepercaya mereka dengan perpustakaan otentikasi yang dipelihara, parameter yang sesuai, batas kecepatan, dan perlindungan akun.
