Tes push-up dan pelacak set

Rekam satu set sebagai pengujian sederhana atau catat beberapa set dengan sisanya di antaranya. Anda menghitung dan memasukkan pengulangan; alat ini tidak menggunakan kamera Anda atau menentukan kekuatan Anda.

Masukkan hingga 20 hitungan bilangan bulat dari 0 hingga 500. Baris kosong diabaikan dan tidak dihitung sebagai set. Hitung hanya pengulangan yang Anda selesaikan dengan formulir pilihan Anda.

Menyimpan catatan umum; ini bukan rekam medis.

Pilih rentang gerak yang nyaman dan hentikan jika Anda merasakan nyeri, pusing, atau sesak napas yang tidak biasa. Jumlah pengulangan bergantung pada bentuk, kecepatan, dan kondisi pengujian; alat ini tidak memberikan peringkat kebugaran, diagnosis, atau resep latihan.

Menyimpan bersifat opsional dan hanya menggunakan browser ini. Hapus centang untuk menghitung tanpa menyimpan, atau hapus riwayat yang disimpan di bawah.

Sesi Anda

Bagaimana total pengulangan pelacak tes push-up?

Ini menambahkan pengulangan bilangan bulat yang dimasukkan untuk setiap set yang tidak kosong. Garis kosong diabaikan, himpunan nol tetap nol, dan estimasi sisanya adalah istirahat per jeda dikalikan dengan jumlah jeda.

Pertanyaan umum

Bagaimana total pengulangan pelacak tes push-up?

Ini menambahkan pengulangan bilangan bulat yang dimasukkan untuk setiap set yang tidak kosong. Garis kosong diabaikan, himpunan nol tetap nol, dan estimasi sisanya adalah istirahat per jeda dikalikan dengan jumlah jeda.

Apakah set push-up saya sudah diunggah?

No. Perhitungan berjalan di browser ini. Riwayat sesi ditulis ke perangkat ini hanya setelah Anda ikut serta; Anda dapat menghapusnya di sini.

Apakah garis kosong dihitung sebagai satu set atau pengulangan?

Tidak. Baris kosong diabaikan. Garis dengan 0 mencatat kumpulan pengulangan nol dan tidak menambahkan pengulangan ke total.

Bisakah saya menggunakan ini untuk satu set maksimum atau untuk beberapa set?

Ya. Masukkan satu baris untuk satu kumpulan yang dihitung secara manual, atau beberapa baris untuk meringkas kumpulan dan sisanya di antara kumpulan tersebut. Ketentuan pengujian terserah Anda; hasilnya tidak dibandingkan dengan norma populasi.

Apakah riwayat latihan saya diunggah?

Tidak. Riwayat bersifat opsional dan tetap ada di browser pada perangkat ini. Hapus dengan tombol hapus kapan pun Anda mau.
