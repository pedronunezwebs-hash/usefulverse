Generator Kartu VC

Buat satu kontak digital sebagai file .vcf di browser Anda. Pilih vCard 3.0 atau 4.0, tambahkan detail kontak dan opsional sematkan foto JPEG atau PNG kecil.

JPEG atau PNG opsional, hingga 128 KiB. Foto tersebut disematkan ke dalam file VCF; itu tidak diunggah.

Satu kontak, hingga 5 telepon dan 5 email, 500 karakter per bidang teks, dan batas file yang dihasilkan 1 MiB. Hanya vCard 3.0 dan 4.0 yang ditawarkan.

Berjalan secara lokal setelah Anda memilih Hasilkan. Tidak ada akun, akses buku kontak, unggahan, API, pemrosesan server atau penyimpanan otomatis.

Apakah ini akan menambahkan kontak ke ponsel saya?
Tidak. Ini membuat file VCF untuk Anda pratinjau, salin, atau unduh. Itu tidak pernah membaca atau mengubah buku alamat Anda; Anda memutuskan apakah dan di mana akan mengimpor file.


    
Pertanyaan umum
Apakah ini akan menambahkan kontak ke ponsel saya?
Tidak. Ini membuat file VCF untuk Anda pratinjau, salin, atau unduh. Itu tidak pernah membaca atau mengubah buku alamat Anda; Anda memutuskan apakah dan di mana akan mengimpor file.
Apakah informasi kontak saya sudah diunggah?
No. Detail dan foto opsional diproses pada perangkat ini. Tidak ada unggahan, akun, pemrosesan server atau penyimpanan otomatis.
Apa perbedaan antara vCard 3.0 dan 4.0?
Ini adalah dua versi format kontak vCard. Alat ini menulis file teks VCF yang kompatibel menggunakan versi yang Anda pilih; aplikasi kontak mungkin mendukungnya secara berbeda.
Apakah ini memverifikasi nomor telepon atau alamat email?
Tidak. Ini hanya memeriksa format dasarnya. Itu tidak dapat memverifikasi bahwa nomor, kotak surat, alamat atau situs web adalah milik orang tersebut.
