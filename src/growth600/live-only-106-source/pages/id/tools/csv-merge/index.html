CSV Gabungkan

Gabungkan beberapa file CSV ke dalam satu tabel. Nama kolom yang cocok akan berbaris meskipun urutannya berbeda, dan kolom tambahan ditambahkan dengan sel kosong jika diperlukan. File tetap berada di browser ini.

Pilih 2–20 file, masing-masing hingga 2 MiB dan total 8 MiB. Pemrosesan tetap ada di perangkat ini.

Dengan header, kolom cocok dengan nama persisnya dan kolom baru mengikuti urutan yang pertama kali ditemukan. Tanpa header, kolom dicocokkan berdasarkan posisi. Header atau nilai yang mirip rumus diawali dengan tanda kutip untuk pembukaan spreadsheet yang lebih aman. Pembatas, pengkodean file, dan teks sel tidak dinormalisasi.

Digabung CSV

Tinjau CSV yang digabungkan sebelum menggunakannya di aplikasi lain.

Bagaimana cara menggabungkan file CSV dengan urutan kolom berbeda?

Pilih dua atau lebih file CSV dan tetap aktifkan opsi header. Kolom dicocokkan dengan teks header yang tepat, menggunakan urutan yang pertama kali dilihat. Kolom yang hilang menjadi sel kosong; kolom yang tidak cocok ditambahkan ke output.

Pertanyaan umum

Bagaimana cara menggabungkan file CSV dengan urutan kolom berbeda?

Pilih dua atau lebih file CSV dan tetap aktifkan opsi header. Kolom dicocokkan dengan teks header yang tepat, menggunakan urutan yang pertama kali dilihat. Kolom yang hilang menjadi sel kosong; kolom yang tidak cocok ditambahkan ke output.

Apakah file CSV saya sudah diunggah?

Tidak. File yang dipilih dibaca dan digabungkan secara lokal di browser ini. Hingga 20 file didukung, dengan 2 MiB per file dan 8 MiB batas input gabungan. Tidak ada pemrosesan akun atau server yang digunakan.

Bisakah saya menggabungkan file CSV ketika urutan kolomnya berbeda?

Ya. Dengan mengaktifkan header, kolom akan disejajarkan berdasarkan teks header yang tepat, bukan posisinya. Header baru ditambahkan sesuai urutan yang pertama kali ditemukan, dan nilai yang hilang dibiarkan kosong.

Apa yang terjadi jika file CSV tidak memiliki baris header?

Matikan opsi header. Nilai kemudian disejajarkan menurut posisi kolom, dan keluarannya menggunakan nama netral seperti Kolom 1. Baris masukan dengan sel lebih sedikit diisi oleh parser CSV.

Apakah rumus atau perintah spreadsheet diubah?

Header dan nilai yang mirip rumus diawali dengan tanda kutip di output CSV untuk mengurangi risiko eksekusi saat dibuka di perangkat lunak spreadsheet. Ini dengan sengaja mengubah nilai sel tersebut.
