Konverter XML ke CSV

Ubah daftar data XML sederhana menjadi tabel CSV, atau buat data XML dari teks file CSV. Pilih arahnya, tempel data Anda, lalu salin atau unduh hasilnya. Tidak ada yang diunggah.

Mendukung daftar sederhana elemen rekaman dengan nama yang sama, atau satu rekaman datar. Anak elemen harus berupa nilai skalar; bidang bersarang dan berulang tidak diratakan.

Gunakan baris pertama untuk nama kolom. Header seperti @id menjadi atribut XML. Gunakan #text untuk merekam teks.

Ini adalah konversi tabel sederhana, bukan konversi format XML lossless. Ruang nama, struktur bersarang, konten campuran, komentar, dan format XML tidak dipertahankan. Teks tidak peka terhadap tipe. Nilai CSV yang mirip rumus spreadsheet diawali dengan tanda kutip untuk keamanan.

Hasil

Periksa output sebelum mengimpornya ke aplikasi lain.

Bagaimana cara mengonversi XML ke CSV?

Pilih XML ke CSV dan tempel XML dengan daftar catatan sederhana. Elemen rekaman langsung yang berulang menjadi baris. Nama elemen menjadi kolom; atribut menggunakan @name. Pilih CSV ke XML untuk membuat rekaman XML sederhana dari header dan baris.

Pertanyaan umum

Bagaimana cara mengonversi XML ke CSV?

Pilih XML ke CSV dan tempel XML dengan daftar catatan sederhana. Elemen rekaman langsung yang berulang menjadi baris. Nama elemen menjadi kolom; atribut menggunakan @name. Pilih CSV ke XML untuk membuat rekaman XML sederhana dari header dan baris.

Apakah XML atau CSV saya sudah diunggah?

No. Parsing dan konversi dijalankan di browser ini. Input dibatasi hingga 200.000 karakter, 5.000 baris, 64 kolom, dan 20.000 sel. Deklarasi DTD dan entitas diblokir, dan sumber daya eksternal tidak diambil.

Bagaimana atribut XML ditampilkan di CSV?

Atribut seperti id="101" menjadi kolom bernama @id. Saat mengonversi kembali, header CSV yang dimulai dengan @ menjadi atribut XML.

Bisakah itu mengubah XML bersarang menjadi tabel datar?

Tidak. Struktur anak yang disarangkan, bidang berulang di dalam rekaman, dan teks campuran ditolak, bukannya diratakan atau hilang secara diam-diam. Gunakan alur kerja XML-ke-JSON khusus untuk data bertumpuk.

Apakah CSV akan mempertahankan tipe dan format XML?

No. CSV menyimpan teks sel, bukan tipe XML, namespace, atau pemformatan. Nilai sel yang mirip rumus mendapatkan awalan apostrof saat diekspor untuk mengurangi risiko eksekusi rumus spreadsheet.
