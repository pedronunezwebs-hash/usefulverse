Pertanyaan umum

Bagaimana cara menyetel alarm online?

Pilih tanggal dan waktu mendatang dalam zona waktu lokal perangkat Anda, lalu pilih Setel alarm. Suara adalah opsional. Anda dapat mengujinya terlebih dahulu, menundanya selama lima menit, atau menghentikannya saat berdering.

Apakah alarm ini mengirimkan data atau berfungsi setelah saya menutup halaman?

Tidak ada data yang dikirim atau disimpan. Alarm hanya berjalan di halaman ini dan tidak dapat memperingatkan Anda secara andal jika tab ditutup, browser menjedanya, atau perangkat dalam mode tidur.

Akankah alarm berbunyi jika saya menutup tab?

Tidak. Ini adalah alarm dalam halaman, bukan alarm atau pemberitahuan sistem operasi. Biarkan halaman tetap terbuka dan perangkat tetap aktif; untuk pengingat penting, gunakan aplikasi alarm perangkat Anda.

Bisakah saya menunda alarm?

Ya. Saat berdering, pilih Tunda 5 menit untuk menjadwalkannya lagi dari waktu saat ini.

Apakah alarm menggunakan lokasi saya atau menghemat waktu saya?

Tidak. Ini menggunakan waktu lokal yang dikonfigurasi pada perangkat Anda. Alarm hanya ditahan di halaman terbuka dan tidak diunggah atau disimpan.
