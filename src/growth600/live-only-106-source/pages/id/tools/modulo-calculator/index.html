Kalkulator Modulo

Menghitung hasil bagi Euclidean dan sisa bilangan bulat. Masukan negatif ditangani secara konsisten, dan identitas pembagian menunjukkan bagaimana jawabannya terbentuk.

Nomor yang akan dibagi; itu mungkin negatif.

Gunakan bilangan bulat bukan nol apa pun; nilai absolutnya menentukan modulus.

Periksa apakah nilai ini kongruen dengan modul pembagian pembagi.

Menerima bilangan bulat bertanda hingga 50 digit. Tidak ada pecahan atau desimal. Hasilnya menggunakan modulo Euclidean; beberapa bahasa pemrograman menggunakan aturan sisa yang berbeda untuk negatif.

Hasil

Bagaimana cara menghitung modulo dengan bilangan negatif?

Kalkulator ini menggunakan sisa non-negatif yang lebih kecil dari pembagi mutlak. Misalnya, −7 mod 3 adalah 2 karena −7 = (−3 × 3) + 2.

Apa itu −7 mod 3?

Menggunakan konvensi Euclidean, −7 mod 3 adalah 2: −7 = (−3 × 3) + 2, dan 0 ≤ 2 < 3.

Apa yang dimaksud dengan modulo m kongruen?

Dua bilangan bulat kongruen modulo m jika selisihnya habis dibagi |m|. Perbandingan opsional memeriksa hal ini dengan tepat.

Mengapa ini berbeda dari operator % bahasa pemrograman?

Beberapa bahasa menyimpan tanda dividen negatif di sisanya. Kalkulator ini mengembalikan sisa dari 0 hingga, namun tidak termasuk, pembagi absolut.
