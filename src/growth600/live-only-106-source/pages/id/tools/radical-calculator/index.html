Penyederhana Akar Kuadrat

Sederhanakan radikal bilangan bulat eksak dengan mengekstraksi pangkat sempurna, atau tulis ulang pecahan sehingga penyebutnya tidak mengandung akar kuadrat. Hasil tepat untuk masukan bilangan bulat yang didukung.

Masukkan bilangan bulat. Radicand dibatasi hingga ±1.000.000.000.000; indeks akarnya adalah 2–12. Radikan negatif hanya didukung untuk indeks ganjil.

Mode ini menangani pembilang / (koefisien × √radicand). Koefisien penyebut tidak boleh nol; radikan harus berupa bilangan bulat positif.

Hasil

Bagaimana cara menyederhanakan akar kuadrat?

Faktorkan radikan menjadi pangkat prima. Tarik setiap pasangan lengkap keluar dari akar kuadrat; misalnya, √72 = √(36 × 2) = 6√2. Alat ini juga mendukung akar bilangan bulat dengan indeks 2 hingga 12.
