Ekstrak Gambar dari PDF

Pilih PDF untuk menemukan gambar raster yang disematkan, pratinjau gambar tersebut, dan simpan salinan PNG terpisah atau satu ZIP. Halaman tidak diraster menjadi tangkapan layar.

mendukung objek gambar raster yang tertanam; itu tidak mengubah seluruh halaman PDF menjadi gambar. Gambar vektor dan teks halaman bukanlah gambar raster yang terpisah.

File Anda tetap ada di perangkat ini dan tidak diunggah. Piksel yang diekstraksi dikodekan ulang sebagai PNG, sehingga format file dan metadata asli yang disematkan tidak dipertahankan.

Batas lokal: 25 MiB PDF, 300 halaman, 200 gambar, 8 megapiksel per gambar, total 16 megapiksel, dan 25 MiB ZIP. PDF yang besar menggunakan memori perangkat; komputer dianjurkan.

Gambar ditemukan

ditampilkan hingga 12 gambar pertama; setiap gambar yang terdaftar masih dapat diunduh.

Unduh semua gambar (ZIP)

    Bagaimana cara mengekstrak gambar dari PDF?

    Pilih PDF dan pilih Ekstrak gambar. Browser ini membaca objek gambar raster tersemat yang didukung dan mengonversi piksel yang didekodekan menjadi file PNG. Unduh gambar satu per satu atau satu ZIP.

    Pertanyaan umum

    Bagaimana cara mengekstrak gambar dari PDF?

    Pilih PDF dan pilih Ekstrak gambar. Browser ini membaca objek gambar raster tersemat yang didukung dan mengonversi piksel yang didekodekan menjadi file PNG. Unduh gambar satu per satu atau satu ZIP.

    Apakah PDF atau gambar saya diunggah?

    Tidak. PDF Anda diproses di tab browser ini. Alat ini tidak mengunggah file atau menyimpannya ke akun.

    Apakah alat ini mengubah setiap halaman PDF menjadi gambar?

    Tidak. Ini mencari objek gambar raster tertanam yang didukung. Gunakan alat PDF-to-image jika Anda ingin gambar yang dirender dari setiap halaman keseluruhan.

    Akankah PNG yang diekstraksi menjadi byte-demi-byte yang identik dengan file yang disematkan?

    Tidak. Browser mendekodekan objek gambar yang didukung dan mengkodekan ulang pikselnya sebagai PNG pada dimensi objek yang didekodekan. Kompresi asli, format file, dan metadata tidak dipertahankan.

    Mengapa beberapa gambar PDF mungkin tidak muncul?

    Karya seni vektor, masker gambar, pengkodean yang tidak biasa, perlindungan kata sandi, format file yang salah, dan batas memori browser dapat mencegah ekstraksi. Alat ini hanya melaporkan objek yang didukung dan tidak mengunggah file Anda.
