Validator Peta Situs

Tempelkan dokumen XML peta situs untuk memeriksa strukturnya, entri URL, tanggal, dan bidang umum. XML diurai hanya di browser ini; halaman yang terdaftar tidak pernah diambil.

Mendukung urlset atau sitemapindex standar. Maksimal 1.000.000 karakter dan 5.000 entri langsung.

XML lokal hanya memeriksa: ini tidak meminta URL yang terdaftar, merayapi situs, mengirimkan peta situs, atau menjamin pengindeksan.

Ringkasan validasi

Temuan

    Apa yang diperiksa validator peta situs ini?

    Ini memeriksa entri urlset atau sitemapindex, lokasi HTTP atau HTTPS absolut, duplikat URL yang dinormalisasi, tanggal mod terakhir, frekuensi perubahan opsional dan nilai prioritas, dan ruang nama peta situs. Peringatan dan kesalahan dicantumkan berdasarkan nomor entri.

    Pertanyaan umum

    Apa yang diperiksa validator peta situs ini?

    Ini memeriksa entri urlset atau sitemapindex, lokasi HTTP atau HTTPS absolut, duplikat URL yang dinormalisasi, tanggal mod terakhir, frekuensi perubahan opsional dan nilai prioritas, dan ruang nama peta situs. Peringatan dan kesalahan dicantumkan berdasarkan nomor entri.

    Apakah ia mengunggah atau mengirimkan peta situs saya?

    Tidak. XML diproses secara lokal di browser Anda. Alat ini tidak merayapi URL, mengambil file peta situs jarak jauh, mengirimkan apa pun ke mesin telusur, atau mengonfirmasi pengindeksan.

    Apakah ini memeriksa apakah URL peta situs aktif?

    Tidak. Ia memeriksa sintaks URL dan duplikat dalam XML yang ditempel, namun sengaja tidak meminta URL atau merayapi situs.

    Apakah peta situs yang valid berarti Google mengindeks halamannya?

    No. Validasi XML bukan pengiriman mesin pencari atau laporan pengindeksan. Kirimkan peta situs melalui alat webmaster mesin pencari yang relevan dan periksa statusnya sendiri.

    Bisakah saya memvalidasi indeks peta situs?

    Ya. Alat ini memeriksa entri sitemapindex langsung serta bidang loc dan lastmodnya, tetapi tidak mengunduh atau memeriksa file peta situs yang direferensikan secara rekursif.
