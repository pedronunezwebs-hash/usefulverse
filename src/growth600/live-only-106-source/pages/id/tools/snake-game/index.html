Pertanyaan umum

Bagaimana cara memainkan permainan ular?

Mulai putaran, arahkan ke arah makanan menggunakan arrow keys, WASD atau tombol sentuh, dan hindari dinding dan tubuh Anda. Jeda kapan saja. Makan makanan menumbuhkan ular dan menambah satu poin.

Apakah game ular menyimpan skor saya atau menggunakan akun?

Tidak diperlukan akun atau unduhan. Skor dan sesi terbaik Anda saat ini hanya tersimpan dalam memori di tab ini; mereka tidak diunggah atau disimpan setelah Anda keluar.

Bisakah saya bermain di ponsel atau tablet?

Ya. Gunakan tombol arah di layar. Keyboard dengan arrow keys atau WASD juga berfungsi di komputer.

Bisakah saya menjeda permainan?

Ya. Pilih Jeda kapan saja; ular berhenti bergerak sampai Anda melanjutkan.

Apakah saya akan mendapatkan game yang sama setiap saat?

Tata letak papan tetap familiar, tetapi posisi makanan diacak untuk setiap babak baru. Skor sesi saat ini dan terbaik tidak disimpan setelah Anda keluar.
