Memory Test

Poćwicz zapamiętywanie rosnącej sekwencji cyfr lub pozycji na siatce 3×3. Każda poprawna runda dodaje jeden przedmiot.

Tylko praktyka. To nie jest test IQ, diagnoza ani potwierdzona ocena poznawcza. Wyniki nie mają znaczenia klinicznego ani populacyjnego.

W przypadku czytników ekranu wybierz opcję Rozpiętość cyfr: każda cyfra jest ogłaszana raz podczas odtwarzania. Tryb wzorca wizualnego zależy od wzroku.

Długość następnej sekwencji: 3

Element sekwencji: —

Twoja odpowiedź

Nie wprowadzono jeszcze żadnych elementów.

Prawidłowe rundy: 0

Wybierz tryb i prędkość, a następnie rozpocznij.

Wynik testu

Jak działa ten test pamięci?

Wybierz cyfry lub siatkę wizualną i szybkość wyświetlania. Obejrzyj lub posłuchaj sekwencji raz, a następnie wprowadź ją w tej samej kolejności. Prawidłowe rundy stają się dłuższe, aż do 12 przedmiotów. Jest to zwykła gra ćwiczeniowa, a nie ujednolicona ocena pamięci.

Często zadawane pytania

Jak działa ten test pamięci?

Wybierz cyfry lub siatkę wizualną i szybkość wyświetlania. Obejrzyj lub posłuchaj sekwencji raz, a następnie wprowadź ją w tej samej kolejności. Prawidłowe rundy stają się dłuższe, aż do 12 przedmiotów. Jest to zwykła gra ćwiczeniowa, a nie ujednolicona ocena pamięci.

Czy ten test pamięci zapisuje mój wynik?

Nie. Sekwencja i partytura pozostają na tej stronie, dopóki jest ona otwarta. Nic nie jest przesyłane, nie ma konta ani rankingu online.

Co mierzy ten test pamięci?

Jest to zwykła gra polegająca na przypominaniu sobie sekwencji. Nie jest znormalizowany i nie pozwala zdiagnozować stanu ani zmierzyć IQ.

Czym różnią się zakres cyfr i tryb wzoru?

Digit span wyświetla cyfry pojedynczo i ogłasza je, aby umożliwić czytnikowi ekranu dostęp do nich. Tryb wzoru miga pozycjami na siatce 3 × 3 i wymaga wzroku.

Czy wyniki są zapisywane lub porównywane z wynikami innych osób?

Nie. Wyniki istnieją tylko wtedy, gdy ta strona pozostaje otwarta. Nie ma tabeli liderów, konta ani przesyłania na serwer.
