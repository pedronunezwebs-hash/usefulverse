Jak korzystać z tego ćwiczenia oddechowego?

Czy dane mojej sesji są przesyłane?

Nie. Odliczanie odbywa się na tej stronie. Nie jest wymagane konto ani przesyłanie danych; nie korzystamy z API ani nie zapisujemy sesji.

Czy mogę stosować oddychanie pudełkowe lub metodę 4-7-8?

Tak. Wybierz gotowy schemat lub dostosuj czas poszczególnych faz. To techniki regulacji oddechu, a nie leczenie.

Czy sesja będzie kontynuowana po zamknięciu karty?

Nie ma takiej gwarancji. Przeglądarki mogą wstrzymywać karty w tle, a urządzenia przechodzić w tryb uśpienia. Pozostaw stronę otwartą i urządzenie aktywne, aby dokładniej mierzyć czas.

Czy mogę wyłączyć dźwięk lub zakończyć wcześniej?

Tak. Dźwięk jest opcjonalny i można go wyłączyć. Pauza lub Reset natychmiast przerywa odliczanie.
