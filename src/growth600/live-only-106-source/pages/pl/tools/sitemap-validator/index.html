Walidator mapy witryny

Wklej dokument XML mapy witryny, aby sprawdzić jego strukturę, wpisy URL, daty i wspólne pola. Plik XML jest analizowany tylko w tej przeglądarce; wymienione strony nigdy nie są pobierane.

Obsługuje standardowy urlset lub sitemapindex. Maksymalnie 1 000 000 znaków i 5 000 wpisów bezpośrednich.

Tylko lokalne kontrole XML: nie powoduje to żądania podanych adresów URL, przeszukiwania witryny, przesyłania mapy witryny ani gwarantowania indeksowania.

Podsumowanie walidacji

Ustalenia

    Co sprawdza ten moduł sprawdzania poprawności mapy witryny?

    Sprawdza wpisy urlset lub sitemapindex, bezwzględne lokalizacje HTTP lub HTTPS, zduplikowane znormalizowane adresy URL, daty ostatniej modyfikacji, opcjonalne wartości częstotliwości zmian i priorytetów oraz przestrzeń nazw mapy witryny. Ostrzeżenia i błędy są wymienione według numeru wpisu.

    Często zadawane pytania

    Co sprawdza ten moduł sprawdzania poprawności mapy witryny?

    Sprawdza wpisy urlset lub sitemapindex, bezwzględne lokalizacje HTTP lub HTTPS, zduplikowane znormalizowane adresy URL, daty ostatniej modyfikacji, opcjonalne wartości częstotliwości zmian i priorytetów oraz przestrzeń nazw mapy witryny. Ostrzeżenia i błędy są wymienione według numeru wpisu.

    Czy przesyła lub wysyła moją mapę witryny?

    Nie. Plik XML jest przetwarzany lokalnie w przeglądarce. Narzędzie nie przeszukuje adresów URL, nie pobiera plików zdalnych map witryn, nie przesyła niczego do wyszukiwarki ani nie potwierdza indeksowania.

    Czy sprawdza to, czy adres URL mapy witryny jest aktywny?

    Nie. Sprawdza składnię adresu URL i duplikaty w wklejonym formacie XML, ale celowo nie żąda adresów URL ani nie przeszukuje serwisu.

    Czy prawidłowa mapa witryny oznacza, że Google zaindeksował jej strony?

    Nie. Walidacja XML nie jest raportem przesyłanym do wyszukiwarki ani raportem indeksującym. Prześlij mapę witryny za pomocą odpowiedniego narzędzia dla webmasterów wyszukiwarki i sprawdź jej status.

    Czy mogę sprawdzić indeks mapy witryny?

    Tak. Narzędzie sprawdza bezpośrednie wpisy sitemapindex oraz ich pola loc i lastmod, ale nie pobiera ani nie sprawdza rekurencyjnie plików map witryn, do których istnieją odniesienia.
