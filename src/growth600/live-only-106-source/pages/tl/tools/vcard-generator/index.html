VCard Generator

Lumikha ng isang digital na contact bilang isang .vcf file sa iyong browser. Pumili ng vCard 3.0 o 4.0, magdagdag ng mga detalye ng contact at opsyonal na mag-embed ng maliit na JPEG o PNG na larawan.

Opsyonal na JPEG o PNG, hanggang 128 KiB. Ang larawan ay naka-embed sa VCF file; hindi ito na-upload.

Isang contact, hanggang 5 telepono at 5 email, 500 character bawat text field, at 1 MiB na nabuong-file na limitasyon. Ang vCard 3.0 at 4.0 lang ang inaalok.

Lokal na tumatakbo pagkatapos mong piliin ang Bumuo. Walang account, access sa contact-book, pag-upload, API, pagpoproseso ng server o awtomatikong pag-save.

Mga madalas itanong
Idaragdag ba nito ang contact sa aking telepono?
Hindi. Lumilikha ito ng VCF file para sa iyo upang i-preview, kopyahin o i-download. Hindi nito kailanman binabasa o binabago ang iyong address book; ikaw ang magpapasya kung at saan i-import ang file.
Na-upload ba ang aking impormasyon sa pakikipag-ugnayan?
Hindi. Ang mga detalye at isang opsyonal na larawan ay pinoproseso sa device na ito. Walang pag-upload, account, pagpoproseso ng server o awtomatikong pag-save.
Ano ang pagkakaiba sa pagitan ng vCard 3.0 at 4.0?
Ang mga ito ay dalawang bersyon ng vCard contact format. Ang tool ay nagsusulat ng isang katugmang VCF text file gamit ang bersyon na iyong pinili; maaaring iba ang suporta ng mga contact app sa kanila.
Bine-verify ba nito ang mga numero ng telepono o email address?
Hindi. Sinusuri nito ang kanilang pangunahing format lamang. Hindi nito ma-verify na ang isang numero, mailbox, address o website ay pagmamay-ari ng tao.
