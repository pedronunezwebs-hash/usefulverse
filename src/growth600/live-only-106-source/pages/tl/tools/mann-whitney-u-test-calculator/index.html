Mann–Whitney U Test Calculator

Mag-paste ng dalawang independiyenteng numeric na sample upang ihambing ang kanilang mga ranggo. Ang tool ay nag-uulat ng parehong mga istatistika ng U, isang dalawang panig na p-value, paghawak ng tie, pamamaraan at naka-sign na rank-biserial effect.

Maglagay ng 2–500 finite na numero bawat sample (hanggang ±1,000,000,000,000). Paghiwalayin gamit ang mga kuwit, semicolon, puwang o bagong linya; gumamit ng tuldok para sa mga decimal na lugar. Ang mga sample ay dapat na independyente.

Ang pahinang ito ay nagpapatakbo ng dalawang panig na pagsubok lamang. Gumagamit ito ng eksaktong pamamahagi ng permutasyon para sa mga sample na walang tie na may hindi hihigit sa 40 obserbasyon sa kabuuan; kung hindi, ito ay gumagamit ng isang normal na pagtatantya na itinama ang tie na may pagwawasto ng pagpapatuloy. Ang lahat ng pantay na pinagsama-samang halaga ay nagbabalik ng p=1.

Mann–Whitney na mga resulta ng pagsusulit

Ang pagsusulit ay naghahambing ng mga ranggo, hindi kinakailangang mga median: ang isang median na interpretasyon ay nangangailangan din ng magkatulad na hugis na mga pamamahagi. Ang rank-biserial effect ay nilagdaan ng sample order at inilalarawan ang pairwise rank dominance. Hindi sinusukat ng p-value ang kahalagahan ng epekto, nagpapatunay ng dahilan, o pinapalitan ang pagsusuri sa disenyo ng pag-aaral.

Ano ang pinaghahambing ng Mann–Whitney U test?

Inihahambing nito ang mga pamamahagi ng ranggo ng dalawang independiyenteng sample. Ito ay hindi awtomatikong pagsubok ng mga median maliban kung ang mga karagdagang pagpapalagay sa hugis ng pamamahagi ay nananatili.

Ano ang pinaghahambing ng Mann–Whitney U test?

Inihahambing nito ang mga pamamahagi ng ranggo ng dalawang independiyenteng sample. Ito ay hindi awtomatikong pagsubok ng mga median maliban kung ang mga karagdagang pagpapalagay sa hugis ng pamamahagi ay nananatili.

Na-upload ba ang aking mga sample value?

Hindi. Ang pagraranggo at ang pagsubok ay kinakalkula sa browser na ito. Ang mga sample na halaga ay hindi ipinadala sa isang server o nai-save ng tool na ito.

Pareho ba ang Mann–Whitney sa Wilcoxon signed-rank test?

No. Mann–Whitney (Wilcoxon rank-sum) ay naghahambing ng dalawang independiyenteng grupo. Ang signed-ranggo na pagsubok ay para sa ipinares o tugmang mga obserbasyon.

Palagi bang sinusuri ng Mann–Whitney kung nagkakaiba ang mga median?

Hindi. Sinusubok nito ang mga pamamahagi ng ranggo. Ang pagbibigay-kahulugan dito bilang isang median na paghahambing ay nangangailangan ng mga karagdagang pagpapalagay, kabilang ang mga katulad na hugis na pamamahagi.

Paano pinangangasiwaan ng calculator ang mga kurbatang?

Nagtatalaga ito ng mga average na ranggo sa pantay na mga halaga at gumagamit ng normal na pagtatantya na itinama ang tie. Ang eksaktong paraan ng permutation nito ay ginagamit lamang kapag ang pinagsama-samang mga obserbasyon ay walang mga ugnayan at ang kabuuang sukat ng sample ay hindi hihigit sa 40.
