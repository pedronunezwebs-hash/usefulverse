CSV Pagsamahin ang

Pagsamahin ang ilang CSV file sa isang table. Ang mga katugmang pangalan ng column ay nakahanay kahit na ang kanilang order ay naiiba, at ang mga karagdagang column ay idinaragdag na may mga blangkong cell kung saan kinakailangan. Ang mga file ay mananatili sa browser na ito.

Pumili ng 2–20 file, hanggang 2 MiB bawat isa at 8 MiB sa kabuuan. Ang pagpoproseso ay nananatili sa device na ito.

Sa mga header, tumutugma ang mga column sa mga eksaktong pangalan at sumusunod ang mga bagong column sa pagkakasunud-sunod na unang nakita. Kung walang mga header, tumutugma ang mga column ayon sa posisyon. Ang mga tulad-pormula na header o value ay nilagyan ng apostrophe para sa mas ligtas na pagbubukas ng spreadsheet. Ang mga delimiter, file encoding at cell text ay hindi na-normalize.

Pinagsama ang CSV

Suriin ang pinagsamang CSV bago ito gamitin sa ibang application.

Paano ko pagsasamahin ang mga CSV na file sa iba't ibang mga order ng column?

Pumili ng dalawa o higit pang CSV file at panatilihing naka-on ang opsyon sa header. Itinutugma ang mga column sa pamamagitan ng eksaktong teksto ng header, gamit ang unang nakitang pagkakasunud-sunod. Ang mga nawawalang column ay nagiging walang laman na mga cell; idinaragdag ang mga hindi magkatugmang column sa output.

Mga madalas itanong

Pumili ng dalawa o higit pang CSV file at panatilihing naka-on ang opsyon sa header. Ang mga nawawalang column ay nagiging walang laman na mga cell; idinaragdag ang mga hindi magkatugmang column sa output.

Na-upload ba ang aking mga CSV file?

Hindi. Ang mga napiling file ay binabasa at pinagsasama-sama nang lokal sa browser na ito. Hanggang 20 file ang sinusuportahan, na may 2 MiB per-file at 8 MiB na pinagsamang limitasyon sa input. Walang ginagamit na pagpoproseso ng account o server.

Maaari ko bang pagsamahin ang mga CSV file kapag ang kanilang mga column ay nasa ibang pagkakasunud-sunod?

Oo. Kapag naka-enable ang mga header, nakahanay ang mga column ayon sa eksaktong teksto ng header, hindi posisyon. Ang mga bagong header ay idinaragdag sa pagkakasunud-sunod na unang nakita, at ang mga nawawalang halaga ay iniwang blangko.

Ano ang mangyayari kung ang CSV file ay walang header row?

I-off ang opsyon sa header. Pagkatapos ay i-align ang mga value ayon sa posisyon ng column, at ang output ay gumagamit ng mga neutral na pangalan gaya ng Column 1. Ang mga row ng input na may mas kaunting mga cell ay pinalamutian ng CSV parser.

Binago ba ang mga formula o spreadsheet command?

Ang mga tulad-pormula na mga header at value ay may prefix na apostrophe sa output na CSV upang mabawasan ang panganib ng pagpapatupad kapag binuksan sa spreadsheet software. Sinasadya nitong baguhin ang mga halaga ng cell na iyon.
