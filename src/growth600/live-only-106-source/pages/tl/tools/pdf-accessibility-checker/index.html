PDF Accessibility Checker

Mag-inspeksyon ng PDF nang lokal para sa ilang signal ng accessibility na nade-detect ng machine, kabilang ang mga tag ng dokumento, metadata, maaaring piliin na text, mga figure na walang kahaliling text, at heading-level jumps. Isa lang itong first-pass checker, hindi isang PDF/UA validator o isang kapalit para sa assistive-technology testing.

Pinakamataas na 25 MiB at 300 na pahina. Maaaring gumamit ng memorya ng device ang inspeksyon; ang isang computer ay inirerekomenda para sa malalaking file.

Inspection sa iyong device pagkatapos mong pumili ng file. Walang pag-upload, account, API, awtomatikong pag-save, o pagpoproseso ng server.

Ang mga pagsusuring ito ay heuristic. Hindi nila makumpirma ang tamang pagkakasunud-sunod ng pagbabasa, makabuluhang mga paglalarawan, contrast ng kulay, paggamit ng keyboard, mga label ng form, mga relasyon sa table-header, o PDF/UA/Section 508/WCAG conformance. Manu-manong suriin at subukan gamit ang pantulong na teknolohiya.

Ulat ng Inspeksyon

Ano ang makikita nitong PDF accessibility checker?

Ito ay nag-uulat kung ang PDF ay naglalantad ng mga tag ng istraktura, isang pamagat ng dokumento at wika, maaaring piliin na teksto sa bawat pahina, mga numero na may alternatibong teksto, at mga posibleng pagtalon sa mga antas ng heading. Hindi ito makapagpapasya kung makabuluhan ang ayos ng pagbasa o alternatibong teksto.

Mga madalas itanong

Ano ang makikita nitong PDF accessibility checker?

Ito ay nag-uulat kung ang PDF ay naglalantad ng mga tag ng istraktura, isang pamagat ng dokumento at wika, maaaring piliin na teksto sa bawat pahina, mga numero na may alternatibong teksto, at mga posibleng pagtalon sa mga antas ng heading. Hindi ito makapagpapasya kung makabuluhan ang ayos ng pagbasa o alternatibong teksto.

Na-upload ba ang aking PDF para suriin?

Hindi. Ang napiling PDF ay siniyasat sa tab ng browser na ito. Ang file at ang teksto nito ay hindi ina-upload, awtomatikong nai-save, o ipinadala sa isang server.

Nangangahulugan ba ang isang positibong resulta na ang PDF ay naa-access?

Hindi. Ito ay limitadong mga awtomatikong signal lamang. Ang isang naka-tag na PDF ay maaari pa ring magkaroon ng maling ayos ng pagbabasa, hindi magandang paglalarawan, hindi naa-access na mga form, mababang contrast, o iba pang mga hadlang. Kailangan pa rin ang manual at assistive-technology testing.

Maaari ba nitong kumpirmahin ang pagsunod sa PDF/UA o WCAG?

Hindi. Hindi sinusuri ng first-pass checker na ito ang bawat kinakailangan at hindi mapapatunayan ang PDF/UA, WCAG, Section 508, o legal na pagsunod.
