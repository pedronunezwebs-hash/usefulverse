Bcrypt Generator

Bumuo ng karaniwang bcrypt hash o suriin ang isang password laban sa isang umiiral na bcrypt hash. Gumagana ang trabaho sa isang lokal na manggagawa sa browser, at ang password ay iki-clear pagkatapos ng bawat pagsusuri.

Bcrypt ay gumagamit lamang ng unang 72 UTF-8 byte. Tinatanggihan ng tool na ito ang mas mahabang halaga sa halip na tahimik na putulin ang mga ito. Ang gastos 8–14 ay nagpapalaki ng trabaho; ang mas mataas na mga gastos ay maaaring magtagal, lalo na sa mga telepono. Pinapanatili ng isang lokal na manggagawa ang page na tumutugon, ngunit ginagawa ng iyong device ang trabaho.

Gumamit ng pansubok na password, hindi isang tunay na password sa pag-log in. Ang resulta ay para sa pag-aaral at mga pagsusuri sa pagiging tugma; huwag gamitin ang pahina ng browser na ito bilang isang production account-storage system.

Ano ang ginagawa ng bcrypt hash?

Bcrypt ay isang password-hashing function, hindi encryption. Pinagsasama nito ang isang one-way na hash na may random na asin at isang na-configure na work factor. Maaaring suriin ang hash laban sa password ng kandidato ngunit hindi ma-decrypt upang ipakita ang orihinal.

Mga madalas itanong

Ano ang ginagawa ng bcrypt hash?

Bcrypt ay isang password-hashing function, hindi encryption. Pinagsasama nito ang isang one-way na hash na may random na asin at isang na-configure na work factor. Maaaring suriin ang hash laban sa password ng kandidato ngunit hindi ma-decrypt upang ipakita ang orihinal.

Na-upload o nai-save ba ang aking password o hash?

Hindi. Ang pag-hash at pag-verify ay tumatakbo sa browser na ito. Ang pahina ay hindi nagpapadala ng inilagay na password o hash sa isang server o i-save ang mga ito; ang patlang ng password ay na-clear kapag natapos ang operasyon. Para sa kaligtasan, gumamit ng pansubok na password sa halip na isang tunay na password ng account.

Ine-encrypt ba ng bcrypt ang aking password?

Hindi. Ang Bcrypt ay isang one-way na hash ng password, hindi nababaligtad na pag-encrypt. Ito ay dinisenyo upang hayaan ang software na suriin ang isang kandidatong password nang hindi iniimbak ang orihinal na password.

Bakit may 72-byte na limitasyon ang bcrypt?

Ang bcrypt na format ay nagpoproseso ng pinakamaraming 72 UTF-8 byte. Ang tool na ito ay tumatanggi sa mas mahabang input kaya ang iba't ibang mga password ay hindi kailanman tahimik na tinatrato bilang parehong pinutol na halaga.

Dapat ko bang iimbak ang hash na ito para sa isang tunay na account?

Huwag gamitin ang page na ito bilang isang production credential system. Ang mga tunay na serbisyo ay dapat mag-hash ng mga password sa kanilang pinagkakatiwalaang server na may pinananatili na mga library ng pagpapatotoo, angkop na mga parameter, mga limitasyon sa rate at mga proteksyon ng account.
