Stem at Leaf Plot Generator

Mag-paste ng hanggang 250 value para ayusin ang mga ito sa mga tangkay at nakaayos na mga dahon. Piliin ang leaf digit at hatiin ang bawat stem sa isa, dalawa o limang row.

Paghiwalayin ang mga value gamit ang mga kuwit, espasyo, semicolon o bagong linya. Gumamit ng tuldok para sa mga halaga ng decimal.

Maglagay ng 1–250 finite value na may absolute value na hindi hihigit sa 1,000,000,000. Ang mga halaga ay maaaring magkaroon ng hanggang tatlong decimal na lugar; piliin ang katugmang lugar ng dahon. Ang mga karagdagang decimal na digit ay tinatanggihan, hindi bilugan. Ang mga negatibong tangkay ay gumagamit ng di-negatibong dahon (halimbawa, −12 ay −2 | 8). Ang mapaglarawang display na ito ay hindi kinakalkula ang mga quartile o inaalis ang mga outlier.

Paano ako gagawa ng stem-and-leaf plot?

Ipasok ang data at piliin kung aling huling digit ang magiging bawat dahon. Ang mga digit bago ito bumuo ng stem. Pinagbukud-bukod ang mga value, at nananatiling nakikita ang mga inuulit na value bilang mga paulit-ulit na dahon.

Paano ako gagawa ng stem-and-leaf plot?

Ipasok ang data at piliin kung aling huling digit ang magiging bawat dahon. Ang mga digit bago ito bumuo ng stem. Pinagbukud-bukod ang mga value, at nananatiling nakikita ang mga inuulit na value bilang mga paulit-ulit na dahon.

Na-upload ba ang aking data?

Hindi. Ang plot ay nabuo sa browser na ito. Ang iyong mga halaga ay hindi ina-upload o sine-save ng tool na ito.

Ano ang susi sa isang stem-and-leaf plot?

Ang susi ay nagpapaliwanag kung paano basahin ang isang tangkay at dahon bilang orihinal na halaga ng data. Halimbawa, na may mga buong numero, 1 | Ang 2 ay nangangahulugang 12. Sa mga negatibong halaga, ang tool na ito ay gumagamit ng isang floor-based stem, kaya −2 | 8 ay nangangahulugang −12.

Maaari ko bang hatiin ang mga tangkay?

Oo. Pumili ng isang row para sa dahon 0–9, dalawang row para sa 0–4 at 5–9, o limang row na may dalawang leaf digit sa bawat row. Pinapanatili ang mga walang laman na split row para maging malinaw ang pagpapangkat.

Tinatanggal ba ang mga duplicate na halaga?

Hindi. Bawat inilagay na halaga ay pananatilihin. Ang mga umuulit na halaga ay lilitaw bilang paulit-ulit na mga digit ng dahon, kaya ipinapakita pa rin ng plot ang orihinal na dalas.
