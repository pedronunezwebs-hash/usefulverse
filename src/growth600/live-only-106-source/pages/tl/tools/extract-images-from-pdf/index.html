Extract Mga Larawan mula sa PDF

Pumili ng PDF upang maghanap ng mga naka-embed na raster na larawan, i-preview ang mga ito, at mag-save ng magkakahiwalay na PNG na kopya o isang ZIP. Ang mga page ay hindi naraster sa mga screenshot.

Extract ang mga naka-embed na raster image object; hindi nito ginagawang mga larawan ang buong PDF na mga pahina. Ang mga vector drawing at page text ay hindi magkahiwalay na mga raster na larawan.

Ang iyong file ay nananatili sa device na ito at hindi ina-upload. Ang mga na-extract na pixel ay muling na-encode bilang PNG, kaya ang orihinal na naka-embed na format ng file at metadata ay hindi napanatili.

Lokal na limitasyon: 25 MiB PDF, 300 pages, 200 larawan, 8 megapixel bawat larawan, 16 megapixel sa kabuuan at 25 MiB ZIP. Ang malalaking PDF ay gumagamit ng memorya ng device; Inirerekomenda ang isang computer.

    Pumili ng PDF at piliin ang I-extract ang mga larawan. Binabasa ng browser na ito ang mga sinusuportahang naka-embed na raster image object at kino-convert ang kanilang mga decoded pixels sa PNG na mga file. Mag-download ng mga indibidwal na larawan o isang ZIP.

    Na-upload ba ang aking PDF o mga larawan?

    Hindi. Ang iyong PDF ay pinoproseso sa tab ng browser na ito. Hindi ina-upload ng tool ang file o nai-save ito sa isang account.

    Ginagawa bang larawan ng tool na ito ang bawat pahina ng PDF?

    Hindi. Ito ay naghahanap ng mga sinusuportahang naka-embed na raster image object. Gumamit ng PDF-to-image tool kung gusto mo ng render na larawan ng bawat buong page.

    Magiging byte-for-byte ba ang na-extract na PNG sa naka-embed na file?

    Hindi. Ang browser ay nagde-decode ng mga sinusuportahang object ng imahe at muling nag-encode ng kanilang mga pixel bilang PNG sa mga decoded na dimensyon ng object. Ang orihinal na compression, format ng file at metadata ay hindi pinapanatili.

    Bakit maaaring hindi lumitaw ang ilang PDF na larawan?

    Vector na likhang sining, mga mask ng imahe, hindi pangkaraniwang pag-encode, proteksyon ng password, mga malformed na file at mga limitasyon sa memorya ng browser ay maaaring maiwasan ang pagkuha. Ang tool ay nag-uulat ng mga sinusuportahang bagay lamang at hindi ina-upload ang iyong file.
