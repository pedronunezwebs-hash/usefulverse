DOCX Editor

Gumawa ng mga nakatutok na pag-edit ng teksto sa isang modernong Word DOCX file sa browser na ito. Binabago ng editor ang umiiral na text na tumatakbo sa pangunahing dokumento at pinapanatili ang iba pang mga bahagi ng dokumento na hindi nagbabago. Ito ay hindi isang ganap na kapalit ng Salita, at ang kumplikadong pag-format ay maaaring hindi ma-preview dito.

Modern .docx lang. Maximum na 25 MiB, 80 MiB expanded package, 8 MiB document XML, 500 text segment at 250,000 character. Mas mahusay na gumagana ang malalaking dokumento sa isang computer.

Ang pagpoproseso ay nangyayari sa iyong device pagkatapos mong pumili ng file. Walang pag-upload, account, API, autosave o pagpoproseso ng server.

Ang nakatutok na editor na ito ay nagbabago lamang ng umiiral na tekstong tumatakbo sa pangunahing dokumento. Pinapanatili nito ang mga istilo, larawan at iba pang nilalaman ng bahagi ng package, ngunit nire-repack ang lalagyan ng DOCX ZIP. Hindi nito ine-edit ang mga header, footer, komento, footnote, formatting, istraktura ng talata o sinusubaybayang pagbabago. Ang mga macro at digitally signed na pakete ay hindi suportado.

Ano ang maaari kong i-edit sa isang DOCX file?

Maaari mong i-edit ang mga kasalukuyang segment ng teksto sa mga talata at mga cell ng talahanayan sa isang modernong .docx file, i-preview ang teksto at mag-download ng na-edit na kopya. Ang editor na ito ay hindi nagdaragdag o nag-aalis ng mga talata, nagbabago ng pag-format, nag-e-edit ng mga header o footer, o sumusuporta sa mga sinusubaybayang pagbabago.

Na-upload ba ang aking Word document?

Hindi. Ang file ay pinoproseso sa browser na ito pagkatapos mong piliin ito. Hindi ito ina-upload, awtomatikong nai-save o ipinadala sa isang server.

Papanatilihin ba ng na-edit na file ang aking kasalukuyang pag-format?

Ang mga istilo ng text at iba pang nilalaman ng package-part ay pinapanatili. Kapag pinalitan ang isang text segment, ang kasalukuyang run formatting nito ay mananatili; ang tool na ito ay hindi nag-aalok ng rich text formatting controls o ginagarantiya na ang bawat feature ng Word ay nagre-render nang magkapareho.

Maaari bang masubaybayan ng pag-edit na ito ang mga pagbabago, header, o pinirmahang dokumento?

Hindi. Binabago ng nakatutok na editor ang text na tumatakbo sa pangunahing dokumento lamang. Hindi sinusuportahan ang mga tracked-change workflow, header at footer, macro at digitally signed na mga file.
