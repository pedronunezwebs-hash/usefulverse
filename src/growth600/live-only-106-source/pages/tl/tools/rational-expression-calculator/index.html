Rational Expression Calculator

Maglagay ng integer-coefficient polynomial sa x upang bawasan ang isang rational expression. Ang resulta ay nagpapanatili sa orihinal na paghihigpit ng denominator, kaya ang pagkansela ay hindi nagtatago ng mga halaga na ginagawang hindi natukoy ang input.

Gumamit ng mga integer coefficient at x, halimbawa x^2-1. Powers hanggang 8.

Gumamit ng mga integer coefficient at x, halimbawa x-1. Hindi ito maaaring maging zero.

Sinusuportahan ang isang variable na x, integer coefficients hanggang 1,000,000 at degree hanggang 8. Walang panaklong o decimal coefficient.

Paano mo pinapasimple ang isang rational expression?

I-factor ang numerator at denominator, kanselahin ang kanilang karaniwang polynomial at panatilihin ang mga zero ng orihinal na denominator bilang mga paghihigpit. Halimbawa, ang x²−1 sa x−1 ay bumababa sa x+1, na ang x≠1 ay hindi pa rin kasama.

Mga madalas itanong

Paano mo pinapasimple ang isang rational expression?

I-factor ang numerator at denominator, kanselahin ang kanilang karaniwang polynomial at panatilihin ang mga zero ng orihinal na denominator bilang mga paghihigpit. Halimbawa, ang x²−1 sa x−1 ay bumababa sa x+1, na ang x≠1 ay hindi pa rin kasama.

Na-upload ba ang aking mga expression?

Hindi. Ang pag-parse at pagpapasimple ay tumatakbo nang lokal sa browser na ito; hindi na-upload o nai-save ang mga input.

Bakit panatilihin ang isang paghihigpit pagkatapos kanselahin ang isang kadahilanan?

Ang pinasimple na expression ay maaaring tukuyin sa isang halaga kung saan ang orihinal na denominator ay zero. Ang halagang iyon ay nananatiling hindi kasama sa domain ng orihinal na expression.

Anong polynomial format ang sinusuportahan?

Gumamit ng isang variable na x na may mga integer coefficient, gaya ng 2x^3−x+4. Ang mga kapangyarihan mula 0 hanggang 8 ay sinusuportahan; ang mga panaklong, decimal coefficient at maramihang mga variable ay hindi.

Nakikita ba nito ang lahat ng posibleng factorization?

Kinakansela nito ang eksaktong karaniwang polynomial factor gamit ang integer arithmetic. Hindi ito nagbibigay ng kumpletong factorization sa irreducible linear o quadratic factor.
