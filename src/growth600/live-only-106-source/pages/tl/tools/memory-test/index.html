Memory Test

Magsanay sa pag-alala sa lumalaking pagkakasunod-sunod ng mga digit o posisyon sa isang 3×3 grid. Ang bawat tamang round ay nagdaragdag ng isang item.

Practice lang. Ito ay hindi isang IQ test, diagnosis o validated cognitive assessment. Ang mga resulta ay walang kahulugang klinikal o populasyon.

Para sa mga screen reader, piliin ang Digit span: ang bawat digit ay inaanunsyo nang isang beses habang nagpe-playback. Ang visual pattern mode ay depende sa paningin.

Nai-save ba ng memory test na ito ang aking marka?

Hindi. Ang sequence at score ay mananatili sa page na ito habang ito ay bukas. Walang na-upload, at walang account o online ranking.

Ano ang sinusukat ng memory test na ito?

Ito ay isang kaswal na sequence-recall practice game. Ito ay hindi standardized at hindi maaaring mag-diagnose ng isang kondisyon o masukat ang IQ.

Paano nagkakaiba ang digit span at pattern mode?

Digit span ang mga digit nang paisa-isa at inaanunsyo ang mga ito para sa access sa screen-reader. Ang pattern mode ay nagpapa-flash ng mga posisyon sa isang 3×3 grid at nangangailangan ng paningin.

Naka-save ba ang mga score o inihambing sa ibang tao?

Hindi. Umiiral lamang ang mga marka habang nananatiling bukas ang pahinang ito. Walang leaderboard, account o pag-upload ng server.
