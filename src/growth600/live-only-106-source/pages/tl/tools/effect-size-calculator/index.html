Effect Size Calculator

Maglagay ng buod na istatistika para sa dalawang independiyenteng grupo para kalkulahin ang kanilang nilagdaang standardized mean difference, pinagsamang standard deviation at small-sample corrected Hedges’ g.

Pangkat 1
Pangkat 2

Para sa mga independiyenteng grupo, ang bersyon na ito ay gumagamit ng kumbensyonal na pooled-SD na kahulugan at ipinapalagay ang isang nakabahaging pagkakaiba-iba ng populasyon. Maglagay ng sample (n−1) standard deviations, hindi standard errors.

Ang bawat sample size ay dapat na 2–1,000,000; ibig sabihin at ang mga SD ay limitado sa ±1,000,000,000 (hindi maaaring negatibo ang mga SD). Hindi bababa sa isang SD ay dapat na higit sa zero.

resulta ng laki ng epekto

d = (mean₁ − mean₂) / pooled SD. Hedges’ g = J(df) × d, na may df = n₁ + n₂ − 2. Ang tanda ay depende sa pagkakasunud-sunod ng pangkat. Ang isang magnitude ay hindi awtomatikong "maliit", "katamtaman" o "malaki"; bigyang-kahulugan ito sa paksa at disenyo ng pag-aaral.

Ano ang sinusukat ng calculator ng laki ng epekto?

Ito ay nagpapahayag ng pagkakaiba sa pagitan ng dalawang paraan ng grupo sa mga pinagsama-samang standard-deviation unit. Ang d ni Cohen ay ang hindi naitama na pamantayang pagkakaiba; Naglalapat ang Hedges' g ng maliit na sample na pagwawasto.

Na-upload ba ang mga istatistika ng aking pag-aaral?

Hindi. Ang pagkalkula ay tumatakbo sa browser na ito. Ang iyong mga istatistika ng buod ay hindi ipinadala sa isang server o nai-save ng tool na ito.

Ano ang pagkakaiba ng Cohen's d at Hedges' g?

Parehong istandardize ang ibig sabihin ng pagkakaiba sa pamamagitan ng pinagsama-samang standard deviation. Ang hedges’ g ay dumarami d ng maliit na sample na pagwawasto, na nagpapababa ng bias kapag maliit ang mga sample.

Maaari ba akong magpasok ng mga karaniwang error sa halip na mga karaniwang paglihis?

Hindi. Inaasahan ng calculator na ito ang sample na standard deviation ng bawat grupo. Ang isang karaniwang error ay naglalarawan ng kawalan ng katiyakan sa isang sample na pagtatantya at hindi mapapalitan ng SD dito.

Ang mas malaking sukat ba ng epekto ay nagpapatunay na ang isang resulta ay mahalaga?

Hindi. Ang laki ng epekto ay naglalarawan ng isang standardized na pagkakaiba, hindi istatistikal na kahalagahan, sanhi o praktikal na kahalagahan. Ang konteksto, kawalan ng katiyakan, disenyo ng pag-aaral at sukat ng pagsukat ay mahalaga.
