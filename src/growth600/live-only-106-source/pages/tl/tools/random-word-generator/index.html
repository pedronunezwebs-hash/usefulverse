Tagabuo ng Random na Salita

Pumili ng mga salita para sa writing prompt, laro sa klase o mabilis na inspirasyon. Pumili ng kategorya at haba, pagkatapos ay kopyahin o i-download ang listahan.

Gamitin muli ang seed para makuha ang parehong listahan.

Sadyang maliit ang listahan; hindi ito diksyunaryo ng pagsasalin o dalas.

Mga salita mo

    Paano ako bubuo ng mga random na salita?

    Pumili ng kategorya, saklaw ng haba at bilang ng resulta, pagkatapos ay piliin ang Bumuo. Iwanang blangko ang seed para sa bagong listahan o gamitin itong muli para sa parehong pagpili.

    Mga madalas itanong

    Paano ako bubuo ng mga random na salita?

    Pumili ng kategorya, saklaw ng haba at bilang ng resulta, pagkatapos ay piliin ang Bumuo. Iwanang blangko ang seed para sa bagong listahan o gamitin itong muli para sa parehong pagpili.

    Ina-upload ba ang mga salita ko?

    Hindi. Pinipili ang listahan mula sa maliit na diksyunaryong nasa browser mo. Walang ina-upload o sine-save.

    Maaari ba akong kumuha ng ibang listahan sa bawat pagkakataon?

    Oo. Iwanang blangko ang seed para gumawa ng bagong listahan. Parehong seed, filter at diksyunaryo ang nagbibigay ng parehong pagpili.

    Kasama ba sa generator ang bawat salita?

    Hindi. Gumagamit ito ng maliit na piniling listahan at pantay na pumipili sa mga salitang tumutugma sa filter.
