Box Plot Calculator

Mag-paste ng isa o dalawang sample upang ihambing ang kanilang limang-numero na mga buod, interquartile range at Tukey outlier. Piliin kung paano kinakalkula ang mga quartile.

Sample 2

Maglagay ng hanggang 2,000 numero bawat sample. Paghiwalayin ang mga value gamit ang mga semicolon, puwang o bagong linya. Ang mga semicolon ay nagpapanatili ng mga decimal na kuwit na buo.

Ang bawat sample ay tumatanggap ng 1–2,000 finite value na may absolute magnitude na hindi hihigit sa 1,000,000,000. Ang 1.5×IQR na bakod ay nagba-flag ng mga potensyal na outlier; nagtatapos ang mga whisker sa pinakamatinding halaga sa loob ng bakod. Ang iba't ibang pamamaraan ng quartile ay maaaring magbigay ng iba't ibang mga halaga ng Q1 at Q3. Ito ay isang mapaglarawang tsart, hindi isang pagsubok sa kahalagahan o isang dahilan upang alisin ang data.

Box

Paano mo kinakalkula ang isang box plot?

Pagbukud-bukurin ang bawat sample, hanapin ang median at quartile nito, pagkatapos ay kalkulahin ang interquartile range (Q3 − Q1). Ang mga whisker ay umabot sa pinakamatinding obserbasyon sa loob ng 1.5 IQR na bakod; ang mga halagang higit sa kanila ay ipinapakita bilang mga outlier.

Na-upload ba ang aking data?

Hindi. Ang mga istatistika at ang tsart ay kinakalkula sa browser na ito. Ang iyong mga halaga ay hindi ina-upload o sine-save ng tool na ito.

Ano ang ipinapakita ng kahon sa isang plot ng kahon?

Ang kahon ay tumatakbo mula sa unang quartile (Q1) hanggang sa ikatlong quartile (Q3). Ang linya sa loob ay nagmamarka ng median, at ang haba ng kahon ay ang interquartile range (IQR). Ang mga balbas ay nagpapakita ng saklaw sa loob ng bakod; ang mga punto sa kabila ng mga bakod ay minarkahan bilang mga outlier.

Bakit maaaring magkaiba ang mga resulta ng quartile?

Mayroong higit sa isang tinatanggap na quartile convention. Nilagyan ng label ng calculator na ito ang bawat pamamaraan: median ng mga halves hindi kasama ang pangkalahatang median, median ng mga halves kabilang ito, o linear interpolation gamit ang uri 7. Piliin ang convention na kinakailangan ng iyong klase o pagsusuri.

Nangangahulugan ba ang outlier na dapat kong tanggalin ang halagang iyon?

No. Ang 1.5×IQR na panuntunan ay nagba-flag lang ng mga value para sa pagsusuri. Suriin ang data at konteksto bago magpasya kung ano ang gagawin; ang mga hindi pangkaraniwang halaga ay maaaring wastong mga obserbasyon.
