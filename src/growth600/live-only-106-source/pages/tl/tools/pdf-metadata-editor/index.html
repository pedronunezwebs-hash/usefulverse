PDF Metadata Editor

Basahin o i-edit ang karaniwang impormasyon ng dokumento na nakaimbak sa isang PDF, pagkatapos ay mag-download ng hiwalay na kopya. Ang napiling PDF ay mananatili sa device na ito.

Panatilihin ang iyong orihinal. Ang muling pag-save ay maaaring magpawalang-bisa sa mga digital na lagda o makaapekto sa mga advanced na feature ng PDF. Ang tool na ito ay hindi nag-aalis ng nakatagong impormasyon o nagpapatunay sa privacy.

Mga lokal na limitasyon: 25 MiB input, 300 page at 50 MiB output. Ang malalaking dokumento ay maaaring mangailangan ng higit na memorya; Inirerekomenda ang isang computer.

Ang karaniwang impormasyon ng dokumentong PDF lamang ang na-edit. Ang XMP, custom na metadata, mga attachment, nakatagong nilalaman at pagpapatunay ng lagda ay hindi suportado.

Karaniwang impormasyon ng dokumento

Mag-iwan ng field na blangko upang alisin ang karaniwang entry ng impormasyon mula sa bagong kopya. Ang iba pang mga patlang ay pinananatili.

Handa na ang iyong PDF copy

I-download ang na-edit na PDF

Processing ay lokal sa browser na ito. Walang account, pag-upload, pagpoproseso ng server o awtomatikong pag-save.

Aling PDF metadata ang maaari kong baguhin?

Ang tool na ito ay nag-e-edit ng karaniwang mga field ng impormasyon ng dokumento: pamagat, may-akda, paksa, mga keyword, tagalikha, producer, petsa ng paglikha at petsa ng pagbabago. Hindi nito ine-edit ang XMP metadata o mga custom na property.

Mga madalas itanong

Aling PDF metadata ang maaari kong baguhin?

Ang tool na ito ay nag-e-edit ng karaniwang mga field ng impormasyon ng dokumento: pamagat, may-akda, paksa, mga keyword, tagalikha, producer, petsa ng paglikha at petsa ng pagbabago. Hindi nito ine-edit ang XMP metadata o mga custom na property.

Na-upload ba ang aking PDF?

Hindi. Nagaganap ang pagbabasa at pag-edit sa iyong browser pagkatapos mong pumili ng file. Ang orihinal na file ay hindi nabago; ang pag-save ay lumilikha ng isang hiwalay na kopya ng PDF.

Tinatanggal ba nito ang lahat ng metadata mula sa isang PDF?

Hindi. Ini-edit lamang nito ang mga karaniwang entry sa karaniwang diksyunaryo ng impormasyon ng dokumentong PDF. Maaaring manatili ang XMP, mga custom na property, naka-embed na file at iba pang nakatagong content.

Magpapanatili ba ng digital signature ang pag-edit ng metadata?

Huwag umasa diyan. Ang pag-save ay muling isinusulat ang PDF at maaaring magpawalang-bisa sa mga umiiral nang digital na lagda o makakaapekto sa mga feature na hindi sinusuportahan ng tool na ito. Panatilihin ang orihinal at i-verify ang kopya.

Na-overwrite ba ang orihinal na PDF?

Hindi. Binabasa ng tool ang napiling file at gumagawa ng hiwalay na mada-download na kopya. Hindi nito binabago ang orihinal sa iyong device.
