Image Vectorizer

Subaybayan ang mga simpleng logo, icon, at flat-color na likhang sining sa mga SVG na landas. Pumili ng limitasyon sa kulay at laki ng detalye, i-preview ang vector, pagkatapos ay i-download ang SVG.

128

Ang pinakamahabang bahagi ay nababawasan sa ganitong karaming pixel o mas kaunti. Ang mas malaking detalye ay maaaring lumikha ng mas malaking SVG.

Pinakamahusay para sa mga simpleng logo, icon, at flat-color na drawing. Ang pamamaraang ito ay sumusunod sa pixel grid; hindi ito nagpapakinis ng mga kurba o nagpaparami ng detalye ng larawan.

Hanggang 5 MiB bawat source na larawan. Ang imahe ay lokal na pinoproseso at hindi na-upload o awtomatikong nai-save. Maaaring gumamit ng memorya ng device ang malalaking larawan; Inirerekomenda ang isang computer.

Paano mo gagawing SVG ang isang imahe?

Pumili ng raster na imahe, piliin ang detalye ng output at bilang ng kulay nito, pagkatapos ay gawin ang SVG. Ang tool ay nagpapangkat ng kulay na pixel na tumatakbo sa mga tunay na vector path; sinusundan ng mga gilid ang napiling pixel grid, kaya mas gumagana ang flat artwork kaysa sa mga litrato.

Mga madalas itanong

Paano mo gagawing SVG ang isang imahe?

Pumili ng raster na imahe, piliin ang detalye ng output at bilang ng kulay nito, pagkatapos ay gawin ang SVG. Ang tool ay nagpapangkat ng kulay na pixel na tumatakbo sa mga tunay na vector path; sinusundan ng mga gilid ang napiling pixel grid, kaya mas gumagana ang flat artwork kaysa sa mga litrato.

Na-upload ba ang aking larawan?

Hindi. Ang imahe ay na-decode at sinusubaybayan sa tab ng browser na ito. Hindi ito na-upload o awtomatikong nai-save.

Naglalaman ba ang SVG ng orihinal na larawan?

Hindi. Ang resulta ay naglalaman ng SVG na mga hugis ng path, hindi isang naka-embed na raster na imahe. Tinatantiya nito ang pinagmulan sa pamamagitan ng pagpapangkat ng mga pixel sa mga kulay at landas.

Magiging vector ba ito ng isang litrato nang maayos?

Hindi. Ang pixel-grid trace ay inilaan para sa mga simpleng logo, icon, at flat-color na drawing. Ang mga larawan ay maaaring makagawa ng mga blocky na gilid at malalaking SVG file.

Ina-upload o pinapanatili ba ng tool ang aking larawan?

Hindi. Ang pinagmulan ay pinoproseso sa tab na ito at hindi na-upload o awtomatikong nai-save. Ang bilis ng pagproseso at paggamit ng memory ay depende sa iyong device.
