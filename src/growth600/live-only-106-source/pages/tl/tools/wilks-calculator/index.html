Wilks at DOTS powerlifting calculator

Maglagay ng lifter bodyweight at isang powerlifting total o single-lift na resulta. Pumili ng pinangalanang modelo ng pagmamarka upang makakita ng maihahambing na marka; ang bawat modelo ay ipinapakita nang hiwalay.

Tinantyang Iskor

Paghahambing na pagtatantya lamang. Hindi ang kasalukuyang opisyal na marka ng IPF Goodlift. Paghambingin ang mga resulta gamit ang parehong modelo, pangkat ng koepisyent, at format ng kaganapan; iba-iba ang mga tuntunin at pagiging angkop ng modelo.

Paano kinakalkula ang marka ng Wilks o DOTS?

Inilalapat ng bawat modelo ang na-publish na bodyweight coefficient nito sa inilagay na bodyweight, pagkatapos ay sinusuri ang ipinasok na resulta ng pag-angat ng denominator ng modelong iyon. Maihahambing lamang ang resulta kapag ginamit ang parehong formula, pangkat ng koepisyent, at uri ng kaganapan.

Na-upload o nai-save ba ang aking mga numero?

Hindi. Ang pagkalkula ay tumatakbo sa browser na ito; ang mga inilagay na halaga ay hindi ina-upload o nai-save.

Ano ang pagkakaiba sa pagitan ng Wilks, Wilks-2 at DOTS?

Sila ay hiwalay na mga modelo ng bodyweight-adjustment na may iba't ibang nai-publish na coefficient. Ang kanilang mga marka ay hindi mapapalitan, at ang dalawang modelo ay maaaring mag-order ng mga lifter nang magkaiba.

Ito ba ang opisyal na marka ng IPF?

Hindi. Ipinapakita ng calculator na ito ang mga pagtatantya ng Wilks, Wilks-2 at DOTS. Ginagamit ng mga kumpetisyon ng IPF ang kasalukuyang sistema ng pagmamarka ng federation at ang mga panuntunan nito; suriin ang mga opisyal na resulta ng organizer.

Maaari ko bang ihambing ang resulta ng bench press sa kabuuang kabuuang powerlifting?

Gamitin ang parehong format ng kaganapan para sa parehong mga atleta. Maaaring kalkulahin ng aritmetika ang isang marka mula sa alinmang input, ngunit ang paghahambing ng isang pagtaas sa kabuuang tatlong pagtaas ay hindi isang katulad na paghahambing ng kumpetisyon.
