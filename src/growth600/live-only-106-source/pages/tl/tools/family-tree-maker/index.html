Family Tree Maker

Gumawa ng family chart mula sa impormasyong alam mo na. Magdagdag ng mga tao, ikonekta ang mga link ng magulang, pagkatapos ay mag-export ng diagram o isang GEDCOM file. Ang page ay hindi naghahanap ng mga talaan o nagse-save ng data ng iyong pamilya.

Mga tao sa punong ito
Ikonekta ang magulang at anak

Maaaring maging sensitibo ang mga detalye ng pamilya. Ang data ay mananatili sa memorya hanggang sa isara o i-reset mo ang pahinang ito; maaaring maglaman ng pribadong impormasyon ang mga pag-export.

Family tree

    Paano ako gagawa ng family tree?

    Idagdag ang bawat tao nang isang beses, pagkatapos ay ikonekta ang isang magulang sa isang bata. Hinaharangan ng chart ang mga duplicate na link, higit sa dalawang nakalistang magulang at cycle ng ninuno. Mag-export ng SVG diagram o GEDCOM text file kapag handa ka na.

    Mga madalas itanong

    Paano ako gagawa ng family tree?

    Idagdag ang bawat tao nang isang beses, pagkatapos ay ikonekta ang isang magulang sa isang bata. Hinaharangan ng chart ang mga duplicate na link, higit sa dalawang nakalistang magulang at cycle ng ninuno. Mag-export ng SVG diagram o GEDCOM text file kapag handa ka na.

    Na-upload o nai-save ba ang impormasyon ng aking pamilya?

    Hindi. Ang tsart ay nananatili sa sesyon ng pahinang ito. Hindi ito na-upload o nai-save sa storage ng browser. Ang isang na-export na file ay sa iyo upang iimbak at ibahagi, kaya suriin muna ito para sa mga pribadong detalye.

    Makakahanap ba ng mga kamag-anak o pampublikong talaan ang tool na ito?

    Hindi. Ito ay nag-aayos lamang ng mga detalye na iyong ipinasok. Hindi ito naghahanap ng mga talaan, nagpapatunay ng mga pagkakakilanlan o nagtatatag ng mga legal na relasyon.

    Ano ang GEDCOM file?

    Ang GEDCOM ay isang format ng text na ginagamit upang ilipat ang mga talaan ng family-history sa pagitan ng mga katugmang programa ng genealogy. Suriin ang isang na-export na file bago ito ibahagi.

    Sinusuportahan ba ng chart ang higit sa dalawang magulang?

    Ang bersyon na ito ay nagbibigay-daan sa hanggang dalawang nakalistang magulang bawat tao. Ang isang relasyon sa pamilya ay maaaring mas kumplikado kaysa sa maaaring katawanin ng tsart na ito.
