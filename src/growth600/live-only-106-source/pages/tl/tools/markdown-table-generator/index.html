Markdown Table Generator

Gumawa ng Markdown table sa isang maliit na nae-edit na grid. Mag-import ng comma-separated, semicolon-separated, o tab-separated text, piliin ang column alignment, at kopyahin ang plain Markdown na may mga pipe na ligtas na nakatakas.

Naka-quote na mga CSV field ay suportado. Pinapalitan ng import ang kasalukuyang grid; hanggang 100 row, 20 column, at 250,000 character.

Ang unang hilera ay nagiging Markdown header. Magdagdag ng kahit isang row at isang column.

Paano ako gagawa ng Markdown table?

Maglagay ng header row at data row, piliin ang bawat column alignment, pagkatapos ay kopyahin ang nabuong Markdown. Ang mga tubo ay nakatakas at ang hindi pantay na imported na mga hilera ay may palaman.

Na-upload ba ang aking talahanayan?

Hindi. Ang iyong talahanayan ay pinoproseso sa tab ng browser na ito. Ang pag-import, pag-edit, at nabuong Markdown ay hindi ipinapadala sa isang server o awtomatikong nai-save.

Maaari ba akong mag-import ng CSV o TSV?

Oo. I-paste ang mga halagang pinaghihiwalay ng kuwit, pinaghihiwalay ng semicolon, o pinaghihiwalay ng tab, pagkatapos ay i-import ang mga ito sa nae-edit na grid. Sinusuportahan ang mga naka-quote na field ng CSV at mga naka-quote na separator.

Paano pinangangasiwaan ang mga pipe at line break?

Ang isang tubo sa loob ng isang cell ay nakatakas kaya hindi nito nahahati ang talahanayan ng Markdown. Nakatakas din ang mga backslashes, at ang mga cell line break ay kinakatawan ng <br>.
