Lingguhang Plano

Bumuo ng isang simpleng lingguhang iskedyul ng time-block para sa trabaho, mga personal na plano, pag-aaral, o kalusugan. Malinaw na ipinapakita ang mga overnight block at mga salungatan sa iskedyul.

Ang paulit-ulit na lingguhang plano ay gumagamit ng mga lokal na oras ng wall-clock; hindi nito isinasaalang-alang ang mga time zone, mga pagbabago sa daylight-saving, mga kaganapan sa kalendaryo, o mga paalala.

Ang plano ay nananatili sa memorya sa tab na ito. Mag-download ng JSON backup upang mapanatili ito; walang awtomatikong imbakan o pag-upload.

Lingguhang iskedyul

Paano ako gagawa ng lingguhang iskedyul?

Magdagdag ng pamagat, araw, oras ng pagsisimula, oras ng pagtatapos, at kategorya para sa bawat bloke. Maaaring tumawid ng hatinggabi ang mga bloke. Naka-flag ang overlapping na oras, kabilang ang buong Linggo at Lunes.

Mga madalas itanong

Paano ako gagawa ng lingguhang iskedyul?

Magdagdag ng pamagat, araw, oras ng pagsisimula, oras ng pagtatapos, at kategorya para sa bawat bloke. Maaaring tumawid ng hatinggabi ang mga bloke. Naka-flag ang overlapping na oras, kabilang ang buong Linggo at Lunes.

Na-upload o nai-save ba ang aking lingguhang iskedyul?

Hindi. Mananatili ang iyong iskedyul sa tab ng browser na ito maliban kung pipiliin mong mag-download ng JSON backup. Mag-import ng backup na pinili mo mula sa iyong device.

Maaari bang isama ng isang lingguhang tagaplano ang mga overnight shift?

Oo. Pumili ng isang oras ng pagtatapos nang mas maaga kaysa sa oras ng pagsisimula upang lumikha ng isang bloke na magtatapos sa susunod na araw. Sinusuportahan ang mga block hanggang 18 oras.

Nakikita ba ng lingguhang iskedyul ang mga salungatan?

Oo. Sinusuri nito ang mga bloke ng oras sa parehong araw at sa hatinggabi, kabilang ang isang bloke ng Linggo na nag-o-overlap sa Lunes.

Nagsi-sync ba ang planner na ito sa Google Calendar?

Hindi. Gumagana ito nang lokal sa tab na ito at walang koneksyon sa kalendaryo o serbisyo ng paalala. Maaari mong i-print ang plano o mag-download at mag-import ng JSON backup.
