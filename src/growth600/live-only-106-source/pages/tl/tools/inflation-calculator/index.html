Calculator ng Inflation

Tantyahin kung paano nagbabago ang antas ng presyo sa pagitan ng mga taon na may mga taunang average ng U.S. CPI-U, o ilagay ang sarili mong taunang rate para sa isa pang market. Ang mga kalkulasyon ay nananatili sa browser na ito.

Gamitin ang parehong unit ng currency para sa iyong halaga; ang tool na ito ay hindi nagko-convert ng mga pera.

U.S. mode ay gumagamit ng taunang-average na CPI-U para sa lahat ng item, U.S. city average, mula 1913–2025. Ito ay isang malawak na pagtatantya sa kasaysayan, hindi ang iyong personal na basket o isang live na hula. Ang ibang mga merkado ay nangangailangan ng iyong sariling ipinapalagay na rate. Gumamit ng computer o mas malaking screen kung nakakatulong; ang magaan na calculator na ito ay hindi nangangailangan ng pag-download ng modelo.

Paano ko kalkulahin ang inflation sa pagitan ng dalawang taon?

Magpasok ng halaga at dalawang taon. Pina-multiply ito ng U.S. mode sa mas huling taunang index ng CPI-U na hinati sa naunang index. Gamitin ang custom-rate mode kapag gusto mong mag-modelo ng ipinapalagay na taunang rate sa halip.

Mga madalas itanong

Paano ko kalkulahin ang inflation sa pagitan ng dalawang taon?

Magpasok ng halaga at dalawang taon. Pina-multiply ito ng U.S. mode sa mas huling taunang index ng CPI-U na hinati sa naunang index. Gamitin ang custom-rate mode kapag gusto mong mag-modelo ng ipinapalagay na taunang rate sa halip.

Na-upload ba ang aking halaga o rate?

Hindi. Ang halaga, taon at rate ay kinakalkula sa browser na ito at hindi ina-upload o nai-save ng tool.

Aling data ng inflation ng U.S. ang ginagamit ng calculator na ito?

Ginagamit nito ang BLS Consumer Price Index for All Urban Consumers (CPI-U), U.S. city average, lahat ng item, annual-average index values ​​mula 1913 hanggang 2025. Maaaring mag-iba ang taunang average sa isang partikular na buwan o karanasan sa sambahayan.

Maaari ko bang gamitin ito para sa ibang bansa?

Oo, piliin ang Custom na taunang rate at maglagay ng ipinapalagay na rate at tagal. Iyan ay isang senaryo, hindi isang opisyal na panukala sa inflation para sa bansang iyon; gumamit ng index ng ahensya ng lokal na istatistika para sa paghahambing na nakabatay sa data.

Kasama ba sa resulta ang investment return o currency conversion?

Hindi. Inihahambing lamang nito ang mga antas ng presyo. Hindi kasama dito ang interes, mga return ng pamumuhunan, halaga ng palitan, buwis, bayarin o isang basket ng personal na paggastos.
