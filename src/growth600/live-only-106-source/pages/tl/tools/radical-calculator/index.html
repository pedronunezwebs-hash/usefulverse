Pagpapasimple ng Square Root

Pasimplehin ang eksaktong integer radical sa pamamagitan ng pagkuha ng mga perpektong kapangyarihan, o muling isulat ang isang fraction upang ang denominator nito ay walang square root. Eksaktong mga resulta para sa mga sinusuportahang input ng integer.

Ipasok ang mga buong numero. Ang mga radican ay limitado sa ±1,000,000,000,000; ang root index ay 2–12. Ang mga negatibong radicand ay sinusuportahan lamang para sa mga kakaibang index.

Ang mode na ito ay humahawak ng numerator / (coefficient × √radicand). Ang denominator coefficient ay hindi maaaring maging zero; ang radicand ay dapat na isang positibong buong numero.

Resulta

Paano mo pinapasimple ang isang square root?

I-factor ang radicand sa prime powers. Hilahin ang bawat kumpletong pares sa labas ng square root; halimbawa, √72 = √(36 × 2) = 6√2. Sinusuportahan din ng tool na ito ang mga integer root na may mga index 2 hanggang 12.

Na-upload ba ang aking mga numero?

Hindi. Ang pagkalkula ay tumatakbo sa browser na ito at ang tool na ito ay hindi nag-a-upload o nagse-save ng iyong mga input.

Ano ang pinapasimple ng √72?

√72 ay 6√2, dahil 72 = 36 × 2 at √36 = 6.

Maaari ba itong i-rationalize ang isang denominator?

Oo. Isinulat muli nito ang a / (c√b) na may mga integer na input bilang katumbas na fraction na ang denominator ay walang square root, pagkatapos ay binabawasan ang rational coefficient.

Nagbibigay ba ito ng decimal approximation?

Hindi. Pinapanatili nito ang eksaktong radikal na anyo. Gumamit ng siyentipikong calculator kung kailangan mo rin ng decimal approximation.
