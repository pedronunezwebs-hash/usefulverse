Linear Programming Calculator

Magpasok ng isang linear na layunin at hanggang sa walong mga hadlang upang malutas ang isang two-variable linear program na may x at y na hindi negatibo. Ang two-phase simplex na paraan ay nag-uulat ng pinakamabuting kalagayan, hindi magagawa o walang hangganan at ipinapakita ang bawat pivot.

Mga coefficient ng layunin (x, y)

Isa bawat linya: a,b <= rhs, a,b >= rhs o a,b = rhs

Gumagamit ng hindi hihigit sa walong mga hadlang at coefficients/kanang bahagi sa loob ng ±1,000,000. Ang parehong mga variable ng desisyon ay may x ≥ 0 at y ≥ 0. Gumamit ng kuwit sa pagitan ng x at y coefficients; magpasok ng isang hindi pagkakapantay-pantay o pagkakapantay-pantay bawat linya.

Isang two-phase primal simplex solver para sa dalawang variable. Ginagamit ang numerical tolerance para sa mga floating-point pivot; Ang mga problemang malapit nang bumagsak ay maaaring maging sensitibo sa pag-ikot. Ang mga kaso na hindi magagawa, walang hangganan at limitasyon sa pag-ulit ay iniulat sa halip na isang imbentong pinakamabuting kalagayan.

Linear na mga resulta ng programa

Ang resulta ay para lamang sa mathematical model na iyong ipinasok. Hindi nito pinapatunayan kung ang layunin, mga hadlang, mga yunit o mga pagpapalagay ay angkop para sa isang tunay na desisyon.

    Paano gumagana ang two-variable simplex calculator?

    Ginagawa nitong posible na tableau ang mga hadlang, gumagamit ng layunin ng Phase I kapag kinakailangan, pagkatapos ay inilalapat ang mga primal simplex na pivot upang ma-optimize ang hiniling na layunin. Ang mga variable na x at y ay pinipigilan na maging nonnegative.

    Paano gumagana ang two-variable simplex calculator?

    Ginagawa nitong posible na tableau ang mga hadlang, gumagamit ng layunin ng Phase I kapag kinakailangan, pagkatapos ay inilalapat ang mga primal simplex na pivot upang ma-optimize ang hiniling na layunin. Ang mga variable na x at y ay pinipigilan na maging nonnegative.

    Na-upload ba ang aking layunin at mga hadlang?

    Hindi. Ang solver ay tumatakbo sa browser na ito. Ang iyong layunin at mga hadlang ay hindi ipinadala sa isang server o nai-save ng tool na ito.

    Anong format ang dapat kong gamitin para sa mga hadlang?

    Maglagay ng isang row sa bawat linya, tulad ng 1,1 <= 5 o 2,1 >= 4. Ang unang numero ay nagpaparami ng x, ang pangalawa ay nagpaparami ng y, at ang parehong mga variable ay dapat na hindi negatibo.

    Ano ang ibig sabihin ng infeasible at unbounded?

    Infeasible ay walang puntong nakakatugon sa bawat ipinasok na hadlang. Ang ibig sabihin ng walang hangganan ay isang magagawang direksyon na hinahayaan ang hiniling na layunin na patuloy na umunlad nang walang tiyak na pinakamabuting kalagayan.

    Ang resulta ba ay nagpapatunay na tama ang aking real-world na modelo?

    Hindi. Nilulutas lamang nito ang mga equation na iyong ipinasok. Suriin ang mga yunit, pagpapalagay at kung ang mga hadlang ay wastong naglalarawan sa iyong desisyon.
