ICS Calendar Viewer

Tingnan ang isang iCalendar .ics file nang hindi kumukonekta ng online na kalendaryo. I-filter ang mga kaganapan ayon sa petsa at teksto, palawakin ang mga sinusuportahang umuulit na kaganapan at i-export ang nakikitang listahan bilang CSV.

Read-only na ICS viewer. Ito ay hindi isang editor ng kalendaryo o serbisyo sa pag-sync. Iniuulat ang mga hindi sinusuportahang opsyon sa pag-ulit sa halip na hulaan.

Kung pareho ang ibinigay, ang napiling file ay ginagamit. Ang halimbawa ay nagpapakita ng umuulit na kaganapan na may hindi kasamang petsa.

Walang koneksyon sa account sa kalendaryo o paghahanap ng network. Ginagamit ng mga lumulutang na oras ang lokal na oras ng iyong device; Ginagamit ng mga oras ng TZID ang kanilang nakasaad na time zone.

Local na mga limitasyon: 5 MiB, 2,000 event, 10,000 na ipinapakitang pangyayari at isang hanay ng petsa na hanggang 366 araw. Ang mga kumplikadong file ay maaaring gumamit ng memorya ng device; isang computer ang inirerekomenda.

Paano ako magbubukas ng ICS calendar file?

Pumili ng lokal na .ics file o i-paste ang text nito, pumili ng hanay ng petsa at tingnan ang mga tumutugmang kaganapan. Pinapalawak ng manonood ang mga sinusuportahang pang-araw-araw, lingguhan, buwanan at taunang mga panuntunan at inilalapat ang mga EXDATE na pagbubukod.

Mga madalas itanong

Paano ako magbubukas ng ICS calendar file?

Pumili ng lokal na .ics file o i-paste ang text nito, pumili ng hanay ng petsa at tingnan ang mga tumutugmang kaganapan. Pinapalawak ng manonood ang mga sinusuportahang pang-araw-araw, lingguhan, buwanan at taunang mga panuntunan at inilalapat ang mga EXDATE na pagbubukod.

Na-upload ba ang aking kalendaryo?

No. Ang kalendaryo ay binabasa sa browser na ito lamang. Hindi kumokonekta ang UsefulVerse sa iyong account sa kalendaryo, i-upload ang file o i-save ang iyong mga kaganapan.

Nagpapakita ba ang ICS viewer ng mga umuulit na kaganapan?

Ito ay lumalawak araw-araw, lingguhan, buwanan at taunang mga panuntunan sa napiling hanay ng petsa at inilalapat ang mga pagbubukod ng EXDATE. Ang mga hindi sinusuportahang opsyon sa pag-ulit ay tinatanggihan sa halip na hulaan.

Maaari ba itong kumonekta sa Google Calendar o Outlook?

No. Nagbabasa ito ng file na iyong pinili o text na iyong i-paste. Hindi ito nagsa-sign in, kumukuha ng online na kalendaryo o nagsi-sync ng mga pagbabago.

Aling time zone ang ginagamit nito?

A TZID sa isang kaganapan ay binibigyang-kahulugan sa zone na iyon. Ang mga timestamp ng UTC ay nananatiling UTC; ginagamit ng mga oras ng lumulutang na kaganapan ang time zone ng iyong device. Naka-format ang listahan sa lokal na zone ng iyong browser.
