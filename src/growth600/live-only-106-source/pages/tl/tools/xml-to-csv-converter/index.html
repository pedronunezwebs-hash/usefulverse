XML to CSV Converter

Gawing CSV table ang isang simpleng XML record list, o bumuo ng mga XML record mula sa text ng CSV file. Piliin ang direksyon, i-paste ang iyong data, pagkatapos ay kopyahin o i-download ang resulta. Walang na-upload.

Sinusuportahan ang isang simpleng listahan ng mga elemento ng record na may parehong pangalan, o isang flat record. Ang mga bata ng elemento ay dapat na mga scalar value; hindi naka-flatten ang mga nested at repeated field.

Gamitin ang unang row para sa mga pangalan ng column. Ang isang header gaya ng @id ay nagiging isang XML attribute. Gamitin ang #text para sa record text.

Ito ay isang simpleng conversion ng talahanayan, hindi isang lossless na XML format na conversion. Hindi pinapanatili ang mga namespace, nested structure, mixed content, komento at XML formatting. Hindi type-aware ang text. Ang mga value ng CSV na tulad ng formula ng spreadsheet ay may prefix na apostrophe para sa kaligtasan.

Paano ko iko-convert ang XML sa CSV?

Pumili ng XML sa CSV at i-paste ang XML gamit ang isang simpleng listahan ng record. Ang mga paulit-ulit na elemento ng direktang tala ay nagiging mga hilera. Ang mga pangalan ng elemento ay nagiging mga hanay; ang mga katangian ay gumagamit ng @name. Piliin ang CSV hanggang XML upang lumikha ng mga simpleng XML na tala mula sa mga header at row.

Na-upload ba ang aking XML o CSV?

Hindi. Ang pag-parse at conversion ay tumatakbo sa browser na ito. Limitado ang input sa 200,000 character, 5,000 row, 64 column at 20,000 cell. Naka-block ang mga deklarasyon ng DTD at entity, at hindi kinukuha ang mga panlabas na mapagkukunan.

Paano ipinapakita ang mga katangian ng XML sa CSV?

Ang isang attribute gaya ng id="101" ay nagiging column na pinangalanang @id. Kapag nagko-convert pabalik, ang isang CSV header na nagsisimula sa @ ay nagiging isang XML attribute.

Maaari ba nitong i-convert ang nested XML sa isang flat table?

Hindi. Ang mga nested na istruktura ng bata, mga paulit-ulit na field sa loob ng isang talaan at pinaghalong teksto ay tinatanggihan sa halip na ma-flatten o tahimik na mawala. Gumamit ng nakalaang XML-to-JSON na workflow para sa nested data.

Papanatilihin ba ng CSV ang mga uri at pag-format ng XML?

Hindi. Nag-iimbak ang CSV ng cell text, hindi mga uri ng XML, namespace o pag-format. Ang mga value ng cell na tulad ng formula ay nakakakuha ng apostrophe prefix kapag na-export upang mabawasan ang panganib sa pagpapatupad ng formula ng spreadsheet.
