Paano ang kabuuang pag-uulit ng push-up test tracker?

Idinaragdag nito ang buong bilang na mga pag-uulit na ipinasok para sa bawat hindi-bakanteng hanay. Binabalewala ang mga blangkong linya, ang isang set ng zero ay nananatiling zero, at ang natitirang pagtatantya ay pahinga bawat pahinga na na-multiply sa bilang ng mga pahinga.

Na-upload ba ang aking mga push-up set?

Hindi. Ang pagkalkula ay tumatakbo sa browser na ito. Ang history ng session ay isinulat lamang sa device na ito pagkatapos mong mag-opt in; maaari mong tanggalin ito dito.

Ang mga blangkong linya ba ay binibilang bilang isang set o pag-uulit?

Hindi. Binabalewala ang mga walang laman na linya. Ang isang linyang may 0 ay nagtatala ng zero-repetition set at hindi nagdaragdag ng repetitions sa kabuuan.

Maaari ko bang gamitin ito para sa isang maximum na set o para sa ilang set?

Oo. Magpasok ng isang linya para sa isang solong manu-manong binilang na hanay, o maraming linya upang i-summarize ang mga hanay at ang natitira sa pagitan ng mga ito. Ang mga kondisyon ng pagsubok ay nasa iyo; ang mga resulta ay hindi inihambing sa mga pamantayan ng populasyon.

Na-upload ba ang kasaysayan ng aking pagsasanay?

Hindi. Ang kasaysayan ay opsyonal at nananatili sa browser na ito sa device na ito. I-clear ito gamit ang delete button kahit kailan mo gusto.
