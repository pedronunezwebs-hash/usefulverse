Sitemap Validator

Mag-paste ng sitemap XML na dokumento upang suriin ang istraktura, mga entry ng URL, petsa at karaniwang mga field nito. Ang XML ay na-parse sa browser na ito lamang; hindi kinukuha ang mga nakalistang pahina.

Sinusuportahan ang isang karaniwang urlset o sitemapindex. Pinakamataas na 1,000,000 character at 5,000 direktang entry.

Lokal na XML check lamang: hindi ito humihiling ng mga nakalistang URL, i-crawl ang site, isumite ang sitemap, o ginagarantiyahan ang pag-index.

Mga Natuklasan

    Ano ang sinusuri ng validator ng sitemap na ito?

    Sinusuri nito ang urlset o sitemapindex na mga entry, ganap na HTTP o HTTPS na lokasyon, mga duplicate na normalized na URL, lastmod date, opsyonal na changefreq at priority value, at ang namespace ng sitemap. Ang mga babala at error ay nakalista ayon sa entry number.

    Mga madalas itanong

    Ano ang sinusuri ng validator ng sitemap na ito?

    Sinusuri nito ang urlset o sitemapindex na mga entry, ganap na HTTP o HTTPS na lokasyon, mga duplicate na normalized na URL, lastmod date, opsyonal na changefreq at priority value, at ang namespace ng sitemap. Ang mga babala at error ay nakalista ayon sa entry number.

    Nag-a-upload ba ito o nagsusumite ng aking sitemap?

    Hindi. Ang XML ay lokal na pinoproseso sa iyong browser. Ang tool ay hindi nagko-crawl ng mga URL, kumukuha ng malayuang sitemap file, nagsusumite ng kahit ano sa isang search engine, o nagkukumpirma ng pag-index.

    Sinusuri ba nito kung live ang URL ng sitemap?

    Hindi. Sinusuri nito ang syntax ng URL at mga duplicate sa loob ng nai-paste na XML, ngunit sadyang hindi humihiling ng mga URL o i-crawl ang site.

    Nangangahulugan ba ang isang wastong sitemap na na-index ng Google ang mga pahina nito?

    Hindi. Ang XML validation ay hindi isang search-engine submission o indexing report. Magsumite ng sitemap sa pamamagitan ng nauugnay na search-engine webmaster tool at tingnan ang sarili nitong katayuan.

    Maaari ko bang patunayan ang isang index ng sitemap?

    Oo. Sinusuri ng tool ang mga direktang entry ng sitemapindex at ang kanilang loc at lastmod na mga field, ngunit hindi nagda-download o nag-recursive na sinisiyasat ang mga reference na file ng sitemap.
