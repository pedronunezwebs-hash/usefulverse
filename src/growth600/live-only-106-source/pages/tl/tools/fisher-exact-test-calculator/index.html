Ano ang null hypothesis?

Sinusuri ng pagsubok kung ang mga klasipikasyon ng row at column ay independiyente, may kondisyon sa mga naobserbahang margin. Hindi nito ipinapaliwanag kung bakit maaaring umiral ang isang asosasyon.

Paano kinakalkula ang isang two-sided p-value?

Ang calculator na ito ay nagdaragdag ng mga probabilidad ng lahat ng posibleng mga talahanayan na may parehong mga margin na ang conditional na posibilidad ay hindi mas malaki kaysa sa naobserbahang talahanayan. Maaaring mag-iba ang iba pang mga software convention.

May epekto ba ang isang maliit na p-value?

Hindi. Ang p-value ay hindi sukat ng epekto o patunay ng sanhi. Suriin ang odds ratio, disenyo ng pag-aaral, kalidad ng data, kawalan ng katiyakan at anumang planong maramihang pagsubok.
