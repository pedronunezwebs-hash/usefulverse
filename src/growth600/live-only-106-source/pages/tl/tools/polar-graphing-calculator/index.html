Polar Graphing Calculator

I-graph ang isang polar equation sa pamamagitan ng paglalagay ng radius r bilang function ng angle θ. Pumili ng mga degree o radian, ayusin ang pagitan ng anggulo at bilang ng sample, pagkatapos ay siyasatin ang curve at i-download ang mga coordinate nito.

Gamitin ang θ o t bilang variable ng anggulo. Sinusunod ng mga function ng trigonometriko ang napiling unit ng anggulo. Mga sinusuportahang function: sin, cos, tan, sqrt, abs, exp, ln at log. Maaaring makaligtaan ang mga de-numerong sample; hindi ito simbolikong patunay. Tumatakbo nang lokal; walang upload.

Polar na graph

Paano mo i-graph ang isang polar equation?

Maglagay ng radius expression gaya ng 1 o 2*cos(θ), pumili ng angle interval at unit, pagkatapos ay kalkulahin. Kino-convert ng graph ang bawat sample na polar point sa x=r cos(θ) at y=r sin(θ). Para sa r=1 mula 0° hanggang 360°, ang resulta ay ang bilog ng yunit.

Mga madalas itanong

Paano mo i-graph ang isang polar equation?

Maglagay ng radius expression gaya ng 1 o 2*cos(θ), pumili ng angle interval at unit, pagkatapos ay kalkulahin. Kino-convert ng graph ang bawat sample na polar point sa x=r cos(θ) at y=r sin(θ). Para sa r=1 mula 0° hanggang 360°, ang resulta ay ang bilog ng yunit.

Ina-upload ba ang equation ko?

Hindi. Ang equation ay na-parse at naka-plot nang lokal sa browser na ito. Hindi ito ina-upload o nai-save ng tool na ito.

Ano ang hitsura ng r=1 sa mga polar coordinates?

Ang bawat anggulo ay isang yunit mula sa pinanggalingan, kaya ang r=1 ay bumubuo ng isang bilog na radius 1 na nakasentro sa pinanggalingan.

Maaari ba akong mag-export ng mga polar graph point?

Oo. Pagkatapos mag-plot, mag-download ng CSV na naglalaman ng bawat finite sample na anggulo, radius at ang Cartesian x at y coordinate nito.
