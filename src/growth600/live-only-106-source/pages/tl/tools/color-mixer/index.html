Panghalo ng Kulay

Paghaluin ang mga kulay na may mga nae-edit na timbang, paghambingin ang dalawang digital mixing mode, at bumuo ng swatch ramp sa pagitan ng unang dalawang kulay. Walang na-upload.

Mga kulay na ihahalo

Ang napiling paraan ay nakakaapekto sa resulta. Pinagsasama ng sRGB ang mga ipinapakitang halaga ng channel; ang linear light ay nagko-convert ng mga channel bago ihalo.

Hinuhulaan nito ang mga kulay ng digital na screen, hindi kung paano maghahalo ang totoong pintura o pigment.

Gumagana sa browser na ito. Ang mga kulay ay hindi na-upload o awtomatikong nai-save.

Paano ako maghahalo ng dalawang kulay online?

Pumili ng dalawa o higit pang mga kulay, itakda ang bawat timbang, at piliin ang sRGB o linear-light mixing. Ang resulta ay nagpapakita ng mga halaga ng HEX, RGB, at HSL.

Na-upload ba ang aking mga kulay?

Hindi. Lokal na tumatakbo ang mga kalkulasyon ng kulay sa iyong browser. Walang kinakailangang pag-upload ng account o larawan.

Bakit iba ang hitsura ng sRGB at linear-light mix?

Katamtaman ng sRGB ang mga value ng channel ng naka-encode na screen. Kino-convert muna sila ng linear-light mode sa mga light value, hinahalo, pagkatapos ay i-convert pabalik. Binabago ng piniling paraan ang resulta.

Mahuhulaan ba nito ang kulay ng pinaghalong pintura?

Hindi. Ito ay digital color math para sa mga screen, hindi isang pisikal na modelo ng pigment. Ang tunay na pintura ay nakasalalay sa mga katangian ng pigment, transparency, konsentrasyon, pag-iilaw, at sa ibabaw.

Anong mga format ng kulay ang maaari kong kopyahin?

Ipinapakita ng resulta ang HEX, RGB, at HSL. Maaari mong kopyahin ang halaga ng HEX o mag-download ng maliit na palette ng kulay ng CSS.
