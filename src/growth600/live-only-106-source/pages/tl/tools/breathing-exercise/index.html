Ehersisyo sa Paghinga

Pumili ng banayad na bilis ng paghinga at sundin ang visual na gabay. Panatilihing komportable ang sesyon; huminto kahit kailan mo gusto.

Iniiwasan ng gabay ang biglaang galaw kapag naka-on ang pinababang galaw.

Pangkalahatang timer ito para sa kalusugan, hindi pangangalagang medikal. Huminga nang komportable at huminto kung masama ang pakiramdam.

Kasalukuyang yugto: Huminga papasok

Natitirang oras: 01:00

Paano ko gagamitin ang ehersisyo sa paghinga na ito?

Pumili ng preset o itakda ang bawat yugto, piliin ang haba ng sesyon at pindutin ang Start. I-pause o i-reset anumang oras. Opsyonal ang audio at magsisimula lamang pagkatapos mong magsimula.

Na-upload ba ang aking sesyon ng paghinga?

Hindi. Tumatakbo ang timing sa pahinang ito. Walang account, upload, API o naka-save na sesyon ang ginagamit.

Maaari ko bang gamitin ang box breathing o 4-7-8?

Oo. Pumili ng preset o ayusin ang haba ng mga yugto. Mga pattern ito ng paghinga, hindi medikal na paggamot.

Tatakbo pa ba ito kapag isinara ko ang tab?

Walang garantiya. Maaaring i-pause ng mga browser ang background tab at maaaring matulog ang device. Panatilihing bukas ang page at gising ang device para sa mas maaasahang timing.

Maaari ko bang patayin ang tunog o huminto nang maaga?

Oo. Opsyonal ang tunog at maaari itong patayin. Agad na ititigil ng I-pause o I-reset ang aktibong timer.
