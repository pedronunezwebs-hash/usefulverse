Calculatrice de programmation linéaire

Entrez un objectif linéaire et jusqu'à huit contraintes pour résoudre un programme linéaire à deux variables avec x et y non négatifs. La méthode simplexe en deux phases rapporte un optimal, une infaisabilité ou un caractère illimité et montre chaque pivot.

Coefficients objectifs (x, y)

Un par ligne : a,b <= droite, a,b >= droite ou a,b = droite

Utilise au maximum huit contraintes et coefficients/parties droites dans une plage de ±1 000 000. Les deux variables de décision ont x ≥ 0 et y ≥ 0. Utilisez une virgule entre les coefficients x et y ; saisissez une inégalité ou une égalité par ligne.

Un solveur simplex primal biphasé pour deux variables. La tolérance numérique est utilisée pour les pivots à virgule flottante ; les problèmes quasi dégénérés peuvent être sensibles aux arrondis. Les cas infaisables, illimités et limites d'itération sont rapportés au lieu d'un optimal inventé.

Résultats du programme linéaire

Le résultat concerne uniquement le modèle mathématique que vous avez entré. Il ne valide pas si l'objectif, les contraintes, les unités ou les hypothèses sont appropriés pour une décision réelle.

    Comment fonctionne la calculatrice simplexe à deux variables ?

    Il convertit les contraintes en un tableau réalisable, utilise un objectif de phase I si nécessaire, puis applique des pivots simplex primordiaux pour optimiser l'objectif demandé. Les variables x et y sont contraintes d'être non négatives.

    Foire aux questions

    Comment fonctionne la calculatrice simplexe à deux variables ?

    Il convertit les contraintes en un tableau réalisable, utilise un objectif de phase I si nécessaire, puis applique des pivots simplex primordiaux pour optimiser l'objectif demandé. Les variables x et y sont contraintes d'être non négatives.

    Mon objectif et mes contraintes sont-ils téléchargés ?

    Non. Le solveur s'exécute dans ce navigateur. Votre objectif et vos contraintes ne sont pas envoyés sur un serveur ni enregistrés par cet outil.

    Quel format dois-je utiliser pour les contraintes ?

    Entrez une ligne par ligne, par exemple 1,1 <= 5 ou 2,1 >= 4. Le premier nombre multiplie x, le second multiplie y et les deux variables doivent être non négatives.

    Que signifient infaisable et illimité ?

    Infaisable signifie qu'aucun point ne satisfait toutes les contraintes entrées. Sans limite signifie qu'une direction réalisable permet à l'objectif demandé de continuer à s'améliorer sans un optimal fini.

    Le résultat prouve-t-il que mon modèle réel est correct ?

    Non. Il résout uniquement les équations que vous avez saisies. Vérifiez les unités, les hypothèses et si les contraintes décrivent correctement votre décision.
