Calculatrice modulo

Calculez le quotient et le reste euclidiens pour des nombres entiers. Les entrées négatives sont traitées de manière cohérente et l'identité de la division montre comment la réponse est formée.

Le nombre à diviser ; cela peut être négatif.

Utilisez n'importe quel nombre entier différent de zéro ; sa valeur absolue définit le module.

Vérifiez si cette valeur est conforme au dividende modulo le diviseur.

Accepte les nombres entiers signés jusqu'à 50 chiffres. Pas de fractions ni de décimales. Le résultat utilise le modulo euclidien ; certains langages de programmation utilisent une règle de reste différente pour les négatifs.

Résultat

Comment calculer un modulo avec un nombre négatif ?

Cette calculatrice utilise un reste non négatif inférieur au diviseur absolu. Par exemple, −7 mod 3 vaut 2 car −7 = (−3 × 3) + 2.

Foire aux questions

Comment calculer un modulo avec un nombre négatif ?

Cette calculatrice utilise un reste non négatif inférieur au diviseur absolu. Par exemple, −7 mod 3 vaut 2 car −7 = (−3 × 3) + 2.

Mes numéros sont-ils téléchargés ?

Non. Le calcul exact s'exécute dans ce navigateur. Les numéros ne sont ni téléchargés ni enregistrés.

Qu'est-ce que −7 mod 3 ?

D'après la convention euclidienne, −7 mod 3 vaut 2 : −7 = (−3 × 3) + 2 et 0 ≤ 2 < 3.

Que signifie modulo m congruent ?

Deux entiers sont congrus modulo m lorsque leur différence est divisible par |m|. The optional comparison checks this exactly.

Pourquoi cela peut-il différer de l’opérateur % d’un langage de programmation ?

Certaines langues gardent le signe d'un dividende négatif dans le reste. Cette calculatrice renvoie à la place un reste de 0 jusqu'au diviseur absolu, sans l'inclure.
