Compteur de jours de sobriété

Choisissez une date de début pour compter les jours calendaires écoulés et voir les jalons à venir. Ce compteur privé n'est pas un traitement, un conseil de guérison ou une mesure de santé.

Saisissez la date à partir de laquelle vous souhaitez compter. Une date aujourd’hui est le jour zéro ; les dates futures ne sont pas autorisées. La valeur par défaut est aujourd'hui et peut être modifiée pour consulter une date antérieure, mais pas une date antérieure au début.

Jusqu'à 280 caractères. Gardez les détails sensibles hors des appareils partagés.

Il s'agit uniquement d'arithmétique de date. Il n’évalue pas la consommation de substances, la santé, les risques, les progrès ou les besoins en matière de traitement. Le rétablissement est personnel ; envisagez une assistance qualifiée si vous souhaitez de l'aide.

L'enregistrement est facultatif et utilise uniquement le stockage local de ce navigateur ; rien n'est téléchargé. Effacez les données enregistrées ci-dessous.

Votre nombre de jours

Comment fonctionne le compteur de jours de sobriété ?

Il compte les jours calendaires entiers à partir de la date que vous avez saisie jusqu'à aujourd'hui. La date de début sélectionnée elle-même est le jour zéro ; les dates ultérieures utilisent l'arithmétique de date uniquement, de sorte que l'heure d'été n'ajoute ni ne supprime de jour.

Foire aux questions

Comment fonctionne le compteur de jours de sobriété ?

Il compte les jours calendaires entiers à partir de la date que vous avez saisie jusqu'à aujourd'hui. La date de début sélectionnée elle-même est le jour zéro ; les dates ultérieures utilisent l'arithmétique de date uniquement, de sorte que l'heure d'été n'ajoute ni ne supprime de jour.

Ma date de sobriété est-elle téléchargée ou enregistrée ?

Aucune donnée n'est téléchargée. Vos dates sont utilisées uniquement dans ce navigateur. Une note ou une date ne peut être enregistrée sur cet appareil que si vous vous y inscrivez explicitement, et vous pouvez effacer l'enregistrement local à tout moment.

La date de début compte-t-elle comme premier jour ?

Non. La date de début choisie est le jour zéro. La prochaine date calendaire est un jour écoulé plus tard.

Ce compteur peut-il donner un rétablissement ou des conseils médicaux ?

Non. Il compte les jours calendaires et affiche uniquement les jalons. Il n’évalue pas la santé, la consommation de substances, le traitement ou les progrès personnels.

Les dates et les notes sont-elles envoyées à un serveur ?

Non. Les calculs s'exécutent dans votre navigateur. L'enregistrement est facultatif et stocke un petit enregistrement dans ce navigateur sur cet appareil ; vous pouvez l'effacer ici.
