Accueil/générateur de signature électronique

Utilisation gratuite, sans compte

générateur de signature électronique

Créez une signature électronique claire et compacte avec vos coordonnées, une touche de couleur et un logo facultatif. Prévisualisez-le, puis copiez le bloc formaté ou son code HTML.

PNG, JPEG ou GIF ; jusqu'à 512 Ko et 1 600 × 1 600 px. L'image est intégrée à la signature, mais certaines applications de messagerie suppriment les images intégrées.

Les applications de messagerie affichent les signatures différemment. Une disposition en tableau et des styles en ligne améliorent la compatibilité, mais vérifiez le résultat dans votre application de messagerie avant de l'envoyer.

Vos coordonnées et votre image restent dans cet onglet du navigateur. Rien n'est téléchargé ou automatiquement enregistré.

Aperçu de la signature

Comment créer une signature email ?

Ajoutez votre nom et vos coordonnées facultatives, choisissez une couleur d'accent, puis générez la signature. Copiez le bloc formaté dans vos paramètres de messagerie ou copiez son code HTML si votre application de messagerie le prend en charge.

Foire aux questions

Comment créer une signature email ?

Ajoutez votre nom et vos coordonnées facultatives, choisissez une couleur d'accent, puis générez la signature. Copiez le bloc formaté dans vos paramètres de messagerie ou copiez son code HTML si votre application de messagerie le prend en charge.

Mes coordonnées sont-elles téléchargées ?

Non. Vos coordonnées et votre logo facultatif sont gérés dans cet onglet du navigateur et ne sont pas téléchargés ni automatiquement enregistrés.

Cette signature sera-t-elle identique dans toutes les applications de messagerie ?

Non. Les applications de messagerie prennent en charge différentes fonctionnalités HTML et d'image. Ce générateur utilise un tableau compact et des styles en ligne, mais vous devez tester la signature collée dans votre propre application de messagerie.

Puis-je utiliser un logo dans ma signature ?

Oui. Choisissez un format PNG, JPEG ou GIF jusqu'à 512 Ko. Il est intégré sous forme de données d'image ; Certaines applications de messagerie bloquent ou suppriment les images intégrées, de sorte qu'une signature contenant uniquement du texte peut être plus fiable.

Le générateur envoie-t-il ou enregistre-t-il mes coordonnées ?

Non. Il crée la signature dans cet onglet du navigateur. Vous choisissez quand le copier ou le télécharger ; cette page ne télécharge ni n'enregistre automatiquement vos coordonnées.
