Calculateur de valeur nette

Additionnez les soldes que vous connaissez déjà pour estimer votre valeur nette : actif moins passif. Comparez les instantanés dans une seule devise. Il s'agit d'un organisateur, pas d'une évaluation ou d'une recommandation financière.

Actifs
Passif

Les détails financiers sont sensibles. Rien n'est téléchargé. L'enregistrement est facultatif, local sur ce navigateur et visible par toute personne y ayant accès.

    Comment calculer la valeur nette ?

    Ajoutez vos soldes d'actifs et vos passifs en utilisant la même devise, puis soustrayez le total du passif du total de l'actif. Les valeurs sont aussi précises que les montants et les évaluations que vous saisissez.

    Foire aux questions

    Comment calculer la valeur nette ?

    Ajoutez vos soldes d'actifs et vos passifs en utilisant la même devise, puis soustrayez le total du passif du total de l'actif. Les valeurs sont aussi précises que les montants et les évaluations que vous saisissez.

    Mes soldes financiers sont-ils enregistrés ou téléchargés ?

    Les calculs ont lieu dans cette page. Le stockage du navigateur est désactivé, sauf si vous cochez la case de consentement et enregistrez séparément un instantané. Les données enregistrées restent dans ce navigateur et peuvent être supprimées ici ou dans les paramètres du navigateur.

    Qu'est-ce qui compte comme valeur nette ?

    La valeur nette est la valeur totale que vous attribuez aux actifs moins les passifs que vous saisissez. Le résultat n’est pas une évaluation ou une cote de crédit.

    Puis-je comparer différentes devises ?

    Aucun taux de change automatique n'est utilisé. Comparez les instantanés uniquement lorsqu'ils utilisent le même code de devise.

    Où sont stockés les instantanés enregistrés ?

    uniquement dans le stockage local de ce navigateur après vous être inscrit et avoir appuyé sur Enregistrer. La suppression des données du navigateur les supprime ; téléchargez un CSV si vous avez besoin d’une copie séparée.
