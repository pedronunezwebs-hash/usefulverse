Convertisseur XML en CSV

Transformez une simple liste d'enregistrements XML en table CSV ou créez des enregistrements XML à partir du texte d'un fichier CSV. Choisissez la direction, collez vos données, puis copiez ou téléchargez le résultat. Rien n'est téléchargé.

Prend en charge une simple liste d'éléments d'enregistrement de même nom ou un enregistrement plat. Les enfants des éléments doivent être des valeurs scalaires ; Les champs imbriqués et répétés ne sont pas aplatis.

Utilisez la première ligne pour les noms de colonnes. Un en-tête tel que @id devient un attribut XML. Utilisez #text pour le texte d'enregistrement.

Il s'agit d'une simple conversion de table, pas d'une conversion au format XML sans perte. Les espaces de noms, les structures imbriquées, le contenu mixte, les commentaires et le formatage XML ne sont pas conservés. Le texte n'est pas sensible à la typographie. Les valeurs CSV de type formule de feuille de calcul sont préfixées par une apostrophe pour des raisons de sécurité.

Résultat

Vérifiez la sortie avant de l'importer dans une autre application.

Comment convertir du XML en CSV ?

Choisissez XML vers CSV et collez XML avec une simple liste d'enregistrements. Les éléments d'enregistrement direct répétés deviennent des lignes. Les noms d'éléments deviennent des colonnes ; les attributs utilisent @name. Choisissez CSV vers XML pour créer des enregistrements XML simples à partir d'en-têtes et de lignes.

Foire aux questions

Comment convertir du XML en CSV ?

Choisissez XML vers CSV et collez XML avec une simple liste d'enregistrements. Les éléments d'enregistrement direct répétés deviennent des lignes. Les noms d'éléments deviennent des colonnes ; les attributs utilisent @name. Choisissez CSV vers XML pour créer des enregistrements XML simples à partir d'en-têtes et de lignes.

Mon XML ou CSV est-il téléchargé ?

Non. L'analyse et la conversion sont exécutées dans ce navigateur. La saisie est limitée à 200 000 caractères, 5 000 lignes, 64 colonnes et 20 000 cellules. Les déclarations de DTD et d'entité sont bloquées et les ressources externes ne sont pas récupérées.

Comment les attributs XML sont-ils affichés dans CSV ?

Un attribut tel que id="101" devient une colonne nommée @id. Lors de la reconversion, un en-tête CSV commençant par @ devient un attribut XML.

Peut-il convertir du XML imbriqué en un tableau plat ?

Non. Les structures enfants imbriquées, les champs répétés à l'intérieur d'un enregistrement et le texte mixte sont rejetés au lieu d'être aplatis ou perdus silencieusement. Utilisez un workflow XML vers JSON dédié pour les données imbriquées.

Le CSV conservera-t-il les types et le formatage XML ?

Non. CSV stocke le texte des cellules, pas les types XML, les espaces de noms ou le formatage. Les valeurs de cellules de type formule reçoivent un préfixe d'apostrophe lors de l'exportation afin de réduire le risque d'exécution des formules de la feuille de calcul.
