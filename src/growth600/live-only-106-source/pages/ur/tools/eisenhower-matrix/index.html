آئزن ہاور میٹرکس

ایک کام کی فہرست کو چار واضح انتخاب میں تبدیل کریں: کرو، شیڈول، ڈیلیگیٹ یا چھوڑیں۔ آپ فیصلہ کرتے ہیں کہ کیا ضروری اور فوری ہے۔ تاریخیں یاددہانی ہیں، خودکار فیصلے نہیں۔

اپنے سیاق و سباق کا استعمال کرتے ہوئے کاموں کی درجہ بندی کریں۔ میٹرکس آپ کے لیے اہمیت کا فیصلہ نہیں کرتا۔ ڈیٹا اس ٹیب میں میموری میں رہتا ہے اور جب آپ اسے بند کرتے یا دوبارہ لوڈ کرتے ہیں تو صاف ہوجاتا ہے جب تک کہ آپ بیک اپ برآمد نہیں کرتے ہیں۔ درآمد صرف اس ٹول کے JSON بیک اپ کو قبول کرتا ہے، 1 MB تک اور 300 کام۔

اہم کا مطلب ہے کہ یہ کسی مقصد، ذمہ داری یا نتیجہ کو معنی خیز طور پر متاثر کرتا ہے جس کا آپ کو خیال ہے۔

فوری کا مطلب ہے کہ اسے ایک حقیقی آخری تاریخ یا نتیجہ کی وجہ سے جلد توجہ کی ضرورت ہے۔ صرف ایک مقررہ تاریخ اہمیت کا فیصلہ نہیں کرتی۔
