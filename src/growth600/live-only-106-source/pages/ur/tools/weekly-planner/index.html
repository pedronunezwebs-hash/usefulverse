ہفتہ وار منصوبہ دہرانے والا مقامی دیوار گھڑی کے اوقات استعمال کرتا ہے۔ اس میں ٹائم زونز، ڈے لائٹ سیونگ تبدیلیاں، کیلنڈر ایونٹس، یا یاد دہانیوں کا حساب نہیں ہے۔

منصوبہ اس ٹیب میں میموری میں رہتا ہے۔ اسے رکھنے کے لیے JSON بیک اپ ڈاؤن لوڈ کریں۔ کوئی خودکار اسٹوریج یا اپ لوڈ نہیں۔
