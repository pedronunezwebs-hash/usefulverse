استعمال کے لیے مفت، اکاؤنٹ کی ضرورت نہیں

سائٹ کا نقشہ درست کرنے والا

سائٹ کا نقشہ XML دستاویز کو اس کی ساخت، URL اندراجات، تاریخوں اور عام فیلڈز کو چیک کرنے کے لیے چسپاں کریں۔ XML کو صرف اس براؤزر میں پارس کیا جاتا ہے۔ درج شدہ صفحات کبھی حاصل نہیں کیے جاتے ہیں۔

معیاری urlset یا sitemapindex کو سپورٹ کرتا ہے۔ زیادہ سے زیادہ 1,000,000 حروف اور 5,000 براہ راست اندراجات۔

صرف مقامی XML چیک کرتا ہے: یہ درج شدہ URLs کی درخواست نہیں کرتا، سائٹ کو کرال کرتا ہے، سائٹ کا نقشہ جمع کرتا ہے، یا انڈیکسنگ کی ضمانت دیتا ہے۔

توثیق کا خلاصہ

نتائج

    یہ سائٹ کا نقشہ درست کرنے والا کیا چیک کرتا ہے؟

    یہ urlset یا sitemapindex اندراجات، مطلق HTTP یا HTTPS مقامات، ڈپلیکیٹ نارملائزڈ یو آر ایل، آخری موڈ کی تاریخیں، اختیاری تبدیلی کی فریکوئنسی اور ترجیحی اقدار، اور سائٹ کا نقشہ نام کی جگہ کو چیک کرتا ہے۔ انتباہات اور غلطیاں اندراج نمبر کے ذریعہ درج ہیں۔

    اکثر پوچھے گئے سوالات

    یہ سائٹ کا نقشہ درست کرنے والا کیا چیک کرتا ہے؟

    یہ urlset یا sitemapindex اندراجات، مطلق HTTP یا HTTPS مقامات، ڈپلیکیٹ نارملائزڈ یو آر ایل، آخری موڈ کی تاریخیں، اختیاری تبدیلی کی فریکوئنسی اور ترجیحی اقدار، اور سائٹ کا نقشہ نام کی جگہ کو چیک کرتا ہے۔ انتباہات اور غلطیاں اندراج نمبر کے ذریعہ درج ہیں۔

    کیا یہ میری سائٹ کا نقشہ اپ لوڈ یا جمع کراتا ہے؟

    نمبر۔ XML کو مقامی طور پر آپ کے براؤزر میں پروسیس کیا جاتا ہے۔ یہ ٹول یو آر ایل کو کرال نہیں کرتا، ریموٹ سائٹ میپ فائلیں نہیں لاتا، سرچ انجن میں کچھ بھی جمع نہیں کرتا، یا انڈیکسنگ کی تصدیق نہیں کرتا ہے۔

    کیا یہ چیک کرتا ہے کہ آیا سائٹ کا نقشہ URL لائیو ہے؟

    نمبر۔ یہ URL نحو کو چیک کرتا ہے اور پیسٹ کردہ XML کے اندر نقل کرتا ہے، لیکن جان بوجھ کر URLs کی درخواست نہیں کرتا ہے یا سائٹ کو کرال نہیں کرتا ہے۔

    کیا ایک درست سائٹ کے نقشے کا مطلب ہے کہ گوگل نے اپنے صفحات کو انڈیکس کیا ہے؟

    نمبر XML کی توثیق سرچ انجن جمع کرانے یا اشاریہ سازی کی رپورٹ نہیں ہے۔ متعلقہ سرچ انجن ویب ماسٹر ٹول کے ذریعے سائٹ کا نقشہ جمع کروائیں اور اس کی اپنی حیثیت چیک کریں۔

    کیا میں سائٹ میپ انڈیکس کی توثیق کر سکتا ہوں؟

    ہاں۔ یہ ٹول براہ راست sitemapindex اندراجات اور ان کے loc اور lastmod فیلڈز کو چیک کرتا ہے، لیکن حوالہ شدہ سائٹ میپ فائلوں کو ڈاؤن لوڈ یا بار بار معائنہ نہیں کرتا ہے۔
