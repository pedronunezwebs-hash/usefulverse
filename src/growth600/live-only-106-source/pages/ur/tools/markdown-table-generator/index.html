مارک ڈاؤن ٹیبل جنریٹر

ایک چھوٹے قابل تدوین گرڈ میں مارک ڈاؤن ٹیبل بنائیں۔ کوما سے الگ کردہ، سیمیکولن سے الگ، یا ٹیب سے الگ کردہ متن درآمد کریں، کالم کی سیدھ کا انتخاب کریں، اور سادہ مارک ڈاؤن کو نقل کریں جس میں پائپ محفوظ طریقے سے بچ گئے ہیں۔

کوٹڈ CSV فیلڈز سپورٹ ہیں۔ درآمد موجودہ گرڈ کی جگہ لے لیتا ہے۔ 100 قطاروں، 20 کالموں، اور 250,000 حروف تک۔

پہلی قطار مارک ڈاؤن ہیڈر بن جاتی ہے۔ کم از کم ایک قطار اور ایک کالم شامل کریں۔

قابل تدوین ٹیبل سیل

ہیڈر اور الگ کرنے والے قطار کے ساتھ ایک معیاری پائپ ٹیبل بناتا ہے۔ سیل لائن ٹوٹ جاتے ہیں <br>؛ مارک ڈاون پائپ اور بیک سلیشس بچ گئے ہیں۔

تمام پروسیسنگ اس ٹیب میں رہتی ہے۔ کوئی اپ لوڈ، اکاؤنٹ، API، خودکار محفوظ، یا سرور پروسیسنگ نہیں۔
