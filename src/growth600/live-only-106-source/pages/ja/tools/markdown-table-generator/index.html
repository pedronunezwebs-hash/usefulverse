マークダウン テーブル ジェネレーター

小さな編集可能なグリッドにマークダウン テーブルを作成します。カンマ区切り、セミコロン区切り、またはタブ区切りのテキストをインポートし、列の配置を選択して、パイプを安全にエスケープしたプレーンな Markdown をコピーします。

引用符で囲まれた CSV フィールドがサポートされています。インポートすると、現在のグリッドが置き換えられます。最大 100 行、20 列、250,000 文字。

最初の行は Markdown ヘッダーになります。少なくとも 1 行と 1 列を追加します。

編集可能な表セル

ヘッダーと区切り行を含む標準パイプ テーブルを作成します。細胞株の切れ目は <br> になります。マークダウン パイプとバックスラッシュはエスケープされます。

すべての処理はこのタブに留まります。アップロード、アカウント、API、自動保存、サーバー処理はありません。

Markdown テーブルを作成するにはどうすればよいですか?

よくある質問

Markdown テーブルを作成するにはどうすればよいですか?

ヘッダー行とデータ行を入力し、各列の配置を選択して、生成されたマークダウンをコピーします。パイプはエスケープされ、不均一なインポート行は埋め込まれます。

私のテーブルはアップロードされていますか?

いいえ。テーブルはこのブラウザ タブで処理されます。インポート、編集、生成されたマークダウンはサーバーに送信されず、自動的に保存されません。

CSVまたはTSVをインポートできますか?

はい。カンマ区切り、セミコロン区切り、またはタブ区切りの値を貼り付けて、編集可能なグリッドにインポートします。引用符で囲まれた CSV フィールドと引用符で囲まれた区切り文字がサポートされています。

パイプや改行はどのように処理されますか?

セル内のパイプはエスケープされるため、Markdown テーブルは分割されません。バックスラッシュもエスケープされ、セルの改行は <br> で表されます。
