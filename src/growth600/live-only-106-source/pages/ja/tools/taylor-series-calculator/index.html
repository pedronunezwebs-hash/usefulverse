テイラー級数計算機

初等関数、展開中心、次数、評価点を選択してください。各係数、多項式推定値、およびその点ごとの誤差を検査します。

サポートされている関数: eˣ、sin(x)、cos(x)、ln(x)、1/x、および √x。 0 ～ 30 を注文します。入力は ±50 に制限されます。三角関数入力ではラジアンが使用されます。

テイラー多項式の結果

ln(x)、√x、1/x の場合、テイラー級数は選択した中心の周りに有限の収束半径を持ちます。多項式はその外部でも評価できますが、関数を適切に近似できない可能性があります。

点ごとの差は |f(x) − Pₙ(x)| です。これは、最大誤差の推定値でも、区間全体に対する正式な剰余限界でもありません。

テイラー級数計算機は何を示しますか?

選択した中心の導関数から有限テイラー多項式を構築します。報告される誤差は、選択したポイントでの絶対的な差であり、一定期間にわたる保証された誤差の範囲ではありません。

よくある質問

テイラー級数計算機は何を示しますか?

選択した中心の導関数から有限テイラー多項式を構築します。報告される誤差は、選択したポイントでの絶対的な差であり、一定期間にわたる保証された誤差の範囲ではありません。

私の値はアップロードされていますか?

いいえ。多項式と比較はこのブラウザで計算されます。値はアップロードまたは保存されません。

マクローリン多項式とは何ですか?

ゼロを中心とするテイラー多項式です。この計算機を使用すると、ゼロまたは別の有効な中心を選択できます。

表示された差は、間隔全体の精度を保証しますか?

いいえ、単一の評価点における絶対的な差です。区間全体で拘束された剰余には、追加の導関数の範囲と条件が必要です。

収束半径の外側では多項式が不十分になるのはなぜですか?

有限多項式はそこで評価できますが、対数、平方根、逆関数の無限テイラー級数は中心を中心とした半径内でのみ収束します。
