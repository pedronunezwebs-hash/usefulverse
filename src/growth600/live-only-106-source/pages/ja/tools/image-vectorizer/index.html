画像ベクタライザー

シンプルなロゴ、アイコン、単色のアートワークを SVG パスにトレースします。色の制限と詳細サイズを選択し、ベクターをプレビューしてから、SVG をダウンロードします。

128

最長の辺がこのピクセル数以下に縮小されます。詳細を大きくすると、より大きな SVG が作成される場合があります。

シンプルなロゴ、アイコン、単色の描画に最適です。この方法はピクセル グリッドに従います。曲線を滑らかにしたり、写真の細部を再現したりすることはありません。

ソース イメージごとに最大 5 つの MiB。画像はローカルで処理され、アップロードされたり、自動的に保存されたりしません。大きな画像はデバイスのメモリを使用する可能性があります。コンピュータをお勧めします。

ベクター プレビュー

画像を SVG に変換するにはどうすればよいですか?

ラスター イメージを選択し、出力の詳細と色数を選択して、SVG を作成します。このツールは、実際のベクトル パスに含まれる色付きピクセルをグループ化します。エッジは選択したピクセル グリッドに従うため、写真よりもフラットなアートワークの方が効果的です。

よくある質問

画像を SVG に変換するにはどうすればよいですか?

ラスター イメージを選択し、出力の詳細と色数を選択して、SVG を作成します。このツールは、実際のベクトル パスに含まれる色付きピクセルをグループ化します。エッジは選択したピクセル グリッドに従うため、写真よりもフラットなアートワークの方が効果的です。

私の画像はアップロードされましたか?

いいえ。画像はこのブラウザ タブでデコードされ、トレースされます。アップロードされたり、自動的に保存されたりしません。

SVG には元のイメージが含まれていますか?

いいえ。結果には、埋め込まれたラスター イメージではなく、SVG パス シェイプが含まれます。ピクセルを色とパスにグループ化することでソースを近似します。

写真をスムーズにベクター化できますか?

いいえ。ピクセル グリッド トレースは、単純なロゴ、アイコン、単色描画を対象としています。写真では、ブロック状のエッジや大きな SVG ファイルが生成されることがあります。

ツールは画像をアップロードまたは保存しますか?

いいえ。ソースはこのタブで処理され、アップロードまたは自動保存されません。処理速度とメモリ使用量はデバイスによって異なります。
