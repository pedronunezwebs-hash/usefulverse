年金計算機

開始金額、レート、スケジュールを使用して均等支払いのストリームをモデル化します。結果は推定値であり、見積もりや財務上のアドバイスではありません。

固定の名目年率を支払頻度で割ったものと仮定します。手数料、税金、変更レートは含まれません。

結果

年金計算ツールはどのように機能しますか?

一連の均等支払いに、支払い頻度で割った固定名目年率を適用します。通常の支払いは各期間の終了時に行われます。年金の支払いは最初に発生します。手数料、税金、変動金利、または特定の保険会社の契約をモデル化したものではありません。

よくある質問

年金計算ツールはどのように機能しますか?

一連の均等支払いに、支払い頻度で割った固定名目年率を適用します。通常の支払いは各期間の終了時に行われます。年金の支払いは最初に発生します。手数料、税金、変動金利、または特定の保険会社の契約をモデル化したものではありません。

私の値はアップロードされていますか?

いいえ。計算はこのブラウザ タブで実行され、値はこのツールによってアップロードまたは保存されません。

現在の価値と将来の価値の違いは何ですか?

現在価値は、支払いストリームの現在の価値を推定します。将来価値は、スケジュールの終了までに初期残高と定期拠出金がどのように蓄積されるかを推定します。

これは年金契約の支払いを予測しますか?

いいえ。これは、入力した仮定を使用した一般的な算術です。実際の商品には、この計算機がモデル化していない手数料、保証、税金、および条件が含まれる場合があります。
