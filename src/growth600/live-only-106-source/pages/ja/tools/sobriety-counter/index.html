断酒日数カウンター

開始日を選択して、経過日数をカウントし、今後のマイルストーンを確認します。このプライベートカウンターは、治療、回復のアドバイス、または健康の尺度ではありません。

カウントする日付を入力します。今日の日付は 0 日目です。未来の日付は許可されません。 デフォルトは今日ですが、以前の日付を確認するように変更できますが、開始前の日付を確認することはできません。

最大 280 文字。機密情報を共有デバイスに入れないようにしてください。

これは日付演算のみです。物質の使用、健康状態、リスク、進行状況、または治療の必要性を評価するものではありません。回復は個人的なものです。サポートが必要な場合は、資格のあるサポートを検討してください。

保存はオプションであり、このブラウザのローカル ストレージのみを使用します。何もアップロードされていません。以下の保存データをクリアします。

あなたの日のカウント

禁酒日カウンターはどのように機能しますか?

入力した日付から今日までの暦日を丸ごとカウントします。選択した開始日自体は 0 日目です。それ以降の日付では日付のみの演算が使用されるため、夏時間によって日が追加または削除されることはありません。

よくある質問

禁酒日カウンターはどのように機能しますか?

入力した日付から今日までの暦日を丸ごとカウントします。選択した開始日自体は 0 日目です。それ以降の日付では日付のみの演算が使用されるため、夏時間によって日が追加または削除されることはありません。

私の断酒日はアップロードまたは保存されていますか?

データがアップロードされていません。あなたの日付はこのブラウザでのみ使用されます。明示的にオプトインした場合にのみ、メモまたは日付をこのデバイスに保存できます。ローカル記録はいつでもクリアできます。

開始日は1日目としてカウントされますか?

いいえ。選択された開始日は 0 日目です。次の暦日は 1 日後です。

この窓口では回復や医学的なアドバイスをしてもらえますか?

いいえ。暦日をカウントし、マイルストーンのみを表示します。健康、薬物使用、治療、個人の進歩を評価するものではありません。

日付やメモはサーバーに送信されますか?

いいえ。計算はブラウザーで実行されます。保存はオプションであり、このデバイス上のこのブラウザに小さなレコードが保存されます。ここでクリアできます。
