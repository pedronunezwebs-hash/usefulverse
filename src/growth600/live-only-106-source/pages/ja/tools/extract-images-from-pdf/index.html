PDF から画像を抽出

PDF を選択して、埋め込まれたラスター イメージを検索し、プレビューし、個別の PNG コピーまたは 1 つの ZIP を保存します。ページはスクリーンショットにラスタライズされません。

サポートされている埋め込みラスター イメージ オブジェクトを抽出します。 PDF ページ全体を画像に変換するわけではありません。ベクトル描画とページ テキストは別個のラスター イメージではありません。

ファイルはこのデバイス上に残り、アップロードされません。抽出されたピクセルは PNG として再エンコードされるため、元の埋め込みファイル形式とメタデータは保持されません。

ローカル制限: 25 MiB PDF、300 ページ、200 画像、画像あたり 8 メガピクセル、合計 16 メガピクセル、および 25 MiB ZIP。大型の PDF はデバイス メモリを使用します。コンピュータをお勧めします。

    PDF から画像を抽出するにはどうすればよいですか?

    PDF を選択し、[画像の抽出] を選択します。このブラウザは、サポートされている埋め込みラスター イメージ オブジェクトを読み取り、デコードされたピクセルを PNG ファイルに変換します。個別の画像または 1 つの ZIP をダウンロードします。

    よくある質問

    PDF から画像を抽出するにはどうすればよいですか?

    PDF を選択し、[画像の抽出] を選択します。このブラウザは、サポートされている埋め込みラスター イメージ オブジェクトを読み取り、デコードされたピクセルを PNG ファイルに変換します。個別の画像または 1 つの ZIP をダウンロードします。

    PDF または画像はアップロードされていますか?

    いいえ。PDF はこのブラウザ タブで処理されます。このツールはファイルをアップロードしたり、アカウントに保存したりしません。

    このツールは PDF のすべてのページを画像に変換しますか?

    いいえ。サポートされている埋め込みラスター イメージ オブジェクトを検索します。各ページ全体のレンダリングされたイメージが必要な場合は、PDF-to-image ツールを使用します。

    抽出された PNG は、埋め込まれたファイルとバイトごとに同一になりますか?

    いいえ。ブラウザはサポートされている画像オブジェクトをデコードし、そのピクセルをデコードされたオブジェクトの寸法で PNG として再エンコードします。元の圧縮、ファイル形式、メタデータは保持されません。

    一部の PDF 画像が表示されないのはなぜですか?

    ベクター アートワーク、イメージ マスク、異常なエンコーディング、パスワード保護、不正な形式のファイル、ブラウザのメモリ制限により、抽出が妨げられる場合があります。このツールはサポートされているオブジェクトのみをレポートし、ファイルはアップロードしません。
