有理式電卓

x に整数係数多項式を入力して、有理式を簡略化します。結果では元の分母の制限が維持されるため、キャンセルによって入力が未定義になる値が隠蔽されることはありません。

整数の係数と x (x^2-1 など) を使用します。パワーアップは8まで。

整数の係数と x (x-1 など) を使用します。ゼロにすることはできません。

1 つの変数 x、最大 1,000,000 までの整数係数、および最大 8 次数をサポートします。括弧や小数係数は使用しません。

結果

有理式を簡略化するにはどうすればよいですか?

分子と分母を因数分解し、それらの共通多項式をキャンセルし、制限として元の分母のゼロを保持します。たとえば、x-1 に対する x²-1 は x+1 に減りますが、x≠1 は依然として除外されます。

よくある質問

有理式を簡略化するにはどうすればよいですか?

分子と分母を因数分解し、それらの共通多項式をキャンセルし、制限として元の分母のゼロを保持します。たとえば、x-1 に対する x²-1 は x+1 に減りますが、x≠1 は依然として除外されます。

私の表現はアップロードされていますか?

いいえ。解析と単純化はこのブラウザでローカルに実行されます。入力はアップロードまたは保存されません。

要因をキャンセルした後も制限が残るのはなぜですか?

簡略化された式は、元の分母がゼロだった値で定義される可能性があります。その値は、元の式のドメインから除外されたままになります。

どのような多項式形式がサポートされていますか?

2x^3−x+4 などの整数係数を持つ単一変数 x を使用します。 0 から 8 までのべき乗がサポートされています。括弧、10 進数の係数、および複数の変数はそうではありません。

これは考えられるすべての因数分解を見つけますか?

整数演算を使用して完全共通多項式因数をキャンセルします。既約線形因数または二次因数への完全な因数分解は提供されません。
