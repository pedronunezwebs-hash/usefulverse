電子メール署名ジェネレーター

連絡先の詳細、色のアクセント、およびオプションのロゴを使用して、すっきりとしたコンパクトな電子メール署名を作成します。プレビューしてから、フォーマットされたブロックまたはその HTML をコピーします。

PNG、JPEG、または GIF。最大 512 KiB および 1,600 × 1,600 ピクセル。画像は署名に埋め込まれていますが、一部の電子メール アプリでは埋め込まれた画像が削除されます。

電子メール アプリの署名の表示方法が異なります。テーブル レイアウトとインライン スタイルにより互換性が向上しますが、送信する前にメール アプリで結果を確認してください。

詳細と画像はこのブラウザ タブに表示されます。何もアップロードされず、自動的に保存されません。

署名のプレビュー

電子メールの署名を作成するにはどうすればよいですか?

名前とオプションの連絡先詳細を追加し、アクセントカラーを選択して、署名を生成します。書式設定されたブロックをメール設定にコピーするか、メール アプリがサポートしている場合は HTML をコピーします。

よくある質問

電子メールの署名を作成するにはどうすればよいですか?

名前とオプションの連絡先詳細を追加し、アクセントカラーを選択して、署名を生成します。書式設定されたブロックをメール設定にコピーするか、メール アプリがサポートしている場合は HTML をコピーします。

私の詳細はアップロードされていますか?

いいえ。詳細とオプションのロゴはこのブラウザ タブで処理され、アップロードされたり、自動的に保存されたりしません。

この署名はどのメール アプリでも同じように見えますか?

いいえ。電子メール アプリは、さまざまな HTML および画像機能をサポートしています。このジェネレーターはコンパクトなテーブルとインライン スタイルを使用しますが、貼り付けた署名を独自の電子メール アプリでテストする必要があります。

署名にロゴを使用できますか?

はい。最大 512 KiB の PNG、JPEG、または GIF を選択します。画像データとして埋め込まれます。一部の電子メール アプリでは埋め込み画像がブロックまたは削除されるため、テキストのみの署名の方が信頼性が高い場合があります。

ジェネレーターは私の連絡先詳細を送信または保存しますか?

いいえ。このブラウザ タブで署名が構築されます。いつコピーまたはダウンロードするかを選択します。このページでは、詳細情報がアップロードされたり、自動的に保存されたりしません。
