PDF ブックマーク エディタ

PDF にナビゲート可能な目次を追加するか、既存のブックマークを整理します。ネストされたセクションを作成し、ページの宛先を割り当て、エントリを並べ替えて、ブラウザに別のコピーを保存します。

Editing により、新しい PDF コピーが作成されます。読者によってはブックマークの表示方法が異なる場合があります。保存したコピーを共有する前に確認してください。

ローカル制限: 25 MiB 入力、300 ページ、500 ブックマーク、20 ネスト レベル、および 50 MiB 出力。大きなファイルは大量のデバイス メモリを使用する可能性があります。コンピューターの使用を推奨します。

C内部ページ宛先とネストされたアウトライン エントリを作成します。既存の外部リンク、名前付き宛先、またはサポートされていないブックマーク アクションは、サイレントに破棄されるのではなく、拒否されます。ページの内容は編集されていません。デジタル署名は保存後に無効になる場合があります。

PDF ブックマーク

ブックマークはまだありません。目次を開始するには 1 つ追加します。

Export は、現在のアウトラインをここに書き込みます。インポートにより、検証後に現在のアウトラインが置き換えられます。ソース PDF のバックアップを保管してください。 JSON にはページ コンテンツが含まれていません。

PDF にブックマークを追加するにはどうすればよいですか?

PDF を選択し、サポートされている内部ページ ブックマークを読み取ります。タイトル、ページ、およびオプションの親セクションを追加または編集し、エントリを配置して、別の PDF コピーを保存します。アウトラインを JSON.

よくある質問

PDF にブックマークを追加するにはどうすればよいですか?

PDF を選択し、サポートされている内部ページ ブックマークを読み取ります。タイトル、ページ、およびオプションの親セクションを追加または編集し、エントリを配置して、別の PDF コピーを保存します。アウトラインを JSON.

PDF またはブックマークはアップロードされていますか?

No.選択したドキュメントは、選択後このブラウザで処理されます。 UsefulVerse は、PDF をアップロードしたり、そのブックマーク データをサーバーに送信したりしません。

ブックマークはセクションの下にネストできますか?

はい。親セクションを設定して階層を作成します。文書ページ自体は変更されません。各ブックマークは、選択したページ番号を指します。

外部リンクを開くブックマークは保持されますか?

このエディターは現在、内部ページの宛先をサポートしています。サポートされていない外部アクションまたは名前付き宛先を持つファイルは、サイレントにドロップするのではなく拒否されます。

PDF ページまたは署名は変更されますか?

ページのコンテンツではなく、ドキュメントのアウトラインを編集し、新しいコピーを保存します。編集するとデジタル署名が無効になる可能性があるため、結果を確認し、このツールを署名の保存として扱わないでください。
