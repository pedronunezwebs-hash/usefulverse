エフェクト サイズ計算ツール

2 つの独立したグループの要約統計量を入力して、符号付きの標準化平均差、プールされた標準偏差、および小標本補正されたヘッジの g を計算します。

グループ 1
グループ 2

独立グループの場合、このバージョンでは従来のプール SD 定義が使用され、共有母集団分散が想定されます。標準誤差ではなく、サンプル (n−1) 個の標準偏差を入力します。

各サンプル サイズは 2 ～ 1,000,000 でなければなりません。は平均値であり、SD は ±1,000,000,000 に制限されます (SD を負にすることはできません)。少なくとも 1 つの SD はゼロより大きくなければなりません。

効果量の結果

d = (平均₁ − 平均₂) / プールされた SD。ヘッジズの g = J(df) × d、df = n₁ + n₂ − 2。符号は群の次数によって異なります。マグニチュードは自動的に「小」、「中」、または「大」になるわけではありません。それを主題分野で解釈し、デザインを研究します。

効果量計算ツールは何を測定しますか?

2 つのグループ平均の差をプールされた標準偏差単位で表します。コーエンの d は、未補正の標準化差です。 Hedges の g は、小さなサンプル補正を適用します。

よくある質問

効果量計算ツールは何を測定しますか?

2 つのグループ平均の差をプールされた標準偏差単位で表します。コーエンの d は、未補正の標準化差です。 Hedges の g は、小さなサンプル補正を適用します。

私の研究統計はアップロードされていますか?

いいえ。計算はこのブラウザで実行されます。概要統計はサーバーに送信されたり、このツールによって保存されたりすることはありません。

コーエンの d とヘッジズの g の違いは何ですか?

どちらも、プールされた標準偏差によって平均差を標準化します。 Hedges の g は d に小さいサンプルの補正を乗算し、サンプルが小さい場合のバイアスを軽減します。

標準偏差の代わりに標準誤差を入力できますか?

いいえ。この計算機は各グループのサンプル標準偏差を想定しています。標準誤差はサンプル推定値の不確実性を表し、ここでは SD と互換性はありません。

効果量が大きいほど、結果が重要であることが証明されますか?

いいえ。効果量は、統計的な有意性、因果関係、または実際の重要性ではなく、標準化された差異を表します。背景、不確実性、研究デザイン、測定スケールが重要です。
