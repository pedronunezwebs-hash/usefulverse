呼吸エクササイズ

心地よい呼吸のペースを選び、画面のガイドに従ってください。無理をせず、いつでも中断できます。

「動きを抑える」設定が有効な場合、ガイドの急激な動きは避けられます。

これは一般的なウェルネス用タイマーであり、医療行為ではありません。心地よいペースで呼吸し、体調が優れない場合は中止してください。

この呼吸エクササイズの使い方は？

プリセットまたは各段階の時間を設定し、セッションの長さを選んで「開始」を押します。いつでも一時停止やリセットが可能です。音声はオプションで、開始後にのみ流れます。

よくある質問

この呼吸エクササイズの使い方は？

プリセットまたは各段階の時間を設定し、セッションの長さを選んで「開始」を押します。いつでも一時停止やリセットが可能です。音声はオプションで、開始後にのみ流れます。

呼吸セッションのデータはアップロードされますか？

いいえ。タイマーはこのページ内だけで動作します。アカウント登録、アップロード、API通信、セッションデータの保存は行いません。

ボックス呼吸や4-7-8法を使えますか？

はい。プリセットを選択するか、各段階の時間を調整してください。これらは呼吸のペースを整えるためのものであり、医療行為ではありません。

タブを閉じても動作し続けますか？

保証はできません。ブラウザがバックグラウンドのタブを一時停止したり、デバイスがスリープ状態になったりすることがあります。正確なタイミングには、このページを開いたままにし、デバイスをスリープさせないでください。

音声をオフにしたり、途中で終了したりできますか？

はい。音声は任意で、オフにできます。「一時停止」または「リセット」を押すと実行中のタイマーはすぐに停止します。
