XML から CSV へのコンバーター

単純な XML レコード リストを CSV テーブルに変換するか、CSV ファイルのテキストから XML レコードを構築します。方向を選択し、データを貼り付けて、結果をコピーまたはダウンロードします。何もアップロードされていません。

同名のレコード要素の単純なリスト、または 1 つのフラット レコードをサポートします。要素の子はスカラー値である必要があります。ネストされたフィールドと繰り返しフィールドはフラット化されません。

列名には最初の行を使用します。 @id などのヘッダーは XML 属性になります。レコードテキストには #text を使用します。

これは単純なテーブル変換であり、ロスレス XML 形式変換ではありません。ネームスペース、ネストされた構造、混合コンテンツ、コメント、および XML 形式は保持されません。テキストは型を認識しません。スプレッドシートの数式に似た CSV 値には、安全のためにアポストロフィが接頭辞として付けられます。

結果

別のアプリケーションにインポートする前に出力を確認してください。

XML を CSV に変換するにはどうすればよいですか?

XML to CSV を選択し、単純なレコード リストを含む XML を貼り付けます。繰り返される直接レコード要素は行になります。要素名は列になります。属性は @name を使用します。ヘッダーと行から単純な XML レコードを作成するには、[CSV to XML] を選択します。

よくある質問

XML を CSV に変換するにはどうすればよいですか?

XML to CSV を選択し、単純なレコード リストを含む XML を貼り付けます。繰り返される直接レコード要素は行になります。要素名は列になります。属性は @name を使用します。ヘッダーと行から単純な XML レコードを作成するには、[CSV to XML] を選択します。

XML または CSV はアップロードされていますか?

いいえ。解析と変換はこのブラウザで実行されます。入力は 200,000 文字、5,000 行、64 列、20,000 セルに制限されます。 DTD およびエンティティ宣言はブロックされ、外部リソースはフェッチされません。

XML 属性は CSV にどのように表示されますか?

id="101" などの属性は、@id という名前の列になります。逆変換すると、@ で始まる CSV ヘッダーが XML 属性になります。

ネストされた XML をフラット テーブルに変換できますか?

いいえ。ネストされた子構造、レコード内の繰り返しフィールド、および混合テキストは、フラット化されたり暗黙的に失われるのではなく、拒否されます。ネストされたデータには専用の XML から JSON へのワークフローを使用します。

CSV は XML タイプとフォーマットを保持しますか?

いいえ。CSV には、XML タイプ、名前空間、または書式設定ではなく、セル テキストが保存されます。スプレッドシートの数式の実行リスクを軽減するために、数式のようなセル値にはエクスポート時にアポストロフィ接頭辞が付けられます。
