よくある質問

スネーク ゲームはどうやってプレイしますか?

ラウンドを開始し、arrow keys、WASD、またはタッチ ボタンを使用して餌に向かって操縦し、壁や体を避けてください。いつでも一時停止してください。食べ物を食べると蛇が成長し、1ポイントが追加されます。

スネーク ゲームはスコアを保存しますか、それともアカウントを使用しますか?

アカウントやダウンロードは必要ありません。現在のスコアとセッションは、この tab 内でのみ記憶されるのが最適です。退会後はアップロードも保存もされません。

携帯電話や tablet でプレイできますか?

はい。画面上の方向ボタンを使用します。 arrow keys または WASD を備えたキーボードもコンピュータで動作します。

ゲームを一時停止できますか?

はい。いつでも一時停止を選択します。あなたが再開するまでヘビは動きを止めます。

毎回同じゲームが手に入るのですか？

ボードのレイアウトはおなじみのものですが、食べ物の位置は新しいラウンドごとにランダム化されます。現在のセッション スコアと最高のセッション スコアは、終了後は保存されません。
