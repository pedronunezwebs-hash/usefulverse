無料で利用可能、アカウント不要

Wilks・DOTSパワーリフティング計算機

リフターの体重とパワーリフティングの合計またはシングルリフトの結果を入力します。比較可能なスコアを確認するには、名前付きスコアリング モデルを選択します。各モデルは個別に表示されます。

モデルには互換性がなく、リフターのランクが異なる場合があります。モデルの公開されたテーブルに必要な係数グループを選択します。これは式の設定であり、ID ラベルではありません。公平な比較を行うには、同じイベント形式 (フルパワーリフティング合計または同じシングルリフト)、単位、モデルからの結果を使用します。これは連盟の公式結果や競技順位の予測ではありません。

係数とモデルのリファレンス
  • オリジナルウィルクス係数表（欧州パワーリフティング連盟）
  • Wilks-2 および DOTS 係数ドキュメント (IPF 評価レポート)

スコア推定

比較見積りのみ。現在の公式 IPF グッドリフト スコアではありません。同じモデル、係数グループ、イベント形式を使用して結果を比較します。ルールとモデルの適合性は異なります。

Wilks スコアまたは DOTS スコアはどのように計算されますか?

各モデルは、公開されている体重係数を入力された体重に適用し、入力されたリフト結果をそのモデルの分母でスケールします。結果は、同じ式、係数グループ、およびイベント タイプが使用された場合にのみ比較できます。

よくある質問

Wilks スコアまたは DOTS スコアはどのように計算されますか?

各モデルは、公開されている体重係数を入力された体重に適用し、入力されたリフト結果をそのモデルの分母でスケールします。結果は、同じ式、係数グループ、およびイベント タイプが使用された場合にのみ比較できます。

私の番号はアップロードまたは保存されていますか?

いいえ。計算はこのブラウザで実行されます。入力した値はアップロードまたは保存されません。

Wilks、Wilks-2、DOTSの違いは何ですか?

これらは、公表されている係数が異なる別個の体重調整モデルです。それらのスコアは交換可能ではなく、2 つのモデルはリフターを異なる順序で並べることができます。

これはIPFの公式スコアですか?

いいえ。この計算機は Wilks、Wilks-2、および DOTS 推定値を表示します。 IPF 競技会では、現在の連盟スコアリング システムとそのルールが使用されます。主催者の公式結果を確認してください。

ベンチプレスの結果をパワーリフティングの合計結果と比較できますか?

両方のアスリートに同じイベント形式を使用します。算術演算ではどちらの入力からもスコアを計算できますが、1 つのリフトと 3 つのリフトの合計を比較することは、同様の競争の比較ではありません。
