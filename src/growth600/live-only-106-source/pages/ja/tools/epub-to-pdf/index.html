EPUB から PDF コンバーター

このデバイスで DRM フリー EPUB を開き、ブラウザの印刷ダイアログを使用してテキストファースト PDF を保存します。章の順序は本に従います。元のレイアウト、画像、埋め込みフォントは保持されません。

最大ファイルサイズ: 25 MB。ブラウザのメモリを保護するために、拡張されたブック コンテンツは制限されています。

テキストファースト変換: 章の順序と読みやすいテキストが維持されます。元のページのデザイン、写真、表、脚注、埋め込みフォント、およびインタラクティブなコンテンツは保持されない場合があります。 DRM で保護された EPUB ファイルや不正な形式の EPUB ファイルはサポートされていません。大きなブックでは大量のメモリが使用される場合があります。パソコンの使用を推奨します。

印刷プレビュー

EPUB を PDF として保存するにはどうすればよいですか?

最大 25 MB の DRM フリー EPUB を選択してください。書籍をローカルで読んだ後、[PDF の準備] を選択します。印刷ダイアログで [PDF として保存] を選択し、デバイス上の保存先を選択します。

よくある質問

EPUB を PDF として保存するにはどうすればよいですか?

最大 25 MB の DRM フリー EPUB を選択してください。書籍をローカルで読んだ後、[PDF の準備] を選択します。印刷ダイアログで [PDF として保存] を選択し、デバイス上の保存先を選択します。

私の EPUB はアップロードされていますか?

いいえ。ファイルはこのブラウザで読み取られ、UsefulVerse には送信されません。ブラウザーでローカルの印刷ドキュメントが開き、PDF として保存できます。

PDF は EPUB とまったく同じように見えますか?

いいえ。これにより、章順に、きれいなテキストファーストの印刷可能なコピーが作成されます。元のスタイル、画像、表、脚注、埋め込みフォントは省略される場合があります。

DRM で保護された書籍を変換できますか?

いいえ。 DRM の解除はサポートされていません。変換が許可されている書籍のみを使用してください。ブラウザの印刷ダイアログが開きます。 [PDF として保存] を選択し、保存場所を選択します。
