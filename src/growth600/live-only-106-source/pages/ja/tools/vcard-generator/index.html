Vカードジェネレーター

ブラウザで .vcf ファイルとして単一のデジタル連絡先を作成します。 vCard 3.0 または 4.0 を選択し、連絡先の詳細を追加し、オプションで小さな JPEG または PNG 写真を埋め込みます。

オプションの JPEG または PNG、最大 128 KiB。写真は VCF ファイルに埋め込まれます。アップロードされていません。

1 つの連絡先、最大 5 つの電話と 5 つの電子メール、テキスト フィールドあたり 500 文字、生成されるファイルの制限は 1 MiB です。 vCard 3.0 および 4.0 のみが提供されます。

[生成] を選択した後、ローカルで実行されます。アカウント、連絡帳へのアクセス、アップロード、API、サーバー処理、自動保存はありません。

VCF プレビュー


  

    
これにより、連絡先が私の携帯電話に追加されますか?
いいえ。プレビュー、コピー、またはダウンロードできる VCF ファイルが作成されます。アドレス帳を読み取ったり変更したりすることはありません。ファイルをインポートするかどうか、およびどこにインポートするかを決定します。


    
よくある質問
これにより、連絡先が私の携帯電話に追加されますか?
いいえ。プレビュー、コピー、またはダウンロードできる VCF ファイルが作成されます。アドレス帳を読み取ったり変更したりすることはありません。ファイルをインポートするかどうか、およびどこにインポートするかを決定します。
私の連絡先情報はアップロードされていますか?
No. 詳細とオプションの写真はこのデバイスで処理されます。アップロード、アカウント、サーバー処理、自動保存はありません。
vCard 3.0 と 4.0 の違いは何ですか?
これらは、vCard 連絡先フォーマットの 2 つのバージョンです。このツールは、選択したバージョンを使用して互換性のある VCF テキスト ファイルを書き込みます。連絡先アプリではサポートが異なる場合があります。
これは電話番号または電子メール アドレスを認証しますか?
いいえ。基本的な形式のみをチェックします。番号、メールボックス、住所、Web サイトがその個人のものであるかどうかを確認することはできません。
