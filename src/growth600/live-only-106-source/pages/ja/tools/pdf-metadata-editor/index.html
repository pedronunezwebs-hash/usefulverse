PDF メタデータ エディター

PDF に保存されている共通文書情報を読み取りまたは編集し、別のコピーをダウンロードします。選択した PDF はこのデバイス上に残ります。

オリジナルを保管してください。再保存すると、デジタル署名が無効になったり、高度な PDF 機能に影響を与えたりする可能性があります。このツールは、隠された情報を削除したり、プライバシーを保証したりするものではありません。

ローカル制限: 25 MiB 入力、300 ページ、50 MiB 出力。大きなドキュメントにはさらに多くのメモリが必要になる場合があります。コンピュータをお勧めします。

標準PDF文書情報のみ編集します。 XMP、カスタム メタデータ、添付ファイル、非表示のコンテンツ、署名の検証はサポートされていません。

標準文書情報

新しいコピーからその標準情報エントリを削除するには、フィールドを空白のままにします。他のフィールドは保持されます。

PDF コピーの準備ができました

編集済みPDFをダウンロード

処理はこのブラウザ内でローカルに行われます。アカウント、アップロード、サーバー処理、自動保存はありません。

どの PDF メタデータを変更できますか?

このツールは、標準の文書情報フィールド (タイトル、作成者、件名、キーワード、作成者、作成者、作成日、および変更日) を編集します。 XMP メタデータやカスタム プロパティは編集されません。

よくある質問

どの PDF メタデータを変更できますか?

このツールは、標準の文書情報フィールド (タイトル、作成者、件名、キーワード、作成者、作成者、作成日、および変更日) を編集します。 XMP メタデータやカスタム プロパティは編集されません。

私の PDF はアップロードされましたか?

いいえ。ファイルを選択すると、ブラウザーで読み取りと編集が行われます。元のファイルは変更されません。保存すると、別の PDF コピーが作成されます。

これにより、PDF からすべてのメタデータが削除されますか?

いいえ。標準の PDF 文書情報辞書の共通エントリのみを編集します。 XMP、カスタム プロパティ、埋め込みファイル、その他の非表示のコンテンツが残る場合があります。

メタデータを編集するとデジタル署名は保持されますか?

そんなものに頼らないでください。保存すると PDF が書き換えられ、既存のデジタル署名が無効になったり、このツールでサポートされていない機能に影響を与えたりする可能性があります。原本を保管し、コピーを確認してください。

元のPDFは上書きされますか？

いいえ。ツールは選択されたファイルを読み取り、ダウンロード可能な別のコピーを作成します。デバイス上のオリジナルは変更されません。
