PDF アクセシビリティ チェッカー

PDF をローカルで検査して、文書タグ、メタデータ、選択可能なテキスト、代替テキストのない図、見出しレベルのジャンプなど、機械が検出できるいくつかのアクセシビリティ信号を確認します。これは単なるファーストパス チェッカーであり、PDF/UA 検証ツールや支援技術テストの代替品ではありません。

最大 25 MiB および 300 ページ。検査ではデバイスのメモリが使用される場合があります。大きなファイルの場合はコンピュータの使用をお勧めします。

ファイルを選択すると、デバイス上で検査が実行されます。アップロード、アカウント、API、自動保存、サーバー処理はありません。

これらのチェックはヒューリスティックです。正しい読み取り順序、意味のある説明、色のコントラスト、キーボードの使用、フォームのラベル、テーブルヘッダーの関係、または PDF/UA/Section 508/WCAG への準拠を確認することはできません。手動で確認し、支援技術を使用してテストします。

検査報告書

この PDF アクセシビリティ チェッカーは何を検出できますか?

PDF が構造タグ、文書のタイトルと言語、各ページの選択可能なテキスト、代替テキストを含む図、および見出しレベルのジャンプの可能性を公開しているかどうかを報告します。読む順序や代替テキストが意味があるかどうかを判断することはできません。

よくある質問

この PDF アクセシビリティ チェッカーは何を検出できますか?

PDF が構造タグ、文書のタイトルと言語、各ページの選択可能なテキスト、代替テキストを含む図、および見出しレベルのジャンプの可能性を公開しているかどうかを報告します。読む順序や代替テキストが意味があるかどうかを判断することはできません。

私の PDF はチェック用にアップロードされていますか?

いいえ。選択した PDF はこのブラウザ タブで検査されます。ファイルとそのテキストはアップロードされず、自動的に保存されず、サーバーに送信されません。

肯定的な結果は、PDF がアクセス可能であることを意味しますか?

いいえ。これらは限定された自動信号のみです。タグ付けされた PDF には、依然として、間違った読み取り順序、不十分な説明、アクセスできないフォーム、低コントラスト、またはその他の障壁が存在する可能性があります。手動および支援技術のテストは依然として必要です。

PDF/UA または WCAG への準拠を確認できますか?

いいえ。このファーストパス チェッカーはすべての要件をテストするわけではなく、PDF/UA、WCAG、セクション 508、または法的準拠を認証することはできません。
