家系図メーカー

すでに知っている情報から家系図を作成します。人を追加し、親リンクを接続して、図または GEDCOM ファイルをエクスポートします。このページでは記録を検索したり、家族のデータを保存したりすることはありません。

このツリーにいる人
親と子を接続します

家族の詳細は機密情報となる可能性があります。このページを閉じるかリセットするまで、データはメモリ内に残ります。エクスポートには個人情報が含まれる場合があります。

家系図

    家系図を作成するにはどうすればよいですか?

    各ユーザーを 1 回追加してから、親を子に接続します。チャートは、重複リンク、リストされた 3 つ以上の親および祖先サイクルをブロックします。準備ができたら、SVG 図または GEDCOM テキスト ファイルをエクスポートします。

    よくある質問

    家系図を作成するにはどうすればよいですか?

    各ユーザーを 1 回追加してから、親を子に接続します。チャートは、重複リンク、リストされた 3 つ以上の親および祖先サイクルをブロックします。準備ができたら、SVG 図または GEDCOM テキスト ファイルをエクスポートします。

    私の家族情報はアップロードまたは保存されていますか?

    いいえ。チャートはこのページのセッションに残ります。ブラウザのストレージにアップロードまたは保存されることはありません。エクスポートされたファイルは保存および共有できるため、最初にプライベートな詳細がないか確認してください。

    このツールは親戚や公的記録を見つけることができますか?

    いいえ。入力した詳細が整理されるだけです。記録を検索したり、身元を確認したり、法的関係を確立したりすることはありません。

    GEDCOM ファイルとは何ですか?

    GEDCOM は、互換性のある家系図プログラム間で家族歴史記録を移動するために使用されるテキスト形式です。エクスポートされたファイルを共有する前に確認してください。

    グラフは 2 人以上の親をサポートしていますか?

    このバージョンでは、1 人あたり最大 2 人の保護者をリストに登録できます。家族関係は、このグラフで表現できるよりも複雑である可能性があります。
