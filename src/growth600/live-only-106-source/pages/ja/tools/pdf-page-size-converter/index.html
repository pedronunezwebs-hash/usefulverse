PDF ページ サイズ コンバータ

PDF の各ページのサイズを A4、US Letter、Legal、またはカスタム用紙サイズに変更します。新しい寸法をプレビューし、元のページ領域全体に合わせて、デバイス上で処理された別のコピーをダウンロードします。

サイズ変更すると、別のコピーが作成されます。再保存するとデジタル署名が無効になる場合があります。オリジナルを保持し、共有する前に新しい PDF を確認してください。

ローカル制限: 25 MiB 入力、300 ページ、50 MiB 出力。大きなファイルは大量のメモリを使用する可能性があります。コンピューターの使用を推奨します。

サイレント変更を避けるため、このツールは回転されたページ、カスタム ページ ボックス、注釈、リンク、対話型フォームを拒否します。フィット モードでは、既存のページの四角形全体が拡大縮小され、既に境界の外側にあるコンテンツは復元できません。

PDF のページ サイズを変更するにはどうすればよいですか?

PDF を選択し、そのページを検査し、A4、レター、リーガル、またはカスタムサイズを選択して、ページに合わせるか実際のサイズを選択します。フィット モードでは、比例的に拡大縮小し、各ページ領域全体が中央に配置されます。新しいコピーをダウンロードして、オリジナルを保存してください。

よくある質問

PDF のページ サイズを変更するにはどうすればよいですか?

PDF を選択し、そのページを検査し、A4、レター、リーガル、またはカスタムサイズを選択して、ページに合わせるか実際のサイズを選択します。フィット モードでは、比例的に拡大縮小し、各ページ領域全体が中央に配置されます。新しいコピーをダウンロードして、オリジナルを保存してください。

PDF をアップロードしてサイズを変更できますか?

No. PDF を選択すると、このブラウザで PDF が処理されます。 UsefulVerse によってアップロードまたは保存されていません。大きな PDF はデバイスのメモリを使用する可能性があります。コンピューターを推奨します。

PDF を A4 または US Letter にサイズ変更できますか?

はい。 A4、US Letter、または US Legal を選択し、縦または横を選択して、結果をプレビューします。カスタム サイズはミリメートルまたはインチで入力することもできます。

サイズを変更すると PDF コンテンツがトリミングされますか?

Fit モードは、元のページの完全な四角形を均一に拡大縮小し、新しい用紙の中央に配置します。意図的に切り取っているわけではありません。すでに元の PDF ページ境界の外側にあるコンテンツは回復できません。

これにより、リンク、フォーム、またはデジタル署名が保持されますか?

このツールは、注釈、リンク、インタラクティブ フィールド、回転、またはカスタム ページ ボックスを含むページを、サイレントに削除するのではなく拒否します。 PDF を保存すると、デジタル署名が無効になる可能性があります。オリジナルを保存して確認してください。
