アイゼンハワー マトリックス

タスクリストを 4 つの明確な選択肢に変えます: 実行する、スケジュールする、委任する、ドロップする。 何が重要で緊急であるかを決めるのはあなたです。 日付はリマインダーであり、自動判断ではありません。

独自のコンテキストを使用してタスクを分類します。 マトリックスが重要性を決めるわけではありません。 データはこのタブのメモリ内に残り、バックアップをエクスポートしない限り、タブを閉じるか再ロードすると消去されます。 インポートでは、このツールの JSON バックアップのみ、最大 1 MB および 300 タスクを受け入れます。

重要とは、あなたが関心を持っている目標、責任、または結果に意味のある影響を与えることを意味します。

「緊急」とは、実際の期限または結果のためにすぐに対応する必要があることを意味します。 期日だけで重要性が決まるわけではありません。

最初にやる

緊急かつ重要: 今すぐ行動してください。

    スケジュール

    重要ですが緊急ではありません: 緊急になる前に時間を確保します。

      代表者

      緊急だが重要度は低い: 適切なときに引き渡し、フォローアップを追跡します。

        削除を検討してください

        緊急でも重要でもない: 削除するか、計画から外してください。

          アイゼンハワー マトリックスはどのように使用しますか?

          各タスクについて 4 つの象限から 1 つを選択します。緊急で実行することが重要、重要だがスケジュールは急ではない、緊急だが委任するのは重要ではない、またはどちらも削除することは考慮しない。 タスクの象限はいつでも変更できます。

          よくある質問

          アイゼンハワー マトリックスはどのように使用しますか?

          各タスクについて 4 つの象限から 1 つを選択します。緊急で実行することが重要、重要だがスケジュールは急ではない、緊急だが委任するのは重要ではない、またはどちらも削除することは考慮しない。 タスクの象限はいつでも変更できます。

          アイゼンハワー マトリックスのタスクは非公開ですか?

          タスクはこのブラウザタブに残り、自動的にアップロードまたは保存されません。 保持したい場合は JSON バックアップをエクスポートし、後でそのファイルをこのデバイスにインポートします。

          アイゼンハワー マトリックスの各象限には何が入っていますか?

          緊急かつ重要な仕事を最初に行います。 緊急ではない重要な仕事のスケジュールを立てます。 他の人が処理できる場合は重要度が低い緊急の仕事を委任します。 緊急でも重要でもないタスクを削除することを検討してください。

          期日によって自動的にタスクは緊急または重要になりますか?

          いいえ。 期限は緊急性を判断するのに役立ちますが、緊急性と重要性は実際の期限、結果、目標に基づいて決定します。
