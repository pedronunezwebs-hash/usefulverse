サイトマップ検証ツール

サイトマップ XML ドキュメントを貼り付けて、その構造、URL エントリ、日付、および共通フィールドを確認します。 XML はこのブラウザでのみ解析されます。リストされたページは決して取得されません。

標準の urlset または sitemapindex をサポートします。最大 1,000,000 文字および 5,000 の直接入力。

ローカル XML チェックのみ: リストされた URL の要求、サイトのクロール、サイトマップの送信、またはインデックス作成の保証は行いません。

検証の概要

調査結果

    このサイトマップ検証ツールは何をチェックしますか?

    urlset または sitemapindex エントリ、絶対的な HTTP または HTTPS の場所、重複した正規化された URL、lastmod の日付、オプションの変更頻度と優先度の値、およびサイトマップの名前空間をチェックします。警告とエラーはエントリ番号ごとにリストされます。

    よくある質問

    このサイトマップ検証ツールは何をチェックしますか?

    urlset または sitemapindex エントリ、絶対的な HTTP または HTTPS の場所、重複した正規化された URL、lastmod の日付、オプションの変更頻度と優先度の値、およびサイトマップの名前空間をチェックします。警告とエラーはエントリ番号ごとにリストされます。

    サイトマップをアップロードまたは送信しますか?

    いいえ。XML はブラウザーでローカルに処理されます。このツールは、URL のクロール、リモート サイトマップ ファイルの取得、検索エンジンへの送信、インデックス作成の確認などは行いません。

    これはサイトマップ URL が有効かどうかをチェックしますか?

    いいえ。URL 構文と貼り付けられた XML 内の重複をチェックしますが、意図的に URL を要求したり、サイトをクロールしたりすることはありません。

    有効なサイトマップとは、Google がそのページをインデックス付けしたことを意味しますか?

    いいえ。XML 検証は、検索エンジンの送信やインデックス作成レポートではありません。関連する検索エンジンのウェブマスター ツールを通じてサイトマップを送信し、そのステータスを確認します。

    サイトマップ インデックスを検証できますか?

    はい。このツールは、直接の sitemapindex エントリとその loc および lastmod フィールドをチェックしますが、参照されたサイトマップ ファイルのダウンロードや再帰的な検査は行いません。
