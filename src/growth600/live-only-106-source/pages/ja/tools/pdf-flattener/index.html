PDF フォーム フラットナー

サポートされている AcroForm フィールドを表示ページの外観にフラット化した別の PDF コピーを作成します。ページ上のテキストは引き続き選択および検索可能です。

フラット化により、新しいコピーのフォームの対話機能が削除されます。オリジナルを保管してください。既存のデジタル署名は無効化または削除される場合があります。これは署名検証ツールではありません。

ローカル制限: 25 MiB 入力、300 ページ、2,500 フィールド、および 50 MiB 出力。複雑な、暗号化されたフォーム、または XFA フォームはサポートされない場合があります。大きなファイルの場合はコンピュータを推奨します。

サポートされている AcroForm フィールドのみがフラット化されます。他のコメント、ハイライト、リンク、スタンプ、メタデータ、およびアクセシビリティ構造はフラット化されず、変更されないことが保証されません。

新しいコピーの準備ができました

フラット化されたコピーをダウンロード

このブラウザではオープンソースの pdf-lib ライブラリを使用します。元のファイルは決して変更されません。

PDF フォームをフラット化すると何をしますか?

サポートされている対話型フォーム フィールドの外観をページ コンテンツに描画し、それらの対話型フィールドを新しいコピーから削除します。これは、一般的なコメント、リンク、スタンプ、またはその他のマークアップ注釈をフラット化するものではありません。

よくある質問

PDF フォームをフラット化すると何をしますか?

サポートされている対話型フォーム フィールドの外観をページ コンテンツに描画し、それらの対話型フィールドを新しいコピーから削除します。これは、一般的なコメント、リンク、スタンプ、またはその他のマークアップ注釈をフラット化するものではありません。

私の PDF はアップロードされましたか?

いいえ。このブラウザで処理が実行されます。選択した PDF はサーバーに送信されず、自動的に保存されません。

フラット化されたコピーのフィールドを編集できますか?

いいえ。サポートされているフィールドはページの外観の一部となり、対話型ではなくなります。後で編集する必要がある場合に備えて、オリジナルを保存しておいてください。

コメント、ハイライト、デジタル署名はフラット化されますか?

いいえ。このツールは、サポートされている AcroForm フィールドのみを対象としています。他のマークアップ注釈はフラット化されず、デジタル署名は編集によって無効化または削除される可能性があります。認証された文書または法的に署名された文書にはこれを使用しないでください。

ページのテキストは引き続き検索可能ですか?

ページ コンテンツは画像に変換されないため、既存のページ テキストは引き続き検索可能です。フォームフィールドの外観はページコンテンツに統合されます。
