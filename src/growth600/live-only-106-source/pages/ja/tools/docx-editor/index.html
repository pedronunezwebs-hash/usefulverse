DOCX Editor

このブラウザーで、最新の Word DOCX ファイルに対して集中的なテキスト編集を行います。エディターはメイン文書内の既存のテキスト行を変更し、他の文書部分は変更しないままにします。 Word の完全な置き換えではないため、複雑な書式設定はここでプレビューされない場合があります。

最新の .docx のみ。最大 25 MiB、80 MiB 拡張パッケージ、8 MiB ドキュメント XML、500 テキスト セグメント、250,000 文字。サイズの大きいドキュメントはコンピュータでより適切に作業できます。

ファイルを選択すると、デバイス上で処理が行われます。アップロード、アカウント、API、自動保存、サーバー処理はありません。

この焦点を絞ったエディターは、メイン文書内の既存のテキストのみを変更します。スタイル、画像、その他のパッケージ部分のコンテンツは保持されますが、DOCX ZIP コンテナは再パックされます。ヘッダー、フッター、コメント、脚注、書式設定、段落構造、または追跡された変更は編集されません。マクロとデジタル署名されたパッケージはサポートされていません。

テキストプレビュー

DOCX ファイルの何を編集できますか?

最新の .docx ファイルの段落や表のセル内の既存のテキスト セグメントを編集し、テキストをプレビューして、編集したコピーをダウンロードできます。このエディターは、段落の追加または削除、書式設定の変更、ヘッダーまたはフッターの編集、または変更の追跡をサポートしません。

よくある質問

DOCX ファイルの何を編集できますか?

最新の .docx ファイルの段落や表のセル内の既存のテキスト セグメントを編集し、テキストをプレビューして、編集したコピーをダウンロードできます。このエディターは、段落の追加または削除、書式設定の変更、ヘッダーまたはフッターの編集、または変更の追跡をサポートしません。

Word 文書はアップロードされましたか?

いいえ。ファイルを選択すると、このブラウザでファイルが処理されます。アップロードされたり、自動的に保存されたり、サーバーに送信されたりすることはありません。

編集したファイルは既存のフォーマットを維持しますか?

テキスト スタイルとその他のパッケージ パーツのコンテンツは保持されます。テキストセグメントが置換されると、その既存の実行フォーマットは保持されます。このツールは、リッチ テキストの書式設定コントロールを提供したり、すべての Word 機能が同じように表示されることを保証したりするものではありません。

これは、追跡された変更、ヘッダー、または署名された文書を編集できますか?

いいえ。フォーカスされたエディターは、メイン文書内のテキストのみを変更します。変更追跡ワークフロー、ヘッダーとフッター、マクロ、およびデジタル署名されたファイルはサポートされていません。
