フリーセル

Move all 52 cards to their suit foundations. Use four free cells as temporary space, build descending alternating-color columns, and plan each supermove around the open cells and columns.

Leave blank for a fresh random deal. Use the same seed to recreate the same deal; it stays only in this page.

は: 0

Tableau cards build downward in alternating colors. A selected run must already alternate colors and descend by one rank. A supermove is limited by the currently empty free cells and helper columns.

Foundations build up from Ace to King in the same suit. Only the top card of a column or a card in a free cell can be moved.

How do you play FreeCell?

Build each foundation from Ace to King in one suit. On the tableau, build downward in alternating colors. A free cell can hold one card. You may move a valid descending alternating-color run as a supermove only when the available empty cells and helper columns can support it.

よくある質問

How do you play FreeCell?

Build each foundation from Ace to King in one suit. On the tableau, build downward in alternating colors. A free cell can hold one card. You may move a valid descending alternating-color run as a supermove only when the available empty cells and helper columns can support it.

Does FreeCell save my game?

No. The game runs in this browser tab. It does not use an account, upload moves or save a game automatically. A replay seed is optional and stays only in this page.

フリーセルのスーパームーブで移動できるカードは何枚ですか?

上限は、(空の空きセル + 1) に 2 を乗算して空のヘルパー列を乗じた値です。宛先列が空の場合、ヘルパーとしてカウントされません。ランも下降し、赤と黒を交互に行う必要があります。

フリーセルでシーケンスを直接移動できますか?

Yes, if the cards already form a descending alternating-color run and its size does not exceed the capacity provided by the empty free cells and helper columns. The game enforces this limit.

フリーセルの取引は再プレイ可能ですか?

Yes. Enter the same optional seed and choose a new deal to recreate its layout in this browser. Leave the seed blank for a random shuffle. No seed or game is sent to a server.
