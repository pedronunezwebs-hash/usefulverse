韻ファインダー

詩、詩、または単語リストを貼り付けて、文末を共有する単語をグループ化します。比較する最後の文字の数と、アクセントを無視するかどうかを選択します。

独自のテキストを貼り付けます。単語はブラウザ内で抽出されます。

オプション: é の上のマークは無視されるため、cafe とカフェは有効にすると一致します。

制限: 50,000 文字および 5,000 単語。結果は発音ではなくスペルを比較します。

結果

見つかったグループ: 0

一致するグループのない単語: 0

ローカルで実行します。テキストはアップロードまたは保存されません。

この韻ファインダーはどのように機能しますか?

最後に書かれた文字と一致することで単語をグループ化します。発音、強勢、音節は比較されないため、スペルの語尾が共通であっても、話されたときに単語が韻を踏むことが保証されるわけではありません。

よくある質問

この韻ファインダーはどのように機能しますか?

最後に書かれた文字と一致することで単語をグループ化します。発音、強勢、音節は比較されないため、スペルの語尾が共通であっても、話されたときに単語が韻を踏むことが保証されるわけではありません。

私の言葉はアップロードされていますか?

いいえ。テキストはこのブラウザで分析され、アップロードまたは保存されません。

これは単語の響きをチェックしますか?

いいえ。語尾のみを比較し、発音辞書や発音表記は使用しません。

どの言語の単語も使用できますか?

はい。 Unicode 文字はサポートされていますが、結果はスペルに基づいているため、その言語での単語の発音と一致しない場合があります。

詩全体を貼り付けることはできますか?

はい。ローカル入力は 50,000 文字および 5,000 単語に制限されています。
