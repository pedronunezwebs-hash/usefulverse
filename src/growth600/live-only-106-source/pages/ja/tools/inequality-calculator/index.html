不等式電卓

ゼロと比較した ax² + bx + c の形式で実一次または二次不等式を解きます。重要なポイント、間隔表記、および数直線の概要を参照してください。

定数、線形および二次の実不等式 ax² + bx + c <、≤、>、または ≥ 0 のみをサポートします。係数は有限であり、絶対値が最大 10⁹ である必要があります。計算には浮動小数点数が使用されるため、ルートは近似値になります。スケールベースの許容値は、繰り返されるルートの近くで使用されます。

結果

二次不等式はどうやって解くのですか?

多項式の実ゼロを見つけて、それらのゼロの間と外側の符号を決定します。このツールは、実解区間と各有限端点が含まれるかどうかを返します。

よくある質問

二次不等式はどうやって解くのですか?

多項式の実ゼロを見つけて、それらのゼロの間と外側の符号を決定します。このツールは、実解区間と各有限端点が含まれるかどうかを返します。

私の係数はアップロードされていますか?

いいえ。不等式はこのブラウザで計算され、このツールによってアップロードまたは保存されるものではありません。

音程表記は何を示していますか?

括弧はエンドポイントが除外されることを意味し、角括弧はエンドポイントが含まれることを意味します。 Infinity は実際のエンドポイントではないため、Infinity では常に括弧が使用されます。

三次不等式または有理不等式を解くことはできますか?

いいえ。この計算機は次数 0、1、または 2 の実多項式に限定されています。三次、有理、絶対値、または複合不等式は解決されません。

ルートは正確ですか?

いいえ。係数と根は浮動小数点演算を使用します。反復根に近い結果や係数サイズが大きく異なる結果は、丸めの影響を受ける可能性があります。
