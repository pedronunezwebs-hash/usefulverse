線形計画計算機

線形目的と最大 8 つの制約を入力して、x と y が負でない 2 変数線形計画法を解きます。 2 相シンプレックス法は、最適性、実行不可能性、または無限性を報告し、各ピボットを示します。

目的係数 (x, y)

1 行に 1 つ: a,b <= rhs、a,b >= rhs または a,b = rhs

最大 8 つの制約と、±1,000,000 以内の係数/右辺を使用します。どちらの決定変数も x ≥ 0 および y ≥ 0 です。x 係数と y 係数の間にはコンマを使用します。 1 行に 1 つの不等式または等式を入力します。

2 変数の 2 相主シンプレックス ソルバー。浮動小数点ピボットには数値許容差が使用されます。縮退に近い問題は丸めの影響を受けやすい可能性があります。発明された最適値の代わりに、実行不可能で、制限がなく、反復制限があるケースが報告されます。

線形計画結果

結果は、入力した数学モデルのみに関するものです。目的、制約、単位、または仮定が実際の意思決定に適切であるかどうかは検証されません。

    2 変数シンプレックス計算機はどのように機能しますか?

    制約を実行可能なタブローに変換し、必要に応じてフェーズ I 目標を使用し、主単体ピボットを適用して要求された目標を最適化します。変数 x と y は非負になるように制約されます。

    よくある質問

    2 変数シンプレックス計算機はどのように機能しますか?

    制約を実行可能なタブローに変換し、必要に応じてフェーズ I 目標を使用し、主単体ピボットを適用して要求された目標を最適化します。変数 x と y は非負になるように制約されます。

    私の目標と制約はアップロードされていますか?

    いいえ。ソルバーはこのブラウザで実行されます。目標と制約はサーバーに送信されたり、このツールによって保存されたりすることはありません。

    制約にはどのような形式を使用すればよいですか?

    1,1 <= 5 または 2,1 >= 4 のように、1 行に 1 行を入力します。最初の数値は x を乗算し、2 番目の数値は y を乗算します。両方の変数は非負でなければなりません。

    実行不可能、無制限とはどういう意味ですか?

    実行不可能とは、入力されたすべての制約を満たす点がないことを意味します。無制限とは、有限最適化を行わずに、要求された目標を改善し続けることができる実現可能な方向を意味します。

    この結果は、現実世界のモデルが正しいことを証明していますか?

    いいえ。入力した方程式のみを解きます。単位、前提条件、および制約が決定を適切に説明しているかどうかを確認してください。
