腕立て伏せテストとセット記録

単一のセットを単純なテストとして記録するか、残りを間に挟んで複数のセットを記録します。繰り返しを数えて入力します。このツールはカメラを使用したり、強さをランク付けしたりすることはありません。

0 ～ 500 の整数カウントを最大 20 個入力します。空白行は無視され、セットとしてカウントされません。選択したフォームで完了した繰り返しのみをカウントします。

一般的なメモを保管してください。これは医療記録ではありません。

快適な可動範囲を選択し、痛み、めまい、または異常な息切れを感じた場合は停止してください。レップ数はフォーム、ペース、テスト条件によって異なります。このツールは、フィットネスの評価、診断、または運動の処方箋を提供するものではありません。

保存はオプションであり、このブラウザのみを使用します。チェックを外すと保存せずに計算するか、以下の保存された履歴をクリアします。

あなたのセッション

腕立て伏せテスト トラッカーの合計反復回数はどのように計算されますか?

空ではない各セットに入力された整数の繰り返しを加算します。空白行は無視され、ゼロのセットはゼロのままであり、休憩の推定値は休憩ごとの休憩に休憩の数を乗算したものになります。

よくある質問

腕立て伏せテスト トラッカーの合計反復回数はどのように計算されますか?

空ではない各セットに入力された整数の繰り返しを加算します。空白行は無視され、ゼロのセットはゼロのままであり、休憩の推定値は休憩ごとの休憩に休憩の数を乗算したものになります。

私の腕立て伏せセットはアップロードされていますか?

いいえ。計算はこのブラウザで実行されます。セッション履歴は、オプトインした後にのみこのデバイスに書き込まれます。ここで削除できます。

空白行はセットまたは繰り返しとしてカウントされますか?

いいえ。空行は無視されます。 0 の行はゼロの繰り返しセットを記録し、合計に繰り返しは追加されません。

最大1セットまたは複数セットで使用できますか?

はい。手動でカウントされた 1 つのセットに対して 1 行を入力するか、セットとその間の残りを要約するために複数行を入力します。テスト条件はあなた次第です。結果は母集団の標準と比較されません。

私のトレーニング履歴はアップロードされていますか?

いいえ。履歴はオプションであり、このデバイス上のこのブラウザーに残ります。いつでも削除ボタンで消去してください。
