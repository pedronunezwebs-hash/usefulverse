ウィークリー プランナー

仕事、個人的な計画、勉強、または健康のための単純な週単位のスケジュールを作成します。夜間のブロックとスケジュールの競合が明確に表示されます。

毎週の繰り返しプランでは、ローカルの実時間を使用します。タイムゾーン、夏時間の変更、カレンダーのイベント、リマインダーは考慮されません。

計画はこのタブのメモリに残ります。 JSON バックアップをダウンロードして保存します。自動ストレージやアップロードはありません。

週間スケジュール

毎週のスケジュールを立てるにはどうすればよいですか?

各ブロックにタイトル、日付、開始時刻、終了時刻、カテゴリを追加します。ブロックは真夜中を越えることがあります。日曜日と月曜日をまたぐ場合も含め、重複する時間にはフラグが付けられます。

よくある質問

毎週のスケジュールを立てるにはどうすればよいですか?

各ブロックにタイトル、日付、開始時刻、終了時刻、カテゴリを追加します。ブロックは真夜中を越えることがあります。日曜日と月曜日をまたぐ場合も含め、重複する時間にはフラグが付けられます。

私の週間スケジュールはアップロードまたは保存されていますか?

いいえ。JSON バックアップをダウンロードすることを選択しない限り、スケジュールはこのブラウザー タブに表示されます。選択したバックアップをデバイスからインポートします。

週間プランナーに夜勤を含めることはできますか?

はい。翌日に終了するブロックを作成するには、開始時刻より前の終了時刻を選択します。最大 18 時間のブロックがサポートされます。

週次スケジュールは競合を検出しますか?

はい。月曜日と重なる日曜日のブロックを含む、同日および午前 0 時をまたぐ時間ブロックをチェックします。

このプランナーは Google カレンダーと同期しますか?

いいえ。このタブではローカルに動作し、カレンダー接続やリマインダー サービスはありません。計画を印刷したり、JSON バックアップをダウンロードしてインポートしたりできます。
