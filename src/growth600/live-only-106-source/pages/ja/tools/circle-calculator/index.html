円計算機

半径、直径、面積、円周から円を計算します。中心角の円弧と扇形の測定を調べたり、弦と矢線を含む円セグメントを計算したりできます。

0 ～ 360 度の角度を使用します。数式はそれをラジアンに変換します。

JavaScript 値 π の正円公式を使用します。表示される小数点以下は四捨五入されます。円形セグメントは選択した中心角を使用します。180° 未満は副セグメント、180° を超えると主セグメントです。入力は、最大 10¹² の正の値と 0° ～ 360° の角度に制限されます。

結果

円はどのように計算しますか?

半径rの場合、直径は2r、円周は2πr、面積はπr²となります。ラジアン単位の中心角 θ の場合、円弧の長さは rθ、扇形の面積は r²θ/2 です。この計算機は、入力された角度を度単位でラジアンに変換して、数式を計算します。

よくある質問

円はどのように計算しますか?

半径rの場合、直径は2r、円周は2πr、面積はπr²となります。ラジアン単位の中心角 θ の場合、円弧の長さは rθ、扇形の面積は r²θ/2 です。この計算機は、入力された角度を度単位でラジアンに変換して、数式を計算します。

私の測定値はアップロードされていますか?

いいえ。数式はこのブラウザで実行され、このツールは測定値をアップロードまたは保存しません。

半径1の円の面積と円周はいくらですか?

面積はπ（約3.14159）、円周は2π（約6.28318）です。結果は表示のために四捨五入されています。

円弧の長さを計算するにはどうすればよいですか?

半径にラジアン単位の中心角を掛けます。このツールは度を受け入れ、計算する前に変換します。

セクターとセグメントの違いは何ですか?

セクターは 2 つの半径と 1 つの円弧によって境界されます。セグメントは弦とその円弧によって境界付けられます。ここではその面積が中心角から計算されます。
