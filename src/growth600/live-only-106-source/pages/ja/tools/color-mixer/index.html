カラーミキサー

編集可能なウェイトを使用してカラーをブレンドし、2 つのデジタル混合モードを比較し、最初の 2 つのカラーの間にスウォッチ ランプを構築します。何もアップロードされていません。

混ぜる色

選択した方法は結果に影響します。 sRGB は表示されたチャネル値をブレンドします。リニアライトは混合する前にチャンネルを変換します。

これはデジタル画面の色を予測するものであり、実際の絵の具や顔料がどのように混合するかを予測するものではありません。

このブラウザで実行されます。カラーはアップロードされず、自動的に保存されません。

カラーランプ

オンラインで 2 つの色を混ぜるにはどうすればよいですか?

2 つ以上の色を選択し、それぞれの重みを設定し、sRGB またはリニアライト混合を選択します。結果には、HEX、RGB、および HSL 値が表示されます。

よくある質問

オンラインで 2 つの色を混ぜるにはどうすればよいですか?

2 つ以上の色を選択し、それぞれの重みを設定し、sRGB またはリニアライト混合を選択します。結果には、HEX、RGB、および HSL 値が表示されます。

私のカラーはアップロードされていますか?

いいえ。色の計算はブラウザ内でローカルに実行されます。アカウントや画像のアップロードは必要ありません。

sRGB とリニアライトの混合が異なって見えるのはなぜですか?

sRGB は、エンコードされたスクリーン チャネル値を平均します。リニアライト モードでは、まずライト値に変換し、混合してから逆変換します。選択した方法によって結果が変わります。

これで混合塗料の色を予測できますか?

いいえ。これは画面のデジタル カラー計算であり、物理的な色素モデルではありません。実際のペイントは、顔料の特性、透明度、濃度、照明、および表面に依存します。

どのようなカラー形式をコピーできますか?

結果には HEX、RGB、および HSL が表示されます。 HEX 値をコピーするか、小さな CSS カラー パレットをダウンロードできます。
