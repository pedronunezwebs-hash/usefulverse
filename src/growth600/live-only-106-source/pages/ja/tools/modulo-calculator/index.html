モジュロ計算機

整数のユークリッド商と余りを計算します。負の入力は一貫して処理され、除算恒等式は答えがどのように形成されるかを示します。

除算する数値。 it may be negative.

ゼロ以外の任意の整数を使用します。その絶対値が係数を定義します。

この値が除数を法とした被除数に一致するかどうかを確認します。

最大 50 桁の符号付き整数を受け入れます。分数や小数は使用できません。結果にはユークリッド剰余が使用されます。一部のプログラミング言語では、負数に対して異なる剰余規則が使用されます。

結果

負の数のモジュロを計算するにはどうすればよいですか?

この計算機は、絶対除数より小さい非負の剰余を使用します。たとえば、−7 = (−3 × 3) + 2 であるため、−7 mod 3 は 2 になります。

よくある質問

負の数のモジュロを計算するにはどうすればよいですか?

この計算機は、絶対除数より小さい非負の剰余を使用します。たとえば、−7 = (−3 × 3) + 2 であるため、−7 mod 3 は 2 になります。

私の番号はアップロードされていますか?

いいえ。正確な計算はこのブラウザで実行されます。番号はアップロードまたは保存されません。

−7 mod 3とは何ですか?

ユークリッドの規則を使用すると、−7 mod 3 は 2: −7 = (−3 × 3) + 2、および 0 ≤ 2 < 3 となります。

合同法 m とはどういう意味ですか?

2 つの整数は、その差が |m| で割り切れる場合、m を法として合同です。オプションの比較では、これを正確にチェックします。

これがプログラミング言語の % 演算子と異なるのはなぜですか?

一部の言語では、剰余に負の被除数の符号が保持されます。この計算機は代わりに、0 から絶対除数まで (絶対除数は含まない) の剰余を返します。
