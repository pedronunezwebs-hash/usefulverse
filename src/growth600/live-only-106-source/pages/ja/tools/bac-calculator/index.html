BAC電卓

体重、飲み物のサイズ、体力を入力すると、不確実性の高い数学的シナリオが表示されます。これは血中アルコール濃度の測定値または信頼できる予測ではありません。

この推定値を、運転、機械の操作、または医学的または法的判断ができるかどうかを判断するために使用しないでください。これは呼気/血液検査、診断、または信頼できる予測ではありません。アルコールは運転に支障をきたす可能性があります。飲酒した場合は車の運転をせず、しらふの運転を手配してください。誰かが意識を失っている、目覚めにくい、発作を起こしている、または呼吸が遅い/不規則である場合は、今すぐ地元の救急サービスに連絡してください。

現在のおおよその重量を入力します。このツールを選択すると、ポンドがキログラムに変換されます。 ドリンクの種類を8種類まで入力できます。アルコールがない場合はカウント 0 を使用します。各列は同一の分量と強度を想定しています。

この BAC シナリオはどのように機能しますか?

飲料のエントリをエタノールのグラムに変換し、広範な仮定を使用して単純化された Widmark スタイルの分布推定を適用し、その後、経過時間に基づいて例示的な広範な除去範囲を減算します。即時吸収を前提としており、あなたの体や各飲み物のタイミングをモデル化することはできません。

よくある質問

この BAC シナリオはどのように機能しますか?

飲料のエントリをエタノールのグラムに変換し、広範な仮定を使用して単純化された Widmark スタイルの分布推定を適用し、その後、経過時間に基づいて例示的な広範な除去範囲を減算します。即時吸収を前提としており、あなたの体や各飲み物のタイミングをモデル化することはできません。

私のエントリーはアップロードされましたか?

いいえ。計算はこのブラウザで実行されます。エントリはサーバーにアップロード、保存、送信されません。

これで安全に運転できるかどうかわかりますか?

いいえ、その決定をするために決して電卓を使用しないでください。 BAC の推定値にはかなりの不確実性があり、障害は法定限度以下で始まる可能性があり、最後の飲酒後もアルコールが吸収される可能性があります。飲酒した場合は運転しないでください。地味な乗車を手配します。

結果は私の実際の血中アルコール濃度ですか?

いいえ。これは単純化されたウィドマーク スタイルの図であり、テストや信頼できる予測ではありません。身体組成、吸収、食べ物、健康、薬、飲むタイミング、その他多くの要素は、これらのエントリからはわかりません。

広範囲が表示されるのはなぜですか?

分布と消去の仮定は人によって大きく異なります。この範囲は例示的なものであり、実際の測定値がその範囲内に収まることを保証するものではありません。
