XML से CSV कन्वर्टर

एक साधारण XML रिकॉर्ड सूची को CSV तालिका में बदलें, या CSV फ़ाइल के टेक्स्ट से XML रिकॉर्ड बनाएं। दिशा चुनें, अपना डेटा पेस्ट करें, फिर परिणाम कॉपी करें या डाउनलोड करें। कुछ भी अपलोड नहीं किया गया है.

समान नाम वाले रिकॉर्ड तत्वों या एक फ्लैट रिकॉर्ड की एक सरल सूची का समर्थन करता है। तत्व बच्चों का अदिश मान होना चाहिए; नेस्टेड और दोहराए गए फ़ील्ड समतल नहीं होते हैं।

कॉलम नामों के लिए पहली पंक्ति का उपयोग करें। @id जैसा हेडर एक XML विशेषता बन जाता है। रिकॉर्ड टेक्स्ट के लिए #text का उपयोग करें।

यह एक साधारण तालिका रूपांतरण है, दोषरहित XML प्रारूप रूपांतरण नहीं। नामस्थान, नेस्टेड संरचनाएं, मिश्रित सामग्री, टिप्पणियाँ और XML स्वरूपण संरक्षित नहीं हैं। टेक्स्ट टाइप-अवेयर नहीं है. स्प्रेडशीट फ़ॉर्मूला-जैसे CSV मानों को सुरक्षा के लिए एक एपोस्ट्रोफ़ के साथ उपसर्ग किया जाता है।

परिणाम

किसी अन्य एप्लिकेशन में आयात करने से पहले आउटपुट की जांच करें।

मैं XML को CSV में कैसे परिवर्तित करूं?

XML को CSV में चुनें और XML को एक साधारण रिकॉर्ड सूची के साथ पेस्ट करें। बार-बार दोहराए गए प्रत्यक्ष रिकॉर्ड तत्व पंक्तियाँ बन जाते हैं। तत्व नाम स्तंभ बन जाते हैं; विशेषताएँ @name का उपयोग करती हैं। हेडर और पंक्तियों से सरल XML रिकॉर्ड बनाने के लिए CSV से XML चुनें।

मैं XML को CSV में कैसे परिवर्तित करूं?

XML को CSV में चुनें और XML को एक साधारण रिकॉर्ड सूची के साथ पेस्ट करें। बार-बार दोहराए गए प्रत्यक्ष रिकॉर्ड तत्व पंक्तियाँ बन जाते हैं। तत्व नाम स्तंभ बन जाते हैं; विशेषताएँ @name का उपयोग करती हैं। हेडर और पंक्तियों से सरल XML रिकॉर्ड बनाने के लिए CSV से XML चुनें।

क्या मेरा XML या CSV अपलोड किया गया है?

नं. इस ब्राउज़र में पार्सिंग और रूपांतरण चलता है। इनपुट 200,000 वर्ण, 5,000 पंक्तियाँ, 64 कॉलम और 20,000 सेल तक सीमित है। डीटीडी और इकाई घोषणाएं अवरुद्ध हैं, और बाहरी संसाधन नहीं लाए गए हैं।

CSV में XML विशेषताएँ कैसे दिखाई जाती हैं?

id='101' जैसी एक विशेषता @id नामक कॉलम बन जाती है। वापस कनवर्ट करते समय, @ से शुरू होने वाला CSV हेडर एक XML विशेषता बन जाता है।

क्या यह नेस्टेड XML को एक फ्लैट टेबल में बदल सकता है?

नहीं, नेस्टेड चाइल्ड संरचनाएं, रिकॉर्ड के अंदर दोहराए गए फ़ील्ड और मिश्रित पाठ को चपटा या चुपचाप खो जाने के बजाय अस्वीकार कर दिया जाता है। नेस्टेड डेटा के लिए समर्पित XML-टू-JSON वर्कफ़्लो का उपयोग करें।

क्या CSV XML प्रकार और फ़ॉर्मेटिंग को सुरक्षित रखेगा?

नहीं। CSV सेल टेक्स्ट को संग्रहीत करता है, XML प्रकार, नामस्थान या फ़ॉर्मेटिंग को नहीं। स्प्रेडशीट फॉर्मूला निष्पादन जोखिम को कम करने के लिए निर्यात किए जाने पर फॉर्मूला-जैसे सेल मानों को एपॉस्ट्रॉफी उपसर्ग मिलता है।
