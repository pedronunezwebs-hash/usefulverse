Memory Test

تدرب على تذكر تسلسل متزايد من الأرقام أو المواضع على شبكة 3×3. تضيف كل جولة صحيحة عنصرًا واحدًا.

تدريب فقط. هذا ليس اختبار الذكاء أو التشخيص أو التقييم المعرفي المعتمد. النتائج ليس لها معنى سريري أو سكاني.

بالنسبة لقارئات الشاشة، اختر نطاق الأرقام: يتم الإعلان عن كل رقم مرة واحدة أثناء التشغيل. يعتمد وضع النمط المرئي على البصر.

طول التسلسل التالي: 3

عنصر التسلسل: —

إجابتك

لم يتم إدخال أي عناصر بعد.

الجولات الصحيحة: 0

اختر الوضع والسرعة، ثم ابدأ.

Test result

كيف يعمل اختبار الذاكرة هذا؟

اختر الأرقام أو الشبكة المرئية وسرعة العرض. شاهد التسلسل أو استمع إليه مرة واحدة، ثم أدخله بنفس الترتيب. تصبح الجولات الصحيحة أطول، حتى 12 عنصرًا. هذه لعبة تدريب عادية، وليست تقييمًا موحدًا للذاكرة.

الأسئلة الشائعة

كيف يعمل اختبار الذاكرة هذا؟

اختر الأرقام أو الشبكة المرئية وسرعة العرض. شاهد التسلسل أو استمع إليه مرة واحدة، ثم أدخله بنفس الترتيب. تصبح الجولات الصحيحة أطول، حتى 12 عنصرًا. هذه لعبة تدريب عادية، وليست تقييمًا موحدًا للذاكرة.

هل يحفظ اختبار الذاكرة هذا نتيجتي؟

لا. يبقى التسلسل والنتيجة في هذه الصفحة أثناء فتحها. لم يتم تحميل أي شيء، ولا يوجد حساب أو تصنيف عبر الإنترنت.

ما الذي يقيسه اختبار الذاكرة هذا؟

إنها لعبة تدريب غير رسمية على استدعاء التسلسل. إنه غير موحد ولا يمكنه تشخيص حالة ما أو قياس معدل الذكاء.

كيف يختلف نطاق الأرقام ووضع النمط؟

الأرقام واحدًا تلو الآخر ويعلن عنها للوصول إلى قارئ الشاشة. يومض وضع النمط المواضع على شبكة 3 × 3 ويتطلب البصر.

هل يتم حفظ النتائج أو مقارنتها بأشخاص آخرين؟

لا. النتائج موجودة فقط عندما تظل هذه الصفحة مفتوحة. لا يوجد تحميل للمتصدرين أو الحساب أو الخادم.
