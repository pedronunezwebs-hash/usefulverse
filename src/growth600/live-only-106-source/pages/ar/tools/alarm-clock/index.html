المنبه عبر الإنترنت

اضبط منبهًا واحدًا لفترة في الأيام السبعة القادمة. أبقِ هذه الصفحة مفتوحة وجهازك نشطًا؛ إنذارات المتصفح ليست بديلاً لإنذار النظام.

اترك هذه الصفحة مفتوحة والجهاز نشطًا. يمكن أن يؤدي اختناق المتصفح أو وضع السكون أو إيقاف التشغيل أو مشكلات الاتصال/الجهاز إلى تأخير الإنذار أو منعه. استخدم إنذار النظام لأي شيء مهم.

المنبه يرن.

كيف أقوم بضبط المنبه على الإنترنت؟

اختر تاريخًا ووقتًا مستقبليًا حسب المنطقة الزمنية المحلية لجهازك، ثم حدد ضبط المنبه. الصوت اختياري. يمكنك اختباره أولاً، أو الغفوة لمدة خمس دقائق أو إيقافه عندما يرن.

الأسئلة الشائعة

اختر تاريخًا ووقتًا مستقبليًا حسب المنطقة الزمنية المحلية لجهازك، ثم حدد ضبط المنبه. الصوت اختياري. يمكنك اختباره أولاً، أو الغفوة لمدة خمس دقائق أو إيقافه عندما يرن.

هل هذا التنبيه يرسل بيانات أو يعمل بعد إغلاق الصفحة؟

لا يتم إرسال أو حفظ أي بيانات. يتم تشغيل المنبه في هذه الصفحة فقط ولا يمكنه تنبيهك بشكل موثوق في حالة إغلاق علامة التبويب أو قيام المتصفح بإيقافها مؤقتًا أو دخول الجهاز في وضع السكون.

هل سيرن المنبه إذا قمت بإغلاق علامة التبويب؟

لا. هذا إنذار داخل الصفحة، وليس إنذار أو إعلام لنظام التشغيل. أبقِ الصفحة مفتوحة والجهاز نشطًا؛ وللتذكيرات المهمة، استخدم تطبيق المنبه الخاص بجهازك.

هل يمكنني تأجيل المنبه؟

نعم. عندما يرن، اختر غفوة لمدة 5 دقائق لجدولتها مرة أخرى من الوقت الحالي.

هل يستخدم المنبه موقعي أو يوفر وقتي؟

لا. يستخدم التوقيت المحلي الذي تم تكوينه على جهازك. يتم عقد التنبيه فقط في الصفحة المفتوحة ولا يتم تحميله أو حفظه.
