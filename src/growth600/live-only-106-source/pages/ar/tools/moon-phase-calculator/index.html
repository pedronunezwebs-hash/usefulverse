اختر تاريخًا لتقدير مرحلة القمر وإضاءته، ثم شاهد اللحظات التقريبية للقمر الجديد وربع القمر واكتماله لهذا الشهر بالتوقيت العالمي المنسق.

لا يوجد إذن موقع أو تحميل أو حساب أو API أو حفظ تلقائي.

دورة مجمعية متوسطة مرتبطة بقمر مرجعي جديد، وليس تقويمًا فلكيًا كاملاً. يمكن أن تختلف أوقات المرحلة الفردية حسب الساعات ويمكن أن يختلف تاريخ UTC المعروض عن تاريخ التقويم المحلي. تقدير المرحلة العالمية هذا لا يحسب تواريخ شروق القمر أو غروبه أو رؤيته أو التقويم الديني المحلي.

No. تستخدم هذه الأداة خفيفة الوزن دورة قمرية متوسطة. يمكن أن تختلف الأوقات الفعلية للمرحلة الأولية بعدة ساعات، لذا لا تستخدمها كتقويم فلكي أو للمراقبة ذات الوقت الحرج.

No. ولا يتنبأ برؤية الهلال أو يحدد بداية الشهر الديني. اتبع السلطة المحلية ذات الصلة أو التقويم.
