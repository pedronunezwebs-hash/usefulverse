مدقق خريطة الموقع

قم بلصق مستند XML لخريطة الموقع للتحقق من بنيته وإدخالات URL والتواريخ والحقول المشتركة. يتم تحليل XML في هذا المتصفح فقط؛ لا يتم جلب الصفحات المدرجة أبدًا.

يدعم urlset القياسي أو sitemapindex. الحد الأقصى 1,000,000 حرف و5,000 إدخال مباشر.

عمليات فحص XML المحلية فقط: لا يتطلب ذلك عناوين URL المدرجة، أو الزحف إلى الموقع، أو إرسال خريطة الموقع، أو ضمان الفهرسة.

ملخص التحقق من الصحة

النتائج

    ما الذي يتحقق منه مدقق خريطة الموقع هذا؟

    يقوم بالتحقق من إدخالات urlset أو sitemapindex، ومواقع HTTP أو HTTPS المطلقة، وعناوين URL المكررة، وتواريخ lastmod، وقيم التغيير الاختيارية والأولوية، ومساحة اسم خريطة الموقع. يتم سرد التحذيرات والأخطاء حسب رقم الإدخال.

    الأسئلة الشائعة

    ما الذي يتحقق منه مدقق خريطة الموقع هذا؟

    يقوم بالتحقق من إدخالات urlset أو sitemapindex، ومواقع HTTP أو HTTPS المطلقة، وعناوين URL المكررة، وتواريخ lastmod، وقيم التغيير الاختيارية والأولوية، ومساحة اسم خريطة الموقع. يتم سرد التحذيرات والأخطاء حسب رقم الإدخال.

    هل يقوم بتحميل أو إرسال خريطة الموقع الخاصة بي؟

    لا. تتم معالجة ملف XML محليًا في متصفحك. لا تقوم الأداة بالزحف إلى عناوين URL أو جلب ملفات خريطة الموقع البعيدة أو إرسال أي شيء إلى محرك بحث أو تأكيد الفهرسة.

    هل يتحقق هذا مما إذا كان عنوان URL لخريطة الموقع نشطًا؟

    لا. فهو يتحقق من بناء جملة URL والنسخ المكررة داخل ملف XML الملصق، ولكنه لا يطلب عناوين URL أو يزحف إلى الموقع عمدًا.

    هل خريطة الموقع الصالحة تعني أن Google قام بفهرسة صفحاته؟

    لا. التحقق من صحة XML ليس تقرير إرسال أو فهرسة لمحرك البحث. قم بإرسال خريطة الموقع من خلال أداة مشرفي المواقع لمحرك البحث ذات الصلة وتحقق من حالتها.

    هل يمكنني التحقق من صحة فهرس خريطة الموقع؟

    نعم. تتحقق الأداة من إدخالات sitemapindex المباشرة وحقول loc وlastmod الخاصة بها، ولكنها لا تقوم بتنزيل ملفات خريطة الموقع المشار إليها أو فحصها بشكل متكرر.
