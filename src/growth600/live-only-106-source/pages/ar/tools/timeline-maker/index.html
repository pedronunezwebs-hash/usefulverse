هذا جدول زمني للحدث، وليس جدول مهمة/تبعية أو مصدرًا للحقائق التاريخية. أدخل التواريخ التي قمت بالتحقق منها.

تبقى أسماء الأحداث وتواريخها في علامة التبويب هذه. لا يتم تحميل أي شيء أو حفظه تلقائيًا. يتم إنشاء الصادرات محليا.

الأسئلة الشائعة

كيف أقوم بعمل جدول زمني للحدث؟

أضف حدثين مسميين على الأقل واختر تاريخ بدء لكل منهما. أضف تاريخ انتهاء لمدة أو اتركه فارغًا لحدث ليوم واحد. أنشئ مخططًا زمنيًا لفرز الأحداث حسب التاريخ، وضبط التكبير/التصغير، وتنزيل ملفات SVG أو CSV.

هل تم تحميل أحداث الجدول الزمني الخاص بي؟

لا. تتم معالجة الأسماء والتواريخ في علامة تبويب المتصفح هذه. يتم إنشاء SVG وCSV على جهازك؛ لا يتم تحميل أي شيء أو حفظه تلقائيًا.

هل يمكن أن يستمر الحدث لأكثر من يوم واحد؟

نعم. أدخل تاريخ البدء والانتهاء. يتضمن المخطط تواريخ نقطة النهاية؛ اترك النهاية فارغة لحدث ليوم واحد.

هل يقوم هذا المخطط الزمني بإنشاء تبعيات المهام؟

رقم. يعرض الأحداث المؤرخة ويتراوح بالترتيب الزمني. استخدم أداة جدول المشروع للمهام والمدد والتبعيات.

هل يمكنني حفظ الجدول الزمني أو مشاركته؟

قم بتنزيل SVG لصورة قابلة للتحجيم أو CSV لجدول الأحداث. لا تقوم الصفحة بتحميل بيانات الأحداث الخاصة بك أو حفظها تلقائيًا.
