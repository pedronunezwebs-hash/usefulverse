XML لتحويل CSV

قم بتحويل قائمة سجلات XML بسيطة إلى جدول CSV، أو أنشئ سجلات XML من نص ملف CSV. اختر الاتجاه، والصق بياناتك، ثم انسخ النتيجة أو قم بتنزيلها. لم يتم تحميل أي شيء.

يدعم قائمة بسيطة من عناصر السجل التي تحمل نفس الاسم، أو سجل واحد ثابت. يجب أن تكون العناصر الفرعية قيمًا عددية؛ لا يتم تسوية الحقول المتداخلة والمتكررة.

استخدم الصف الأول لأسماء الأعمدة. يصبح الرأس مثل @id سمة XML. استخدم #text لتسجيل النص.

هذا تحويل جدول بسيط، وليس تحويل تنسيق XML بدون فقدان البيانات. لا يتم الاحتفاظ بمساحات الأسماء والهياكل المتداخلة والمحتوى المختلط والتعليقات وتنسيق XML. النص ليس على علم بالنوع. تكون قيم CSV المشابهة لصيغة جدول البيانات مسبوقة بفاصلة عليا للسلامة.

نتيجة

تحقق من الإخراج قبل استيراده إلى تطبيق آخر.

كيف يمكنني تحويل XML إلى CSV؟

اختر XML إلى CSV والصق XML بقائمة تسجيل بسيطة. عناصر السجل المباشر المتكررة تصبح صفوفًا. تصبح أسماء العناصر أعمدة؛ تستخدم السمات @name. اختر CSV إلى XML لإنشاء سجلات XML بسيطة من الرؤوس والصفوف.

الأسئلة الشائعة

كيف يمكنني تحويل XML إلى CSV؟

اختر XML إلى CSV والصق XML بقائمة تسجيل بسيطة. عناصر السجل المباشر المتكررة تصبح صفوفًا. تصبح أسماء العناصر أعمدة؛ تستخدم السمات @name. اختر CSV إلى XML لإنشاء سجلات XML بسيطة من الرؤوس والصفوف.

هل تم تحميل XML أو CSV الخاص بي؟

لا. يتم تشغيل التحليل والتحويل في هذا المتصفح. يقتصر الإدخال على 200000 حرف و5000 صف و64 عمودًا و20000 خلية. يتم حظر إعلانات DTD والكيانات، ولا يتم جلب الموارد الخارجية.

كيف يتم عرض سمات XML في ملف CSV؟

تصبح السمة مثل id = "101" عمودًا يسمى @id. عند التحويل مرة أخرى، يصبح رأس CSV الذي يبدأ بـ @ سمة XML.

هل يمكن تحويل XML المتداخل إلى جدول مسطح؟

رقم. يتم رفض الهياكل الفرعية المتداخلة والحقول المتكررة داخل السجل والنص المختلط بدلاً من تسويتها أو فقدانها بصمت. استخدم سير عمل XML-to-JSON مخصصًا للبيانات المتداخلة.

هل سيحتفظ ملف CSV بأنواع XML وتنسيقاتها؟

لا. يقوم ملف CSV بتخزين نص الخلية، وليس أنواع XML أو مساحات الأسماء أو التنسيق. تحصل قيم الخلايا المشابهة للصيغة على بادئة بفاصلة عليا عند تصديرها لتقليل مخاطر تنفيذ صيغة جدول البيانات.
