حاسبة المتباينات

حل المتباينات الحقيقية الخطية أو التربيعية بالصورة ax² + bx + c مقارنة بالصفر. اعرض النقاط الحرجة وترميز الفترات وملخصًا على خط الأعداد.

تدعم الأداة المتباينات الحقيقية الثابتة أو الخطية أو التربيعية ax² + bx + c < أو ≤ أو > أو ≥ 0 فقط. يجب أن تكون المعاملات أعدادًا منتهية لا يتجاوز مقدارها المطلق 10⁹. الجذور تقريبية لأن الحساب يستخدم أعداد الفاصلة العائمة. يُستخدم حد نسبي قرب الجذور المكررة.

النتائج

كيف تحل متباينة تربيعية؟

أوجد الأصفار الحقيقية لكثير الحدود ثم حدد إشارته بينها وخارجها. تعرض الأداة فترات الحل الحقيقية وتوضح ما إذا كان كل طرف منتهٍ مشمولًا.

الأسئلة الشائعة

كيف تحل متباينة تربيعية؟

أوجد الأصفار الحقيقية لكثير الحدود ثم حدد إشارته بينها وخارجها. تعرض الأداة فترات الحل الحقيقية وتوضح ما إذا كان كل طرف منتهٍ مشمولًا.

هل يتم تحميل المعاملات؟

لا. تُحسب المتباينة في هذا المتصفح ولا ترفعها الأداة أو تحفظها.

ماذا يوضح ترميز الفترات؟

تعني الأقواس الدائرية أن الطرف غير مشمول، وتعني الأقواس المربعة أنه مشمول. تستخدم اللانهاية دائمًا أقواسًا دائرية لأنها ليست طرفًا حقيقيًا.

هل يمكنني حل المتباينات التكعيبية أو الكسرية؟

لا. هذه الحاسبة محدودة بكثيرات الحدود الحقيقية من الدرجة صفر أو واحد أو اثنين. لا تحل المتباينات التكعيبية أو الكسرية أو المطلقة أو المركبة.

هل الجذور دقيقة؟

لا. تستخدم المعاملات والجذور حساب الفاصلة العائمة. قد تتأثر النتائج قرب الجذور المكررة أو عندما تختلف أحجام المعاملات كثيرًا بالتقريب.

الرئيسية

أدوات مجانية عبر المتصفح. تبقى بياناتك على جهازك عندما تسمح الأداة بذلك.
