مولد الجدول تخفيض السعر

قم بإنشاء جدول Markdown في شبكة صغيرة قابلة للتحرير. قم باستيراد نص مفصول بفواصل، أو مفصول بفاصلة منقوطة، أو مفصول بعلامات جدولة، واختر محاذاة الأعمدة، وانسخ Markdown العادي باستخدام الأنابيب التي تم الهروب منها بأمان.

يتم دعم حقول CSV المقتبسة. يستبدل الاستيراد الشبكة الحالية؛ ما يصل إلى 100 صف و20 عمودًا و250000 حرف.

يصبح الصف الأول هو رأس Markdown. أضف صفًا واحدًا وعمودًا واحدًا على الأقل.

خلايا الجدول القابلة للتحرير

يقوم بإنشاء جدول أنابيب قياسي برأس وصف فاصل. تصبح فواصل أسطر الخلية <br>؛ يتم الهروب من أنابيب Markdown والخطوط المائلة العكسية.

تبقى جميع عمليات المعالجة في علامة التبويب هذه. لا يوجد تحميل أو حساب أو واجهة برمجة تطبيقات أو حفظ تلقائي أو معالجة الخادم.

تم إنشاء تخفيض السعر

معاينة الجدول المقدمة

كيف أقوم بعمل جدول Markdown؟

أدخل صف الرأس وصفوف البيانات، واختر محاذاة كل عمود، ثم انسخ Markdown الذي تم إنشاؤه. يتم هروب الأنابيب ويتم تعبئة الصفوف المستوردة غير المستوية.

الأسئلة الشائعة

كيف أقوم بعمل جدول Markdown؟

أدخل صف الرأس وصفوف البيانات، واختر محاذاة كل عمود، ثم انسخ Markdown الذي تم إنشاؤه. يتم هروب الأنابيب ويتم تعبئة الصفوف المستوردة غير المستوية.

هل تم تحميل الجدول الخاص بي؟

لا. تتم معالجة الجدول الخاص بك في علامة تبويب المتصفح هذه. لا يتم إرسال عمليات الاستيراد والتحرير وإنشاء Markdown إلى الخادم أو حفظها تلقائيًا.

هل يمكنني استيراد ملف CSV أو TSV؟

نعم. قم بلصق قيم مفصولة بفواصل، أو مفصولة بفواصل منقوطة، أو مفصولة بعلامات جدولة، ثم قم باستيرادها إلى الشبكة القابلة للتحرير. يتم دعم حقول CSV المقتبسة والفواصل المقتبسة.

كيف يتم التعامل مع الأنابيب وفواصل الأسطر؟

يتم هروب الأنبوب الموجود داخل الخلية بحيث لا يؤدي إلى تقسيم جدول Markdown. يتم أيضًا تخطي الخطوط المائلة العكسية، ويتم تمثيل فواصل أسطر الخلايا بـ <br>.
