مخطط الاجتماعات

قم بمقارنة نافذة التوفر اليومية المتكررة عبر المنظم والمشاركين في مناطق زمنية مختلفة. قم بمراجعة كل تاريخ ووقت محلي، ثم قم بتنزيل دعوة ICS للحصول على فتحة مطابقة.

يتم تشغيله محليًا. لا يوجد اتصال بالتقويم أو طلب موقع أو تحميل أو حساب أو API أو حفظ تلقائي.

أمثلة: أمريكا/نيويورك، أوروبا/لندن، آسيا/طوكيو. يتم تضمين المنظم تلقائيًا؛ استخدم ما يصل إلى ثماني مناطق متميزة في المجموع.

Daylight من قاعدة بيانات المنطقة الزمنية لهذا المتصفح وقد تكون قديمة. إذا تكرر الوقت الاحتياطي، فسيتم تحديد التكرار السابق؛ يتم تخطي حد الإتاحة غير الموجود أثناء الفجوة الربيعية للأمام.

نفس نافذة التوقيت المحلي اليومية في كل منطقة زمنية. ولا يعرف التقاويم الفردية أو العطلات أو أيام العمل أو تفضيلات الحضور. اختر مكانًا فعليًا مع الجميع قبل إرسال الدعوة.

أوقات الاجتماعات المشتركة المحتملة

لم يتم العثور على فتحات مطابقة لهذه المناطق والساعات. جرّب نافذة أوسع، أو نطاقًا زمنيًا مختلفًا، أو اجتماعًا أقصر.

هل يتصل هذا بالتقويم الخاص بي؟

No. يتم تشغيل كافة الحسابات في المتصفح الخاص بك. لا يقوم المخطط بتسجيل الدخول أو قراءة التقويمات أو تحميل جدولك الزمني أو حفظ اختياراتك.

هل يتحقق من توفر تقويم Google أو Outlook؟

No. فهو يقارن نفس الساعات التي تدخلها لكل منطقة زمنية. لا يمكنه رؤية المواعيد أو الإجازات أو أيام العمل أو التفضيلات الشخصية لأي شخص.

هل يتم احتساب التوقيت الصيفي؟

يستخدم قاعدة بيانات المنطقة الزمنية IANA الخاصة بالمتصفح لتحويل كل لحظة مرشحة. قد تكون قاعدة البيانات قديمة؛ التحقق من أوقات الاجتماعات المهمة مع المشاركين.

هل يمكنني إضافة الاجتماع المقترح إلى التقويم؟

قم بتنزيل حدث ICS للفتحة المحددة وقم باستيراده بنفسك. لا تقوم الأداة بالاتصال بأي تقويم أو تعديله.
