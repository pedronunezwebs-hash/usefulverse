تمرين التنفس

اختر إيقاعاً مريحاً للتنفس واتبع الدليل البصري. حافظ على راحتك أثناء الجلسة وتوقف متى شئت.

يتجنب الدليل الحركات المفاجئة عند تفعيل خيار تقليل الحركة.

هذا مؤقت عام للصحة والعافية وليس أداة طبية. تنفس براحة وتوقف إذا شعرت بانزعاج.

كيف أستخدم تمرين التنفس هذا؟

كيف أستخدم تمرين التنفس هذا؟

اختر نمطاً جاهزاً أو حدد مدة كل مرحلة، واختر طول الجلسة ثم اضغط على بدء. يمكنك الإيقاف المؤقت أو إعادة الضبط في أي وقت. الصوت اختياري ويبدأ بعد تشغيل التمرين.

هل يتم رفع بيانات جلسة التنفس؟

لا. يعمل المؤقت في هذه الصفحة فقط. لا تُستخدم حسابات أو عمليات رفع أو API أو تخزين للجلسات.

هل يمكنني استخدام التنفس الصندوقي أو تقنية 4-7-8؟

نعم. اختر إعداداً مسبقاً أو عدّل مدة المراحل. هذه أنماط لتنظيم وتيرة التنفس وليست علاجاً طبياً.

هل يستمر المؤقت إذا أغلقت علامة التبويب؟

لا يوجد ضمان. قد توقف المتصفحات علامات التبويب في الخلفية وقد تدخل الأجهزة في وضع السكون. أبقِ الصفحة مفتوحة والجهاز نشطاً للحصول على توقيت أدق.

هل يمكنني إيقاف الصوت أو التوقف مبكراً؟

نعم. الصوت اختياري ويمكن إيقافه. يؤدي الإيقاف المؤقت أو إعادة الضبط إلى إنهاء التوقيت النشط.
