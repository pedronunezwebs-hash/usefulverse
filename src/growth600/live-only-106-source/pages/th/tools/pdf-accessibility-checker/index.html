ตัวตรวจสอบการเข้าถึง PDF

ตรวจสอบ PDF ในเครื่องเพื่อดูสัญญาณการเข้าถึงที่ตรวจพบโดยเครื่อง รวมถึงแท็กเอกสาร ข้อมูลเมตา ข้อความที่เลือกได้ รูปภาพที่ไม่มีข้อความสำรอง และการข้ามระดับส่วนหัว นี่เป็นเพียงเครื่องมือตรวจสอบผ่านครั้งแรก ไม่ใช่เครื่องมือตรวจสอบ PDF/UA หรือสิ่งทดแทนการทดสอบเทคโนโลยีช่วยเหลือ

สูงสุด 25 MiB และ 300 หน้า การตรวจสอบอาจใช้หน่วยความจำของอุปกรณ์ แนะนำให้ใช้คอมพิวเตอร์สำหรับไฟล์ขนาดใหญ่

ทำงานบนอุปกรณ์ของคุณหลังจากที่คุณเลือกไฟล์ ไม่มีการอัปโหลด บัญชี API บันทึกอัตโนมัติ หรือการประมวลผลเซิร์ฟเวอร์

การตรวจสอบเหล่านี้เป็นการตรวจสอบพฤติกรรม พวกเขาไม่สามารถยืนยันลำดับการอ่านที่ถูกต้อง คำอธิบายที่มีความหมาย คอนทราสต์ของสี การใช้แป้นพิมพ์ ป้ายกำกับแบบฟอร์ม ความสัมพันธ์ของส่วนหัวตาราง หรือความสอดคล้องของ PDF/UA/Section 508/WCAG ตรวจสอบด้วยตนเองและทดสอบด้วยเทคโนโลยีช่วยเหลือ

ตัวตรวจสอบการเข้าถึง PDF นี้สามารถตรวจจับอะไรได้บ้าง

จะรายงานว่า PDF แสดงแท็กโครงสร้าง ชื่อเอกสารและภาษา ข้อความที่เลือกได้ในแต่ละหน้า รูปภาพพร้อมข้อความแสดงแทน และการข้ามระดับส่วนหัวที่เป็นไปได้ ไม่สามารถตัดสินได้ว่าลำดับการอ่านหรือข้อความแสดงแทนมีความหมายหรือไม่

PDF ของฉันถูกอัปโหลดเพื่อตรวจสอบหรือไม่

ไม่ PDF ที่เลือกได้รับการตรวจสอบในแท็บเบราว์เซอร์นี้ ไฟล์และข้อความไม่ได้รับการอัพโหลด บันทึกโดยอัตโนมัติ หรือส่งไปยังเซิร์ฟเวอร์

ผลลัพธ์ที่เป็นบวกหมายความว่าสามารถเข้าถึง PDF ได้หรือไม่

ไม่ นี่เป็นสัญญาณอัตโนมัติแบบจำกัดเท่านั้น PDF ที่แท็กยังคงมีลำดับการอ่านที่ไม่ถูกต้อง คำอธิบายที่ไม่ดี รูปแบบที่ไม่สามารถเข้าถึงได้ คอนทราสต์ต่ำ หรืออุปสรรคอื่นๆ ยังคงจำเป็นต้องมีการทดสอบด้วยตนเองและเทคโนโลยีช่วยเหลือ

สามารถยืนยันการปฏิบัติตามข้อกำหนด PDF/UA หรือ WCAG ได้หรือไม่

ไม่ เครื่องมือตรวจสอบผ่านครั้งแรกนี้ไม่ได้ทดสอบข้อกำหนดทุกประการ และไม่สามารถรับรอง PDF/UA, WCAG, มาตรา 508 หรือการปฏิบัติตามกฎหมายได้
