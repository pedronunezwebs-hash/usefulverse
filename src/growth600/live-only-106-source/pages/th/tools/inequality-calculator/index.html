เครื่องคำนวณอสมการ

แก้อสมการเชิงเส้นหรือกำลังสองจริงในรูปแบบ ax² + bx + c เปรียบเทียบกับศูนย์ ดูจุดวิกฤต สัญกรณ์ช่วงเวลา และการสรุปเส้นจำนวน

รองรับเฉพาะอสมการจริงคงที่ เชิงเส้น และกำลังสอง ax² + bx + c <, ≤, > หรือ ≥ 0 ค่าสัมประสิทธิ์จะต้องมีจำกัด โดยมีค่าสัมบูรณ์ไม่เกิน 10⁹ รากเป็นการประมาณเนื่องจากการคำนวณใช้ตัวเลขทศนิยม ความอดทนตามขนาดจะใช้ใกล้กับรากซ้ำ

ค่าสัมประสิทธิ์ของฉันถูกอัปโหลดหรือไม่

ไม่ ความไม่เท่าเทียมกันได้รับการคำนวณในเบราว์เซอร์นี้ และไม่ได้อัปโหลดหรือบันทึกโดยเครื่องมือนี้

สัญลักษณ์ช่วงเวลาแสดงอะไร

หมายความว่าไม่รวมจุดสิ้นสุด ในขณะที่วงเล็บเหลี่ยมหมายความว่ารวมอยู่ด้วย อินฟินิตี้ใช้วงเล็บเสมอเพราะอินฟินิตี้ไม่ใช่จุดสิ้นสุดที่แท้จริง

ฉันสามารถแก้สมการกำลังสามหรือตรรกยะได้หรือไม่

ไม่ เครื่องคิดเลขนี้จำกัดให้ใช้พหุนามจริงของดีกรี 0 หนึ่งหรือสองเท่านั้น ไม่สามารถแก้สมการกำลังสาม เหตุผล ค่าสัมบูรณ์ หรืออสมการเชิงประกอบได้

รากถูกต้องหรือไม่

หมายเลข สัมประสิทธิ์และรากใช้เลขคณิตทศนิยม ผลลัพธ์ที่ใกล้กับรากซ้ำหรือมีขนาดสัมประสิทธิ์ต่างกันมากอาจไวต่อการปัดเศษ
