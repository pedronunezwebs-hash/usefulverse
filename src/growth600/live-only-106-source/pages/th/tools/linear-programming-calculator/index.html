ค่าสัมประสิทธิ์วัตถุประสงค์ (x, y)

หนึ่งรายการต่อบรรทัด: a,b <= rhs, a,b >= rhs หรือ a,b = rhs

ใช้ข้อจำกัดและสัมประสิทธิ์/ด้านขวามือสูงสุดแปดรายการภายใน ±1,000,000 ตัวแปรการตัดสินใจทั้งสองมี x ≥ 0 และ y ≥ 0 ใช้เครื่องหมายจุลภาคระหว่างสัมประสิทธิ์ x และ y ป้อนความไม่เท่าเทียมกันหรือความเท่าเทียมกันหนึ่งรายการต่อบรรทัด

ตัวแก้ปัญหาซิมเพล็กซ์เบื้องต้นแบบสองเฟสสำหรับตัวแปรสองตัว ค่าเผื่อเชิงตัวเลขใช้สำหรับจุดหมุนจุดลอยตัว ปัญหาที่ใกล้เสื่อมอาจไวต่อการปัดเศษ กรณีที่เป็นไปได้ ไม่จำกัด และจำกัดการวนซ้ำจะถูกรายงานแทนกรณีที่เหมาะสมที่สุดที่ประดิษฐ์ขึ้น
