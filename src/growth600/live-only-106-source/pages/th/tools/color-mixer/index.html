เครื่องผสมสี

ผสมผสานสีด้วยน้ำหนักที่แก้ไขได้ เปรียบเทียบโหมดการผสมดิจิทัลสองโหมด และสร้างทางลาดตัวอย่างระหว่างสองสีแรก ไม่มีอะไรถูกอัปโหลด

สีที่จะผสม

วิธีการที่เลือกส่งผลต่อผลลัพธ์ sRGB ผสมผสานค่าช่องที่แสดง แสงเชิงเส้นแปลงช่องสัญญาณก่อนผสม

ค่านี้เป็นการคาดการณ์สีของหน้าจอดิจิทัล ไม่ใช่ว่าสีหรือเม็ดสีจริงจะผสมกันอย่างไร

สีของฉันถูกอัปโหลดหรือไม่

ไม่ การคำนวณสีทำงานในเบราว์เซอร์ของคุณ ไม่จำเป็นต้องอัปโหลดบัญชีหรือรูปภาพ

เหตุใด sRGB และแสงเชิงเส้นจึงดูแตกต่างกัน

sRGB เฉลี่ยค่าช่องสัญญาณของหน้าจอที่เข้ารหัส โหมดแสงเชิงเส้นจะแปลงเป็นค่าแสงก่อน ผสมแล้วแปลงกลับ วิธีการที่เลือกจะเปลี่ยนผลลัพธ์

สิ่งนี้สามารถทำนายสีของสีผสมได้หรือไม่?

ไม่ นี่คือคณิตศาสตร์สีดิจิทัลสำหรับหน้าจอ ไม่ใช่แบบจำลองเม็ดสีทางกายภาพ สีจริงขึ้นอยู่กับคุณสมบัติของเม็ดสี ความโปร่งใส ความเข้มข้น แสง และพื้นผิว

ฉันสามารถคัดลอกรูปแบบสีใดได้บ้าง

ผลลัพธ์จะแสดง HEX, RGB และ HSL คุณสามารถคัดลอกค่า HEX หรือดาวน์โหลดชุดสี CSS ขนาดเล็กได้
