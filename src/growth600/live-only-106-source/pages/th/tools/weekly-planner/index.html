ใช้ฟรี ไม่ต้องมีบัญชี

วางแผนรายสัปดาห์

สร้างตารางเวลารายสัปดาห์แบบง่ายๆ สำหรับการทำงาน แผนการส่วนตัว การศึกษา หรือสุขภาพ บล็อกข้ามคืนและข้อขัดแย้งของกำหนดการจะแสดงอย่างชัดเจน

แผนรายสัปดาห์แบบทำซ้ำใช้เวลาท้องถิ่น โดยไม่ได้คำนึงถึงโซนเวลา การเปลี่ยนแปลงเวลาออมแสง กิจกรรมในปฏิทิน หรือการเตือนความจำ

แผนจะยังคงอยู่ในหน่วยความจำในแท็บนี้ ดาวน์โหลดข้อมูลสำรอง JSON เพื่อเก็บไว้ ไม่มีการจัดเก็บหรืออัปโหลดอัตโนมัติ

ตารางรายสัปดาห์

ฉันจะจัดตารางรายสัปดาห์ได้อย่างไร?

เพิ่มชื่อ วัน เวลาเริ่มต้น เวลาสิ้นสุด และหมวดหมู่สำหรับแต่ละบล็อก บล็อกสามารถข้ามเที่ยงคืนได้ เวลาที่ทับซ้อนกันจะถูกตั้งค่าสถานะ รวมถึงวันอาทิตย์และวันจันทร์ด้วย

คำถามที่พบบ่อย

ฉันจะจัดตารางรายสัปดาห์ได้อย่างไร?

เพิ่มชื่อ วัน เวลาเริ่มต้น เวลาสิ้นสุด และหมวดหมู่สำหรับแต่ละบล็อก บล็อกสามารถข้ามเที่ยงคืนได้ เวลาที่ทับซ้อนกันจะถูกตั้งค่าสถานะ รวมถึงวันอาทิตย์และวันจันทร์ด้วย

กำหนดการรายสัปดาห์ของฉันอัปโหลดหรือบันทึกหรือไม่

ไม่ กำหนดการของคุณจะยังคงอยู่ในแท็บเบราว์เซอร์นี้ เว้นแต่คุณจะเลือกดาวน์โหลดข้อมูลสำรอง JSON นำเข้าข้อมูลสำรองที่คุณเลือกจากอุปกรณ์ของคุณ

ผู้วางแผนรายสัปดาห์สามารถรวมกะข้ามคืนได้หรือไม่

ใช่ เลือกเวลาสิ้นสุดก่อนเวลาเริ่มต้นเพื่อสร้างบล็อกที่จะสิ้นสุดในวันถัดไป รองรับการบล็อกสูงสุด 18 ชั่วโมง

กำหนดการรายสัปดาห์ตรวจพบข้อขัดแย้งหรือไม่

ใช่ โดยจะตรวจสอบบล็อคเวลาในวันเดียวกันและข้ามเที่ยงคืน รวมถึงบล็อกวันอาทิตย์ที่ทับซ้อนกับวันจันทร์

ผู้วางแผนนี้ซิงค์กับ Google Calendar หรือไม่

ไม่ ใช้งานได้ภายในแท็บนี้ และไม่มีการเชื่อมต่อปฏิทินหรือบริการเตือนความจำ คุณสามารถพิมพ์แผนหรือดาวน์โหลดและนำเข้าข้อมูลสำรอง JSON ได้
