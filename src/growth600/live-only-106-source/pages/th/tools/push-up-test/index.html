บันทึกชุดเดียวเป็นการทดสอบอย่างง่าย หรือบันทึกหลายชุดโดยให้ส่วนที่เหลืออยู่ระหว่างชุดเหล่านั้น คุณนับและป้อนการทำซ้ำ เครื่องมือนี้ไม่ได้ใช้กล้องของคุณหรือจัดอันดับความแข็งแกร่งของคุณ

ป้อนจำนวนเต็มได้สูงสุด 20 จำนวนตั้งแต่ 0 ถึง 500 บรรทัดว่างจะถูกละเว้นและไม่นับเป็นชุด นับเฉพาะการทำซ้ำที่คุณกรอกด้วยแบบฟอร์มที่คุณเลือก

เก็บบันทึกทั่วไป นี่ไม่ใช่เวชระเบียน

เลือกช่วงการเคลื่อนไหวที่สะดวกสบายและหยุดหากคุณรู้สึกเจ็บปวด เวียนศีรษะ หรือหายใจไม่สะดวกผิดปกติ จำนวนตัวแทนขึ้นอยู่กับรูปแบบ ฝีเท้า และเงื่อนไขการทดสอบ เครื่องมือนี้ไม่ได้ให้คะแนนสมรรถภาพ การวินิจฉัย หรือใบสั่งยาในการออกกำลังกาย

การบันทึกเป็นทางเลือก และใช้เบราว์เซอร์นี้เท่านั้น ยกเลิกการเลือกเพื่อคำนวณโดยไม่บันทึก หรือล้างประวัติที่บันทึกไว้ด้านล่าง

เพิ่มจำนวนซ้ำที่ป้อนสำหรับชุดที่ไม่ว่างแต่ละชุด บรรทัดว่างจะถูกละเว้น ชุดของศูนย์ยังคงเป็นศูนย์ และค่าประมาณส่วนที่เหลือคือส่วนที่เหลือต่อการแบ่งคูณด้วยจำนวนการแบ่ง

ชุดวิดพื้นของฉันอัปโหลดแล้วหรือยัง?

ไม่ การคำนวณรันในเบราว์เซอร์นี้ ประวัติเซสชันจะถูกเขียนลงในอุปกรณ์นี้หลังจากที่คุณเลือกใช้เท่านั้น คุณสามารถลบได้ที่นี่

บรรทัดว่างนับเป็นชุดหรือการทำซ้ำหรือไม่

No. บรรทัดว่างจะถูกละเว้น บรรทัดที่มี 0 จะบันทึกชุดการทำซ้ำเป็นศูนย์และไม่บวกการซ้ำซ้อนกับผลรวม

ใช้กับชุดสูงสุดชุดเดียวหรือหลายชุดได้หรือไม่

ใช่ ป้อนหนึ่งบรรทัดสำหรับชุดที่นับด้วยตนเองชุดเดียว หรือหลายบรรทัดเพื่อสรุปชุดและส่วนที่เหลือระหว่างชุดเหล่านั้น เงื่อนไขการทดสอบขึ้นอยู่กับคุณ ผลลัพธ์ไม่ได้รับการเปรียบเทียบกับบรรทัดฐานของประชากร

ประวัติการฝึกของฉันถูกอัพโหลดหรือไม่?

ไม่ ประวัติเป็นทางเลือกและจะคงอยู่ในเบราว์เซอร์นี้บนอุปกรณ์นี้ ล้างข้อมูลด้วยปุ่มลบทุกครั้งที่คุณต้องการ
