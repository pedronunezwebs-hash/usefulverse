เครื่องมือแปลง XML เป็น CSV

เปลี่ยนรายการบันทึก XML แบบธรรมดาให้เป็นตาราง CSV หรือสร้างบันทึก XML จากข้อความของไฟล์ CSV เลือกทิศทาง วางข้อมูลของคุณ จากนั้นคัดลอกหรือดาวน์โหลดผลลัพธ์ ไม่มีอะไรถูกอัปโหลด

รองรับรายการอย่างง่ายขององค์ประกอบบันทึกที่มีชื่อเดียวกัน หรือบันทึกแบบเรียบหนึ่งรายการ องค์ประกอบลูกต้องเป็นค่าสเกลาร์ ฟิลด์ที่ซ้อนกันและซ้ำจะไม่ถูกทำให้แบน

ใช้แถวแรกสำหรับชื่อคอลัมน์ ส่วนหัวเช่น @id จะกลายเป็นแอตทริบิวต์ XML ใช้ #text สำหรับบันทึกข้อความ

นี่เป็นการแปลงตารางอย่างง่าย ไม่ใช่การแปลงรูปแบบ XML แบบไม่สูญเสีย เนมสเปซ โครงสร้างที่ซ้อนกัน เนื้อหาผสม ความคิดเห็น และการจัดรูปแบบ XML จะไม่ถูกรักษาไว้ ข้อความไม่รับรู้ถึงประเภท ค่า CSV ที่คล้ายกับสูตรสเปรดชีตจะมีเครื่องหมายอะพอสทรอฟี่นำหน้าเพื่อความปลอดภัย

เลือก XML เป็น CSV และวาง XML ด้วยรายการบันทึกแบบง่าย องค์ประกอบบันทึกโดยตรงที่ทำซ้ำจะกลายเป็นแถว ชื่อองค์ประกอบกลายเป็นคอลัมน์ คุณลักษณะใช้ @name เลือก CSV เป็น XML เพื่อสร้างบันทึก XML อย่างง่ายจากส่วนหัวและแถว

XML หรือ CSV ของฉันถูกอัปโหลดหรือไม่

ไม่ การแยกวิเคราะห์และการแปลงทำงานในเบราว์เซอร์นี้ อินพุตจำกัดอยู่ที่ 200,000 อักขระ 5,000 แถว 64 คอลัมน์ และ 20,000 เซลล์ การประกาศ DTD และเอนทิตีถูกบล็อก และทรัพยากรภายนอกไม่ถูกดึงข้อมูล

คุณลักษณะ XML แสดงใน CSV อย่างไร

แอ็ตทริบิวต์ เช่น id="101" จะกลายเป็นคอลัมน์ชื่อ @id เมื่อแปลงกลับ ส่วนหัว CSV ที่ขึ้นต้นด้วย @ จะกลายเป็นแอตทริบิวต์ XML

มันสามารถแปลง XML ที่ซ้อนกันเป็นตารางเรียบได้หรือไม่?

ไม่ โครงสร้างลูกที่ซ้อนกัน ฟิลด์ที่ซ้ำกันภายในบันทึก และข้อความแบบผสมจะถูกปฏิเสธ แทนที่จะถูกทำให้ราบเรียบหรือสูญหายไปอย่างเงียบๆ ใช้เวิร์กโฟลว์ XML-to-JSON เฉพาะสำหรับข้อมูลที่ซ้อนกัน

CSV จะรักษาประเภทและการจัดรูปแบบ XML ไว้หรือไม่

หมายเลข CSV จะจัดเก็บข้อความในเซลล์ ไม่ใช่ประเภท XML เนมสเปซ หรือการจัดรูปแบบ ค่าเซลล์ที่มีลักษณะคล้ายสูตรจะมีเครื่องหมายอะพอสทรอฟีนำหน้าเมื่อส่งออกเพื่อลดความเสี่ยงในการดำเนินการตามสูตรสเปรดชีต
