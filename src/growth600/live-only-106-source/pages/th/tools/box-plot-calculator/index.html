เครื่องคำนวณพล็อตกล่อง

วางตัวอย่างหนึ่งหรือสองตัวอย่างเพื่อเปรียบเทียบผลสรุปห้าตัวเลข ช่วงระหว่างควอไทล์ และค่าผิดปกติของ Tukey เลือกวิธีคำนวณควอร์ไทล์

ตัวอย่าง 1
ตัวอย่าง 2

ป้อนตัวเลขสูงสุด 2,000 ต่อตัวอย่าง แยกค่าด้วยอัฒภาค ช่องว่าง หรือขึ้นบรรทัดใหม่ อัฒภาคยังคงรักษาเครื่องหมายจุลภาคทศนิยมไว้

แต่ละตัวอย่างยอมรับค่าจำกัด 1–2,000 ค่าที่มีขนาดสัมบูรณ์สูงสุด 1,000,000,000 รั้ว 1.5×IQR ระบุค่าผิดปกติที่อาจเกิดขึ้น หนวดจะสิ้นสุดที่ค่าในรั้วที่สูงที่สุด วิธีการควอร์ไทล์ที่ต่างกันสามารถให้ค่า Q1 และ Q3 ที่แตกต่างกันได้ นี่เป็นแผนภูมิอธิบาย ไม่ใช่การทดสอบที่มีนัยสำคัญหรือเหตุผลในการลบข้อมูล

ผลลัพธ์การพล็อตกล่อง

คุณจะคำนวณ box plot ได้อย่างไร?

จัดเรียงตัวอย่างแต่ละตัวอย่าง ค้นหาค่ามัธยฐานและควอร์ไทล์ จากนั้นคำนวณช่วงระหว่างควอไทล์ (Q3 − Q1) หนวดเข้าถึงการสังเกตที่รุนแรงที่สุดภายในรั้ว 1.5 IQR ค่าที่เกินกว่านั้นจะแสดงเป็นค่าผิดปกติ

คำถามที่พบบ่อย

คุณจะคำนวณ box plot ได้อย่างไร?

จัดเรียงตัวอย่างแต่ละตัวอย่าง ค้นหาค่ามัธยฐานและควอร์ไทล์ จากนั้นคำนวณช่วงระหว่างควอไทล์ (Q3 − Q1) หนวดเข้าถึงการสังเกตที่รุนแรงที่สุดภายในรั้ว 1.5 IQR ค่าที่เกินกว่านั้นจะแสดงเป็นค่าผิดปกติ

ข้อมูลของฉันถูกอัปโหลดหรือไม่

หมายเลข สถิติและแผนภูมิคำนวณในเบราว์เซอร์นี้ เครื่องมือนี้ไม่ได้อัปโหลดหรือบันทึกค่าของคุณ

กล่องในพล็อตกล่องแสดงอะไร

กล่องเริ่มจากควอร์ไทล์ที่หนึ่ง (Q1) ถึงควอร์ไทล์ที่สาม (Q3) เส้นด้านในทำเครื่องหมายค่ามัธยฐาน และความยาวของกล่องคือช่วงระหว่างควอไทล์ (IQR) หนวดเคราแสดงระยะในรั้ว จุดที่อยู่เหนือรั้วจะถูกทำเครื่องหมายว่าเป็นค่าผิดปกติ

เหตุใดผลลัพธ์ควอไทล์จึงแตกต่างกัน

มีรูปแบบควอไทล์ที่ยอมรับมากกว่าหนึ่งแบบ เครื่องคิดเลขนี้ติดป้ายกำกับแต่ละวิธี: ค่ามัธยฐานของครึ่งโดยไม่รวมค่ามัธยฐานโดยรวม ค่ามัธยฐานของครึ่งหนึ่งรวมอยู่ด้วย หรือการประมาณค่าเชิงเส้นโดยใช้ประเภท 7 เลือกรูปแบบที่กำหนดโดยชั้นเรียนหรือการวิเคราะห์ของคุณ

ค่าผิดปกติหมายความว่าฉันควรลบค่านั้นหรือไม่

ไม่ กฎ 1.5×IQR จะตั้งค่าสถานะสำหรับการตรวจสอบเท่านั้น ตรวจสอบข้อมูลและบริบทก่อนตัดสินใจว่าจะทำอย่างไร ค่าที่ผิดปกติอาจเป็นข้อสังเกตที่ถูกต้อง
