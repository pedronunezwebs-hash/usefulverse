ตัวนับวันปลอดสารเสพติด

เลือกวันที่เริ่มต้นเพื่อนับวันตามปฏิทินที่ผ่านไป และดูเหตุการณ์สำคัญที่กำลังจะเกิดขึ้น เคาน์เตอร์ส่วนตัวนี้ไม่ใช่การรักษา คำแนะนำในการฟื้นฟู หรือการวัดสุขภาพ

ใส่วันที่ที่คุณต้องการนับ วันที่วันนี้คือวันที่ศูนย์ ไม่อนุญาตให้มีวันที่ในอนาคต มีค่าเริ่มต้นเป็นวันนี้และสามารถเปลี่ยนแปลงเพื่อตรวจสอบวันที่ก่อนหน้าได้ แต่ไม่ใช่วันที่ก่อนการเริ่มต้น

สูงสุด 280 อักขระ เก็บรายละเอียดที่ละเอียดอ่อนออกจากอุปกรณ์ที่ใช้ร่วมกัน

นี่เป็นเลขคณิตวันที่เท่านั้น ไม่ได้ประเมินการใช้สาร สุขภาพ ความเสี่ยง ความก้าวหน้า หรือความต้องการในการรักษา การฟื้นตัวเป็นเรื่องส่วนตัว พิจารณาการสนับสนุนที่มีคุณสมบัติเหมาะสมหากคุณต้องการความช่วยเหลือ

การบันทึกเป็นทางเลือก และใช้ที่จัดเก็บในเครื่องของเบราว์เซอร์นี้เท่านั้น ไม่มีอะไรถูกอัพโหลด ล้างข้อมูลที่บันทึกไว้ด้านล่าง

นับวันของคุณ

ตัวนับวันมีสติทำงานอย่างไร?

นับวันตามปฏิทินทั้งหมดนับจากวันที่ที่คุณป้อนจนถึงวันนี้ วันที่เริ่มต้นที่เลือกคือวันที่ศูนย์ วันที่ภายหลังจะใช้เลขคณิตเฉพาะวันที่เท่านั้น ดังนั้นเวลาออมแสงจึงไม่เพิ่มหรือลบวัน

คำถามที่พบบ่อย

ตัวนับวันมีสติทำงานอย่างไร?

นับวันตามปฏิทินทั้งหมดนับจากวันที่ที่คุณป้อนจนถึงวันนี้ วันที่เริ่มต้นที่เลือกคือวันที่ศูนย์ วันที่ภายหลังจะใช้เลขคณิตเฉพาะวันที่เท่านั้น ดังนั้นเวลาออมแสงจึงไม่เพิ่มหรือลบวัน

วันที่ความสุขของฉันถูกอัปโหลดหรือบันทึกหรือไม่

ไม่มีการอัพโหลดข้อมูล วันที่ของคุณใช้ในเบราว์เซอร์นี้เท่านั้น คุณสามารถบันทึกบันทึกหรือวันที่บนอุปกรณ์นี้ได้เฉพาะเมื่อคุณเลือกอย่างชัดเจน และคุณสามารถล้างบันทึกในเครื่องได้ตลอดเวลา

วันที่เริ่มต้นนับเป็นวันแรกหรือไม่?

ไม่ วันที่เริ่มต้นที่เลือกคือวันที่ศูนย์ วันที่ปฏิทินถัดไปคือหนึ่งวันที่ผ่านไปในภายหลัง

ตัวนับนี้สามารถให้การรักษาหรือคำแนะนำทางการแพทย์ได้หรือไม่?

No. นับวันตามปฏิทินและแสดงเฉพาะเหตุการณ์สำคัญเท่านั้น ไม่ได้ประเมินสุขภาพ การใช้สาร การรักษา หรือความก้าวหน้าส่วนบุคคล

วันที่และบันทึกย่อถูกส่งไปยังเซิร์ฟเวอร์หรือไม่

ไม่ การคำนวณทำงานในเบราว์เซอร์ของคุณ การบันทึกเป็นทางเลือกและจัดเก็บบันทึกขนาดเล็กในเบราว์เซอร์นี้บนอุปกรณ์นี้ คุณสามารถเคลียร์มันได้ที่นี่
