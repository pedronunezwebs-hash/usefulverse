ติดตามโลโก้ ไอคอน และอาร์ตเวิร์กสีเรียบๆ ลงในเส้นทาง SVG เลือกขีดจำกัดสีและขนาดรายละเอียด ดูตัวอย่างเวกเตอร์ จากนั้นดาวน์โหลด SVG

128

ด้านที่ยาวที่สุดจะลดลงเหลือจำนวนพิกเซลหรือน้อยกว่านี้ รายละเอียดที่ใหญ่ขึ้นอาจสร้าง SVG ที่ใหญ่ขึ้น

เหมาะสำหรับโลโก้ ไอคอน และภาพวาดสีเรียบๆ วิธีนี้เป็นไปตามตารางพิกเซล มันไม่ทำให้เส้นโค้งเรียบหรือสร้างรายละเอียดของภาพถ่าย

สูงสุด 5 MiB ต่ออิมเมจต้นฉบับ รูปภาพได้รับการประมวลผลในเครื่องและไม่ได้อัปโหลดหรือบันทึกโดยอัตโนมัติ รูปภาพขนาดใหญ่สามารถใช้หน่วยความจำอุปกรณ์ได้ แนะนำให้ใช้คอมพิวเตอร์

รูปภาพของฉันถูกอัปโหลดหรือไม่

ไม่ รูปภาพถูกถอดรหัสและติดตามในแท็บเบราว์เซอร์นี้ ไม่ได้อัปโหลดหรือบันทึกโดยอัตโนมัติ

SVG มีรูปภาพต้นฉบับหรือไม่

ไม่ ผลลัพธ์ประกอบด้วยรูปร่างเส้นทาง SVG ไม่ใช่ภาพแรสเตอร์ที่ฝังไว้ โดยจะประมาณแหล่งที่มาโดยการจัดกลุ่มพิกเซลเป็นสีและเส้นทาง

มันจะปรับภาพเวกเตอร์ได้อย่างราบรื่นหรือไม่?

ไม่ การติดตามตารางพิกเซลมีไว้สำหรับโลโก้ ไอคอน และภาพวาดสีเรียบๆ ภาพถ่ายสามารถสร้างขอบที่เป็นบล็อกและไฟล์ SVG ขนาดใหญ่ได้

เครื่องมืออัปโหลดหรือเก็บรูปภาพของฉันไว้หรือไม่

ไม่ แหล่งที่มาได้รับการประมวลผลในแท็บนี้ และไม่ได้อัปโหลดหรือบันทึกโดยอัตโนมัติ ความเร็วในการประมวลผลและการใช้หน่วยความจำขึ้นอยู่กับอุปกรณ์ของคุณ
