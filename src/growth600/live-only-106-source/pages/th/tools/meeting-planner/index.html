Meeting Planner

เปรียบเทียบกรอบเวลาว่างรายวันที่เกิดซ้ำระหว่างผู้จัดงานและผู้เข้าร่วมในเขตเวลาที่ต่างกัน ตรวจสอบวันที่และเวลาในท้องถิ่นแต่ละแห่ง จากนั้นดาวน์โหลดคำเชิญ ICS สำหรับช่องที่ตรงกัน

Runs ภายในเครื่อง ไม่มีการเชื่อมต่อปฏิทิน, คำขอตำแหน่ง, อัปโหลด, บัญชี, API หรือบันทึกอัตโนมัติ

ตัวอย่าง: อเมริกา/นิวยอร์ก ยุโรป/ลอนดอน เอเชีย/โตเกียว ผู้จัดงานจะถูกรวมไว้โดยอัตโนมัติ ใช้โซนที่แตกต่างกันได้สูงสุดแปดโซน

กฎการประหยัดเวลากลางวันมาจากฐานข้อมูลเขตเวลาของเบราว์เซอร์นี้และอาจเก่าแล้ว หากเวลาย้อนกลับเกิดซ้ำ ระบบจะเลือกเหตุการณ์ก่อนหน้านั้น ขอบเขตความพร้อมใช้งานที่ไม่มีอยู่ระหว่างช่องว่างสปริงไปข้างหน้าถูกข้ามไป

ใช้กรอบเวลาท้องถิ่นรายวันเดียวกันในทุกโซนเวลา ไม่ทราบปฏิทิน วันหยุด วันทำงาน หรือการตั้งค่าของผู้เข้าร่วมแต่ละคน เลือกช่องจริงกับทุกคนก่อนส่งคำเชิญ
