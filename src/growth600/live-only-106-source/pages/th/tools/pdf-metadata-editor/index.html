ใช้ฟรี ไม่ต้องมีบัญชี

โปรแกรมแก้ไขข้อมูลเมตา PDF

อ่านหรือแก้ไขข้อมูลเอกสารทั่วไปที่จัดเก็บไว้ใน PDF จากนั้นดาวน์โหลดสำเนาแยกต่างหาก PDF ที่เลือกจะยังคงอยู่ในอุปกรณ์นี้

เก็บต้นฉบับของคุณไว้ การบันทึกซ้ำอาจทำให้ลายเซ็นดิจิทัลไม่ถูกต้องหรือส่งผลต่อคุณสมบัติ PDF ขั้นสูง เครื่องมือนี้ไม่ได้ลบข้อมูลที่ซ่อนอยู่หรือรับรองความเป็นส่วนตัว

ขีดจำกัดท้องถิ่น: อินพุต 25 MiB, 300 หน้า และเอาต์พุต 50 MiB เอกสารขนาดใหญ่อาจต้องการหน่วยความจำเพิ่มเติม แนะนำให้ใช้คอมพิวเตอร์

เฉพาะข้อมูลเอกสาร PDF มาตรฐานเท่านั้นที่ได้รับการแก้ไข ไม่รองรับ XMP, ข้อมูลเมตาที่กำหนดเอง, ไฟล์แนบ, เนื้อหาที่ซ่อน และการตรวจสอบลายเซ็น

ข้อมูลเอกสารมาตรฐาน

ปล่อยให้ฟิลด์ว่างไว้เพื่อลบการป้อนข้อมูลมาตรฐานออกจากสำเนาใหม่ ส่วนช่องอื่นๆ จะถูกเก็บไว้

สำเนา PDF ของคุณพร้อมแล้ว

ดาวน์โหลด PDF ที่แก้ไขแล้ว

อยู่ในเบราว์เซอร์นี้ ไม่มีบัญชี การอัปโหลด การประมวลผลเซิร์ฟเวอร์ หรือการบันทึกอัตโนมัติ

ฉันสามารถเปลี่ยนข้อมูลเมตา PDF ใดได้บ้าง

เครื่องมือนี้แก้ไขฟิลด์ข้อมูลเอกสารมาตรฐาน: ชื่อเรื่อง ผู้แต่ง หัวเรื่อง คำสำคัญ ผู้สร้าง ผู้ผลิต วันที่สร้าง และวันที่แก้ไข ไม่ได้แก้ไขข้อมูลเมตา XMP หรือคุณสมบัติที่กำหนดเอง

ฉันสามารถเปลี่ยนข้อมูลเมตา PDF ใดได้บ้าง

เครื่องมือนี้แก้ไขฟิลด์ข้อมูลเอกสารมาตรฐาน: ชื่อเรื่อง ผู้แต่ง หัวเรื่อง คำสำคัญ ผู้สร้าง ผู้ผลิต วันที่สร้าง และวันที่แก้ไข ไม่ได้แก้ไขข้อมูลเมตา XMP หรือคุณสมบัติที่กำหนดเอง

PDF ของฉันถูกอัปโหลดหรือไม่

ไม่ การอ่านและการแก้ไขจะเกิดขึ้นในเบราว์เซอร์ของคุณหลังจากที่คุณเลือกไฟล์แล้ว ไฟล์ต้นฉบับไม่มีการเปลี่ยนแปลง การบันทึกจะสร้างสำเนา PDF แยกต่างหาก

สิ่งนี้จะลบข้อมูลเมตาทั้งหมดออกจาก PDF หรือไม่

ไม่ แก้ไขเฉพาะรายการทั่วไปในพจนานุกรมข้อมูลเอกสาร PDF มาตรฐาน XMP คุณสมบัติที่กำหนดเอง ไฟล์ที่ฝัง และเนื้อหาที่ซ่อนอยู่อื่นๆ อาจยังคงอยู่

การแก้ไขข้อมูลเมตาจะรักษาลายเซ็นดิจิทัลหรือไม่

อย่าไปพึ่งมันนะ การบันทึกจะเขียน PDF ใหม่และอาจทำให้ลายเซ็นดิจิทัลที่มีอยู่เป็นโมฆะหรือส่งผลต่อฟีเจอร์ที่เครื่องมือนี้ไม่รองรับ เก็บต้นฉบับและตรวจสอบสำเนา

PDF ต้นฉบับถูกเขียนทับหรือไม่

ไม่ เครื่องมือจะอ่านไฟล์ที่เลือกและสร้างสำเนาที่ดาวน์โหลดแยกต่างหาก มันไม่ได้ดัดแปลงต้นฉบับบนอุปกรณ์ของคุณ
