PDF โปรแกรมแก้ไขบุ๊กมาร์ก

เพิ่มสารบัญที่นำทางไปยัง PDF หรือจัดระเบียบบุ๊กมาร์กที่มีอยู่ สร้างส่วนที่ซ้อนกัน กำหนดปลายทางของหน้า เรียงลำดับรายการใหม่ และบันทึกสำเนาแยกต่างหากในเบราว์เซอร์ของคุณ

Editing สร้างสำเนา PDF ใหม่ โปรแกรมอ่านบางส่วนอาจแสดงบุ๊กมาร์กแตกต่างออกไป ตรวจสอบสำเนาที่บันทึกไว้ก่อนที่จะแชร์

L ขีดจำกัดท้องถิ่น: อินพุต 25 MiB, 300 หน้า, บุ๊กมาร์ก 500 รายการ, ระดับการซ้อน 20 ระดับ และเอาต์พุต 50 MiB ไฟล์ขนาดใหญ่อาจใช้หน่วยความจำอุปกรณ์จำนวนมาก แนะนำให้ใช้คอมพิวเตอร์

Creates ปลายทางเพจภายในและรายการเค้าร่างที่ซ้อนกัน ลิงก์ภายนอกที่มีอยู่ ปลายทางที่มีชื่อ หรือการดำเนินการบุ๊กมาร์กที่ไม่สนับสนุนจะถูกปฏิเสธ แทนที่จะถูกละทิ้งอย่างเงียบๆ เนื้อหาของหน้าไม่ได้รับการแก้ไข ลายเซ็นดิจิทัลอาจใช้ไม่ได้หลังจากบันทึก

PDF ที่คั่นหนังสือ

ยังไม่มีบุ๊กมาร์ก เพิ่มหนึ่งรายการเพื่อเริ่มสารบัญ

Export เขียนโครงร่างปัจจุบันที่นี่ การนำเข้าจะแทนที่โครงร่างปัจจุบันหลังจากการตรวจสอบความถูกต้อง เก็บข้อมูลสำรองของไฟล์ PDF ต้นฉบับ; JSON ไม่มีเนื้อหาของหน้า

จะเก็บบุ๊กมาร์กที่เปิดลิงก์ภายนอกไว้หรือไม่

ตัวแก้ไขนี้รองรับปลายทางหน้าภายในในปัจจุบัน โดยจะปฏิเสธไฟล์ที่มีการดำเนินการภายนอกที่ไม่รองรับหรือปลายทางที่มีชื่อ แทนที่จะทิ้งไฟล์เหล่านั้นอย่างเงียบๆ

จะเปลี่ยนหน้า PDF หรือลายเซ็นหรือไม่

แก้ไขโครงร่างเอกสารและบันทึกสำเนาใหม่ ไม่ใช่เนื้อหาของหน้า การแก้ไขใดๆ อาจทำให้ลายเซ็นดิจิทัลเป็นโมฆะได้ ดังนั้น โปรดตรวจสอบผลลัพธ์และอย่าถือว่าเครื่องมือนี้เป็นการเก็บรักษาลายเซ็น
