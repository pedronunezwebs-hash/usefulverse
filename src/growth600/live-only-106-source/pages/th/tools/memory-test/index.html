Memory Test

ฝึกจำลำดับที่เพิ่มขึ้นของตัวเลขหรือตำแหน่งบนตารางขนาด 3×3 แต่ละรอบที่ถูกต้องจะเพิ่มหนึ่งรายการ

ฝึกซ้อมเท่านั้น นี่ไม่ใช่การทดสอบไอคิว การวินิจฉัย หรือการประเมินความรู้ความเข้าใจที่ได้รับการตรวจสอบแล้ว ผลลัพธ์ไม่มีความหมายทางคลินิกหรือประชากร

สำหรับโปรแกรมอ่านหน้าจอ ให้เลือก ช่วงตัวเลข: แต่ละหลักจะประกาศหนึ่งครั้งระหว่างการเล่น โหมดรูปแบบการมองเห็นขึ้นอยู่กับการมองเห็น

ความยาวลำดับถัดไป: 3

รายการลำดับ: —

คำตอบของคุณ

ยังไม่มีรายการเข้า

รอบที่ถูกต้อง: 0

เลือกโหมดและความเร็ว จากนั้นเริ่ม

ผลการทดสอบ

การทดสอบหน่วยความจำนี้ทำงานอย่างไร

เลือกตัวเลขหรือตารางภาพและความเร็วในการแสดงผล ดูหรือฟังซีเควนซ์หนึ่งครั้ง จากนั้นจึงป้อนตามลำดับเดียวกัน รอบที่ถูกต้องจะนานขึ้นสูงสุด 12 รายการ นี่เป็นเกมฝึกหัดทั่วไป ไม่ใช่การประเมินความจำมาตรฐาน

คำถามที่พบบ่อย

การทดสอบหน่วยความจำนี้ทำงานอย่างไร

เลือกตัวเลขหรือตารางภาพและความเร็วในการแสดงผล ดูหรือฟังซีเควนซ์หนึ่งครั้ง จากนั้นจึงป้อนตามลำดับเดียวกัน รอบที่ถูกต้องจะนานขึ้นสูงสุด 12 รายการ นี่เป็นเกมฝึกหัดทั่วไป ไม่ใช่การประเมินความจำมาตรฐาน

การทดสอบหน่วยความจำนี้บันทึกคะแนนของฉันหรือไม่

ไม่ ลำดับและคะแนนจะยังคงอยู่ในหน้านี้ในขณะที่เปิดอยู่ ไม่มีการอัปโหลดใด ๆ และไม่มีบัญชีหรือการจัดอันดับออนไลน์

การทดสอบหน่วยความจำนี้วัดค่าอะไร?

เป็นเกมฝึกการจำลำดับเหตุการณ์แบบสบาย ๆ ไม่ได้มาตรฐานและไม่สามารถวินิจฉัยภาวะหรือวัดไอคิวได้

ช่วงตัวเลขและโหมดรูปแบบแตกต่างกันอย่างไร?

Digit span จะแสดงทีละหลักและประกาศให้เข้าถึงโปรแกรมอ่านหน้าจอได้ โหมดรูปแบบจะกะพริบตำแหน่งบนตารางขนาด 3×3 และต้องใช้การมองเห็น

คะแนนจะถูกบันทึกไว้หรือเปรียบเทียบกับคนอื่น?

ไม่ คะแนนจะมีอยู่เฉพาะในขณะที่หน้านี้ยังคงเปิดอยู่เท่านั้น ไม่มีการอัปโหลดกระดานผู้นำ บัญชี หรือเซิร์ฟเวอร์
