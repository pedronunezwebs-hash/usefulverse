เครื่องคำนวณขนาดเอฟเฟกต์

ป้อนสถิติสรุปสำหรับกลุ่มอิสระสองกลุ่มเพื่อคำนวณผลต่างค่าเฉลี่ยมาตรฐานที่มีการลงนาม ค่าเบี่ยงเบนมาตรฐานรวม และ g ของ Hedges ที่แก้ไขด้วยตัวอย่างขนาดเล็ก

กลุ่มที่ 1
กลุ่มที่ 2

สำหรับกลุ่มอิสระ เวอร์ชันนี้ใช้คำจำกัดความ pooled-SD แบบธรรมดา และถือว่าค่าแปรปรวนประชากรที่ใช้ร่วมกัน ป้อนค่าเบี่ยงเบนมาตรฐานตัวอย่าง (n−1) ไม่ใช่ข้อผิดพลาดมาตรฐาน

ขนาดตัวอย่างแต่ละขนาดต้องเป็น 2–1,000,000; ค่าเฉลี่ยและ SD ถูกจำกัดไว้ที่ ±1,000,000,000 (SD ไม่สามารถเป็นค่าลบได้) อย่างน้อยหนึ่ง SD จะต้องอยู่เหนือศูนย์

ผลลัพธ์ขนาดเอฟเฟกต์

d = (ค่าเฉลี่ย₁ - ค่าเฉลี่ย₂) / SD ที่รวมกัน แนวป้องกันความเสี่ยง g = J(df) × d โดยที่ df = n₁ + n₂ − 2 เครื่องหมายจะขึ้นอยู่กับลำดับของกลุ่ม ขนาดจะไม่เป็น "เล็ก" "กลาง" หรือ "ใหญ่" โดยอัตโนมัติ ตีความในสาขาวิชาและการออกแบบการศึกษา

สถิติการศึกษาของฉันถูกอัปโหลดหรือไม่

ไม่ การคำนวณรันในเบราว์เซอร์นี้ สถิติสรุปของคุณจะไม่ถูกส่งไปยังเซิร์ฟเวอร์หรือบันทึกโดยเครื่องมือนี้

อะไรคือความแตกต่างระหว่าง d ของ Cohen และ g ของ Hedges?

ทั้งสองสร้างมาตรฐานให้กับผลต่างเฉลี่ยด้วยค่าเบี่ยงเบนมาตรฐานรวม g ของ Hedges คูณ d ด้วยการแก้ไขตัวอย่างขนาดเล็ก ซึ่งช่วยลดอคติเมื่อตัวอย่างมีขนาดเล็ก

ฉันสามารถป้อนข้อผิดพลาดมาตรฐานแทนส่วนเบี่ยงเบนมาตรฐานได้หรือไม่

ไม่ เครื่องคิดเลขนี้คาดหวังค่าเบี่ยงเบนมาตรฐานของกลุ่มตัวอย่างแต่ละกลุ่ม ข้อผิดพลาดมาตรฐานอธิบายถึงความไม่แน่นอนในการประมาณค่าตัวอย่าง และไม่สามารถใช้แทนค่า SD ในที่นี้ได้

ขนาดเอฟเฟกต์ที่ใหญ่ขึ้นพิสูจน์ได้ว่าผลลัพธ์มีความสำคัญหรือไม่?

ไม่ ขนาดผลกระทบอธิบายถึงความแตกต่างที่เป็นมาตรฐาน ไม่ใช่นัยสำคัญทางสถิติ สาเหตุ หรือความสำคัญในทางปฏิบัติ บริบท ความไม่แน่นอน การออกแบบการศึกษา และมาตราส่วนการวัดผล
