หน้าแรก/เครื่องกำเนิดตารางมาร์กดาวน์

ใช้ฟรี ไม่ต้องมีบัญชี

เครื่องกำเนิดตารางมาร์กดาวน์

สร้างตาราง Markdown ในตารางขนาดเล็กที่สามารถแก้ไขได้ นำเข้าข้อความที่คั่นด้วยเครื่องหมายจุลภาค คั่นอัฒภาค หรือคั่นด้วยแท็บ เลือกการจัดแนวคอลัมน์ และคัดลอก Markdown ธรรมดาโดยมีการ Escape ไปป์อย่างปลอดภัย

การนำเข้าจะแทนที่ตารางปัจจุบัน สูงสุด 100 แถว 20 คอลัมน์ และ 250,000 อักขระ

แถวแรกจะกลายเป็นส่วนหัวของ Markdown เพิ่มอย่างน้อยหนึ่งแถวและหนึ่งคอลัมน์

เซลล์ตารางที่แก้ไขได้

สร้างตารางไปป์มาตรฐานพร้อมแถวส่วนหัวและตัวแยก ตัวแบ่งเซลล์กลายเป็น <br>; ไปป์ Markdown และแบ็กสแลชจะถูกหลีกหนี

การประมวลผลทั้งหมดจะยังคงอยู่ในแท็บนี้ ไม่มีการอัปโหลด บัญชี API บันทึกอัตโนมัติ หรือการประมวลผลเซิร์ฟเวอร์

สร้างมาร์กดาวน์

การแสดงตัวอย่างตารางที่แสดงผล

ฉันจะสร้างตาราง Markdown ได้อย่างไร

ป้อนแถวส่วนหัวและแถวข้อมูล เลือกการจัดแนวคอลัมน์แต่ละคอลัมน์ จากนั้นคัดลอก Markdown ที่สร้างขึ้น ไปป์หลบหนีและมีเบาะแถวที่นำเข้าไม่เท่ากัน

คำถามที่พบบ่อย

ฉันจะสร้างตาราง Markdown ได้อย่างไร

ป้อนแถวส่วนหัวและแถวข้อมูล เลือกการจัดแนวคอลัมน์แต่ละคอลัมน์ จากนั้นคัดลอก Markdown ที่สร้างขึ้น ไปป์หลบหนีและมีเบาะแถวที่นำเข้าไม่เท่ากัน

ตารางของฉันถูกอัพโหลดหรือไม่?

ไม่ ตารางของคุณได้รับการประมวลผลในแท็บเบราว์เซอร์นี้ การนำเข้า แก้ไข และ Markdown ที่สร้างขึ้นจะไม่ถูกส่งไปยังเซิร์ฟเวอร์หรือบันทึกโดยอัตโนมัติ

ฉันสามารถนำเข้า CSV หรือ TSV ได้หรือไม่

ใช่ วางค่าที่คั่นด้วยเครื่องหมายจุลภาค คั่นด้วยอัฒภาค หรือคั่นด้วยแท็บ จากนั้นนำเข้าค่าเหล่านั้นลงในตารางที่แก้ไขได้ รองรับช่อง CSV ที่มีเครื่องหมายคำพูดและตัวคั่นที่มีเครื่องหมายคำพูด

ท่อและตัวแบ่งบรรทัดได้รับการจัดการอย่างไร

ไปป์ภายในเซลล์ถูก Escape ดังนั้นจึงไม่แยกตาราง Markdown แบ็กสแลชจะถูกหลีกด้วยเช่นกัน และตัวแบ่งเซลล์จะแสดงด้วย <br>
