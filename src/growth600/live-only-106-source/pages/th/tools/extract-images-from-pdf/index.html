แยกรูปภาพจาก PDF

เลือก PDF เพื่อค้นหาภาพแรสเตอร์ที่ฝังไว้ ดูตัวอย่าง และบันทึกสำเนา PNG แยกกันหรือ ZIP หนึ่งชุด หน้าต่างๆ จะไม่ถูกแรสเตอร์เป็นภาพหน้าจอ

Extracts รองรับออบเจ็กต์ภาพแรสเตอร์ที่ฝังอยู่ มันไม่ได้เปลี่ยนหน้า PDF ทั้งหมดให้เป็นรูปภาพ ภาพวาดเวกเตอร์และข้อความบนหน้าไม่ใช่ภาพแรสเตอร์ที่แยกจากกัน

ไฟล์ของคุณยังคงอยู่ในอุปกรณ์นี้และไม่ได้อัปโหลด พิกเซลที่แยกออกมาจะถูกเข้ารหัสใหม่เป็น PNG ดังนั้นรูปแบบไฟล์และข้อมูลเมตาดั้งเดิมที่ฝังไว้จะไม่ถูกรักษาไว้

ขีดจำกัดท้องถิ่น: 25 MiB PDF, 300 หน้า, 200 ภาพ, 8 ล้านพิกเซลต่อภาพ, รวม 16 ล้านพิกเซลและ 25 MiB ZIP PDF ขนาดใหญ่ใช้หน่วยความจำอุปกรณ์ แนะนำให้ใช้คอมพิวเตอร์

พบรูปภาพ

จะแสดงสูงสุด 12 ภาพแรก รูปภาพทุกรายการยังคงสามารถดาวน์โหลดได้

ดาวน์โหลดภาพทั้งหมด (ZIP)

    ฉันจะดึงภาพจาก PDF ได้อย่างไร

    เลือก PDF และเลือกแยกรูปภาพ เบราว์เซอร์นี้จะอ่านออบเจ็กต์รูปภาพแรสเตอร์ที่ฝังไว้ที่รองรับ และแปลงพิกเซลที่ถอดรหัสแล้วเป็นไฟล์ PNG ดาวน์โหลดภาพแต่ละภาพหรือ ZIP หนึ่งภาพ

    ฉันจะดึงภาพจาก PDF ได้อย่างไร

    เลือก PDF และเลือกแยกรูปภาพ เบราว์เซอร์นี้จะอ่านออบเจ็กต์รูปภาพแรสเตอร์ที่ฝังไว้ที่รองรับ และแปลงพิกเซลที่ถอดรหัสแล้วเป็นไฟล์ PNG ดาวน์โหลดภาพแต่ละภาพหรือ ZIP หนึ่งภาพ

    PDF หรือรูปภาพของฉันถูกอัปโหลดหรือไม่

    ไม่ PDF ของคุณได้รับการประมวลผลในแท็บเบราว์เซอร์นี้ เครื่องมือนี้ไม่ได้อัปโหลดไฟล์หรือบันทึกลงในบัญชี

    เครื่องมือนี้เปลี่ยนทุกหน้า PDF ให้เป็นรูปภาพหรือไม่

    ไม่ โดยจะค้นหาออบเจ็กต์ภาพแรสเตอร์ที่ฝังไว้ที่รองรับ ใช้เครื่องมือ PDF-to-image หากคุณต้องการให้ภาพที่แสดงผลของแต่ละหน้า

    PNG ที่แตกออกมาจะเป็นแบบไบต์ต่อไบต์เหมือนกับไฟล์ที่ฝังหรือไม่

    ไม่ เบราว์เซอร์จะถอดรหัสออบเจ็กต์รูปภาพที่รองรับ และเข้ารหัสพิกเซลอีกครั้งเป็น PNG ตามขนาดออบเจ็กต์ที่ถอดรหัส การบีบอัดต้นฉบับ รูปแบบไฟล์ และข้อมูลเมตาจะไม่ถูกรักษาไว้

    เหตุใดภาพ PDF บางภาพจึงไม่ปรากฏขึ้น

    งานศิลปะเวกเตอร์ มาสก์รูปภาพ การเข้ารหัสที่ผิดปกติ การป้องกันด้วยรหัสผ่าน ไฟล์ที่มีรูปแบบไม่ถูกต้อง และขีดจำกัดหน่วยความจำของเบราว์เซอร์สามารถป้องกันการแตกไฟล์ได้ เครื่องมือรายงานเฉพาะออบเจ็กต์ที่รองรับและไม่ได้อัปโหลดไฟล์ของคุณ
