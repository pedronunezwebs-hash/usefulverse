สร้างแบบจำลองกระแสการชำระเงินที่เท่ากันด้วยจำนวนเงิน อัตรา และกำหนดการเริ่มต้น ผลลัพธ์เป็นเพียงการประมาณการ ไม่ใช่การเสนอราคาหรือคำแนะนำทางการเงิน

ถือว่าอัตรารายปีที่กำหนดคงที่หารด้วยความถี่ในการชำระเงิน ไม่รวมค่าธรรมเนียม ภาษี และอัตราการเปลี่ยนแปลง

มีการอัปโหลดค่าของฉันหรือไม่

ไม่ การคำนวณทำงานในแท็บเบราว์เซอร์นี้ และเครื่องมือนี้ไม่ได้อัปโหลดหรือบันทึกค่า

มูลค่าปัจจุบันและอนาคตแตกต่างกันอย่างไร?

มูลค่าปัจจุบันจะประมาณว่ากระแสการชำระเงินมีมูลค่าเท่าใดในขณะนี้ มูลค่าในอนาคตจะประมาณว่ายอดคงเหลือเริ่มต้นและการมีส่วนร่วมที่เกิดขึ้นประจำอาจสะสมได้เมื่อสิ้นสุดกำหนดการอย่างไร

สิ่งนี้คาดการณ์การจ่ายเงินตามสัญญารายปีหรือไม่

ไม่ มันเป็นเลขคณิตทั่วไปที่มีสมมติฐานที่คุณป้อน ผลิตภัณฑ์จริงอาจรวมค่าธรรมเนียม การรับประกัน ภาษี และเงื่อนไขที่เครื่องคิดเลขนี้ไม่ได้จำลองไว้
