ผู้สร้างต้นไม้ครอบครัว

สร้างแผนภูมิครอบครัวจากข้อมูลที่คุณรู้อยู่แล้ว เพิ่มบุคคล เชื่อมต่อลิงก์หลัก จากนั้นส่งออกไดอะแกรมหรือไฟล์ GEDCOM หน้านี้จะไม่ค้นหาบันทึกหรือบันทึกข้อมูลครอบครัวของคุณ

ผู้คนบนต้นไม้ต้นนี้
เชื่อมต่อผู้ปกครองและบุตรหลาน

รายละเอียดครอบครัวอาจเป็นเรื่องละเอียดอ่อน ข้อมูลจะยังคงอยู่ในหน่วยความจำจนกว่าคุณจะปิดหรือรีเซ็ตหน้านี้ การส่งออกอาจมีข้อมูลส่วนตัว

แผนภูมิลำดับวงศ์ตระกูล

    ฉันจะสร้างแผนภูมิต้นไม้ครอบครัวได้อย่างไร

    เพิ่มแต่ละคนหนึ่งครั้ง จากนั้นเชื่อมต่อผู้ปกครองกับลูก แผนภูมิจะบล็อกลิงก์ที่ซ้ำกัน มากกว่าสองรายการที่มีรายการพ่อแม่และรอบบรรพบุรุษ ส่งออกไดอะแกรม SVG หรือไฟล์ข้อความ GEDCOM เมื่อคุณพร้อม

    คำถามที่พบบ่อย

    ฉันจะสร้างแผนภูมิต้นไม้ครอบครัวได้อย่างไร

    เพิ่มแต่ละคนหนึ่งครั้ง จากนั้นเชื่อมต่อผู้ปกครองกับลูก แผนภูมิจะบล็อกลิงก์ที่ซ้ำกัน มากกว่าสองรายการที่มีรายการพ่อแม่และรอบบรรพบุรุษ ส่งออกไดอะแกรม SVG หรือไฟล์ข้อความ GEDCOM เมื่อคุณพร้อม

    ข้อมูลครอบครัวของฉันถูกอัพโหลดหรือบันทึกหรือไม่?

    ไม่ แผนภูมิยังคงอยู่ในเซสชันของหน้านี้ มันไม่ได้อัปโหลดหรือบันทึกลงในพื้นที่เก็บข้อมูลของเบราว์เซอร์ ไฟล์ที่ส่งออกเป็นของคุณสำหรับจัดเก็บและแชร์ ดังนั้นโปรดตรวจสอบรายละเอียดส่วนตัวก่อน

    เครื่องมือนี้สามารถค้นหาญาติหรือบันทึกสาธารณะได้หรือไม่

    ไม่ จะจัดระเบียบเฉพาะรายละเอียดที่คุณป้อนเท่านั้น ไม่ค้นหาบันทึก ตรวจสอบตัวตน หรือสร้างความสัมพันธ์ทางกฎหมาย

    ไฟล์ GEDCOM คืออะไร

    GEDCOM เป็นรูปแบบข้อความที่ใช้ในการย้ายบันทึกประวัติครอบครัวระหว่างโปรแกรมลำดับวงศ์ตระกูลที่เข้ากันได้ ตรวจสอบไฟล์ที่ส่งออกก่อนแชร์

    แผนภูมิรองรับผู้ปกครองมากกว่าสองคนหรือไม่

    เวอร์ชันนี้อนุญาตให้มีผู้ปกครองที่อยู่ในรายการได้สูงสุดสองคนต่อคน ความสัมพันธ์ในครอบครัวอาจซับซ้อนเกินกว่าที่แผนภูมินี้จะเป็นตัวแทนได้

    หน้าแรก

    เครื่องมือฟรีบนเบราว์เซอร์ ข้อมูลจะอยู่บนอุปกรณ์ของคุณเมื่อเครื่องมือนั้นรองรับ
