เครื่องคิดเลขบัค

ป้อนน้ำหนักตัว ขนาดเครื่องดื่ม และความแข็งแกร่งเพื่อดูสถานการณ์ทางคณิตศาสตร์ที่มีความไม่แน่นอนสูง นี่ไม่ใช่การวัดหรือการทำนายระดับแอลกอฮอล์ในเลือดของคุณที่เชื่อถือได้

อย่าใช้การประมาณนี้เพื่อตัดสินใจว่าคุณสามารถขับรถ ใช้เครื่องจักร หรือทำการตัดสินใจทางการแพทย์หรือทางกฎหมายได้หรือไม่ ไม่ใช่การตรวจลมหายใจ/เลือด การวินิจฉัย หรือการทำนายที่เชื่อถือได้ แอลกอฮอล์ใดๆ ก็ตามสามารถส่งผลเสียต่อการขับขี่ได้ หากคุณดื่มสุราอยู่ อย่าขับรถ—เตรียมการเดินทางอย่างมีสติ หากมีใครหมดสติ ตื่นยาก มีอาการชัก หรือหายใจช้า/ผิดปกติ โปรดติดต่อบริการฉุกเฉินในพื้นที่ทันที

ป้อนน้ำหนักโดยประมาณปัจจุบัน เครื่องมือจะแปลงปอนด์เป็นกิโลกรัมเมื่อเลือก ใส่เครื่องดื่มได้ถึง 8 ประเภท ใช้นับ 0 สำหรับการไม่มีแอลกอฮอล์ แต่ละแถวถือว่าเสิร์ฟและความแข็งแกร่งเท่ากัน

สมมติฐานที่ง่ายขึ้น: อัตราส่วนการกระจายที่ชัดเจน 0.45–0.80 และการกำจัด 0.01–0.03 เปอร์เซ็นต์ต่อชั่วโมง จะดูดซึมได้ทันที การดูดซึมและการกำจัดที่แท้จริงนั้นแตกต่างกันอย่างมาก อาจเกิดขึ้นต่อไปหลังจากดื่ม และไม่สามารถอนุมานได้จากข้อมูลเหล่านี้

รายการของฉันถูกอัปโหลดหรือไม่

ไม่ การคำนวณรันในเบราว์เซอร์นี้ รายการจะไม่ถูกอัพโหลด จัดเก็บ หรือส่งไปยังเซิร์ฟเวอร์

ช่วยบอกฉันได้ไหมว่าฉันขับรถได้อย่างปลอดภัยหรือไม่?

ไม่ ห้ามใช้เครื่องคิดเลขในการตัดสินใจเด็ดขาด การประมาณการของ BAC มีความไม่แน่นอนอย่างมาก การด้อยค่าอาจเริ่มต่ำกว่าขีดจำกัดที่กฎหมายกำหนด และอาจยังคงดูดซึมแอลกอฮอล์ได้หลังจากดื่มครั้งสุดท้าย หากคุณดื่มอย่าขับรถ จัดการเดินทางอย่างมีสติ

ผลลัพธ์คือระดับแอลกอฮอล์ในเลือดจริงของฉันหรือไม่

ไม่ มันเป็นภาพประกอบสไตล์ Widmark ที่เรียบง่าย ไม่ใช่การทดสอบหรือการทำนายที่เชื่อถือได้ องค์ประกอบของร่างกาย การดูดซึม อาหาร สุขภาพ ยา จังหวะการดื่ม และปัจจัยอื่นๆ ยังไม่ทราบจากรายการเหล่านี้

ทำไมมันแสดงได้หลากหลาย?

สมมติฐานด้านการกระจายและการกำจัดแตกต่างกันไปในแต่ละบุคคล ช่วงนี้เป็นเพียงภาพประกอบและไม่สามารถรับประกันได้ว่าจะมีการวัดจริงอยู่ภายใน
