แบบฝึกหัดการหายใจ

เลือกจังหวะการหายใจที่สบายและทำตามคำแนะนำบนหน้าจอ เน้นความรู้สึกผ่อนคลายและหยุดได้ทุกเมื่อที่ต้องการ

คำแนะนำจะหลีกเลี่ยงการเคลื่อนไหวฉับพลันเมื่อเปิดโหมดลดการเคลื่อนไหว

นี่คือตัวจับเวลาเพื่อสุขภาวะทั่วไป ไม่ใช่การรักษาทางการแพทย์ หายใจอย่างสบายและหยุดหากรู้สึกไม่สบาย

จะใช้แบบฝึกหัดการหายใจนี้อย่างไร?

เลือกรูปแบบที่มีให้หรือกำหนดแต่ละช่วงเอง เลือกความยาวเซสชันแล้วกดเริ่ม สามารถหยุดชั่วคราวหรือเริ่มใหม่ได้ตลอดเวลา เสียงเป็นตัวเลือกเสริมและเริ่มหลังจากกดเริ่มเท่านั้น

จะใช้แบบฝึกหัดการหายใจนี้อย่างไร?

เลือกรูปแบบที่มีให้หรือกำหนดแต่ละช่วงเอง เลือกความยาวเซสชันแล้วกดเริ่ม สามารถหยุดชั่วคราวหรือเริ่มใหม่ได้ตลอดเวลา เสียงเป็นตัวเลือกเสริมและเริ่มหลังจากกดเริ่มเท่านั้น

เซสชันการหายใจของฉันถูกอัปโหลดหรือไม่?

ไม่ ระบบจับเวลาทำงานอยู่บนหน้านี้เท่านั้น ไม่มีบัญชี การอัปโหลด API หรือการบันทึกข้อมูลเซสชัน

ใช้เทคนิค Box Breathing หรือ 4-7-8 ได้ไหม?

ได้ เลือกรูปแบบที่ตั้งค่าไว้หรือปรับเวลาแต่ละช่วงได้ รูปแบบเหล่านี้เป็นแนวทางกำหนดจังหวะการหายใจ ไม่ใช่การรักษาทางการแพทย์

ตัวจับเวลาจะยังทำงานเมื่อปิดแท็บหรือไม่?

ไม่รับประกัน เบราว์เซอร์อาจหยุดแท็บที่ไม่ได้เปิดใช้งานและอุปกรณ์อาจเข้าสู่โหมดพัก ควรเปิดหน้านี้ไว้และให้อุปกรณ์ทำงานเพื่อให้จับเวลาได้แม่นยำขึ้น

ปิดเสียงหรือหยุดก่อนกำหนดได้ไหม?

ได้ เสียงเป็นตัวเลือกและปิดได้ กดหยุดชั่วคราวหรือเริ่มใหม่เพื่อหยุดการจับเวลาทันที.
