เริ่มรอบ เลี้ยวไปทางอาหารโดยใช้ arrow keys, WASD หรือปุ่มสัมผัส และหลีกเลี่ยงกำแพงและร่างกายของคุณ หยุดชั่วคราวเมื่อใดก็ได้ การกินอาหารทำให้งูโตและเพิ่มจุดหนึ่ง

เกมงูบันทึกคะแนนของฉันหรือใช้บัญชีหรือไม่?

ไม่จำเป็นต้องมีบัญชีหรือดาวน์โหลด คะแนนและเซสชันปัจจุบันของคุณดีที่สุดจะอยู่ในหน่วยความจำใน tab นี้เท่านั้น พวกเขาจะไม่ถูกอัปโหลดหรือบันทึกหลังจากที่คุณออกไป

ฉันสามารถเล่นบนโทรศัพท์หรือ tablet ได้หรือไม่?

ใช่ ใช้ปุ่มทิศทางบนหน้าจอ แป้นพิมพ์ที่มี arrow keys หรือ WASD ก็ใช้งานได้บนคอมพิวเตอร์เช่นกัน

ฉันสามารถหยุดเกมชั่วคราวได้หรือไม่?

ใช่ เลือกหยุดชั่วคราวได้ตลอดเวลา งูหยุดเคลื่อนไหวจนกว่าคุณจะดำเนินการต่อ

ฉันจะได้เกมเดิมทุกครั้งหรือไม่?

เค้าโครงของกระดานยังคงคุ้นเคย แต่ตำแหน่งอาหารจะถูกสุ่มสำหรับแต่ละรอบใหม่ คะแนนเซสชันปัจจุบันและดีที่สุดจะไม่ถูกบันทึกหลังจากที่คุณออกไป
