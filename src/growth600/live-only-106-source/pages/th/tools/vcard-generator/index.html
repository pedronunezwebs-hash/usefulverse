เครื่องกำเนิด VCard

สร้างผู้ติดต่อดิจิทัลเดียวเป็นไฟล์ .vcf ในเบราว์เซอร์ของคุณ เลือก vCard 3.0 หรือ 4.0 เพิ่มรายละเอียดการติดต่อ และเลือกฝังรูปภาพ JPEG หรือ PNG ขนาดเล็กได้

ตัวเลือก JPEG หรือ PNG สูงสุด 128 KiB ภาพถ่ายถูกฝังอยู่ในไฟล์ VCF มันไม่ได้อัพโหลด

หนึ่งรายชื่อ โทรศัพท์สูงสุด 5 เครื่องและอีเมล 5 รายการ 500 ตัวอักษรต่อช่องข้อความ และจำกัดไฟล์ที่สร้าง 1 MiB มีเฉพาะ vCard 3.0 และ 4.0 เท่านั้น

รันในเครื่องหลังจากที่คุณเลือกสร้าง ไม่มีบัญชี การเข้าถึงสมุดติดต่อ การอัปโหลด API การประมวลผลเซิร์ฟเวอร์ หรือการบันทึกอัตโนมัติ

ข้อมูลติดต่อของฉันถูกอัพโหลดหรือไม่?
ไม่ รายละเอียดและรูปภาพเสริมได้รับการประมวลผลบนอุปกรณ์นี้ ไม่มีการอัปโหลด บัญชี การประมวลผลเซิร์ฟเวอร์ หรือการบันทึกอัตโนมัติ
vCard 3.0 และ 4.0 แตกต่างกันอย่างไร?
เป็นรูปแบบการติดต่อ vCard สองเวอร์ชัน เครื่องมือนี้จะเขียนไฟล์ข้อความ VCF ที่เข้ากันได้โดยใช้เวอร์ชันที่คุณเลือก แอพผู้ติดต่ออาจรองรับแตกต่างกัน
สิ่งนี้จะยืนยันหมายเลขโทรศัพท์หรือที่อยู่อีเมลหรือไม่?
ไม่ จะตรวจสอบรูปแบบพื้นฐานเท่านั้น ไม่สามารถตรวจสอบได้ว่าหมายเลข ตู้ไปรษณีย์ ที่อยู่ หรือเว็บไซต์เป็นของบุคคลนั้น
