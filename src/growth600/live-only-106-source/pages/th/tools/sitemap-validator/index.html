หน้าแรก/เครื่องมือตรวจสอบแผนผังเว็บไซต์

ใช้ฟรี ไม่ต้องมีบัญชี

เครื่องมือตรวจสอบแผนผังเว็บไซต์

วางเอกสาร XML แผนผังเว็บไซต์เพื่อตรวจสอบโครงสร้าง รายการ URL วันที่ และฟิลด์ทั่วไป XML ถูกแยกวิเคราะห์ในเบราว์เซอร์นี้เท่านั้น เพจที่แสดงไว้จะไม่ถูกดึงข้อมูล

รองรับ urlset หรือ sitemapindex มาตรฐาน สูงสุด 1,000,000 อักขระและ 5,000 รายการโดยตรง

ตรวจสอบ XML ในเครื่องเท่านั้น: สิ่งนี้ไม่ได้ขอ URL ที่อยู่ในรายการ รวบรวมข้อมูลเว็บไซต์ ส่งแผนผังเว็บไซต์ หรือรับประกันการจัดทำดัชนี

สรุปการตรวจสอบ

ผลการสืบค้น

    เครื่องมือตรวจสอบแผนผังเว็บไซต์นี้ตรวจสอบอะไรบ้าง

    จะตรวจสอบรายการ urlset หรือ sitemapindex, ตำแหน่ง HTTP หรือ HTTPS แบบสัมบูรณ์, URL ที่ได้รับการปรับมาตรฐานซ้ำ, วันที่ล่าสุด, ค่าความถี่การเปลี่ยนแปลงและลำดับความสำคัญที่เป็นตัวเลือก และเนมสเปซแผนผังเว็บไซต์ คำเตือนและข้อผิดพลาดจะแสดงตามหมายเลขรายการ

    คำถามที่พบบ่อย

    เครื่องมือตรวจสอบแผนผังเว็บไซต์นี้ตรวจสอบอะไรบ้าง

    จะตรวจสอบรายการ urlset หรือ sitemapindex, ตำแหน่ง HTTP หรือ HTTPS แบบสัมบูรณ์, URL ที่ได้รับการปรับมาตรฐานซ้ำ, วันที่ล่าสุด, ค่าความถี่การเปลี่ยนแปลงและลำดับความสำคัญที่เป็นตัวเลือก และเนมสเปซแผนผังเว็บไซต์ คำเตือนและข้อผิดพลาดจะแสดงตามหมายเลขรายการ

    มีการอัปโหลดหรือส่งแผนผังไซต์ของฉันหรือไม่

    ไม่ XML ได้รับการประมวลผลภายในเบราว์เซอร์ของคุณ เครื่องมือนี้จะไม่รวบรวมข้อมูล URL, ดึงไฟล์แผนผังเว็บไซต์ระยะไกล, ส่งสิ่งใดๆ ไปยังเครื่องมือค้นหา หรือยืนยันการจัดทำดัชนี

    สิ่งนี้จะตรวจสอบว่า URL ของแผนผังไซต์ใช้งานได้หรือไม่

    ไม่ โดยจะตรวจสอบไวยากรณ์ของ URL และรายการที่ซ้ำกันภายใน XML ที่วาง แต่ตั้งใจว่าจะไม่ขอ URL หรือรวบรวมข้อมูลไซต์

    แผนผังเว็บไซต์ที่ถูกต้องหมายความว่า Google จัดทำดัชนีหน้าเว็บของตนหรือไม่

    หมายเลข การตรวจสอบ XML ไม่ใช่รายงานการส่งหรือจัดทำดัชนีของเครื่องมือค้นหา ส่งแผนผังเว็บไซต์ผ่านเครื่องมือค้นหาเว็บมาสเตอร์ที่เกี่ยวข้องและตรวจสอบสถานะของตนเอง

    ฉันสามารถตรวจสอบดัชนีแผนผังเว็บไซต์ได้หรือไม่

    ใช่ เครื่องมือตรวจสอบรายการ sitemapindex โดยตรงและฟิลด์ loc และ Lastmod แต่จะไม่ดาวน์โหลดหรือตรวจสอบไฟล์แผนผังไซต์ที่อ้างอิงซ้ำ
