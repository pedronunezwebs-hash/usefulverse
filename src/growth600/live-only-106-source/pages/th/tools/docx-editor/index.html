โปรแกรมแก้ไข DOCX

ทำการแก้ไขข้อความที่เน้นไปที่ไฟล์ Word DOCX สมัยใหม่ในเบราว์เซอร์นี้ ตัวแก้ไขเปลี่ยนแปลงข้อความที่มีอยู่ในเอกสารหลักและคงส่วนอื่น ๆ ของเอกสารไว้ไม่เปลี่ยนแปลง ไม่ใช่การแทนที่ Word โดยสมบูรณ์ และการจัดรูปแบบที่ซับซ้อนอาจไม่แสดงตัวอย่างที่นี่

Modern .docx เท่านั้น สูงสุด 25 MiB, แพ็คเกจขยาย 80 MiB, เอกสาร XML 8 MiB, ส่วนข้อความ 500 ส่วน และ 250,000 ตัวอักษร เอกสารขนาดใหญ่ทำงานได้ดีกว่าบนคอมพิวเตอร์

การประมวลผลจะเกิดขึ้นบนอุปกรณ์ของคุณหลังจากที่คุณเลือกไฟล์ ไม่มีการอัปโหลด บัญชี API บันทึกอัตโนมัติ หรือการประมวลผลของเซิร์ฟเวอร์

โปรแกรมแก้ไขที่เน้นการเปลี่ยนแปลงเฉพาะข้อความที่มีอยู่ในเอกสารหลัก โดยจะรักษาสไตล์ รูปภาพ และเนื้อหาในส่วนของแพ็คเกจอื่นๆ แต่จะบรรจุคอนเทนเนอร์ DOCX ZIP ใหม่ ไม่แก้ไขส่วนหัว ท้ายกระดาษ ความคิดเห็น เชิงอรรถ การจัดรูปแบบ โครงสร้างย่อหน้า หรือการติดตามการเปลี่ยนแปลง ไม่รองรับมาโครและแพ็คเกจที่เซ็นชื่อแบบดิจิทัล

ข้อความเอกสารที่มีอยู่

การแสดงตัวอย่างข้อความ

ฉันสามารถแก้ไขอะไรในไฟล์ DOCX ได้บ้าง

คุณสามารถแก้ไขส่วนของข้อความที่มีอยู่ในย่อหน้าและเซลล์ตารางในไฟล์ .docx ที่ทันสมัย ดูตัวอย่างข้อความ และดาวน์โหลดสำเนาที่แก้ไขแล้ว ตัวแก้ไขนี้ไม่เพิ่มหรือลบย่อหน้า เปลี่ยนการจัดรูปแบบ แก้ไขส่วนหัวหรือส่วนท้าย หรือสนับสนุนการเปลี่ยนแปลงที่ติดตาม

คำถามที่พบบ่อย

ฉันสามารถแก้ไขอะไรในไฟล์ DOCX ได้บ้าง

คุณสามารถแก้ไขส่วนของข้อความที่มีอยู่ในย่อหน้าและเซลล์ตารางในไฟล์ .docx ที่ทันสมัย ดูตัวอย่างข้อความ และดาวน์โหลดสำเนาที่แก้ไขแล้ว ตัวแก้ไขนี้ไม่เพิ่มหรือลบย่อหน้า เปลี่ยนการจัดรูปแบบ แก้ไขส่วนหัวหรือส่วนท้าย หรือสนับสนุนการเปลี่ยนแปลงที่ติดตาม

เอกสาร Word ของฉันถูกอัปโหลดหรือไม่

ไม่ ไฟล์จะถูกประมวลผลในเบราว์เซอร์นี้หลังจากที่คุณเลือกแล้ว มันไม่ได้ถูกอัพโหลด บันทึกโดยอัตโนมัติ หรือส่งไปยังเซิร์ฟเวอร์

ไฟล์ที่แก้ไขจะคงรูปแบบเดิมของฉันไว้หรือไม่

ลักษณะข้อความและเนื้อหาในส่วนของแพ็คเกจอื่นๆ จะยังคงอยู่ เมื่อส่วนข้อความถูกแทนที่ การจัดรูปแบบการรันที่มีอยู่จะยังคงอยู่ เครื่องมือนี้ไม่มีการควบคุมการจัดรูปแบบ Rich Text หรือรับประกันว่าฟีเจอร์ Word ทุกฟีเจอร์จะแสดงผลเหมือนกัน

นี้สามารถแก้ไขการติดตามการเปลี่ยนแปลง ส่วนหัว หรือเอกสารที่เซ็นชื่อได้หรือไม่

ไม่ ตัวแก้ไขที่โฟกัสจะเปลี่ยนข้อความที่ทำงานในเอกสารหลักเท่านั้น ไม่รองรับเวิร์กโฟลว์การเปลี่ยนแปลงที่ติดตาม ส่วนหัวและส่วนท้าย มาโคร และไฟล์ที่เซ็นชื่อแบบดิจิทัล
