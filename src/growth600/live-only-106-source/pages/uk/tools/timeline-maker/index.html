Поширені запитання

Як створити хронологію події?

Додайте принаймні дві події з назвами та виберіть дату початку для кожної. Додайте кінцеву дату для тривалості або залиште її пустою для одноденної події. Створіть часову шкалу, щоб сортувати події за датою, налаштувати масштаб і завантажити файли SVG або CSV.

Чи завантажені події моєї хронології?

Ні. Імена та дати обробляються на цій вкладці браузера. SVG і CSV генеруються на вашому пристрої; нічого не завантажується і не зберігається автоматично.

Чи може подія тривати більше одного дня?

Так. Введіть дату початку та завершення. Діаграма містить обидві кінцеві дати; залиште кінець порожнім для одноденної події.

Чи створює ця шкала часу залежності завдань?

Ні. Показує датовані події та діапазони в хронологічному порядку. Використовуйте інструмент розкладу проекту для завдань, тривалості та залежностей.

Чи можу я зберегти або поділитися хронологією?

Завантажте SVG для масштабованого зображення або CSV для таблиці подій. Сторінка не завантажує та не зберігає автоматично дані про вашу подію.
