введіть зріст і вагу, щоб порівняти дві загальні оцінки площі поверхні тіла. Результати формул можуть відрізнятися; це математична інформація, а не медичне керівництво.

лише для дорослих. Підтримуваний діапазон: 50–250 см і 10–500 кг, включаючи еквівалентні одиниці США.

Як оцінюється площа поверхні тіла?

мої вимірювання завантажено?

Ні. Оцінки виконуються в цьому браузері. Вимірювання не зберігаються та не завантажуються.

Чому формули дають різні результати?

кожна формула моделює зріст і вагу по-різному. Відображена різниця є арифметичною, а не мірою того, яка формула підходить для конкретної людини.

Чи можу я використовувати площу поверхні тіла для розрахунку дози ліків?

Ні. Не використовуйте цю сторінку, щоб вибрати або змінити дозу. Користуйтеся лише інструкціями кваліфікованого медичного працівника.

Чи працює цей калькулятор для дітей?

Ні. Це лише оцінка для дорослих і не передбачає педіатричних формул чи клінічної інтерпретації.
