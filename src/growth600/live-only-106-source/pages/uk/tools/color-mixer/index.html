Поширені запитання

Як змішати два кольори онлайн?

Виберіть два або більше кольорів, встановіть вагу для кожного та виберіть sRGB або змішування лінійного світла. Результат показує значення HEX, RGB і HSL.

Чи завантажено мої кольори?

Ні. Обчислення кольорів виконується локально у вашому браузері. Не потрібно завантажувати обліковий запис або зображення.

Чому суміші sRGB і лінійного світла виглядають по-різному?

sRGB усереднює значення закодованих каналів екрана. Лінійний світловий режим спочатку перетворює їх на світлові значення, змішує, а потім перетворює назад. Обраний метод змінює результат.

Чи можна передбачити колір змішаної фарби?

Ні. Це цифрова математика кольору для екранів, а не фізична модель пігменту. Справжня фарба залежить від властивостей пігменту, прозорості, концентрації, освітлення та поверхні.

які кольорові формати можна копіювати?

результат відображає HEX, RGB і HSL. Ви можете скопіювати значення HEX або завантажити невелику палітру кольорів CSS.
