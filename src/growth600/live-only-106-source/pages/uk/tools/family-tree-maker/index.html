Створення сімейного дерева

Створіть сімейну діаграму з інформації, яку ви вже знаєте. Додайте людей, підключіть батьківські посилання, потім експортуйте діаграму або файл GEDCOM. Сторінка не шукає записи та не зберігає дані вашої родини.

Люди на цьому дереві
підключення батьківського та дочірнього

Генеалогічне дерево

    Як створити сімейне дерево?

    додайте кожну особу один раз, а потім підключіть батьківську до дочірньої. Діаграма блокує повторювані посилання, більше двох перерахованих батьків і цикли предків. Коли будете готові, експортуйте діаграму SVG або текстовий файл GEDCOM.

    Ні. Діаграма залишається в цьому сеансі сторінки. Він не завантажується та не зберігається в пам’яті браузера. Експортований файл є вашим, щоб зберігати та ділитися ним, тому спочатку перевірте його на особисті дані.

    Чи може цей інструмент знайти родичів або публічні записи?

    Ні. Він упорядковує лише дані, які ви вводите. Він не шукає записи, не перевіряє особи та не встановлює правові відносини.

    Що таке файл GEDCOM?

    GEDCOM — це текстовий формат, який використовується для переміщення записів сімейної історії між сумісними генеалогічними програмами. Перевірте експортований файл перед тим, як поділитися ним.
