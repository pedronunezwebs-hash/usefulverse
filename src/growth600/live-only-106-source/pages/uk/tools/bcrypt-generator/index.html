Головна/Генератор Bcrypt

Безкоштовно, без облікового запису

Генератор Bcrypt

Згенеруйте стандартний хеш bcrypt або перевірте пароль на існуючий хеш bcrypt. Робота виконується в локальному браузері Worker, а пароль очищається після кожної перевірки.

Bcrypt використовує лише перші байти 72 UTF-8. Цей інструмент відхиляє довші значення, а не мовчки їх скорочує. Вартість 8–14 експоненціально збільшує роботу; більші витрати можуть зайняти більше часу, особливо на телефонах. Місцевий працівник забезпечує адаптивність сторінки, але ваш пристрій виконує роботу.

Використовуйте тестовий пароль, а не справжній пароль для входу. Результат для навчання та перевірки сумісності; не використовуйте цю сторінку браузера як робочу систему зберігання облікових записів.

Вставте стандартний 60-символьний хеш bcrypt. Перевірка підтримує bcrypt коштує 4–14; незвично дорогі хеші відхиляються, щоб уникнути необмеженої роботи на вашому пристрої.

Результат

Що робить хеш bcrypt?

Bcrypt — це функція хешування паролів, а не шифрування. Він поєднує в собі односторонній хеш із випадковою сіллю та робочим фактором, що налаштовується. Хеш можна перевірити на потенційний пароль, але не можна розшифрувати для виявлення оригіналу.

Поширені запитання

Що робить хеш bcrypt?

Bcrypt — це функція хешування паролів, а не шифрування. Він поєднує в собі односторонній хеш із випадковою сіллю та робочим фактором, що налаштовується. Хеш можна перевірити на потенційний пароль, але не можна розшифрувати для виявлення оригіналу.

Чи завантажено чи збережено мій пароль або хеш?

Ні. Хешування та перевірка виконуються в цьому браузері. Сторінка не надсилає введений пароль чи хеш на сервер і не зберігає їх; поле пароля очищається після завершення операції. Для безпеки використовуйте тестовий пароль, а не справжній пароль облікового запису.

Чи шифрує bcrypt мій пароль?

Ні. Bcrypt — це одностороннє хешування пароля, а не оборотне шифрування. Він призначений для того, щоб дозволити програмному забезпеченню перевіряти кандидатський пароль, не зберігаючи вихідний пароль.

Чому bcrypt має обмеження у 72 байт?

Формат bcrypt обробляє максимум 72 UTF-8 байтів. Цей інструмент відмовляється від довшого введення, тому різні паролі ніколи мовчки не розглядаються як однакові скорочені значення.

Чи варто мені зберігати цей хеш для реального облікового запису?

Не використовуйте цю сторінку як робочу систему облікових даних. Справжні служби повинні хешувати паролі на своєму надійному сервері з підтримуваними бібліотеками автентифікації, відповідними параметрами, обмеженнями швидкості та захистом облікових записів.
