Калькулятор лінійного програмування

Введіть лінійну ціль і до восьми обмежень, щоб розв’язати лінійну програму з двома змінними з невід’ємними x і y. Двофазний симплекс-метод повідомляє оптимум, нездійсненність або необмеженість і показує кожну точку.

Цільові коефіцієнти (x, y)

По одному на рядок: a,b <= Rhs, a,b >= Rhs або a,b = Rhs

Використовує не більше восьми обмежень і коефіцієнтів/праві частини в межах ±1 000 000. Обидві змінні рішення мають x ≥ 0 і y ≥ 0. Використовуйте кому між коефіцієнтами x і y; введіть одну нерівність або рівність на рядок.

Двофазний простий симплексний розв’язувач для двох змінних. Числовий допуск використовується для поворотів із плаваючою комою; майже вироджені проблеми можуть бути чутливими до округлення. Замість вигаданого оптимуму повідомляються випадки нездійсненних, необмежених і граничних ітерацій.

Результати лінійної програми

Результат лише для математичної моделі, яку ви ввели. Він не підтверджує, чи цілі, обмеження, одиниці чи припущення підходять для реального рішення.

    Як працює симплексний калькулятор із двома змінними?

    Він перетворює обмеження на здійсненну таблицю, за потреби використовує ціль фази I, а потім застосовує первинні симплексні опорні точки для оптимізації запитуваної цілі. Змінні x і y мають бути невід’ємними.

    Як працює симплексний калькулятор із двома змінними?

    Він перетворює обмеження на здійсненну таблицю, за потреби використовує ціль фази I, а потім застосовує первинні симплексні опорні точки для оптимізації запитуваної цілі. Змінні x і y мають бути невід’ємними.

    Чи завантажено мої цілі та обмеження?

    Ні. Розв’язувач працює в цьому браузері. Ваша ціль і обмеження не надсилаються на сервер і не зберігаються цим інструментом.

    Який формат слід використовувати для обмежень?

    Введіть по одному рядку на рядок, наприклад 1,1 <= 5 або 2,1 >= 4. Перше число множить на x, друге — на y, і обидві змінні мають бути невід’ємними.

    Що означають нездійсненний і необмежений?

    Неможливо означає, що жодна точка не задовольняє кожне введене обмеження. Необмежений означає, що можливий напрямок дозволяє поставленій меті продовжувати вдосконалюватися без кінцевого оптимуму.

    Чи підтверджує результат правильну мою реальну модель?

    Ні. Він розв’язує лише рівняння, які ви ввели. Перевірте одиниці вимірювання, припущення та чи правильно обмеження описують ваше рішення.

    Головна

    Безкоштовні браузерні інструменти. Дані залишаються на вашому пристрої, якщо це дозволяє інструмент.
