Конвертер XML у CSV

Перетворіть простий список записів XML у таблицю CSV або створіть записи XML із тексту файлу CSV. Виберіть напрямок, вставте свої дані, потім скопіюйте або завантажте результат. Нічого не завантажено.

Підтримує простий список одноіменних елементів запису або один плоский запис. Дочірні елементи мають бути скалярними значеннями; вкладені та повторювані поля не зведені.

Використовуйте перший рядок для назв стовпців. Такий заголовок, як @id, стає атрибутом XML. Використовуйте #text для запису тексту.

Це просте перетворення таблиці, а не перетворення формату XML без втрат. Простори імен, вкладені структури, змішаний вміст, коментарі та форматування XML не зберігаються. Текст не розпізнає текст. Значення CSV, схожі на формулу електронної таблиці, мають префікс із апострофом для безпеки.

Результат

Перевірте результат, перш ніж імпортувати його в іншу програму.

Як конвертувати XML у CSV?

Виберіть XML у CSV і вставте XML із простим списком записів. Елементи прямого запису, що повторюються, стають рядками. Імена елементів стають стовпцями; атрибути використовують @name. Виберіть CSV до XML, щоб створювати прості записи XML із заголовків і рядків.

Поширені запитання

Як конвертувати XML у CSV?

Виберіть XML у CSV і вставте XML із простим списком записів. Елементи прямого запису, що повторюються, стають рядками. Імена елементів стають стовпцями; атрибути використовують @name. Виберіть CSV до XML, щоб створювати прості записи XML із заголовків і рядків.

Чи завантажено мій XML або CSV?

Ні. Розбір і перетворення виконуються в цьому браузері. Введення обмежено до 200 000 символів, 5 000 рядків, 64 стовпців і 20 000 клітинок. DTD і оголошення об’єктів блокуються, а зовнішні ресурси не завантажуються.

Як атрибути XML відображаються в CSV?

Такий атрибут, як id="101", стає стовпцем із назвою @id. Під час зворотного перетворення заголовок CSV, який починається з @, стає атрибутом XML.

Чи може він перетворити вкладений XML у плоску таблицю?

Ні. Вкладені дочірні структури, повторювані поля всередині запису та змішаний текст відхиляються замість того, щоб бути зведеними або мовчки втраченими. Використовуйте спеціальний робочий процес XML-JSON для вкладених даних.

Чи збереже CSV типи та форматування XML?

Ні. CSV зберігає текст клітинки, а не типи XML, простори імен або форматування. Значення клітинок, схожих на формулу, отримують префікс апостроф під час експорту, щоб зменшити ризик виконання формули електронної таблиці.
