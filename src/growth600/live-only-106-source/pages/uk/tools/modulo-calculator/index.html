Модульний калькулятор

Обчисліть евклідову приватну та остачу для цілих чисел. Негативні вхідні дані обробляються послідовно, а ідентифікатор поділу показує, як формується відповідь.

Число для ділення; це може бути негативним.

Використовуйте будь-яке ненульове ціле число; його абсолютне значення визначає модуль.

Перевірте, чи це значення конгруентно до діленого за модулем дільника.

Приймає цілі числа зі знаком до 50 цифр. Ні дробів, ні десяткових дробів. Результат використовує евклідове модуль; деякі мови програмування використовують інше правило залишку для мінусів.

Результат

Як обчислити модуль з від’ємним числом?

Цей калькулятор використовує невід’ємний залишок, менший за абсолютний дільник. Наприклад, −7 mod 3 дорівнює 2, оскільки −7 = (−3 × 3) + 2.

Поширені запитання

Як обчислити модуль з від’ємним числом?

Цей калькулятор використовує невід’ємний залишок, менший за абсолютний дільник. Наприклад, −7 mod 3 дорівнює 2, оскільки −7 = (−3 × 3) + 2.

Чи завантажено мої номери?

Ні. Точний розрахунок виконується в цьому браузері. Номери не завантажуються і не зберігаються.

Що таке −7 за модулем 3?

Використовуючи евклідову конвенцію, −7 mod 3 дорівнює 2: −7 = (−3 × 3) + 2 і 0 ≤ 2 < 3.

Що означає конгруентність за модулем m?

Два цілі числа конгруентні за модулем m, якщо їх різниця ділиться на |m|. Додаткове порівняння точно перевіряє це.

Чому це може відрізнятися від оператора % мови програмування?

Деякі мови зберігають знак від’ємного діленого в залишку. Натомість цей калькулятор повертає залишок від 0 до абсолютного дільника, але не включаючи його.
