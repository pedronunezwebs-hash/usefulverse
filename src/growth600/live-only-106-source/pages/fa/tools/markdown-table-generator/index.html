مولد جدول نشانه گذاری

یک جدول Markdown در یک شبکه کوچک قابل ویرایش ایجاد کنید. متن جدا شده با کاما، نقطه ویرگول یا زبانه را وارد کنید، تراز ستونی را انتخاب کنید، و Markdown ساده را با لوله هایی که به طور ایمن فرار کرده اند کپی کنید.

پشتیبانی می شوند. واردات جایگزین شبکه فعلی می شود. حداکثر 100 سطر، 20 ستون و 250000 کاراکتر.

اولین ردیف به عنوان Markdown تبدیل می شود. حداقل یک سطر و یک ستون اضافه کنید.

سلول های جدول قابل ویرایش

یک جدول لوله استاندارد با هدر و ردیف جداکننده ایجاد می کند. شکسته شدن خطوط سلولی به <br> تبدیل می شود. لوله های Markdown و بک اسلش ها فرار می کنند.

تمام پردازش ها در این برگه باقی می ماند. بدون آپلود، حساب، API، ذخیره خودکار یا پردازش سرور.

آیا جدول من آپلود شده است؟

نه. جدول شما در این برگه مرورگر پردازش می شود. واردات، ویرایش‌ها و Markdown ایجاد شده به سرور ارسال نمی‌شوند یا به‌طور خودکار ذخیره نمی‌شوند.

آیا می توانم CSV یا TSV را وارد کنم؟

بله. مقادیر جدا شده با کاما، نقطه ویرگول یا تب را جایگذاری کنید، سپس آنها را به شبکه قابل ویرایش وارد کنید. فیلدهای CSV نقل قول و جداکننده های نقل قول پشتیبانی می شوند.

لوله ها و شکستگی های خط چگونه مدیریت می شوند؟

یک لوله در داخل یک سلول خارج شده است بنابراین جدول Markdown را تقسیم نمی کند. اسلش‌های برگشتی نیز حذف می‌شوند و شکسته‌های خطوط سلولی با <br> نشان داده می‌شوند.

خانه

ابزارهای رایگان مرورگر. داده‌های شما، در مواردی که ابزار اجازه دهد، روی دستگاهتان می‌مانند.
