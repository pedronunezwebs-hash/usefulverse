تایم لاین ساز

نقاط عطف یا رویدادهای تاریخی را به یک جدول زمانی روشن و زمانی تبدیل کنید. برای هر رویداد یک تاریخ یا تاریخ شروع و پایان اضافه کنید.

این جدول زمانی رویداد است، نه یک برنامه زمانبندی کار/وابستگی یا منبعی از حقایق تاریخی. تاریخ هایی را که بررسی کرده اید وارد کنید.

نام و تاریخ رویداد شما در این برگه باقی می ماند. هیچ چیزی آپلود یا ذخیره نمی شود. صادرات به صورت محلی ایجاد می شود.

چگونه یک جدول زمانی رویداد ایجاد کنم؟

حداقل دو رویداد نامگذاری شده را اضافه کنید و برای هر کدام یک تاریخ شروع انتخاب کنید. تاریخ پایانی را برای مدت زمان اضافه کنید یا آن را برای یک رویداد یک روزه خالی بگذارید. برای مرتب کردن رویدادها بر اساس تاریخ، تنظیم بزرگنمایی و دانلود فایل های SVG یا CSV، جدول زمانی ایجاد کنید.

چگونه یک جدول زمانی رویداد ایجاد کنم؟

حداقل دو رویداد نامگذاری شده را اضافه کنید و برای هر کدام یک تاریخ شروع انتخاب کنید. تاریخ پایانی را برای مدت زمان اضافه کنید یا آن را برای یک رویداد یک روزه خالی بگذارید. برای مرتب کردن رویدادها بر اساس تاریخ، تنظیم بزرگنمایی و دانلود فایل های SVG یا CSV، جدول زمانی ایجاد کنید.

آیا رویدادهای جدول زمانی من آپلود شده است؟

شماره. نام ها و تاریخ ها در این برگه مرورگر پردازش می شوند. SVG و CSV بر روی دستگاه شما تولید می شوند. هیچ چیز به طور خودکار آپلود یا ذخیره نمی شود.

آیا یک رویداد می تواند بیش از یک روز طول بکشد؟

بله. تاریخ شروع و پایان را وارد کنید. نمودار شامل هر دو تاریخ نقطه پایانی است. انتهای آن را برای یک رویداد یک روزه خالی بگذارید.

آیا این جدول زمانی وابستگی های کار را ایجاد می کند؟

شماره. رویدادها و محدوده های تاریخ را به ترتیب زمانی نشان می دهد. از ابزار برنامه زمانبندی پروژه برای وظایف، مدت زمان و وابستگی ها استفاده کنید.

آیا می توانم جدول زمانی را ذخیره کنم یا به اشتراک بگذارم؟

یک SVG برای یک تصویر مقیاس پذیر یا یک CSV برای جدول رویداد دانلود کنید. صفحه داده‌های رویداد شما را آپلود نمی‌کند یا به‌طور خودکار ذخیره نمی‌کند.
