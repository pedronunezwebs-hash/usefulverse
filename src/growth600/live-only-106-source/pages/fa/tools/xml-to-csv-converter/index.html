XML به CSV

یک لیست ضبط ساده XML را به یک جدول CSV تبدیل کنید یا رکوردهای XML را از متن یک فایل CSV بسازید. جهت را انتخاب کنید، داده های خود را جایگذاری کنید، سپس نتیجه را کپی یا دانلود کنید. چیزی آپلود نمیشه

از یک لیست ساده از عناصر رکوردی همنام یا یک رکورد مسطح پشتیبانی می کند. فرزندان عنصر باید مقادیر اسکالر باشند. زمینه های تو در تو و تکراری صاف نمی شوند.

از ردیف اول برای نام ستون ها استفاده کنید. هدر مانند @id به یک ویژگی XML تبدیل می شود. از #text برای ضبط متن استفاده کنید.

این یک تبدیل جدول ساده است، نه تبدیل فرمت XML بدون ضرر. فضاهای نام، ساختارهای تودرتو، محتوای ترکیبی، نظرات و قالب بندی XML حفظ نمی شوند. متن از نوع آگاه نیست. مقادیر CSV فرمول مانند صفحه‌گسترده برای ایمنی با یک آپوستروف پیشوند می‌شوند.

نتیجه

خروجی را قبل از وارد کردن آن به برنامه دیگری بررسی کنید.

چگونه XML را به CSV تبدیل کنم؟

XML را به CSV انتخاب کنید و XML را با یک لیست رکورد ساده جای‌گذاری کنید. عناصر ضبط مستقیم مکرر به ردیف تبدیل می شوند. نام عناصر تبدیل به ستون می شود. ویژگی ها از @name استفاده می کنند. برای ایجاد رکوردهای XML ساده از سرصفحه ها و ردیف ها، CSV به XML را انتخاب کنید.

چگونه XML را به CSV تبدیل کنم؟

XML را به CSV انتخاب کنید و XML را با یک لیست رکورد ساده جای‌گذاری کنید. عناصر ضبط مستقیم مکرر به ردیف تبدیل می شوند. نام عناصر تبدیل به ستون می شود. ویژگی ها از @name استفاده می کنند. برای ایجاد رکوردهای XML ساده از سرصفحه ها و ردیف ها، CSV به XML را انتخاب کنید.

آیا XML یا CSV من آپلود شده است؟

شماره. تجزیه و تبدیل در این مرورگر اجرا می شود. ورودی به 200000 کاراکتر، 5000 ردیف، 64 ستون و 20000 سلول محدود شده است. DTD و اعلامیه های موجودیت مسدود شده اند و منابع خارجی واکشی نمی شوند.

چگونه ویژگی های XML در CSV نشان داده می شوند؟

یک ویژگی مانند id="101" به ستونی با نام @id تبدیل می شود. هنگام تبدیل مجدد، یک هدر CSV که با @ شروع می شود به یک ویژگی XML تبدیل می شود.

آیا می تواند XML تودرتو را به یک جدول مسطح تبدیل کند؟

نه. ساختارهای فرزند تودرتو، فیلدهای تکراری داخل یک رکورد و متن ترکیبی به جای اینکه مسطح یا بی‌صدا گم شوند رد می‌شوند. از یک گردش کار اختصاصی XML به JSON برای داده های تودرتو استفاده کنید.

آیا CSV انواع و قالب بندی XML را حفظ می کند؟

نه. CSV متن سلول را ذخیره می کند، نه انواع XML، فضاهای نام یا قالب بندی. مقادیر سلول‌های فرمول‌مانند برای کاهش خطر اجرای فرمول صفحه‌گسترده، یک پیشوند آپوستروف دریافت می‌کنند.
