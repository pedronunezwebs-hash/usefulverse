اعتبارسنجی نقشه سایت

یک سند XML نقشه سایت را جایگذاری کنید تا ساختار، ورودی های URL، تاریخ ها و فیلدهای رایج آن را بررسی کنید. XML فقط در این مرورگر تجزیه می شود. صفحات فهرست شده هرگز واکشی نمی شوند.

از urlset یا sitemapindex استاندارد پشتیبانی می کند. حداکثر 1,000,000 کاراکتر و 5,000 ورودی مستقیم.

فقط XML محلی را بررسی می‌کند: این نشانی‌های اینترنتی فهرست‌شده را درخواست نمی‌کند، سایت را خزیده، نقشه سایت را ارسال می‌کند، یا نمایه‌سازی را تضمین نمی‌کند.

خلاصه اعتبارسنجی

یافته ها

    این اعتبارسنجی نقشه سایت چه چیزی را بررسی می کند؟

    ورودی‌های urlset یا sitemapindex، مکان‌های HTTP یا HTTPS مطلق، URLهای عادی شده تکراری، تاریخ‌های آخرین حالت، تغییرات اختیاری فرکانس و مقادیر اولویت و فضای نام نقشه سایت را بررسی می‌کند. هشدارها و خطاها با شماره ورودی فهرست شده اند.

    پرسش‌های متداول

    این اعتبارسنجی نقشه سایت چه چیزی را بررسی می کند؟

    ورودی‌های urlset یا sitemapindex، مکان‌های HTTP یا HTTPS مطلق، URLهای عادی شده تکراری، تاریخ‌های آخرین حالت، تغییرات اختیاری فرکانس و مقادیر اولویت و فضای نام نقشه سایت را بررسی می‌کند. هشدارها و خطاها با شماره ورودی فهرست شده اند.

    آیا نقشه سایت من را آپلود می کند یا ارسال می کند؟

    نه. XML به صورت محلی در مرورگر شما پردازش می شود. این ابزار آدرس‌های اینترنتی را نمی‌خزد، فایل‌های نقشه سایت از راه دور را واکشی نمی‌کند، چیزی را به موتور جستجو ارسال نمی‌کند، یا فهرست‌سازی را تایید نمی‌کند.

    آیا این نشانی وب نقشه سایت فعال است؟

    نه. نحو URL و موارد تکراری را در XML چسبانده شده بررسی می کند، اما عمداً URL ها را درخواست نمی کند یا در سایت نمی خزند.

    آیا نقشه سایت معتبر به این معنی است که گوگل صفحات خود را ایندکس کرده است؟

    نه. اعتبارسنجی XML یک گزارش ارسال یا نمایه سازی توسط موتور جستجو نیست. نقشه سایت را از طریق ابزار وب مستر موتور جستجوی مربوطه ارسال کنید و وضعیت خود را بررسی کنید.

    آیا می توانم فهرست نقشه سایت را تأیید کنم؟

    بله. این ابزار ورودی‌های مستقیم sitemapindex و فیلدهای loc و lastmod آن‌ها را بررسی می‌کند، اما فایل‌های نقشه سایت ارجاع‌شده را دانلود یا به صورت بازگشتی بررسی نمی‌کند.

    خانه

    ابزارهای رایگان مرورگر. داده‌های شما، در مواردی که ابزار اجازه دهد، روی دستگاهتان می‌مانند.
