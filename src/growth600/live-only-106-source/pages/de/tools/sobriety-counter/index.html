Zähler für nüchterne Tage

Wählen Sie ein Startdatum, um die verstrichenen Kalendertage zu zählen und bevorstehende Meilensteine anzuzeigen. Bei diesem privaten Schalter handelt es sich nicht um eine Behandlung, einen Genesungsratschlag oder ein Maß für die Gesundheit.

Geben Sie das Datum ein, ab dem gezählt werden soll. Ein Datum heute ist Tag Null; Zukünftige Termine sind nicht zulässig. Der Standardwert ist heute und kann geändert werden, um ein früheres Datum anzuzeigen, jedoch kein Datum vor dem Start.

Bis zu 280 Zeichen. Halten Sie vertrauliche Daten von gemeinsam genutzten Geräten fern.

Dies ist nur eine Datumsarithmetik. Substanzkonsum, Gesundheit, Risiko, Fortschritt oder Behandlungsbedarf werden nicht beurteilt. Genesung ist etwas Persönliches; Ziehen Sie qualifizierten Support in Betracht, wenn Sie Hilfe benötigen.

Das Speichern ist optional und verwendet nur den lokalen Speicher dieses Browsers; Es wird nichts hochgeladen. Löschen Sie die unten gespeicherten Daten.

Ihre Tageszählung

Wie funktioniert der Nüchternheitstagzähler?

Es werden ganze Kalendertage ab dem von Ihnen eingegebenen Datum bis zum heutigen Tag gezählt. Das ausgewählte Startdatum selbst ist Tag Null; Spätere Datumsangaben verwenden reine Datumsarithmetik, sodass bei der Sommerzeit kein Tag hinzugefügt oder entfernt wird.

Häufig gestellte Fragen

Wie funktioniert der Nüchternheitstagzähler?

Es werden ganze Kalendertage ab dem von Ihnen eingegebenen Datum bis zum heutigen Tag gezählt. Das ausgewählte Startdatum selbst ist Tag Null; Spätere Datumsangaben verwenden reine Datumsarithmetik, sodass bei der Sommerzeit kein Tag hinzugefügt oder entfernt wird.

Wird mein Nüchternheitsdatum hochgeladen oder gespeichert?

Es werden keine Daten hochgeladen. Ihre Daten werden nur in diesem Browser verwendet. Eine Notiz oder ein Datum kann auf diesem Gerät nur gespeichert werden, wenn Sie sich ausdrücklich dafür entscheiden, und Sie können den lokalen Datensatz jederzeit löschen.

Zählt das Startdatum als Tag eins?

Nein. Das gewählte Startdatum ist Tag Null. Das nächste Kalenderdatum liegt einen verstrichenen Tag später.

Kann dieser Zähler Genesungs- oder medizinische Ratschläge geben?

Nein. Es zählt Kalendertage und zeigt nur Meilensteine an. Gesundheit, Substanzkonsum, Behandlung oder persönlicher Fortschritt werden nicht beurteilt.

Werden Daten und Notizen an einen Server gesendet?

Nein. Berechnungen werden in Ihrem Browser ausgeführt. Das Speichern ist optional und speichert einen kleinen Datensatz in diesem Browser auf diesem Gerät; Sie können es hier löschen.
