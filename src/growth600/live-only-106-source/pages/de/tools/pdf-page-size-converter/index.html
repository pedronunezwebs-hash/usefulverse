PDF-Seitengrößenkonverter

Ändern Sie die Größe jeder Seite in einer PDF-Datei auf A4, US-Letter, Legal oder ein benutzerdefiniertes Papierformat. Sehen Sie sich die neuen Abmessungen in der Vorschau an, passen Sie sie an den gesamten Originalseitenbereich an und laden Sie eine separate, auf Ihrem Gerät verarbeitete Kopie herunter.

Resizing erstellt eine separate Kopie. Durch erneutes Speichern können digitale Signaturen ungültig werden. Behalten Sie das Original und überprüfen Sie das neue PDF, bevor Sie es teilen.

LLokale Grenzen: 25 MiB Eingabe, 300 Seiten und 50 MiB Ausgabe. Große Dateien können viel Speicher beanspruchen; Ein Computer wird empfohlen.

Um stille Änderungen zu vermeiden, lehnt dieses Tool gedrehte Seiten, benutzerdefinierte Seitenrahmen, Anmerkungen, Links und interaktive Formulare ab. Der Anpassungsmodus skaliert das gesamte vorhandene Seitenrechteck und kann Inhalte, die sich bereits außerhalb seiner Grenzen befinden, nicht wiederherstellen.

Wie ändere ich die Seitengröße einer PDF-Datei?

Wählen Sie eine PDF-Datei aus, überprüfen Sie ihre Seiten, wählen Sie A4, Letter, Legal oder benutzerdefinierte Abmessungen aus und wählen Sie dann „An Seite anpassen“ oder „Originalgröße“. Ist mein PDF hochgeladen, um die Größe zu ändern?

Nr. Das PDF wird in diesem Browser verarbeitet, nachdem Sie es ausgewählt haben. Es wird nicht von UsefulVerse hochgeladen oder gespeichert. Große PDFs können Gerätespeicher beanspruchen; Ein Computer wird empfohlen.

Kann ich die Größe einer PDF-Datei auf A4 oder US-Letter ändern?

YJa. Wählen Sie A4, US Letter oder US Legal, wählen Sie Hoch- oder Querformat und zeigen Sie eine Vorschau des Ergebnisses an. Eine benutzerdefinierte Größe kann auch in Millimetern oder Zoll eingegeben werden.

Wird die Größenänderung den PDF-Inhalt beschneiden?

Fit-Modus skaliert das gesamte Originalseitenrechteck gleichmäßig und zentriert es auf dem neuen Papier. Es wird nicht absichtlich beschnitten. Inhalte, die bereits außerhalb der ursprünglichen PDF-Seitengrenze liegen, können nicht wiederhergestellt werden.

Behält dies Links, Formulare oder digitale Signaturen bei?

Dieses Tool lehnt Seiten mit Anmerkungen, Links, interaktiven Feldern, Drehungen oder benutzerdefinierten Seitenrahmen ab, anstatt sie stillschweigend abzulegen. Das Speichern einer PDF-Datei kann dazu führen, dass digitale Signaturen ungültig werden. Bewahren Sie das Original auf und überprüfen Sie es.
