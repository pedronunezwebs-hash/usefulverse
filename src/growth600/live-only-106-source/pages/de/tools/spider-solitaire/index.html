Spider Solitaire

Bauen Sie absteigende Sequenzen in derselben Kartenfarbe vom König bis zum Ass auf, decken Sie verdeckte Karten auf und vervollständigen Sie alle acht Sequenzen. Wählen Sie eine, zwei oder vier Kartenfarben.

Für ein neues Zufallsspiel leer lassen. Verwenden Sie denselben Samen erneut, um denselben gemischten Deal zu reproduzieren. es bleibt nur auf dieser Seite.

Abgeschlossene Sequenzen: 0/8

Verschiebt: 0

Nur aufgedeckte absteigende Gruppen derselben Kartenfarbe können gemeinsam ziehen. Eine einzelne offene Karte kann sich alleine bewegen. Verdeckte Karten werden aufgedeckt, wenn sie aufgedeckt werden.

Abgeschlossene Läufe werden automatisch entfernt. Leere Spalten akzeptieren jede offene Karte oder jeden gültigen Lauf.

Wie spielt man Spider Solitaire?

Verschieben Sie offene absteigende Sequenzen derselben Kartenfarbe auf den nächsthöheren Rang oder eine leere Spalte. Decken Sie versteckte Karten auf, ziehen Sie zehn Karten vom Stapel, wenn jede Spalte belegt ist, und vervollständigen Sie acht King-to-Ace-Sequenzen derselben Farbe, um zu gewinnen.

Speichert Spider Solitaire mein Spiel?

Nein. Das Spiel läuft auf dieser Registerkarte und speichert kein Spiel, verwendet kein Konto, lädt keine Züge hoch und sendet sie nicht an einen Server. Der Beginn eines neuen Deals ersetzt das aktuelle Spiel.

Was ist der Unterschied zwischen einer, zwei und vier Kartenfarben?

Eine Kartenfarbe ist der entspannteste Modus, zwei Kartenfarben fügen eine weitere Farbe hinzu und bei vier Kartenfarben muss die Farbe in einem Tableau mit gemischten Farben kombiniert werden.

Wann kann ich Karten vom Stapel ziehen?

Ziehe zehn Karten, eine für jede Spalte, solange der Vorrat übrig ist. Jede Tableauspalte muss mindestens eine Karte enthalten, bevor sie vom Vorratsstapel gezogen werden kann.

Wie funktioniert das Rückgängigmachen?

„Rückgängig“ stellt den genauen vorherigen Spielstatus für einen Zug, einen Aktienverkauf oder eine abgeschlossene Entfernung wieder her. Bis zu 100 aktuelle Aktionen werden nur auf dieser Registerkarte gespeichert.
