Wochennummernrechner

Geben Sie ein Datum ein, um dessen ISO 8601-Wochennummer, das Wochenjahr und die Daten von Montag bis Sonntag zu finden. Sie können auch eine Kalenderwochenregel vergleichen, die am Sonntag, Montag oder Samstag beginnt.

-Modus zählt die Woche, die den 1. Januar enthält, als Woche 1 und beschriftet sie mit dem Kalenderjahr. ISO 8601 kann Termine in der Nähe von Neujahr einem anderen Wochenjahr zuordnen. Für reine Datumsberechnungen wird UTC verwendet. Es werden keine Zeitzonenumrechnungs- oder Steuerkalenderregeln angewendet.

Wochendetails

Wie finde ich die Wochennummer für ein Datum?

Wählen Sie ISO 8601 oder eine Kalenderwochenregel, geben Sie das Datum ein und berechnen Sie. ISO-Wochen beginnen am Montag und Woche 1 ist die Woche, die den 4. Januar enthält. Das Wochenjahr kann vom Kalenderjahr in der Nähe von Neujahr abweichen.

Häufig gestellte Fragen

Wie finde ich die Wochennummer für ein Datum?

Wählen Sie ISO 8601 oder eine Kalenderwochenregel, geben Sie das Datum ein und berechnen Sie. ISO-Wochen beginnen am Montag und Woche 1 ist die Woche, die den 4. Januar enthält. Das Wochenjahr kann vom Kalenderjahr in der Nähe von Neujahr abweichen.

Wird mein Datum an einen Server gesendet?

Nein. Diese Datumsberechnung wird in Ihrem Browser ausgeführt. Das Datum wird von diesem Tool nicht hochgeladen oder gespeichert.

Warum kann das ISO-Wochenjahr vom Kalenderjahr abweichen?

Eine ISO-Woche gehört zu dem Jahr, das ihren Donnerstag enthält. Ein Datum Anfang Januar kann daher zur letzten ISO-Woche des Vorjahres gehören, und ein Datum Ende Dezember kann zur Woche 1 des nächsten ISO-Jahres gehören.

Was bedeutet die benutzerdefinierte Kalenderwochenoption?

Es nummeriert den Sieben-Tage-Zeitraum, der den 1. Januar als Woche 1 enthält, unter Verwendung des ausgewählten ersten Tages. Die Beschriftung bleibt beim Kalenderjahr. Hierbei handelt es sich um eine transparente Vergleichsregel und nicht um eine Aussage über Ihr Land oder die offizielle Konvention Ihres Arbeitgebers.

Berechnet dies die Geschäftswochenzahlen?

Nein. Finanzkalender können organisationsspezifische Startdaten und 4-4-5 oder andere Regeln verwenden. Dieses Tool berechnet nur ISO-Wochen oder die angegebene Kalenderwochenregel vom 1. Januar.
