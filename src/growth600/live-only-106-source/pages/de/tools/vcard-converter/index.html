VCF-zu-CSV-Konverter

Verwandeln Sie eine VCF-Datei mit mehreren Kontakten in eine tabellenkalkulationsfähige CSV-Datei. Wählen Sie die benötigten Felder aus und laden Sie eine separate Datei herunter.

Verwenden Sie jeweils eine Quelle. Ein einzelnes VCF kann viele Kontakte enthalten.

Lokale Verarbeitung: Die ausgewählte Datei bleibt in diesem Browser-Tab. In Ihrem Adressbuch wird nichts hinzugefügt oder geändert.

Liest allgemeine Textfelder in vCard 2.1, 3.0 und 4.0: Name, Organisation, Titel, Telefon, E-Mail, URL, Adresse und Notiz. Binärfotos werden ignoriert. In Anführungszeichen druckbarer und Nicht-UTF-8-Text wird nicht dekodiert.

CSV-Spalten zur Einbindung von

Lokale Grenzwerte: 5 MiB Eingabe, 5.000 Kontakte und 20 MiB CSV-Ausgabe. Große Dateien benötigen möglicherweise mehr Gerätespeicher. Ein Computer wird empfohlen.

Tabellenkalkulationssicherheit: Werte, die als Formeln behandelt werden könnten, beginnen in der CSV mit einem Apostroph. Dadurch werden die exportierten Zellen absichtlich geändert.

Umgewandelte Kontakte

Wie konvertiere ich VCF-Kontakte in CSV?

Wählen Sie eine UTF-8-.vcf-Datei oder fügen Sie vCard-Text ein, wählen Sie die einzuschließenden Kontaktspalten aus, konvertieren Sie dann die CSV-Datei und laden Sie sie herunter. Wiederholte Telefonnummern, E-Mail-Adressen und andere unterstützte Felder bleiben in der Zeile dieses Kontakts zusammen.

Häufig gestellte Fragen

Wie konvertiere ich VCF-Kontakte in CSV?

Wählen Sie eine UTF-8-.vcf-Datei oder fügen Sie vCard-Text ein, wählen Sie die einzuschließenden Kontaktspalten aus, konvertieren Sie dann die CSV-Datei und laden Sie sie herunter. Wiederholte Telefonnummern, E-Mail-Adressen und andere unterstützte Felder bleiben in der Zeile dieses Kontakts zusammen.

Werden meine VCF-Kontakte hochgeladen oder geändert?

Nein. Die Datei wird in diesem Browser gelesen und konvertiert, nachdem Sie sie ausgewählt haben. UsefulVerse greift nicht auf Ihr Adressbuch zu, lädt die Datei nicht hoch und ändert keine Kontakte.

Erstellt ein Kontakt eine CSV-Zeile?

Ja. Jeder vCard-Kontakt wird zu einer Datenzeile. Wiederholte Telefonnummern, E-Mail-Adressen und andere unterstützte Werte werden in der Zelle dieses Kontakts mit Semikolons verbunden.

Umfasst dies Kontaktfotos?

Nein. Binäres Foto, Logo, Ton und Schlüsseldaten werden ignoriert; Sie sind nicht in CSV eingebettet.

Ändert die Konvertierung meine Kontakte?

Nein. Es wird ein separater CSV-Download erstellt und niemals aus dem Adressbuch Ihres Geräts gelesen oder in dieses geschrieben.
