BAC-Rechner

Geben Sie Körpergewicht, Getränkegröße und Stärke ein, um ein äußerst unsicheres mathematisches Szenario anzuzeigen. Dies ist keine Messung oder zuverlässige Vorhersage Ihres Blutalkoholspiegels.

Verwenden Sie diese Schätzung nicht, um zu entscheiden, ob Sie Auto fahren, Maschinen bedienen oder eine medizinische oder rechtliche Entscheidung treffen können. Es handelt sich nicht um einen Atem-/Bluttest, keine Diagnose oder verlässliche Vorhersage. Jeglicher Alkohol kann die Fahrtüchtigkeit beeinträchtigen. Wenn Sie getrunken haben, fahren Sie nicht, sondern vereinbaren Sie eine nüchterne Fahrt. Wenn jemand bewusstlos ist, schwer aufzuwachen ist, Anfälle hat oder langsam/unregelmäßig atmet, wenden Sie sich jetzt an den örtlichen Rettungsdienst.

Geben Sie ein aktuelles ungefähres Gewicht ein. Das Werkzeug rechnet bei Auswahl Pfund in Kilogramm um. Geben Sie bis zu 8 Getränkearten ein. Verwenden Sie Zählwert 0 für keinen Alkohol; Jede Reihe setzt identische Portionen und Stärke voraus.

Wie funktioniert dieses BAC-Szenario?

Es wandelt die Getränkeeinträge in Gramm Ethanol um, wendet eine vereinfachte Verteilungsschätzung im Widmark-Stil mit breiten Annahmen an und subtrahiert dann einen breiten illustrativen Eliminationsbereich basierend auf der verstrichenen Zeit. Es setzt eine sofortige Absorption voraus und kann Ihren Körper oder den Zeitpunkt jedes Getränks nicht modellieren.

Werden meine Einträge hochgeladen?

Nein. Die Berechnung läuft in diesem Browser. Einträge werden nicht hochgeladen, gespeichert oder an einen Server gesendet.

Kann mir das sagen, ob ich sicher Auto fahren kann?

Nein. Benutzen Sie niemals einen Taschenrechner, um diese Entscheidung zu treffen. BAC-Schätzungen weisen erhebliche Unsicherheiten auf, die Beeinträchtigung kann unterhalb der gesetzlichen Grenzwerte beginnen und der Alkohol kann nach dem letzten Getränk noch aufgenommen werden. Wenn Sie getrunken haben, fahren Sie nicht. Vereinbaren Sie eine nüchterne Fahrt.

Entspricht das Ergebnis meinem tatsächlichen Blutalkoholspiegel?

Nein. Es handelt sich um eine vereinfachte Illustration im Widmark-Stil, nicht um einen Test oder eine zuverlässige Vorhersage. Körperzusammensetzung, Absorption, Ernährung, Gesundheit, Medikamente, Trinkzeitpunkt und viele andere Faktoren sind aus diesen Einträgen nicht bekannt.

Warum wird ein großer Bereich angezeigt?

Die Verteilungs- und Eliminierungsannahmen variieren stark zwischen den Menschen. Der Bereich dient der Veranschaulichung und kann nicht garantieren, dass eine tatsächliche Messung innerhalb dieses Bereichs liegt.
