Quadratwurzelvereinfacher

Vereinfachen Sie exakte ganzzahlige Radikale, indem Sie perfekte Potenzen extrahieren, oder schreiben Sie einen Bruch so um, dass sein Nenner keine Quadratwurzel enthält. Die Ergebnisse sind für die unterstützten Ganzzahleingaben genau.

Geben Sie ganze Zahlen ein. Radikanden sind auf ±1.000.000.000.000 begrenzt; Der Wurzelindex ist 2–12. Negative Radikanden werden nur für ungerade Indizes unterstützt.

Dieser Modus verarbeitet Zähler / (Koeffizient × √Radikand). Der Nennerkoeffizient darf nicht Null sein; Der Radikand muss eine positive ganze Zahl sein.

Ergebnis

Wie vereinfacht man eine Quadratwurzel?

Faktorisieren Sie den Radikanden in Primzahlpotenzen. Ziehen Sie jedes vollständige Paar außerhalb einer Quadratwurzel; zum Beispiel √72 = √(36 × 2) = 6√2. Dieses Tool unterstützt auch ganzzahlige Wurzeln mit den Indizes 2 bis 12.

Häufig gestellte Fragen

Wie vereinfacht man eine Quadratwurzel?

Faktorisieren Sie den Radikanden in Primzahlpotenzen. Ziehen Sie jedes vollständige Paar außerhalb einer Quadratwurzel; zum Beispiel √72 = √(36 × 2) = 6√2. Dieses Tool unterstützt auch ganzzahlige Wurzeln mit den Indizes 2 bis 12.

Werden meine Nummern hochgeladen?

Nein. Die Berechnung läuft in diesem Browser und dieses Tool lädt oder speichert Ihre Eingaben nicht.

Wozu vereinfacht sich √72?

√72 ist 6√2, weil 72 = 36 × 2 und √36 = 6.

Kann es einen Nenner rationalisieren?

Ja. Es schreibt a / (c√b) mit ganzzahligen Eingaben als äquivalenten Bruch um, dessen Nenner keine Quadratwurzel hat, und reduziert dann den rationalen Koeffizienten.

Ergibt dies dezimale Näherungen?

Nein. Es behält die exakte Wurzelform bei. Verwenden Sie einen wissenschaftlichen Taschenrechner, wenn Sie auch eine dezimale Näherung benötigen.
