Atemübung

Wählen Sie einen angenehmen Atemrhythmus und folgen Sie der visuellen Anleitung. Atmen Sie entspannt und hören Sie jederzeit auf.

Bei aktivierter Einstellung für reduzierte Bewegung vermeidet die Anleitung abrupte Bewegungen.

Dies ist ein allgemeiner Wellness-Timer, kein medizinisches Hilfsmittel. Atmen Sie entspannt und brechen Sie ab, falls Sie sich unwohl fühlen.

Wie verwende ich diese Atemübung?

Wählen Sie eine Voreinstellung oder legen Sie die Phasen fest, bestimmen Sie die Sitzungsdauer und drücken Sie auf Start. Sie können jederzeit pausieren oder zurücksetzen. Der Ton ist optional und beginnt mit der Sitzung.

Häufig gestellte Fragen

Wie verwende ich diese Atemübung?

Wählen Sie eine Voreinstellung oder legen Sie die Phasen fest, bestimmen Sie die Sitzungsdauer und drücken Sie auf Start. Sie können jederzeit pausieren oder zurücksetzen. Der Ton ist optional und beginnt mit der Sitzung.

Wird meine Atemsitzung hochgeladen?

Nein. Der Timer läuft auf dieser Seite. Es werden kein Konto, Upload, API oder gespeicherte Sitzungsdaten verwendet.

Kann ich Box-Atmung oder die 4-7-8-Methode verwenden?

Ja. Wählen Sie eine Voreinstellung oder passen Sie die Phasen an. Dies sind Atemrhythmen, keine medizinische Behandlung.

Läuft der Timer weiter, wenn ich den Tab schließe?

Nicht garantiert. Browser können Hintergrund-Tabs pausieren, und Geräte können in den Ruhezustand wechseln. Lassen Sie diese Seite geöffnet und das Gerät aktiv, damit die Zeitmessung zuverlässiger ist.

Kann ich den Ton ausschalten oder früher stoppen?

Ja. Der Ton ist optional und kann ausgeschaltet werden. Pause oder Zurücksetzen beendet die laufende Zeitmessung.
