PDF-Barrierefreiheitsprüfung

Untersuchen Sie ein PDF lokal auf einige maschinenerkennbare Barrierefreiheitssignale, darunter Dokument-Tags, Metadaten, auswählbaren Text, Abbildungen ohne Alternativtext und Sprünge auf Überschriftenebene. Dies ist nur ein First-Pass-Checker, kein PDF/UA-Validator oder ein Ersatz für Tests unterstützender Technologien.

Maximal 25 MiB und 300 Seiten. Bei der Inspektion kann der Gerätespeicher verwendet werden. Für große Dateien wird ein Computer empfohlen.

Inspection wird auf Ihrem Gerät ausgeführt, nachdem Sie eine Datei ausgewählt haben. Kein Upload, kein Konto, keine API, kein automatisches Speichern oder keine Serververarbeitung.

Diese Prüfungen sind heuristisch. Sie können die korrekte Lesereihenfolge, aussagekräftige Beschreibungen, den Farbkontrast, die Verwendung der Tastatur, die Formularbeschriftungen, die Tabellen-Kopfzeilen-Beziehungen oder die PDF/UA/Section 508/WCAG-Konformität nicht bestätigen. Überprüfen Sie manuell und testen Sie mit unterstützender Technologie.

Inspektionsbericht

Was kann dieser PDF-Barrierefreiheitsprüfer erkennen?

Es meldet, ob das PDF Struktur-Tags, einen Dokumenttitel und eine Sprache, auswählbaren Text auf jeder Seite, Abbildungen mit alternativem Text und mögliche Sprünge in den Überschriftenebenen offenlegt. Es kann nicht entschieden werden, ob die Lesereihenfolge oder der Alternativtext sinnvoll ist.

Häufig gestellte Fragen

Was kann dieser PDF-Barrierefreiheitsprüfer erkennen?

Es meldet, ob das PDF Struktur-Tags, einen Dokumenttitel und eine Sprache, auswählbaren Text auf jeder Seite, Abbildungen mit alternativem Text und mögliche Sprünge in den Überschriftenebenen offenlegt. Es kann nicht entschieden werden, ob die Lesereihenfolge oder der Alternativtext sinnvoll ist.

Wird mein PDF zur Überprüfung hochgeladen?

Nein. Das ausgewählte PDF wird in diesem Browser-Tab überprüft. Die Datei und ihr Text werden nicht hochgeladen, automatisch gespeichert oder an einen Server gesendet.

Bedeutet ein positives Ergebnis, dass das PDF zugänglich ist?

Nein. Dies sind nur begrenzte automatisierte Signale. Eine mit Tags versehene PDF-Datei kann immer noch eine falsche Lesereihenfolge, schlechte Beschreibungen, unzugängliche Formulare, geringen Kontrast oder andere Hindernisse aufweisen. Es sind weiterhin manuelle und unterstützende Technologietests erforderlich.

Kann es die PDF/UA- oder WCAG-Konformität bestätigen?

Nein. Dieser First-Pass-Checker prüft nicht alle Anforderungen und kann weder PDF/UA, WCAG, Abschnitt 508 noch die Einhaltung gesetzlicher Vorschriften zertifizieren.
