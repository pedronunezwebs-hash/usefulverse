Sitemap-Validator

Fügen Sie ein Sitemap-XML-Dokument ein, um dessen Struktur, URL-Einträge, Daten und gemeinsame Felder zu überprüfen. Das XML wird nur in diesem Browser analysiert; Die aufgelisteten Seiten werden nie abgerufen.

Unterstützt einen Standard-urlset oder sitemapindex. Maximal 1.000.000 Zeichen und 5.000 Direkteinträge.

Nur lokale XML-Prüfungen: Dabei werden keine aufgelisteten URLs angefordert, die Website nicht gecrawlt, die Sitemap übermittelt oder die Indizierung garantiert.

Validierungszusammenfassung

Ergebnisse

    Was prüft dieser Sitemap-Validator?

    Es überprüft urlset- oder sitemapindex-Einträge, absolute HTTP- oder HTTPS-Standorte, doppelte normalisierte URLs, Lastmod-Daten, optionale Changefreq- und Prioritätswerte sowie den Sitemap-Namespace. Warnungen und Fehler werden nach Eintragsnummer aufgelistet.

    Häufig gestellte Fragen

    Was prüft dieser Sitemap-Validator?

    Es überprüft urlset- oder sitemapindex-Einträge, absolute HTTP- oder HTTPS-Standorte, doppelte normalisierte URLs, Lastmod-Daten, optionale Changefreq- und Prioritätswerte sowie den Sitemap-Namespace. Warnungen und Fehler werden nach Eintragsnummer aufgelistet.

    Wird meine Sitemap hochgeladen oder übermittelt?

    Nein. Das XML wird lokal in Ihrem Browser verarbeitet. Das Tool crawlt keine URLs, ruft keine Remote-Sitemap-Dateien ab, sendet nichts an eine Suchmaschine und bestätigt die Indizierung nicht.

    Überprüft dies, ob eine Sitemap-URL aktiv ist?

    Nein. Es überprüft die URL-Syntax und Duplikate im eingefügten XML, fordert jedoch absichtlich keine URLs an und crawlt die Website nicht.

    Bedeutet eine gültige Sitemap, dass Google seine Seiten indiziert hat?

    Nein. Bei der XML-Validierung handelt es sich nicht um eine Suchmaschinenübermittlung oder einen Indexierungsbericht. Reichen Sie eine Sitemap über das entsprechende Suchmaschinen-Webmaster-Tool ein und überprüfen Sie den eigenen Status.

    Kann ich einen Sitemap-Index validieren?

    Ja. Das Tool überprüft direkte sitemapindex-Einträge und deren Felder „loc“ und „lastmod“, lädt jedoch keine referenzierten Sitemap-Dateien herunter und überprüft sie auch nicht rekursiv.
