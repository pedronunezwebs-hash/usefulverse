Inflationsrechner

Schätzen Sie mit den US-amerikanischen CPI-U-Jahresdurchschnitten, wie sich ein Preisniveau zwischen den Jahren ändert, oder geben Sie Ihre eigene Jahresrate für einen anderen Markt ein. Berechnungen bleiben in diesem Browser.

Verwenden Sie für Ihren Betrag dieselbe Währungseinheit; Dieses Tool konvertiert keine Währungen.

Der US-Modus verwendet für alle Artikel den Jahresdurchschnitt CPI-U, US-Stadtdurchschnitt, von 1913 bis 2025. Es handelt sich um eine umfassende historische Schätzung, nicht um Ihren persönlichen Warenkorb oder eine Live-Prognose. Für andere Märkte ist Ihr eigener angenommener Tarif erforderlich. Verwenden Sie ggf. einen Computer oder einen größeren Bildschirm. Für diesen leichten Rechner ist kein Modell-Download erforderlich.

Wie berechne ich die Inflation zwischen zwei Jahren?

Geben Sie einen Betrag und zwei Jahre ein. Der US-Modus multipliziert ihn mit dem späteren jährlichen CPI-U-Index dividiert durch den früheren Index. Verwenden Sie den benutzerdefinierten Zinssatzmodus, wenn Sie stattdessen einen angenommenen jährlichen Zinssatz modellieren möchten.

Häufig gestellte Fragen

Wie berechne ich die Inflation zwischen zwei Jahren?

Geben Sie einen Betrag und zwei Jahre ein. Der US-Modus multipliziert ihn mit dem späteren jährlichen CPI-U-Index dividiert durch den früheren Index. Verwenden Sie den benutzerdefinierten Zinssatzmodus, wenn Sie stattdessen einen angenommenen jährlichen Zinssatz modellieren möchten.

Ist mein Betrag oder Tarif hochgeladen?

Nein. Betrag, Jahre und Rate werden in diesem Browser berechnet und vom Tool nicht hochgeladen oder gespeichert.

Welche US-Inflationsdaten verwendet dieser Rechner?

Es werden der BLS-Verbraucherpreisindex für alle städtischen Verbraucher (CPI-U), der US-amerikanische Stadtdurchschnitt, alle Artikel und jährliche durchschnittliche Indexwerte von 1913 bis 2025 verwendet. Jahresdurchschnitte können je nach Monat oder Haushaltserfahrung abweichen.

Kann ich dies für ein anderes Land verwenden?

Ja, wählen Sie „Benutzerdefinierte Jahresrate“ und geben Sie eine angenommene Rate und Dauer ein. Das ist ein Szenario und kein offizielles Inflationsmaß für dieses Land; Verwenden Sie für einen datenbasierten Vergleich einen Index einer lokalen Statistikbehörde.

Beinhaltet das Ergebnis Anlagerenditen oder Währungsumrechnungen?

Nein. Es werden nur Preisniveaus verglichen. Zinsen, Anlagerenditen, Wechselkurse, Steuern, Gebühren oder ein persönlicher Ausgabenkorb sind darin nicht enthalten.
