Stammbaum-Ersteller

Erstellen Sie ein Familiendiagramm aus Informationen, die Sie bereits kennen. Fügen Sie Personen hinzu, verbinden Sie übergeordnete Links und exportieren Sie dann ein Diagramm oder eine GEDCOM-Datei. Die Seite durchsucht keine Datensätze und speichert Ihre Familiendaten nicht.

Personen in diesem Baum
Eltern und Kind verbinden

Familiendaten können vertraulich sein. Die Daten bleiben im Speicher, bis Sie diese Seite schließen oder zurücksetzen; Exporte können private Informationen enthalten.

Stammbaum

    Wie erstelle ich einen Stammbaum?

    Fügen Sie jede Person einmal hinzu und verbinden Sie dann ein Elternteil mit einem Kind. Das Diagramm blockiert doppelte Links, mehr als zwei aufgelistete Eltern und Abstammungszyklen. Exportieren Sie ein SVG-Diagramm oder eine GEDCOM-Textdatei, wenn Sie bereit sind.

    Häufig gestellte Fragen

    Wie erstelle ich einen Stammbaum?

    Fügen Sie jede Person einmal hinzu und verbinden Sie dann ein Elternteil mit einem Kind. Das Diagramm blockiert doppelte Links, mehr als zwei aufgelistete Eltern und Abstammungszyklen. Exportieren Sie ein SVG-Diagramm oder eine GEDCOM-Textdatei, wenn Sie bereit sind.

    Werden meine Familieninformationen hochgeladen oder gespeichert?

    Nein. Das Diagramm bleibt in dieser Seitensitzung. Es wird nicht hochgeladen oder im Browserspeicher gespeichert. Eine exportierte Datei steht Ihnen zum Speichern und Teilen zur Verfügung. Überprüfen Sie sie daher zunächst auf private Daten.

    Kann dieses Tool Verwandte oder öffentliche Aufzeichnungen finden?

    Nein. Es werden nur die von Ihnen eingegebenen Daten verwaltet. Es werden keine Aufzeichnungen durchsucht, keine Identitäten überprüft und keine Rechtsbeziehungen hergestellt.

    Was ist eine GEDCOM-Datei?

    GEDCOM ist ein Textformat, das zum Verschieben von Familiengeschichtsaufzeichnungen zwischen kompatiblen Genealogieprogrammen verwendet wird. Überprüfen Sie eine exportierte Datei, bevor Sie sie freigeben.

    Unterstützt das Diagramm mehr als zwei Eltern?

    Diese Version erlaubt bis zu zwei eingetragene Eltern pro Person. Eine familiäre Beziehung kann komplexer sein, als dieses Diagramm darstellen kann.
