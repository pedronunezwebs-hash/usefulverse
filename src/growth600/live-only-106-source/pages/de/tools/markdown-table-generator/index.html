Markdown-Tabellengenerator

Erstellen Sie eine Markdown-Tabelle in einem kleinen bearbeitbaren Raster. Importieren Sie durch Kommas, Semikolons oder Tabulatoren getrennten Text, wählen Sie die Spaltenausrichtung und kopieren Sie einfachen Markdown mit sicher maskierten Pipes.

Angeführte CSV-Felder werden unterstützt. Der Import ersetzt das aktuelle Raster; bis zu 100 Zeilen, 20 Spalten und 250.000 Zeichen.

Die erste Zeile wird zum Markdown-Header. Fügen Sie mindestens eine Zeile und eine Spalte hinzu.

Bearbeitbare Tabellenzellen

Erstellt eine Standard-Pipe-Tabelle mit einer Kopfzeile und einer Trennzeile. Zelllinienbrüche werden zu <br>; Markdown-Pipes und Backslashes werden maskiert.

Die gesamte Verarbeitung bleibt auf dieser Registerkarte. Kein Upload, kein Konto, keine API, kein automatisches Speichern oder keine Serververarbeitung.

Häufig gestellte Fragen

Wie erstelle ich eine Markdown-Tabelle?

Geben Sie eine Kopfzeile und Datenzeilen ein, wählen Sie die Ausrichtung jeder Spalte aus und kopieren Sie dann den generierten Markdown. Pipes werden maskiert und unebene importierte Zeilen werden aufgefüllt.

Wird meine Tabelle hochgeladen?

Nein. Ihre Tabelle wird in diesem Browser-Tab verarbeitet. Importe, Bearbeitungen und generierte Markdowns werden nicht an einen Server gesendet oder automatisch gespeichert.

Kann ich CSV oder TSV importieren?

Ja. Fügen Sie durch Kommas, Semikolons oder Tabulatoren getrennte Werte ein und importieren Sie sie dann in das bearbeitbare Raster. CSV-Felder in Anführungszeichen und Trennzeichen in Anführungszeichen werden unterstützt.

Wie werden Pipes und Zeilenumbrüche gehandhabt?

Eine Pipe innerhalb einer Zelle wird maskiert, sodass die Markdown-Tabelle nicht geteilt wird. Backslashes werden ebenfalls maskiert und Zelllinienumbrüche werden mit <br> dargestellt.
