Statistischer Leistungsrechner

Planen Sie einen Zwei-Gruppen-Mittelwertvergleich. Schätzen Sie die Trennschärfe anhand einer Stichprobengröße oder schätzen Sie die Teilnehmerzahl, die für eine Zielstärke erforderlich ist.

Cohens d ist die erwartete Differenz zwischen den Gruppenmitteln dividiert durch die gemeinsame Standardabweichung. Verwenden Sie eine vertretbare Schätzung auf der Grundlage vorheriger Erkenntnisse oder einen aussagekräftigen Mindesteffekt – kein Ergebnis, das nach Einsicht in die Daten ausgewählt wird.

Näherung für zwei unabhängige, gleich große Gruppen, die Mittelwerte mit einem normalen (z)-Modell vergleichen. Es handelt sich nicht um die exakte T-Test-Berechnung für kleine Stichproben.

Planungsschätzung

Die Schätzung der Stichprobengröße wird auf einen ganzen Teilnehmer aufgerundet. Die Einstellungsvergütung wird getrennt von der analysierten Stichprobe berechnet.

Was bedeutet statistische Aussagekraft?

Leistung ist die Chance, dass ein geplanter Test den angegebenen Effekt erkennt, wenn dieser Effekt real ist. Dies hängt von der Effektgröße, der Stichprobengröße und dem Signifikanzniveau ab.

Häufig gestellte Fragen

Was bedeutet statistische Aussagekraft?

Leistung ist die Chance, dass ein geplanter Test den angegebenen Effekt erkennt, wenn dieser Effekt real ist. Dies hängt von der Effektgröße, der Stichprobengröße und dem Signifikanzniveau ab.

Werden meine Studienannahmen hochgeladen?

Nein. Die Berechnung läuft in diesem Browser. Ihre Annahmen werden von diesem Tool nicht hochgeladen oder gespeichert.

Was bedeutet 80 % Leistung?

Unter den eingegebenen Annahmen bedeutet eine 80 %-Schätzung, dass der geplante Test den angegebenen Effekt in etwa 80 % der Fälle erkennen würde, wenn dieser Effekt real wäre. Es besteht keine 80-prozentige Chance, dass ein Ergebnis wahr ist.

Was ist Cohens d?

Cohens d ist eine standardisierte Differenz zwischen zwei Mittelwerten: der erwarteten Lücke dividiert durch die gemeinsame Standardabweichung. Das Ergebnis hängt stark vom gewählten Effekt ab.

Ersetzt dies eine vollständige Leistungsanalyse?

Nein. Diese Browserschätzung deckt einen ausgeglichenen Zwei-Gruppen-Mittelwertvergleich mit einer normalen Näherung ab. Ungleiche Gruppengrößen, gepaarte Daten, Proportionen, ANOVA, geclusterte oder wiederholte Messungen, Kovariaten, exakte T-Tests, Mehrfachtests oder studienspezifische Designbeschränkungen werden nicht modelliert.
