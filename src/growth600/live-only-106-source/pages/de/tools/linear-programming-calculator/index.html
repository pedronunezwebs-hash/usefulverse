Linearer Programmierrechner

Geben Sie ein lineares Ziel und bis zu acht Einschränkungen ein, um ein lineares Programm mit zwei Variablen zu lösen, wobei x und y nicht negativ sind. Die Zweiphasen-Simplex-Methode meldet ein Optimum, eine Undurchführbarkeit oder Unbeschränktheit und zeigt jeden Drehpunkt an.

Objektive Koeffizienten (x, y)

Eine pro Zeile: a,b <= rhs, a,b >= rhs oder a,b = rhs

Verwendet höchstens acht Einschränkungen und Koeffizienten/rechte Seiten innerhalb von ±1.000.000. Beide Entscheidungsvariablen haben x ≥ 0 und y ≥ 0. Verwenden Sie ein Komma zwischen den x- und y-Koeffizienten; Geben Sie pro Zeile eine Ungleichung oder Gleichheit ein.

Ein zweiphasiger Primal-Simplex-Löser für zwei Variablen. Numerische Toleranz wird für Gleitkomma-Pivots verwendet; Nahezu entartete Probleme können rundungsempfindlich sein. Anstelle eines erfundenen Optimums werden unzulässige, unbeschränkte und iterationslimitierte Fälle angegeben.

Lineare Programmergebnisse

Das Ergebnis gilt nur für das von Ihnen eingegebene mathematische Modell. Es validiert nicht, ob das Ziel, die Einschränkungen, die Einheiten oder die Annahmen für eine tatsächliche Entscheidung geeignet sind.

    Wie funktioniert der Zwei-Variablen-Simplex-Rechner?

    Es wandelt Einschränkungen in ein realisierbares Tableau um, verwendet bei Bedarf ein Phase-I-Ziel und wendet dann Primal-Simplex-Pivots an, um das angeforderte Ziel zu optimieren. Die Variablen x und y dürfen nicht negativ sein.

    Häufig gestellte Fragen

    Wie funktioniert der Zwei-Variablen-Simplex-Rechner?

    Es wandelt Einschränkungen in ein realisierbares Tableau um, verwendet bei Bedarf ein Phase-I-Ziel und wendet dann Primal-Simplex-Pivots an, um das angeforderte Ziel zu optimieren. Die Variablen x und y dürfen nicht negativ sein.

    Werden meine Ziele und Einschränkungen hochgeladen?

    Nein. Der Solver läuft in diesem Browser. Ihr Ziel und Ihre Einschränkungen werden von diesem Tool nicht an einen Server gesendet oder gespeichert.

    Welches Format sollte ich für Einschränkungen verwenden?

    Geben Sie eine Zeile pro Zeile ein, z. B. 1,1 <= 5 oder 2,1 >= 4. Die erste Zahl multipliziert x, die zweite multipliziert y, und beide Variablen dürfen nicht negativ sein.

    Was bedeuten „undurchführbar“ und „unbegrenzt“?

    Unzulässig bedeutet, dass kein Punkt jede eingegebene Einschränkung erfüllt. Unbegrenzt bedeutet, dass eine realisierbare Richtung es ermöglicht, das gewünschte Ziel ohne ein endliches Optimum weiter zu verbessern.

    Beweist das Ergebnis, dass mein reales Modell korrekt ist?

    Nein. Es werden nur die von Ihnen eingegebenen Gleichungen gelöst. Überprüfen Sie Einheiten, Annahmen und ob die Einschränkungen Ihre Entscheidung richtig beschreiben.
