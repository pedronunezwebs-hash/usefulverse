Differentialgleichungslöser

Approximieren Sie ein Anfangswertproblem erster Ordnung y′ = f(x,y) mit Runge-Kutta mit fester Schrittweite. 4. Geben Sie die Ableitung, den Startpunkt und -wert, den Endpunkt und die Schrittanzahl ein. Alles läuft in diesem Browser.

Verwenden Sie x und y, Zahlen, + − × ÷ und ^. Unterstützte Funktionen: sin, cos, tan, exp, ln, log, sqrt und abs. Schreiben Sie die Multiplikation explizit, z. B. x*y.

Festschrittiges klassisches RK4 nur für eine ODE mit Anfangswert erster Ordnung. Unterstützt bis zu 10.000 Schritte; x muss innerhalb von ±1.000.000 und y innerhalb von ±1.000.000.000.000 bleiben. Das Diagramm und die CSV-Datei zeigen bis zu etwa 101 abgetastete Punkte. Numerische Ergebnisse können in der Nähe von Diskontinuitäten, Singularitäten oder bei steifen Gleichungen ungenau sein. Es werden keine symbolischen allgemeinen Lösungen gefunden oder Fehler bestätigt.

Numerische Lösung

Wie funktioniert der Differentialgleichungslöser RK4?

RK4 schätzt die Lösung anhand von vier Steigungsauswertungen pro Schritt. Kleinere Schritte verbessern häufig die Genauigkeit glatter Lösungen, diese numerische Schätzung ist jedoch keine symbolische oder exakte Lösung.

Häufig gestellte Fragen

Werden meine Gleichung und Werte hochgeladen?

Nein. Die Berechnung, Grafik und CSV werden in diesem Browser erstellt. Dieses Tool lädt oder speichert Ihre Eingaben nicht.

Was berechnet die Runge-Kutta-Methode?

Es schätzt den Weg einer Lösung von einem Startpunkt aus, indem es in jedem Schritt wiederholt mehrere abgeleitete Stichproben verwendet. Diese Seite verwendet die klassische RK-Methode vierter Ordnung.

Wie viele Schritte sollte ich verwenden?

Beginnen Sie mit dem Beispiel und vergleichen Sie die Ergebnisse mithilfe weiterer Schritte. Ein kleinerer Schritt kann eine glatte Lösung verbessern, kann jedoch keine Singularität beheben oder eine steife Gleichung für diese grundlegende Methode geeignet machen.

Kann es jede Differentialgleichung exakt lösen?

Nein. Es nähert sich numerisch unterstützten Anfangswertproblemen erster Ordnung an. Es bietet keine symbolische allgemeine Lösung, beweist keine Eindeutigkeit und garantiert keine Fehlergrenze.
