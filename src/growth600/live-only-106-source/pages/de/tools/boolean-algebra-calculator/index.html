Boolescher Algebra-Rechner

Geben Sie einen logischen Ausdruck ein, um minimierte Produktsummen- und Summenproduktformen zu erhalten. Überprüfen Sie jede Zeile der Wahrheitstabelle und zeigen Sie eine Karnaugh-Karte an, wenn der Ausdruck zwei bis vier Variablen enthält.

Verwenden Sie die variablen Buchstaben A–F, die Konstanten 0 und 1 und die Symbole ! & ^ |. Gruppenausdrücke in Klammern setzen.

Exakte Minimierung für akzeptierte Ausdrücke. Höchstens 6 Variablen und 180 Zeichen; Karnaugh-Karten werden für 2–4 Variablen angezeigt. Äquivalente Minimalformen können abweichen. Dies ist kein Schaltungssimulator oder formales Beweiswerkzeug.

Vereinfachtes Ergebnis

Wie vereinfacht man einen booleschen Ausdruck?

Geben Sie einen Ausdruck mit den Variablen A–F und booleschen Operatoren ein und wählen Sie dann Vereinfachen aus. Vergleichen Sie die SOP- und POS-Formulare mit der generierten Wahrheitstabelle. Für zwei bis vier Variablen zeigt das Tool auch eine Gray-geordnete Karnaugh-Karte an.

Häufig gestellte Fragen

Wie vereinfacht man einen booleschen Ausdruck?

Geben Sie einen Ausdruck mit den Variablen A–F und booleschen Operatoren ein und wählen Sie dann Vereinfachen aus. Vergleichen Sie die SOP- und POS-Formulare mit der generierten Wahrheitstabelle. Für zwei bis vier Variablen zeigt das Tool auch eine Gray-geordnete Karnaugh-Karte an.

Wird mein boolescher Ausdruck hochgeladen?

Nein. Parsing, Minimierung, Erstellung von Wahrheitstabellen und Karnaugh-Kartenlayout werden in diesem Browser ausgeführt. Der Ausdruck wird von diesem Tool nicht hochgeladen oder gespeichert.

Was bedeuten SOP und POS in der Booleschen Algebra?

SOP kombiniert AND-Begriffe mit OR; POS kombiniert OR-Klauseln mit AND. Dieses Tool berechnet beide Formen aus derselben Wahrheitstabelle.

Wann wird eine Karnaugh-Karte angezeigt?

Für Ausdrücke mit zwei, drei oder vier Variablen wird eine Gray-geordnete Karnaugh-Karte angezeigt. Die Wahrheitstabelle und minimierte Formulare unterstützen bis zu sechs Variablen.
