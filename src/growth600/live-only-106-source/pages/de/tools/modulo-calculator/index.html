Modulo Calculator

Berechnen Sie den euklidischen Quotienten und den Rest für ganze Zahlen. Negative Eingaben werden konsistent behandelt und die Abteilungsidentität zeigt, wie die Antwort gebildet wird.

Die zu dividierende Zahl; es kann negativ sein.

Verwenden Sie eine beliebige ganze Zahl ungleich Null. sein absoluter Wert definiert den Modul.

Prüfen Sie, ob dieser Wert mit dem Dividendenmodulo des Divisors übereinstimmt.

Akzeptiert vorzeichenbehaftete ganze Zahlen mit bis zu 50 Ziffern. Keine Brüche oder Dezimalzahlen. Das Ergebnis verwendet das euklidische Modulo; Einige Programmiersprachen verwenden eine andere Restregel für Negative.

Ergebnis

Wie berechnet man ein Modulo mit einer negativen Zahl?

Dieser Rechner verwendet einen nicht negativen Rest, der kleiner als der absolute Teiler ist. Beispielsweise ist −7 mod 3 2, weil −7 = (−3 × 3) + 2.

Häufig gestellte Fragen

Wie berechnet man ein Modulo mit einer negativen Zahl?

Dieser Rechner verwendet einen nicht negativen Rest, der kleiner als der absolute Teiler ist. Beispielsweise ist −7 mod 3 2, weil −7 = (−3 × 3) + 2.

Are my numbers uploaded?

Nein. Die genaue Berechnung läuft in diesem Browser. Numbers are not uploaded or saved.

Was ist −7 mod 3?

Unter Verwendung der euklidischen Konvention ist −7 mod 3 2: −7 = (−3 × 3) + 2 und 0 ≤ 2 < 3.

Was bedeutet kongruentes Modulo m?

Zwei ganze Zahlen sind modulo m kongruent, wenn ihre Differenz durch |m| teilbar ist. Der optionale Vergleich prüft dies genau.

Warum kann sich dies vom %-Operator einer Programmiersprache unterscheiden?

Einige Sprachen behalten im Rest das Vorzeichen einer negativen Dividende bei. Dieser Rechner gibt stattdessen einen Rest von 0 bis zum absoluten Teiler (aber nicht einschließlich) zurück.
