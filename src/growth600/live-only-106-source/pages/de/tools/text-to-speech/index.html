Text-to-Speech

Verwandeln Sie geschriebenen Text mit einer in Ihrem Browser oder Gerät verfügbaren Stimme in Sprache. Wählen Sie eine Stimme, passen Sie Geschwindigkeit und Tonhöhe an und pausieren Sie, setzen Sie fort oder stoppen Sie.

Einige Stimmen senden möglicherweise Text an einen Drittanbieter. Sie bleiben ausgeblendet, es sei denn, Sie zeigen sie an. Bei der Wiedergabe werden Sie zunächst zur Bestätigung aufgefordert.

Sprachverfügbarkeit und -verarbeitung hängen vom Browser, dem Betriebssystem und den installierten Sprachdiensten ab. Eine „lokale“ Bezeichnung ist keine Garantie dafür, wie das Betriebssystem mit Audio umgeht.

Sprachwiedergabe

Wie konvertiere ich Text online in Sprache?

Geben Sie Text ein oder fügen Sie ihn ein, wählen Sie eine verfügbare Stimme und drücken Sie „Play“. Sie können jederzeit pausieren, fortfahren oder stoppen. Die Wiedergabe nutzt den in Ihrem Browser oder Gerät ausgewählten Sprachdienst.

Häufig gestellte Fragen

Wie konvertiere ich Text online in Sprache?

Geben Sie Text ein oder fügen Sie ihn ein, wählen Sie eine verfügbare Stimme und drücken Sie „Play“. Sie können jederzeit pausieren, fortfahren oder stoppen. Die Wiedergabe nutzt den in Ihrem Browser oder Gerät ausgewählten Sprachdienst.

Wird mein Text hochgeladen oder gespeichert?

Diese Website lädt oder speichert Ihren Text nicht. Der Text wird an den in Ihrem Browser oder Gerät ausgewählten Sprachdienst weitergeleitet. Eine lokal markierte Stimme kann auf Ihrem Gerät verarbeitet werden. Eine unbekannte oder entfernte Stimme kann Text an ihren Anbieter senden. Lesen Sie die Datenschutzbestimmungen dieses Anbieters, bevor Sie sich für diese Stimme entscheiden.

Erstellt dies eine MP3-Datei?

Nein. Die Browser-Sprachsynthese spielt Audio ab, bietet jedoch keinen konsistenten Audiodateiexport. Verwenden Sie ein separates Aufnahmetool nur, wenn Sie die Berechtigung zum Aufzeichnen des Audios haben.

Warum sehe ich keine Stimmen?

Stimmen kommen von Ihrem Browser und Betriebssystem. Sie werden möglicherweise mit einer kurzen Verzögerung geladen oder es ist möglicherweise keines für diese Sprache installiert. Überprüfen Sie die Spracheinstellungen des Geräts oder versuchen Sie es mit einem anderen Browser.

Garantiert eine lokale Stimme, dass der Ton auf meinem Gerät bleibt?

Nein. Diese Website lädt Ihren Text nicht hoch, aber die lokale Bezeichnung des Browsers kann nicht garantieren, wie das Betriebssystem oder der Sprachdienst Audio verarbeitet. Eine unbekannte oder entfernte Stimme sendet möglicherweise Text an ihren Anbieter.
