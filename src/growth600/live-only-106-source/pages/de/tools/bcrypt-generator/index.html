Kostenlose Nutzung, kein Konto erforderlich

Bcrypt-Generator

Generieren Sie einen Standard-bcrypt-Hash oder vergleichen Sie ein Passwort mit einem vorhandenen bcrypt-Hash. Die Arbeit wird in einem lokalen Browser-Worker ausgeführt und das Passwort wird nach jeder Überprüfung gelöscht.

Bcrypt verwendet nur die ersten 72 UTF-8 Bytes. Dieses Tool lehnt längere Werte ab, anstatt sie stillschweigend zu kürzen. Kosten 8–14 erhöhen die Arbeit exponentiell; Höhere Kosten können insbesondere bei Telefonen länger dauern. Ein lokaler Mitarbeiter sorgt dafür, dass die Seite reagiert, aber Ihr Gerät führt die Arbeit aus.

Verwenden Sie ein Testpasswort, kein echtes Login-Passwort. Das Ergebnis dient dem Lernen und der Kompatibilitätsprüfung. Verwenden Sie diese Browserseite nicht als Produktionskonto-Speichersystem.

Fügen Sie einen Standard-bcrypt-Hash mit 60 Zeichen ein. Die Verifizierung unterstützt bcrypt und kostet 4–14; Ungewöhnlich teure Hashes werden abgelehnt, um übermäßige Arbeit auf Ihrem Gerät zu vermeiden.

Ergebnis

Was macht ein bcrypt-Hash?

Bcrypt ist eine Passwort-Hashing-Funktion, keine Verschlüsselung. Es kombiniert einen Einweg-Hash mit einem zufälligen Salt und einem konfigurierbaren Arbeitsfaktor. Ein Hash kann mit dem Passwort eines Kandidaten verglichen, aber nicht entschlüsselt werden, um das Original preiszugeben.

Häufig gestellte Fragen

Was macht ein bcrypt-Hash?

Bcrypt ist eine Passwort-Hashing-Funktion, keine Verschlüsselung. Es kombiniert einen Einweg-Hash mit einem zufälligen Salt und einem konfigurierbaren Arbeitsfaktor. Ein Hash kann mit dem Passwort eines Kandidaten verglichen, aber nicht entschlüsselt werden, um das Original preiszugeben.

Werden mein Passwort oder mein Hash hochgeladen oder gespeichert?

Nein. Hashing und Überprüfung werden in diesem Browser ausgeführt. Die Seite sendet das eingegebene Passwort oder den Hash nicht an einen Server und speichert sie auch nicht; Das Passwortfeld wird gelöscht, wenn der Vorgang abgeschlossen ist. Verwenden Sie aus Sicherheitsgründen ein Testpasswort anstelle eines echten Kontopassworts.

Verschlüsselt bcrypt mein Passwort?

Nein. Bcrypt ist ein Einweg-Passwort-Hash, keine umkehrbare Verschlüsselung. Es ist so konzipiert, dass die Software das Passwort eines Kandidaten überprüfen kann, ohne das ursprüngliche Passwort zu speichern.

Warum hat bcrypt ein 72-Byte-Limit?

Das bcrypt-Format verarbeitet höchstens 72 UTF-8 Bytes. Dieses Tool verweigert längere Eingaben, sodass unterschiedliche Passwörter niemals stillschweigend als derselbe gekürzte Wert behandelt werden.

Soll ich diesen Hash für ein echtes Konto speichern?

Verwenden Sie diese Seite nicht als Produktionsanmeldeinformationssystem. Echte Dienste sollten Passwörter auf ihrem vertrauenswürdigen Server mit gepflegten Authentifizierungsbibliotheken, geeigneten Parametern, Ratenbegrenzungen und Kontoschutzmaßnahmen hashen.
