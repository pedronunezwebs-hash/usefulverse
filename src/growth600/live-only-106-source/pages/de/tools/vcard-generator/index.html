VCard-Generator

Erstellen Sie einen einzelnen digitalen Kontakt als .vcf-Datei in Ihrem Browser. Wählen Sie vCard 3.0 oder 4.0, fügen Sie Kontaktdaten hinzu und betten Sie optional ein kleines JPEG- oder PNG-Foto ein.

Optional JPEG oder PNG, bis zu 128 KiB. Das Foto wird in die VCF-Datei eingebettet; es wird nicht hochgeladen.

Ein Kontakt, bis zu 5 Telefonnummern und 5 E-Mails, 500 Zeichen pro Textfeld und ein Limit für generierte Dateien von 1 MiB. Es werden nur vCard 3.0 und 4.0 angeboten.

Wird lokal ausgeführt, nachdem Sie „Generieren“ ausgewählt haben. Kein Konto, Kontaktbuchzugriff, Upload, API, Serververarbeitung oder automatische Speicherung.

VCF-Vorschau


  

    
Wird dadurch der Kontakt zu meinem Telefon hinzugefügt?
Nein. Es wird eine VCF-Datei erstellt, die Sie in der Vorschau ansehen, kopieren oder herunterladen können. Es liest oder ändert niemals Ihr Adressbuch; Sie entscheiden, ob und wo die Datei importiert werden soll.


    
Häufig gestellte Fragen
Wird dadurch der Kontakt zu meinem Telefon hinzugefügt?
Nein. Es wird eine VCF-Datei erstellt, die Sie in der Vorschau ansehen, kopieren oder herunterladen können. Es liest oder ändert niemals Ihr Adressbuch; Sie entscheiden, ob und wo die Datei importiert werden soll.
Werden meine Kontaktinformationen hochgeladen?
Nein. Details und ein optionales Foto werden auf diesem Gerät verarbeitet. Es gibt keinen Upload, kein Konto, keine Serververarbeitung oder automatische Speicherung.
Was ist der Unterschied zwischen vCard 3.0 und 4.0?
Es handelt sich um zwei Versionen des vCard-Kontaktformats. Das Tool schreibt eine kompatible VCF-Textdatei mit der von Ihnen ausgewählten Version; Kontakt-Apps unterstützen sie möglicherweise unterschiedlich.
Werden dadurch Telefonnummern oder E-Mail-Adressen überprüft?
Nein. Es wird nur das Grundformat überprüft. Es kann nicht überprüft werden, ob eine Nummer, ein Postfach, eine Adresse oder eine Website der Person gehört.
