Wochenplaner

Erstellen Sie einen einfachen wöchentlichen Zeitblockplan für Arbeit, persönliche Pläne, Studium oder Gesundheit. Übernachtsperren und Fahrplankonflikte werden übersichtlich dargestellt.

Ein sich wiederholender Wochenplan verwendet lokale Uhrzeiten; Zeitzonen, Sommerzeitumstellungen, Kalenderereignisse oder Erinnerungen werden nicht berücksichtigt.

Der Plan bleibt in dieser Registerkarte im Speicher. Laden Sie ein JSON-Backup herunter, um es aufzubewahren. keine automatische Speicherung oder Upload.

Wochenplan

Wie erstelle ich einen Wochenplan?

Fügen Sie für jeden Block einen Titel, einen Tag, eine Startzeit, eine Endzeit und eine Kategorie hinzu. Blöcke können Mitternacht überschreiten. Überlappende Zeiten werden gekennzeichnet, auch am Sonntag und Montag.

Häufig gestellte Fragen

Wie erstelle ich einen Wochenplan?

Fügen Sie für jeden Block einen Titel, einen Tag, eine Startzeit, eine Endzeit und eine Kategorie hinzu. Blöcke können Mitternacht überschreiten. Überlappende Zeiten werden gekennzeichnet, auch am Sonntag und Montag.

Wird mein Wochenplan hochgeladen oder gespeichert?

Nein. Ihr Zeitplan bleibt in diesem Browser-Tab, es sei denn, Sie laden ein JSON-Backup herunter. Importieren Sie ein von Ihnen ausgewähltes Backup von Ihrem Gerät.

Kann ein Wochenplaner Nachtschichten einschließen?

Ja. Wählen Sie eine Endzeit vor der Startzeit, um einen Block zu erstellen, der am nächsten Tag endet. Es werden Blöcke bis zu 18 Stunden unterstützt.

Erkennt der Wochenplan Konflikte?

Ja. Es überprüft Zeitblöcke am selben Tag und über Mitternacht hinweg, einschließlich eines Sonntagsblocks, der sich mit dem Montag überschneidet.

Wird dieser Planer mit Google Kalender synchronisiert?

Nein. Es funktioniert lokal auf dieser Registerkarte und verfügt über keine Kalenderverbindung oder Erinnerungsdienst. Sie können den Plan ausdrucken oder ein JSON-Backup herunterladen und importieren.
