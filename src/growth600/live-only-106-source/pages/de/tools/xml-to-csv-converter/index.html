XML-zu-CSV-Konverter

Verwandeln Sie eine einfache XML-Datensatzliste in eine CSV-Tabelle oder erstellen Sie XML-Datensätze aus dem Text einer CSV-Datei. Wählen Sie die Richtung, fügen Sie Ihre Daten ein und kopieren oder laden Sie das Ergebnis herunter. Es wird nichts hochgeladen.

Unterstützt eine einfache Liste gleichnamiger Datensatzelemente oder einen einfachen Datensatz. Untergeordnete Elemente müssen Skalarwerte sein; Verschachtelte und wiederholte Felder werden nicht reduziert.

Verwenden Sie die erste Zeile für Spaltennamen. Ein Header wie @id wird zu einem XML-Attribut. Verwenden Sie #text für Datensatztext.

Dies ist eine einfache Tabellenkonvertierung, keine verlustfreie XML-Formatkonvertierung. Namespaces, verschachtelte Strukturen, gemischte Inhalte, Kommentare und XML-Formatierungen bleiben nicht erhalten. Text ist nicht typbewusst. Tabellenkalkulationsformelähnlichen CSV-Werten wird aus Sicherheitsgründen ein Apostroph vorangestellt.

Ergebnis

Überprüfen Sie die Ausgabe, bevor Sie sie in eine andere Anwendung importieren.

Wie konvertiere ich XML in CSV?

Wählen Sie XML zu CSV und fügen Sie XML mit einer einfachen Datensatzliste ein. Wiederholte direkte Datensatzelemente werden zu Zeilen. Elementnamen werden zu Spalten; Attribute verwenden @name. Wählen Sie „CSV zu XML“, um einfache XML-Datensätze aus Kopfzeilen und Zeilen zu erstellen.

Häufig gestellte Fragen

Wie konvertiere ich XML in CSV?

Wählen Sie XML zu CSV und fügen Sie XML mit einer einfachen Datensatzliste ein. Wiederholte direkte Datensatzelemente werden zu Zeilen. Elementnamen werden zu Spalten; Attribute verwenden @name. Wählen Sie „CSV zu XML“, um einfache XML-Datensätze aus Kopfzeilen und Zeilen zu erstellen.

Wird mein XML oder CSV hochgeladen?

Nein. Parsing und Konvertierung werden in diesem Browser ausgeführt. Die Eingabe ist auf 200.000 Zeichen, 5.000 Zeilen, 64 Spalten und 20.000 Zellen beschränkt. DTD- und Entity-Deklarationen werden blockiert und externe Ressourcen werden nicht abgerufen.

Wie werden XML-Attribute in CSV angezeigt?

Ein Attribut wie id="101" wird zu einer Spalte mit dem Namen @id. Bei der Rückkonvertierung wird ein CSV-Header, der mit @ beginnt, zu einem XML-Attribut.

Kann es verschachteltes XML in eine flache Tabelle konvertieren?

Nein. Verschachtelte untergeordnete Strukturen, wiederholte Felder innerhalb eines Datensatzes und gemischter Text werden abgelehnt, anstatt reduziert zu werden oder stillschweigend verloren zu gehen. Verwenden Sie einen dedizierten XML-zu-JSON-Workflow für verschachtelte Daten.

Behält die CSV XML-Typen und -Formatierungen bei?

Nein. CSV speichert Zellentext, keine XML-Typen, Namespaces oder Formatierungen. Formelähnliche Zellwerte erhalten beim Exportieren ein Apostroph-Präfix, um das Risiko der Ausführung von Tabellenformeln zu verringern.
