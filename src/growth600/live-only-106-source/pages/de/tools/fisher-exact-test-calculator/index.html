Fisher Exact Test-Rechner

Geben Sie die vier Zählwerte in eine 2×2-Tabelle ein, um den exakten Fisher-Test mit festen Rändern zu berechnen.

Beobachtete 2×2-Zähltabelle

Wählen Sie eine einseitige Richtung nur, wenn dies vor der Untersuchung der Daten angegeben wurde. Das Odds Ratio ist das unkorrigierte Kreuzproduktverhältnis; Null Zellen können es undefiniert oder unendlich machen. Dies ist keine kausale Schlussfolgerung.

Zählungen müssen ganze Zahlen sein. Maximal 10.000 pro Zelle und 20.000 insgesamt. Die zweiseitigen Testsummentabellen sind nicht wahrscheinlicher als die beobachtete Tabelle unter festen Rändern.

Genaues Fisher-Testergebnis

Der p-Wert hängt von den beobachteten Zeilen- und Spaltensummen ab. Es ist nicht für mehrere Tests, Kovariaten oder ein komplexes Stichprobendesign geeignet.

Wann sollte ich den exakten Fisher-Test verwenden?

Es handelt sich um einen exakten Assoziationstest für eine 2×2-Tabelle, der häufig verwendet wird, wenn die erwartete Anzahl gering ist. Das Ergebnis hängt vom Studiendesign ab und beweist keine Kausalität.

Häufig gestellte Fragen

Wann sollte ich den exakten Fisher-Test verwenden?

Es handelt sich um einen exakten Assoziationstest für eine 2×2-Tabelle, der häufig verwendet wird, wenn die erwartete Anzahl gering ist. Das Ergebnis hängt vom Studiendesign ab und beweist keine Kausalität.

Werden meine Zählungen hochgeladen?

Nein. Die Berechnung läuft in diesem Browser. Zählungen werden von diesem Tool nicht hochgeladen oder gespeichert.

Was ist die Nullhypothese?

Der Test bewertet, ob die Zeilen- und Spaltenklassifizierungen abhängig von den beobachteten Rändern unabhängig sind. Es erklärt nicht, warum eine Assoziation bestehen kann.

Wie wird ein zweiseitiger p-Wert berechnet?

Dieser Rechner addiert Wahrscheinlichkeiten aller möglichen Tabellen mit denselben Rändern, deren bedingte Wahrscheinlichkeit nicht größer ist als die der beobachteten Tabelle. Andere Softwarekonventionen können abweichen.

Beweist ein kleiner p-Wert einen Effekt?

Nein. Ein p-Wert ist keine Effektgröße oder ein Kausalitätsbeweis. Überprüfen Sie das Chancenverhältnis, das Studiendesign, die Datenqualität, die Unsicherheit und etwaige Mehrfachtestpläne.
