VO2 Max Rechner

Schätzen Sie die aerobe Kapazität anhand eines 12-minütigen Cooper-Laufs oder eines 1,6 km langen Rockport-Spaziergangs. Wählen Sie die Methode aus, deren Test Sie abgeschlossen haben, und geben Sie deren Messwerte ein.

Cooper 12-Minuten-Lauf
Rockport eine Meile zu Fuß

Rockport-Protokoll: Gehen Sie eine abgemessene Meile so schnell, wie Sie sicher können; Notieren Sie sofort im Ziel die Zeit und die Herzfrequenz. Führen Sie diesen Test nicht aus.

Feldtestgleichungen schätzen nur die aerobe Kapazität. Die Ergebnisse können von einer überwachten Labormessung abweichen und passen möglicherweise nicht für jede Person oder Bevölkerung. Es wird keine Fitnesskategorie oder Diagnose zugewiesen.

Der Cooper-Test ist anstrengend. Versuchen Sie nicht, maximale Anstrengungen zu unternehmen, wenn Sie sich unwohl fühlen, Symptome haben oder Ihnen geraten wurde, intensive körperliche Betätigung zu vermeiden. Hören Sie auf, wenn Sie sich unwohl fühlen; Fragen Sie einen qualifizierten Arzt nach der persönlichen Sicherheit.

Sources: Cooper, JAMA. 1968;203(3):201–204. doi:10.1001/jama.1968.03140030033008. Kline et al., Med Sci Sports Exerc. 1987;19(3):253–259. PMID:3600239.

Verwendete Methode:

Wie kann ich VO2 max mit einem Feldtest abschätzen?

Die Cooper-Schätzung verwendet die in 12 Minuten zurückgelegte Strecke. Die Rockport-Schätzung verwendet einen schnellen Spaziergang von einer Meile, Alter, Gewicht, den Mann/Frau-Koeffizienten der Gleichung, die Gehzeit und die Endherzfrequenz. Es handelt sich jeweils um eine bevölkerungsbasierte Vorhersage, nicht um eine Labormessung.

Was verwendet die Cooper-Testschätzung?

Es wird die während eines 12-minütigen Laufs zurückgelegte Distanz verwendet. Die Schätzung ist eine Regression aus einem Feldtest; es handelt sich nicht um eine direkte Messung des Sauerstoffverbrauchs.

Welche Maße benötigt die Rockport-Gehschätzung?

Die ursprüngliche Gleichung verwendet eine Gehzeit von einer Meile, die Endherzfrequenz, das Alter, das Gewicht und einen binären Geschlechtskoeffizienten. Die Quellenstudie umfasste gesunde Erwachsene im Alter von 30–69 Jahren; Das Ergebnis sollte nicht als universelle Vorhersage betrachtet werden.

Ist ein VO2 max-Feldtest-Schätzwert ein medizinisches Ergebnis?

Nein. Es handelt sich um eine ungefähre Fitnessschätzung, die von Labortests abweichen kann. Es stellt keine Gesundheitsdiagnose dar und bestimmt nicht, ob Bewegung für Sie sicher ist.
