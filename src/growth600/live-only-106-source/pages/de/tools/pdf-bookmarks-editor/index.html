PDF-Lesezeichen-Editor

Fügen Sie einem PDF ein navigierbares Inhaltsverzeichnis hinzu oder organisieren Sie die vorhandenen Lesezeichen. Erstellen Sie verschachtelte Abschnitte, weisen Sie Seitenziele zu, ordnen Sie Einträge neu an und speichern Sie eine separate Kopie in Ihrem Browser.

Editing erstellt eine neue PDF-Kopie. Einige Reader zeigen Lesezeichen möglicherweise anders an; Überprüfen Sie die gespeicherte Kopie, bevor Sie sie freigeben.

LLokale Grenzen: 25 MiB Eingabe, 300 Seiten, 500 Lesezeichen, 20 Verschachtelungsebenen und 50 MiB Ausgabe. Große Dateien beanspruchen möglicherweise erheblichen Gerätespeicher; Ein Computer wird empfohlen.

Erstellt interne Seitenziele und verschachtelte Gliederungseinträge. Vorhandene externe Links, benannte Ziele oder nicht unterstützte Lesezeichenaktionen werden abgelehnt und nicht stillschweigend verworfen. Der Seiteninhalt wird nicht bearbeitet. Digitale Signaturen können nach dem Speichern ungültig werden.

Werden meine PDFs oder Lesezeichen hochgeladen?

Nr. Das ausgewählte Dokument wird in diesem Browser verarbeitet, nachdem Sie es ausgewählt haben. UsefulVerse lädt das PDF nicht hoch und sendet seine Lesezeichendaten nicht an einen Server.

Können Lesezeichen unter Abschnitten verschachtelt werden?

Yes. Legen Sie einen übergeordneten Abschnitt fest, um eine Hierarchie zu erstellen. Die Dokumentseite selbst bleibt unverändert; Jedes Lesezeichen verweist auf die von Ihnen gewählte Seitenzahl.

Werden dadurch Lesezeichen erhalten, die externe Links öffnen?

Dieser Editor unterstützt derzeit interne Seitenziele. Es lehnt Dateien mit nicht unterstützten externen Aktionen oder benannten Zielen ab, anstatt sie stillschweigend zu löschen.

Ändert es die PDF-Seiten oder die Signatur?

Es bearbeitet die Dokumentgliederung und speichert eine neue Kopie, nicht den Seiteninhalt. Jede Bearbeitung kann eine digitale Signatur ungültig machen. Überprüfen Sie daher das Ergebnis und behandeln Sie dieses Tool nicht als Signaturerhaltung.
