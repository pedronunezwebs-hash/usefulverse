Rechner für rationale Ausdrücke

Geben Sie Polynome mit ganzzahligen Koeffizienten in x ein, um einen rationalen Ausdruck zu reduzieren. Das Ergebnis behält die ursprüngliche Nennerbeschränkung bei, sodass beim Abbruch niemals Werte ausgeblendet werden, die die Eingabe undefiniert machen.

Verwenden Sie ganzzahlige Koeffizienten und x, zum Beispiel x^2-1. Versorgt bis zu 8 Personen.

Verwenden Sie ganzzahlige Koeffizienten und x, zum Beispiel x-1. Es kann nicht Null sein.

Unterstützt eine Variable x, ganzzahlige Koeffizienten bis zu 1.000.000 und Grad bis zu 8. Keine Klammern oder Dezimalkoeffizienten.

Ergebnis

Wie vereinfacht man einen rationalen Ausdruck?

Faktorisieren Sie Zähler und Nenner, heben Sie deren gemeinsames Polynom auf und behalten Sie die Nullstellen des ursprünglichen Nenners als Einschränkungen bei. Beispielsweise reduziert sich x²−1 über x−1 auf x+1, wobei x≠1 immer noch ausgeschlossen ist.

Häufig gestellte Fragen

Wie vereinfacht man einen rationalen Ausdruck?

Faktorisieren Sie Zähler und Nenner, heben Sie deren gemeinsames Polynom auf und behalten Sie die Nullstellen des ursprünglichen Nenners als Einschränkungen bei. Beispielsweise reduziert sich x²−1 über x−1 auf x+1, wobei x≠1 immer noch ausgeschlossen ist.

Werden meine Ausdrücke hochgeladen?

Nein. Parsing und Vereinfachung werden lokal in diesem Browser ausgeführt. Eingaben werden nicht hochgeladen oder gespeichert.

Warum eine Einschränkung beibehalten, nachdem ein Faktor storniert wurde?

Der vereinfachte Ausdruck kann mit einem Wert definiert werden, bei dem der ursprüngliche Nenner Null war. Dieser Wert bleibt von der Domäne des ursprünglichen Ausdrucks ausgeschlossen.

Welches Polynomformat wird unterstützt?

Verwenden Sie eine einzelne Variable x mit ganzzahligen Koeffizienten, z. B. 2x^3−x+4. Potenzen von 0 bis 8 werden unterstützt; Klammern, Dezimalkoeffizienten und mehrere Variablen gelten nicht.

Findet dies jede mögliche Faktorisierung?

Es löscht den exakten gemeinsamen Polynomfaktor mithilfe der Ganzzahlarithmetik. Es bietet keine vollständige Faktorisierung in irreduzible lineare oder quadratische Faktoren.
