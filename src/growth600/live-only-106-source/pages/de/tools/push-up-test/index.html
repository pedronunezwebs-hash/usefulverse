Liegestütztest und Satz-Tracker

Zeichnen Sie einen einzelnen Satz als einfachen Test auf oder protokollieren Sie mehrere Sätze mit dem Rest dazwischen. Sie zählen und tragen Wiederholungen ein; Dieses Tool nutzt weder Ihre Kamera noch bewertet es Ihre Stärke.

Geben Sie bis zu 20 ganzzahlige Zählungen von 0 bis 500 ein. Leerzeilen werden ignoriert und zählen nicht als Sätze. Zählen Sie nur Wiederholungen, die Sie mit der von Ihnen gewählten Form absolviert haben.

Notizen allgemein halten; Dies ist keine Krankenakte.

Wählen Sie einen bequemen Bewegungsbereich und stoppen Sie, wenn Sie Schmerzen, Schwindel oder ungewöhnliche Kurzatmigkeit verspüren. Die Anzahl der Wiederholungen hängt von der Form, dem Tempo und den Testbedingungen ab. Dieses Tool bietet keine Fitnessbewertung, Diagnose oder Übungsvorschrift.

Das Speichern ist optional und verwendet nur diesen Browser. Deaktivieren Sie das Kontrollkästchen, um ohne Speichern zu berechnen, oder löschen Sie den gespeicherten Verlauf unten.

Ihre Sitzung

Wie berechnet der Push-Up-Test-Tracker die Anzahl der Wiederholungen?

Es addiert die ganzzahligen Wiederholungen, die für jeden nicht leeren Satz eingegeben wurden. Leerzeilen werden ignoriert, eine Nullmenge bleibt Null und die Restschätzung ist die Pause pro Pause multipliziert mit der Anzahl der Pausen.

Häufig gestellte Fragen

Wie berechnet der Push-Up-Test-Tracker die Anzahl der Wiederholungen?

Es addiert die ganzzahligen Wiederholungen, die für jeden nicht leeren Satz eingegeben wurden. Leerzeilen werden ignoriert, eine Nullmenge bleibt Null und die Restschätzung ist die Pause pro Pause multipliziert mit der Anzahl der Pausen.

Werden meine Liegestützsets hochgeladen?

Nein. Die Berechnung läuft in diesem Browser. Der Sitzungsverlauf wird erst auf dieses Gerät geschrieben, nachdem Sie sich dafür angemeldet haben. Sie können es hier löschen.

Zählen Leerzeilen als Satz oder Wiederholung?

Nein. Leere Zeilen werden ignoriert. Eine Zeile mit 0 zeichnet einen Satz mit Null Wiederholungen auf und fügt der Gesamtmenge keine Wiederholungen hinzu.

Kann ich dies für ein maximales Set oder für mehrere Sets verwenden?

Ja. Geben Sie eine Zeile für einen einzelnen manuell gezählten Satz oder mehrere Zeilen ein, um Sätze und den Rest dazwischen zusammenzufassen. Die Testbedingungen liegen bei Ihnen; Die Ergebnisse werden nicht mit Bevölkerungsnormen verglichen.

Wird mein Trainingsverlauf hochgeladen?

Nein. Der Verlauf ist optional und bleibt in diesem Browser auf diesem Gerät. Löschen Sie es jederzeit mit der Schaltfläche „Löschen“.
