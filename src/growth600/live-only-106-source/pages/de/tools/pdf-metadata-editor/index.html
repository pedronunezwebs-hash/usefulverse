PDF-Metadaten-Editor

Lesen oder bearbeiten Sie allgemeine Dokumentinformationen, die in einer PDF-Datei gespeichert sind, und laden Sie dann eine separate Kopie herunter. Das ausgewählte PDF verbleibt auf diesem Gerät.

Behalten Sie Ihr Original. Durch das erneute Speichern können digitale Signaturen ungültig werden oder erweiterte PDF-Funktionen beeinträchtigt werden. Dieses Tool entfernt keine versteckten Informationen und zertifiziert auch nicht den Datenschutz.

Lokale Grenzwerte: 25 MiB Eingabe, 300 Seiten und 50 MiB Ausgabe. Große Dokumente benötigen möglicherweise mehr Speicher; Ein Computer wird empfohlen.

Es werden nur Standard-PDF-Dokumentinformationen bearbeitet. XMP, benutzerdefinierte Metadaten, Anhänge, versteckte Inhalte und Signaturvalidierung werden nicht unterstützt.

Die Verarbeitung erfolgt lokal in diesem Browser. Kein Konto, kein Upload, keine Serververarbeitung oder automatische Speicherung.

Welche PDF-Metadaten kann ich ändern?

Dieses Tool bearbeitet die Standard-Dokumentinformationsfelder: Titel, Autor, Betreff, Schlüsselwörter, Ersteller, Produzent, Erstellungsdatum und Änderungsdatum. XMP-Metadaten oder benutzerdefinierte Eigenschaften werden nicht bearbeitet.

Häufig gestellte Fragen

Welche PDF-Metadaten kann ich ändern?

Dieses Tool bearbeitet die Standard-Dokumentinformationsfelder: Titel, Autor, Betreff, Schlüsselwörter, Ersteller, Produzent, Erstellungsdatum und Änderungsdatum. XMP-Metadaten oder benutzerdefinierte Eigenschaften werden nicht bearbeitet.

Ist mein PDF hochgeladen?

Nein. Das Lesen und Bearbeiten erfolgt in Ihrem Browser, nachdem Sie eine Datei ausgewählt haben. Die Originaldatei wird nicht verändert; Beim Speichern wird eine separate PDF-Kopie erstellt.

Entfernt dies alle Metadaten aus einem PDF?

Nein. Es werden nur allgemeine Einträge im Standard-PDF-Dokumentinformationswörterbuch bearbeitet. XMP, benutzerdefinierte Eigenschaften, eingebettete Dateien und andere versteckte Inhalte bleiben möglicherweise erhalten.

Bleibt beim Bearbeiten von Metadaten eine digitale Signatur erhalten?

Verlassen Sie sich nicht darauf. Durch das Speichern wird die PDF-Datei neu geschrieben und kann vorhandene digitale Signaturen ungültig machen oder Funktionen beeinträchtigen, die von diesem Tool nicht unterstützt werden. Bewahren Sie das Original auf und überprüfen Sie die Kopie.

Wird das Original-PDF überschrieben?

Nein. Das Tool liest die ausgewählte Datei und erstellt eine separate herunterladbare Kopie. Das Original auf Ihrem Gerät wird dadurch nicht verändert.
