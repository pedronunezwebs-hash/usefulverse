FreeCell

Verschiebe alle 52 Karten auf ihre Farbablagen. Nutzen Sie vier freie Zellen als temporären Raum, bauen Sie absteigende Spalten mit wechselnden Farben auf und planen Sie jede Superbewegung um die offenen Zellen und Spalten herum.

Lassen Sie das Feld leer, um ein neues, zufälliges Angebot zu erhalten. Verwenden Sie denselben Startwert, um denselben Deal neu zu erstellen. es bleibt nur auf dieser Seite.

Verschiebt: 0

Tableaukarten werden in abwechselnden Farben nach unten aufgebaut. Ein ausgewählter Lauf muss bereits die Farben wechseln und um einen Rang absteigen. Ein Supermove wird durch die aktuell leeren freien Zellen und Hilfsspalten begrenzt.

Foundations bauen sich von Ass bis König in derselben Farbe auf. Es kann nur die oberste Karte einer Spalte oder eine Karte in einer freien Zelle verschoben werden.

Wie spielt man FreeCell?

Bauen Sie jedes Fundament von Ass bis König in einer Farbe. Bauen Sie auf dem Tableau in wechselnden Farben nach unten auf. Eine freie Zelle kann eine Karte enthalten. Sie können einen gültigen absteigenden Lauf mit wechselnden Farben nur dann als Supermove verschieben, wenn die verfügbaren leeren Zellen und Hilfsspalten dies unterstützen.

Speichert FreeCell mein Spiel?

Nein. Das Spiel läuft in diesem Browser-Tab. Es wird kein Konto benötigt, keine Züge hochgeladen oder ein Spiel automatisch gespeichert. Ein Replay-Seed ist optional und verbleibt nur auf dieser Seite.

Wie viele Karten kann ein FreeCell-Supermove bewegen?

Die Obergrenze beträgt (leere freie Zellen + 1) multipliziert mit 2 hoch die leeren Hilfsspalten. Die Zielspalte wird nicht als Hilfsspalte gezählt, wenn sie leer ist. Der Lauf muss ebenfalls absteigend sein und rot und schwarz abwechseln.

Kann ich eine Sequenz direkt in FreeCell verschieben?

Ja, wenn die Karten bereits eine absteigende Farbwechselreihe bilden und deren Größe die Kapazität der leeren freien Zellen und Hilfsspalten nicht überschreitet. Das Spiel erzwingt dieses Limit.

Sind FreeCell-Angebote wiederholbar?

Ja. Geben Sie den gleichen optionalen Startwert ein und wählen Sie einen neuen Deal aus, um dessen Layout in diesem Browser neu zu erstellen. Lassen Sie den Samen leer, um ihn zufällig zu mischen. Es werden keine Samen oder Spiele an einen Server gesendet.
