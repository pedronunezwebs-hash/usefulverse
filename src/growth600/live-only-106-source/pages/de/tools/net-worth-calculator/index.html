Vermögensrechner

Addieren Sie die Salden, die Sie bereits kennen, um Ihr Nettovermögen zu schätzen: Vermögenswerte minus Verbindlichkeiten. Vergleichen Sie Snapshots in einer Währung. Hierbei handelt es sich um einen Veranstalter, nicht um eine Bewertung oder finanzielle Empfehlung.

Vermögenswerte
Verbindlichkeiten

Finanzielle Details sind vertraulich. Es wird nichts hochgeladen. Das Speichern ist optional, lokal in diesem Browser und für jeden sichtbar, der Zugriff darauf hat.

Schätzung

Gespeicherte Schnappschüsse

    Wie berechne ich das Nettovermögen?

    Addieren Sie Ihre Vermögenssalden und Verbindlichkeiten in derselben Währung und subtrahieren Sie dann die Gesamtverbindlichkeiten vom Gesamtvermögen. Die Werte sind nur so genau wie die von Ihnen eingegebenen Beträge und Bewertungen.

    Häufig gestellte Fragen

    Wie berechne ich das Nettovermögen?

    Addieren Sie Ihre Vermögenssalden und Verbindlichkeiten in derselben Währung und subtrahieren Sie dann die Gesamtverbindlichkeiten vom Gesamtvermögen. Die Werte sind nur so genau wie die von Ihnen eingegebenen Beträge und Bewertungen.

    Werden meine Finanzguthaben gespeichert oder hochgeladen?

    Berechnungen finden auf dieser Seite statt. Die Browserspeicherung ist deaktiviert, es sei denn, Sie aktivieren das Zustimmungskästchen und speichern separat einen Snapshot. Gespeicherte Daten bleiben in diesem Browser und können hier oder in den Browsereinstellungen gelöscht werden.

    Was zählt als Nettovermögen?

    Das Nettovermögen ist der Gesamtwert, den Sie den Vermögenswerten zuordnen, abzüglich der von Ihnen eingegebenen Verbindlichkeiten. Bei dem Ergebnis handelt es sich weder um eine Bewertung noch um einen Bonitätsscore.

    Kann ich verschiedene Währungen vergleichen?

    Es werden keine automatischen Wechselkurse verwendet. Vergleichen Sie Snapshots nur, wenn sie denselben Währungscode verwenden.

    Wo werden gespeicherte Snapshots gespeichert?

    Nur im lokalen Speicher dieses Browsers, nachdem Sie sich angemeldet und auf Speichern geklickt haben. Durch das Löschen der Browserdaten werden sie entfernt. Laden Sie eine CSV-Datei herunter, wenn Sie eine separate Kopie benötigen.
