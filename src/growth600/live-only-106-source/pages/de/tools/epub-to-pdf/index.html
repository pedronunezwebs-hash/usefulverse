EPUB-zu-PDF-Konverter

Öffnen Sie ein DRM-freies EPUB auf diesem Gerät und verwenden Sie dann den Druckdialog Ihres Browsers, um ein PDF mit Text zuerst zu speichern. Die Reihenfolge der Kapitel richtet sich nach dem Buch. Originallayout, Bilder und eingebettete Schriftarten bleiben nicht erhalten.

Maximale Dateigröße: 25 MB. Der erweiterte Buchinhalt ist zum Schutz des Browserspeichers begrenzt.

Text-zuerst-Konvertierung: Kapitelreihenfolge und lesbarer Text bleiben erhalten. Das ursprüngliche Seitendesign, Bilder, Tabellen, Fußnoten, eingebettete Schriftarten und interaktive Inhalte bleiben möglicherweise nicht erhalten. DRM-geschützte oder fehlerhafte EPUB-Dateien werden nicht unterstützt. Große Bücher können viel Speicher beanspruchen; Ein Computer wird empfohlen.

Druckvorschau

Wie speichere ich ein EPUB als PDF?

Wählen Sie ein DRM-freies EPUB mit bis zu 25 MB. Nachdem das Buch lokal gelesen wurde, wählen Sie „PDF vorbereiten“. Wählen Sie im Druckdialog „Als PDF speichern“ und dann ein Ziel auf Ihrem Gerät aus.

Häufig gestellte Fragen

Wie speichere ich ein EPUB als PDF?

Wählen Sie ein DRM-freies EPUB mit bis zu 25 MB. Nachdem das Buch lokal gelesen wurde, wählen Sie „PDF vorbereiten“. Wählen Sie im Druckdialog „Als PDF speichern“ und dann ein Ziel auf Ihrem Gerät aus.

Ist mein EPUB hochgeladen?

Nein. Die Datei wird in diesem Browser gelesen und nicht an UsefulVerse gesendet. Ihr Browser öffnet ein lokales Druckdokument, das Sie als PDF speichern können.

Wird das PDF genauso aussehen wie das EPUB?

Nein. Dadurch wird eine saubere, druckbare Kopie mit dem Text zuerst in der Kapitelreihenfolge erstellt. Originalstil, Bilder, Tabellen, Fußnoten und eingebettete Schriftarten können weggelassen werden.

Kann es ein DRM-geschütztes Buch konvertieren?

Nein. DRM-Entfernung wird nicht unterstützt. Verwenden Sie nur Bücher, die Sie konvertieren dürfen. Der Druckdialog des Browsers wird geöffnet; Wählen Sie „Als PDF speichern“ und wählen Sie den Speicherort aus.
