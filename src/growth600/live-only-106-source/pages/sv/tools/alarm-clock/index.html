Vanliga frågor

Hur ställer jag in ett onlinelarm?

Välj ett framtida datum och tid i enhetens lokala tidszon och välj sedan Ställ in alarm. Ljud är valfritt. Du kan testa den först, snooze i fem minuter eller stoppa den när den ringer.

Skickar det här larmet data eller fungerar det efter att jag stänger sidan?

Ingen data skickas eller sparas. Larmet körs endast på denna sida och kan inte varna dig på ett tillförlitligt sätt om fliken stängs, webbläsaren pausar den eller enheten sover.

Ringer larmet om jag stänger fliken?

Nej. Detta är ett larm på sidan, inte ett larm eller meddelande från operativsystemet. Håll sidan öppen och enheten vaken; Använd enhetens larmapp för viktiga påminnelser.

Kan jag snooze alarmet?

Ja. När det ringer väljer du Snooze 5 minuter för att schemalägga det igen från den aktuella tiden.

Använder larmet min plats eller sparar jag tid?

Nej. Den använder den lokala tiden som är konfigurerad på din enhet. Larmet hålls endast på den öppna sidan och laddas inte upp eller sparas.
