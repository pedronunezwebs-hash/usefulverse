Σχεδιαστής συνάντησης

Συγκρίνετε ένα επαναλαμβανόμενο ημερήσιο παράθυρο διαθεσιμότητας σε έναν διοργανωτή και σε συμμετέχοντες σε διαφορετικές ζώνες ώρας. Ελέγξτε κάθε τοπική ημερομηνία και ώρα και, στη συνέχεια, πραγματοποιήστε λήψη μιας πρόσκλησης ICS για μια αντίστοιχη υποδοχή.

Εκτελείται τοπικά. Χωρίς σύνδεση ημερολογίου, αίτημα τοποθεσίας, μεταφόρτωση, λογαριασμό, API ή αυτόματη αποθήκευση.

Παραδείγματα: Αμερική/Νέα_Υόρκη, Ευρώπη/Λονδίνο, Ασία/Τόκιο. Ο διοργανωτής συμπεριλαμβάνεται αυτόματα. χρησιμοποιήστε έως και οκτώ διακριτές ζώνες συνολικά.

Daylight-saving προέρχονται από τη βάση δεδομένων ζώνης ώρας αυτού του προγράμματος περιήγησης και ενδέχεται να είναι παλιοί. Εάν επαναληφθεί ένας χρόνος επιστροφής, επιλέγεται η προηγούμενη εμφάνιση. παραλείπεται ένα όριο διαθεσιμότητας που δεν υπάρχει κατά τη διάρκεια ενός κενού ελατηρίου προς τα εμπρός.

Χρησιμοποιεί το ίδιο καθημερινό παράθυρο τοπικής ώρας σε κάθε ζώνη ώρας. Δεν γνωρίζει μεμονωμένα ημερολόγια, αργίες, εργάσιμες ή προτιμήσεις συμμετεχόντων. Επιλέξτε μια πραγματική υποδοχή με όλους πριν στείλετε την πρόσκληση.

Πιθανοί κοινόχρηστοι χρόνοι συναντήσεων

Δεν βρέθηκαν αντίστοιχες θέσεις για αυτές τις ζώνες και τις ώρες. Δοκιμάστε ένα ευρύτερο παράθυρο, ένα διαφορετικό εύρος ημερομηνιών ή μικρότερη συνάντηση.

Υπολογίζει τη θερινή ώρα;

It χρησιμοποιεί τη βάση δεδομένων ζώνης ώρας IANA του προγράμματος περιήγησης για τη μετατροπή κάθε υποψήφιας στιγμής. Μια βάση δεδομένων μπορεί να είναι ξεπερασμένη. επαληθεύστε σημαντικές ώρες συναντήσεων με τους συμμετέχοντες.

Μπορώ να προσθέσω την προτεινόμενη σύσκεψη σε ένα ημερολόγιο;

Κάντε λήψη ενός συμβάντος ICS για μια επιλεγμένη υποδοχή και εισαγάγετέ το μόνοι σας. Το εργαλείο δεν συνδέεται ούτε τροποποιεί κανένα ημερολόγιο.
