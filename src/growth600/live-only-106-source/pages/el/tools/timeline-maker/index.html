Timeline Maker

Μετατρέψτε ορόσημα ή ιστορικά γεγονότα σε ένα σαφές, χρονολογικό χρονοδιάγραμμα. Προσθέστε μια μεμονωμένη ημερομηνία ή μια ημερομηνία έναρξης και λήξης για κάθε συμβάν.

Αυτό είναι ένα χρονοδιάγραμμα συμβάντων, όχι ένα χρονοδιάγραμμα εργασιών/εξάρτησης ή πηγή ιστορικών γεγονότων. Εισαγάγετε ημερομηνίες που έχετε ελέγξει.

Τα ονόματα και οι ημερομηνίες των συμβάντων σας παραμένουν σε αυτήν την καρτέλα. Τίποτα δεν μεταφορτώνεται ή αποθηκεύεται αυτόματα. Οι εξαγωγές δημιουργούνται τοπικά.

Ένα χρονοδιάγραμμα απεικονίζει μόνο τις ημερομηνίες που εισάγετε. Δεν επαληθεύει την ακρίβεια του συμβάντος ούτε συνάγει ημερομηνίες που λείπουν.

Πώς μπορώ να δημιουργήσω ένα χρονοδιάγραμμα εκδήλωσης;

Προσθέστε τουλάχιστον δύο επώνυμα συμβάντα και επιλέξτε μια ημερομηνία έναρξης για το καθένα. Προσθέστε μια ημερομηνία λήξης για μια διάρκεια ή αφήστε την κενή για ένα μονοήμερο συμβάν. Συχνές ερωτήσεις

Πώς μπορώ να δημιουργήσω ένα χρονοδιάγραμμα εκδήλωσης;

Προσθέστε τουλάχιστον δύο επώνυμα συμβάντα και επιλέξτε μια ημερομηνία έναρξης για το καθένα. Προσθέστε μια ημερομηνία λήξης για μια διάρκεια ή αφήστε την κενή για ένα μονοήμερο συμβάν. Δημιουργήστε το χρονοδιάγραμμα για να ταξινομήσετε συμβάντα κατά ημερομηνία, να προσαρμόσετε το ζουμ και να κατεβάσετε αρχεία SVG ή CSV.

Έχουν μεταφορτωθεί τα συμβάντα του χρονολογίου μου;

Όχι. Τα ονόματα και οι ημερομηνίες επεξεργάζονται σε αυτήν την καρτέλα του προγράμματος περιήγησης. Τα SVG και CSV δημιουργούνται στη συσκευή σας. τίποτα δεν μεταφορτώνεται ή αποθηκεύεται αυτόματα.

Μπορεί μια εκδήλωση να διαρκέσει περισσότερο από μία ημέρα;

Ναι. Εισαγάγετε και ημερομηνία έναρξης και λήξης. Το γράφημα περιλαμβάνει και τις δύο ημερομηνίες λήξης. αφήστε το τέλος κενό για ένα μονοήμερο συμβάν.

Αυτό το χρονοδιάγραμμα δημιουργεί εξαρτήσεις εργασιών;

Όχι. Εμφανίζει χρονολογημένα συμβάντα και εύρη με χρονολογική σειρά. Χρησιμοποιήστε ένα εργαλείο χρονοδιαγράμματος έργου για εργασίες, διάρκειες και εξαρτήσεις.

Μπορώ να αποθηκεύσω ή να μοιραστώ τη γραμμή χρόνου;

Κατεβάστε ένα SVG για μια κλιμακούμενη εικόνα ή ένα CSV για τον πίνακα συμβάντων. Η σελίδα δεν ανεβάζει ούτε αποθηκεύει αυτόματα τα δεδομένα της εκδήλωσης σας.
