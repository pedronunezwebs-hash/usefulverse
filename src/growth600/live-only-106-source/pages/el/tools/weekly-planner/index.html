Εβδομαδιαίος προγραμματιστής

Δημιουργήστε ένα απλό εβδομαδιαίο χρονοδιάγραμμα για εργασία, προσωπικά σχέδια, μελέτη ή υγεία. Τα ολονύκτια μπλοκ και οι διενέξεις χρονοδιαγράμματος εμφανίζονται καθαρά.

Ένα επαναλαμβανόμενο εβδομαδιαίο πρόγραμμα χρησιμοποιεί τοπικούς χρόνους ρολογιού τοίχου. δεν λαμβάνει υπόψη τις ζώνες ώρας, τις αλλαγές κατά τη διάρκεια της ημέρας, τα συμβάντα ημερολογίου ή τις υπενθυμίσεις.

Το σχέδιο παραμένει στη μνήμη σε αυτήν την καρτέλα. Κάντε λήψη ενός αντιγράφου ασφαλείας JSON για να το διατηρήσετε. χωρίς αυτόματη αποθήκευση ή μεταφόρτωση.

Εβδομαδιαίο πρόγραμμα

Πώς μπορώ να κάνω ένα εβδομαδιαίο πρόγραμμα;

Προσθέστε έναν τίτλο, ημέρα, ώρα έναρξης, ώρα λήξης και κατηγορία για κάθε μπλοκ. Τα μπλοκ μπορεί να περάσουν τα μεσάνυχτα. Ο χρόνος επικάλυψης επισημαίνεται, συμπεριλαμβανομένης της Κυριακής και της Δευτέρας.

Ναι. Επιλέξτε μια ώρα λήξης νωρίτερα από την ώρα έναρξης για να δημιουργήσετε ένα μπλοκ που τελειώνει την επόμενη μέρα. Υποστηρίζονται μπλοκ έως 18 ώρες.

Ναι. Ελέγχει τα χρονικά τετράγωνα την ίδια μέρα και τα μεσάνυχτα, συμπεριλαμβανομένου ενός αποκλεισμού της Κυριακής που επικαλύπτει τη Δευτέρα.
