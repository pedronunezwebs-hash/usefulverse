Memory Test

Εξασκηθείτε στη μνήμη μιας αυξανόμενης ακολουθίας ψηφίων ή θέσεων σε ένα πλέγμα 3×3. Κάθε σωστός γύρος προσθέτει ένα στοιχείο.

Εξάσκηση μόνο. Αυτό δεν είναι τεστ IQ, διάγνωση ή επικυρωμένη γνωστική αξιολόγηση. Τα αποτελέσματα δεν έχουν καμία κλινική ή πληθυσμιακή σημασία.

Για προγράμματα ανάγνωσης οθόνης, επιλέξτε Διάστημα ψηφίων: κάθε ψηφίο ανακοινώνεται μία φορά κατά την αναπαραγωγή. Η λειτουργία οπτικού μοτίβου εξαρτάται από την όραση.

Μήκος επόμενης ακολουθίας: 3

Στοιχείο ακολουθίας: —

Η απάντησή σας

Δεν έχουν καταχωρηθεί ακόμη στοιχεία.

Σωστοί γύροι: 0

Επιλέξτε λειτουργία και ταχύτητα και μετά ξεκινήστε.

Αποτέλεσμα δοκιμής

Πώς λειτουργεί αυτό το τεστ μνήμης;

Επιλέξτε ψηφία ή ένα οπτικό πλέγμα και μια ταχύτητα εμφάνισης. Παρακολουθήστε ή ακούστε τη σειρά μία φορά και μετά εισάγετέ την με την ίδια σειρά. Οι σωστοί γύροι μεγαλώνουν, έως και 12 αντικείμενα. Αυτό είναι ένα περιστασιακό παιχνίδι πρακτικής, όχι μια τυποποιημένη αξιολόγηση μνήμης.

Συχνές ερωτήσεις

Πώς λειτουργεί αυτό το τεστ μνήμης;

Επιλέξτε ψηφία ή ένα οπτικό πλέγμα και μια ταχύτητα εμφάνισης. Παρακολουθήστε ή ακούστε τη σειρά μία φορά και μετά εισάγετέ την με την ίδια σειρά. Οι σωστοί γύροι μεγαλώνουν, έως και 12 αντικείμενα. Αυτό είναι ένα περιστασιακό παιχνίδι πρακτικής, όχι μια τυποποιημένη αξιολόγηση μνήμης.

Αυτό το τεστ μνήμης αποθηκεύει τη βαθμολογία μου;

Όχι. Η σειρά και η βαθμολογία παραμένουν σε αυτήν τη σελίδα όσο είναι ανοιχτή. Δεν μεταφορτώνεται τίποτα και δεν υπάρχει λογαριασμός ή κατάταξη στο διαδίκτυο.

Τι μετράει αυτό το τεστ μνήμης;

Είναι ένα περιστασιακό παιχνίδι πρακτικής ανάκλησης ακολουθίας. Δεν είναι τυποποιημένο και δεν μπορεί να διαγνώσει μια πάθηση ή να μετρήσει το IQ.

Πώς διαφέρουν το εύρος ψηφίων και η λειτουργία μοτίβου;

Το εύρος ψηφίων εμφανίζει ψηφία ένα κάθε φορά και τα ανακοινώνει για πρόσβαση σε πρόγραμμα ανάγνωσης οθόνης. Η λειτουργία μοτίβου αναβοσβήνει θέσεις σε πλέγμα 3×3 και απαιτεί όραση.

Οι βαθμολογίες αποθηκεύονται ή συγκρίνονται με άλλα άτομα;

Όχι. Οι βαθμολογίες υπάρχουν μόνο όσο αυτή η σελίδα παραμένει ανοιχτή. Δεν υπάρχει leaderboard, λογαριασμός ή μεταφόρτωση διακομιστή.
