Αριθμομηχανή Γραμμικού Προγραμματισμού

Εισαγάγετε έναν γραμμικό στόχο και έως και οκτώ περιορισμούς για να λύσετε ένα γραμμικό πρόγραμμα δύο μεταβλητών με x και y μη αρνητικά. Η μέθοδος απλού δύο φάσεων αναφέρει ένα βέλτιστο, μη εφικτό ή απεριόριστο και δείχνει κάθε άξονα.

Αντικειμενικοί συντελεστές (x, y)

Ένα ανά γραμμή: a,b <= rhs, a,b >= rhs ή a,b = rhs

Χρησιμοποιεί το πολύ οκτώ περιορισμούς και συντελεστές/δεξιές πλευρές εντός ±1.000.000. Και οι δύο μεταβλητές απόφασης έχουν x ≥ 0 και y ≥ 0. Χρησιμοποιήστε κόμμα μεταξύ των συντελεστών x και y. εισάγετε μία ανισότητα ή ισότητα ανά γραμμή.

Ένας διφασικός αρχικός επιλύτης απλού για δύο μεταβλητές. Η αριθμητική ανοχή χρησιμοποιείται για περιστροφές κινητής υποδιαστολής. σχεδόν εκφυλισμένα προβλήματα μπορεί να είναι ευαίσθητα στη στρογγυλοποίηση. Αναφέρονται περιπτώσεις ανέφικτων, απεριόριστων και ορίων επανάληψης αντί για επινοηθείσα βέλτιστη.

Αποτελέσματα γραμμικού προγράμματος

Το αποτέλεσμα είναι μόνο για το μαθηματικό μοντέλο που καταχωρίσατε. Δεν επικυρώνει εάν ο στόχος, οι περιορισμοί, οι μονάδες ή οι παραδοχές είναι κατάλληλες για μια πραγματική απόφαση.

    Πώς λειτουργεί η αριθμομηχανή simplex δύο μεταβλητών;
