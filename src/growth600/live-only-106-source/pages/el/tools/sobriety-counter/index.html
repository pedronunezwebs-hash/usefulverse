Μετρητής ημερών νηφαλιότητας

Επιλέξτε μια ημερομηνία έναρξης για να μετρήσετε τις ημερολογιακές ημέρες που έχουν περάσει και να δείτε τα επερχόμενα ορόσημα. Αυτός ο ιδιωτικός πάγκος δεν αποτελεί θεραπεία, συμβουλές ανάκτησης ή μέτρο υγείας.

Εισαγάγετε την ημερομηνία από την οποία θέλετε να μετρήσετε. Μια ημερομηνία σήμερα είναι η ημέρα μηδέν. μελλοντικές ημερομηνίες δεν επιτρέπονται. Η προεπιλογή είναι σήμερα και μπορεί να αλλάξει για να ελέγξει μια παλαιότερη ημερομηνία, αλλά όχι μια ημερομηνία πριν από την έναρξη.

Ο αριθμός των ημερών σας

Πώς λειτουργεί ο μετρητής ημέρας νηφαλιότητας;

Μετρά ολόκληρες ημερολογιακές ημέρες από την ημερομηνία που εισάγετε μέχρι σήμερα. Η ίδια η επιλεγμένη ημερομηνία έναρξης είναι η ημέρα μηδέν. Οι μεταγενέστερες ημερομηνίες χρησιμοποιούν αριθμητική μόνο ημερομηνία, επομένως η θερινή ώρα δεν προσθέτει ή αφαιρεί μια ημέρα.

Μεταφορτώθηκε ή αποθηκεύτηκε η ημερομηνία νηφαλιότητας μου;

Δεν έχουν μεταφορτωθεί δεδομένα. Οι ημερομηνίες σας χρησιμοποιούνται μόνο σε αυτό το πρόγραμμα περιήγησης. Μια σημείωση ή μια ημερομηνία μπορεί να αποθηκευτεί σε αυτήν τη συσκευή μόνο εάν επιλέξετε ρητά και μπορείτε να διαγράψετε την τοπική εγγραφή ανά πάσα στιγμή.

Η ημερομηνία έναρξης υπολογίζεται ως πρώτη ημέρα;

Όχι. Η επιλεγμένη ημερομηνία έναρξης είναι η ημέρα μηδέν. Η επόμενη ημερολογιακή ημερομηνία είναι μία ημέρα μετά.

Μπορεί αυτός ο μετρητής να προσφέρει ανάρρωση ή ιατρική συμβουλή;

Όχι. Μετρά ημερολογιακές ημέρες και εμφανίζει μόνο ορόσημα. Δεν αξιολογεί την υγεία, τη χρήση ουσιών, τη θεραπεία ή την προσωπική πρόοδο.

Οι ημερομηνίες και οι σημειώσεις αποστέλλονται σε διακομιστή;

Όχι. Οι υπολογισμοί εκτελούνται στο πρόγραμμα περιήγησής σας. Η αποθήκευση είναι προαιρετική και αποθηκεύει μια μικρή εγγραφή σε αυτό το πρόγραμμα περιήγησης σε αυτήν τη συσκευή. μπορείτε να το καθαρίσετε εδώ.
