Μετατροπέας XML σε CSV

Μετατρέψτε μια απλή λίστα εγγραφών XML σε πίνακα CSV ή δημιουργήστε εγγραφές XML από το κείμενο ενός αρχείου CSV. Επιλέξτε την κατεύθυνση, επικολλήστε τα δεδομένα σας και, στη συνέχεια, αντιγράψτε ή κατεβάστε το αποτέλεσμα. Δεν έχει ανέβει τίποτα.

Υποστηρίζει μια απλή λίστα με ομώνυμα στοιχεία εγγραφής ή μια επίπεδη εγγραφή. Τα παιδιά στοιχείων πρέπει να είναι βαθμωτές τιμές. τα ένθετα και τα επαναλαμβανόμενα πεδία δεν ισοπεδώνονται.

Χρησιμοποιήστε την πρώτη σειρά για ονόματα στηλών. Μια κεφαλίδα όπως το @id γίνεται χαρακτηριστικό XML. Χρησιμοποιήστε το #text για εγγραφή κειμένου.

Αυτή είναι μια απλή μετατροπή πίνακα, όχι μια μετατροπή μορφής XML χωρίς απώλειες. Οι χώροι ονομάτων, οι ένθετες δομές, το μικτό περιεχόμενο, τα σχόλια και η μορφοποίηση XML δεν διατηρούνται. Το κείμενο δεν είναι ενήμερο για τον τύπο. Οι τιμές CSV που μοιάζουν με τύπο υπολογιστικού φύλλου έχουν ένα πρόθεμα απόστροφου για ασφάλεια.

Αποτέλεσμα

Επιλέξτε XML σε CSV και επικολλήστε XML με μια απλή λίστα εγγραφών. Τα επαναλαμβανόμενα στοιχεία άμεσης εγγραφής γίνονται σειρές. Τα ονόματα των στοιχείων γίνονται στήλες. τα χαρακτηριστικά χρησιμοποιούν @name. Επιλέξτε CSV σε XML για να δημιουργήσετε απλές εγγραφές XML από κεφαλίδες και σειρές.

Συχνές ερωτήσεις

Επιλέξτε XML σε CSV και επικολλήστε XML με μια απλή λίστα εγγραφών. Τα επαναλαμβανόμενα στοιχεία άμεσης εγγραφής γίνονται σειρές. Τα ονόματα των στοιχείων γίνονται στήλες. τα χαρακτηριστικά χρησιμοποιούν @name. Επιλέξτε CSV σε XML για να δημιουργήσετε απλές εγγραφές XML από κεφαλίδες και σειρές.

Έχει μεταφορτωθεί το XML ή το CSV μου;

Όχι. Η ανάλυση και η μετατροπή εκτελούνται σε αυτό το πρόγραμμα περιήγησης. Η εισαγωγή περιορίζεται σε 200.000 χαρακτήρες, 5.000 σειρές, 64 στήλες και 20.000 κελιά. Οι δηλώσεις DTD και οντοτήτων έχουν αποκλειστεί και δεν γίνεται ανάκτηση εξωτερικών πόρων.

Πώς εμφανίζονται τα χαρακτηριστικά XML στο CSV;

Ένα χαρακτηριστικό όπως id="101" γίνεται στήλη με το όνομα @id. Κατά την εκ νέου μετατροπή, μια κεφαλίδα CSV που ξεκινά με @ γίνεται χαρακτηριστικό XML.

Μπορεί να μετατρέψει την ένθετη XML σε επίπεδο τραπέζι;

Όχι. Οι ένθετες θυγατρικές δομές, τα επαναλαμβανόμενα πεδία μέσα σε μια εγγραφή και το μικτό κείμενο απορρίπτονται αντί να ισοπεδωθούν ή να χαθούν σιωπηλά. Χρησιμοποιήστε μια αποκλειστική ροή εργασίας XML-to-JSON για ένθετα δεδομένα.

Θα διατηρήσει το CSV τύπους και μορφοποίηση XML;

Όχι. Το CSV αποθηκεύει κείμενο κελιών, όχι τύπους XML, χώρους ονομάτων ή μορφοποίηση. Οι τιμές κελιών τύπου τύπου λαμβάνουν ένα πρόθεμα απόστροφου όταν εξάγονται για να μειωθεί ο κίνδυνος εκτέλεσης τύπου υπολογιστικού φύλλου.
