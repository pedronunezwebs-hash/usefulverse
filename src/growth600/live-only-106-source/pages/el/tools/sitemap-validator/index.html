Επικύρωση χάρτη ιστότοπου

Επικολλήστε ένα έγγραφο XML χάρτη ιστότοπου για να ελέγξετε τη δομή του, τις καταχωρίσεις URL, τις ημερομηνίες και τα κοινά πεδία. Το XML αναλύεται μόνο σε αυτό το πρόγραμμα περιήγησης. Οι σελίδες που αναφέρονται στη λίστα δεν λαμβάνονται ποτέ.

Υποστηρίζει ένα τυπικό urlset ή sitemapindex. Μέγιστο 1.000.000 χαρακτήρες και 5.000 άμεσες καταχωρήσεις.

Τοπικοί έλεγχοι XML μόνο: αυτό δεν ζητά καταχωρημένες διευθύνσεις URL, δεν ανιχνεύει τον ιστότοπο, υποβάλλει τον χάρτη ιστότοπου ή δεν εγγυάται ευρετηρίαση.

Σύνοψη επικύρωσης

Ευρήματα

    Τι ελέγχει αυτό το εργαλείο επικύρωσης χάρτη ιστότοπου;

    Ελέγχει καταχωρήσεις urlset ή sitemapindex, απόλυτες τοποθεσίες HTTP ή HTTPS, διπλότυπες κανονικοποιημένες διευθύνσεις URL, ημερομηνίες τελευταίας τροποποίησης, προαιρετικές τιμές συχνότητας αλλαγής και προτεραιότητας και τον χώρο ονομάτων του χάρτη ιστότοπου. Οι προειδοποιήσεις και τα σφάλματα παρατίθενται με αριθμό καταχώρισης.

    Συχνές ερωτήσεις

    Τι ελέγχει αυτό το εργαλείο επικύρωσης χάρτη ιστότοπου;

    Ελέγχει καταχωρήσεις urlset ή sitemapindex, απόλυτες τοποθεσίες HTTP ή HTTPS, διπλότυπες κανονικοποιημένες διευθύνσεις URL, ημερομηνίες τελευταίας τροποποίησης, προαιρετικές τιμές συχνότητας αλλαγής και προτεραιότητας και τον χώρο ονομάτων του χάρτη ιστότοπου. Οι προειδοποιήσεις και τα σφάλματα παρατίθενται με αριθμό καταχώρισης.

    Ανεβάζει ή υποβάλλει τον χάρτη ιστοτόπου μου;

    Όχι. Η επεξεργασία της XML γίνεται τοπικά στο πρόγραμμα περιήγησής σας. Το εργαλείο δεν ανιχνεύει διευθύνσεις URL, δεν ανακτά αρχεία απομακρυσμένων χαρτών ιστότοπου, δεν υποβάλλει οτιδήποτε σε μια μηχανή αναζήτησης ή δεν επιβεβαιώνει τη δημιουργία ευρετηρίου.

    Ελέγχει αν μια διεύθυνση URL χάρτη ιστότοπου είναι ζωντανή;

    Όχι. Ελέγχει τη σύνταξη διευθύνσεων URL και τα διπλότυπα εντός του επικολλημένου XML, αλλά σκόπιμα δεν ζητά διευθύνσεις URL ούτε ανιχνεύει τον ιστότοπο.

    Ένας έγκυρος χάρτης ιστότοπου σημαίνει ότι η Google έχει ευρετηριάσει τις σελίδες της;

    Όχι. Η επικύρωση XML δεν είναι αναφορά υποβολής ή δημιουργίας ευρετηρίου από μηχανή αναζήτησης. Υποβάλετε έναν χάρτη ιστότοπου μέσω του σχετικού εργαλείου webmaster της μηχανής αναζήτησης και ελέγξτε τη δική του κατάσταση.

    Μπορώ να επικυρώσω ένα ευρετήριο χάρτη ιστότοπου;

    Ναι. Το εργαλείο ελέγχει τις άμεσες εγγραφές sitemapindex και τα πεδία loc και lastmod τους, αλλά δεν πραγματοποιεί λήψη ούτε επιθεωρεί αναδρομικά αρχεία χάρτη ιστότοπου που αναφέρονται.

    Αρχική

    Δωρεάν εργαλεία προγράμματος περιήγησης. Τα δεδομένα σας παραμένουν στη συσκευή σας, όπου το επιτρέπει το εργαλείο.
