Markdown Table Generator

Δημιουργήστε έναν πίνακα Markdown σε ένα μικρό επεξεργάσιμο πλέγμα. Εισαγάγετε κείμενο διαχωρισμένο με κόμματα, ερωτηματικό ή διαχωρισμένο με στηλοθέτες, επιλέξτε τη στοίχιση στηλών και αντιγράψτε το απλό Markdown με τους σωλήνες να έχουν διαφύγει με ασφάλεια.

Τα πεδία CSV σε εισαγωγικά υποστηρίζονται. Η εισαγωγή αντικαθιστά το τρέχον πλέγμα. έως 100 σειρές, 20 στήλες και 250.000 χαρακτήρες.

Η πρώτη σειρά γίνεται η κεφαλίδα Markdown. Προσθέστε τουλάχιστον μία γραμμή και μία στήλη.

Επεξεργάσιμα κελιά πίνακα

Δημιουργεί έναν τυπικό πίνακα σωλήνων με μια κεφαλίδα και μια διαχωριστική σειρά. Οι διακοπές κυτταρικής γραμμής γίνονται <br>. Οι σωλήνες Markdown και οι ανάστροφες κάθετες διαφεύγουν.

Όλη η επεξεργασία παραμένει σε αυτήν την καρτέλα. Χωρίς μεταφόρτωση, λογαριασμό, API, αυτόματη αποθήκευση ή επεξεργασία διακομιστή.

Έχει μεταφορτωθεί ο πίνακας μου;

Όχι. Ο πίνακας σας υποβάλλεται σε επεξεργασία σε αυτήν την καρτέλα του προγράμματος περιήγησης. Η εισαγωγή, οι επεξεργασίες και η δημιουργία Markdown δεν αποστέλλονται σε διακομιστή ούτε αποθηκεύονται αυτόματα.

Μπορώ να εισάγω CSV ή TSV;

Ναι. Επικολλήστε τιμές διαχωρισμένες με κόμμα, ερωτηματικά ή διαχωρισμένες με στηλοθέτες και, στη συνέχεια, εισαγάγετέ τις στο επεξεργάσιμο πλέγμα. Υποστηρίζονται πεδία CSV με εισαγωγικά και διαχωριστικά με εισαγωγικά.

Πώς αντιμετωπίζονται οι διακοπές σωλήνων και αγωγών;

Ένας σωλήνας μέσα σε ένα κελί έχει διαφύγει, οπότε δεν χωρίζει τον πίνακα Markdown. Οι ανάστροφες κάθετες έχουν επίσης διαφυγή και οι αλλαγές γραμμής κυψέλης αντιπροσωπεύονται με <br>.
