Άσκηση αναπνοής

Επιλέξτε έναν ήπιο ρυθμό αναπνοής και ακολουθήστε τον οπτικό οδηγό. Διατηρήστε τη διαδικασία άνετη και σταματήστε όποτε θέλετε.

Ο οδηγός αποφεύγει τις απότομες κινήσεις όταν είναι ενεργοποιημένη η λειτουργία μειωμένης κίνησης.

Πρόκειται για χρονόμετρο γενικής ευεξίας, όχι για ιατρική φροντίδα. Αναπνεύστε άνετα και σταματήστε εάν νιώσετε αδιαθεσία.

Εισπνοή

Κύκλος: 1

Χρόνος που απομένει: 01:00

Πώς χρησιμοποιώ αυτή την άσκηση αναπνοής;

Επιλέξτε μια προκαθορισμένη ρύθμιση ή ορίστε κάθε φάση, επιλέξτε τη διάρκεια της συνεδρίας και πατήστε «Έναρξη». Μπορείτε να κάνετε παύση ή επαναφορά ανά πάσα στιγμή. Ο ήχος είναι προαιρετικός και ενεργοποιείται μόνο αφού ξεκινήσετε.

Μεταφορτώνονται τα δεδομένα της συνεδρίας αναπνοής μου;

Όχι. Η χρονομέτρηση γίνεται σε αυτή τη σελίδα. Δεν χρησιμοποιούνται λογαριασμός, μεταφόρτωση δεδομένων, API ή αποθήκευση συνεδρίας.

Μπορώ να χρησιμοποιήσω την τεχνική «αναπνοή του κουτιού» ή τη μέθοδο 4-7-8;

Ναι. Επιλέξτε μια προκαθορισμένη ρύθμιση ή προσαρμόστε τη διάρκεια των φάσεων. Πρόκειται για πρότυπα ρυθμού αναπνοής, όχι για ιατρική θεραπεία.

Θα συνεχίσει να λειτουργεί αν κλείσω την καρτέλα;

Δεν υπάρχει εγγύηση. Τα προγράμματα περιήγησης ενδέχεται να θέτουν σε παύση τις καρτέλες στο παρασκήνιο και οι συσκευές να μεταβούν σε αναστολή λειτουργίας. Διατηρήστε τη σελίδα ανοιχτή και τη συσκευή ενεργή για αξιόπιστη χρονομέτρηση.

Μπορώ να απενεργοποιήσω τον ήχο ή να σταματήσω νωρίτερα;

Ναι. Ο ήχος είναι προαιρετικός και μπορεί να απενεργοποιηθεί. Η παύση ή η επαναφορά τερματίζει άμεσα τη χρονομέτρηση.
