Υπολογιστής Φάσης Σελήνης

Επιλέξτε μια ημερομηνία για να υπολογίσετε τη φάση και τον φωτισμό της Σελήνης και, στη συνέχεια, δείτε τις κατά προσέγγιση στιγμές της νέας σελήνης, του τετάρτου και της πανσελήνου για αυτόν τον μήνα UTC.

Χωρίς άδεια τοποθεσίας, μεταφόρτωση, λογαριασμό, API ή αυτόματη αποθήκευση.

Χρησιμοποιεί έναν μέσο συνοδικό κύκλο αγκυροβολημένο σε μια νέα σελήνη αναφοράς, όχι σε μια πλήρη αστρονομική εφημερία. Οι μεμονωμένοι χρόνοι φάσης μπορεί να διαφέρουν ανά ώρες και η εμφανιζόμενη ημερομηνία UTC μπορεί να διαφέρει από μια τοπική ημερολογιακή ημερομηνία. Αυτή η συνολική εκτίμηση φάσης δεν υπολογίζει τοπικές ημερομηνίες ανατολής, δύσης, ορατότητας ή θρησκευτικού ημερολογίου.

Είναι η ημερομηνία αποστολής μου;

Αρ. Ο υπολογισμός εκτελείται σε αυτό το πρόγραμμα περιήγησης. Δεν χρησιμοποιεί την τοποθεσία σας, δεν καλεί μια υπηρεσία αστρονομίας ή δεν αποθηκεύει την ημερομηνία σας.

Είναι ακριβείς οι χρόνοι φάσης;

Αρ. Αυτό το ελαφρύ εργαλείο χρησιμοποιεί έναν μέσο σεληνιακό κύκλο. Οι πραγματικοί χρόνοι αρχικής φάσης μπορεί να διαφέρουν κατά αρκετές ώρες, επομένως μην το χρησιμοποιείτε ως εφήμερο ή για κρίσιμη χρονική παρατήρηση.

Η φάση της Σελήνης εξαρτάται από την τοποθεσία μου;

Η γεωκεντρική φάση είναι γενικά η ίδια παγκοσμίως σε μια δεδομένη στιγμή. Η τοπική ανατολή, η δύση του φεγγαριού, η ορατότητα και η τοπική ημερολογιακή ημερομηνία εξαρτώνται από την τοποθεσία και δεν υπολογίζονται εδώ.

Δείχνει θρησκευτικές σεληνιακές ημερομηνίες;

Αρ. Δεν προβλέπει ορατότητα ημισελήνου ούτε καθορίζει την αρχή ενός θρησκευτικού μήνα. Ακολουθήστε τη σχετική τοπική αρχή ή το ημερολόγιο.
