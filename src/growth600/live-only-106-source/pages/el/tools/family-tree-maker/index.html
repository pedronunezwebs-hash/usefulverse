Family Tree Maker

Δημιουργήστε ένα οικογενειακό γράφημα από πληροφορίες που ήδη γνωρίζετε. Προσθέστε άτομα, συνδέστε γονικούς συνδέσμους και, στη συνέχεια, εξάγετε ένα διάγραμμα ή ένα αρχείο GEDCOM. Η σελίδα δεν αναζητά αρχεία ούτε αποθηκεύει τα οικογενειακά δεδομένα σας.

Τα οικογενειακά στοιχεία μπορεί να είναι ευαίσθητα. Τα δεδομένα παραμένουν στη μνήμη μέχρι να κλείσετε ή να επαναφέρετε αυτήν τη σελίδα. οι εξαγωγές ενδέχεται να περιέχουν ιδιωτικές πληροφορίες.

Οικογενειακό δέντρο

    Πώς μπορώ να φτιάξω ένα γενεαλογικό δέντρο;

    Προσθέστε κάθε άτομο μία φορά και μετά συνδέστε έναν γονέα με ένα παιδί. Το γράφημα αποκλείει διπλούς συνδέσμους, περισσότερους από δύο καταχωρισμένους γονείς και κύκλους καταγωγής. Εξάγετε ένα διάγραμμα SVG ή ένα αρχείο κειμένου GEDCOM όταν είστε έτοιμοι.

    Συχνές ερωτήσεις

    Πώς μπορώ να φτιάξω ένα γενεαλογικό δέντρο;

    Προσθέστε κάθε άτομο μία φορά και μετά συνδέστε έναν γονέα με ένα παιδί. Το γράφημα αποκλείει διπλούς συνδέσμους, περισσότερους από δύο καταχωρισμένους γονείς και κύκλους καταγωγής. Εξάγετε ένα διάγραμμα SVG ή ένα αρχείο κειμένου GEDCOM όταν είστε έτοιμοι.

    Τα στοιχεία της οικογένειάς μου έχουν μεταφορτωθεί ή αποθηκευτεί;

    Όχι. Το γράφημα παραμένει σε αυτήν την περίοδο λειτουργίας σελίδας. Δεν μεταφορτώνεται ούτε αποθηκεύεται στον χώρο αποθήκευσης του προγράμματος περιήγησης. Ένα εξαγόμενο αρχείο είναι δικό σας για αποθήκευση και κοινή χρήση, επομένως ελέγξτε το πρώτα για προσωπικές λεπτομέρειες.

    Μπορεί αυτό το εργαλείο να βρει συγγενείς ή δημόσια αρχεία;

    Όχι. Οργανώνει μόνο τις λεπτομέρειες που εισάγετε. Δεν αναζητά αρχεία, δεν επαληθεύει ταυτότητες ή δεν δημιουργεί νομικές σχέσεις.

    Τι είναι ένα αρχείο GEDCOM;

    Το GEDCOM είναι μια μορφή κειμένου που χρησιμοποιείται για τη μετακίνηση εγγραφών οικογενειακού ιστορικού μεταξύ συμβατών γενεαλογικών προγραμμάτων. Ελέγξτε ένα εξαγόμενο αρχείο πριν το μοιραστείτε.

    Το γράφημα υποστηρίζει περισσότερους από δύο γονείς;

    Αυτή η έκδοση επιτρέπει έως και δύο αναγραφόμενους γονείς ανά άτομο. Μια οικογενειακή σχέση μπορεί να είναι πιο περίπλοκη από ό,τι μπορεί να αντιπροσωπεύει αυτό το διάγραμμα.
