Υπολογιστής Modulo

Υπολογίστε το Ευκλείδειο πηλίκο και το υπόλοιπο για ακέραιους αριθμούς. Οι αρνητικές εισροές αντιμετωπίζονται με συνέπεια και η ταυτότητα της διαίρεσης δείχνει πώς σχηματίζεται η απάντηση.

Ο αριθμός που πρέπει να διαιρεθεί. μπορεί να είναι αρνητικό.

Χρησιμοποιήστε οποιονδήποτε μη μηδενικό ακέραιο αριθμό. Η απόλυτη τιμή του ορίζει το μέτρο.

Ελέγξτε εάν αυτή η τιμή είναι σύμφωνη με το modulo dividend του διαιρέτη.

Δέχεται υπογεγραμμένους ακέραιους αριθμούς έως 50 ψηφία. Χωρίς κλάσματα ή δεκαδικά ψηφία. Το αποτέλεσμα χρησιμοποιεί Ευκλείδειο modulo. Ορισμένες γλώσσες προγραμματισμού χρησιμοποιούν διαφορετικό κανόνα υπολειπόμενου για τα αρνητικά.

Αποτέλεσμα

Πώς υπολογίζετε ένα modulo με αρνητικό αριθμό;

Αυτή η αριθμομηχανή χρησιμοποιεί ένα μη αρνητικό υπόλοιπο μικρότερο από τον απόλυτο διαιρέτη. Για παράδειγμα, το −7 mod 3 είναι 2 επειδή −7 = (−3 × 3) + 2.

Συχνές ερωτήσεις

Πώς υπολογίζετε ένα modulo με αρνητικό αριθμό;

Αυτή η αριθμομηχανή χρησιμοποιεί ένα μη αρνητικό υπόλοιπο μικρότερο από τον απόλυτο διαιρέτη. Για παράδειγμα, το −7 mod 3 είναι 2 επειδή −7 = (−3 × 3) + 2.

Έχουν μεταφορτωθεί οι αριθμοί μου;

Όχι. Ο ακριβής υπολογισμός εκτελείται σε αυτό το πρόγραμμα περιήγησης. Οι αριθμοί δεν μεταφορτώνονται ούτε αποθηκεύονται.

Τι είναι το −7 mod 3;

Χρησιμοποιώντας την ευκλείδεια σύμβαση, το −7 mod 3 είναι 2: −7 = (−3 × 3) + 2, και 0 ≤ 2 < 3.

Τι σημαίνει το congruent modulo m;

Δύο ακέραιοι αριθμοί είναι ίσοι modulo m όταν η διαφορά τους διαιρείται με |m|. Η προαιρετική σύγκριση το ελέγχει ακριβώς αυτό.

Γιατί αυτό μπορεί να διαφέρει από τον τελεστή % μιας γλώσσας προγραμματισμού;

Ορισμένες γλώσσες διατηρούν το πρόσημο του αρνητικού μερίσματος στο υπόλοιπο. Αυτή η αριθμομηχανή επιστρέφει ένα υπόλοιπο από το 0 έως, αλλά χωρίς να περιλαμβάνει, τον απόλυτο διαιρέτη.
