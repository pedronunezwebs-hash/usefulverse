Calcolatore del test esatto Fisher

Inserisci i quattro conteggi in una tabella 2×2 per calcolare il test esatto di Fisher con margini fissi.

Tabella dei conteggi 2×2 osservati

Scegliere una direzione unilaterale solo quando specificato prima di esaminare i dati. L'odds ratio è il rapporto tra prodotti incrociati non corretto; zero celle possono renderlo indefinito o infinito. Questa non è una conclusione causale.

I conteggi devono essere numeri interi. Massimo 10.000 per cella e 20.000 in totale. Il test bilaterale somma le tabelle non più probabili della tabella osservata con margini fissi.

Risultato esatto del test Fisher

Il valore p è condizionato dai totali di riga e colonna osservati. Non si adatta a test multipli, covariate o a un disegno di campionamento complesso.

Quando dovrei utilizzare il test esatto di Fisher?

È un test esatto di associazione per una tabella 2×2, spesso utilizzato quando i conteggi attesi sono piccoli. Il risultato dipende dal disegno dello studio e non dimostra la causalità.

Domande frequenti

Quando dovrei utilizzare il test esatto di Fisher?

È un test esatto di associazione per una tabella 2×2, spesso utilizzato quando i conteggi attesi sono piccoli. Il risultato dipende dal disegno dello studio e non dimostra la causalità.

I miei conteggi sono caricati?

No. Il calcolo viene eseguito in questo browser. I conteggi non vengono caricati o archiviati da questo strumento.

Qual è l'ipotesi nulla?

Il test valuta se le classificazioni di righe e colonne sono indipendenti, condizionate ai margini osservati. Non spiega perché possa esistere un'associazione.

Come viene calcolato il valore p bilaterale?

Questa calcolatrice somma le probabilità di tutte le possibili tabelle con gli stessi margini la cui probabilità condizionale non è maggiore di quella della tabella osservata. Altre convenzioni software possono differire.

Un valore p basso dimostra un effetto?

No. Un valore p non è una dimensione dell'effetto o una prova di causalità. Rivedere l'odds ratio, il disegno dello studio, la qualità dei dati, l'incertezza e qualsiasi piano di test multipli.
