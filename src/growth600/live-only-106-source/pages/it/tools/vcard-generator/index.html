Generatore di VCard

Crea un singolo contatto digitale come file .vcf nel tuo browser. Scegli vCard 3.0 o 4.0, aggiungi i dettagli del contatto e, facoltativamente, incorpora una piccola foto JPEG o PNG.

JPEG o PNG opzionali, fino a 128 KiB. La foto è incorporata nel file VCF; non è caricato.

Un contatto, fino a 5 telefoni e 5 e-mail, 500 caratteri per campo di testo e un limite di file generati di 1 MiB. Sono offerte solo vCard 3.0 e 4.0.

Viene eseguito localmente dopo aver scelto Genera. Nessun account, accesso alla rubrica, caricamento, API, elaborazione del server o salvataggio automatico.

Anteprima VCF


  

    
Il contatto verrà aggiunto al mio telefono?
No. Crea un file VCF da visualizzare in anteprima, copiare o scaricare. Non legge né modifica mai la tua rubrica; decidi tu se e dove importare il file.


    
Domande frequenti
Il contatto verrà aggiunto al mio telefono?
No. Crea un file VCF da visualizzare in anteprima, copiare o scaricare. Non legge né modifica mai la tua rubrica; decidi tu se e dove importare il file.
Le mie informazioni di contatto sono state caricate?
No. I dettagli e una foto opzionale vengono elaborati su questo dispositivo. Non sono previsti caricamento, account, elaborazione del server o salvataggio automatico.
Qual è la differenza tra vCard 3.0 e 4.0?
Sono due versioni del formato di contatto vCard. Lo strumento scrive un file di testo VCF compatibile utilizzando la versione selezionata; le app di contatto potrebbero supportarle in modo diverso.
Verifica i numeri di telefono o gli indirizzi e-mail?
No. Controlla solo il formato di base. Non può verificare che un numero, una casella di posta, un indirizzo o un sito web appartengano alla persona.
