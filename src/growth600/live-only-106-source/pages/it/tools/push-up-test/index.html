Test di flessioni e registro delle serie

Registra un singolo set come test semplice o registra diversi set con il resto tra di loro. Conti e inserisci le ripetizioni; questo strumento non utilizza la tua fotocamera né classifica la tua forza.

Immettere fino a 20 conteggi di numeri interi compresi tra 0 e 500. Le righe vuote vengono ignorate e non vengono conteggiate come serie. Conta solo le ripetizioni che hai completato con il modulo scelto.

Mantieni note generali; questa non è una cartella clinica.

Scegli un range di movimento confortevole e fermati se avverti dolore, vertigini o insolita mancanza di respiro. Il conteggio delle ripetizioni dipende dalla forma, dal ritmo e dalle condizioni del test; questo strumento non fornisce una valutazione della forma fisica, una diagnosi o una prescrizione di esercizi.

Il salvataggio è facoltativo e utilizza solo questo browser. Deseleziona per calcolare senza salvare oppure cancella la cronologia salvata di seguito.

La tua sessione

In che modo il tracker del test push-up totalizza le ripetizioni?

Somma le ripetizioni a numero intero immesse per ogni set non vuoto. Le righe vuote vengono ignorate, un insieme di zero rimane zero e la stima del riposo corrisponde al riposo per interruzione moltiplicato per il numero di interruzioni.

Domande frequenti

In che modo il tracker del test push-up totalizza le ripetizioni?

Somma le ripetizioni a numero intero immesse per ogni set non vuoto. Le righe vuote vengono ignorate, un insieme di zero rimane zero e la stima del riposo corrisponde al riposo per interruzione moltiplicato per il numero di interruzioni.

I miei set di flessioni vengono caricati?

No. Il calcolo viene eseguito in questo browser. La cronologia delle sessioni viene scritta su questo dispositivo solo dopo l'attivazione; puoi eliminarlo qui.

Le righe vuote contano come serie o ripetizioni?

No. Le righe vuote vengono ignorate. Una riga con 0 registra un set con ripetizioni pari a zero e non aggiunge ripetizioni al totale.

Posso usarlo per un set massimo o per più set?

Sì. Inserisci una riga per un singolo set conteggiato manualmente oppure più righe per riepilogare i set e il resto tra di essi. Le condizioni del test dipendono da te; i risultati non sono confrontati con le norme della popolazione.

La cronologia dei miei allenamenti è stata caricata?

No. La cronologia è facoltativa e rimane nel browser di questo dispositivo. Cancellalo con il pulsante Elimina quando vuoi.
