ICS Visualizzatore calendario

Visualizza un file iCalendar .ics senza connetterti a un calendario online. Filtra gli eventi per data e testo, espandi gli eventi ricorrenti supportati ed esporta l'elenco visibile come CSV.

Visualizzatore ICS di sola lettura. Questo non è un editor di calendario o un servizio di sincronizzazione. Le opzioni di ricorrenza non supportate vengono segnalate anziché indovinate.

Se vengono forniti entrambi, viene utilizzato il file selezionato. L'esempio mostra un evento ricorrente con una data esclusa.

Nessuna connessione all'account del calendario o ricerca di rete. Gli orari variabili utilizzano l'ora locale del tuo dispositivo; Gli orari TZID utilizzano il fuso orario indicato.

Limiti locali: 5 MiB, 2.000 eventi, 10.000 occorrenze visualizzate e un intervallo di date fino a 366 giorni. I file complessi possono utilizzare la memoria del dispositivo; si consiglia un computer.

Come faccio ad aprire un file di calendario ICS?

Scegli un file .ics locale o incollane il testo, seleziona un intervallo di date e visualizza gli eventi corrispondenti. Il visualizzatore espande le regole giornaliere, settimanali, mensili e annuali supportate e applica le eccezioni EXDATE.

Domande frequenti

Come faccio ad aprire un file di calendario ICS?

Scegli un file .ics locale o incollane il testo, seleziona un intervallo di date e visualizza gli eventi corrispondenti. Il visualizzatore espande le regole giornaliere, settimanali, mensili e annuali supportate e applica le eccezioni EXDATE.

Iil mio calendario è stato caricato?

N. Il calendario viene letto solo in questo browser. UsefulVerse non si connette al tuo account del calendario, carica il file o salva i tuoi eventi.

Il visualizzatore ICS mostra eventi ricorrenti?

Espande le regole giornaliere, settimanali, mensili e annuali nell'intervallo di date selezionato e applica le esclusioni EXDATE. Le opzioni di ricorrenza non supportate vengono rifiutate anziché indovinate.

Può connettersi a Google Calendar o Outlook?

N. Legge un file scelto o un testo incollato. Non effettua l'accesso, non recupera un calendario online né sincronizza le modifiche.

Quale fuso orario utilizza?

A TZID su un evento viene interpretato con quella zona. I timestamp UTC rimangono UTC; gli orari degli eventi variabili utilizzano il fuso orario del tuo dispositivo. L'elenco è formattato nella zona locale del tuo browser.
