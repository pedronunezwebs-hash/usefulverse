CSV Unisci

Combina diversi file CSV in un'unica tabella. I nomi delle colonne corrispondenti vengono allineati anche quando il loro ordine è diverso e le colonne aggiuntive vengono aggiunte con celle vuote dove necessario. I file rimangono in questo browser.

Selezionare da 2 a 20 file, fino a 2 MiB ciascuno e 8 MiB in totale. L'elaborazione rimane su questo dispositivo.

Con le intestazioni, le colonne corrispondono ai nomi esatti e le nuove colonne seguono l'ordine trovato per primo. Senza intestazioni, le colonne corrispondono in base alla posizione. Le intestazioni o i valori simili a formule sono preceduti da un apostrofo per un'apertura più sicura del foglio di calcolo. I delimitatori, la codifica dei file e il testo delle celle non vengono altrimenti normalizzati.

Unito CSV

Rivedere il CSV unito prima di utilizzarlo in un'altra applicazione.

Come posso unire file CSV con ordini di colonne diversi?

Seleziona due o più file CSV e mantieni attiva l'opzione dell'intestazione. Le colonne vengono abbinate in base al testo esatto dell'intestazione, utilizzando l'ordine visualizzato per primo. Le colonne mancanti diventano celle vuote; le colonne senza corrispondenza vengono aggiunte all'output.

Domande frequenti

Come posso unire file CSV con ordini di colonne diversi?

Seleziona due o più file CSV e mantieni attiva l'opzione dell'intestazione. Le colonne vengono abbinate in base al testo esatto dell'intestazione, utilizzando l'ordine visualizzato per primo. Le colonne mancanti diventano celle vuote; le colonne senza corrispondenza vengono aggiunte all'output.

I miei file CSV sono caricati?

No. I file selezionati vengono letti e uniti localmente in questo browser. Sono supportati fino a 20 file, con un limite di input combinato di 2 MiB per file e 8 MiB. Non viene utilizzata alcuna elaborazione tramite account o server.

Posso unire file CSV quando le relative colonne sono in un ordine diverso?

Sì. Con le intestazioni abilitate, le colonne vengono allineate in base al testo esatto dell'intestazione, non alla posizione. Le nuove intestazioni vengono aggiunte nell'ordine riscontrato per prime e i valori mancanti vengono lasciati vuoti.

Cosa succede se un file CSV non ha una riga di intestazione?

Disattiva l'opzione dell'intestazione. I valori vengono quindi allineati in base alla posizione della colonna e l'output utilizza nomi neutri come Colonna 1. Le righe di input con meno celle vengono riempite dal parser CSV.

Sono state modificate formule o comandi del foglio di calcolo?

Intestazioni e valori simili a formule sono preceduti da un apostrofo nell'output CSV per ridurre il rischio di esecuzione quando vengono aperti nel software per fogli di calcolo. Ciò modifica intenzionalmente i valori della cella.
