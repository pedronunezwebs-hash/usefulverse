Editor DOCX

Apporta modifiche mirate al testo in un moderno file Word DOCX in questo browser. L'editor modifica le sequenze di testo esistenti nel documento principale e mantiene invariate le altre parti del documento. Non si tratta di una sostituzione completa di Word e la formattazione complessa potrebbe non essere visualizzata in anteprima qui.

Solo .docx moderno. Massimo 25 MiB, pacchetto espanso da 80 MiB, documento XML da 8 MiB, 500 segmenti di testo e 250.000 caratteri. I documenti di grandi dimensioni funzionano meglio su un computer.

L'elaborazione avviene sul tuo dispositivo dopo aver scelto un file. Nessun caricamento, account, API, salvataggio automatico o elaborazione del server.

Questo editor mirato modifica solo il testo esistente nel documento principale. Conserva stili, immagini e altri contenuti di parti del pacchetto, ma reimballa il contenitore DOCX ZIP. Non modifica intestazioni, piè di pagina, commenti, note a piè di pagina, formattazione, struttura del paragrafo o modifiche tracciate. Le macro e i pacchetti con firma digitale non sono supportati.

Anteprima testo

Cosa posso modificare in un file DOCX?

Puoi modificare segmenti di testo esistenti nei paragrafi e nelle celle della tabella in un moderno file .docx, visualizzare in anteprima il testo e scaricare una copia modificata. Questo editor non aggiunge o rimuove paragrafi, modifica la formattazione, modifica intestazioni o piè di pagina né supporta le modifiche rilevate.

Domande frequenti

Cosa posso modificare in un file DOCX?

Puoi modificare segmenti di testo esistenti nei paragrafi e nelle celle della tabella in un moderno file .docx, visualizzare in anteprima il testo e scaricare una copia modificata. Questo editor non aggiunge o rimuove paragrafi, modifica la formattazione, modifica intestazioni o piè di pagina né supporta le modifiche rilevate.

Il mio documento Word è stato caricato?

No. Il file viene elaborato in questo browser dopo averlo scelto. Non viene caricato, salvato automaticamente o inviato a un server.

Il file modificato manterrà la formattazione esistente?

Gli stili di testo e altri contenuti delle parti del pacchetto vengono conservati. Quando un segmento di testo viene sostituito, viene mantenuta la formattazione di esecuzione esistente; questo strumento non offre controlli di formattazione RTF né garantisce che ogni funzionalità di Word venga visualizzata in modo identico.

È possibile modificare le revisioni, le intestazioni o i documenti firmati?

No. L'editor focalizzato modifica le sequenze di testo solo nel documento principale. I flussi di lavoro con modifiche tracciate, le intestazioni e i piè di pagina, le macro e i file con firma digitale non sono supportati.
