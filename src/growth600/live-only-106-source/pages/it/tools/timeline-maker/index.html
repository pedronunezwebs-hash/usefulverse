Creatore di sequenza temporale

Trasforma le pietre miliari o gli eventi storici in una sequenza temporale chiara e cronologica. Aggiungi una singola data o una data di inizio e fine per ogni evento.

Questa è una cronologia degli eventi, non un programma di attività/dipendenze o una fonte di fatti storici. Inserisci le date che hai controllato.

I nomi e le date dei tuoi eventi rimangono in questa scheda. Niente viene caricato o salvato automaticamente. Le esportazioni vengono create localmente.

Come faccio a creare una cronologia degli eventi?

Aggiungi almeno due eventi con nome e scegli una data di inizio per ciascuno. Aggiungi una data di fine per una durata o lasciala vuota per un evento di un solo giorno. Crea la sequenza temporale per ordinare gli eventi per data, regolare lo zoom e scaricare file SVG o CSV.

Domande frequenti

Come faccio a creare una cronologia degli eventi?

Aggiungi almeno due eventi con nome e scegli una data di inizio per ciascuno. Aggiungi una data di fine per una durata o lasciala vuota per un evento di un solo giorno. Crea la sequenza temporale per ordinare gli eventi per data, regolare lo zoom e scaricare file SVG o CSV.

Gli eventi della mia sequenza temporale vengono caricati?

No. I nomi e le date vengono elaborati in questa scheda del browser. SVG e CSV vengono generati sul tuo dispositivo; nulla viene caricato o salvato automaticamente.

Un evento può durare più di un giorno?

Sì. Inserisci sia la data di inizio che quella di fine. Il grafico include entrambe le date finali; lasciare vuota la fine per un evento di un solo giorno.

Questa sequenza temporale crea dipendenze tra le attività?

No. Mostra gli eventi e gli intervalli con data in ordine cronologico. Utilizza uno strumento di pianificazione del progetto per attività, durate e dipendenze.

Posso salvare o condividere la sequenza temporale?

Scarica un SVG per un'immagine scalabile o un CSV per la tabella degli eventi. La pagina non carica né salva automaticamente i dati dell'evento.
