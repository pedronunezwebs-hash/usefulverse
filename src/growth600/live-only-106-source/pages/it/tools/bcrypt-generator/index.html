Generatore Bcrypt

Genera un hash bcrypt standard o confronta una password con un hash bcrypt esistente. Il lavoro viene eseguito in un browser lavoratore locale e la password viene cancellata dopo ogni controllo.

Bcrypt utilizza solo i primi byte 72 UTF-8. Questo strumento rifiuta i valori più lunghi anziché troncarli silenziosamente. Il costo 8–14 aumenta il lavoro in modo esponenziale; costi più elevati possono richiedere più tempo, soprattutto sui telefoni. Un operatore locale mantiene la pagina reattiva, ma il tuo dispositivo esegue il lavoro.

Utilizzare una password di prova, non una vera password di accesso. Il risultato serve per verifiche di apprendimento e compatibilità; non utilizzare questa pagina del browser come sistema di archiviazione dell'account di produzione.

Incolla un hash bcrypt standard di 60 caratteri. La verifica supporta bcrypt costa 4–14; Gli hash insolitamente costosi vengono rifiutati per evitare un lavoro illimitato sul dispositivo.

Risultato

Cosa fa un hash bcrypt?

Bcrypt è una funzione di hashing della password, non una crittografia. Combina un hash unidirezionale con un sale casuale e un fattore di lavoro configurabile. Un hash può essere confrontato con una password candidata ma non può essere decrittografato per rivelare l'originale.

Domande frequenti

Cosa fa un hash bcrypt?

Bcrypt è una funzione di hashing della password, non una crittografia. Combina un hash unidirezionale con un sale casuale e un fattore di lavoro configurabile. Un hash può essere confrontato con una password candidata ma non può essere decrittografato per rivelare l'originale.

La mia password o il mio hash vengono caricati o salvati?

No. Hashing e verifica eseguiti in questo browser. La pagina non invia la password o l'hash immessi a un server né li salva; il campo della password viene cancellato al termine dell'operazione. Per sicurezza, utilizza una password di prova anziché una password dell'account reale.

bcrypt crittografa la mia password?

No. Bcrypt è un hash della password unidirezionale, una crittografia non reversibile. È progettato per consentire al software di verificare una password candidata senza memorizzare la password originale.

Perché bcrypt ha un limite di 72 byte?

Il formato bcrypt elabora al massimo 72 UTF-8 byte. Questo strumento rifiuta input più lunghi, quindi password diverse non vengono mai trattate silenziosamente come lo stesso valore troncato.

Dovrei archiviare questo hash per un account reale?

Non utilizzare questa pagina come sistema di credenziali di produzione. I servizi reali dovrebbero eseguire l'hashing delle password sui propri server affidabili con librerie di autenticazione mantenute, parametri adeguati, limiti di velocità e protezioni degli account.
