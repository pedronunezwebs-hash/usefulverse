Editor metadati PDF

Leggi o modifica le informazioni comuni sui documenti archiviate in un PDF, quindi scarica una copia separata. Il PDF selezionato rimane su questo dispositivo.

Mantieni il tuo originale. Il nuovo salvataggio potrebbe invalidare le firme digitali o influenzare le funzionalità PDF avanzate. Questo strumento non rimuove le informazioni nascoste né certifica la privacy.

Limiti locali: 25 MiB in ingresso, 300 pagine e 50 MiB in uscita. I documenti di grandi dimensioni potrebbero richiedere più memoria; si consiglia un computer.

Vengono modificate solo le informazioni standard del documento PDF. XMP, metadati personalizzati, allegati, contenuto nascosto e convalida della firma non sono supportati.

L'elaborazione è locale in questo browser. Nessun account, caricamento, elaborazione del server o salvataggio automatico.

Quali metadati PDF posso modificare?

Questo strumento modifica i campi di informazioni standard del documento: titolo, autore, oggetto, parole chiave, creatore, produttore, data di creazione e data di modifica. Non modifica i metadati XMP o le proprietà personalizzate.

Domande frequenti

Quali metadati PDF posso modificare?

Questo strumento modifica i campi di informazioni standard del documento: titolo, autore, oggetto, parole chiave, creatore, produttore, data di creazione e data di modifica. Non modifica i metadati XMP o le proprietà personalizzate.

Il mio PDF è stato caricato?

No. La lettura e la modifica avvengono nel browser dopo aver scelto un file. Il file originale non viene modificato; il salvataggio crea una copia PDF separata.

Verranno rimossi tutti i metadati da un PDF?

No. Modifica solo le voci comuni nel dizionario standard delle informazioni sui documenti PDF. XMP, proprietà personalizzate, file incorporati e altri contenuti nascosti potrebbero rimanere.

La modifica dei metadati conserverà una firma digitale?

Non fare affidamento su questo. Il salvataggio riscrive il PDF e può invalidare le firme digitali esistenti o influenzare funzionalità non supportate da questo strumento. Conserva l'originale e verifica la copia.

Il PDF originale è stato sovrascritto?

No. Lo strumento legge il file selezionato e crea una copia scaricabile separata. Non modifica l'originale sul tuo dispositivo.
