Modello verbale di riunione

utilizza un modello chiaro di verbale della riunione per partecipanti, argomenti all'ordine del giorno, decisioni e azioni. Ogni azione può includere un proprietario e una data di scadenza.

Esempio: Bozza di revisione | Sam | 2026-10-16. Ogni azione necessita di una persona responsabile e di una data valida.

questo è un modello per prendere appunti, non un registratore automatico di riunioni o un generatore di trascrizioni.

Le note rimangono in questa scheda finché non la chiudi. Scaricateli o stampateli per conservarne una copia.

Verbale assemblea


  

    
Cosa deve contenere il verbale della riunione?
registra il titolo della riunione, la data, il facilitatore, i partecipanti, l'ordine del giorno, le decisioni e le azioni. Assegna un proprietario e una data di scadenza a ciascuna azione in modo che il follow-up sia chiaro.


    
Domande frequenti
Cosa deve contenere il verbale della riunione?
registra il titolo della riunione, la data, il facilitatore, i partecipanti, l'ordine del giorno, le decisioni e le azioni. Assegna un proprietario e una data di scadenza a ciascuna azione in modo che il follow-up sia chiaro.
Gli appunti della mia riunione vengono caricati o salvati?
No. Il modello viene eseguito in questa scheda del browser. Non salva o carica automaticamente le tue note; esporta un file Markdown o stampalo se ne desideri una copia.
Come devo formattare un'azione?
Immettere un'azione per riga come attività | proprietario | data di scadenza, utilizzando una data AAAA-MM-GG valida, ad esempio: Invia note | Sam | 2026-10-16.
Posso stampare o esportare il verbale?
Sì. Visualizza l'anteprima delle note strutturate, scaricale come file Markdown o utilizza l'opzione di stampa nel tuo browser.
Questo strumento registra o trascrive una riunione?
No. Non accede a un microfono né crea una trascrizione. Inserisci tu stesso le note e le decisioni.
