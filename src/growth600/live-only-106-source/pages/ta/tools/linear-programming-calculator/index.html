லீனியர் புரோகிராமிங் கால்குலேட்டர்

ஒரு நேரியல் நோக்கத்தை உள்ளிடவும் மற்றும் x மற்றும் y அல்லாத எதிர்மறையான இரண்டு-மாறி நேரியல் நிரலைத் தீர்க்க எட்டு கட்டுப்பாடுகள் வரை உள்ளிடவும். இரண்டு-கட்ட சிம்ப்ளக்ஸ் முறையானது ஒரு உகந்த, இயலாமை அல்லது வரம்பற்ற தன்மையைப் புகாரளிக்கிறது மற்றும் ஒவ்வொரு பிவோட்டையும் காட்டுகிறது.

அதிகபட்சம் எட்டு கட்டுப்பாடுகள் மற்றும் குணகங்கள்/வலது பக்கங்களை ±1,000,000 க்குள் பயன்படுத்துகிறது. இரண்டு முடிவு மாறிகளும் x ≥ 0 மற்றும் y ≥ 0 ஆகியவற்றைக் கொண்டுள்ளன. x மற்றும் y குணகங்களுக்கு இடையே கமாவைப் பயன்படுத்தவும்; ஒரு வரிக்கு ஒரு சமத்துவமின்மை அல்லது சமத்துவத்தை உள்ளிடவும்.

இரண்டு மாறிகளுக்கான இரண்டு-கட்ட ப்ரைமல் சிம்ப்ளக்ஸ் தீர்வு. மிதக்கும் புள்ளி மையங்களுக்கு எண் சகிப்புத்தன்மை பயன்படுத்தப்படுகிறது; ஏறக்குறைய சீரழிந்த பிரச்சனைகள் ரவுண்டிங்கிற்கு உணர்திறன் கொண்டதாக இருக்கும். கண்டுபிடிக்கப்பட்ட உகந்ததிற்குப் பதிலாக சாத்தியமற்ற, வரம்பற்ற மற்றும் மறு செய்கை-வரம்பு வழக்குகள் பதிவாகியுள்ளன.
