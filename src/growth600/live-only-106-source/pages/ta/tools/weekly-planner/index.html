வாராந்திர திட்டமிடுபவர்

வேலை, தனிப்பட்ட திட்டங்கள், படிப்பு அல்லது ஆரோக்கியத்திற்கான எளிய வாராந்திர நேர-தடுப்பு அட்டவணையை உருவாக்கவும். இரவு நேரத் தடைகள் மற்றும் கால அட்டவணை முரண்பாடுகள் தெளிவாகக் காட்டப்பட்டுள்ளன.

மீண்டும் மீண்டும் வாராந்திர திட்டம் உள்ளூர் சுவர்-கடிகார நேரங்களைப் பயன்படுத்துகிறது; இது நேர மண்டலங்கள், பகல்-சேமிப்பு மாற்றங்கள், காலண்டர் நிகழ்வுகள் அல்லது நினைவூட்டல்களைக் கணக்கில் கொள்ளாது.

இந்தத் தாவலில் திட்டம் நினைவகத்தில் இருக்கும். அதை வைத்திருக்க JSON காப்புப்பிரதியைப் பதிவிறக்கவும்; தானியங்கு சேமிப்பு அல்லது பதிவேற்றம் இல்லை.

வாராந்திர அட்டவணை

வாராந்திர அட்டவணையை எப்படி உருவாக்குவது?

ஒவ்வொரு தொகுதிக்கும் ஒரு தலைப்பு, நாள், தொடக்க நேரம், முடிவு நேரம் மற்றும் வகையைச் சேர்க்கவும். தொகுதிகள் நள்ளிரவை கடக்கலாம். ஞாயிறு மற்றும் திங்கட்கிழமைகள் உட்பட, ஒன்றுடன் ஒன்று நேரம் குறிக்கப்படுகிறது.

வாராந்திர அட்டவணையை எப்படி உருவாக்குவது?

ஒவ்வொரு தொகுதிக்கும் ஒரு தலைப்பு, நாள், தொடக்க நேரம், முடிவு நேரம் மற்றும் வகையைச் சேர்க்கவும். தொகுதிகள் நள்ளிரவை கடக்கலாம். ஞாயிறு மற்றும் திங்கட்கிழமைகள் உட்பட, ஒன்றுடன் ஒன்று நேரம் குறிக்கப்படுகிறது.

எனது வாராந்திர அட்டவணை பதிவேற்றப்பட்டதா அல்லது சேமிக்கப்பட்டதா?

இல்லை. JSON காப்புப்பிரதியைப் பதிவிறக்க நீங்கள் தேர்வுசெய்யும் வரை உங்கள் அட்டவணை இந்த உலாவி தாவலில் இருக்கும். உங்கள் சாதனத்திலிருந்து நீங்கள் தேர்ந்தெடுத்த காப்புப்பிரதியை இறக்குமதி செய்யவும்.

வாராந்திர திட்டமிடுபவர் இரவு நேர ஷிப்ட்களை சேர்க்க முடியுமா?

ஆம். அடுத்த நாள் முடிவடையும் ஒரு தொகுதியை உருவாக்க, தொடக்க நேரத்தை விட ஒரு முடிவு நேரத்தை தேர்வு செய்யவும். 18 மணிநேரம் வரையிலான தடைகள் ஆதரிக்கப்படுகின்றன.

வாராந்திர அட்டவணை முரண்பாடுகளைக் கண்டறியுமா?

ஆம். திங்கட்கிழமை ஒன்றுடன் ஒன்று ஞாயிறு தொகுதி உட்பட, அதே நாளில் மற்றும் நள்ளிரவு முழுவதும் நேரத் தொகுதிகளை இது சரிபார்க்கிறது.

இந்த பிளானர் Google Calendar உடன் ஒத்திசைகிறதா?

எண். இது இந்த தாவலில் உள்ளூரில் வேலை செய்கிறது மற்றும் காலண்டர் இணைப்பு அல்லது நினைவூட்டல் சேவை இல்லை. நீங்கள் திட்டத்தை அச்சிடலாம் அல்லது JSON காப்புப்பிரதியை பதிவிறக்கம் செய்து இறக்குமதி செய்யலாம்.
