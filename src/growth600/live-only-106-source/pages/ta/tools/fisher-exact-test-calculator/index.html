எண்ணிக்கைகள் முழு எண்களாக இருக்க வேண்டும். ஒரு கலத்திற்கு அதிகபட்சம் 10,000 மற்றும் மொத்தம் 20,000. நிலையான விளிம்புகளின் கீழ் கவனிக்கப்பட்ட அட்டவணையை விட இருபக்க சோதனை கூட்டுத்தொகை அட்டவணைகள் சாத்தியமில்லை.
