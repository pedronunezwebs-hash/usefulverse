சுவாசப் பயிற்சி

மென்மையான சுவாச வேகத்தைத் தேர்ந்தெடுத்து, திரையில் உள்ள வழிகாட்டியைப் பின்பற்றவும். பயிற்சியை வசதியாக மேற்கொள்ளுங்கள்; எப்போது வேண்டுமானாலும் நிறுத்தலாம்.

குறைந்த அசைவு அமைப்பு இயக்கப்பட்டால் வழிகாட்டி திடீர் அசைவுகளைத் தவிர்க்கும்.

இது பொதுவான நல்வாழ்வுக்கான டைமர்; மருத்துவச் சிகிச்சை அல்ல. வசதியாகச் சுவாசிக்கவும்; உடல்நலக்குறைவு ஏற்பட்டால் நிறுத்தவும்.
