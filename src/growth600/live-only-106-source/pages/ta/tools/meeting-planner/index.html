மீட்டிங் திட்டமிடுபவர்

வெவ்வேறு நேர மண்டலங்களில் அமைப்பாளர் மற்றும் பங்கேற்பாளர்கள் முழுவதும் தினசரி கிடைக்கும் சாளரத்தை ஒப்பிடுக. ஒவ்வொரு உள்ளூர் தேதியையும் நேரத்தையும் மதிப்பாய்வு செய்து, பொருந்தக்கூடிய ஸ்லாட்டுக்கான ICS அழைப்பைப் பதிவிறக்கவும்.

உள்ளூரில் இயங்குகிறது. காலெண்டர் இணைப்பு, இருப்பிட கோரிக்கை, பதிவேற்றம், கணக்கு, API அல்லது தானியங்கு சேமிப்பு இல்லை.

எடுத்துக்காட்டுகள்: அமெரிக்கா/நியூயார்க், ஐரோப்பா/லண்டன், ஆசியா/டோக்கியோ. அமைப்பாளர் தானாகவே சேர்க்கப்படுகிறார்; மொத்தம் எட்டு தனித்தனி மண்டலங்கள் வரை பயன்படுத்தவும்.

பகல்-சேமிப்பு விதிகள் இந்த உலாவியின் நேர மண்டல தரவுத்தளத்திலிருந்து வந்தவை மற்றும் பழையதாக இருக்கலாம். ஒரு வீழ்ச்சி-மீண்டும் நேரம் மீண்டும் நடந்தால், முந்தைய நிகழ்வு தேர்ந்தெடுக்கப்பட்டது; ஸ்பிரிங்-ஃபார்வர்ட் இடைவெளியின் போது இல்லாத கிடைக்கும் எல்லை தவிர்க்கப்பட்டது.

ஒவ்வொரு நேர மண்டலத்திலும் ஒரே தினசரி உள்ளூர் நேர சாளரத்தைப் பயன்படுத்துகிறது. தனிப்பட்ட நாட்காட்டிகள், விடுமுறை நாட்கள், வேலை நாட்கள் அல்லது பங்கேற்பாளர் விருப்பங்கள் இதற்குத் தெரியாது. அழைப்பை அனுப்பும் முன் அனைவருடனும் உண்மையான ஸ்லாட்டைத் தேர்வு செய்யவும்.
