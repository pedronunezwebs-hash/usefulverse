ஃப்ரீசெல்

அனைத்து 52 கார்டுகளையும் அவற்றின் சூட் அடித்தளங்களுக்கு நகர்த்தவும். நான்கு இலவச கலங்களை தற்காலிக இடமாகப் பயன்படுத்தவும், இறங்கு மாற்று-வண்ண நெடுவரிசைகளை உருவாக்கவும், மேலும் திறந்த செல்கள் மற்றும் நெடுவரிசைகளைச் சுற்றி ஒவ்வொரு சூப்பர் மூவையும் திட்டமிடுங்கள்.

புதிய சீரற்ற ஒப்பந்தத்திற்கு காலியாக விடவும். அதே ஒப்பந்தத்தை மீண்டும் உருவாக்க அதே விதையைப் பயன்படுத்தவும்; அது இந்தப் பக்கத்தில் மட்டுமே இருக்கும்.

அட்டவணை அட்டைகள் மாற்று வண்ணங்களில் கீழ்நோக்கி உருவாக்கப்படுகின்றன. தேர்ந்தெடுக்கப்பட்ட ரன் ஏற்கனவே வண்ணங்களை மாற்ற வேண்டும் மற்றும் ஒரு தரவரிசையில் இறங்க வேண்டும். ஒரு சூப்பர் மூவ் தற்போது காலியாக உள்ள இலவச செல்கள் மற்றும் உதவி நெடுவரிசைகளால் வரையறுக்கப்பட்டுள்ளது.

அறக்கட்டளைகள் ஒரே உடையில் ஏஸ் முதல் கிங் வரை உருவாக்கப்படுகின்றன. ஒரு நெடுவரிசையின் மேல் அட்டை அல்லது இலவச கலத்தில் உள்ள கார்டை மட்டுமே நகர்த்த முடியும்.

How do you play FreeCell?

Build each foundation from Ace to King in one suit. On the tableau, build downward in alternating colors. A free cell can hold one card. You may move a valid descending alternating-color run as a supermove only when the available empty cells and helper columns can support it.

How do you play FreeCell?

Build each foundation from Ace to King in one suit. On the tableau, build downward in alternating colors. A free cell can hold one card. You may move a valid descending alternating-color run as a supermove only when the available empty cells and helper columns can support it.

Does FreeCell save my game?

No. The game runs in this browser tab. It does not use an account, upload moves or save a game automatically. A replay seed is optional and stays only in this page.

ஃப்ரீசெல் சூப்பர் மூவ் எத்தனை கார்டுகளை நகர்த்த முடியும்?

மேல் வரம்பு (வெற்று இலவச கலங்கள் + 1) வெற்று உதவி நெடுவரிசைகளின் சக்தியுடன் 2 ஆல் பெருக்கப்படுகிறது. இலக்கு நெடுவரிசை காலியாக இருக்கும்போது உதவியாளராகக் கணக்கிடப்படாது. ஓட்டமானது இறங்குமுகமாகவும், சிவப்பு மற்றும் கருப்பு நிறமாகவும் மாற வேண்டும்.

Can I move a sequence directly in FreeCell?

ஆம், கார்டுகள் ஏற்கனவே ஒரு இறங்கு மாற்று-வண்ண ஓட்டத்தை உருவாக்கி, அதன் அளவு வெற்று இலவச செல்கள் மற்றும் ஹெல்பர் நெடுவரிசைகள் வழங்கும் திறனை விட அதிகமாக இல்லை என்றால். விளையாட்டு இந்த வரம்பை செயல்படுத்துகிறது.

ஃப்ரீசெல் ஒப்பந்தங்கள் மீண்டும் இயக்க முடியுமா?

Yes. Enter the same optional seed and choose a new deal to recreate its layout in this browser. Leave the seed blank for a random shuffle. No seed or game is sent to a server.
