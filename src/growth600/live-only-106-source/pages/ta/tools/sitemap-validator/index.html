தளவரைபட சரிபார்ப்பு

அதன் அமைப்பு, URL உள்ளீடுகள், தேதிகள் மற்றும் பொதுவான புலங்களைச் சரிபார்க்க ஒரு தளவரைபட XML ஆவணத்தை ஒட்டவும். எக்ஸ்எம்எல் இந்த உலாவியில் மட்டுமே பாகுபடுத்தப்படுகிறது; பட்டியலிடப்பட்ட பக்கங்கள் ஒருபோதும் எடுக்கப்படவில்லை.

நிலையான urlset அல்லது sitemapindex ஐ ஆதரிக்கிறது. அதிகபட்சம் 1,000,000 எழுத்துகள் மற்றும் 5,000 நேரடி உள்ளீடுகள்.

உள்ளூர் XML சரிபார்க்கிறது: இது பட்டியலிடப்பட்ட URLகளை கோராது, தளத்தை வலைவலம் செய்யாது, தளவரைபடத்தைச் சமர்ப்பிக்காது, அல்லது அட்டவணைப்படுத்தலுக்கு உத்தரவாதம் அளிக்காது.

சரிபார்ப்பு சுருக்கம்

கண்டுபிடிப்புகள்

    இந்த தளவரைபட வேலிடேட்டர் எதைச் சரிபார்க்கிறது?

    இது urlset அல்லது sitemapindex உள்ளீடுகள், முழுமையான HTTP அல்லது HTTPS இருப்பிடங்கள், நகல் இயல்பாக்கப்பட்ட URLகள், லாஸ்ட்மோட் தேதிகள், விருப்ப மாறுதல் அதிர்வெண் மற்றும் முன்னுரிமை மதிப்புகள் மற்றும் தளவரைபட பெயர்வெளி ஆகியவற்றைச் சரிபார்க்கிறது. எச்சரிக்கைகள் மற்றும் பிழைகள் நுழைவு எண் மூலம் பட்டியலிடப்பட்டுள்ளன.

    அடிக்கடி கேட்கப்படும் கேள்விகள்

    இந்த தளவரைபட வேலிடேட்டர் எதைச் சரிபார்க்கிறது?

    இது எனது தளவரைபடத்தைப் பதிவேற்றுகிறதா அல்லது சமர்ப்பிக்கிறதா?

    எண். XML உங்கள் உலாவியில் உள்நாட்டில் செயலாக்கப்படுகிறது. கருவி URLகளை வலைவலம் செய்யாது, தொலைநிலை தளவரைபடக் கோப்புகளைப் பெறாது, தேடுபொறியில் எதையும் சமர்ப்பிக்காது அல்லது அட்டவணைப்படுத்தலை உறுதிப்படுத்தாது.

    தளவரைபட URL நேரலையில் உள்ளதா என்பதை இது சரிபார்க்கிறதா?

    எண். இது URL தொடரியல் மற்றும் ஒட்டப்பட்ட XML க்குள் நகல்களை சரிபார்க்கிறது, ஆனால் வேண்டுமென்றே URLகளை கோரவோ அல்லது தளத்தை வலைவலம் செய்யவோ இல்லை.

    செல்லுபடியாகும் தளவரைபடம் என்றால் Google அதன் பக்கங்களை அட்டவணைப்படுத்தியதா?

    எண். XML சரிபார்ப்பு என்பது தேடுபொறி சமர்ப்பிப்பு அல்லது அட்டவணைப்படுத்தல் அறிக்கை அல்ல. தொடர்புடைய தேடுபொறி வெப்மாஸ்டர் கருவி மூலம் தளவரைபடத்தைச் சமர்ப்பித்து அதன் சொந்த நிலையைச் சரிபார்க்கவும்.

    தளவரைபட குறியீட்டை நான் சரிபார்க்க முடியுமா?

    ஆம். கருவி நேரடி sitemapindex உள்ளீடுகள் மற்றும் அவற்றின் இருப்பிடம் மற்றும் லாஸ்ட்மோட் புலங்களைச் சரிபார்க்கிறது, ஆனால் குறிப்பிடப்பட்ட தளவரைபடக் கோப்புகளைப் பதிவிறக்கவோ அல்லது மீண்டும் மீண்டும் ஆய்வு செய்யவோ இல்லை.
