XML முதல் CSV மாற்றி

எளிய XML பதிவு பட்டியலை CSV அட்டவணையாக மாற்றவும் அல்லது CSV கோப்பின் உரையிலிருந்து XML பதிவுகளை உருவாக்கவும். திசையைத் தேர்வுசெய்து, உங்கள் தரவை ஒட்டவும், பின்னர் முடிவை நகலெடுக்கவும் அல்லது பதிவிறக்கவும். எதுவும் பதிவேற்றப்படவில்லை.

ஒரே பெயர் பதிவு கூறுகளின் எளிய பட்டியலை அல்லது ஒரு தட்டையான பதிவை ஆதரிக்கிறது. உறுப்பு குழந்தைகள் அளவுகோல் மதிப்புகளாக இருக்க வேண்டும்; உள்ளமைக்கப்பட்ட மற்றும் மீண்டும் மீண்டும் வயல்களை சமன் செய்யவில்லை.

நெடுவரிசைப் பெயர்களுக்கு முதல் வரிசையைப் பயன்படுத்தவும். @id போன்ற தலைப்பு XML பண்புக்கூறாக மாறும். பதிவு உரைக்கு #text ஐப் பயன்படுத்தவும்.

இது ஒரு எளிய அட்டவணை மாற்றமாகும், இழப்பற்ற XML வடிவ மாற்றம் அல்ல. பெயர்வெளிகள், உள்ளமைக்கப்பட்ட கட்டமைப்புகள், கலப்பு உள்ளடக்கம், கருத்துகள் மற்றும் XML வடிவமைப்பு ஆகியவை பாதுகாக்கப்படவில்லை. உரை தட்டச்சு-அறிவு இல்லை. ஸ்ப்ரெட்ஷீட் ஃபார்முலா போன்ற CSV மதிப்புகள் பாதுகாப்பிற்காக அபோஸ்ட்ரோபியுடன் முன்னொட்டாக இருக்கும்.

முடிவு

வெளியீட்டை மற்றொரு பயன்பாட்டில் இறக்குமதி செய்வதற்கு முன் சரிபார்க்கவும்.

XML ஐ CSV ஆக மாற்றுவது எப்படி?

XML முதல் CSV வரை தேர்வு செய்து, XMLஐ எளிய பதிவுப் பட்டியலுடன் ஒட்டவும். மீண்டும் மீண்டும் நேரடி பதிவு கூறுகள் வரிசைகளாக மாறும். உறுப்பு பெயர்கள் நெடுவரிசைகளாக மாறும்; பண்புக்கூறுகள் @name ஐப் பயன்படுத்துகின்றன. தலைப்புகள் மற்றும் வரிசைகளில் இருந்து எளிய XML பதிவுகளை உருவாக்க CSV முதல் XML வரை தேர்வு செய்யவும்.

எனது XML அல்லது CSV பதிவேற்றப்பட்டதா?

உள்ளமைக்கப்பட்ட XML ஐ பிளாட் டேபிளாக மாற்ற முடியுமா?

எண். உள்ளமைக்கப்பட்ட குழந்தை கட்டமைப்புகள், பதிவின் உள்ளே திரும்பத் திரும்ப வரும் புலங்கள் மற்றும் கலவையான உரை ஆகியவை தட்டையான அல்லது அமைதியாக இழக்கப்படுவதற்குப் பதிலாக நிராகரிக்கப்படுகின்றன. உள்ளமைக்கப்பட்ட தரவுகளுக்கு, பிரத்யேக XML-to-JSON பணிப்பாய்வுகளைப் பயன்படுத்தவும்.

எண். CSV செல் உரையை சேமிக்கிறது, XML வகைகள், பெயர்வெளிகள் அல்லது வடிவமைப்பை அல்ல. ஸ்ப்ரெட்ஷீட் ஃபார்முலா எக்ஸிகியூஷன் ஆபத்தைக் குறைக்க, ஃபார்முலா போன்ற செல் மதிப்புகள் ஏற்றுமதி செய்யப்படும் போது, ​​அபோஸ்ட்ரோஃபி முன்னொட்டைப் பெறுகின்றன.
