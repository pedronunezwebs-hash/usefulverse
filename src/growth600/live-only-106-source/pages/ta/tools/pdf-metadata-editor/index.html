PDF மெட்டாடேட்டா எடிட்டர்

PDF இல் சேமிக்கப்பட்ட பொதுவான ஆவணத் தகவலைப் படிக்கவும் அல்லது திருத்தவும், பின்னர் ஒரு தனி நகலைப் பதிவிறக்கவும். தேர்ந்தெடுக்கப்பட்ட PDF இந்தச் சாதனத்தில் இருக்கும்.

உங்கள் அசலை வைத்திருங்கள். மீண்டும் சேமிப்பது டிஜிட்டல் கையொப்பங்களை செல்லாததாக்கலாம் அல்லது மேம்பட்ட PDF அம்சங்களை பாதிக்கலாம். இந்த கருவி மறைக்கப்பட்ட தகவலை அகற்றாது அல்லது தனியுரிமையை சான்றளிக்காது.

உள்ளூர் வரம்புகள்: 25 MiB உள்ளீடு, 300 பக்கங்கள் மற்றும் 50 MiB வெளியீடு. பெரிய ஆவணங்களுக்கு அதிக நினைவகம் தேவைப்படலாம்; ஒரு கணினி பரிந்துரைக்கப்படுகிறது.

நிலையான PDF ஆவணத் தகவல் மட்டுமே திருத்தப்பட்டது. XMP, தனிப்பயன் மெட்டாடேட்டா, இணைப்புகள், மறைக்கப்பட்ட உள்ளடக்கம் மற்றும் கையொப்ப சரிபார்ப்பு ஆதரிக்கப்படவில்லை.

நிலையான ஆவணத் தகவல்

புதிய நகலில் இருந்து அந்த நிலையான தகவல் உள்ளீட்டை அகற்ற ஒரு புலத்தை காலியாக விடவும். மற்ற துறைகள் வைக்கப்பட்டுள்ளன.

எந்த PDF மெட்டாடேட்டாவை மாற்றலாம்?

இந்த கருவி நிலையான ஆவண தகவல் புலங்களைத் திருத்துகிறது: தலைப்பு, ஆசிரியர், பொருள், முக்கிய வார்த்தைகள், உருவாக்கியவர், தயாரிப்பாளர், உருவாக்கிய தேதி மற்றும் மாற்றியமைக்கும் தேதி. இது XMP மெட்டாடேட்டா அல்லது தனிப்பயன் பண்புகளைத் திருத்தாது.

எண். நீங்கள் ஒரு கோப்பைத் தேர்ந்தெடுத்த பிறகு உங்கள் உலாவியில் படித்தல் மற்றும் திருத்துதல் நடக்கும். அசல் கோப்பு மாற்றப்படவில்லை; சேமிப்பது ஒரு தனி PDF நகலை உருவாக்குகிறது.

இது PDF இலிருந்து அனைத்து மெட்டாடேட்டாவையும் அகற்றுமா?

எண். இது நிலையான PDF ஆவண தகவல் அகராதியில் உள்ள பொதுவான உள்ளீடுகளை மட்டுமே திருத்துகிறது. XMP, தனிப்பயன் பண்புகள், உட்பொதிக்கப்பட்ட கோப்புகள் மற்றும் பிற மறைக்கப்பட்ட உள்ளடக்கம் இருக்கலாம்.

மெட்டாடேட்டாவைத் திருத்துவது டிஜிட்டல் கையொப்பத்தைப் பாதுகாக்குமா?

அதை நம்ப வேண்டாம். சேமிப்பது PDF ஐ மீண்டும் எழுதுகிறது மற்றும் ஏற்கனவே உள்ள டிஜிட்டல் கையொப்பங்களை செல்லாததாக்குகிறது அல்லது இந்த கருவியால் ஆதரிக்கப்படாத அம்சங்களை பாதிக்கலாம். அசலை வைத்து நகலைச் சரிபார்க்கவும்.
