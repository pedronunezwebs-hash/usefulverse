மாடுலோ கால்குலேட்டர்

முழு எண்களுக்கான யூக்ளிடியன் பங்கு மற்றும் மீதியைக் கணக்கிடவும். எதிர்மறை உள்ளீடுகள் தொடர்ந்து கையாளப்படுகின்றன, மேலும் பிரிவின் அடையாளம் பதில் எவ்வாறு உருவாகிறது என்பதைக் காட்டுகிறது.

வகுக்க வேண்டிய எண்; அது எதிர்மறையாக இருக்கலாம்.

பூஜ்ஜியம் அல்லாத முழு எண்ணையும் பயன்படுத்தவும்; அதன் முழுமையான மதிப்பு மாடுலஸை வரையறுக்கிறது.

இந்த மதிப்பு டிவிடெண்ட் மாடுலோ வகுப்பிக்கு ஒத்துப்போகிறதா என்பதைச் சரிபார்க்கவும்.

50 இலக்கங்கள் வரை கையொப்பமிடப்பட்ட முழு எண்களை ஏற்றுக்கொள்கிறது. பின்னங்கள் அல்லது தசமங்கள் இல்லை. இதன் விளைவாக யூக்ளிடியன் மாடுலோவைப் பயன்படுத்துகிறது; சில நிரலாக்க மொழிகள் எதிர்மறைகளுக்கு வேறுபட்ட மீதமுள்ள விதியைப் பயன்படுத்துகின்றன.

இந்த கால்குலேட்டர் முழுமையான வகுப்பியை விட சிறிய எதிர்மறையான மீதியைப் பயன்படுத்துகிறது. எடுத்துக்காட்டாக, −7 மோட் 3 என்பது 2 ஆகும், ஏனெனில் -7 = (-3 × 3) + 2.

எனது எண்கள் பதிவேற்றப்பட்டதா?

எண். இந்த உலாவியில் சரியான கணக்கீடு இயங்குகிறது. எண்கள் பதிவேற்றம் செய்யப்படவில்லை அல்லது சேமிக்கப்படவில்லை.

−7 மோட் 3 என்றால் என்ன?

யூக்ளிடியன் கன்வென்ஷனைப் பயன்படுத்தி, −7 மோட் 3 என்பது 2: −7 = (−3 × 3) + 2, மற்றும் 0 ≤ 2 < 3.

சில மொழிகள் மீதியில் எதிர்மறை ஈவுத்தொகையின் அடையாளத்தை வைத்திருக்கின்றன. இந்த கால்குலேட்டர் 0 முதல் மீதியை முழு வகுப்பான் வரை வழங்குகிறது.
