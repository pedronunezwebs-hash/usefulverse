Solucionador d'equacions diferencials

Aproximació d'un problema de valor inicial de primer ordre y′ = f(x,y) amb Runge–Kutta de pas fix 4. Introduïu la derivada, el punt inicial i el valor, el punt final i el recompte de passos. Tot funciona en aquest navegador.

Utilitzeu x i y, nombres, + − × ÷ i ^. Funcions admeses: sin, cos, tan, exp, ln, log, sqrt i abs. Escriu la multiplicació explícitament, com x*y.

RK4 clàssic de pas fix només per a un ODE de valor inicial de primer ordre. Admet fins a 10.000 passos; x ha de romandre dins de ±1.000.000 i y dins de ±1.000.000.000.000. El gràfic i el CSV mostren uns 101 punts mostrejats. Els resultats numèrics poden ser inexactes prop de discontinuïtats, singularitats o per a equacions rígides. No troba solucions generals simbòliques ni certifica errors.

Solució numèrica

Com funciona el solucionador d'equacions diferencials RK4?

RK4 estima la solució utilitzant quatre avaluacions de pendent per pas. Els passos més petits sovint milloren la precisió per a solucions suaus, però aquesta estimació numèrica no és una solució simbòlica o exacta.

Preguntes freqüents

Com funciona el solucionador d'equacions diferencials RK4?

RK4 estima la solució utilitzant quatre avaluacions de pendent per pas. Els passos més petits sovint milloren la precisió per a solucions suaus, però aquesta estimació numèrica no és una solució simbòlica o exacta.

S'han penjat la meva equació i els meus valors?

No. El càlcul, el gràfic i el CSV es creen en aquest navegador. Aquesta eina no carrega ni desa les vostres entrades.

Què calcula el mètode Runge–Kutta?

Estima el camí d'una solució des d'un punt de partida utilitzant repetidament diverses mostres derivades a cada pas. Aquesta pàgina utilitza el mètode clàssic RK de quart ordre.

Quants passos he de fer?

Comenceu amb l'exemple i compareu els resultats amb més passos. Un pas més petit pot millorar una solució suau, però no pot solucionar una singularitat ni fer una equació rígida adequada per a aquest mètode bàsic.

Pot resoldre totes les equacions diferencials exactament?

No. Aproxima numèricament els problemes de valor inicial de primer ordre admesos. No proporciona una solució general simbòlica, no demostra la singularitat ni garanteix un error limitat.
