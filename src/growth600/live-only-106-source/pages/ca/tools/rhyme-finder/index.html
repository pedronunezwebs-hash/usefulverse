Cercador de rimes

Enganxeu un poema, un vers o una llista de paraules per agrupar paraules que comparteixen un final escrit. Trieu quantes lletres finals voleu comparar i si voleu ignorar els accents.

Enganxeu el vostre propi text. Les paraules s'extreuen al vostre navegador.

Opcional: la cafeteria i la cafeteria poden coincidir quan estan habilitades perquè s'ignora la marca sobre é.

Límit: 50.000 caràcters i 5.000 paraules. Els resultats comparen l'ortografia, no la pronunciació.

Resultats

S'han trobat grups: 0

Paraules sense un grup coincident: 0

S'executa localment; el text no es carrega ni es desa.

Com funciona aquest cercador de rimes?

Agrupa paraules fent coincidir les seves lletres escrites finals. No compara la pronunciació, l'accent ni les síl·labes, de manera que una terminació ortogràfica compartida no és una garantia que les paraules rimin quan es pronuncien.

Preguntes freqüents

Com funciona aquest cercador de rimes?

Agrupa paraules fent coincidir les seves lletres escrites finals. No compara la pronunciació, l'accent ni les síl·labes, de manera que una terminació ortogràfica compartida no és una garantia que les paraules rimin quan es pronuncien.

S'han penjat les meves paraules?

No. El text s'analitza en aquest navegador i no es carrega ni es desa.

Comprova això com sonen les paraules?

No. Només compara les terminacions escrites i no utilitza un diccionari de pronunciació ni una transcripció fonètica.

Puc utilitzar paraules de qualsevol idioma?

Sí. S'admeten les lletres Unicode, però els resultats es basen en l'ortografia i és possible que no coincideixin amb la manera en què sonen les paraules en aquest idioma.

Puc enganxar un poema sencer?

Sí. L'entrada local està limitada a 50.000 caràcters i 5.000 paraules.
