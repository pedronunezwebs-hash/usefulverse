PDF Editor d'adreces d'interès

Afegiu una taula de continguts navegable a un PDF o organitzeu les adreces d'interès existents. Creeu seccions imbricades, assigneu destinacions de pàgina, reordena les entrades i deseu una còpia independent al vostre navegador.

Editing crea una còpia PDF nova. Alguns lectors poden mostrar els marcadors de manera diferent; reviseu la còpia desada abans de compartir-la.

Límits locals: 25 MiB d'entrada, 300 pàgines, 500 adreces d'interès, 20 nivells d'imbricació i 50 MiB de sortida. Els fitxers grans poden utilitzar una memòria important del dispositiu; es recomana un ordinador.

Crea destinacions de pàgines internes i entrades d'esquema imbricades. Els enllaços externs existents, les destinacions amb nom o les accions d'adreces d'interès no admeses es rebutgen en lloc de descartar-se en silenci. El contingut de la pàgina no està editat. Les signatures digitals poden no ser vàlides després de desar-les.

Preguntes freqüents

Com afegeixo adreces d'interès a un PDF?

Trieu un PDF i llegiu les adreces d'interès de la pàgina interna admesa. Afegiu o editeu un títol, una pàgina i una secció principal opcional, organitzeu les entrades i deseu una còpia en PDF independent. També podeu importar o exportar l'esquema com a JSON.

S'han penjat els meus PDF o adreces d'interès?

Núm. El document seleccionat es processa en aquest navegador després de triar-lo. UsefulVerse no carrega el PDF ni envia les seves dades de marcador a un servidor.

Les adreces d'interès es poden niar a les seccions?

Sí. Estableix una secció principal per crear una jerarquia. La pàgina del document es manté sense canvis; cada marcador apunta al número de pàgina que trieu.

Conservarà això les adreces d'interès que obren enllaços externs?

Aquest editor actualment admet destinacions de pàgines internes. Rebutja els fitxers amb accions externes no compatibles o amb destinacions anomenades en lloc de deixar-los caure en silenci.

Canvia les pàgines PDF o la signatura?

I edita l'esquema del document i desa una còpia nova, no el contingut de la pàgina. Qualsevol edició pot invalidar una signatura digital, així que comproveu el resultat i no tracteu aquesta eina com a preservació de signatures.
