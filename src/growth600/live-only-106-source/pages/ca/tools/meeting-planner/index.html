Planificador de reunions

Compareu una finestra de disponibilitat diària que es repeteix entre un organitzador i participants en diferents zones horàries. Reviseu cada data i hora local i, a continuació, baixeu una invitació ICS per a una ranura coincident.

S'executa localment. Sense connexió de calendari, sol·licitud d'ubicació, càrrega, compte, API o desament automàtic.

Exemples: Amèrica/Nova_York, Europa/Londres, Àsia/Tòquio. L'organitzador s'inclou automàticament; utilitzeu fins a vuit zones diferents en total.

Les regles d'estiueig provenen de la base de dades de zones horàries d'aquest navegador i poden ser obsoletes. Si es repeteix un temps de retrocés, se selecciona l'ocurrència anterior; s'omet un límit de disponibilitat que no existeix durant una bretxa d'avantguarda de primavera.

Utilitza la mateixa finestra d'hora local diària a cada zona horària. No coneix calendaris individuals, festius, dies laborables ni preferències dels assistents. Trieu un espai real amb tothom abans d'enviar la invitació.

Possibles hores de reunió compartides

No s'han trobat ranures coincidents per a aquestes zones i hores. Prova una finestra més àmplia, un interval de dates diferent o una reunió més curta.

Com puc trobar una hora de reunió entre zones horàries?

Introduïu la zona horària IANA de l'organitzador, les zones dels participants, un interval de dates local, les hores de disponibilitat compartides i la durada de la reunió. El planificador comprova els instants reals amb les finestres de treball locals, inclosos els canvis de data i les compensacions d'estiu.

Preguntes freqüents

Com puc trobar una hora de reunió entre zones horàries?

Introduïu la zona horària IANA de l'organitzador, les zones dels participants, un interval de dates local, les hores de disponibilitat compartides i la durada de la reunió. El planificador comprova els instants reals amb les finestres de treball locals, inclosos els canvis de data i les compensacions d'estiu.

Està connectat amb el meu calendari?

Núm. Tots els càlculs s'executen al vostre navegador. El planificador no inicia sessió, llegeix calendaris, penja la vostra programació ni desa les vostres eleccions.

Comprova la disponibilitat de Google Calendar o Outlook?

Núm. Compara les mateixes hores que introduïu per a cada zona horària. No pot veure les cites, les vacances, els dies laborables ni les preferències personals de ningú.

Compta l'horari d'estiu?

I fa servir la base de dades de fus horari IANA del navegador per convertir cada instant candidat. Una base de dades pot estar obsoleta; verificar les hores de reunió importants amb els participants.

Puc afegir la reunió suggerida a un calendari?

Descarregueu un esdeveniment ICS per a una ranura seleccionada i importeu-lo vosaltres mateixos. L'eina no es connecta ni modifica cap calendari.
