Calculadora de programació lineal

Introduïu un objectiu lineal i fins a vuit restriccions per resoldre un programa lineal de dues variables amb x i y no negatius. El mètode simplex de dues fases informa d'un òptim, d'inviabilitat o il·limitat i mostra cada pivot.

Coeficients objectius (x, y)

Un per línia: a,b <= rhs, a,b >= rhs o a,b = rhs

Utilitza com a màxim vuit restriccions i coeficients/costs dret dins de ±1.000.000. Ambdues variables de decisió tenen x ≥ 0 i y ≥ 0. Utilitzeu una coma entre els coeficients x i y; introduïu una desigualtat o igualtat per línia.

Un solucionador simplex primal de dues fases per a dues variables. La tolerància numèrica s'utilitza per als pivots de coma flotant; problemes gairebé degenerats poden ser sensibles a l'arrodoniment. Es reporten casos inviables, il·limitats i amb límit d'iteració en lloc d'un òptim inventat.

Resultats del programa lineal

El resultat és només per al model matemàtic que heu introduït. No valida si l'objectiu, les restriccions, les unitats o els supòsits són adequats per a una decisió real.

    Com funciona la calculadora simplex de dues variables?

    Converteix les restriccions en un quadre factible, utilitza un objectiu de la Fase I quan és necessari i, a continuació, aplica pivots simples primaris per optimitzar l'objectiu sol·licitat. Les variables x i y estan restringides perquè no siguin negatives.

    Preguntes freqüents

    Com funciona la calculadora simplex de dues variables?

    Converteix les restriccions en un quadre factible, utilitza un objectiu de la Fase I quan és necessari i, a continuació, aplica pivots simples primaris per optimitzar l'objectiu sol·licitat. Les variables x i y estan restringides perquè no siguin negatives.

    S'han penjat el meu objectiu i les meves limitacions?

    No. El solucionador s'executa en aquest navegador. El vostre objectiu i les vostres limitacions no s'envien a un servidor ni es desen amb aquesta eina.

    Quin format he d'utilitzar per a les restriccions?

    Introduïu una fila per línia, com ara 1,1 <= 5 o 2,1 >= 4. El primer nombre multiplica x, el segon multiplica y, i ambdues variables han de ser no negatives.

    Què significa inviable i il·limitat?

    Inviable significa que cap punt compleix totes les restriccions introduïdes. Sense límits significa que una direcció factible permet que l'objectiu sol·licitat continuï millorant sense un òptim finit.

    El resultat demostra que el meu model del món real és correcte?

    No. Només resol les equacions que heu introduït. Comproveu les unitats, els supòsits i si les restriccions descriuen correctament la vostra decisió.
