Generador de taules de reducció

Creeu una taula Markdown en una petita graella editable. Importeu text separat per comes, punt i coma o separat per tabulació, trieu l'alineació de columnes i copieu Markdown sense format amb tubs escapats de manera segura.

S'admeten els camps CSV citats. Importació substitueix la graella actual; fins a 100 files, 20 columnes i 250.000 caràcters.

La primera fila es converteix en la capçalera Markdown. Afegiu almenys una fila i una columna.

Cel·les de taula editables

Crea una taula de canonades estàndard amb una capçalera i una fila separadora. Els trencaments de línia cel·lular es converteixen en <br>; S'escapen les canonades de reducció i les barres invertides.

Tot el processament es manté en aquesta pestanya. Sense càrrega, compte, API, desament automàtic ni processament del servidor.

Com puc fer una taula de Markdown?

Introduïu una fila de capçalera i files de dades, trieu l'alineació de cada columna i copieu el Markdown generat. Les canonades s'escapen i les files importades desiguals s'encoixina.

Preguntes freqüents

Com puc fer una taula de Markdown?

Introduïu una fila de capçalera i files de dades, trieu l'alineació de cada columna i copieu el Markdown generat. Les canonades s'escapen i les files importades desiguals s'encoixina.

S'ha carregat la meva taula?

No. La vostra taula es processa en aquesta pestanya del navegador. La importació, les edicions i el Markdown generat no s'envien a un servidor ni es desen automàticament.

Puc importar CSV o TSV?

Sí. Enganxeu valors separats per comes, punt i coma o separats per tabulacions i, a continuació, importeu-los a la quadrícula editable. S'admeten els camps CSV citats i els separadors entre cometes.

Com es gestionen les canonades i els trencaments de línia?

S'escapa una canonada dins d'una cel·la perquè no divideixi la taula Markdown. Les barres invertides també s'escapen i els salts de línia cel·lular es representen amb <br>.
