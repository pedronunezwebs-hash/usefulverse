Convertidor XML a CSV

Converteix una simple llista de registres XML en una taula CSV o crea registres XML a partir del text d'un fitxer CSV. Trieu la direcció, enganxeu les vostres dades i després copieu o descarregueu el resultat. No s'ha carregat res.

Admet una llista senzilla d'elements de registre del mateix nom o un registre pla. Els fills dels elements han de ser valors escalars; els camps imbricats i repetits no s'aplanen.

Utilitzeu la primera fila per als noms de columnes. Una capçalera com ara @id es converteix en un atribut XML. Utilitzeu #text per gravar el text.

Aquesta és una conversió de taula senzilla, no una conversió de format XML sense pèrdues. Els espais de noms, les estructures imbricades, el contingut mixt, els comentaris i el format XML no es conserven. El text no és conscient de tipus. Els valors CSV semblants a les fórmules de full de càlcul tenen un apòstrofe prefixat per seguretat.

Resultat

Comproveu la sortida abans d'importar-la a una altra aplicació.

Com puc convertir XML a CSV?

Trieu XML a CSV i enganxeu XML amb una llista de registres senzilla. Els elements de registre directe repetits es converteixen en files. Els noms dels elements es converteixen en columnes; els atributs utilitzen @name. Trieu CSV a XML per crear registres XML senzills a partir de capçaleres i files.

Preguntes freqüents

Com puc convertir XML a CSV?

Trieu XML a CSV i enganxeu XML amb una llista de registres senzilla. Els elements de registre directe repetits es converteixen en files. Els noms dels elements es converteixen en columnes; els atributs utilitzen @name. Trieu CSV a XML per crear registres XML senzills a partir de capçaleres i files.

S'ha penjat el meu XML o CSV?

No. L'anàlisi i la conversió s'executen en aquest navegador. L'entrada està limitada a 200.000 caràcters, 5.000 files, 64 columnes i 20.000 cel·les. Es bloquegen les declaracions de DTD i d'entitats i no s'obtenen recursos externs.

Com es mostren els atributs XML en CSV?

Un atribut com id="101" es converteix en una columna anomenada @id. Quan es torna a convertir, una capçalera CSV que comença per @ es converteix en un atribut XML.

Pot convertir XML imbricat en una taula plana?

No. Les estructures fills niuades, els camps repetits dins d'un registre i el text mixt es rebutgen en lloc d'aplanar-se o perdre's en silenci. Utilitzeu un flux de treball XML a JSON dedicat per a les dades imbricades.

El CSV conservarà els tipus i el format XML?

No. CSV emmagatzema text de cel·la, no tipus XML, espais de noms o format. Els valors de cel·les semblants a una fórmula reben un prefix d'apòstrof quan s'exporten per reduir el risc d'execució de fórmules de full de càlcul.
