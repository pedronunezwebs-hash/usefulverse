如何計算箱型圖？

將每個樣本排序，找出其中位數和四分位數，然後計算四分位數間距 (Q3 − Q1)。晶須在 1.5 IQR 範圍內達到最極端的觀測值；超出它們的值顯示為異常值。

我的資料上傳了嗎？

编号 统计数据和图表是在此浏览器中计算的。此工具不會上傳或儲存您的值。

箱型圖中的方格顯示什麼？

此框從第一個四分位數 (Q1) 延伸到第三個四分位數 (Q3)。裡面的線標記中位數，框的長度是四分位數距 (IQR)。鬍鬚顯示圍欄範圍；柵欄之外的點被標記為異常值。

為什麼四分位數結果會不一樣？

有不只一個公認的四分位約定。此計算器會對每種方法進行標記：排除總體中位數的一半中位數、包括整體中位數的一半中位數或使用類型 7 的線性內插。選擇您的類別或分析所需的約定。

異常值是否意味著我應該刪除該值？

否。 1.5×IQR 规则仅标记值以供审核。在決定做什麼之前檢查資料和上下文；異常值可能是有效的觀察。
