常見問題

這個BAC場景是如何運作的？

它將飲料條目轉換為乙醇克數，應用帶有廣泛假設的簡化維德馬克式分佈估計，然後根據經過的時間減去廣泛的說明性消除範圍。它假定立即吸收，無法模擬您的身體或每次飲用的時間。

我的參賽作品上傳了嗎？

否。計算在此瀏覽器中運行。參賽作品不會上傳、儲存或發送到伺服器。

這可以告訴我是否可以安全駕駛嗎？

不。切勿使用計算機來做決定。 BAC 的估計存在很大的不確定性，損害可能會在低於法定限制的情況下開始，並且在最後一次飲酒後酒精可能仍會被吸收。如果你喝酒了，不要開車；安排一次清醒的乘車。

結果是我的實際血液酒精濃度嗎？

否。這是一個簡化的 Widmark 風格的插圖，不是測試或可靠的預測。從這些條目中無法得知身體組成、吸收、食物、健康、藥物、飲酒時間和許多其他因素。

為什麼顯示範圍很大？

分佈和消除假設因人而異。此範圍僅供參考，無法保證實際測量值落在該範圍內。
