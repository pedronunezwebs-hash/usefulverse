盧多遊戲

與兩到四名玩家一起玩當地的盧多競賽遊戲。每次擲骰後選擇一個令牌，使用安全方塊，捕捉對手，並以精確的擲骰到達目的地。

這是本地傳球遊戲或與簡單的電腦對手進行的遊戲。它不是線上多人遊戲。移動保留在此瀏覽器標籤中並且不會儲存。

遊戲狀態

骰子結果: —

休閒規則：六次離開基地；起始方格和星方格是安全的；六、捕捉並準確完成可再次進行擲骰。沒有三重六罰分或封鎖規則。地區規則有所不同。

這個飛行棋遊戲怎麼玩？

選擇兩到四名玩家以及可選的電腦對手。擲骰子；六從底座釋放一個令牌。沿著賽道移動合法標記，避免在不安全的方塊上被捕獲，然後進入主車道。這個隨意的規則集需要精確的擲骰才能完成。

常見問題

這是Ludo遊戲線上多人遊戲嗎？

不。您可以在一台裝置上進行傳遞遊戲，也可以在此瀏覽器中與簡單的機器人對戰。不會上傳動作，無需帳戶或註冊。

我可以跟電腦玩Ludo嗎？

是的。選擇一名或多名本地電腦對手。該機器人使用簡單的合法移動優先級，並且不連接到服務。

這個版本有哪些安全方塊？

每位玩家開始，四個標記的星形方塊是安全的。安全方塊上的代幣無法被捕獲。 Ludo House 規則因地區而異。

令牌是否需要精準擲骰才能完成？

是的。此版本需要準確的數字才能到達最終的家園空間；過衝擲骰不會移動該標記。
