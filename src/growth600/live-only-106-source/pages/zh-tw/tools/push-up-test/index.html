伏地挺身測試與組數追蹤

將單一群組記錄為簡單測試，或記錄多個群組並將其餘群組記錄在其中。您計算並輸入重複次數；工具不會使用您的相機或對您的實力進行排名。

輸入最多 20 個從 0 到 500 的整數計數。空白行將被忽略，並且不計為集合。僅計算您使用所選形式完成的重複次數。

保留一般筆記；這不是醫療記錄。

選擇舒適的活動範圍，如果感到疼痛、頭暈或異常呼吸急促，請停止。重複次數取決於形式、速度和測試條件；該工具不提供健身評級、診斷或運動處方。

儲存是可選的，並且僅使用此瀏覽器。取消勾選即可計算而不儲存，或清除下面已儲存的歷史記錄。

您的會話

伏地挺身測試追蹤器的總重複次數是多少？

它將為每個非空集合輸入的整數重複次數相加。空白行將被忽略，一組零仍為零，其餘估計值是每次中斷的休息乘以中斷數。

常見問題

伏地挺身測試追蹤器的總重複次數是多少？

它將為每個非空集合輸入的整數重複次數相加。空白行將被忽略，一組零仍為零，其餘估計值是每次中斷的休息乘以中斷數。

我的伏地挺身組上傳了嗎？

否。計算在此瀏覽器中運行。只有在您選擇加入後，會話歷史記錄才會寫入此裝置；您可以在這裡刪除它。

空白行算一組還是重複？

否。空行將被忽略。帶有 0 的行記錄零重複集，並且不會將重複添加到總數中。

我可以使用最多一組或多組嗎？

是的。輸入一行用於單一手動計數的集合，或輸入多行以匯總集合以及它們之間的其餘部分。測試條件由您決定；結果未與人口標準進行比較。

我的訓練歷史記錄上傳了嗎？

編號歷史記錄是可選的，並保留在此裝置上的瀏覽器中。隨時使用刪除按鈕將其清除。
