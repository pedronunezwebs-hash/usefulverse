常見問題

如何設定線上鬧鐘？

選擇裝置本地時區的未來日期和時間，然後選擇「設定鬧鐘」。聲音是可選的。您可以先測試一下，小睡五分鐘或鈴聲響起時停止。

關閉頁面後這個警報是否發送資料或運作？

沒有發送或儲存資料。警報僅在此頁面中運行，如果選項卡關閉、瀏覽器暫停或裝置休眠，則無法可靠地向您發出警報。

如果關閉標籤頁，鬧鐘會響嗎？

否。這是頁內警報，而不是作業系統警報或通知。保持頁面開啟且裝置處於喚醒狀態；對於重要提醒，請使用裝置的鬧鐘應用程式。

我可以暫停鬧鐘嗎？

是的。當鈴聲響起時，選擇暫停 5 分鐘以從目前時間重新排程。

警報會使用我的位置還是節省我的時間？

否。它使用您設備上配置的本地時間。警報僅保留在開啟的頁面中，不會上傳或儲存。
