艾森豪威爾矩陣

將任務清單變成四個明確的選擇：執行、安排、委派或刪除。您決定什麼是重要且緊急的；日期是提醒，而不是自動判斷。

使用您自己的上下文對任務進行分類；矩陣並不能決定對您的重要性。資料保留在該標籤的記憶體中，並在您關閉或重新載入時清除，除非您匯出備份。匯入僅接受此工具的 JSON 備份，最多 1 MB 和 300 個任務。

重要意味著它對您關心的目標、責任或結果產生有意義的影響。

緊急意味著由於真正的截止日期或後果而需要盡快關注；僅僅截止日期並不能決定重要性。

先做

緊急且重要：立即採取行動。

    時間表

    重要，不緊急：在事情變得緊急之前預留時間。

      代表

      緊急，不太重要：在適當的時候將其移交並追蹤後續行動。

        考慮刪除

        既不緊急也不重要：將其刪除或從您的計劃中刪除。

          如何使用艾森豪威爾矩陣？

          為每項任務選擇四個像限之一：緊急且重要的任務、重要但不緊急的日程安排、緊急但不那麼重要的委派任務，或者兩者都不考慮放棄。您可以隨時變更任務的象限。

          常見問題

          如何使用艾森豪威爾矩陣？

          為每項任務選擇四個像限之一：緊急且重要的任務、重要但不緊急的日程安排、緊急但不那麼重要的委派任務，或者兩者都不考慮放棄。您可以隨時變更任務的象限。

          我的艾森豪威爾矩陣任務是私有的嗎？

          任務保留在此瀏覽器標籤中，不會自動上傳或儲存。如果您想保留 JSON 備份，請匯出它們，並稍後在此裝置上匯入該檔案。

          艾森豪威爾矩陣每個象限都有什麼？

          先做緊急、重要的工作。安排重要但不緊急的工作。當其他人可以處理時，將不太重要的緊急工作委託給他人。考慮放棄既不緊急也不重要的任務。

          截止日期是否會自動使任務變得緊急或重要？

          否。截止日期可以幫助您判斷緊急程度，但您根據實際的截止日期、後果和目標來決定緊急程度和重要性。
