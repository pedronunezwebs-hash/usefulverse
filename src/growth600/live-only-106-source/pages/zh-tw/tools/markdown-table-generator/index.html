Markdown 表格產生器

在小型可編輯網格中建立 Markdown 表格。匯入逗號分隔、分號分隔或製表符分隔的文本，選擇列對齊方式，並複製純 Markdown 並安全轉義管道。

支援引號的 CSV 欄位。匯入替換目前網格；最多 100 行、20 列和 250,000 個字元。

第一行成為 Markdown 標題。新增至少一行和一列。

可編輯表格儲存格

建立具有標題行和分隔行的標準管道表。細胞系斷裂變成<br>； Markdown 管路和反斜線被轉義。

所有處理都在此標籤中進行。沒有上傳、帳戶、API、自動儲存或伺服器處理。

常見問題

如何製作 Markdown 表格？

輸入標題行和資料行，選擇每列對齊方式，然後複製產生的 Markdown。管道被轉義，並且不均勻的導入行被填滿。

我的表格上傳了嗎？

否。您的表格將在此瀏覽器標籤中處理。匯入、編輯和產生的 Markdown 不會傳送到伺服器或自動儲存。

我可以匯入 CSV 或 TSV 嗎？

是的。貼上以逗號分隔、分號分隔或製表符分隔的值，然後將它們匯入可編輯網格中。支援引號的 CSV 欄位和引號的分隔符號。

管路和斷線如何處理？

單元格內的管道被轉義，因此它不會拆分 Markdown 表。反斜線也被轉義，單元格換行符用 <br> 表示。
