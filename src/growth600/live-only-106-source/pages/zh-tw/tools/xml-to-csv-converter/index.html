XML 到 CSV 轉換器

將簡單的 XML 記錄清單轉換為 CSV 表，或從 CSV 檔案的文字建立 XML 記錄。選擇方向，貼上數據，然後複製或下載結果。沒有上傳任何內容。

支援同名記錄元素的簡單列表，或平面記錄。元素子元素必須是標量值；嵌套和重複欄位不會被展平。

使用第一行作為列名稱。 @id 等標頭成為 XML 屬性。使用 #text 記錄文字。

這是簡單的表格轉換，而不是無損 XML 格式轉換。命名空間、巢狀結構、混合內容、註解和 XML 格式都不會保留。文字不識別類型。為了安全起見，類似電子表格公式的 CSV 值帶有撇號前綴。

如何將 XML 轉換為 CSV？

選擇 XML 到 CSV 並貼上帶有簡單記錄清單的 XML。重複的直接記錄元素成為行。元素名稱變成列；屬性使用 @name。選擇 CSV 到 XML 從標題和行建立簡單的 XML 記錄。

常見問題

如何將 XML 轉換為 CSV？

選擇 XML 到 CSV 並貼上帶有簡單記錄清單的 XML。重複的直接記錄元素成為行。元素名稱變成列；屬性使用 @name。選擇 CSV 到 XML 從標題和行建立簡單的 XML 記錄。

我的 XML 或 CSV 上傳了嗎？

否。在此瀏覽器中執行解析和轉換。輸入限制為 200,000 個字元、5,000 行、64 列和 20,000 個儲存格。 DTD 和實體聲明被阻止，並且無法取得外部資源。

XML 屬性如何在 CSV 中顯示？

諸如 id="101" 之類的屬性將成為名為 @id 的欄位。轉換回來時，以 @ 開頭的 CSV 標頭將成為 XML 屬性。

可以將巢狀XML轉換為平面表嗎？

否。嵌套子結構、記錄內的重複欄位和混合文字將被拒絕，而不是被展平或默默遺失。對嵌套資料使用專用的 XML 到 JSON 工作流程。

CSV 會保留 XML 類型和格式嗎？

否。 CSV 儲存單元格文本，而不是 XML 類型、命名空間或格式。類似公式的儲存格值在匯出時會帶有撇號前綴，以降低電子表格公式執行風險。
