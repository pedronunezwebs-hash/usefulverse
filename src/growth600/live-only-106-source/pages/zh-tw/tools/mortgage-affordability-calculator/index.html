常見問題

我如何估算自己能買得起多少房子？

輸入每月總收入、每月債務、總債務與收入限額、房屋成本假設。該估計解決了模型每月債務和住房成本與該限制相符的價格。

我的收入或債務詳細資料已上傳嗎？

沒有。該計算在您的瀏覽器中運作；您輸入的值不會由該工具上傳或儲存。

每月的住房預算包含哪些費用？

本金和利息、預估財產稅、房屋保險、HOA 或公寓費用，以及您輸入的任何每月抵押貸款保險金額。估算不包括維護、公用事業或關閉費用。

這個估計是否意味著貸方會批准我？

沒有。這是基於您的假設的算術，而不是貸款人的決定。貸款人可以審查信用、資產、就業、貸款條款、財產詳細資訊和其他規則。

為什麼每月債務金額較高會降低房價預估？

所選的總債務與收入限額由住房成本及其他債務支付分擔。每月債務越多，住房模型預算越少。
