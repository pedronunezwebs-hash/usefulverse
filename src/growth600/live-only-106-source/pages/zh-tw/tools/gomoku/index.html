五子棋

將黑色和白色石子放在 15×15 的棋盤上。水平、垂直或對角連續五個或更多即可獲勝。在此設備上與朋友比賽或挑戰基本的本地對手。

规则 自由式五子棋：連續五子或五子以上獲勝。本地對手使用小型啟發式搜索，而不是錦標賽強度搜索。遊戲狀態保留在此標籤中，並在重新載入時清除。

如何在五子棋中獲勝？

輪流將一顆石頭放在空的十字路口上。第一個在任何方向上連續擲出五個或更多棋子的玩家獲勝。這個版本使用自由式規則：上劃線也獲勝。

常見問題

如何在五子棋中獲勝？

輪流將一顆石頭放在空的十字路口上。第一個在任何方向上連續擲出五個或更多棋子的玩家獲勝。這個版本使用自由式規則：上劃線也獲勝。

我可以在不下載任何東西的情況下玩五子棋嗎？

是的。棋盤和本地對手在此瀏覽器中運行。遊戲不會上傳或自動儲存。

一條線必須剛好是五顆棋子嗎？

不可以。本游戏采用自由式规则：水平、垂直或对角方向连续五个或更多棋子获胜。

我可以跟電腦對上五子棋嗎？

是的。本地電腦檢查即時勝利和攔網，然後對附近的空位得分。這是一個簡單的對手，而不是高級或錦標賽級別的人工智慧。

五子棋可以與兩名玩家一起玩嗎？

是的。選擇兩人模式在同一裝置上輪流玩。沒有線上多人遊戲或自動遊戲保存。
