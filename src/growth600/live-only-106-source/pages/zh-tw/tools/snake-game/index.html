常見問題

貪吃蛇遊戲怎麼玩？

開始回合，使用 arrow keys、WASD 或觸控按鈕轉向食物，並避開牆壁和您的身體。隨時暫停。吃食物會使蛇長大加一分。

貪食蛇遊戲會保存我的分數還是使用帳號？

無需帳戶或下載。您當前的分數和會話最好僅保留在此 tab 中；您離開後，它們不會上傳或保存。

可以在手機或tablet上玩嗎？

是的。使用螢幕上的方向按鈕。帶有 arrow keys 或 WASD 的鍵盤也可以在電腦上使用。

可以暫停遊戲嗎？

是的。隨時選擇暫停；蛇會停止移動，直到您恢復為止。

我每次都會得到相同的遊戲嗎？

棋盤佈局保持熟悉，但每輪新的食物位置都是隨機的。您離開後，不會保存當前和最好的會話分數。
