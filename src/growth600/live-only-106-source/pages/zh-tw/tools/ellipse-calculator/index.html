橢圓計算器

輸入橢圓的兩個半軸以找到其面積、焦距、偏心率和清晰標記的周長近似值。

以同一單位輸入正半軸長度，最多 1,000,000,000。面積使用該單位的平方。週長使用拉馬努金的第二近似值，而不是精確的初等公式。

橢圓屬性

面積 = πab。中心到焦點距離 c = √(A² − B²)，其中 A 是長半軸，B 是短半軸。偏心率 e = c/A。 Perimeter 使用 Ramanujan II，其中 h = ((A − B)/(A + B))²。

橢圓計算器可以找到什麼？

給定兩個正半軸，它識別長軸和短軸，計算面積和焦距，並使用拉馬努金的第二近似值估計週長。

常見問題

橢圓計算器可以找到什麼？

給定兩個正半軸，它識別長軸和短軸，計算面積和焦距，並使用拉馬努金的第二近似值估計週長。

我的測量結果上傳了嗎？

否。幾何圖形在此瀏覽器中計算。您的值不會傳送到伺服器或由該工具儲存。

如何計算橢圓的面積？

将 π 乘以长半轴和短半轴。如果 a 和 b 是半軸，則面積為 πab。

橢圓週長準確嗎？

不。一般橢圓週長沒有簡單的基本封閉形式。該工具使用拉馬努金的第二近似值並將其標記為近似值。

焦點和偏心率是什麼意思？

兩個焦點位於主軸上，與中心的距離相等。偏心率範圍從 0（表示圓形）到 1（表示逐漸拉長的橢圓）。
