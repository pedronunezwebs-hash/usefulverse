貼上詩歌、詩句或單字列表，將共享書面結尾的單字分組。選擇要比較的最終字母數量以及是否忽略重音符號。

貼上您自己的文字。單字將在您的瀏覽器中提取。

這個韻律查找器如何運作？

它透過匹配最終的書面字母來將單字分組。它不會比較發音、重音或音節，因此共享的拼字結尾並不能保證單字在發音時押韻。

常見問題

這個韻律查找器如何運作？

它透過匹配最終的書面字母來將單字分組。它不會比較發音、重音或音節，因此共享的拼字結尾並不能保證單字在發音時押韻。

我的話上傳了嗎？

否。文字在此瀏覽器中進行分析，不會上傳或儲存。

這個可以檢查單字的發音嗎？

否。僅比較書面詞尾，不使用發音字典或音標。

我可以使用任何語言的單字嗎？

是的。支援 Unicode 字母，但結果是基於拼寫，可能與該語言中單字的發音不符。

我可以貼整首詩嗎？

是的。本地輸入限制為 50,000 個字元和 5,000 個單字。
