向量預覽

如何將影像變成SVG？

選擇一個光柵影像，選擇其輸出細節和色彩計數，然後建立 SVG。該工具將彩色像素軌跡分組為真實的向量路徑；邊緣遵循選定的像素網格，因此平面藝術品比照片效果更好。

常見問題

如何將影像變成SVG？

選擇一個光柵影像，選擇其輸出細節和色彩計數，然後建立 SVG。該工具將彩色像素軌跡分組為真實的向量路徑；邊緣遵循選定的像素網格，因此平面藝術品比照片效果更好。

我的圖片上傳了嗎？

否。圖像在此瀏覽器標籤中進行解碼和追蹤。它不會上傳或自動儲存。

SVG 是否包含原始影像？

否。結果包含 SVG 路徑形狀，而不是嵌入的光柵影像。它透過將像素分組為顏色和路徑來近似來源。

它能順利地向量化照片嗎？

否。像素網格軌跡適用於簡單的標誌、圖示和純色繪圖。照片可以產生塊狀邊緣和大型 SVG 檔案。

該工具是否上傳或保留我的映像？

否。來源在此選項卡中進行處理，不會上傳或自動儲存。處理速度和記憶體使用取決於您的裝置。
