PDF 元資料編輯器

閱讀或編輯 PDF 中儲存的常見文件訊息，然後下載單獨的副本。所選 PDF 保留在此裝置上。

保留原件。重新儲存可能會使數位簽章無效或影響進階 PDF 功能。此工具不會刪除隱藏資訊或驗證隱私。

本地限制：25 MiB 輸入、300 頁和 50 MiB 輸出。大文件可能需要更多記憶體；建議使用電腦。

僅編輯標準 PDF 文件資訊。不支援 XMP、自訂元資料、附件、隱藏內容和簽名驗證。

我可以更改哪些 PDF 元資料？

此工具編輯標準文件資訊欄位：標題、作者、主題、關鍵字、創建者、製作者、建立日期和修改日期。它不編輯 XMP 元資料或自訂屬性。

常見問題

我可以更改哪些 PDF 元資料？

此工具編輯標準文件資訊欄位：標題、作者、主題、關鍵字、創建者、製作者、建立日期和修改日期。它不編輯 XMP 元資料或自訂屬性。

我的PDF上傳了嗎？

否。選擇檔案後，在瀏覽器中進行讀取和編輯。原始文件沒有改變；儲存會建立單獨的 PDF 副本。

這是否會從 PDF 中刪除所有元資料？

否。僅編輯標準 PDF 文件資訊字典中的常用條目。 XMP、自訂屬性、嵌入檔案和其他隱藏內容可能會保留。

編輯元資料會保留數位簽章嗎？

不要依賴它。儲存會重寫 PDF，並可能使現有數位簽章失效或影響此工具不支援的功能。保留原件並驗證副本。

原PDF是否被覆蓋？

否。該工具讀取所選檔案並建立單獨的可下載副本。它不會修改您裝置上的原始版本。
