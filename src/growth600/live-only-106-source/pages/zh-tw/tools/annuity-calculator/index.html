年金計算器

對具有起始金額、費率和時間表的等額支付流進行建模。結果是估計值，而不是報價或財務建議。

假設固定名目年利率除以支付頻率；不包括費用、稅金和變動費率。

結果

年金計算器如何運作？

將固定名目年利率除以支付頻率應用於一系列等額支付。普通付款發生在每個期間結束時；年金到期付款發生在開始時。它不會對費用、稅金、可變利率或特定保險公司的合約進行建模。

常見問題

年金計算器如何運作？

將固定名目年利率除以支付頻率應用於一系列等額支付。普通付款發生在每個期間結束時；年金到期付款發生在開始時。它不會對費用、稅金、可變利率或特定保險公司的合約進行建模。

我的值上傳了嗎？

否。計算在此瀏覽器標籤中運行，並且此工具不會上傳或保存值。

目前價值和未來價值有什麼不同？

現值估計支付流現在的價值。未來價值估計初始餘額和經常性捐款在計劃結束時如何累積。

這是否預測年金合約支付？

否。這是根據您輸入的假設進行的一般算術。實際產品可能包括此計算器未模擬的費用、保固、稅金和條款。
