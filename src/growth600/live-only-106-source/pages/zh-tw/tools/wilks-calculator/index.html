Wilks 與 DOTS 力量舉重計算器

輸入舉重者體重和舉重總成績或單次舉重成績。選擇一個命名的評分模型以查看可比較的分數；每個模型都單獨顯示。

型號不可互換，並且可以對舉昇機進行不同的排名。選擇模型發布表所需的係​​數組；這是一個公式設置，而不是一個身份標籤。為了公平比較，請使用相同賽事形式（全部舉重或相同單次舉重）、單位和模型的結果。這不是聯合會的官方結果或比賽排名的預測。

分數預估

僅比較估計。不是目前的官方 IPF Goodlift 分數。使用相同的模型、係數組和事件格式比較結果；規則和模型適用性各不相同。

Wilks 或 DOTS 分數是如何計算的？

每個模型將其發布的體重係數應用於輸入的體重，然後按該模型的分母對輸入的升力結果進行縮放。只有當使用相同的公式、係數群組和事件類型時，結果才具有可比性。

常見問題

Wilks 或 DOTS 分數是如何計算的？

每個模型將其發布的體重係數應用於輸入的體重，然後按該模型的分母對輸入的升力結果進行縮放。只有當使用相同的公式、係數群組和事件類型時，結果才具有可比性。

我的號碼是否已上傳或已儲存？

否。計算在此瀏覽器中運行；輸入的值不會上傳或保存。

Wilks、Wilks-2 和 DOTS 有什么区别？

它们是单独的体重调整模型，具有不同的公布系数。它們的分數不可互換，並且兩種型號可以以不同的方式訂購舉重器。

这是官方的 IPF 分数吗？

編號。此計算器顯示 Wilks、Wilks-2 和 DOTS 估計值。 IPF比賽採用現行的聯合會評分系統及其規則；檢查組織者的官方結果。

我可以將臥推結果與完整的舉重總成績進行比較嗎？

兩位運動員使用相同的賽事形式。此算術可以根據任一輸入計算得分，但將單次舉重與三次舉重的總分進行比較並不是同類競爭的比較。
