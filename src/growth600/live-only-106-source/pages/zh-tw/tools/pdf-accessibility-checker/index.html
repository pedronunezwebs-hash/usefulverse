PDF 輔助使用檢查器

在本機檢查 PDF 中是否有一些機器可偵測的輔助功能訊號，包括文件標籤、元資料、可選文字、沒有替代文字的圖形以及標題級跳轉。這只是初步檢查器，不是 PDF/UA 驗證器或輔助技術測試的替代品。

最大 25 MiB 和 300 頁。檢查可能會使用設備記憶體；對於大文件，建議使用電腦。

Inspection 將在您的裝置上運作。沒有上傳、帳戶、API、自動儲存或伺服器處理。

這些檢定是啟發式的。他們無法確認正確的閱讀順序、有意義的描述、顏色對比、鍵盤使用、表單標籤、表頭關係或 PDF/UA/Section 508/WCAG 一致性。手動檢查並使用輔助技術進行測試。

檢定報告

PDF 輔助使用檢查器可以偵測什麼？

它報告 PDF 是否公開結構標籤、文件標題和語言、每頁上的可選文字、帶有替代文字的圖形以及標題層級中可能的跳躍。它無法決定閱讀順序或替代文字是否有意義。

我的PDF是否已上傳以供檢查？

否。在此瀏覽器標籤中檢查所選 PDF。文件及其文字不會上傳、自動儲存或傳送到伺服器。

陽性結果是否意味著 PDF 可以存取？

否。這些只是有限的自動訊號。標籤的 PDF 仍然可能存在閱讀順序不正確、描述不清晰、表格無法存取、對比度低或其他障礙。仍然需要手動和輔助技術測試。

能否確認 PDF/UA 或 WCAG 合規性？

否。此首次檢查程序不會測試所有要求，且無法證明 PDF/UA、WCAG、第 508 節或法律合規性。
