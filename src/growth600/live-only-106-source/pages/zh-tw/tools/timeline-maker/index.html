將里程碑或歷史事件轉變為清晰的按時間順序排列的時間表。為每個事件新增單一日期或開始和結束日期。

如何製作事件時間表？

新增至少兩個命名事件並為每個事件選擇開始日期。新增持續時間的結束日期，或對於單日事件將其留空。建立時間軸以按日期對事件進行排序、調整縮放以及下載 SVG 或 CSV 檔案。

常見問題

如何製作事件時間表？

新增至少兩個命名事件並為每個事件選擇開始日期。新增持續時間的結束日期，或對於單日事件將其留空。建立時間軸以按日期對事件進行排序、調整縮放以及下載 SVG 或 CSV 檔案。

我的時間軸事件上傳了嗎？

否。姓名和日期在此瀏覽器標籤中處理。 SVG 和 CSV 在您的裝置上產生；不會自動上傳或儲存任何內容。

活動可以持續超過一天嗎？

是的。輸入開始日期和結束日期。此圖表包括兩個終點日期；對於單日活動，請將末端留空。

此時間軸是否會建立任務依賴性？

編號 它會依時間順序顯示日期事件和範圍。使用專案進度工具來確定任務、持續時間和依賴性。

我可以儲存或分享時間軸嗎？

下載可縮放影像的 SVG 或事件表的 CSV。該頁面不會上傳或自動儲存您的事件資料。
