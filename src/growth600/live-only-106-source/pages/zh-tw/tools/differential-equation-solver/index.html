微分方程求解器

使用固定步長 Runge-Kutta 近似一階初始值問題 y′ = f(x,y) 4. 輸入導數、起點和值、終點以及步數。一切都在這個瀏覽器中運行。

使用 x 和 y、數字、+ − × ÷ 和 ^。支援的函數：sin、cos、tan、exp、ln、log、sqrt 和 abs。明確地寫出乘法，例如 x*y。

僅適用於一階初始值 ODE 的固定步長經典 RK4。支援多達10000步； x 必須保持在 ±1,000,000 範圍內，y 必須保持在 ±1,000,000,000,000 範圍內。圖表和 CSV 顯示最多約 101 個採樣點。在不連續點、奇異點或剛性方程式附近，數值結果可能不準確。它沒有找到符號通用解決方案或證明錯誤。

數值解

RK4微分方程求解器如何運作？

RK4 每步驟使用四個斜率評估來估計解。較小的步長通常可以提高平滑解的準確性，但這種數值估計不是符號解或精確解。

常見問題

RK4微分方程求解器如何運作？

RK4 每步驟使用四個斜率評估來估計解。較小的步長通常可以提高平滑解的準確性，但這種數值估計不是符號解或精確解。

我的方程式和值是否已上傳？

否。計算、圖表和 CSV 在此瀏覽器中建立。該工具不會上傳或儲存您的輸入。

龍格-庫塔法計算什麼？

透過在每一步重複使用多個導數樣本，從起點估計解的路徑。本頁使用經典的四階RK方法。

我應該使用多少步驟？

從範例開始，並使用更多步驟比較結果。較小的步長可以改善平滑解，但無法修復奇點或使剛性方程式適合此基本方法。

能準確求解每個微分方程式嗎？

否。它在數值上近似支持的一階初始值問題。它不提供符號通用解決方案、證明唯一性或保證誤差範圍。
