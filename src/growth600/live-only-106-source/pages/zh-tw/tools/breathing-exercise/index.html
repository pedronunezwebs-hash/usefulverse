常見問題

如何使用此呼吸練習？

選擇預設或設定每個階段，選擇練習時長，然後點選「開始」。隨時可以暫停或重設。音訊為可選，僅在開始後播放。

我的呼吸練習會被上傳嗎？

不會。計時在此頁面進行。無需註冊、上傳、API 或儲存練習。

我可以使用方框呼吸法或 4-7-8 呼吸法嗎？

可以。選擇預設呼吸法或調整各階段時長。這些是呼吸節奏引導，不是醫療治療。

關閉分頁後，計時會繼續嗎？

無法保證。瀏覽器可能暫停背景分頁，裝置也可能進入睡眠模式。為了更準確計時，請保持此頁面開啟且裝置處於喚醒狀態。

我可以關閉聲音或提前停止嗎？

可以。聲音是可選的，開始後才會播放，也可以取消勾選。按「暫停」或「重設」會立即停止計時。
