PDF頁面尺寸轉換器

將 PDF 中的每個頁面調整為 A4、US Letter、Legal 或自訂紙張尺寸。預覽新尺寸，適合整個原始頁面區域，然後下載在您的裝置上處理的單獨副本。

調整大小會建立一個單獨的副本。重新儲存可能會使數位簽章失效。分享前保留原件並檢查新的 PDF。

本地限制：25 MiB 輸入、300 頁和 50 MiB 輸出。大檔案可能會佔用大量記憶體；建議使用電腦。

為了避免靜默更改，此工具拒絕旋轉頁面、自訂頁框、註解、連結和互動式表單。適合模式會縮放整個現有頁面矩形，並且無法恢復已超出其邊界的內容。

如何改變 PDF 的頁面大小？

選擇 PDF，檢查其頁面，選擇 A4、Letter、Legal 或自訂尺寸，然後選擇適合頁面或實際尺寸。適合模式按比例縮放並將每個完整頁面區域置中。下載新副本並保留原始副本。

常見問題

如何改變 PDF 的頁面大小？

選擇 PDF，檢查其頁面，選擇 A4、Letter、Legal 或自訂尺寸，然後選擇適合頁面或實際尺寸。適合模式按比例縮放並將每個完整頁面區域置中。下載新副本並保留原始副本。

我的 PDF 是否已上傳以調整其大小？

編號選擇 PDF 後，將在此瀏覽器中處理。它不是由 UsefulVerse 上傳或保存的。大型 PDF 可以使用裝置記憶體；建議使用電腦。

我可以將 PDF 大小調整為 A4 或 US Letter 嗎？

Y 是的。選擇 A4、US Letter 或 US Legal，選擇縱向或橫向，然後預覽結果。自訂尺寸也可以以毫米或英吋為單位輸入。

調整大小會裁切 PDF 內容嗎？

Fit 模式統一縮放完整的原始頁面矩形並將其置於新紙張的中心。它不是故意裁剪的。無法復原原始 PDF 頁面邊界以外的內容。

這是否保留連結、表格或數位簽章？

此工具拒絕帶有註釋、連結、互動欄位、旋轉或自訂頁面框的頁面，而不是默默地刪除它們。儲存 PDF 可能會使數位簽章失效；保留並查看原件。
