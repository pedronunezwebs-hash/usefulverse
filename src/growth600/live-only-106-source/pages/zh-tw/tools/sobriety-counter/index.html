常見問題

清醒日计数器如何工作？

它计算从您输入的日期到今天的整个日历日。所選的開始日期本身是零天；後來的日期使用僅日期算術，因此夏令時不會添加或刪除一天。

我的清醒日期是否已上傳或已儲存？

未上傳資料。您的日期僅在此瀏覽器中使用。只有當您明確選擇加入時，註釋或日期才能保存在此裝置上，並且您可以隨時清除本機記錄。

開始日期算第一天嗎？

否。選擇的開始日期是零天。下一個日曆日期是一天後。

這個櫃檯可以提供復健或醫療建議嗎？

否。它計算日曆天數並僅顯示里程碑。它不評估健康、物質使用、治療或個人進步。

日期和註解是否有傳送到伺服器？

否。計算在您的瀏覽器中運行。保存是可選的，並在該裝置上的瀏覽器中儲存一條小記錄；你可以在這裡清除它。
