網站地圖驗證器

貼上網站地圖 XML 文件以檢查其結構、URL 條目、日期和公共欄位。 XML 僅在該瀏覽器中進行解析；永遠不會取得列出的頁面。

支持标准 urlset 或 sitemapindex。最多 1,000,000 個字元和 5,000 個直接條目。

僅本機 XML 檢查：這不會要求列出的 URL、抓取網站、提交網站地圖或保證索引。

調查結果

    該網站地圖驗證器檢查什麼？

    它檢查 urlset 或 sitemapindex 條目、絕對 HTTP 或 HTTPS 位置、重複的規範化 URL、lastmod 日期、可選的更改頻率和優先值以及網站地圖命名空間。警告和錯誤按條目號列出。

    常見問題

    該網站地圖驗證器檢查什麼？

    它檢查 urlset 或 sitemapindex 條目、絕對 HTTP 或 HTTPS 位置、重複的規範化 URL、lastmod 日期、可選的更改頻率和優先值以及網站地圖命名空間。警告和錯誤按條目號列出。

    它會上傳或提交我的網站地圖嗎？

    不會。 XML 在您的瀏覽器中本機處理。該工具不會抓取 URL、取得遠端網站地圖檔案、向搜尋引擎提交任何內容或確認索引。

    這是否檢查網站地圖 URL 是否有效？

    不會。它會檢查 URL 語法並在貼上的 XML 中重複，但故意不要求 URL 或抓取網站。

    有效的網站地圖是否意味著 Google 對其頁面建立了索引？

    不。 XML 驗證不是搜尋引擎提交或索引報告。透過相關搜尋引擎站長工具提交網站地圖並檢查其自身狀態。

    我可以驗證網站地圖索引嗎？

    是的。該工具檢查直接 sitemapindex 條目及其 loc 和 lastmod 字段，但不會下載或遞歸檢查引用的網站地圖檔案。
