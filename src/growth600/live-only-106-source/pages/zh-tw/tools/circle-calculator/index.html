圓計算器

根據半徑、直徑、面積或週長計算圓。探索圓心角弧和扇形測量，或計算圓弧及其弦和弧矢。

使用 0 至 360 度的角度。公式將其轉換為弧度。

使用精確的圓公式，JavaScript 值為 π；顯示的小數點被四捨五入。圓弧段使用選定的圓心角：低於 180° 為次弧段，高於 180° 為主弧段。輸入限制為最多 10^2 的正值和 0° 到 360° 的角度。

結果

如何計算圓？

對於半徑 r，直徑為 2r，週長為 2πr，面積為 πr²。對於以弧度表示的圓心角 θ，弧長為 rθ，扇形面積為 r²θ/2。對於這些公式，計算器將輸入的角度（以度為單位）轉換為弧度。

常見問題

如何計算圓？

對於半徑 r，直徑為 2r，週長為 2πr，面積為 πr²。對於以弧度表示的圓心角 θ，弧長為 rθ，扇形面積為 r²θ/2。對於這些公式，計算器將輸入的角度（以度為單位）轉換為弧度。

我的測量結果是否已上傳？

否。公式在此瀏覽器中運行，並且此工具不會上傳或保存您的測量結果。

半徑為1的圓的面積和周長是多少？

面積為π（約3.14159），週長為2π（約6.28318）。結果經過四捨五入後顯示。

如何計算弧長？

將半徑乘以中心角（以弧度表示）。該工具接受度數並在計算之前對其進行轉換。

扇區和段有什麼差別？

扇形由兩個半徑和一個圓弧界定。線段以弦及其弧為界；這裡它的面積是根據圓心角計算的。
