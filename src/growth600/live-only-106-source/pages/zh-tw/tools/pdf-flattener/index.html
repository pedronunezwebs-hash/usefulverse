PDF 表單拼合器

製作單獨的 PDF 副本，其中受支援的 AcroForm 欄位會平鋪到其可見頁面外觀中。頁面上的文字仍然是可選擇和可搜尋的。

扁平化會刪除新副本中的表單互動性。保留你的原件。現有的數位簽章可能會失效或被刪除；這不是簽章驗證工具。

本地限制：25 MiB 輸入、300 頁、2,500 個欄位和 50 MiB 輸出。可能不支援複雜、加密或 XFA 表單。對於大文件，建議使用計算機。

僅支援的 AcroForm 欄位會被展平。其他評論、突出顯示、連結、標記、元資料和可訪問性結構不會被扁平化或保證保持不變。

拼合 PDF 表單有什麼作用？

它將支援的互動式表單欄位外觀繪製到頁面內容中，並從新副本中刪除這些互動式欄位。這不會展平一般註釋、連結、標記或其他標記註釋。

常見問題

拼合 PDF 表單有什麼作用？

它將支援的互動式表單欄位外觀繪製到頁面內容中，並從新副本中刪除這些互動式欄位。這不會展平一般註釋、連結、標記或其他標記註釋。

我的PDF上傳了嗎？

否。處理在此瀏覽器中運行。您選擇的 PDF 不會傳送到伺服器或自動儲存。

我仍然可以編輯拼合副本中的欄位嗎？

否。受支援的欄位將成為頁面外觀的一部分，並且不再具有互動性。如果以後需要編輯，請保留原件。

這是否會扁平化註釋、突出顯示或數位簽名？

否。此工具僅針對受支援的 AcroForm 欄位。其他標記註釋不會被展平，並且數位簽名可能會透過編輯而失效或刪除。請勿將其用於經過認證或合法簽署的文件。

頁面文字仍可搜尋嗎？

頁面內容未轉換為圖像，因此現有頁面文字仍可搜尋。表單欄位的外觀被扁平化為頁面內容。
