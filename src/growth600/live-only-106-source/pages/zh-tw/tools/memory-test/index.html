這個記憶體測試會保存我的分數嗎？

否。開啟時，序列和分數保留在該頁面中。沒有上傳任何內容，也沒有帳戶或線上排名。

這個記憶體測試測量什麼？

這是一款休閒序列回憶練習遊戲。它沒有標準化，無法診斷疾病或測量智商。

數字跨度和模式模式有何不同？

數字範圍一次顯示一位數字，並宣布它們以供螢幕閱讀器存取。圖案模式會在 3×3 網格上閃爍位置，並且需要視線。

分數是否保存或與其他人比較？

否。僅當此頁面保持開啟狀態時，分數才存在。沒有排行榜、帳戶或伺服器上傳。
