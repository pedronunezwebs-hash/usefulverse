泰勒級數計算器

選擇初等函數、展開中心、度數和評價點。檢查每個係數、多項式估計值及其逐點誤差。

支援的函數：eˣ、sin(x)、cos(x)、ln(x)、1/x 和 √x。順序 0–30；輸入限制為±50。三角函數輸入使用弧度。

泰勒多項式結果

對於 ln(x)、√x 和 1/x，泰勒級數在選定中心周圍具有有限的收斂半徑。多項式仍然可以在其外部進行計算，但可能無法很好地逼近該函數。

逐點差為 |f(x) − Pₙ(x)|。它不是整個區間的最大誤差估計或正式的餘數界。

泰勒級數計算器顯示什麼？

它根據選定中心的導數建構有限泰勒多項式。報告的誤差是您所選點的絕對差值，而不是某個時間間隔內的保證誤差範圍。

常見問題

泰勒級數計算器顯示什麼？

它根據選定中心的導數建構有限泰勒多項式。報告的誤差是您所選點的絕對差值，而不是某個時間間隔內的保證誤差範圍。

我的價值觀上傳了嗎？

否。多項式和比較是在這個瀏覽器中計算的；您的值不會上傳或保存。

什麼是麥克勞林多項式？

以零為中心的泰勒多項式。此計算器可讓您選擇零或其他有效中心。

顯示的差異能否保證整個時間間隔內的準確度？

否。這是您單一評估點的絕對差異。跨區間的餘數界需要額外的導數界和條件。

為什麼多項式在收斂半徑之外會很差？

可以在那裡計算有限多項式，但對數、平方根和倒數函數的無限泰勒級數僅在其圍繞中心的半徑內收斂。
