Creatore di alberi genealogici

Crea un grafico familiare partendo dalle informazioni che già conosci. Aggiungi persone, collega i collegamenti principali, quindi esporta un diagramma o un file GEDCOM. La pagina non effettua ricerche nei documenti né salva i dati della tua famiglia.

I dettagli familiari possono essere sensibili. I dati rimangono in memoria finché non chiudi o reimposti questa pagina; le esportazioni possono contenere informazioni private.

Albero genealogico

    Come faccio a creare un albero genealogico?

    Aggiungi ogni persona una volta, quindi collega un genitore a un bambino. Il grafico blocca i collegamenti duplicati, più di due genitori elencati e cicli di ascendenza. Esporta un diagramma SVG o un file di testo GEDCOM quando sei pronto.

    常見問題

    Come faccio a creare un albero genealogico?

    Aggiungi ogni persona una volta, quindi collega un genitore a un bambino. Il grafico blocca i collegamenti duplicati, più di due genitori elencati e cicli di ascendenza. Esporta un diagramma SVG o un file di testo GEDCOM quando sei pronto.

    Le informazioni sulla mia famiglia vengono caricate o salvate?

    No. Il grafico rimane in questa sessione di pagina. Non viene caricato o salvato nella memoria del browser. Un file esportato può essere archiviato e condiviso, quindi controlla prima i dettagli privati.

    Questo strumento può trovare parenti o registri pubblici?

    No. Organizza solo i dettagli inseriti. Non effettua ricerche nei documenti, non verifica le identità né stabilisce rapporti giuridici.

    Cos'è un file GEDCOM?

    GEDCOM è un formato di testo utilizzato per spostare i documenti genealogici tra programmi genealogici compatibili. Controlla un file esportato prima di condividerlo.

    Il grafico supporta più di due genitori?

    Questa versione consente fino a due genitori elencati per persona. Una relazione familiare può essere più complessa di quanto questo grafico possa rappresentare.
