線性規劃計算器

輸入一個線性目標和最多八個限制條件來求解 x 和 y 非負的二變量線性程式。兩階段單純形法報告最適性、不可行性或無界性並顯示每個樞軸。

目標係數 (x, y)

每行一個：a,b <= rhs, a,b >= rhs 或 a,b = rhs

在 ±1,000,000 範圍內最多使用 8 個限制和係數/右側。兩個決策變數的 x ≥ 0 且 y ≥ 0。在 x 和 y 係數之間使用逗號；每行輸入一個不等式或等式。

用於兩個變數的兩相原始單純形求解器。數值容差用於浮點主元；近乎退化的問題可能對舍入敏感。報告不可行的、無界的和迭代限制的情況，而不是發明的最佳值。

線性規劃結果

結果僅適用於您輸入的數學模型。它不驗證目標、限制、單位或假設是否適合真正的決策。

    二變量單純形計算器如何運作？

    它將約束轉換為可行的表，在需要時使用第一階段目標，然後應用原始單純形樞軸來優化所要求的目標。變數 x 和 y 被限制為非負數。

    常見問題

    二變量單純形計算器如何運作？

    它將約束轉換為可行的表，在需要時使用第一階段目標，然後應用原始單純形樞軸來優化所要求的目標。變數 x 和 y 被限制為非負數。

    我的目標和限制上傳了嗎？

    否。求解器在此瀏覽器中運作。您的目標和約束不會發送到伺服器或由該工具保存。

    約束應該使用什麼格式？

    每行輸入一行，例如 1,1 <= 5 或 2,1 >= 4。第一個數字乘以 x，第二個數字乘以 y，兩個變數都必須為非負數。

    不可行、無界是什麼意思？

    不可行意味著沒有點滿足每個輸入的限制。無界意味著可行的方向可以讓所要求的目標不斷改進，而無需有限的最佳值。

    結果證明我的現實世界模型是正確的嗎？

    否。它僅求解您輸入的方程式。檢查單位、假設以及約束條件是否正確描述了您的決定。
