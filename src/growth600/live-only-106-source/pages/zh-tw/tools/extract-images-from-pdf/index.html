從 PDF 擷取影像

選擇 PDF 以尋找嵌入的光柵影像、預覽它們，並儲存單獨的 PNG 副本或一個 ZIP。頁面不會被光柵化為螢幕截圖。

擷取支援的嵌入光柵影像物件；它不會將整個 PDF 頁面轉換為影像。向量繪圖和頁面文字不是單獨的光柵圖像。

您的檔案保留在此裝置上並且不會上傳。提取的像素被重新編碼為 PNG，因此原始嵌入檔案格式和元資料不會保留。

本地限制：25 MiB PDF、300 頁、200 張圖像、每張圖像 800 萬像素、總計 1600 萬像素和 25 MiB ZIP。大型 PDF 使用裝置記憶體；建議使用電腦。

    選擇 PDF 並選擇擷取影像。此瀏覽器讀取支援的嵌入光柵影像物件並將其解碼像素轉換為 PNG 檔案。下載單一影像或一張 ZIP。

    常見問題

    如何從 PDF 擷取影像？

    選擇 PDF 並選擇擷取影像。此瀏覽器讀取支援的嵌入光柵影像物件並將其解碼像素轉換為 PNG 檔案。下載單一影像或一張 ZIP。

    我的 PDF 或圖片是否已上傳？

    否。您的 PDF 在此瀏覽器標籤中進行處理。該工具不會上傳文件或將其儲存到帳戶。

    這個工具能否將每個PDF頁面變成圖片？

    否。它會尋找支援的嵌入光柵圖像物件。如果您想要每個整個頁面的渲染圖像，請使用 PDF 到圖像工具。

    擷取的 PNG 是否與嵌入檔案逐位元組相同？

    否。瀏覽器解碼支援的圖像對象，並按照解碼的對象尺寸將其像素重新編碼為 PNG。原始壓縮、檔案格式和元資料不會保留。

    為什麼有些PDF影像可能不出現？

    向量圖稿、圖像遮罩、異常編碼、密碼保護、格式錯誤的檔案和瀏覽器記憶體限制可能會阻止提取。該工具僅報告支援的對象，不會上傳您的文件。
