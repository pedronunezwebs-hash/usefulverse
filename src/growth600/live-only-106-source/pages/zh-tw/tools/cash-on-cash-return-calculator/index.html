現金回報計算器

估算年度租賃物業現金流量除以您投入的現金。每筆金額使用一種貨幣單位；這是一個簡單的估計，並非投資建議。

對所有輸入使用相同的貨幣單位。將經常性財產支出（例如稅金、保險費、維護費和空置費）納入營運成本。

說明性稅前估算。不包括升值、稅收影響、未來銷售收益、租金變化、融資變化以及您未輸入的任何成本。不是財產估價、保證回報或財務建議。

現金現金估算

如何計算現金回報？

從租金中減去每月營運成本和償債成本，將每月淨現金流量乘以 12，然後除以首付加上成交成本和初始維修費用。例如，6,000 年度現金流量除以 60,000 投資現金等於 10%。

常見問題

如何計算現金回報？

從租金中減去每月營運成本和償債成本，將每月淨現金流量乘以 12，然後除以首付加上成交成本和初始維修費用。例如，6,000 年度現金流量除以 60,000 投資現金等於 10%。

我的房產資料上傳了嗎？

否。計算在此瀏覽器中運行。請勿輸入帳號、地址或其他敏感詳細資料。

現金回報衡量什麼？

它將建模的年度稅前財產現金流量與您投資的初始現金進行比較。它與上限利率不同，上限利率不除以投資股權，也不包括抵押貸款債務還本付息。

我應該包含哪些費用？

將經常性營運費用納入每月成本，並將初始首付款、結算成本和維修預算納入現金投資。稅收、空置、維護和其他成本很重要；輸入適合您情況的實際估計。

負面結果是否意味著該房產將整體虧損？

表示在該簡化模型中輸入的每月租金減去營運成本和償債成本為負。它不包括增值、稅收待遇、銷售收益或每項財產費用。
