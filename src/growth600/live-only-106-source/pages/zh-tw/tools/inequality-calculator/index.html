不等式計算器

求解與零相比的 ax² + bx + c 形式的實數線性或二次不等式。查看臨界點、區間表示法和數軸總結。

僅支援常數、線性和二次實數不等式 ax² + bx + c <、≤、> 或 ≥ 0。係數必須是有限的，絕對值最多為 10⁹。根是近似值，因為計算使用浮點數。基於比例的容差用於重複根附近。

結果

如何解二次不等式？

找出多項式的實零點，然後確定這些零點之間和之外的符號。該工具傳回真實的解區間以及是否包含每個有限端點。

常見問題

如何解二次不等式？

找出多項式的實零點，然後確定這些零點之間和之外的符號。該工具傳回真實的解區間以及是否包含每個有限端點。

我的係數上傳了嗎？

否。不等式是在該瀏覽器中計算的，不是由該工具上傳或儲存的。

區間表示法表示什麼？

圓括號表示排除某個端點，而方括號表示包含該端點。無窮大總是使用括號，因為無窮大不是真正的端點。

我可以解三次不等式或有理不等式嗎？

否。此計算器僅限於零次、一次或二次實多項式。它不能解三次不等式、有理不等式、絕對值不等式或複合不等式。

根準確嗎？

否。係數和根使用浮點運算。接近重複根或係數大小差異很大的結果可能對舍入敏感。
