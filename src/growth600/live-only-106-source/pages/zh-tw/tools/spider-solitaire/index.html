蜘蛛紙牌

將同一花色的牌由 K 排到 A，翻開蓋牌並完成八組序列。選擇 1、2 或 4 種花色。

留空即可隨機發牌。輸入相同代碼可重現相同牌局。代碼只留在此頁面。

已完成的序列: 0/8

移動: 0

只有相同牌組的正面朝上的降序組可以一起移動。一張面朝上的牌可以自行移動。面朝下的卡片暴露後會翻轉。

已完成的運行將自動刪除。空列接受任何面朝上的牌或有效的牌。

如何玩蜘蛛紙牌？

將相同牌組的面朝上降序列移到下一個更高的等級或空列。揭開隱藏的牌，當每一列都被佔據時，從庫存牌堆中抽出十張牌，並完成八個相同花色的 King-to-Ace 序列即可獲勝。

常見問題

如何玩蜘蛛紙牌？

將相同牌組的面朝上降序列移到下一個更高的等級或空列。揭開隱藏的牌，當每一列都被佔據時，從庫存牌堆中抽出十張牌，並完成八個相同花色的 King-to-Ace 序列即可獲勝。

蜘蛛紙牌可以保存我的遊戲嗎？

否。遊戲在此選項卡中運行，不會保存遊戲、使用帳戶、上傳動作或將其發送到伺服器。開始新的交易會取代目前的遊戲。

一、二、四張牌花色有什麼差別？

一張牌花色是最輕鬆的模式，兩張牌花色加上另一種花色，四張牌花色需要在混合花色畫面中搭配花色。

我什麼時候可以從備用牌堆中抽牌？

抽十張牌，每列一張，剩餘剩餘。從備用牌堆中抽牌之前，每個畫面欄必須至少包含一張牌。

撤銷是如何運作的？

撤銷可恢復先前的移動、股票交易或已完成執行刪除的遊戲狀態。僅在此標籤中最多保留 100 個最近操作。
