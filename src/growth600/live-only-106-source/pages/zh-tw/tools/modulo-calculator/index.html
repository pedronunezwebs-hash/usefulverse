模數計算器

計算整數的歐氏商和餘數。負輸入得到一致的處理，並且部門標識顯示了答案是如何形成的。

要除數；它可能是負的。

使用任何非零整數；它的絕對值定義了模數。

如何計算負數的模數？

此計算器使用小於絕對除數的非負餘數。例如，−7 mod 3 為 2，因為 −7 = (−3 × 3) + 2。

常見問題

如何計算負數的模數？

此計算器使用小於絕對除數的非負餘數。例如，−7 mod 3 為 2，因為 −7 = (−3 × 3) + 2。

我的號碼上傳了嗎？

否。精確的計算在此瀏覽器中運行。號碼不會上傳或儲存。

−7 mod 3 是什麼？

使用歐幾里德約定，−7 mod 3 為 2：−7 = (−3 × 3) + 2，且 0 ≤ 2 < 3。

同餘模 m 是什麼意思？

当两个整数的差可被 |m| 整除时，它们模 m 同余。可選的比較可以準確地檢查這一點。

为什么这与编程语言的 % 运算符不同？

某些语言在余数中保留负被除数的符号。该计算器返回从 0 到绝对除数（但不包括绝对除数）的余数。
