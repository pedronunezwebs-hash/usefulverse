VCF 到 CSV 轉換器

將包含多個聯絡人的 VCF 檔案轉換為一個可用於電子表格的 CSV。選擇您需要的欄位並下載單獨的檔案。

一次使用一個來源。單一 VCF 可以包含多個聯絡人。

本機處理：所選檔案保留在此瀏覽器標籤中。您的通訊錄中沒有新增或變更任何內容。

讀取 vCard 2.1、3.0 和 4.0 中的常見文字欄位：姓名、組織、職位、電話、電子郵件、URL、地址和註釋。二進制照片將被忽略。帶有引號的可列印文字和非 UTF-8 文字不會被解碼。

包含

本地限制：5 MiB 輸入、5,000 個聯絡人和 20 MiB CSV 輸出。大檔案可能需要更多的裝置記憶體；建議使用電腦。

電子表格安全性：可視為公式的值在 CSV 中以撇號開頭。這有意改變了那些導出的單元格。

轉換接點

如何將 VCF 聯絡人轉換為 CSV？

選擇一個 UTF-8 .vcf 檔案或貼上 vCard 文本，選擇要包含的聯絡人列，然後轉換並下載 CSV。重複的電話號碼、電子郵件地址和其他支援的欄位會保留在該聯絡人的行中。

常見問題

如何將 VCF 聯絡人轉換為 CSV？

選擇一個 UTF-8 .vcf 檔案或貼上 vCard 文本，選擇要包含的聯絡人列，然後轉換並下載 CSV。重複的電話號碼、電子郵件地址和其他支援的欄位會保留在該聯絡人的行中。

我的 VCF 聯絡人是否已上傳或更改？

否。選擇檔案後，將在此瀏覽器中讀取並轉換該檔案。 UsefulVerse 不會存取您的通訊錄、上傳檔案或更改聯絡人。

一位聯絡人是否建立 1 個 CSV 行？

是的。每個 vCard 聯絡人都成為一個資料行。重複的電話號碼、電子郵件和其他支援的值在該聯絡人的儲存格中以分號連接。

這包含聯絡人照片嗎？

否。二進位照片、標誌、聲音和關鍵數據被忽略；它們沒有嵌入到 CSV 中。

轉換是否會修改我的聯絡人？

否。它會建立單獨的 CSV 下載，並且不會讀取或寫入您的裝置通訊錄。
