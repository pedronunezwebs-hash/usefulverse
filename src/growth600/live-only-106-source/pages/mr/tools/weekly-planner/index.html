साप्ताहिक नियोजक

काम, वैयक्तिक योजना, अभ्यास किंवा आरोग्यासाठी एक साधे साप्ताहिक टाइम-ब्लॉक शेड्यूल तयार करा. रात्रभर ब्लॉक आणि शेड्यूल संघर्ष स्पष्टपणे दर्शविले आहेत.

पुनरावृत्ती होणारी साप्ताहिक योजना स्थानिक वॉल-क्लॉक वेळा वापरते; हे टाइम झोन, डेलाइट-सेव्हिंग बदल, कॅलेंडर इव्हेंट किंवा स्मरणपत्रांसाठी खाते नाही.

योजना या टॅबमध्ये मेमरीमध्ये राहते. ते ठेवण्यासाठी JSON बॅकअप डाउनलोड करा; स्वयंचलित संचयन किंवा अपलोड नाही.

साप्ताहिक वेळापत्रक

मी साप्ताहिक वेळापत्रक कसे बनवू?

प्रत्येक ब्लॉकसाठी शीर्षक, दिवस, प्रारंभ वेळ, समाप्ती वेळ आणि श्रेणी जोडा. ब्लॉक मध्यरात्री ओलांडू शकतात. ओव्हरलॅपिंग वेळ ध्वजांकित आहे, रविवार आणि सोमवारसह.

वारंवार विचारले जाणारे प्रश्न

मी साप्ताहिक वेळापत्रक कसे बनवू?

प्रत्येक ब्लॉकसाठी शीर्षक, दिवस, प्रारंभ वेळ, समाप्ती वेळ आणि श्रेणी जोडा. ब्लॉक मध्यरात्री ओलांडू शकतात. ओव्हरलॅपिंग वेळ ध्वजांकित आहे, रविवार आणि सोमवारसह.

माझे साप्ताहिक वेळापत्रक अपलोड किंवा सेव्ह केले आहे का?

नाही. तुम्ही JSON बॅकअप डाउनलोड करणे निवडल्याशिवाय तुमचे शेड्यूल या ब्राउझर टॅबमध्ये राहते. तुम्ही तुमच्या डिव्हाइसवरून निवडलेला बॅकअप इंपोर्ट करा.

साप्ताहिक नियोजक रात्रीच्या शिफ्टचा समावेश करू शकतो का?

होय. दुसऱ्या दिवशी समाप्त होणारा ब्लॉक तयार करण्यासाठी प्रारंभ वेळेपेक्षा पूर्वीची समाप्ती वेळ निवडा. 18 तासांपर्यंतचे ब्लॉक समर्थित आहेत.

साप्ताहिक शेड्युलमध्ये मतभेद आढळतात का?

होय. हे त्याच दिवशी आणि मध्यरात्री टाइम ब्लॉक्स तपासते, त्यात सोमवारच्या ओव्हरलॅप होणाऱ्या रविवारच्या ब्लॉकचा समावेश आहे.

हा प्लॅनर Google Calendar शी सिंक होतो का?

नाही. हे या टॅबमध्ये स्थानिक पातळीवर कार्य करते आणि त्यात कोणतेही कॅलेंडर कनेक्शन किंवा स्मरणपत्र सेवा नाही. तुम्ही योजना मुद्रित करू शकता किंवा JSON बॅकअप डाउनलोड आणि आयात करू शकता.
