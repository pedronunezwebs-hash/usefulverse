XML ते CSV कनवर्टर

एक साधी XML रेकॉर्ड सूची CSV टेबलमध्ये बदला किंवा CSV फाइलच्या मजकुरातून XML रेकॉर्ड तयार करा. दिशा निवडा, तुमचा डेटा पेस्ट करा, नंतर कॉपी करा किंवा निकाल डाउनलोड करा. काहीही अपलोड केलेले नाही.

समान-नावाच्या रेकॉर्ड घटकांच्या सोप्या सूचीला किंवा एका फ्लॅट रेकॉर्डला समर्थन देते. घटक मुले स्केलर मूल्ये असणे आवश्यक आहे; नेस्टेड आणि वारंवार फील्ड सपाट केलेले नाहीत.

स्तंभ नावांसाठी पहिली पंक्ती वापरा. @id सारखे शीर्षलेख XML विशेषता बनते. मजकूर रेकॉर्ड करण्यासाठी #text वापरा.

हे एक साधे टेबल रूपांतरण आहे, लॉसलेस XML फॉरमॅट रूपांतरण नाही. नेमस्पेसेस, नेस्टेड स्ट्रक्चर्स, मिश्रित सामग्री, टिप्पण्या आणि XML स्वरूपन जतन केलेले नाहीत. मजकूर टाईप-अवेअर नाही. स्प्रेडशीट फॉर्म्युला सारखी CSV मूल्ये सुरक्षिततेसाठी ॲपोस्ट्रॉफीसह उपसर्ग लावली जातात.

परिणाम

दुसऱ्या ऍप्लिकेशनमध्ये आयात करण्यापूर्वी आउटपुट तपासा.

मी XML ला CSV मध्ये कसे रूपांतरित करू?

XML ते CSV निवडा आणि साध्या रेकॉर्ड सूचीसह XML पेस्ट करा. वारंवार थेट रेकॉर्ड घटक पंक्ती बनतात. घटकांची नावे स्तंभ बनतात; विशेषता @name वापरतात. शीर्षलेख आणि पंक्तींमधून साधे XML रेकॉर्ड तयार करण्यासाठी CSV ते XML निवडा.

वारंवार विचारले जाणारे प्रश्न

मी XML ला CSV मध्ये कसे रूपांतरित करू?

XML ते CSV निवडा आणि साध्या रेकॉर्ड सूचीसह XML पेस्ट करा. वारंवार थेट रेकॉर्ड घटक पंक्ती बनतात. घटकांची नावे स्तंभ बनतात; विशेषता @name वापरतात. शीर्षलेख आणि पंक्तींमधून साधे XML रेकॉर्ड तयार करण्यासाठी CSV ते XML निवडा.

माझे XML किंवा CSV अपलोड केले आहे का?

क्र. या ब्राउझरमध्ये पार्सिंग आणि रूपांतरण चालते. इनपुट 200,000 वर्ण, 5,000 पंक्ती, 64 स्तंभ आणि 20,000 सेलपर्यंत मर्यादित आहे. DTD आणि अस्तित्व घोषणा अवरोधित केल्या आहेत आणि बाह्य संसाधने आणली जात नाहीत.

CSV मध्ये XML विशेषता कशा दाखवल्या जातात?

id="101" सारखी विशेषता @id नावाचा कॉलम बनते. परत रूपांतरित करताना, @ ने सुरू होणारे CSV शीर्षलेख XML विशेषता बनते.

हे नेस्टेड XML ला फ्लॅट टेबलमध्ये रूपांतरित करू शकते का?

क्र. नेस्टेड चाइल्ड स्ट्रक्चर्स, रेकॉर्डमधील वारंवार फील्ड आणि मिश्रित मजकूर सपाट किंवा शांतपणे गमावण्याऐवजी नाकारला जातो. नेस्टेड डेटासाठी समर्पित XML-ते-JSON वर्कफ्लो वापरा.

CSV XML प्रकार आणि स्वरूपन जतन करेल का?

क्र. CSV सेल टेक्स्ट स्टोअर करते, XML प्रकार, नेमस्पेसेस किंवा फॉरमॅटिंग नाही. स्प्रेडशीट फॉर्म्युला अंमलबजावणी जोखीम कमी करण्यासाठी फॉर्म्युला सारखी सेल व्हॅल्यूज एक्सपोर्ट केल्यावर ॲपोस्ट्रॉफी उपसर्ग मिळतात.
