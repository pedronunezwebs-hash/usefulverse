मॉड्यूलो कॅल्क्युलेटर

पूर्ण संख्यांसाठी युक्लिडियन भागांक आणि उर्वरित गणना करा. नकारात्मक इनपुट सातत्याने हाताळले जातात आणि विभाग ओळख दर्शवते की उत्तर कसे तयार होते.

ज्या संख्येला भाग घ्यायचा आहे; ते नकारात्मक असू शकते.

कोणतीही शून्य नसलेली पूर्ण संख्या वापरा; त्याचे परिपूर्ण मूल्य मॉड्यूलस परिभाषित करते.

हे मूल्य विभाजक मोड्युलोशी सुसंगत आहे की नाही ते तपासा.

50 अंकांपर्यंत स्वाक्षरी केलेल्या पूर्ण संख्या स्वीकारतो. कोणतेही अपूर्णांक किंवा दशांश नाहीत. परिणाम युक्लिडियन मोड्यूलो वापरतो; काही प्रोग्रामिंग भाषा निगेटिव्हसाठी वेगळा उर्वरित नियम वापरतात.

परिणाम

तुम्ही ऋण संख्या असलेल्या मोड्युलोची गणना कशी करता?

हा कॅल्क्युलेटर निरपेक्ष विभाजकापेक्षा लहान नॉन-ऋण शेष वापरतो. उदाहरणार्थ, −7 mod 3 2 आहे कारण −7 = (−3 × 3) + 2.

वारंवार विचारले जाणारे प्रश्न

तुम्ही ऋण संख्या असलेल्या मोड्युलोची गणना कशी करता?

हा कॅल्क्युलेटर निरपेक्ष विभाजकापेक्षा लहान नॉन-ऋण शेष वापरतो. उदाहरणार्थ, −7 mod 3 2 आहे कारण −7 = (−3 × 3) + 2.

माझे नंबर अपलोड केले आहेत का?

क्रमांक. अचूक गणना या ब्राउझरमध्ये चालते. नंबर अपलोड किंवा सेव्ह केलेले नाहीत.

−7 मोड 3 म्हणजे काय?

युक्लिडियन कन्व्हेन्शन वापरून, −7 मोड 3 म्हणजे 2: −7 = (−3 × 3) + 2, आणि 0 ≤ 2 < 3.

एकरूप मॉड्युलो m चा अर्थ काय?

दोन पूर्णांक एकरूप मोड्युलो m असतात जेव्हा त्यांचा फरक |m| ने भाग जातो. पर्यायी तुलना हे नक्की तपासते.

हे प्रोग्रामिंग भाषेच्या % ऑपरेटरपेक्षा वेगळे का असू शकते?

काही भाषा उर्वरित मध्ये नकारात्मक लाभांशाचे चिन्ह ठेवतात. हे कॅल्क्युलेटर त्याऐवजी 0 ते पूर्ण विभाजक पर्यंत उर्वरित परत करते, परंतु समाविष्ट करत नाही.
