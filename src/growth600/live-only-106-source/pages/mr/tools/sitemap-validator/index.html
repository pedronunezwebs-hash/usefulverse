साइटमॅप व्हॅलिडेटर

साइटमॅप XML दस्तऐवजाची रचना, URL नोंदी, तारखा आणि सामान्य फील्ड तपासण्यासाठी पेस्ट करा. XML फक्त या ब्राउझरमध्ये पार्स केले जाते; सूचीबद्ध पृष्ठे कधीही आणली जात नाहीत.

मानक urlset किंवा sitemapindex चे समर्थन करते. कमाल 1,000,000 वर्ण आणि 5,000 थेट नोंदी.

फक्त स्थानिक XML तपासते: हे सूचीबद्ध URL ची विनंती करत नाही, साइट क्रॉल करत नाही, साइटमॅप सबमिट करत नाही किंवा अनुक्रमणिकेची हमी देत नाही.

प्रमाणीकरण सारांश

निष्कर्ष

    हा साइटमॅप प्रमाणीकरणकर्ता काय तपासतो?

    हे urlset किंवा sitemapindex नोंदी, निरपेक्ष HTTP किंवा HTTPS स्थाने, डुप्लिकेट सामान्यीकृत URL, लास्टमॉड तारखा, पर्यायी चेंजफ्रेक आणि प्राधान्य मूल्ये आणि साइटमॅप नेमस्पेस तपासते. चेतावणी आणि त्रुटी एंट्री नंबरद्वारे सूचीबद्ध केल्या आहेत.

    वारंवार विचारले जाणारे प्रश्न

    हा साइटमॅप प्रमाणीकरणकर्ता काय तपासतो?

    हे urlset किंवा sitemapindex नोंदी, निरपेक्ष HTTP किंवा HTTPS स्थाने, डुप्लिकेट सामान्यीकृत URL, लास्टमॉड तारखा, पर्यायी चेंजफ्रेक आणि प्राधान्य मूल्ये आणि साइटमॅप नेमस्पेस तपासते. चेतावणी आणि त्रुटी एंट्री नंबरद्वारे सूचीबद्ध केल्या आहेत.

    तो माझा साइटमॅप अपलोड करतो किंवा सबमिट करतो?

    क्र. XML ची प्रक्रिया तुमच्या ब्राउझरमध्ये स्थानिक पातळीवर केली जाते. टूल URL क्रॉल करत नाही, रिमोट साइटमॅप फाइल्स आणत नाही, शोध इंजिनला काहीही सबमिट करत नाही किंवा अनुक्रमणिकेची पुष्टी करत नाही.

    हे साइटमॅप URL लाइव्ह आहे की नाही हे तपासते?

    क्र. हे पेस्ट केलेल्या XML मध्ये URL वाक्यरचना आणि डुप्लिकेट तपासते, परंतु जाणूनबुजून URL ची विनंती करत नाही किंवा साइट क्रॉल करत नाही.

    वैध साइटमॅप म्हणजे Google ने त्याची पृष्ठे अनुक्रमित केली आहेत का?

    क्रमांक. XML प्रमाणीकरण शोध-इंजिन सबमिशन किंवा अनुक्रमणिका अहवाल नाही. संबंधित शोध-इंजिन वेबमास्टर टूलद्वारे साइटमॅप सबमिट करा आणि त्याची स्वतःची स्थिती तपासा.

    मी साइटमॅप इंडेक्स प्रमाणित करू शकतो का?

    होय. हे टूल थेट sitemapindex एंट्री आणि त्यांची loc आणि lastmod फील्ड तपासते, परंतु संदर्भित साइटमॅप फाइल डाउनलोड करत नाही किंवा वारंवार तपासत नाही.
