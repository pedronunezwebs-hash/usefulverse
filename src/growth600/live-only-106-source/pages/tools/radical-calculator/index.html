Square Root Simplifier

Simplify exact integer radicals by extracting perfect powers, or rewrite a fraction so its denominator contains no square root. Results are exact for the supported integer inputs.

Enter whole numbers. Radicands are limited to ±1,000,000,000,000; the root index is 2–12. Negative radicands are supported only for odd indexes.

This mode handles numerator / (coefficient × √radicand). The denominator coefficient cannot be zero; the radicand must be a positive whole number.

Result

How do you simplify a square root?

Factor the radicand into prime powers. Pull each complete pair outside a square root; for example, √72 = √(36 × 2) = 6√2. This tool also supports integer roots with indexes 2 through 12.

Frequently asked questions

How do you simplify a square root?

Factor the radicand into prime powers. Pull each complete pair outside a square root; for example, √72 = √(36 × 2) = 6√2. This tool also supports integer roots with indexes 2 through 12.

Are my numbers uploaded?

No. The calculation runs in this browser and this tool does not upload or save your inputs.

What does √72 simplify to?

√72 is 6√2, because 72 = 36 × 2 and √36 = 6.

Can it rationalize a denominator?

Yes. It rewrites a / (c√b) with integer inputs as an equivalent fraction whose denominator has no square root, then reduces the rational coefficient.

Does this give decimal approximations?

No. It keeps the exact radical form. Use a scientific calculator if you also need a decimal approximation.
