Meeting Minutes Template

Use a clear meeting-minutes template for attendees, agenda topics, decisions, and action items. Every action can include an owner and due date.

Example: Review draft | Sam | 2026-10-16. Each action needs a responsible person and a valid date.

This is a note-taking template, not an automatic meeting recorder or transcript generator.

Notes remain in this tab until you close it. Download or print them to keep a copy.

Meeting minutes


  

    
What should meeting minutes include?
Record the meeting title, date, facilitator, attendees, agenda, decisions, and action items. Assign an owner and due date to each action so follow-up is clear.


    
Frequently asked questions
What should meeting minutes include?
Record the meeting title, date, facilitator, attendees, agenda, decisions, and action items. Assign an owner and due date to each action so follow-up is clear.
Are my meeting notes uploaded or saved?
No. The template runs in this browser tab. It does not automatically save or upload your notes; export a Markdown file or print them if you want a copy.
How should I format an action item?
Enter one action per line as task | owner | due date, using a valid YYYY-MM-DD date, for example: Send notes | Sam | 2026-10-16.
Can I print or export the minutes?
Yes. Preview the structured notes, download them as a Markdown file, or use the print option in your browser.
Does this tool record or transcribe a meeting?
No. It does not access a microphone or create a transcript. You enter the notes and decisions yourself.
