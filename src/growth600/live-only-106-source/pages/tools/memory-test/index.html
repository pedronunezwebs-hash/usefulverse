Frequently asked questions

How does this memory test work?

Choose digits or a visual grid and a display speed. Watch or listen to the sequence once, then enter it in the same order. Correct rounds get longer, up to 12 items. This is a casual practice game, not a standardized memory assessment.

Does this memory test save my score?

No. The sequence and score stay in this page while it is open. Nothing is uploaded, and there is no account or online ranking.

What does this memory test measure?

It is a casual sequence-recall practice game. It is not standardized and cannot diagnose a condition or measure IQ.

How do digit span and pattern mode differ?

Digit span shows digits one at a time and announces them for screen-reader access. Pattern mode flashes positions on a 3×3 grid and requires sight.

Are scores saved or compared with other people?

No. Scores exist only while this page remains open. There is no leaderboard, account or server upload.
