Image Vectorizer

Trace simple logos, icons, and flat-color artwork into SVG paths. Choose a color limit and detail size, preview the vector, then download the SVG.

128

The longest side is reduced to this many pixels or fewer. Larger detail may create a bigger SVG.

Up to 5 MiB per source image. The image is processed locally and is not uploaded or automatically saved. Large images can use device memory; a computer is recommended.

Vector preview

How do you turn an image into an SVG?

Choose a raster image, select its output detail and color count, then create the SVG. The tool groups colored pixel runs into real vector paths; edges follow the selected pixel grid, so flat artwork works better than photographs.

Frequently asked questions

How do you turn an image into an SVG?

Choose a raster image, select its output detail and color count, then create the SVG. The tool groups colored pixel runs into real vector paths; edges follow the selected pixel grid, so flat artwork works better than photographs.

Is my image uploaded?

No. The image is decoded and traced in this browser tab. It is not uploaded or automatically saved.

Does the SVG contain the original image?

No. The result contains SVG path shapes, not an embedded raster image. It approximates the source by grouping pixels into colors and paths.

Will it vectorize a photograph smoothly?

No. The pixel-grid trace is intended for simple logos, icons, and flat-color drawings. Photographs can produce blocky edges and large SVG files.

Does the tool upload or keep my image?

No. The source is processed in this tab and is not uploaded or automatically saved. Processing speed and memory use depend on your device.
