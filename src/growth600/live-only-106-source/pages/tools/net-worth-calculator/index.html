    Frequently asked questions

    How do I calculate net worth?

    Add your asset balances and liabilities using the same currency, then subtract total liabilities from total assets. Values are only as accurate as the amounts and valuations you enter.

    Are my financial balances saved or uploaded?

    Calculations happen in this page. Browser storage is off unless you check the consent box and separately save a snapshot. Saved data stays in this browser and can be deleted here or in browser settings.

    What counts as net worth?

    Net worth is the total value you assign to assets minus the liabilities you enter. The result is not an appraisal or a credit score.

    Can I compare different currencies?

    No automatic exchange rates are used. Compare snapshots only when they use the same currency code.

    Where are saved snapshots stored?

    Only in this browser’s local storage after you opt in and press Save. Clearing browser data removes them; download a CSV if you need a separate copy.
