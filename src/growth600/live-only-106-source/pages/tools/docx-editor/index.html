DOCX Editor

Make focused text edits to a modern Word DOCX file in this browser. The editor changes existing text runs in the main document and keeps other document parts unchanged. It is not a full Word replacement, and complex formatting may not preview here.

Modern .docx only. Maximum 25 MiB, 80 MiB expanded package, 8 MiB document XML, 500 text segments and 250,000 characters. Large documents work better on a computer.

Processing happens on your device after you choose a file. No upload, account, API, autosave or server processing.

This focused editor changes only existing text runs in the main document. It preserves styles, images and other package-part contents, but repacks the DOCX ZIP container. It does not edit headers, footers, comments, footnotes, formatting, paragraph structure or tracked changes. Macros and digitally signed packages are not supported.

Existing document text

Text preview

What can I edit in a DOCX file?

You can edit existing text segments in paragraphs and table cells in a modern .docx file, preview the text and download an edited copy. This editor does not add or remove paragraphs, change formatting, edit headers or footers, or support tracked changes.

Frequently asked questions

What can I edit in a DOCX file?

You can edit existing text segments in paragraphs and table cells in a modern .docx file, preview the text and download an edited copy. This editor does not add or remove paragraphs, change formatting, edit headers or footers, or support tracked changes.

Is my Word document uploaded?

No. The file is processed in this browser after you choose it. It is not uploaded, saved automatically or sent to a server.

Will the edited file keep my existing formatting?

Text styles and other package-part contents are preserved. When a text segment is replaced, its existing run formatting is retained; this tool does not offer rich text formatting controls or guarantee that every Word feature renders identically.

Can this edit tracked changes, headers, or signed documents?

No. The focused editor changes text runs in the main document only. Tracked-change workflows, headers and footers, macros and digitally signed files are not supported.
