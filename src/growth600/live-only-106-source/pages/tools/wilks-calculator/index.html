Wilks & DOTS Powerlifting Calculator

Enter a lifter bodyweight and a powerlifting total or single-lift result. Select a named scoring model to see a comparable score; each model is shown separately.

Models are not interchangeable and can rank lifters differently. Choose the coefficient group required by the model’s published table; this is a formula setting, not an identity label. For a fair comparison, use results from the same event format (full powerlifting total or the same single lift), units, and model. This is not an official federation result or a prediction of competition placing.

Score estimate

Comparison estimate only. Not the current official IPF Goodlift score. Compare results using the same model, coefficient group, and event format; rules and model suitability vary.

How is a Wilks or DOTS score calculated?

Each model applies its published bodyweight coefficients to the entered bodyweight, then scales the entered lift result by that model’s denominator. The result is only comparable when the same formula, coefficient group, and event type are used.

Frequently asked questions

How is a Wilks or DOTS score calculated?

Each model applies its published bodyweight coefficients to the entered bodyweight, then scales the entered lift result by that model’s denominator. The result is only comparable when the same formula, coefficient group, and event type are used.

Are my numbers uploaded or saved?

No. The calculation runs in this browser; entered values are not uploaded or saved.

What is the difference between Wilks, Wilks-2 and DOTS?

They are separate bodyweight-adjustment models with different published coefficients. Their scores are not interchangeable, and two models can order lifters differently.

Is this the official IPF score?

No. This calculator displays Wilks, Wilks-2 and DOTS estimates. IPF competitions use the current federation scoring system and its rules; check the organizer’s official results.

Can I compare a bench press result with a full powerlifting total?

Use the same event format for both athletes. The arithmetic can calculate a score from either input, but comparing a single lift with a three-lift total is not a like-for-like competition comparison.
