How do I set an online alarm?

Choose a future date and time in your device’s local time zone, then select Set alarm. Sound is optional. You can test it first, snooze for five minutes or stop it when it rings.

Frequently asked questions

How do I set an online alarm?

Choose a future date and time in your device’s local time zone, then select Set alarm. Sound is optional. You can test it first, snooze for five minutes or stop it when it rings.

Does this alarm send data or work after I close the page?

No data is sent or saved. The alarm runs in this page only and cannot alert you reliably if the tab closes, the browser pauses it or the device sleeps.

Will the alarm ring if I close the tab?

No. This is an in-page alarm, not an operating-system alarm or notification. Keep the page open and the device awake; for important reminders, use your device’s alarm app.

Can I snooze the alarm?

Yes. When it rings, choose Snooze 5 minutes to schedule it again from the current time.

Does the alarm use my location or save my time?

No. It uses the local time configured on your device. The alarm is held only in the open page and is not uploaded or saved.
