Frequently asked questions

How do I mix two colors online?

Choose two or more colors, set each weight, and select sRGB or linear-light mixing. The result shows HEX, RGB, and HSL values.

Are my colors uploaded?

No. Color calculations run locally in your browser. No account or image upload is needed.

Why do sRGB and linear-light mixes look different?

sRGB averages the encoded screen channel values. Linear-light mode converts them to light values first, mixes, then converts back. The chosen method changes the result.

Can this predict the color of mixed paint?

No. This is digital color math for screens, not a physical pigment model. Real paint depends on pigment properties, transparency, concentration, lighting, and the surface.

What color formats can I copy?

The result displays HEX, RGB, and HSL. You can copy the HEX value or download a small CSS color palette.
