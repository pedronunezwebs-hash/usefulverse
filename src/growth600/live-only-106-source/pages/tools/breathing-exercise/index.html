Frequently asked questions

How do I use this breathing exercise?

Choose a preset or set each phase, select a session length and press Start. Pause or reset at any time. Audio is optional and begins only after you start.

Is my breathing session uploaded?

No. Timing runs in this page. No account, upload, API or saved session is used.

Can I use box breathing or 4-7-8?

Yes. Choose either preset or adjust the phase lengths. These are pacing patterns, not medical treatment.

Will it keep running when I close the tab?

No guarantee. Browsers can pause background tabs and sleeping devices. Keep this page open and the device awake for the most reliable timing.

Can I turn off sound or stop early?

Yes. Sound is optional, starts after you press Start and can be unchecked. Pause or Reset ends the active timing immediately.
