VCard Generator

Create a single digital contact as a .vcf file in your browser. Choose vCard 3.0 or 4.0, add contact details and optionally embed a small JPEG or PNG photo.

Optional JPEG or PNG, up to 128 KiB. The photo is embedded into the VCF file; it is not uploaded.

One contact, up to 5 phones and 5 emails, 500 characters per text field, and a 1 MiB generated-file limit. Only vCard 3.0 and 4.0 are offered.

Runs locally after you choose Generate. No account, contact-book access, upload, API, server processing or automatic save.

VCF preview


  

    
Will this add the contact to my phone?
No. It creates a VCF file for you to preview, copy or download. It never reads or changes your address book; you decide whether and where to import the file.


    
Frequently asked questions
Will this add the contact to my phone?
No. It creates a VCF file for you to preview, copy or download. It never reads or changes your address book; you decide whether and where to import the file.
Is my contact information uploaded?
No. Details and an optional photo are processed on this device. There is no upload, account, server processing or automatic saving.
What is the difference between vCard 3.0 and 4.0?
They are two versions of the vCard contact format. The tool writes a compatible VCF text file using the version you select; contact apps may support them differently.
Does this verify phone numbers or email addresses?
No. It checks their basic format only. It cannot verify that a number, mailbox, address or website belongs to the person.
