How do I make an event timeline?

Add at least two named events and choose a start date for each. Add an end date for a duration or leave it blank for a single-day event. Create the timeline to sort events by date, adjust the zoom, and download SVG or CSV files.

Frequently asked questions

How do I make an event timeline?

Add at least two named events and choose a start date for each. Add an end date for a duration or leave it blank for a single-day event. Create the timeline to sort events by date, adjust the zoom, and download SVG or CSV files.

Are my timeline events uploaded?

No. Names and dates are processed in this browser tab. The SVG and CSV are generated on your device; nothing is uploaded or saved automatically.

Can an event last more than one day?

Yes. Enter both a start and end date. The chart includes both endpoint dates; leave the end blank for a single-day event.

Does this timeline create task dependencies?

No. It shows dated events and ranges in chronological order. Use a project schedule tool for tasks, durations and dependencies.

Can I save or share the timeline?

Download an SVG for a scalable image or a CSV for the event table. The page does not upload or automatically save your event data.
