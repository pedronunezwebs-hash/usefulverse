Weekly Planner

Build a simple weekly time-block schedule for work, personal plans, study, or health. Overnight blocks and schedule conflicts are shown clearly.

A repeating weekly plan uses local wall-clock times; it does not account for time zones, daylight-saving changes, calendar events, or reminders.

The plan stays in memory in this tab. Download a JSON backup to keep it; no automatic storage or upload.

Weekly schedule

How do I make a weekly schedule?

Add a title, day, start time, end time, and category for each block. Blocks can cross midnight. Overlapping time is flagged, including across Sunday and Monday.

Frequently asked questions

How do I make a weekly schedule?

Add a title, day, start time, end time, and category for each block. Blocks can cross midnight. Overlapping time is flagged, including across Sunday and Monday.

Is my weekly schedule uploaded or saved?

No. Your schedule stays in this browser tab unless you choose to download a JSON backup. Import a backup you selected from your device.

Can a weekly planner include overnight shifts?

Yes. Choose an end time earlier than the start time to create a block that ends the next day. Blocks up to 18 hours are supported.

Does the weekly schedule detect conflicts?

Yes. It checks time blocks on the same day and across midnight, including a Sunday block that overlaps Monday.

Does this planner sync with Google Calendar?

No. It works locally in this tab and has no calendar connection or reminder service. You can print the plan or download and import a JSON backup.
