Histogram Calculator

Paste up to 5,000 numbers to build an equal-width histogram. Choose an automatic bin rule or set the bin count, then view and export the frequencies.

Separate values with spaces, semicolons or new lines. Semicolons keep decimal commas intact.

Supports 1–5,000 finite values with absolute magnitude at most 10⁹ and 1–50 equal-width bins. The last interval includes its right endpoint. Relative frequency and density are normalized to all entered values. If Freedman–Diaconis cannot use a positive IQR/range, it falls back to Sturges. This is a descriptive chart, not a statistical inference or probability model.

How do I make a histogram?

Enter numeric data and choose a bin rule. The calculator divides the data range into equal-width intervals, counts each value once, and includes the maximum value in the final interval.

Frequently asked questions

How do I make a histogram?

Enter numeric data and choose a bin rule. The calculator divides the data range into equal-width intervals, counts each value once, and includes the maximum value in the final interval.

Is my data uploaded?

No. The histogram is calculated in this browser. Your values are not uploaded or saved by this tool.

Which bin rule should I use?

Sturges is a simple starting point for smaller samples. Square-root uses the square root of the sample size. Freedman–Diaconis uses the interquartile range and can adapt to spread and outliers. You can also choose the bin count yourself.

What is the difference between frequency and density?

Frequency counts values in each interval. Relative frequency shows the percentage. Probability density divides relative frequency by interval width, so the total bar area is one.

Does the final bin include its upper bound?

Yes. Bins are half-open intervals except the final bin, which includes the maximum data value so no value is left out.
