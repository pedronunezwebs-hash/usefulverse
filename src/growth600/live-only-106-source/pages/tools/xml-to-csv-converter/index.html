XML to CSV Converter

Turn a simple XML record list into a CSV table, or build XML records from a CSV file’s text. Choose the direction, paste your data, then copy or download the result. Nothing is uploaded.

Supports a simple list of same-name record elements, or one flat record. Element children must be scalar values; nested and repeated fields are not flattened.

Use the first row for column names. A header such as @id becomes an XML attribute. Use #text for record text.

This is a simple table conversion, not a lossless XML format conversion. Namespaces, nested structures, mixed content, comments and XML formatting are not preserved. Text is not type-aware. Spreadsheet formula-like CSV values are prefixed with an apostrophe for safety.

How do I convert XML to CSV?

Choose XML to CSV and paste XML with a simple record list. Repeated direct record elements become rows. Element names become columns; attributes use @name. Choose CSV to XML to create simple XML records from headers and rows.

Frequently asked questions

How do I convert XML to CSV?

Choose XML to CSV and paste XML with a simple record list. Repeated direct record elements become rows. Element names become columns; attributes use @name. Choose CSV to XML to create simple XML records from headers and rows.

Is my XML or CSV uploaded?

No. Parsing and conversion run in this browser. Input is limited to 200,000 characters, 5,000 rows, 64 columns and 20,000 cells. DTD and entity declarations are blocked, and external resources are not fetched.

How are XML attributes shown in CSV?

An attribute such as id="101" becomes a column named @id. When converting back, a CSV header that starts with @ becomes an XML attribute.

Can it convert nested XML into a flat table?

No. Nested child structures, repeated fields inside a record and mixed text are rejected instead of being flattened or silently lost. Use a dedicated XML-to-JSON workflow for nested data.

Will the CSV preserve XML types and formatting?

No. CSV stores cell text, not XML types, namespaces or formatting. Formula-like cell values get an apostrophe prefix when exported to reduce spreadsheet formula execution risk.
