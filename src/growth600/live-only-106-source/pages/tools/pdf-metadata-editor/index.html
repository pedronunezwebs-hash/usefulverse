PDF Metadata Editor

Read or edit common document information stored in a PDF, then download a separate copy. The selected PDF stays on this device.

Keep your original. Re-saving may invalidate digital signatures or affect advanced PDF features. This tool does not remove hidden information or certify privacy.

Local limits: 25 MiB input, 300 pages and 50 MiB output. Large documents may need more memory; a computer is recommended.

Only standard PDF document information is edited. XMP, custom metadata, attachments, hidden content and signature validation are not supported.

Which PDF metadata can I change?

This tool edits the standard document information fields: title, author, subject, keywords, creator, producer, creation date and modification date. It does not edit XMP metadata or custom properties.

Frequently asked questions

Which PDF metadata can I change?

This tool edits the standard document information fields: title, author, subject, keywords, creator, producer, creation date and modification date. It does not edit XMP metadata or custom properties.

Is my PDF uploaded?

No. Reading and editing happen in your browser after you choose a file. The original file is not changed; saving creates a separate PDF copy.

Does this remove all metadata from a PDF?

No. It edits only common entries in the standard PDF document information dictionary. XMP, custom properties, embedded files and other hidden content may remain.

Will editing metadata preserve a digital signature?

Do not rely on that. Saving rewrites the PDF and can invalidate existing digital signatures or affect features not supported by this tool. Keep the original and verify the copy.

Is the original PDF overwritten?

No. The tool reads the selected file and creates a separate downloadable copy. It does not modify the original on your device.
