Push-Up Test & Set Tracker

Record a single set as a simple test or log several sets with the rest between them. You count and enter repetitions; this tool does not use your camera or rank your strength.

Enter up to 20 whole-number counts from 0 to 500. Blank lines are ignored and do not count as sets. Count only repetitions you completed with your chosen form.

Keep notes general; this is not a medical record.

Choose a comfortable range of motion and stop if you feel pain, dizziness or unusual shortness of breath. Rep counts depend on form, pace and test conditions; this tool does not provide a fitness rating, diagnosis or exercise prescription.

Saving is optional and uses this browser only. Uncheck to calculate without saving, or clear the saved history below.

Your session

How does the push-up test tracker total repetitions?

It adds the whole-number repetitions entered for each non-empty set. Blank lines are ignored, a set of zero remains zero, and the rest estimate is rest per break multiplied by the number of breaks.

Frequently asked questions

How does the push-up test tracker total repetitions?

It adds the whole-number repetitions entered for each non-empty set. Blank lines are ignored, a set of zero remains zero, and the rest estimate is rest per break multiplied by the number of breaks.

Are my push-up sets uploaded?

No. The calculation runs in this browser. Session history is written to this device only after you opt in; you can delete it here.

Do blank lines count as a set or repetition?

No. Empty lines are ignored. A line with 0 records a zero-repetition set and adds no repetitions to the total.

Can I use this for one maximum set or for several sets?

Yes. Enter one line for a single manually counted set, or multiple lines to summarize sets and the rest between them. Test conditions are up to you; results are not compared with population norms.

Is my training history uploaded?

No. History is optional and stays in this browser on this device. Clear it with the delete button whenever you want.
