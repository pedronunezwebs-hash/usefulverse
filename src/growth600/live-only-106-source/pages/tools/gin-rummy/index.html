How do you play this Gin Rummy game?

Draw one card from the stock or discard pile, then discard one card. Build same-suit runs or equal-rank sets; knock with 10 or fewer deadwood points, or go gin with no deadwood.

Frequently asked questions

How do you play this Gin Rummy game?

Draw one card from the stock or discard pile, then discard one card. Build same-suit runs or equal-rank sets; knock with 10 or fewer deadwood points, or go gin with no deadwood.

Does this Gin Rummy game upload my cards?

No. The deal and play run in this browser. There is no account, upload, server opponent or saved match.

Can I play Gin Rummy against the computer?

Yes. One person plays locally against a lightweight browser opponent. It is not multiplayer.

What is deadwood in Gin Rummy?

Cards not included in a run or set count as deadwood. Aces count as 1, number cards at face value, and face cards as 10.

Does this game support layoffs?

No. Knock scoring uses the displayed no-layoff variant; house rules can differ.
