Sobriety Day Counter

Choose a start date to count elapsed calendar days and see upcoming milestones. This private counter is not treatment, recovery advice, or a measure of health.

Enter the date you want to count from. A date today is day zero; future dates are not allowed. Defaults to today and can be changed to review an earlier date, but not a date before the start.

Up to 280 characters. Keep sensitive details out of shared devices.

This is date arithmetic only. It does not assess substance use, health, risk, progress, or treatment needs. Recovery is personal; consider qualified support if you want help.

Saving is optional and uses this browser’s local storage only; nothing is uploaded. Clear saved data below.

Your day count

How does the sobriety day counter work?

It counts whole calendar days from the date you enter through today. The selected start date itself is day zero; later dates use date-only arithmetic, so daylight-saving time does not add or remove a day.

Frequently asked questions

How does the sobriety day counter work?

It counts whole calendar days from the date you enter through today. The selected start date itself is day zero; later dates use date-only arithmetic, so daylight-saving time does not add or remove a day.

Is my sobriety date uploaded or saved?

No data is uploaded. Your dates are used in this browser only. A note or date can be saved on this device only if you explicitly opt in, and you can clear the local record at any time.

Does the start date count as day one?

No. The chosen start date is day zero. The next calendar date is one elapsed day later.

Can this counter give recovery or medical advice?

No. It counts calendar days and displays milestones only. It does not assess health, substance use, treatment or personal progress.

Are dates and notes sent to a server?

No. Calculations run in your browser. Saving is optional and stores a small record in this browser on this device; you can clear it here.
