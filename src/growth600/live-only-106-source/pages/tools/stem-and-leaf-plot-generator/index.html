Stem and Leaf Plot Generator

Paste up to 250 values to organize them into stems and ordered leaves. Choose the leaf digit and split each stem into one, two or five rows.

Separate values with commas, spaces, semicolons or new lines. Use a period for decimal values.

Enter 1–250 finite values with absolute value at most 1,000,000,000. Values can have up to three decimal places; choose the matching leaf place. Extra decimal digits are rejected, not rounded. Negative stems use a non-negative leaf (for example, −12 is −2 | 8). This descriptive display does not calculate quartiles or remove outliers.

Plot results

How do I make a stem-and-leaf plot?

Enter the data and choose which final digit becomes each leaf. The digits before it form the stem. Values are sorted, and repeated values remain visible as repeated leaves.

Frequently asked questions

How do I make a stem-and-leaf plot?

Enter the data and choose which final digit becomes each leaf. The digits before it form the stem. Values are sorted, and repeated values remain visible as repeated leaves.

Are my data uploaded?

No. The plot is generated in this browser. Your values are not uploaded or saved by this tool.

What is the key in a stem-and-leaf plot?

The key explains how to read one stem and leaf as an original data value. For example, with whole numbers, 1 | 2 means 12. With negative values, this tool uses a floor-based stem, so −2 | 8 means −12.

Can I split stems?

Yes. Choose one row for leaves 0–9, two rows for 0–4 and 5–9, or five rows with two leaf digits per row. Empty split rows are retained to make the grouping clear.

Are duplicate values removed?

No. Every entered value is retained. Repeated values appear as repeated leaf digits, so the plot still shows the original frequency.
