    How do I make a family tree?

    Frequently asked questions

    How do I make a family tree?

    Add each person once, then connect a parent to a child. The chart blocks duplicate links, more than two listed parents and ancestry cycles. Export an SVG diagram or GEDCOM text file when you are ready.

    Is my family information uploaded or saved?

    No. The chart stays in this page session. It is not uploaded or saved to browser storage. An exported file is yours to store and share, so check it for private details first.

    Can this tool find relatives or public records?

    No. It only organizes details you enter. It does not search records, verify identities or establish legal relationships.

    What is a GEDCOM file?

    GEDCOM is a text format used to move family-history records between compatible genealogy programs. Check an exported file before sharing it.

    Does the chart support more than two parents?

    This version allows up to two listed parents per person. A family relationship may be more complex than this chart can represent.
