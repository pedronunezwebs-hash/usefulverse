Sitemap Validator

Paste a sitemap XML document to check its structure, URL entries, dates and common fields. The XML is parsed in this browser only; listed pages are never fetched.

Supports a standard urlset or sitemapindex. Maximum 1,000,000 characters and 5,000 direct entries.

Local XML checks only: this does not request listed URLs, crawl the site, submit the sitemap, or guarantee indexing.

Validation summary

Findings

    What does this sitemap validator check?

    It checks urlset or sitemapindex entries, absolute HTTP or HTTPS locations, duplicate normalized URLs, lastmod dates, optional changefreq and priority values, and the sitemap namespace. Warnings and errors are listed by entry number.

    Frequently asked questions

    What does this sitemap validator check?

    It checks urlset or sitemapindex entries, absolute HTTP or HTTPS locations, duplicate normalized URLs, lastmod dates, optional changefreq and priority values, and the sitemap namespace. Warnings and errors are listed by entry number.

    Does it upload or submit my sitemap?

    No. The XML is processed locally in your browser. The tool does not crawl URLs, fetch remote sitemap files, submit anything to a search engine, or confirm indexing.

    Does this check whether a sitemap URL is live?

    No. It checks URL syntax and duplicates within the pasted XML, but intentionally does not request URLs or crawl the site.

    Does a valid sitemap mean Google indexed its pages?

    No. XML validation is not a search-engine submission or indexing report. Submit a sitemap through the relevant search-engine webmaster tool and check its own status.

    Can I validate a sitemap index?

    Yes. The tool checks direct sitemapindex entries and their loc and lastmod fields, but does not download or recursively inspect referenced sitemap files.
