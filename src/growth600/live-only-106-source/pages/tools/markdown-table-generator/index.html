Markdown Table Generator

Create a Markdown table in a small editable grid. Import comma-separated, semicolon-separated, or tab-separated text, choose column alignment, and copy plain Markdown with pipes safely escaped.

Quoted CSV fields are supported. Import replaces the current grid; up to 100 rows, 20 columns, and 250,000 characters.

The first row becomes the Markdown header. Add at least one row and one column.

Editable table cells

Creates a standard pipe table with a header and separator row. Cell line breaks become <br>; Markdown pipes and backslashes are escaped.

All processing stays in this tab. No upload, account, API, automatic save, or server processing.

How do I make a Markdown table?

Enter a header row and data rows, choose each column alignment, then copy the generated Markdown. Pipes are escaped and uneven imported rows are padded.

Frequently asked questions

How do I make a Markdown table?

Enter a header row and data rows, choose each column alignment, then copy the generated Markdown. Pipes are escaped and uneven imported rows are padded.

Is my table uploaded?

No. Your table is processed in this browser tab. Import, edits, and generated Markdown are not sent to a server or saved automatically.

Can I import CSV or TSV?

Yes. Paste comma-separated, semicolon-separated, or tab-separated values, then import them into the editable grid. Quoted CSV fields and quoted separators are supported.

How are pipes and line breaks handled?

A pipe inside a cell is escaped so it does not split the Markdown table. Backslashes are escaped too, and cell line breaks are represented with <br>.
