Sleep Debt Calculator

Enter recent sleep hours and choose the nightly reference you want to compare against. See shortfalls and above-reference nights separately; this estimate is not a diagnosis or sleep plan.

Enter 1–14 nightly durations in hours, separated by semicolons, spaces or new lines. Decimal hours are allowed; for example, 7.5 means 7 hours 30 minutes. Entries are rounded to the nearest minute.

Choose your own comparison reference from 3 to 12 hours. The default is only an editable starting value, not a recommendation.

This adds each below-reference gap; it does not model sleep physiology or predict recovery. Nights above the reference are shown separately and do not erase earlier shortfalls. Sleep needs vary by person and context. Seek qualified care for persistent sleep problems; this tool does not diagnose or prescribe.

Optional local save uses this browser only; it is never uploaded. Uncheck to calculate without saving, or clear saved data below.

Your comparison

How is this sleep shortfall estimate calculated?

For each night, the calculator compares entered sleep with your chosen reference and adds only nights below that reference. Nights above it are reported separately rather than subtracted from the shortfall. Sleep needs vary, and this arithmetic is not a clinical measure.

Frequently asked questions

How is this sleep shortfall estimate calculated?

For each night, the calculator compares entered sleep with your chosen reference and adds only nights below that reference. Nights above it are reported separately rather than subtracted from the shortfall. Sleep needs vary, and this arithmetic is not a clinical measure.

Is my sleep log uploaded?

No. Calculations run in this browser. The log is saved in this browser on this device only if you check the optional save box; you can clear it here.

How much sleep debt do seven nights one hour below my reference add?

They add seven hours of below-reference time in this calculator. It is a simple arithmetic comparison, not a measure of how the body recovers sleep.

Do longer nights cancel earlier shortfalls?

No. The tool displays above-reference time separately and does not subtract it from the shortfall total. It does not estimate how much recovery sleep a person needs.

Is the default eight-hour reference medical advice?

No. The reference is editable and is used only for comparison. Sleep needs vary by person and circumstances; this tool cannot assess health or diagnose a sleep disorder.
