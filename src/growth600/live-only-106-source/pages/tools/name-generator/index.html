    How does the name generator work?

    Frequently asked questions

    How does the name generator work?

    Choose a name style, result count and optional keyword, then generate. The seed makes the same settings reproducible. Results come from built-in word and syllable lists and are suggestions, not verified names.

    Does this generator check business names or usernames online?

    No. Everything is generated in this browser. It does not search trademark registries, social platforms or domain services, and it does not upload or save your input.

    Can I use a generated business name?

    You can consider it as an idea, but this tool does not check trademarks, existing businesses, usernames or domains. Verify availability and legal requirements before using a name commercially.

    Can I get the same name list again?

    Yes. Keep the same style, count, keyword and seed. Changing any of those settings can change the generated list.
