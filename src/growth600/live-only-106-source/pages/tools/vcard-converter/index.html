VCF to CSV Converter

Turn a VCF file with multiple contacts into one spreadsheet-ready CSV. Choose the fields you need and download a separate file.

Use one source at a time. A single VCF can contain many contacts.

Local processing: the selected file stays in this browser tab. Nothing is added to or changed in your address book.

Reads common text fields in vCard 2.1, 3.0 and 4.0: name, organization, title, phone, email, URL, address and note. Binary photos are ignored. Quoted-printable and non-UTF-8 text are not decoded.

CSV columns to include

Local limits: 5 MiB input, 5,000 contacts and 20 MiB CSV output. Large files may need more device memory; a computer is recommended.

Spreadsheet safety: values that could be treated as formulas start with an apostrophe in the CSV. This intentionally changes those exported cells.

Converted contacts

How do I convert VCF contacts to CSV?

Choose one UTF-8 .vcf file or paste vCard text, select the contact columns to include, then convert and download the CSV. Repeated phone numbers, email addresses and other supported fields stay together in that contact’s row.

Frequently asked questions

How do I convert VCF contacts to CSV?

Choose one UTF-8 .vcf file or paste vCard text, select the contact columns to include, then convert and download the CSV. Repeated phone numbers, email addresses and other supported fields stay together in that contact’s row.

Are my VCF contacts uploaded or changed?

No. The file is read and converted in this browser after you choose it. UsefulVerse does not access your address book, upload the file or change contacts.

Does one contact create one CSV row?

Yes. Each vCard contact becomes one data row. Repeated phone numbers, emails and other supported values are joined with semicolons in that contact’s cell.

Does this include contact photos?

No. Binary photo, logo, sound and key data are ignored; they are not embedded in CSV.

Does conversion modify my contacts?

No. It creates a separate CSV download and never reads from or writes to your device address book.
