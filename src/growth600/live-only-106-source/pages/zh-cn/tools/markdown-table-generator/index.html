Markdown 表生成器

在小型可编辑网格中创建 Markdown 表格。导入逗号分隔、分号分隔或制表符分隔的文本，选择列对齐方式，并复制纯 Markdown 并安全转义管道。

支持带引号的 CSV 字段。导入替换当前网格；最多 100 行、20 列和 250,000 个字符。

第一行成为 Markdown 标题。添加至少一行和一列。

可编辑表格单元格

创建带有标题行和分隔行的标准管道表。细胞系断裂变成<br>； Markdown 管道和反斜杠被转义。

所有处理都在此选项卡中进行。没有上传、帐户、API、自动保存或服务器处理。

常见问题

如何制作 Markdown 表格？

输入标题行和数据行，选择每列对齐方式，然后复制生成的 Markdown。管道被转义，并且不均匀的导入行被填充。

我的表格上传了吗？

否。您的表格将在此浏览器选项卡中处理。导入、编辑和生成的 Markdown 不会发送到服务器或自动保存。

我可以导入 CSV 或 TSV 吗？

是的。粘贴以逗号分隔、分号分隔或制表符分隔的值，然后将它们导入到可编辑网格中。支持带引号的 CSV 字段和带引号的分隔符。

管道和断线如何处理？

单元格内的管道被转义，因此它不会拆分 Markdown 表。反斜杠也被转义，单元格换行符用 <br> 表示。
