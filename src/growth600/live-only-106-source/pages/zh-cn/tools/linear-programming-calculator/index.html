线性规划计算器

输入一个线性目标和最多八个约束来求解 x 和 y 非负的二变量线性程序。两阶段单纯形法报告最优性、不可行性或无界性并显示每个枢轴。

目标系数 (x, y)

每行一个：a,b <= rhs, a,b >= rhs 或 a,b = rhs

在 ±1,000,000 范围内最多使用 8 个约束和系数/右侧。两个决策变量的 x ≥ 0 且 y ≥ 0。在 x 和 y 系数之间使用逗号；每行输入一个不等式或等式。

用于两个变量的两相原始单纯形求解器。数值容差用于浮点主元；近乎退化的问题可能对舍入敏感。报告不可行的、无界的和迭代限制的情况，而不是发明的最佳值。

线性规划结果

结果仅适用于您输入的数学模型。它不验证目标、约束、单位或假设是否适合真正的决策。

    二变量单纯形计算器如何工作？

    它将约束转换为可行的表，在需要时使用第一阶段目标，然后应用原始单纯形枢轴来优化所请求的目标。变量 x 和 y 被限制为非负数。

    常见问题

    二变量单纯形计算器如何工作？

    它将约束转换为可行的表，在需要时使用第一阶段目标，然后应用原始单纯形枢轴来优化所请求的目标。变量 x 和 y 被限制为非负数。

    我的目标和约束条件上传了吗？

    否。求解器在此浏览器中运行。您的目标和约束不会发送到服务器或由该工具保存。

    约束应该使用什么格式？

    每行输入一行，例如 1,1 <= 5 或 2,1 >= 4。第一个数字乘以 x，第二个数字乘以 y，并且两个变量都必须为非负数。

    不可行和无界是什么意思？

    不可行意味着没有点满足每个输入的约束。无界意味着可行的方向可以让所要求的目标不断改进，而无需有限的最佳值。

    结果证明我的现实世界模型是正确的吗？

    否。它仅求解您输入的方程。检查单位、假设以及约束条件是否正确描述了您的决定。
