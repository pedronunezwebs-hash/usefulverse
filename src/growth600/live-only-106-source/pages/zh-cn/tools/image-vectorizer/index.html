矢量预览

如何将图像变成SVG？

选择一个光栅图像，选择其输出细节和颜色计数，然后创建 SVG。该工具将彩色像素轨迹分组为真实的矢量路径；边缘遵循选定的像素网格，因此平面艺术品比照片效果更好。

常见问题

如何将图像变成SVG？

选择一个光栅图像，选择其输出细节和颜色计数，然后创建 SVG。该工具将彩色像素轨迹分组为真实的矢量路径；边缘遵循选定的像素网格，因此平面艺术品比照片效果更好。

我的图片上传了吗？

否。图像在此浏览器选项卡中进行解码和跟踪。它不会上传或自动保存。

SVG 是否包含原始图像？

否。结果包含 SVG 路径形状，而不是嵌入的光栅图像。它通过将像素分组为颜色和路径来近似源。

它能顺利地矢量化照片吗？

否。像素网格轨迹适用于简单的徽标、图标和纯色绘图。照片可以生成块状边缘和大型 SVG 文件。

该工具是否上传或保留我的图像？

否。源在此选项卡中进行处理，不会上传或自动保存。处理速度和内存使用取决于您的设备。
