常见问题

如何计算负数的模数？

该计算器使用小于绝对除数的非负余数。例如，−7 mod 3 为 2，因为 −7 = (−3 × 3) + 2。

我的号码上传了吗？

否。精确的计算在此浏览器中运行。号码不会上传或保存。

−7 mod 3 是什么？

使用欧几里得约定，−7 mod 3 为 2：−7 = (−3 × 3) + 2，且 0 ≤ 2 < 3。

同余模 m 是什么意思？

当两个整数的差可被 |m| 整除时，它们模 m 同余。可选的比较可以准确地检查这一点。

为什么这与编程语言的 % 运算符不同？

某些语言在余数中保留负被除数的符号。该计算器返回从 0 到绝对除数（但不包括绝对除数）的余数。
