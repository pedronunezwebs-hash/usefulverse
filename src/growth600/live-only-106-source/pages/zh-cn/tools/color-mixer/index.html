常见问题

كيف أمزج لونين عبر الإنترنت؟

اختر لونين أو أكثر، واضبط كل وزن، وحدد sRGB أو خلط الضوء الخطي. تظهر النتيجة قيم HEX وRGB وHSL.

هل تم تحميل ألواني؟

لا. يتم تشغيل حسابات الألوان محليًا في متصفحك. ليست هناك حاجة إلى حساب أو تحميل الصورة.

لماذا يبدو مزيج sRGB والضوء الخطي مختلفًا؟

يقوم sRGB بحساب متوسط ​​قيم قناة الشاشة المشفرة. يقوم وضع الضوء الخطي بتحويلها إلى قيم ضوئية أولاً، ثم يمزجها، ثم يحولها مرة أخرى. الطريقة المختارة تغير النتيجة.

هل يمكن التنبؤ بلون الطلاء المختلط؟

لا. هذه هي الرياضيات الرقمية للألوان للشاشات، وليست نموذج صبغ مادي. يعتمد الطلاء الحقيقي على خصائص الصباغ والشفافية والتركيز والإضاءة والسطح.

ما هي تنسيقات الألوان التي يمكنني نسخها؟

تعرض النتيجة HEX وRGB وHSL. يمكنك نسخ قيمة HEX أو تنزيل لوحة ألوان CSS صغيرة.
