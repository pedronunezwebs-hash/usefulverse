圆计算器

根据半径、直径、面积或周长计算圆。探索圆心角弧和扇形测量，或计算圆弧及其弦和弧矢。

使用 0 至 360 度的角度。公式将其转换为弧度。

使用精确的圆公式，JavaScript 值为 π；显示的小数点被四舍五入。圆弧段使用选定的圆心角：低于 180° 为次弧段，高于 180° 为主弧段。输入限制为最多 10^2 的正值和 0° 到 360° 的角度。

结果

如何计算圆？

对于半径 r，直径为 2r，周长为 2πr，面积为 πr²。对于以弧度表示的圆心角 θ，弧长为 rθ，扇形面积为 r²θ/2。对于这些公式，该计算器将输入的角度（以度为单位）转换为弧度。

常见问题

如何计算圆？

对于半径 r，直径为 2r，周长为 2πr，面积为 πr²。对于以弧度表示的圆心角 θ，弧长为 rθ，扇形面积为 r²θ/2。对于这些公式，该计算器将输入的角度（以度为单位）转换为弧度。

我的测量结果是否已上传？

否。公式在此浏览器中运行，并且此工具不会上传或保存您的测量结果。

半径为1的圆的面积和周长是多少？

面积为π（约3.14159），周长为2π（约6.28318）。结果经过四舍五入后显示。

如何计算弧长？

将半径乘以中心角（以弧度表示）。该工具接受度数并在计算之前对其进行转换。

扇区和段有什么区别？

扇形由两个半径和一个圆弧界定。线段以弦及其弧为界；这里它的面积是根据圆心角计算的。
