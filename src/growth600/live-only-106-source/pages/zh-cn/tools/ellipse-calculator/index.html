椭圆计算器

输入椭圆的两个半轴以查找其面积、焦距、偏心率和清晰标记的周长近似值。

以同一单位输入正半轴长度，最多 1,000,000,000。面积使用该单位的平方。周长使用拉马努金的第二近似值，而不是精确的初等公式。

椭圆属性

面积 = πab。中心到焦点距离 c = √(A² − B²)，其中 A 是长半轴，B 是短半轴。偏心率 e = c/A。 Perimeter 使用 Ramanujan II，其中 h = ((A − B)/(A + B))²。

椭圆计算器可以找到什么？

给定两个正半轴，它识别长轴和短轴，计算面积和焦距，并使用拉马努金的第二近似值估计周长。

常见问题

椭圆计算器可以找到什么？

给定两个正半轴，它识别长轴和短轴，计算面积和焦距，并使用拉马努金的第二近似值估计周长。

我的测量结果上传了吗？

否。几何图形在此浏览器中计算。您的值不会发送到服务器或由该工具存储。

如何计算椭圆的面积？

将 π 乘以长半轴和短半轴。如果 a 和 b 是半轴，则面积为 πab。

椭圆周长准确吗？

不。一般椭圆周长没有简单的基本封闭形式。该工具使用拉马努金的第二近似值并将其标记为近似值。

焦点和偏心率是什么意思？

两个焦点位于主轴上，距中心的距离相等。偏心率范围从 0（表示圆形）到 1（表示逐渐拉长的椭圆）。
