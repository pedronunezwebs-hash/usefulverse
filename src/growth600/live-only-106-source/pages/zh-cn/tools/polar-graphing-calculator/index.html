极坐标图计算器

输入角度 θ 的半径函数 r 来绘制极坐标方程。选择角度制或弧度制，调整角度范围和采样数量，然后查看曲线并下载坐标。

使用 θ 或 t 作为角度变量。三角函数遵循所选的角度单位。支持的函数：sin、cos、tan、sqrt、abs、exp、ln 和 log。数值样本可能会遗漏不连续点；这不是象征性的证据。在本地运行；没有上传。

极坐标图

如何绘制极坐标方程？

输入半径表达式（例如 1 或 2*cos(θ)），选择角度范围和单位后计算。图形会将每个采样极坐标点转换为 x=r cos(θ)、y=r sin(θ)。当 r=1 且角度范围为 0° 到 360° 时，结果是单位圆。

如何绘制极坐标方程？

我的方程式上传了吗？

不会。方程是在该浏览器中本地解析和绘制的。它不是由该工具上传或保存的。

r=1 在极坐标中是什么样子？

每个角度距原点一个单位，因此 r=1 形成一个以原点为圆心、半径为 1 的圆。

我可以导出极坐标图点吗？

是的。绘图后，下载包含每个有限采样角度、半径及其笛卡尔 x 和 y 坐标的 CSV。
