什么是原假设？

该测试评估行和列分类是否独立，以观察到的边缘为条件。它没有解释为什么可能存在关联。

如何计算两侧 p 值？

该计算器将具有相同边距的所有可能表的概率相加，且其条件概率不大于观察到的表的条件概率。其他软件约定可能有所不同。

否。p 值不是效应大小或因果关系证明。检查比值比、研究设计、数据质量、不确定性和任何多重测试计划。
