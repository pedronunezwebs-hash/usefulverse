XML 到 CSV 转换器

将简单的 XML 记录列表转换为 CSV 表，或从 CSV 文件的文本构建 XML 记录。选择方向，粘贴数据，然后复制或下载结果。没有上传任何内容。

支持同名记录元素的简单列表，或一个平面记录。元素子元素必须是标量值；嵌套和重复字段不会被展平。

使用第一行作为列名称。 @id 等标头成为 XML 属性。使用 #text 记录文本。

这是简单的表格转换，而不是无损 XML 格式转换。命名空间、嵌套结构、混合内容、注释和 XML 格式都不会保留。文本不识别类型。为了安全起见，类似电子表格公式的 CSV 值带有撇号前缀。

如何将 XML 转换为 CSV？

选择 XML 到 CSV 并粘贴带有简单记录列表的 XML。重复的直接记录元素成为行。元素名称变成列；属性使用 @name。选择 CSV 到 XML 从标题和行创建简单的 XML 记录。

常见问题

如何将 XML 转换为 CSV？

选择 XML 到 CSV 并粘贴带有简单记录列表的 XML。重复的直接记录元素成为行。元素名称变成列；属性使用 @name。选择 CSV 到 XML 从标题和行创建简单的 XML 记录。

我的 XML 或 CSV 上传了吗？

否。在此浏览器中运行解析和转换。输入限制为 200,000 个字符、5,000 行、64 列和 20,000 个单元格。 DTD 和实体声明被阻止，并且无法获取外部资源。

XML 属性如何在 CSV 中显示？

诸如 id="101" 之类的属性将成为名为 @id 的列。转换回来时，以 @ 开头的 CSV 标头将成为 XML 属性。

可以将嵌套XML转换为平面表吗？

否。嵌套子结构、记录内的重复字段和混合文本将被拒绝，而不是被展平或默默丢失。对嵌套数据使用专用的 XML 到 JSON 工作流程。

CSV 会保留 XML 类型和格式吗？

否。CSV 存储单元格文本，而不是 XML 类型、命名空间或格式。类似公式的单元格值在导出时会带有撇号前缀，以降低电子表格公式执行风险。
