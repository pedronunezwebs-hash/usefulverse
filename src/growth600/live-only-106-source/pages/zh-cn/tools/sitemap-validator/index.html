站点地图验证器

粘贴站点地图 XML 文档以检查其结构、URL 条目、日期和公共字段。 XML 仅在该浏览器中进行解析；永远不会获取列出的页面。

支持标准 urlset 或 sitemapindex。最多 1,000,000 个字符和 5,000 个直接条目。

仅本地 XML 检查：这不会请求列出的 URL、抓取站点、提交站点地图或保证索引。

调查结果

    该站点地图验证器检查什么？

    它检查 urlset 或 sitemapindex 条目、绝对 HTTP 或 HTTPS 位置、重复的规范化 URL、lastmod 日期、可选的更改频率和优先级值以及站点地图命名空间。警告和错误按条目号列出。

    常见问题

    该站点地图验证器检查什么？

    它检查 urlset 或 sitemapindex 条目、绝对 HTTP 或 HTTPS 位置、重复的规范化 URL、lastmod 日期、可选的更改频率和优先级值以及站点地图命名空间。警告和错误按条目号列出。

    它会上传或提交我的站点地图吗？

    不会。XML 在您的浏览器中本地处理。该工具不会抓取 URL、获取远程站点地图文件、向搜索引擎提交任何内容或确认索引。

    这是否检查站点地图 URL 是否有效？

    不会。它会检查 URL 语法并在粘贴的 XML 中进行重复，但故意不请求 URL 或抓取网站。

    有效的站点地图是否意味着 Google 对其页面建立了索引？

    不。XML 验证不是搜索引擎提交或索引报告。通过相关搜索引擎站长工具提交站点地图并检查其自身状态。

    我可以验证站点地图索引吗？

    是的。该工具检查直接 sitemapindex 条目及其 loc 和 lastmod 字段，但不会下载或递归检查引用的站点地图文件。
