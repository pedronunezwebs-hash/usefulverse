PDF 书签编辑器

将可导航目录添加到 PDF 或组织其现有书签。创建嵌套部分、分配页面目标、重新排序条目并在浏览器中保存单独的副本。

编辑创建新的 PDF 副本。有些读者可能会以不同的方式显示书签；在共享之前查看保存的副本。

本地限制：25 MiB 输入、300 页、500 个书签、20 个嵌套级别和 50 MiB 输出。大文件可能会占用大量设备内存；建议使用计算机。

创建内部页面目标和嵌套大纲条目。现有的外部链接、指定的目的地或不支持的书签操作将被拒绝，而不是默默地丢弃。页面内容未编辑。数字签名保存后可能会失效。

如何向 PDF 添加书签？

选择 PDF 并阅读其支持的内部页面书签。添加或编辑标题、页面和可选的父部分，排列条目，然后保存单独的 PDF 副本。您还可以将轮廓导入或导出为 JSON.

常见问题

如何向 PDF 添加书签？

选择 PDF 并阅读其支持的内部页面书签。添加或编辑标题、页面和可选的父部分，排列条目，然后保存单独的 PDF 副本。您还可以将轮廓导入或导出为 JSON.

我的 PDF 或书签是否已上传？

编号选择后，所选文档将在此浏览器中进行处理。 UsefulVerse 不会上传 PDF 或将其书签数据发送到服务器。

书签可以嵌套在节下吗？

Y 是的。设置父部分以创建层次结构。文档页面本身保持不变；每个书签都指向您选择的页码。

这会保留打开外部链接的书签吗？

此编辑器当前支持内部页面目标。它拒绝具有不支持的外部操作或命名目标的文件，而不是默默地删除它们。

是否更改 PDF 页面或签名？

它编辑文档大纲并保存新副本，而不是页面内容。任何编辑都可能使数字签名失效，因此请检查结果，不要将此工具视为签名保存。
