PDF 表单拼合器

制作单独的 PDF 副本，其中受支持的 AcroForm 字段会平铺到其可见页面外观中。页面上的文本仍然是可选择和可搜索的。

扁平化会删除新副本中的表单交互性。保留你的原件。现有的数字签名可能会失效或被删除；这不是签名验证工具。

本地限制：25 MiB 输入、300 页、2,500 个字段和 50 MiB 输出。可能不支持复杂、加密或 XFA 表单。对于大文件，建议使用计算机。

仅支持的 AcroForm 字段会被展平。其他评论、突出显示、链接、标记、元数据和可访问性结构不会被扁平化或保证保持不变。

拼合 PDF 表单有什么作用？

它将支持的交互式表单字段外观绘制到页面内容中，并从新副本中删除这些交互式字段。这不会展平一般注释、链接、标记或其他标记注释。

常见问题

拼合 PDF 表单有什么作用？

它将支持的交互式表单字段外观绘制到页面内容中，并从新副本中删除这些交互式字段。这不会展平一般注释、链接、标记或其他标记注释。

我的PDF上传了吗？

否。处理在此浏览器中运行。您选择的 PDF 不会发送到服务器或自动保存。

我仍然可以编辑拼合副本中的字段吗？

否。受支持的字段将成为页面外观的一部分，并且不再具有交互性。如果以后需要编辑，请保留原件。

这是否会扁平化注释、突出显示或数字签名？

否。此工具仅针对受支持的 AcroForm 字段。其他标记注释不会被展平，并且数字签名可能会通过编辑而失效或删除。请勿将其用于经过认证或合法签署的文件。

页面文本仍可搜索吗？

页面内容未转换为图像，因此现有页面文本仍然可搜索。表单字段的外观被扁平化为页面内容。
