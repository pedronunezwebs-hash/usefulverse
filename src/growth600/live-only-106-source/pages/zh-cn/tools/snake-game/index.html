常见问题

贪吃蛇游戏怎么玩？

开始回合，使用 arrow keys、WASD 或触摸按钮转向食物，并避开墙壁和您的身体。随时暂停。吃食物会使蛇长大并加一分。

贪吃蛇游戏会保存我的分数还是使用帐户？

无需帐户或下载。您当前的分数和会话最好仅保留在此 tab 中；您离开后，它们不会上传或保存。

可以在手机或tablet上玩吗？

是的。使用屏幕上的方向按钮。带有 arrow keys 或 WASD 的键盘也可以在计算机上使用。

可以暂停游戏吗？

是的。随时选择暂停；蛇会停止移动，直到您恢复为止。

我每次都会得到相同的游戏吗？

棋盘布局保持熟悉，但每轮新的食物位置都是随机的。您离开后，不会保存当前和最好的会话分数。
