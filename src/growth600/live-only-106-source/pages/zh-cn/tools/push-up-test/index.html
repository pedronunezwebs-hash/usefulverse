我的俯卧撑组上传了吗？

否。计算在此浏览器中运行。仅在您选择加入后，会话历史记录才会写入此设备；你可以在这里删除它。

空行算作一组还是重复？

否。空行将被忽略。带有 0 的行记录零重复集，并且不会将重复添加到总数中。

我可以最多使用一组或多组吗？

是的。输入一行用于单个手动计数的集合，或输入多行以汇总集合以及它们之间的其余部分。测试条件由您决定；结果未与人口标准进行比较。

我的训练历史记录上传了吗？

编号历史记录是可选的，并保留在此设备上的浏览器中。随时使用删除按钮将其清除。
