心率区间计算器

根据基于年龄的最大值或您已知的最大值估计五个运动心率区。选择最大百分比或 Karvonen 储备，然后调整每个区域边界。

区域边界百分比

设置从 0 到 100% 的六个严格递增的截止值。他们创建了五个相邻的区域；从默认值开始或自定义它们。

常见的估计是最大心率 ≈ 220 − 年龄，但这不是测量值，并且对于个人而言可能存在很大差异。默认的 50-100% 截止值只是一个可编辑的分区，而不是建议或 AHA 目标范围； AHA 描述的一般目标是中度至剧烈活动的估计最大值的 50-85% 左右。

药物和健康状况可以改变心率反应。如果您患有心脏病、正在服用影响心率的药物、怀孕了、未满 18 岁或需要个人锻炼目标，请咨询合格的健康专业人士。停止活动并针对相关症状寻求适当的帮助。 CDC 谈话测试是判断相对努力程度的另一种方法。

所有输入都保留在该浏览器中；没有上传或存储任何内容。

来源： 美国心脏协会：目标心率 · CDC.

估计心率区

如何计算心率区间？

选择一种方法和六个递增的百分比边界。最大心率百分比是将您的最大心率乘以每个截止值。 Karvonen 将心率储备百分比（最大值减去静息心率）添加到您的静息心率中。年龄估计使用 220 减去年龄；这只是粗略的人口估计。

常见问题

如何计算心率区间？

选择一种方法和六个递增的百分比边界。最大心率百分比是将您的最大心率乘以每个截止值。 Karvonen 将心率储备百分比（最大值减去静息心率）添加到您的静息心率中。年龄估计使用 220 减去年龄；这只是粗略的人口估计。

我的心率输入是否已保存？

否。计算在此浏览器中运行。此工具不会上传或保存您的年龄、心率和区间截止值。

卡沃宁公式是什么？

它将目标心率估计为静息心率加上选定的心率储备分数。储备心率是最大心率减去静息心率。这个结果仍然是一个估计，而不是个体化处方。

220 减去年龄是准确的最大心率吗？

不。这是美国心脏协会引用的基于年龄的粗略人口估计，而不是对您自己的最大值的测量。健身、健康、药物和个体差异都会影响心率。

心率区是否有医疗限制？

不会。这些范围是针对普通教育的可配置算术估计。临床医生可以帮助设定个人目标，特别是对于心脏病或影响心率的药物。
