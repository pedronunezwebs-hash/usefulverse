Wilks 与 DOTS 力量举重计算器

输入举重者体重和举重总成绩或单次举重成绩。选择一个命名的评分模型以查看可比较的分数；每个模型都单独显示。

仅比较估计。不是当前的官方 IPF Goodlift 分数。使用相同的模型、系数组和事件格式比较结果；规则和模型适用性各不相同。

Wilks 或 DOTS 分数是如何计算的？

每个模型将其发布的体重系数应用于输入的体重，然后按该模型的分母对输入的升力结果进行缩放。仅当使用相同的公式、系数组和事件类型时，结果才具有可比性。

常见问题

Wilks 或 DOTS 分数是如何计算的？

每个模型将其发布的体重系数应用于输入的体重，然后按该模型的分母对输入的升力结果进行缩放。仅当使用相同的公式、系数组和事件类型时，结果才具有可比性。

我的号码是否已上传或保存？

否。计算在此浏览器中运行；输入的值不会上传或保存。

Wilks、Wilks-2 和 DOTS 有什么区别？

它们是单独的体重调整模型，具有不同的公布系数。它们的分数不可互换，并且两种型号可以以不同的方式订购举重器。

这是官方的 IPF 分数吗？

编号。此计算器显示 Wilks、Wilks-2 和 DOTS 估计值。 IPF比赛采用现行的联合会评分系统及其规则；检查组织者的官方结果。

我可以将卧推结果与完整的举重总成绩进行比较吗？

两名运动员使用相同的赛事形式。该算术可以根据任一输入计算得分，但将单次举重与三次举重的总分进行比较并不是同类竞争的比较。
