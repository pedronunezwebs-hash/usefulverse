如何制作事件时间表？

添加至少两个命名事件并为每个事件选择开始日期。添加持续时间的结束日期，或者对于单日事件将其留空。创建时间线以按日期对事件进行排序、调整缩放以及下载 SVG 或 CSV 文件。

常见问题

如何制作事件时间表？

添加至少两个命名事件并为每个事件选择开始日期。添加持续时间的结束日期，或者对于单日事件将其留空。创建时间线以按日期对事件进行排序、调整缩放以及下载 SVG 或 CSV 文件。

我的时间线事件上传了吗？

否。姓名和日期在此浏览器选项卡中处理。 SVG 和 CSV 在您的设备上生成；不会自动上传或保存任何内容。

活动可以持续超过一天吗？

是的。输入开始日期和结束日期。该图表包括两个终点日期；对于单日活动，请将末尾留空。

此时间线是否会创建任务依赖性？

编号 它按时间顺序显示日期事件和范围。使用项目进度工具来确定任务、持续时间和依赖性。

我可以保存或共享时间线吗？

下载可缩放图像的 SVG 或事件表的 CSV。该页面不会上传或自动保存您的事件数据。
