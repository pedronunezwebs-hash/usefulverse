蜘蛛纸牌

在相同的牌组中构建从 K 到 A 的降序序列，展示面朝下的牌并完成所有八个序列。选择一张、两张或四张牌的花色。

留空以进行新的随机游戏。重复使用相同的种子来重现相同的洗牌交易；它仅保留在该页面中。

已完成的序列: 0/8

移动: 0

只有相同牌组的正面朝上的降序组可以一起移动。一张面朝上的牌可以自行移动。面朝下的卡片暴露后会翻转。

已完成的运行将自动删除。空列接受任何面朝上的牌或有效的牌。

如何玩蜘蛛纸牌？

将相同牌组的面朝上降序列移动到下一个更高的等级或空列。揭开隐藏的牌，当每一列都被占据时，从库存牌堆中抽出十张牌，并完成八个相同花色的 King-to-Ace 序列即可获胜。

常见问题

如何玩蜘蛛纸牌？

将相同牌组的面朝上降序列移动到下一个更高的等级或空列。揭开隐藏的牌，当每一列都被占据时，从库存牌堆中抽出十张牌，并完成八个相同花色的 King-to-Ace 序列即可获胜。

蜘蛛纸牌可以保存我的游戏吗？

否。游戏在此选项卡中运行，不会保存游戏、使用帐户、上传动作或将其发送到服务器。开始新的交易会取代当前的游戏。

一、二、四张牌花色有什么区别？

一张牌花色是最轻松的模式，两张牌花色加上另一种花色，四张牌花色需要在混合花色画面中匹配花色。

我什么时候可以从备用牌堆中抽牌？

抽十张牌，每列一张，剩余剩余。从备用牌堆中抽牌之前，每个画面栏必须至少包含一张牌。

撤销是如何工作的？

撤消可恢复之前的移动、股票交易或已完成运行删除的游戏状态。仅在此选项卡中最多保留 100 个最近操作。
