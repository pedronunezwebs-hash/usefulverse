艾森豪威尔矩阵

将任务列表变成四个明确的选择：执行、安排、委派或放弃。 您决定什么是重要且紧急的； 日期是提醒，不是自动判断。

使用自己的上下文对任务进行分类； 矩阵并不能决定对你的重要性。 数据保留在该选项卡的内存中，并在您关闭或重新加载时清除，除非您导出备份。 导入仅接受此工具的 JSON 备份，最多 1 MB 和 300 个任务。

重要意味着它对您关心的目标、责任或结果产生有意义的影响。

紧急意味着由于真正的截止日期或后果而需要尽快关注； 仅截止日期并不能决定重要性。

先做

紧急且重要：立即行动。

    时间表

    重要，不紧急：在事情变得紧急之前预留时间。

      代表

      紧急，不太重要：在适当的时候将其移交并跟踪后续行动。

        考虑放弃

        既不紧急也不重要：将其删除或从计划中删除。

          如何使用艾森豪威尔矩阵？

          为每项任务选择四个象限之一：紧急且重要的任务、重要但不紧急的日程安排、紧急但不那么重要的任务委派，或者都不考虑放弃。 您可以随时更改任务的象限。

          常见问题

          如何使用艾森豪威尔矩阵？

          为每项任务选择四个象限之一：紧急且重要的任务、重要但不紧急的日程安排、紧急但不那么重要的任务委派，或者都不考虑放弃。 您可以随时更改任务的象限。

          我的艾森豪威尔矩阵任务是私有的吗？

          任务保留在此浏览器选项卡中，不会自动上传或保存。 如果您想保留 JSON 备份，请导出它们，然后稍后在此设备上导入该文件。

          艾森豪威尔矩阵每个象限里有什么？

          先做紧急而重要的工作。 安排重要但不紧急的工作。 当其他人可以处理时，将不太重要的紧急工作委托给他人。 考虑放弃既不紧急也不重要的任务。

          截止日期是否会自动使任务变得紧急或重要？

          没有。 截止日期可以帮助您判断紧急程度，但您根据实际的截止日期、后果和目标来决定紧急程度和重要性。
