常见问题

我可以更改哪些 PDF 元数据？

该工具编辑标准文档信息字段：标题、作者、主题、关键字、创建者、制作者、创建日期和修改日期。它不编辑 XMP 元数据或自定义属性。

我的PDF上传了吗？

否。选择文件后，在浏览器中进行读取和编辑。原始文件没有改变；保存会创建单独的 PDF 副本。

这是否会从 PDF 中删除所有元数据？

否。仅编辑标准 PDF 文档信息字典中的常用条目。 XMP、自定义属性、嵌入文件和其他隐藏内容可能会保留。

编辑元数据会保留数字签名吗？

不要依赖它。保存会重写 PDF，并可能使现有数字签名失效或影响此工具不支持的功能。保留原件并验证副本。

原PDF是否被覆盖？

否。该工具读取所选文件并创建单独的可下载副本。它不会修改您设备上的原始版本。
