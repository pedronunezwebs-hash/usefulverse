PDF 辅助功能检查器

在本地检查 PDF 中是否有一些机器可检测的辅助功能信号，包括文档标签、元数据、可选文本、没有替代文本的图形以及标题级跳转。这只是初步检查器，不是 PDF/UA 验证器或辅助技术测试的替代品。

最大 25 MiB 和 300 页。检查可能会使用设备内存；对于大文件，建议使用计算机。

Inspection 将在您的设备上运行。没有上传、帐户、API、自动保存或服务器处理。

这些检查是启发式的。他们无法确认正确的阅读顺序、有意义的描述、颜色对比、键盘使用、表单标签、表头关系或 PDF/UA/Section 508/WCAG 一致性。手动检查并使用辅助技术进行测试。

检验报告

PDF 辅助功能检查器可以检测什么？

它报告 PDF 是否公开结构标签、文档标题和语言、每页上的可选文本、带有替代文本的图形以及标题级别中可能的跳转。它无法决定阅读顺序或替代文本是否有意义。

常见问题

PDF 辅助功能检查器可以检测什么？

它报告 PDF 是否公开结构标签、文档标题和语言、每页上的可选文本、带有替代文本的图形以及标题级别中可能的跳转。它无法决定阅读顺序或替代文本是否有意义。

我的PDF是否已上传以供检查？

否。在此浏览器选项卡中检查所选 PDF。文件及其文本不会上传、自动保存或发送到服务器。

阳性结果是否意味着 PDF 可以访问？

否。这些只是有限的自动信号。带标签的 PDF 仍然可能存在阅读顺序不正确、描述不清晰、表格无法访问、对比度低或其他障碍。仍然需要手动和辅助技术测试。

能否确认 PDF/UA 或 WCAG 合规性？

否。此首次检查程序不会测试所有要求，并且无法证明 PDF/UA、WCAG、第 508 节或法律合规性。
