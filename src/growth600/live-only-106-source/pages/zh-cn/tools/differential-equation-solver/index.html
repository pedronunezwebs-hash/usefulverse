微分方程求解器

使用固定步长 Runge-Kutta 近似一阶初始值问题 y′ = f(x,y) 4. 输入导数、起点和值、终点以及步数。一切都在这个浏览器中运行。

使用 x 和 y、数字、+ − × ÷ 和 ^。支持的函数：sin、cos、tan、exp、ln、log、sqrt 和 abs。显式地写出乘法，例如 x*y。

RK4微分方程求解器如何工作？

RK4 每步使用四个斜率评估来估计解。较小的步长通常可以提高平滑解的准确性，但这种数值估计不是符号解或精确解。

我的方程和值是否已上传？

否。计算、图表和 CSV 在此浏览器中创建。该工具不会上传或保存您的输入。

龙格-库塔法计算什么？

通过在每一步中重复使用多个导数样本，从起点估计解的路径。本页使用经典的四阶RK方法。

我应该使用多少步？

从示例开始，并使用更多步骤比较结果。较小的步长可以改善平滑解，但无法修复奇点或使刚性方程适合此基本方法。

能准确求解每个微分方程吗？

否。它在数值上近似支持的一阶初始值问题。它不提供符号通用解决方案、证明唯一性或保证误差范围。
