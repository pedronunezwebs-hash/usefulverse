如何使用此呼吸练习？

我的呼吸练习数据会被上传吗？

不会。计时过程仅在当前页面运行。不涉及账户、数据上传、API 调用或会话记录保存。

我可以使用方框呼吸法或 4-7-8 呼吸法吗？

可以。您可以选择预设模式，也可以自行调整各阶段时长。这些是呼吸节奏引导，不是医疗手段。

关闭标签页后，练习还会继续吗？

无法保证。浏览器可能暂停后台标签页，设备也可能进入休眠状态。为确保计时准确，请保持页面开启并让设备处于唤醒状态。

我可以关闭声音或提前结束练习吗？

可以。声音是可选的，点击“开始”后才会播放，也可以取消勾选。点击“暂停”或“重置”会立即停止计时。
