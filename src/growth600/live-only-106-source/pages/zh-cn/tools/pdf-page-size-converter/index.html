PDF页面尺寸转换器

将 PDF 中的每个页面调整为 A4、US Letter、Legal 或自定义纸张尺寸。预览新尺寸，适合整个原始页面区域，然后下载在您的设备上处理的单独副本。

调整大小会创建一个单独的副本。重新保存可能会使数字签名失效。分享前保留原件并检查新的 PDF。

本地限制：25 MiB 输入、300 页和 50 MiB 输出。大文件可能会占用大量内存；建议使用计算机。

为了避免静默更改，此工具拒绝旋转页面、自定义页面框、注释、链接和交互式表单。适合模式会缩放整个现有页面矩形，并且无法恢复已超出其边界的内容。

常见问题

如何更改 PDF 的页面大小？

选择 PDF，检查其页面，选择 A4、Letter、Legal 或自定义尺寸，然后选择适合页面或实际尺寸。适合模式按比例缩放并将每个完整页面区域居中。下载新副本并保留原始副本。

我的 PDF 是否已上传以调整其大小？

编号选择 PDF 后，将在此浏览器中对其进行处理。它不是由 UsefulVerse 上传或保存的。大型 PDF 可以使用设备内存；建议使用计算机。

我可以将 PDF 大小调整为 A4 或 US Letter 吗？

Y 是的。选择 A4、US Letter 或 US Legal，选择纵向或横向，然后预览结果。自定义尺寸也可以以毫米或英寸为单位输入。

调整大小会裁剪 PDF 内容吗？

Fit 模式统一缩放完整的原始页面矩形并将其置于新纸张的中心。它不是故意裁剪的。无法恢复原始 PDF 页面边界之外的内容。

这是否保留链接、表格或数字签名？

此工具拒绝带有注释、链接、交互字段、旋转或自定义页面框的页面，而不是默默地删除它们。保存 PDF 可能会使数字签名失效；保留并查看原件。
