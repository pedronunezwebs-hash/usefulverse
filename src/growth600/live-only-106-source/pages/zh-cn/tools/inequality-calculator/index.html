不等式计算器

求解与零相比的 ax² + bx + c 形式的实数线性或二次不等式。查看临界点、区间表示法和数轴总结。

仅支持常数、线性和二次实数不等式 ax² + bx + c <、≤、> 或 ≥ 0。系数必须是有限的，绝对值最多为 10⁹。根是近似值，因为计算使用浮点数。基于比例的容差用于重复根附近。

找到多项式的实零点，然后确定这些零点之间和之外的符号。该工具返回真实的解区间以及是否包含每个有限端点。

常见问题

如何解二次不等式？

找到多项式的实零点，然后确定这些零点之间和之外的符号。该工具返回真实的解区间以及是否包含每个有限端点。

我的系数上传了吗？

否。不等式是在该浏览器中计算的，不是由该工具上传或保存的。

区间表示法表示什么？

圆括号表示排除某个端点，而方括号表示包含该端点。无穷大总是使用括号，因为无穷大不是真正的端点。

我可以解三次不等式或有理不等式吗？

否。此计算器仅限于零次、一次或二次实多项式。它不能解决三次不等式、有理不等式、绝对值不等式或复合不等式。

根准确吗？

否。系数和根使用浮点运算。接近重复根或系数大小差异很大的结果可能对舍入敏感。
