સાપ રમત

સાપને ખોરાક માટે માર્ગદર્શન આપો, લાંબા સમય સુધી વધો અને દિવાલો અને તમારી પોતાની પૂંછડીને ટાળો. arrow keys, WASD અથવા ઑન-સ્ક્રીન નિયંત્રણો સાથે રમો.

arrow keys, W A S D અથવા દિશા બટનોનો ઉપયોગ કરો. દિવાલ અને તમારા પોતાના શરીરને ટાળો. રમત ઘડિયાળને રોકવા માટે થોભો.

તમે સાપની રમત કેવી રીતે રમો છો?

રાઉન્ડ શરૂ કરો, arrow keys, WASD અથવા ટચ બટનોનો ઉપયોગ કરીને ખોરાક તરફ આગળ વધો અને દિવાલો અને તમારા શરીરને ટાળો. કોઈપણ સમયે થોભો. ખોરાક ખાવાથી સાપ વધે છે અને એક બિંદુ ઉમેરે છે.

શું સાપની રમત મારો સ્કોર બચાવે છે અથવા એકાઉન્ટનો ઉપયોગ કરે છે?

કોઈ એકાઉન્ટ અથવા ડાઉનલોડની જરૂર નથી. તમારો વર્તમાન સ્કોર અને સત્ર શ્રેષ્ઠ માત્ર આ tab માં મેમરીમાં રહે છે; તમે છોડ્યા પછી તેઓ અપલોડ અથવા સાચવવામાં આવતા નથી.

શું હું ફોન અથવા tablet પર રમી શકું?

હા. ઑન-સ્ક્રીન દિશા બટનોનો ઉપયોગ કરો. arrow keys અથવા WASD સાથેનું કીબોર્ડ પણ કમ્પ્યુટર પર કામ કરે છે.

શું હું રમત થોભાવી શકું?

હા. કોઈપણ સમયે થોભો પસંદ કરો; જ્યાં સુધી તમે ફરી શરૂ ન કરો ત્યાં સુધી સાપ ચાલવાનું બંધ કરે છે.

શું મને દર વખતે સમાન રમત મળશે?

બોર્ડ લેઆઉટ પરિચિત રહે છે, પરંતુ ખોરાકની સ્થિતિ દરેક નવા રાઉન્ડ માટે રેન્ડમાઇઝ્ડ છે. તમે છોડ્યા પછી વર્તમાન અને શ્રેષ્ઠ સત્ર સ્કોર્સ સાચવવામાં આવતા નથી.

હોમ

મફત બ્રાઉઝર સાધનો. જ્યાં સાધન મંજૂરી આપે ત્યાં તમારો ડેટા તમારા ઉપકરણમાં રહે છે.
