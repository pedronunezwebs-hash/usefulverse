PDF પૃષ્ઠ કદ કન્વર્ટર

PDF માં A4, US પત્ર, કાનૂની અથવા કસ્ટમ પેપર સાઇઝમાં દરેક પૃષ્ઠનું કદ બદલો. નવા પરિમાણોનું પૂર્વાવલોકન કરો, સંપૂર્ણ મૂળ પૃષ્ઠ વિસ્તારને ફિટ કરો અને તમારા ઉપકરણ પર પ્રક્રિયા કરેલ એક અલગ નકલ ડાઉનલોડ કરો.

Resizing એક અલગ નકલ બનાવે છે. રિ-સેવિંગ ડિજિટલ હસ્તાક્ષરોને અમાન્ય કરી શકે છે. ઓરિજિનલ રાખો અને શેર કરતા પહેલા નવી PDF તપાસો.

સ્થાનિક મર્યાદા: 25 MiB ઇનપુટ, 300 પૃષ્ઠો અને 50 MiB આઉટપુટ. મોટી ફાઇલો નોંધપાત્ર મેમરીનો ઉપયોગ કરી શકે છે; કમ્પ્યુટરની ભલામણ કરવામાં આવે છે.

મૌન ફેરફારોને ટાળવા માટે, આ સાધન ફેરવાયેલા પૃષ્ઠો, કસ્ટમ પૃષ્ઠ બોક્સ, ટીકાઓ, લિંક્સ અને ઇન્ટરેક્ટિવ સ્વરૂપોને નકારી કાઢે છે. ફીટ મોડ સમગ્ર વર્તમાન પૃષ્ઠ લંબચોરસને માપે છે અને તેની સીમાની બહાર પહેલાથી જ સામગ્રીને પુનઃસ્થાપિત કરી શકતું નથી.
