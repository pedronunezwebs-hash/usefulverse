બે સ્વતંત્ર જૂથો માટે તેમના હસ્તાક્ષરિત પ્રમાણિત સરેરાશ તફાવત, પૂલ કરેલ પ્રમાણભૂત વિચલન અને નાના-નમૂના સુધારેલ હેજીસ જીની ગણતરી કરવા માટે સારાંશ આંકડા દાખલ કરો.

દરેક નમૂનાનું કદ 2-1,000,000 હોવું જોઈએ; અર્થ અને SD ±1,000,000,000 સુધી મર્યાદિત છે (SDs નકારાત્મક હોઈ શકતું નથી). ઓછામાં ઓછું એક SD શૂન્યથી ઉપર હોવું આવશ્યક છે.

શું મારા અભ્યાસના આંકડા અપલોડ કરવામાં આવ્યા છે?

નંબર. ગણતરી આ બ્રાઉઝરમાં ચાલે છે. તમારા સારાંશના આંકડા સર્વર પર મોકલવામાં આવતા નથી અથવા આ સાધન દ્વારા સાચવવામાં આવતા નથી.

Cohen's d અને Hedges'g વચ્ચે શું તફાવત છે?

બંને એક સંકલિત પ્રમાણભૂત વિચલન દ્વારા સરેરાશ તફાવતને પ્રમાણિત કરે છે. હેજ્સનો g નાના-નમૂના સુધારણા દ્વારા d ગુણાકાર કરે છે, જે જ્યારે નમૂના નાના હોય ત્યારે પૂર્વગ્રહ ઘટાડે છે.

શું હું પ્રમાણભૂત વિચલનોને બદલે પ્રમાણભૂત ભૂલો દાખલ કરી શકું?

નંબર. આ કેલ્ક્યુલેટર દરેક જૂથના નમૂના પ્રમાણભૂત વિચલનની અપેક્ષા રાખે છે. પ્રમાણભૂત ભૂલ નમૂના અંદાજમાં અનિશ્ચિતતાનું વર્ણન કરે છે અને અહીં SD સાથે વિનિમયક્ષમ નથી.

શું અસરનું મોટું કદ સાબિત કરે છે કે પરિણામ મહત્વપૂર્ણ છે?

નંબર. અસરનું કદ પ્રમાણિત તફાવતનું વર્ણન કરે છે, આંકડાકીય મહત્વ, કારણ અથવા વ્યવહારિક મહત્વ નહીં. સંદર્ભ, અનિશ્ચિતતા, અભ્યાસ ડિઝાઇન અને માપન સ્કેલ બાબત.
