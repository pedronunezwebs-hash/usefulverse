વાપરવા માટે મફત, એકાઉન્ટ વગર

સાપ્તાહિક પ્લાનર

કાર્ય, અંગત યોજનાઓ, અભ્યાસ અથવા આરોગ્ય માટે એક સરળ સાપ્તાહિક સમય-બ્લોક શેડ્યૂલ બનાવો. રાતોરાત બ્લોક્સ અને શેડ્યૂલ તકરાર સ્પષ્ટ રીતે બતાવવામાં આવે છે.

પુનરાવર્તિત સાપ્તાહિક યોજના સ્થાનિક વોલ-ક્લોક સમયનો ઉપયોગ કરે છે; તે સમય ઝોન, ડેલાઇટ-સેવિંગ ફેરફારો, કેલેન્ડર ઇવેન્ટ્સ અથવા રીમાઇન્ડર્સ માટે જવાબદાર નથી.

આ ટેબમાં પ્લાન મેમરીમાં રહે છે. તેને રાખવા માટે JSON બેકઅપ ડાઉનલોડ કરો; કોઈ સ્વચાલિત સંગ્રહ અથવા અપલોડ નથી.

સાપ્તાહિક શેડ્યૂલ

હું સાપ્તાહિક શેડ્યૂલ કેવી રીતે બનાવી શકું?

દરેક બ્લોક માટે શીર્ષક, દિવસ, પ્રારંભ સમય, સમાપ્તિ સમય અને શ્રેણી ઉમેરો. બ્લોક મધ્યરાત્રિને પાર કરી શકે છે. ઓવરલેપિંગ સમય, રવિવાર અને સોમવાર સહિત, ફ્લેગ કરવામાં આવે છે.

વારંવાર પૂછાતા પ્રશ્નો

હું સાપ્તાહિક શેડ્યૂલ કેવી રીતે બનાવી શકું?

દરેક બ્લોક માટે શીર્ષક, દિવસ, પ્રારંભ સમય, સમાપ્તિ સમય અને શ્રેણી ઉમેરો. બ્લોક મધ્યરાત્રિને પાર કરી શકે છે. ઓવરલેપિંગ સમય, રવિવાર અને સોમવાર સહિત, ફ્લેગ કરવામાં આવે છે.

શું મારું સાપ્તાહિક શેડ્યૂલ અપલોડ અથવા સાચવેલ છે?

ના. જ્યાં સુધી તમે JSON બેકઅપ ડાઉનલોડ કરવાનું પસંદ ન કરો ત્યાં સુધી તમારું શેડ્યૂલ આ બ્રાઉઝર ટૅબમાં રહે છે. તમે તમારા ઉપકરણમાંથી પસંદ કરેલ બેકઅપ આયાત કરો.

શું સાપ્તાહિક પ્લાનર રાતોરાત શિફ્ટનો સમાવેશ કરી શકે છે?

હા. બીજા દિવસે સમાપ્ત થતો બ્લોક બનાવવા માટે પ્રારંભ સમય કરતાં વહેલો સમાપ્તિ સમય પસંદ કરો. 18 કલાક સુધીના બ્લોક્સ સપોર્ટેડ છે.

શું સાપ્તાહિક શેડ્યૂલ તકરાર શોધે છે?

હા. તે તે જ દિવસે અને મધ્યરાત્રિ દરમિયાન સમય બ્લોક્સ તપાસે છે, જેમાં રવિવારના બ્લોકનો સમાવેશ થાય છે જે સોમવારે ઓવરલેપ થાય છે.

શું આ પ્લાનર ગૂગલ કેલેન્ડર સાથે સમન્વયિત થાય છે?

ના. તે આ ટૅબમાં સ્થાનિક રીતે કામ કરે છે અને તેમાં કોઈ કૅલેન્ડર કનેક્શન કે રિમાઇન્ડર સેવા નથી. તમે પ્લાન પ્રિન્ટ કરી શકો છો અથવા JSON બેકઅપ ડાઉનલોડ કરીને આયાત કરી શકો છો.

હોમ

મફત બ્રાઉઝર સાધનો. જ્યાં સાધન મંજૂરી આપે ત્યાં તમારો ડેટા તમારા ઉપકરણમાં રહે છે.
