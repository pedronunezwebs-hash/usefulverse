PDF મેટાડેટા એડિટર

PDF માં સંગ્રહિત સામાન્ય દસ્તાવેજ માહિતી વાંચો અથવા સંપાદિત કરો, પછી એક અલગ નકલ ડાઉનલોડ કરો. પસંદ કરેલ PDF આ ઉપકરણ પર રહે છે.

તમારું મૂળ રાખો. રિ-સેવિંગ ડિજિટલ હસ્તાક્ષરોને અમાન્ય કરી શકે છે અથવા અદ્યતન PDF સુવિધાઓને અસર કરી શકે છે. આ સાધન છુપી માહિતીને દૂર કરતું નથી અથવા ગોપનીયતાને પ્રમાણિત કરતું નથી.

સ્થાનિક મર્યાદા: 25 MiB ઇનપુટ, 300 પૃષ્ઠો અને 50 MiB આઉટપુટ. મોટા દસ્તાવેજોને વધુ મેમરીની જરૂર પડી શકે છે; કમ્પ્યુટરની ભલામણ કરવામાં આવે છે.

માત્ર પ્રમાણભૂત PDF દસ્તાવેજ માહિતી સંપાદિત કરવામાં આવે છે. XMP, કસ્ટમ મેટાડેટા, જોડાણો, છુપાયેલ સામગ્રી અને સહી માન્યતા સમર્થિત નથી.

પ્રમાણભૂત દસ્તાવેજ માહિતી

નવી નકલમાંથી તે પ્રમાણભૂત માહિતી એન્ટ્રીને દૂર કરવા માટે એક ફીલ્ડ ખાલી છોડો. અન્ય ક્ષેત્રો રાખવામાં આવે છે.

તમારી PDF નકલ તૈયાર છે

સંપાદિત PDF

પ્રોસેસિંગ સ્થાનિક છે. કોઈ એકાઉન્ટ, અપલોડ, સર્વર પ્રોસેસિંગ અથવા સ્વચાલિત બચત નથી.

હું કયો PDF મેટાડેટા બદલી શકું?

આ સાધન પ્રમાણભૂત દસ્તાવેજ માહિતી ક્ષેત્રોને સંપાદિત કરે છે: શીર્ષક, લેખક, વિષય, કીવર્ડ્સ, સર્જક, નિર્માતા, બનાવટની તારીખ અને ફેરફારની તારીખ. તે XMP મેટાડેટા અથવા કસ્ટમ ગુણધર્મોને સંપાદિત કરતું નથી.

વારંવાર પૂછાતા પ્રશ્નો

હું કયો PDF મેટાડેટા બદલી શકું?

આ સાધન પ્રમાણભૂત દસ્તાવેજ માહિતી ક્ષેત્રોને સંપાદિત કરે છે: શીર્ષક, લેખક, વિષય, કીવર્ડ્સ, સર્જક, નિર્માતા, બનાવટની તારીખ અને ફેરફારની તારીખ. તે XMP મેટાડેટા અથવા કસ્ટમ ગુણધર્મોને સંપાદિત કરતું નથી.

શું મારી PDF અપલોડ કરવામાં આવી છે?

નંબર. તમે ફાઇલ પસંદ કર્યા પછી તમારા બ્રાઉઝરમાં વાંચન અને સંપાદન થાય છે. મૂળ ફાઇલ બદલાઈ નથી; બચત એક અલગ PDF નકલ બનાવે છે.

શું આ પીડીએફમાંથી તમામ મેટાડેટા દૂર કરે છે?

નંબર. તે પ્રમાણભૂત PDF દસ્તાવેજ માહિતી શબ્દકોશમાં માત્ર સામાન્ય એન્ટ્રીઓને સંપાદિત કરે છે. XMP, કસ્ટમ પ્રોપર્ટીઝ, એમ્બેડેડ ફાઇલો અને અન્ય છુપાયેલ સામગ્રી રહી શકે છે.

શું મેટાડેટાનું સંપાદન ડિજિટલ હસ્તાક્ષર સાચવશે?

તેના પર આધાર રાખશો નહીં. સાચવવાથી પીડીએફ ફરીથી લખાય છે અને હાલના ડિજિટલ હસ્તાક્ષરોને અમાન્ય કરી શકે છે અથવા આ સાધન દ્વારા સમર્થિત ન હોય તેવી સુવિધાઓને અસર કરી શકે છે. અસલ રાખો અને નકલ ચકાસો.

શું મૂળ પીડીએફ ઓવરરાઈટ છે?

નંબર. ટૂલ પસંદ કરેલી ફાઇલ વાંચે છે અને એક અલગ ડાઉનલોડ કરી શકાય તેવી નકલ બનાવે છે. તે તમારા ઉપકરણ પરના મૂળમાં ફેરફાર કરતું નથી.
