Конвертер XML в CSV

Превратите простой список записей XML в таблицу CSV или создайте записи XML из текста файла CSV. Выберите направление, вставьте свои данные, затем скопируйте или загрузите результат. Ничего не загружается.

Поддерживает простой список элементов записи с одинаковым именем или одну неструктурированную запись. Дочерние элементы должны быть скалярными значениями; вложенные и повторяющиеся поля не выравниваются.

Используйте первую строку для имен столбцов. Заголовок, например @id, становится атрибутом XML. Используйте #text для текста записи.

Это простое преобразование таблицы, а не преобразование формата XML без потерь. Пространства имен, вложенные структуры, смешанный контент, комментарии и форматирование XML не сохраняются. Текст не учитывает тип. Значения CSV, подобные формулам электронных таблиц, в целях безопасности начинаются с апострофа.

Результат

Проверьте выходные данные перед импортом их в другое приложение.

Как преобразовать XML в CSV?

Выберите XML в CSV и вставьте XML с простым списком записей. Повторяющиеся элементы прямой записи становятся строками. Имена элементов становятся столбцами; атрибуты используют @name. Выберите CSV в XML, чтобы создавать простые записи XML из заголовков и строк.

Часто задаваемые вопросы

Как преобразовать XML в CSV?

Выберите XML в CSV и вставьте XML с простым списком записей. Повторяющиеся элементы прямой записи становятся строками. Имена элементов становятся столбцами; атрибуты используют @name. Выберите CSV в XML, чтобы создавать простые записи XML из заголовков и строк.

Загружен ли мой файл XML или CSV?

Нет. Анализ и преобразование выполняются в этом браузере. Ввод ограничен 200 000 символов, 5 000 строк, 64 столбцами и 20 000 ячеек. Объявления DTD и сущностей блокируются, а внешние ресурсы не извлекаются.

Как атрибуты XML отображаются в CSV?

Атрибут, например id="101", становится столбцом с именем @id. При обратном преобразовании заголовок CSV, начинающийся с @, становится атрибутом XML.

Может ли он преобразовать вложенный XML в плоскую таблицу?

Нет. Вложенные дочерние структуры, повторяющиеся поля внутри записи и смешанный текст отклоняются, а не сглаживаются или теряются без уведомления. Используйте специальный рабочий процесс преобразования XML в JSON для вложенных данных.

Сохранит ли CSV типы и форматирование XML?

Нет. В формате CSV хранится текст ячеек, а не типы XML, пространства имен или форматирование. Значения ячеек, подобные формулам, получают префикс апострофа при экспорте, чтобы снизить риск выполнения формулы электронной таблицы.
