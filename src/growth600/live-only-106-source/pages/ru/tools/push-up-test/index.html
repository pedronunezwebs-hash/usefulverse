Тест на отжимания и учёт подходов

Запишите один набор в качестве простого теста или запишите несколько наборов, а остальные - между ними. Вы считаете и вводите повторения; этот инструмент не использует вашу камеру и не оценивает вашу силу.

Введите до 20 целых чисел от 0 до 500. Пустые строки игнорируются и не считаются наборами. Считайте только повторения, которые вы выполнили с выбранной формой.

Сохраняйте общие заметки; это не медицинская карта.

Выберите удобный диапазон движений и остановитесь, если почувствуете боль, головокружение или необычную одышку. Количество повторений зависит от формы, темпа и условий испытаний; этот инструмент не предоставляет рейтинг физической подготовки, диагноз или рекомендации по упражнениям.

Сохранение не является обязательным и используется только в этом браузере. Снимите флажок, чтобы выполнить расчет без сохранения, или очистите сохраненную историю ниже.

Ваш сеанс

Как трекер теста на отжимания отслеживает общее количество повторений?

Добавляет целочисленные повторения, введенные для каждого непустого набора. Пустые строки игнорируются, набор нулей остается нулевым, а оценка остатка равна отдыху за перерыв, умноженному на количество перерывов.

Часто задаваемые вопросы

Как трекер теста на отжимания отслеживает общее количество повторений?

Добавляет целочисленные повторения, введенные для каждого непустого набора. Пустые строки игнорируются, набор нулей остается нулевым, а оценка остатка равна отдыху за перерыв, умноженному на количество перерывов.

Загружены ли мои комплекты для отжиманий?

Нет. Расчеты выполняются в этом браузере. История сеансов записывается на это устройство только после вашего согласия; вы можете удалить его здесь.

Пустые строки считаются набором или повторением?

Нет. Пустые строки игнорируются. Строка с 0 записывает набор с нулевым повторением и не добавляет повторений к общему количеству.

Могу ли я использовать это для одного максимального набора или для нескольких наборов?

Да. Введите одну строку для одного набора, подсчитанного вручную, или несколько строк для суммирования наборов и остальных между ними. Условия тестирования зависят от вас; результаты не сравниваются с популяционными нормами.

Загружена ли моя история тренировок?

Нет. История не является обязательной и сохраняется в браузере на этом устройстве. Очистите его с помощью кнопки «Удалить», когда захотите.
