Калькулятор линейного программирования

Введите линейную цель и до восьми ограничений для решения линейной программы с двумя переменными с неотрицательными значениями x и y. Двухфазный симплексный метод сообщает об оптимуме, неосуществимости или неограниченности и показывает каждый поворотный момент.

Целевые коэффициенты (x, y)

По одному на строку: a,b <= правая сторона, a,b >= правая сторона или a,b = правая сторона

Использует не более восьми ограничений и коэффициентов/правых частей в пределах ±1 000 000. Обе переменные решения имеют x ≥ 0 и y ≥ 0. Используйте запятую между коэффициентами x и y; введите по одному неравенству или равенству в каждой строке.

Двухфазный решатель простых симплексов для двух переменных. Числовой допуск используется для поворотов с плавающей запятой; почти вырожденные задачи могут быть чувствительны к округлению. Вместо придуманного оптимума приводятся неосуществимые, неограниченные и итерационные случаи.

Результаты линейной программы

Результат относится только к введенной вами математической модели. Он не проверяет, подходят ли цель, ограничения, единицы или предположения для реального решения.

    Как работает симплексный калькулятор с двумя переменными?

    Он преобразует ограничения в осуществимую таблицу, при необходимости использует цель Фазы I, а затем применяет основные симплексные повороты для оптимизации запрошенной цели. Переменные x и y должны быть неотрицательными.

    Часто задаваемые вопросы

    Как работает симплексный калькулятор с двумя переменными?

    Он преобразует ограничения в осуществимую таблицу, при необходимости использует цель Фазы I, а затем применяет основные симплексные повороты для оптимизации запрошенной цели. Переменные x и y должны быть неотрицательными.

    Загружены ли мои цели и ограничения?

    Нет. Решающая программа работает в этом браузере. Ваша цель и ограничения не отправляются на сервер и не сохраняются с помощью этого инструмента.

    Какой формат следует использовать для ограничений?

    Введите по одной строке в строке, например 1,1 <= 5 или 2,1 >= 4. Первое число умножает x, второе умножает y, и обе переменные должны быть неотрицательными.

    Что означают неосуществимость и неограниченность?

    Недопустимо означает, что ни одна точка не удовлетворяет всем введенным ограничениям. Неограниченность означает, что допустимое направление позволяет продолжать улучшаться запрошенной цели без конечного оптимума.

    Подтверждает ли результат правильность моей реальной модели?

    Нет. Он решает только введенные вами уравнения. Проверьте единицы измерения, предположения и убедитесь, что ограничения правильно описывают ваше решение.
