Калькулятор по модулю

Вычисляет евклидово частное и остаток для целых чисел. Отрицательные входные данные обрабатываются последовательно, а тождество деления показывает, как формируется ответ.

Число, которое нужно разделить; оно может быть отрицательным.

Используйте любое ненулевое целое число; его абсолютное значение определяет модуль.

Проверьте, соответствует ли это значение делимому по модулю делителя.

Принимает целые числа со знаком длиной до 50 цифр. Никаких дробей и десятичных знаков. В результате используется евклидов модуль; некоторые языки программирования используют другое правило остатка для отрицаний.

Результат

Как вычислить модуль отрицательного числа?

В этом калькуляторе используется неотрицательный остаток, меньший абсолютного делителя. Например, −7 по модулю 3 равно 2, поскольку −7 = (−3 × 3) + 2.

Часто задаваемые вопросы

Как вычислить модуль отрицательного числа?

В этом калькуляторе используется неотрицательный остаток, меньший абсолютного делителя. Например, −7 по модулю 3 равно 2, поскольку −7 = (−3 × 3) + 2.

Загружены ли мои номера?

Нет. Точный расчет выполняется в этом браузере. Номера не загружаются и не сохраняются.

Что такое −7 мод 3?

Согласно евклидову соглашению, −7 по модулю 3 равно 2: −7 = (−3 × 3) + 2 и 0 ≤ 2 < 3.

Что означает соответствие по модулю m?

Два целых числа равны по модулю m, если их разность делится на |m|. Необязательное сравнение точно проверяет это.

Почему он может отличаться от оператора % языка программирования?

В некоторых языках сохраняется знак отрицательного делимого в остатке. Вместо этого этот калькулятор возвращает остаток от 0 до абсолютного делителя, но не включая его.
