መነሻ/ቀለም ቀላቃይ

ነጻ፣ መለያ አያስፈልግም

ቀለም ቀላቃይ

ቀለሞችን ሊስተካከል ከሚችል ክብደቶች ጋር ያዋህዱ፣ ሁለት ዲጂታል መቀላቀያ ሁነታዎችን ያወዳድሩ እና በመጀመሪያዎቹ ሁለት ቀለሞች መካከል የዝውውር መወጣጫ ይገንቡ። ምንም አልተሰቀለም።

ለመደባለቅ ቀለሞች

የተመረጠው ዘዴ ውጤቱን ይነካል. sRGB የሚታዩ የሰርጥ ዋጋዎችን ያዋህዳል; መስመራዊ ብርሃን ከመቀላቀል በፊት ቻናሎችን ይለውጣል።

ይህ የዲጂታል ስክሪን ቀለሞችን ይተነብያል እንጂ እውነተኛ ቀለም ወይም ቀለሞች እንዴት እንደሚቀላቀሉ አይደለም።

በዚህ አሳሽ ውስጥ ይሰራል። ቀለሞች አይሰቀሉም ወይም በራስ-ሰር አይቀመጡም.

የቀለም መወጣጫ

በመስመር ላይ ሁለት ቀለሞችን እንዴት እቀላቅላለሁ?

ሁለት ወይም ከዚያ በላይ ቀለሞችን ምረጥ፣ እያንዳንዱን ክብደት አዘጋጅ እና sRGB ወይም linear-light ድብልቅን ምረጥ። ውጤቱ HEX፣ RGB እና HSL እሴቶችን ያሳያል።

ተደጋጋሚ ጥያቄዎች

በመስመር ላይ ሁለት ቀለሞችን እንዴት እቀላቅላለሁ?

ሁለት ወይም ከዚያ በላይ ቀለሞችን ምረጥ፣ እያንዳንዱን ክብደት አዘጋጅ እና sRGB ወይም linear-light ድብልቅን ምረጥ። ውጤቱ HEX፣ RGB እና HSL እሴቶችን ያሳያል።

ቀለሞቼ ተሰቅለዋል?

አይ የቀለም ስሌት በአሳሽዎ ውስጥ በአገር ውስጥ ይሰራል። ምንም መለያ ወይም ምስል መጫን አያስፈልግም።

ለምንድነው sRGB እና መስመራዊ-ብርሃን ድብልቅ የሚለያዩት?

sRGB አማካኝ ኢንኮድ የተደረገውን የስክሪን ሰርጥ ዋጋዎችን ነው። መስመራዊ-ብርሃን ሁነታ መጀመሪያ ወደ ብርሃን እሴቶች ይቀይራቸዋል፣ ይደባለቃል፣ ከዚያም ወደ ኋላ ይለውጣል። የተመረጠው ዘዴ ውጤቱን ይለውጣል.

ይህ የተደባለቀ ቀለምን ሊተነብይ ይችላል?

አይ. ይህ ለስክሪኖች ዲጂታል ቀለም ሂሳብ ነው እንጂ የአካላዊ ቀለም ሞዴል አይደለም። እውነተኛው ቀለም በቀለም ባህሪያት, ግልጽነት, ትኩረትን, መብራትን እና የላይኛውን ገጽታ ይወሰናል.

ምን አይነት የቀለም ቅርጸቶችን መቅዳት እችላለሁ?

ውጤቱ HEX፣ RGB እና HSL ያሳያል። የ HEX እሴትን መቅዳት ወይም ትንሽ የ CSS የቀለም ቤተ-ስዕል ማውረድ ይችላሉ።

መነሻ

ነጻ የአሳሽ መሣሪያዎች። መሣሪያው በሚፈቅድበት ጊዜ ውሂብዎ በመሣሪያዎ ላይ ይቆያል።
