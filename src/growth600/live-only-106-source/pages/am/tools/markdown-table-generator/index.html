ነጻ፣ መለያ አያስፈልግም

Markdown ጠረጴዛ አመንጪ

በትንሽ አርትዖት ሊደረግ በሚችል ፍርግርግ ውስጥ የማርከርድ ሠንጠረዥ ይፍጠሩ። በነጠላ ሰረዝ የተለየ፣ ከፊል ኮሎን የተለየ ወይም በትር የተለየ ጽሑፍ አስመጣ፣ የአምድ አሰላለፍ ምረጥ እና ማርክዳውን ከቧንቧ ጋር በደህና አምልጧል።

የተጠቀሱ የCSV መስኮች ይደገፋሉ። ማስመጣት የአሁኑን ፍርግርግ ይተካዋል; እስከ 100 ረድፎች፣ 20 አምዶች እና 250,000 ቁምፊዎች።

የመጀመሪያው ረድፍ የማርከዳው ራስጌ ይሆናል። ቢያንስ አንድ ረድፍ እና አንድ አምድ ይጨምሩ።

ሊስተካከል የሚችል የሰንጠረዥ ሕዋሳት

ራስጌ እና መለያየት ረድፍ ያለው መደበኛ የቧንቧ ሠንጠረዥ ይፈጥራል። የሕዋስ መስመር መግቻዎች <br> ይሆናሉ; የማርክ ማድረጊያ ቱቦዎች እና የኋላ ሽፋኖች አምልጠዋል።

ሁሉም ሂደት በዚህ ትር ውስጥ ይቆያል። ምንም ሰቀላ፣ መለያ፣ ኤፒአይ፣ አውቶማቲክ ማስቀመጥ ወይም የአገልጋይ ሂደት የለም።

የመነጨ Markdown

የተሰራ የሠንጠረዥ ቅድመ እይታ

የማርክ ዳውን ሰንጠረዥ እንዴት እሰራለሁ?

የራስጌ ረድፍ እና የውሂብ ረድፎችን አስገባ፣ እያንዳንዱን የአምድ አሰላለፍ ምረጥ፣ ከዚያ የመነጨውን Markdown ቅዳ። ቧንቧዎች አምልጠዋል እና ያልተስተካከሉ ረድፎች ተሸፍነዋል።

ተደጋጋሚ ጥያቄዎች

የማርክ ዳውን ሰንጠረዥ እንዴት እሰራለሁ?

የራስጌ ረድፍ እና የውሂብ ረድፎችን አስገባ፣ እያንዳንዱን የአምድ አሰላለፍ ምረጥ፣ ከዚያ የመነጨውን Markdown ቅዳ። ቧንቧዎች አምልጠዋል እና ያልተስተካከሉ ረድፎች ተሸፍነዋል።

የእኔ ጠረጴዛ ተሰቅሏል?

ቁ. የእርስዎ ጠረጴዛ በዚህ አሳሽ ትር ውስጥ ነው የሚሰራው. ማስመጣት፣ አርትዖት እና የመነጨ Markdown ወደ አገልጋይ አይላኩም ወይም በራስ-ሰር አይቀመጡም።

CSV ወይም TSV ማስመጣት እችላለሁ?

አዎ። በነጠላ ሰረዝ የተለዩ፣ ከፊል-ኮሎን-የተለዩ ወይም በትሮች የተለዩ እሴቶችን ለጥፍ፣ ከዚያ ወደ ሊስተካከል የሚችል ፍርግርግ ያስመጣቸው። የተጠቀሱ የCSV መስኮች እና የተጠቀሱ መለያዎች ይደገፋሉ።

ቧንቧዎች እና የመስመር መግቻዎች እንዴት ይያዛሉ?

በሴል ውስጥ ያለ ፓይፕ ያመለጠ በመሆኑ የማርክዳውን ሠንጠረዥ አይከፋፍልም። የኋላ ሽፋኖችም ያመለጠ ናቸው፣ እና የሕዋስ መስመር ክፍተቶች በ<br> ይወከላሉ።

መነሻ

ነጻ የአሳሽ መሣሪያዎች። መሣሪያው በሚፈቅድበት ጊዜ ውሂብዎ በመሣሪያዎ ላይ ይቆያል።
