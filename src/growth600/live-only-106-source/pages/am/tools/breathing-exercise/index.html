መነሻ/የአተነፋፈስ ልምምድ

ነጻ፣ መለያ አያስፈልግም

የአተነፋፈስ ልምምድ

ረጋ ያለ የአተነፋፈስ ፍጥነት ይምረጡና የሚታየውን መመሪያ ይከተሉ። ልምምዱን ምቹ ያድርጉ፤ በማንኛውም ጊዜ ማቆም ይችላሉ።

የእንቅስቃሴ ቅነሳ ከተነቃ መመሪያው ከባድ እንቅስቃሴን ያስወግዳል።

ይህ ለአጠቃላይ ደህንነት የሚረዳ ጊዜ መቆጣጠሪያ ነው፣ የሕክምና እንክብካቤ አይደለም። በምቾት ይተንፍሱ፤ ጤንነት ካልተሰማዎት ያቁሙ።

አሁን ያለው ደረጃ: ወደ ውስጥ ይተንፍሱ

ወደ ውስጥ ይተንፍሱ

ዑደት: 1

የቀረው ጊዜ: 01:00

ይህን የአተነፋፈስ ልምምድ እንዴት እጠቀማለሁ?

ቅድመ ዝግጅት የተደረገለትን ምርጫ ይምረጡ ወይም እያንዳንዱን ደረጃ ያዘጋጁ፣ የክፍለ ጊዜውን ርዝመት ይምረጡና Start ን ይጫኑ። በማንኛውም ጊዜ ማቆም ወይም ዳግም ማስጀመር ይችላሉ። ድምፅ አማራጭ ነው፤ የሚጀምረው ከጀመሩ በኋላ ብቻ ነው።

ተደጋጋሚ ጥያቄዎች

ይህን የአተነፋፈስ ልምምድ እንዴት እጠቀማለሁ?

ቅድመ ዝግጅት የተደረገለትን ምርጫ ይምረጡ ወይም እያንዳንዱን ደረጃ ያዘጋጁ፣ የክፍለ ጊዜውን ርዝመት ይምረጡና Start ን ይጫኑ። በማንኛውም ጊዜ ማቆም ወይም ዳግም ማስጀመር ይችላሉ። ድምፅ አማራጭ ነው፤ የሚጀምረው ከጀመሩ በኋላ ብቻ ነው።

የአተነፋፈስ ክፍለ ጊዜዬ ወደ ኢንተርኔት ይጫናል?

አይጫንም። ጊዜ መቁጠሩ በዚህ ገጽ ላይ ይከናወናል። አካውንት፣ ፋይል መጫን፣ API ወይም የተቀመጠ ክፍለ ጊዜ አይጠቀምም።

Box አተነፋፈስ ወይም 4-7-8 መጠቀም እችላለሁ?

አዎ። ቅድመ ዝግጅት የተደረገለትን ንድፍ ይምረጡ ወይም የደረጃዎቹን ርዝመት ያስተካክሉ። እነዚህ የአተነፋፈስ ፍጥነት ንድፎች ናቸው፣ የሕክምና ሕክምና አይደሉም።

ታቡን ስዘጋ ሥራውን ይቀጥላል?

ዋስትና የለም። አሳሾች ከበስተጀርባ ያሉ ታቦችን ሊያቆሙ ይችላሉ፣ መሳሪያዎችም ወደ እንቅልፍ ሊገቡ ይችላሉ። በጣም ትክክለኛ የጊዜ ቆጠራ ለማግኘት ገጹን ክፍት እና መሳሪያውን ንቁ ያድርጉ።

ድምፁን ማጥፋት ወይም ቀድሜ ማቆም እችላለሁ?

አዎ። ድምፅ አማራጭ ነው፣ ከStart በኋላ ይጀምራል እና ማጥፋት ይቻላል። Pause ወይም Reset ሲጫኑ ጊዜ ቆጠራው ወዲያውኑ ያበቃል።

መነሻ

ነጻ የአሳሽ መሣሪያዎች። መሣሪያው በሚፈቅድበት ጊዜ ውሂብዎ በመሣሪያዎ ላይ ይቆያል።
