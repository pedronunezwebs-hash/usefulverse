መነሻ/መስመራዊ ፕሮግራሚንግ ካልኩሌተር

ነጻ፣ መለያ አያስፈልግም

መስመራዊ ፕሮግራሚንግ ካልኩሌተር

ባለ ሁለት-ተለዋዋጭ መስመራዊ ፕሮግራምን በ x እና y አሉታዊ ያልሆኑ ለመፍታት ወደ መስመራዊ ዓላማ እና እስከ ስምንት ገደቦችን ያስገቡ። ባለሁለት-ደረጃ ሲምፕሌክስ ዘዴ በጣም ጥሩ፣ የማይቻል ወይም ገደብ የለሽነትን ሪፖርት ያደርጋል እና እያንዳንዱን ምሰሶ ያሳያል።

የዓላማ ጥምርታዎች (x፣ y)

በአንድ መስመር አንድ፡ a,b <= rhs, a,b >= rhs or a,b = rhs

በ ± 1,000,000 ውስጥ ቢበዛ ስምንት ገደቦችን እና የቀኝ እጅ ጎኖችን ይጠቀማል። ሁለቱም የውሳኔ ተለዋዋጮች x ≥ 0 እና y 0 አላቸው ። በአንድ መስመር አንድ እኩልነት ወይም እኩልነት ያስገቡ።

ለሁለት ተለዋዋጮች ባለ ሁለት-ደረጃ የመጀመሪያ ደረጃ ቀለል ያለ ፈቺ። የቁጥር መቻቻል ለተንሳፋፊ-ነጥብ ምሰሶዎች ጥቅም ላይ ይውላል; የተበላሹ ችግሮች ለክብ ክብ ቅርጽ የተጋለጡ ሊሆኑ ይችላሉ። የማይቻሉ፣ ያልተገደቡ እና መደጋገም-ገደብ ጉዳዮች ከተፈለሰፈ ምርጥ ይልቅ ሪፖርት ተደርገዋል።

መስመራዊ ፕሮግራም ውጤቶች

ውጤቱ ላስገቡት የሂሳብ ሞዴል ብቻ ነው። ዓላማው፣ ገደቦች፣ ክፍሎች ወይም ግምቶች ለትክክለኛ ውሳኔ ተገቢ መሆናቸውን አያረጋግጥም።

    ባለሁለት-ተለዋዋጭ ቀላልክስ ካልኩሌተር እንዴት ነው የሚሰራው?

    ገደቦችን ወደ ተግባራዊ ሰንጠረዥ ይለውጣል፣ ሲያስፈልግ የደረጃ I ዓላማ ይጠቀማል፣ ከዚያም የተጠየቀውን ዓላማ ለማመቻቸት primal simplex pivots ይተገብራል። ተለዋዋጮች x እና y አሉታዊ እንዳይሆኑ ተገድደዋል።

    ተደጋጋሚ ጥያቄዎች

    ባለሁለት-ተለዋዋጭ ቀላልክስ ካልኩሌተር እንዴት ነው የሚሰራው?

    ገደቦችን ወደ ተግባራዊ ሰንጠረዥ ይለውጣል፣ ሲያስፈልግ የደረጃ I ዓላማ ይጠቀማል፣ ከዚያም የተጠየቀውን ዓላማ ለማመቻቸት primal simplex pivots ይተገብራል። ተለዋዋጮች x እና y አሉታዊ እንዳይሆኑ ተገድደዋል።

    አላማዬ እና ገደቦች ተሰቅለዋል?

    ቁጥር ፈቺው በዚህ አሳሽ ውስጥ ይሰራል። አላማህ እና ገደቦችህ ወደ አገልጋይ አልተላኩም ወይም በዚህ መሳሪያ አልተቀመጡም።

    ለእገዳዎች ምን ዓይነት ቅርጸት መጠቀም አለብኝ?

    በአንድ መስመር አንድ ረድፍ አስገባ እንደ 1,1 <= 5 or 2,1>= 4. የመጀመሪያው ቁጥር x ያበዛል, ሁለተኛው y ያበዛል, እና ሁለቱም ተለዋዋጮች አሉታዊ ያልሆኑ መሆን አለባቸው.

    የማይሰራ እና ያልተገደበ ማለት ምን ማለት ነው?

    የማይተገበር ማለት ማንኛውንም የገባውን ገደብ የሚያረካ ምንም ነጥብ የለም። ያልተገደበ ማለት የሚቻል አቅጣጫ ማለት የተጠየቀው አላማ ያለ ምንም ጥሩ መሻሻል እንዲቀጥል ያስችለዋል።

    ውጤቱ የእኔ የገሃዱ ዓለም ሞዴል ትክክል መሆኑን ያረጋግጣል?

    ቁጥር. እርስዎ ያስገቡትን እኩልታዎች ብቻ ይፈታል. ክፍሎችን፣ ግምቶችን እና ገደቦች ውሳኔዎን በትክክል የሚገልጹ መሆናቸውን ያረጋግጡ።

    መነሻ

    ነጻ የአሳሽ መሣሪያዎች። መሣሪያው በሚፈቅድበት ጊዜ ውሂብዎ በመሣሪያዎ ላይ ይቆያል።
