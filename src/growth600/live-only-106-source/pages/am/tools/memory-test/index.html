ነጻ፣ መለያ አያስፈልግም

የማህደረ ትውስታ ሙከራ

በ3×3 ፍርግርግ ላይ እያደገ ያለ የአሃዞችን ወይም የአቀማመጦችን ቅደም ተከተል ለማስታወስ ይለማመዱ። እያንዳንዱ ትክክለኛ ዙር አንድ ንጥል ይጨምራል.

ልምምድ ብቻ። ይህ የIQ ፈተና፣ ምርመራ ወይም የተረጋገጠ የግንዛቤ ግምገማ አይደለም። ውጤቶቹ ክሊኒካዊ ወይም የህዝብ ትርጉም የላቸውም።

ለስክሪን አንባቢዎች ዲጂት ስፓን የሚለውን ይምረጡ፡ በመልሶ ማጫወት ጊዜ እያንዳንዱ አሃዝ አንድ ጊዜ ይገለጻል። የእይታ ንድፍ ሁነታ በእይታ ላይ የተመሰረተ ነው.

ቀጣይ ተከታታይ ርዝመት፡ 3

ተከታታይ ንጥል: —

የእርስዎ መልስ

እስካሁን ምንም ንጥል ነገር አልገባም።

ትክክለኛ ዙሮች፡ 0

ሁነታ እና ፍጥነት ይምረጡ እና ከዚያ ይጀምሩ።

የፈተና ውጤት

ይህ የማህደረ ትውስታ ሙከራ እንዴት ይሰራል?

አሃዞችን ወይም ምስላዊ ፍርግርግ እና የማሳያ ፍጥነትን ይምረጡ። ተከታታዩን አንድ ጊዜ ይመልከቱ ወይም ያዳምጡ፣ ከዚያ በተመሳሳይ ቅደም ተከተል ያስገቡት። ትክክለኛ ዙሮች ይረዝማሉ, እስከ 12 እቃዎች. ይህ የተለመደ የልምምድ ጨዋታ እንጂ ደረጃውን የጠበቀ የማስታወስ ችሎታ ግምገማ አይደለም።

ተደጋጋሚ ጥያቄዎች

ይህ የማህደረ ትውስታ ሙከራ እንዴት ይሰራል?

አሃዞችን ወይም ምስላዊ ፍርግርግ እና የማሳያ ፍጥነትን ይምረጡ። ተከታታዩን አንድ ጊዜ ይመልከቱ ወይም ያዳምጡ፣ ከዚያ በተመሳሳይ ቅደም ተከተል ያስገቡት። ትክክለኛ ዙሮች ይረዝማሉ, እስከ 12 እቃዎች. ይህ የተለመደ የልምምድ ጨዋታ እንጂ ደረጃውን የጠበቀ የማስታወስ ችሎታ ግምገማ አይደለም።

ይህ የማህደረ ትውስታ ሙከራ ውጤቴን ያድናል?

ቁ. ተከታታዮቹ እና ውጤቱ ክፍት ሆኖ ሳለ በዚህ ገጽ ላይ ይቆያል። ምንም አልተሰቀለም፣ እና ምንም መለያ ወይም የመስመር ላይ ደረጃ የለም።

ይህ የማህደረ ትውስታ ሙከራ ምን ይለካል?

ተራ ተከታታይ የማስታወስ ችሎታ ጨዋታ ነው። ደረጃውን የጠበቀ አይደለም እና ሁኔታን ሊመረምር ወይም IQ ሊለካ አይችልም።

የአሃዛዊ ስፋት እና የስርዓተ-ጥለት ሁነታ እንዴት ይለያያሉ?

አሃዝ ስፓን አሃዞችን አንድ በአንድ ያሳያል እና ለስክሪን-አንባቢ መዳረሻ ያስታውቃል። የስርዓተ ጥለት ሁነታ በ3×3 ፍርግርግ ላይ ቦታዎችን ያበራል እና እይታን ይፈልጋል።

ውጤቶች ተቀምጠዋል ወይም ከሌሎች ሰዎች ጋር ይነጻጸራሉ?

ቁ. ውጤቶች ያሉት ይህ ገጽ ክፍት ሆኖ ሳለ ብቻ ነው። ምንም የመሪዎች ሰሌዳ፣ መለያ ወይም የአገልጋይ ሰቀላ የለም።

መነሻ

ነጻ የአሳሽ መሣሪያዎች። መሣሪያው በሚፈቅድበት ጊዜ ውሂብዎ በመሣሪያዎ ላይ ይቆያል።
