불평등 계산기

0과 비교하여 ax² + bx + c 형식의 실수 선형 또는 2차 부등식을 풉니다. 중요한 점, 간격 표기 및 수직선 요약을 확인하세요.

상수, 선형 및 2차 실수 부등식 ax² + bx + c <, ≤, > 또는 ≥ 0만 지원합니다. 계수는 유한해야 하며 절대값은 최대 10⁹입니다. 계산에서는 부동 소수점 숫자를 사용하므로 근은 근사치입니다. 척도 기반 공차는 반복되는 근 근처에서 사용됩니다.

결과

2차 부등식을 어떻게 해결합니까?

다항식의 실수 0을 찾은 다음 해당 0 사이와 외부의 부호를 결정합니다. 이 도구는 실제 솔루션 구간과 각 유한 끝점이 포함되는지 여부를 반환합니다.

자주 묻는 질문

2차 부등식을 어떻게 해결합니까?

다항식의 실수 0을 찾은 다음 해당 0 사이와 외부의 부호를 결정합니다. 이 도구는 실제 솔루션 구간과 각 유한 끝점이 포함되는지 여부를 반환합니다.

내 계수가 업로드됩니까?

아니요. 부등식은 이 브라우저에서 계산되며 이 도구로 업로드되거나 저장되지 않습니다.

간격 표기법은 무엇을 표시합니까?

괄호는 끝점이 제외됨을 의미하고 대괄호는 포함됨을 의미합니다. 무한대는 실제 끝점이 아니기 때문에 항상 괄호를 사용합니다.

삼차 또는 유리 부등식을 풀 수 있나요?

아니요. 이 계산기는 0차, 1차 또는 2차의 실수 다항식으로 제한됩니다. 이는 삼차, 유리, 절대값 또는 복합 불평등을 해결하지 않습니다.

뿌리가 정확합니까?

아니요. 계수와 근은 부동 소수점 연산을 사용합니다. 반복되는 근에 가깝거나 계수 크기가 매우 다른 결과는 반올림에 민감할 수 있습니다.
