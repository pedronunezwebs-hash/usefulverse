사이트맵 검사기

사이트맵 XML 문서를 붙여넣어 구조, URL 항목, 날짜 및 공통 필드를 확인하세요. XML은 이 브라우저에서만 구문 분석됩니다. 나열된 페이지는 가져오지 않습니다.

표준 urlset 또는 sitemapindex를 지원합니다. 최대 1,000,000자 및 5,000개의 직접 항목입니다.

로컬 XML 검사만 해당: 나열된 URL을 요청하거나, 사이트를 크롤링하거나, 사이트맵을 제출하거나 색인 생성을 보장하지 않습니다.

검증 요약

결과

    이 사이트맵 유효성 검사기는 무엇을 확인합니까?

    urlset 또는 sitemapindex 항목, 절대 HTTP 또는 HTTPS 위치, 정규화된 URL 중복, 마지막 수정 날짜, 선택적 변경 빈도 및 우선 순위 값, 사이트맵 네임스페이스를 확인합니다. 경고 및 오류는 항목 번호별로 나열됩니다.

    자주 묻는 질문

    이 사이트맵 유효성 검사기는 무엇을 확인합니까?

    urlset 또는 sitemapindex 항목, 절대 HTTP 또는 HTTPS 위치, 정규화된 URL 중복, 마지막 수정 날짜, 선택적 변경 빈도 및 우선 순위 값, 사이트맵 네임스페이스를 확인합니다. 경고 및 오류는 항목 번호별로 나열됩니다.

    내 사이트맵을 업로드하거나 제출합니까?

    아니요. XML은 브라우저에서 로컬로 처리됩니다. 이 도구는 URL을 크롤링하거나, 원격 사이트맵 파일을 가져오거나, 검색 엔진에 아무것도 제출하거나, 색인 생성을 확인하지 않습니다.

    사이트맵 URL이 활성화되어 있는지 확인합니까?

    아니요. URL 구문을 확인하고 붙여넣은 XML 내에서 복제하지만 의도적으로 URL을 요청하거나 사이트를 크롤링하지 않습니다.

    유효한 사이트맵은 Google이 해당 페이지의 색인을 생성했음을 의미합니까?

    아니요. XML 유효성 검사는 검색 엔진 제출이나 색인 보고서가 아닙니다. 관련 검색 엔진 웹마스터 도구를 통해 사이트맵을 제출하고 자체 상태를 확인하세요.

    사이트맵 색인을 확인할 수 있나요?

    예. 이 도구는 직접 sitemapindex 항목과 해당 loc 및 lastmod 필드를 확인하지만 참조된 사이트맵 파일을 다운로드하거나 반복적으로 검사하지는 않습니다.

    홈

    무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
