미팅 플래너

다른 시간대에 있는 주최자와 참가자의 반복되는 일일 가용성 창을 비교합니다. 각 현지 날짜와 시간을 검토한 다음 일치하는 슬롯에 대한 ICS 초대를 다운로드하세요.

는 로컬로 실행됩니다. 캘린더 연결, 위치 요청, 업로드, 계정, API 또는 자동 저장이 없습니다.

예: America/New_York, 유럽/런던, 아시아/도쿄. 주최자는 자동으로 포함됩니다. 총 8개의 개별 영역을 사용합니다.

일광 절약 시간 규칙은 이 브라우저의 시간대 데이터베이스에서 가져오며 오래되었을 수 있습니다. 대체 시간이 반복되면 이전 발생이 선택됩니다. 스프링 포워드 간격 동안 존재하지 않는 가용성 경계는 건너뜁니다.

모든 시간대에서 동일한 일일 현지 시간 창을 사용합니다. 개별 달력, 공휴일, 근무일 또는 참석자 기본 설정을 알 수 없습니다. 초대를 보내기 전에 모든 사람이 포함된 실제 슬롯을 선택하세요.

가능한 공유 회의 시간

이 구역 및 시간과 일치하는 슬롯을 찾을 수 없습니다. 더 넓은 기간, 다른 날짜 범위 또는 더 짧은 회의를 시도해 보십시오.

주최자 현지 시간참가자 현지 시간초대

다른 시간대에 걸쳐 회의 시간을 어떻게 찾나요?

주최자의 IANA 시간대, 참가자 구역, 현지 날짜 범위, 공유 가능 시간 및 회의 길이를 입력합니다. 플래너는 날짜 변경 및 일광 절약 시간제 오프셋을 포함하여 로컬 작업 창과 비교하여 실제 순간을 확인합니다.

자주 묻는 질문

다른 시간대에 걸쳐 회의 시간을 어떻게 찾나요?

주최자의 IANA 시간대, 참가자 구역, 현지 날짜 범위, 공유 가능 시간 및 회의 길이를 입력합니다. 플래너는 날짜 변경 및 일광 절약 시간제 오프셋을 포함하여 로컬 작업 창과 비교하여 실제 순간을 확인합니다.

이것이 내 달력에 연결됩니까?

아니요. 모든 계산은 브라우저에서 실행됩니다. 플래너는 로그인하거나, 달력을 읽거나, 일정을 업로드하거나, 선택 사항을 저장하지 않습니다.

Google Calendar 또는 Outlook 가용성을 확인합니까?

아니요. 각 시간대에 대해 입력한 동일한 시간을 비교합니다. 다른 사람의 약속, 공휴일, 평일 근무 또는 개인 취향을 볼 수 없습니다.

일광 절약 시간을 고려합니까?

It는 브라우저의 IANA 시간대 데이터베이스를 사용하여 각 후보 인스턴트를 변환합니다. 데이터베이스가 최신 상태가 아닐 수 있습니다. 참가자들과 중요한 회의 시간을 확인하세요.

추천 회의를 달력에 추가할 수 있습니까?

선택한 슬롯에 대한 ICS 이벤트를 다운로드하고 직접 가져옵니다. 이 도구는 달력에 연결하거나 수정하지 않습니다.
