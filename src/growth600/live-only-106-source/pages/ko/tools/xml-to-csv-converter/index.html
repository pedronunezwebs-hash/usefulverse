XML을 CSV로 변환기

간단한 XML 레코드 목록을 CSV 테이블로 바꾸거나 CSV 파일의 텍스트에서 XML 레코드를 만듭니다. 방향을 선택하고 데이터를 붙여넣은 다음 결과를 복사하거나 다운로드하세요. 아무것도 업로드되지 않았습니다.

동일한 이름의 레코드 요소의 단순 목록 또는 하나의 단순 레코드를 지원합니다. 요소 하위는 스칼라 값이어야 합니다. 중첩 및 반복 필드는 평면화되지 않습니다.

열 이름으로 첫 번째 행을 사용하십시오. @id와 같은 헤더는 XML 속성이 됩니다. 레코드 텍스트에는 #text를 사용하십시오.

이는 무손실 XML 형식 변환이 아닌 단순 테이블 변환입니다. 네임스페이스, 중첩 구조, 혼합 콘텐츠, 주석 및 XML 형식은 유지되지 않습니다. 텍스트는 유형을 인식하지 않습니다. 스프레드시트 수식과 유사한 CSV 값에는 안전을 위해 아포스트로피가 앞에 붙습니다.

결과

다른 애플리케이션으로 가져오기 전에 출력을 확인하십시오.

XML을 CSV로 어떻게 변환합니까?

XML을 CSV로 선택하고 간단한 기록 목록으로 XML을 붙여넣습니다. 반복되는 직접 레코드 요소는 행이 됩니다. 요소 이름은 열이 됩니다. 속성은 @name을 사용합니다. 헤더와 행에서 간단한 XML 레코드를 생성하려면 CSV를 XML로 선택하세요.

자주 묻는 질문

XML을 CSV로 어떻게 변환합니까?

XML을 CSV로 선택하고 간단한 기록 목록으로 XML을 붙여넣습니다. 반복되는 직접 레코드 요소는 행이 됩니다. 요소 이름은 열이 됩니다. 속성은 @name을 사용합니다. 헤더와 행에서 간단한 XML 레코드를 생성하려면 CSV를 XML로 선택하세요.

내 XML 또는 CSV가 업로드됩니까?

아니요. 구문 분석 및 변환은 이 브라우저에서 실행됩니다. 입력은 200,000자, 5,000행, 64열, 20,000셀로 제한됩니다. DTD 및 엔터티 선언이 차단되고 외부 리소스를 가져오지 않습니다.

XML 속성은 CSV에 어떻게 표시됩니까?

id="101"과 같은 속성은 @id라는 열이 됩니다. 다시 변환할 때 @로 시작하는 CSV 헤더는 XML 속성이 됩니다.

중첩된 XML을 플랫 테이블로 변환할 수 있습니까?

아니요. 중첩된 하위 구조, 레코드 내부의 반복 필드 및 혼합 텍스트는 병합되거나 자동으로 손실되는 대신 거부됩니다. 중첩된 데이터에 대해 전용 XML-JSON 워크플로를 사용합니다.

CSV는 XML 유형과 형식을 유지합니까?

아니요. CSV는 XML 유형, 네임스페이스 또는 형식이 아닌 셀 텍스트를 저장합니다. 스프레드시트 수식 실행 위험을 줄이기 위해 수식과 유사한 셀 값을 내보낼 때 아포스트로피 접두사가 붙습니다.
