이 호흡 운동은 어떻게 사용하나요?

사전 설정이나 각 단계별 시간을 선택하고 세션 시간을 정한 뒤 시작을 누르세요. 언제든 일시 정지하거나 초기화할 수 있습니다. 소리는 선택 사항이며 시작 후에만 재생됩니다.

호흡 운동 기록이 업로드되나요?

아니요. 타이머는 이 페이지 내에서만 작동합니다. 계정 생성, 데이터 업로드, API 사용 또는 세션 기록 저장이 이루어지지 않습니다.

박스 호흡법이나 4-7-8 호흡법을 사용할 수 있나요?

네. 사전 설정을 선택하거나 각 단계의 시간을 조절하세요. 이는 호흡 속도 조절을 위한 패턴이며 의학적 치료가 아닙니다.

탭을 닫아도 계속 실행되나요?

보장할 수 없습니다. 브라우저가 백그라운드 탭을 일시 중지하거나 기기가 절전 모드로 전환될 수 있습니다. 정확한 시간을 위해 페이지를 열어두고 기기가 깨어 있도록 하세요.

소리를 끄거나 중간에 멈출 수 있나요?

네. 소리는 선택 사항이며 끌 수 있습니다. 일시 정지나 초기화를 누르면 활성 타이머가 즉시 멈춥니다.
