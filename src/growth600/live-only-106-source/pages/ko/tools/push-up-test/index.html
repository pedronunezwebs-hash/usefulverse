팔굽혀펴기 테스트 및 세트 기록기

간단한 테스트로 단일 세트를 기록하거나 나머지 세트를 사이에 두고 여러 세트를 기록합니다. 반복 횟수를 세고 입력합니다. 이 도구는 카메라를 사용하거나 강도를 평가하지 않습니다.

0부터 500까지 최대 20개의 정수를 입력하세요. 빈 줄은 무시되며 세트로 계산되지 않습니다. 선택한 양식으로 완료한 반복 횟수만 계산하세요.

일반 메모를 유지합니다. 이것은 의료 기록이 아닙니다.

편안한 운동 범위를 선택하고 통증, 현기증 또는 비정상적인 호흡 곤란을 느끼면 중지하십시오. 반복 횟수는 자세, 속도, 테스트 조건에 따라 달라집니다. 이 도구는 체력 등급, 진단 또는 운동 처방을 제공하지 않습니다.

저장은 선택사항이며 이 브라우저만 사용합니다. 저장하지 않고 계산하려면 선택을 취소하거나 아래에 저장된 기록을 삭제하세요.

귀하의 세션

푸시업 테스트 추적기의 총 반복 횟수는 어떻게 되나요?

비어 있지 않은 각 세트에 입력된 정수 반복 횟수를 더합니다. 빈 줄은 무시되고 0 세트는 0으로 유지되며 나머지 추정치는 휴식 시간에 휴식 횟수를 곱한 값입니다.

자주 묻는 질문

푸시업 테스트 추적기의 총 반복 횟수는 어떻게 되나요?

비어 있지 않은 각 세트에 입력된 정수 반복 횟수를 더합니다. 빈 줄은 무시되고 0 세트는 0으로 유지되며 나머지 추정치는 휴식 시간에 휴식 횟수를 곱한 값입니다.

푸쉬업 세트가 업로드되나요?

아니요. 계산은 이 브라우저에서 실행됩니다. 세션 기록은 귀하가 선택한 후에만 이 장치에 기록됩니다. 여기서 삭제할 수 있습니다.

빈 줄은 세트로 계산되나요, 반복으로 계산되나요?

아니요. 빈 줄은 무시됩니다. 0인 라인은 반복이 0인 세트를 기록하고 총계에 반복을 추가하지 않습니다.

최대 1세트로 사용할 수 있나요? 아니면 여러 세트로 사용할 수 있나요?

예. 수동으로 계산된 단일 세트의 경우 한 줄을 입력하고, 세트와 그 사이의 나머지를 요약하려면 여러 줄을 입력합니다. 테스트 조건은 귀하에게 달려 있습니다. 결과는 모집단 표준과 비교되지 않습니다.

내 훈련 이력이 업로드되나요?

아니요. 기록은 선택 사항이며 이 장치의 브라우저에 유지됩니다. 원할 때마다 삭제 버튼으로 삭제하세요.
