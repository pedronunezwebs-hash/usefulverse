모듈로 계산기

정수에 대한 유클리드 몫과 나머지를 계산합니다. 부정적인 입력은 일관되게 처리되며 부서 정체성은 답변이 어떻게 형성되는지 보여줍니다.

나눌 숫자입니다. 부정적일 수도 있습니다.

0이 아닌 정수를 사용하십시오. 절대값은 모듈러스를 정의합니다.

이 값이 제수 모듈로 배당과 일치하는지 확인하세요.

최대 50자리의 부호 있는 정수를 허용합니다. 분수나 소수가 없습니다. 결과는 유클리드 모듈로를 사용합니다. 일부 프로그래밍 언어에서는 음수에 대해 다른 나머지 규칙을 사용합니다.

결과

음수로 모듈로를 어떻게 계산합니까?

이 계산기는 절대 제수보다 작은 음수가 아닌 나머지를 사용합니다. 예를 들어, −7 = (−3 × 3) + 2이므로 −7 mod 3은 2입니다.

자주 묻는 질문

음수로 모듈로를 어떻게 계산합니까?

이 계산기는 절대 제수보다 작은 음수가 아닌 나머지를 사용합니다. 예를 들어, −7 = (−3 × 3) + 2이므로 −7 mod 3은 2입니다.

내 번호가 업로드됐나요?

아니요. 정확한 계산은 이 브라우저에서 실행됩니다. 번호가 업로드되거나 저장되지 않습니다.

-7 모드 3이 뭔가요?

유클리드 규칙을 사용하면 −7 mod 3은 2입니다: −7 = (−3 × 3) + 2, 0 ≤ 2 < 3.

합동 모듈로 m은 무엇을 의미하나요?

두 정수의 차이가 |m|으로 나누어질 때 모듈로 m이 합동입니다. 선택적 비교는 이를 정확하게 확인합니다.

이것이 프로그래밍 언어의 % 연산자와 다른 이유는 무엇입니까?

일부 언어에서는 나머지 부분에 음수 배당 기호를 유지합니다. 대신 이 계산기는 0부터 절대 제수를 포함하지 않는 나머지를 반환합니다.

홈

무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
