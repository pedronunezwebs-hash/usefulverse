자주 묻는 질문

뱀 게임은 어떻게 플레이하나요?

라운드를 시작하고 arrow keys, WASD 또는 터치 버튼을 사용하여 음식 쪽으로 방향을 조정하고 벽과 몸을 피하세요. 언제든지 일시중지하세요. 음식을 먹으면 뱀이 자라며 포인트가 1씩 추가됩니다.

스네이크 게임은 내 점수를 저장하나요, 아니면 계정을 사용하나요?

계정이나 다운로드가 필요하지 않습니다. 현재 점수와 세션은 이 tab에서만 메모리에 가장 잘 남아 있습니다. 떠난 후에는 업로드되거나 저장되지 않습니다.

휴대폰이나 tablet에서 플레이할 수 있나요?

네. 화면의 방향 버튼을 사용하세요. arrow keys 또는 WASD가 포함된 키보드는 컴퓨터에서도 작동합니다.

게임을 일시정지할 수 있나요?

네. 언제든지 일시 중지를 선택하세요. 다시 시작할 때까지 뱀은 움직이지 않습니다.

매번 같은 게임을 받게 되나요?

보드 레이아웃은 친숙하지만 음식 위치는 새로운 라운드마다 무작위로 지정됩니다. 현재 세션 점수와 최고 세션 점수는 퇴장 후에 저장되지 않습니다.
