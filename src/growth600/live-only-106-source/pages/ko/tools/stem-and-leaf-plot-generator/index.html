줄기 및 잎 도표 생성기

최대 250개의 값을 붙여넣어 줄기와 정렬된 잎으로 정리합니다. 잎 자리를 선택하고 각 줄기를 1, 2 또는 5줄로 나눕니다.

쉼표, 공백, 세미콜론 또는 새 줄로 값을 구분하세요. 소수점 값에는 마침표를 사용하세요.

절대값이 최대 1,000,000,000인 1~250개의 유한 값을 입력합니다. 값은 소수점 이하 3자리까지 가질 수 있습니다. 일치하는 잎 위치를 선택하십시오. 추가 소수 자릿수는 거부되며 반올림되지 않습니다. 음수 줄기는 음수가 아닌 잎을 사용합니다(예: −12는 −2 | 8입니다). 이 설명 표시는 사분위수를 계산하거나 이상값을 제거하지 않습니다.

플롯 결과

줄기-잎 그림은 어떻게 만듭니까?

데이터를 입력하고 각 잎이 될 마지막 숫자를 선택하세요. 앞의 숫자가 줄기를 형성합니다. 값은 정렬되며, 반복되는 값은 반복되는 나뭇잎으로 계속 표시됩니다.

자주 묻는 질문

줄기-잎 그림은 어떻게 만듭니까?

데이터를 입력하고 각 잎이 될 마지막 숫자를 선택하세요. 앞의 숫자가 줄기를 형성합니다. 값은 정렬되며, 반복되는 값은 반복되는 나뭇잎으로 계속 표시됩니다.

내 데이터가 업로드되나요?

아니요. 플롯은 이 브라우저에서 생성됩니다. 이 도구는 귀하의 값을 업로드하거나 저장하지 않습니다.

줄기-잎 그림의 핵심은 무엇입니까?

줄기와 잎 하나를 원본 데이터 값으로 읽는 방법을 설명하는 키입니다. 예를 들어 정수의 경우 1 | 2는 12를 의미합니다. 음수 값을 사용하면 이 도구는 바닥 기반 줄기를 사용하므로 −2 | 8은 -12를 의미합니다.

줄기를 쪼갤 수 있나요?

예. 잎 0-9에 대해 한 행, 0-4 및 5-9에 대해 두 행, 또는 행당 잎 숫자 2개가 포함된 5개 행을 선택하십시오. 그룹화를 명확하게 하기 위해 빈 분할 행이 유지됩니다.

중복된 값이 제거되나요?

아니요. 입력한 모든 값이 유지됩니다. 반복되는 값은 반복되는 리프 숫자로 나타나므로 플롯에는 여전히 원래 빈도가 표시됩니다.

홈

무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
