PDF 북마크 편집기

탐색 가능한 목차를 PDF에 추가하거나 기존 책갈피를 구성합니다. 중첩된 섹션을 만들고, 페이지 대상을 할당하고, 항목을 재정렬하고, 브라우저에 별도의 복사본을 저장하세요.

Editing은 새 PDF 사본을 생성합니다. 일부 독자는 북마크를 다르게 표시할 수 있습니다. 공유하기 전에 저장된 사본을 검토하십시오.

Local 제한: 25MiB 입력, 300페이지, 500북마크, 20중첩 수준 및 50MiB 출력. 대용량 파일은 상당한 장치 메모리를 사용할 수 있습니다. 컴퓨터를 권장합니다.

내부 페이지 대상 및 중첩된 개요 항목을 만듭니다. 기존 외부 링크, 명명된 대상 또는 지원되지 않는 북마크 작업은 자동으로 삭제되는 대신 거부됩니다. 페이지 내용은 편집되지 않습니다. 저장 후 디지털 서명이 무효화될 수 있습니다.

PDF 북마크

아직 북마크가 없습니다. 목차를 시작하려면 하나를 추가하세요.

Export는 여기에 현재 개요를 씁니다. 가져오기는 검증 후 현재 개요를 대체합니다. 소스 PDF의 백업을 유지하십시오. JSON에 페이지 콘텐츠가 포함되어 있지 않습니다.

PDF 사본 다운로드

PDF에 책갈피를 어떻게 추가합니까?

PDF를 선택하고 지원되는 내부 페이지 책갈피를 읽어보세요. 제목, 페이지 및 선택적 상위 섹션을 추가하거나 편집하고 항목을 정렬한 다음 별도의 PDF 사본을 저장하세요. 개요를 JSON.

자주 묻는 질문

PDF에 책갈피를 어떻게 추가합니까?

PDF를 선택하고 지원되는 내부 페이지 책갈피를 읽어보세요. 제목, 페이지 및 선택적 상위 섹션을 추가하거나 편집하고 항목을 정렬한 다음 별도의 PDF 사본을 저장하세요. 개요를 JSON.

내 PDF 또는 북마크가 업로드됩니까?

아니요. 선택한 문서는 선택한 후 이 브라우저에서 처리됩니다. UsefulVerse는 PDF를 업로드하지 않거나 해당 북마크 데이터를 서버로 보내지 않습니다.

북마크를 섹션 아래에 중첩할 수 있습니까?

Y예. 계층 구조를 만들려면 상위 섹션을 설정하세요. 문서 페이지 자체는 변경되지 않습니다. 각 북마크는 선택한 페이지 번호를 가리킵니다.

이렇게 하면 외부 링크를 여는 책갈피가 보존됩니까?

이 편집기는 현재 내부 페이지 대상을 지원합니다. 지원되지 않는 외부 작업이나 이름이 지정된 대상이 있는 파일을 자동으로 삭제하는 대신 거부합니다.

PDF 페이지나 서명이 변경됩니까?

문서 개요를 편집하고 페이지 내용이 아닌 새 복사본을 저장합니다. 편집하면 디지털 서명이 무효화될 수 있으므로 결과를 확인하고 이 도구를 서명 보존 도구로 취급하지 마십시오.
