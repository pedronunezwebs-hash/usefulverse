히스토그램 계산기

최대 5,000개의 숫자를 붙여넣어 동일한 너비의 히스토그램을 만듭니다. 자동 빈 규칙을 선택하거나 빈 개수를 설정한 다음 빈도를 보고 내보냅니다.

공백, 세미콜론 또는 새 줄로 값을 구분합니다. 세미콜론은 소수점 쉼표를 그대로 유지합니다.

절대 크기가 최대 10⁹인 1~5,000개의 유한 값과 1~50개의 동일 너비 빈을 지원합니다. 마지막 간격에는 오른쪽 끝점이 포함됩니다. 상대 빈도와 밀도는 입력된 모든 값으로 정규화됩니다. Freedman–Diaconis가 양의 IQR/범위를 사용할 수 없는 경우 Sturges로 대체됩니다. 이는 통계적 추론이나 확률 모델이 아닌 설명 차트입니다.

히스토그램 결과

히스토그램은 어떻게 만듭니까?

숫자 데이터를 입력하고 빈 규칙을 선택합니다. 계산기는 데이터 범위를 동일한 너비의 간격으로 나누고 각 값을 한 번씩 계산하며 최종 간격에 최대값을 포함합니다.

자주 묻는 질문

히스토그램은 어떻게 만듭니까?

숫자 데이터를 입력하고 빈 규칙을 선택합니다. 계산기는 데이터 범위를 동일한 너비의 간격으로 나누고 각 값을 한 번씩 계산하며 최종 간격에 최대값을 포함합니다.

내 데이터가 업로드되나요?

아니요. 히스토그램은 이 브라우저에서 계산됩니다. 이 도구는 귀하의 값을 업로드하거나 저장하지 않습니다.

어떤 빈 규칙을 사용해야 합니까?

Sturges는 더 작은 샘플을 위한 간단한 시작점입니다. 제곱근은 표본 크기의 제곱근을 사용합니다. Freedman–Diaconis는 사분위수 범위를 사용하며 확산 및 이상값에 적응할 수 있습니다. Bin 개수를 직접 선택할 수도 있습니다.

주파수와 밀도의 차이는 무엇입니까?

빈도는 각 간격의 값을 계산합니다. 상대빈도는 백분율을 나타냅니다. 확률 밀도는 상대 빈도를 간격 너비로 나누므로 전체 막대 면적은 1입니다.

최종 빈에 상한이 포함되어 있습니까?

예. Bin은 최대 데이터 값을 포함하므로 어떤 값도 누락되지 않는 최종 Bin을 제외하고는 반 개방 간격입니다.

홈

무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
