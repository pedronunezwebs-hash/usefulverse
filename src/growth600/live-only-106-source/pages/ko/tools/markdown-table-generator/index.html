마크다운 테이블 생성기

편집 가능한 작은 그리드에 Markdown 테이블을 만듭니다. 쉼표로 구분되거나 세미콜론으로 구분되거나 탭으로 구분된 텍스트를 가져오고, 열 정렬을 선택하고, 파이프가 안전하게 이스케이프된 일반 Markdown을 복사합니다.

인용된 CSV 필드가 지원됩니다. 가져오기는 현재 그리드를 대체합니다. 최대 100개 행, 20개 열, 250,000자.

첫 번째 행은 Markdown 헤더가 됩니다. 최소한 하나의 행과 하나의 열을 추가하십시오.

편집 가능한 테이블 셀

머리글과 구분자 행이 있는 표준 파이프 테이블을 생성합니다. 세포주 파손은 <br>이 됩니다. 마크다운 파이프와 백슬래시는 이스케이프됩니다.

모든 처리는 이 탭에 유지됩니다. 업로드, 계정, API, 자동 저장 또는 서버 처리가 없습니다.

렌더링된 테이블 미리보기

마크다운 테이블을 어떻게 만듭니까?

머리글 행과 데이터 행을 입력하고 각 열 정렬을 선택한 다음 생성된 마크다운을 복사합니다. 파이프가 이스케이프되고 고르지 않게 가져온 행이 채워집니다.

자주 묻는 질문

마크다운 테이블을 어떻게 만듭니까?

머리글 행과 데이터 행을 입력하고 각 열 정렬을 선택한 다음 생성된 마크다운을 복사합니다. 파이프가 이스케이프되고 고르지 않게 가져온 행이 채워집니다.

내 테이블이 업로드되었나요?

아니요. 테이블은 이 브라우저 탭에서 처리됩니다. 가져오기, 편집, 생성된 마크다운은 서버로 전송되거나 자동으로 저장되지 않습니다.

CSV 또는 TSV를 가져올 수 있나요?

예. 쉼표로 구분되거나 세미콜론으로 구분되거나 탭으로 구분된 값을 붙여넣은 다음 편집 가능한 그리드로 가져옵니다. 인용된 CSV 필드와 인용된 구분 기호가 지원됩니다.

파이프 및 줄 바꿈은 어떻게 처리됩니까?

셀 내부의 파이프가 이스케이프되어 Markdown 테이블이 분할되지 않습니다. 백슬래시도 이스케이프 처리되며 셀 줄 바꿈은 <br>으로 표시됩니다.

무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
