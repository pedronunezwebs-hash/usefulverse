아이젠하워 매트릭스

작업 목록을 수행, 일정, 위임 또는 취소의 네 가지 명확한 선택으로 전환합니다. 무엇이 중요하고 긴급한지 결정합니다. 날짜는 자동 판단이 아니라 알림입니다.

자신만의 상황에 맞게 작업을 분류하세요. 매트릭스는 당신의 중요성을 결정하지 않습니다. 데이터는 이 탭의 메모리에 유지되며 백업을 내보내지 않는 한 탭을 닫거나 다시 로드하면 지워집니다. 가져오기는 이 도구의 JSON 백업만 허용하며 최대 1MB, 작업 300개입니다.

중요하다는 것은 귀하가 관심을 갖고 있는 목표, 책임 또는 결과에 의미 있는 영향을 미친다는 것을 의미합니다.

긴급은 실제 기한이나 결과로 인해 곧 주의가 필요하다는 의미입니다. 마감일만으로는 중요성이 결정되지 않습니다.

먼저

긴급하고 중요합니다. 지금 조치를 취하세요.

    일정

    중요하지만 긴급하지 않음: 긴급해지기 전에 시간을 확보하세요.

      위임자

      긴급하고 덜 중요함: 적절한 경우 이를 전달하고 후속 조치를 추적합니다.

        삭제를 고려

        긴급하지도 중요하지도 않습니다. 제거하거나 계획에서 제외하세요.

          아이젠하워 매트릭스를 어떻게 사용하나요?

          각 작업에 대해 4개의 사분면 중 하나를 선택하세요. 긴급하고 중요한 일, 중요하지만 일정이 긴급하지 않은 일, 긴급하지만 위임할 일이 덜 중요한 일, 포기를 고려하지 않는 일입니다. 언제든지 작업 사분면을 변경할 수 있습니다.

          자주 묻는 질문

          아이젠하워 매트릭스를 어떻게 사용하나요?

          각 작업에 대해 4개의 사분면 중 하나를 선택하세요. 긴급하고 중요한 일, 중요하지만 일정이 긴급하지 않은 일, 긴급하지만 위임할 일이 덜 중요한 일, 포기를 고려하지 않는 일입니다. 언제든지 작업 사분면을 변경할 수 있습니다.

          내 Eisenhower Matrix 작업은 비공개인가요?

          작업은 이 브라우저 탭에 유지되며 자동으로 업로드되거나 저장되지 않습니다. JSON 백업을 보관하려면 내보내고 나중에 이 기기에서 해당 파일을 가져오세요.

          아이젠하워 매트릭스 사분면에는 무엇이 들어가나요?

          급하고 중요한 일을 먼저 하세요. 긴급하지 않은 중요한 일을 계획하세요. 다른 사람이 처리할 수 있을 때 덜 중요한 긴급한 작업을 위임하세요. 긴급하지도 중요하지도 않은 작업은 삭제해 보세요.

          마감일이 있으면 자동으로 작업을 긴급하거나 중요하게 만드나요?

          아니요. 마감일은 긴급성을 판단하는 데 도움이 될 수 있지만 실제 마감일, 결과 및 목표를 기반으로 긴급성과 중요성을 결정합니다.

          홈

          무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
