랜덤 단어 생성기

글쓰기 아이디어, 수업 게임 또는 새로운 영감을 위한 단어를 찾으세요. 카테고리와 길이를 선택한 다음 목록을 복사하거나 다운로드하세요.

같은 목록을 다시 얻으려면 같은 시드를 사용하세요.

단어 목록은 작으며 번역 사전이나 빈도 사전이 아닙니다.

생성된 단어

    랜덤 단어를 어떻게 생성하나요?

    카테고리를 선택하고 길이 범위와 결과 개수를 정한 뒤 생성 버튼을 누르세요. 시드를 비우면 새 목록이 만들어지고, 같은 시드를 사용하면 같은 조건에서 목록을 다시 만들 수 있습니다.

    자주 묻는 질문

    랜덤 단어를 어떻게 생성하나요?

    카테고리를 선택하고 길이 범위와 결과 개수를 정한 뒤 생성 버튼을 누르세요. 시드를 비우면 새 목록이 만들어지고, 같은 시드를 사용하면 같은 조건에서 목록을 다시 만들 수 있습니다.

    내 단어가 업로드되나요?

    아니요. 목록은 브라우저에 포함된 작은 사전에서 선택됩니다. 데이터가 업로드되거나 저장되지 않습니다.

    매번 다른 목록을 만들 수 있나요?

    네. 시드를 비워 두면 새 목록이 생성됩니다. 같은 시드와 필터, 사전을 사용하면 같은 결과를 다시 얻을 수 있습니다.

    모든 단어가 포함되어 있나요?

    아니요. 작은 선별 목록을 사용하고 필터에 맞는 단어 중에서 균등하게 선택합니다.

    홈

    무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
