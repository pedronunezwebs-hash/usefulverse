운율 찾기

시, 구절 또는 단어 목록을 붙여서 어미를 공유하는 단어를 그룹화하세요. 비교할 최종 문자 수와 악센트 무시 여부를 선택합니다.

원하는 텍스트를 붙여넣으세요. 브라우저에서 단어가 추출됩니다.

선택사항: é 위의 표시가 무시되므로 활성화되면 카페와 카페가 일치할 수 있습니다.

제한: 50,000자, 5,000단어. 결과는 발음이 아닌 철자를 비교합니다.

결과

그룹이 발견되었습니다.: 0

일치하는 그룹이 없는 단어: 0

로컬로 실행됩니다. 텍스트가 업로드되거나 저장되지 않습니다.

이 운율 찾기는 어떻게 작동하나요?

마지막으로 쓰여진 문자를 일치시켜 단어를 그룹화합니다. 발음, 강세 또는 음절을 비교하지 않으므로 철자 어미를 공유한다고 해서 단어가 말할 때 운율이 맞는다는 보장은 없습니다.

자주 묻는 질문

이 운율 찾기는 어떻게 작동하나요?

마지막으로 쓰여진 문자를 일치시켜 단어를 그룹화합니다. 발음, 강세 또는 음절을 비교하지 않으므로 철자 어미를 공유한다고 해서 단어가 말할 때 운율이 맞는다는 보장은 없습니다.

내 말이 업로드되나요?

아니요. 텍스트는 이 브라우저에서 분석되며 업로드되거나 저장되지 않습니다.

단어의 소리를 확인합니까?

아니요. 표기된 어미만 비교하고 발음 사전이나 음성 표기를 사용하지 않습니다.

모든 언어의 단어를 사용할 수 있습니까?

예. 유니코드 문자는 지원되지만 결과는 철자를 기반으로 하며 해당 언어에서 단어가 발음되는 방식과 일치하지 않을 수 있습니다.

시 전체를 붙여넣을 수 있나요?

예. 로컬 입력은 50,000자 및 5,000단어로 제한됩니다.

홈

무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
