PDF 페이지 크기 변환기

PDF의 모든 페이지 크기를 A4, US Letter, Legal 또는 사용자 정의 용지 크기로 조정합니다. 새로운 크기를 미리 보고 전체 원본 페이지 영역에 맞춘 후 장치에서 처리된 별도의 사본을 다운로드하세요.

Resizing은 별도의 복사본을 생성합니다. 다시 저장하면 디지털 서명이 무효화될 수 있습니다. 공유하기 전에 원본을 보관하고 새 PDF를 확인하세요.

Local 제한: 25MiB 입력, 300페이지 및 50MiB 출력. 대용량 파일은 상당한 메모리를 사용할 수 있습니다. 컴퓨터를 권장합니다.

자동 변경을 피하기 위해 이 도구는 회전된 페이지, 사용자 정의 페이지 상자, 주석, 링크 및 대화형 양식을 거부합니다. 맞춤 모드는 기존 페이지 직사각형 전체의 크기를 조정하며 이미 경계 외부에 있는 콘텐츠를 복원할 수 없습니다.

PDF의 페이지 크기를 어떻게 변경합니까?

PDF를 선택하고 해당 페이지를 검사하고 A4, Letter, Legal 또는 사용자 정의 크기를 선택한 다음 페이지에 맞춤 또는 실제 크기를 선택합니다. 맞춤 모드는 비례적으로 크기를 조정하고 각 전체 페이지 영역을 중앙에 배치합니다. 새 사본을 다운로드하고 원본을 보관하세요.

자주 묻는 질문

PDF의 페이지 크기를 어떻게 변경합니까?

PDF를 선택하고 해당 페이지를 검사하고 A4, Letter, Legal 또는 사용자 정의 크기를 선택한 다음 페이지에 맞춤 또는 실제 크기를 선택합니다. 맞춤 모드는 비례적으로 크기를 조정하고 각 전체 페이지 영역을 중앙에 배치합니다. 새 사본을 다운로드하고 원본을 보관하세요.

내 PDF를 업로드하여 크기를 조정합니까?

아니요. PDF는 선택한 후 이 브라우저에서 처리됩니다. UsefulVerse에서는 업로드되거나 저장되지 않습니다. 대용량 PDF는 장치 메모리를 사용할 수 있습니다. 컴퓨터를 권장합니다.

PDF의 크기를 A4 또는 US Letter로 조정할 수 있습니까?

Yes. A4, US Letter 또는 US Legal을 선택하고 세로 또는 가로를 선택한 후 결과를 미리 봅니다. 사용자 정의 크기를 밀리미터 또는 인치 단위로 입력할 수도 있습니다.

크기를 조정하면 PDF 내용이 잘리나요?

Fit 모드는 전체 원본 페이지 직사각형의 크기를 균일하게 조정하고 새 용지의 중심에 놓습니다. 의도적으로 자르지는 않습니다. 이미 원본 PDF 페이지 경계 외부에 있는 콘텐츠는 복구할 수 없습니다.

링크, 양식 또는 디지털 서명이 보존됩니까?

이 도구는 주석, 링크, 대화형 필드, 회전 또는 사용자 정의 페이지 상자가 있는 페이지를 자동으로 삭제하는 대신 거부합니다. PDF를 저장하면 디지털 서명이 무효화될 수 있습니다. 원본을 보관하고 검토하세요.
