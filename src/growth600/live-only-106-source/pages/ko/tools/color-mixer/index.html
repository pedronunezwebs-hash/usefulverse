컬러 믹서

편집 가능한 가중치로 색상을 혼합하고, 두 가지 디지털 혼합 모드를 비교하고, 처음 두 색상 사이에 견본 램프를 만듭니다. 아무것도 업로드되지 않았습니다.

혼합할 색상

선택한 방법이 결과에 영향을 미칩니다. sRGB는 표시된 채널 값을 혼합합니다. 선형 조명은 혼합 전에 채널을 변환합니다.

이는 실제 페인트나 안료가 어떻게 혼합되는지가 아니라 디지털 화면 색상을 예측합니다.

이 브라우저에서 실행됩니다. 색상은 업로드되지 않거나 자동으로 저장되지 않습니다.

색상 램프

온라인에서 두 가지 색상을 어떻게 혼합합니까?

두 개 이상의 색상을 선택하고 각 가중치를 설정한 다음 sRGB 또는 선형-광 혼합을 선택합니다. 결과에는 HEX, RGB 및 HSL 값이 표시됩니다.

자주 묻는 질문

온라인에서 두 가지 색상을 어떻게 혼합합니까?

두 개 이상의 색상을 선택하고 각 가중치를 설정한 다음 sRGB 또는 선형-광 혼합을 선택합니다. 결과에는 HEX, RGB 및 HSL 값이 표시됩니다.

내 색상이 업로드되나요?

아니요. 색상 계산은 브라우저에서 로컬로 실행됩니다. 계정이나 이미지 업로드가 필요하지 않습니다.

sRGB와 선형 조명 혼합이 다르게 보이는 이유는 무엇입니까?

sRGB는 인코딩된 화면 채널 값의 평균을 계산합니다. 선형 조명 모드는 먼저 조명 값으로 변환하고 혼합한 다음 다시 변환합니다. 선택한 방법에 따라 결과가 달라집니다.

혼합페인트의 색상을 예측할 수 있나요?

아니요. 이것은 물리적 안료 모델이 아닌 화면에 대한 디지털 색상 수학입니다. 실제 페인트는 안료 특성, 투명도, 농도, 조명 및 표면에 따라 달라집니다.

어떤 색상 형식을 복사할 수 있나요?

결과는 HEX, RGB 및 HSL을 표시합니다. HEX 값을 복사하거나 작은 CSS 색상 팔레트를 다운로드할 수 있습니다.
