자주 묻는 질문

이벤트 타임라인은 어떻게 만드나요?

두 개 이상의 명명된 이벤트를 추가하고 각각에 대한 시작 날짜를 선택합니다. 특정 기간의 종료 날짜를 추가하거나 하루 동안의 이벤트인 경우에는 비워 두세요. 날짜별로 이벤트를 정렬하고, 확대/축소를 조정하고, SVG 또는 CSV 파일을 다운로드하는 타임라인을 만듭니다.

내 타임라인 이벤트가 업로드되나요?

아니요. 이름과 날짜는 이 브라우저 탭에서 처리됩니다. SVG 및 CSV가 장치에 생성됩니다. 아무것도 자동으로 업로드되거나 저장되지 않습니다.

이벤트가 하루 이상 지속될 수 있나요?

예. 시작일과 종료일을 모두 입력하세요. 차트에는 두 끝점 날짜가 모두 포함됩니다. 하루 동안 진행되는 이벤트의 경우 끝 부분을 비워 두세요.

이 타임라인이 작업 종속성을 생성합니까?

아니요. 날짜가 지정된 이벤트와 범위를 시간순으로 표시합니다. 작업, 기간, 종속성을 위해 프로젝트 일정 도구를 사용하세요.

타임라인을 저장하거나 공유할 수 있나요?

확장 가능한 이미지의 경우 SVG를 다운로드하고 이벤트 테이블의 경우 CSV를 다운로드합니다. 페이지는 이벤트 데이터를 업로드하거나 자동으로 저장하지 않습니다.
