고모쿠

15×15 보드에 검은 돌과 흰 돌을 놓습니다. 가로, 세로, 대각선으로 5개 이상 연속으로 만들면 승리합니다. 이 장치에서 친구와 플레이하거나 기본적인 로컬 상대에게 도전하세요.

규칙 자유형 Gomoku: 5개 이상의 연속 스톤이 승리합니다. 로컬 상대는 토너먼트 수준의 검색이 아닌 작은 경험적 방법을 사용합니다. 게임 상태는 이 탭에 유지되며 다시 로드하면 지워집니다.

Gomoku에서 어떻게 승리하나요?

빈 교차로에 돌 하나를 번갈아 가며 놓습니다. 어떤 방향으로든 5개 이상의 연속된 돌을 먼저 만드는 플레이어가 승리합니다. 이 버전은 자유형 규칙을 사용합니다. 오버라인도 승리합니다.

자주 묻는 질문

Gomoku에서 어떻게 승리하나요?

빈 교차로에 돌 하나를 번갈아 가며 놓습니다. 어떤 방향으로든 5개 이상의 연속된 돌을 먼저 만드는 플레이어가 승리합니다. 이 버전은 자유형 규칙을 사용합니다. 오버라인도 승리합니다.

아무것도 다운로드하지 않고 Gomoku를 플레이할 수 있나요?

네. 보드와 로컬 상대가 이 브라우저에서 실행됩니다. 게임이 업로드되지 않거나 자동으로 저장되지 않습니다.

라인은 정확히 5개의 스톤이어야 하나요?

아니요. 이 게임은 자유형 규칙을 사용합니다. 가로, 세로 또는 대각선 방향으로 연속된 5개 이상의 돌이 승리합니다.

컴퓨터를 상대로 오모쿠를 플레이할 수 있나요?

네. 로컬 컴퓨터는 즉각적인 승리와 차단을 확인한 다음 근처의 열린 라인에 점수를 매깁니다. 고급 AI나 토너먼트급 AI가 아닌 단순한 상대입니다.

Gomoku는 2인 플레이가 가능한가요?

네. 동일한 장치에서 교대로 플레이하려면 2인용 모드를 선택하세요. 온라인 멀티플레이어나 자동 게임 저장 기능은 없습니다.
