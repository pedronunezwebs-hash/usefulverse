크로스워드 온라인

독창적인 단서의 작은 세트에서 로컬로 생성된 새로운 십자말풀이를 풀어보세요. 단서나 사각형을 선택하고, 키보드로 입력하고, 도움이 필요할 때 답변을 확인하거나 공개하세요.

답변에서는 공백과 대소문자를 무시합니다. 단서 세트는 유한하고 독창적입니다. 새로운 보드는 항목을 재정렬하지만 일일 무제한 퍼즐 피드를 약속하지는 않습니다.

키보드: 문자를 입력하고 화살표를 사용하여 이동하고 백스페이스를 눌러 사각형을 지웁니다.

Across

    다운

      이 십자말풀이는 어떻게 플레이하나요?

      가로 또는 세로 단서를 선택한 다음 선택한 사각형에 문자를 입력하세요. 답변 내에서 이동하려면 화살표 키를 사용하세요. 단어 또는 전체 퍼즐을 확인하고, 한 글자 또는 전체 답을 공개하거나, 새로운 섞인 보드를 시작하세요.

      자주 묻는 질문

      이 십자말풀이는 어떻게 플레이하나요?

      가로 또는 세로 단서를 선택한 다음 선택한 사각형에 문자를 입력하세요. 답변 내에서 이동하려면 화살표 키를 사용하세요. 단어 또는 전체 퍼즐을 확인하고, 한 글자 또는 전체 답을 공개하거나, 새로운 섞인 보드를 시작하세요.

      내 답변이 업로드되거나 저장됩니까?

      아니요. 퍼즐, 답변, 점수는 이 브라우저 탭에 유지됩니다. 계정, 업로드, 서버 처리 또는 저장된 플레이 기록이 없습니다.

      이 크로스워드에는 일일 퍼즐 피드가 무제한 포함되어 있나요?

      아니요. 이 페이지는 원래의 단서와 답변 쌍의 한정된 작은 세트로 섞인 보드를 구성합니다. 무제한 일일 퍼즐 라이브러리를 가져오거나 요청하지 않습니다.

      아무것도 업로드하지 않고 이 십자말풀이를 사용할 수 있나요?

      예. 보드와 답변은 이 브라우저 탭에서 실행됩니다. 이 도구는 플레이를 업로드하거나 계정을 요구하지 않습니다.

      이거 크로스워드 메이커인가요?

      아니요. 이 페이지는 단서를 플레이하기 위한 페이지입니다. 자신만의 답과 단서 쌍을 준비하려면 별도의 크로스워드 메이커를 사용하세요.

      무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
