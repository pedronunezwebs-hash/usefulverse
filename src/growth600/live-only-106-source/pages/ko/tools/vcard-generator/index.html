V카드 생성기

브라우저에서 단일 디지털 연락처를 .vcf 파일로 만듭니다. vCard 3.0 또는 4.0을 선택하고 연락처 세부 정보를 추가하고 선택적으로 작은 JPEG 또는 PNG 사진을 삽입하세요.

JPEG 또는 PNG(선택 사항), 최대 128KiB. 사진은 VCF 파일에 포함됩니다. 업로드되지 않습니다.

연락처 1개, 전화 최대 5개, 이메일 5개, 텍스트 필드당 500자, 생성 파일 제한은 1MiB입니다. vCard 3.0 및 4.0만 제공됩니다.

생성을 선택한 후 로컬로 실행됩니다. 계정, 연락처 접근, 업로드, API, 서버 처리 또는 자동 저장이 없습니다.

VCF 미리보기


  

    
내 휴대폰에 연락처가 추가되나요?
아니요. 미리보기, 복사 또는 다운로드할 수 있는 VCF 파일을 생성합니다. 주소록을 읽거나 변경하지 않습니다. 파일을 가져올지 여부와 위치를 결정합니다.


    
자주 묻는 질문
내 휴대폰에 연락처가 추가되나요?
아니요. 미리보기, 복사 또는 다운로드할 수 있는 VCF 파일을 생성합니다. 주소록을 읽거나 변경하지 않습니다. 파일을 가져올지 여부와 위치를 결정합니다.
내 연락처 정보가 업로드되어 있나요?
아니요. 세부정보 및 선택적 사진이 이 장치에서 처리됩니다. 업로드, 계정, 서버 처리, 자동 저장이 없습니다.
vCard 3.0과 4.0의 차이점은 무엇입니까?
vCard 연락처 형식의 두 가지 버전입니다. 이 도구는 선택한 버전을 사용하여 호환 가능한 VCF 텍스트 파일을 작성합니다. 연락처 앱은 이를 다르게 지원할 수 있습니다.
전화번호나 이메일 주소를 확인합니까?
아니요. 기본 형식만 확인합니다. 전화번호, 사서함, 주소 또는 웹사이트가 해당 개인의 소유인지 확인할 수 없습니다.
