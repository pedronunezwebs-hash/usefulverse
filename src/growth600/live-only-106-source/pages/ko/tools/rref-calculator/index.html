RREF 계산기

RREF(Reduced Row Echelon Form), 순위, 피벗 열 및 기본 행 작업 단계를 계산하기 위해 직사각형 행렬을 입력합니다.

한 행에 한 행씩 입력하십시오. 공백, 탭 또는 세미콜론으로 열을 구분하세요. 유한한 십진수 값을 사용하세요. 1/2과 같은 분수는 허용되지 않습니다.

이 절대 크기 이하의 값은 0으로 처리됩니다. 공차가 엄격하면 반올림 오류가 증폭될 수 있습니다.

정확한 기호 연산이 아닌 수치 결과입니다. 최대 12개의 행과 열; 항목은 유한해야 하며 절대값이 10⁹ 이하여야 합니다. 조건이 나쁜 행렬에 대한 허용오차를 확인합니다.

결과

기약행 사다리꼴을 어떻게 찾나요?

가우스 제거를 사용하여 각 피벗 열에 선행 1을 생성하고 해당 열의 다른 모든 값을 제거합니다. 이 계산기는 제한된 숫자 산술을 사용하고 각 행 교환, 크기 조정 및 제거 단계를 표시합니다.

자주 묻는 질문

기약행 사다리꼴을 어떻게 찾나요?

가우스 제거를 사용하여 각 피벗 열에 선행 1을 생성하고 해당 열의 다른 모든 값을 제거합니다. 이 계산기는 제한된 숫자 산술을 사용하고 각 행 교환, 크기 조정 및 제거 단계를 표시합니다.

매트릭스 값이 업로드되었습니까?

아니요. 매트릭스는 이 브라우저에서 처리되며 이 도구로 업로드되거나 저장되지 않습니다.

RREF는 무엇을 의미합니까?

축소 행 사다리꼴 형식은 0이 아닌 각 행에 선행 1이 있고, 각 피벗은 해당 열에서 유일한 0이 아닌 값이며, 피벗 위치는 아래쪽 행에서 오른쪽으로 이동합니다.

피벗 열과 순위를 어떻게 읽나요?

나열된 피벗 열에는 선행 1이 포함되어 있습니다. 순위는 피벗 열의 수 또는 RREF의 0이 아닌 행의 수와 동일합니다.

결과가 정확합니까?

아니요. 이 도구는 부동 소수점 산술 및 선택된 제로 공차를 사용합니다. 정확한 합리적 작업 또는 조건이 나쁜 행렬의 경우 적절한 기호 도구를 사용하여 결과를 확인하십시오.
