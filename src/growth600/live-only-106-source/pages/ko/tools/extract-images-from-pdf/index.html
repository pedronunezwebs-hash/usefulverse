PDF에서 이미지 추출

내장된 래스터 이미지를 찾아 미리 보고 별도의 PNG 사본 또는 하나의 ZIP를 저장하려면 PDF를 선택하세요. 페이지는 스크린샷으로 래스터화되지 않습니다.

지원되는 내장 래스터 이미지 객체를 추출합니다. 전체 PDF 페이지를 이미지로 변환하지 않습니다. 벡터 드로잉과 페이지 텍스트는 별도의 래스터 이미지가 아닙니다.

파일은 이 장치에 유지되며 업로드되지 않습니다. 추출된 픽셀은 PNG로 다시 인코딩되므로 원래 포함된 파일 형식과 메타데이터는 유지되지 않습니다.

로컬 제한: 25 MiB PDF, 300페이지, 200개 이미지, 이미지당 8메가픽셀, 총 16메가픽셀 및 25 MiB ZIP. 대형 PDF는 장치 메모리를 사용합니다. 컴퓨터를 권장합니다.

찾은 이미지

미리보기는 처음 12개 이미지까지 표시됩니다. 나열된 모든 이미지는 계속 다운로드할 수 있습니다.

    PDF에서 이미지를 어떻게 추출하나요?

    PDF를 선택하고 이미지 추출을 선택합니다. 이 브라우저는 지원되는 내장 래스터 이미지 개체를 읽고 디코딩된 픽셀을 PNG 파일로 변환합니다. 개별 이미지 또는 ZIP 하나를 다운로드하세요.

    자주 묻는 질문

    PDF에서 이미지를 어떻게 추출하나요?

    PDF를 선택하고 이미지 추출을 선택합니다. 이 브라우저는 지원되는 내장 래스터 이미지 개체를 읽고 디코딩된 픽셀을 PNG 파일로 변환합니다. 개별 이미지 또는 ZIP 하나를 다운로드하세요.

    내 PDF 또는 이미지가 업로드되나요?

    아니요. PDF는 이 브라우저 탭에서 처리됩니다. 도구는 파일을 업로드하거나 계정에 저장하지 않습니다.

    이 도구는 모든 PDF 페이지를 그림으로 변환합니까?

    아니요. 지원되는 내장 래스터 이미지 개체를 찾습니다. 각 전체 페이지의 렌더링된 이미지를 원할 경우 PDF-to-image 도구를 사용하십시오.

    추출된 PNG는 포함된 파일과 바이트 단위로 동일합니까?

    아니요. 브라우저는 지원되는 이미지 개체를 디코딩하고 디코딩된 개체 크기에서 해당 픽셀을 PNG로 다시 인코딩합니다. 원본 압축, 파일 형식 및 메타데이터는 보존되지 않습니다.

    일부 PDF 이미지가 표시되지 않는 이유는 무엇입니까?

    벡터 아트웍, 이미지 마스크, 비정상적인 인코딩, 비밀번호 보호, 잘못된 형식의 파일 및 브라우저 메모리 제한으로 인해 추출이 불가능할 수 있습니다. 이 도구는 지원되는 개체만 보고하고 파일을 업로드하지 않습니다.
