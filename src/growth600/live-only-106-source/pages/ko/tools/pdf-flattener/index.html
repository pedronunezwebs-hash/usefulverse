PDF 양식 병합

지원되는 AcroForm 필드를 눈에 보이는 페이지 모양으로 병합하여 별도의 PDF 사본을 만듭니다. 페이지의 텍스트는 선택 및 검색이 가능한 상태로 유지됩니다.

병합은 새 복사본에서 양식 상호 작용을 제거합니다. 원본을 보관하세요. 기존 디지털 서명은 무효화되거나 제거될 수 있습니다. 이는 서명 확인 도구가 아닙니다.

로컬 제한: 25MiB 입력, 300페이지, 2,500개 필드 및 50MiB 출력. 복잡하거나 암호화된 양식 또는 XFA 양식은 지원되지 않을 수 있습니다. 대용량 파일에는 컴퓨터를 권장합니다.

지원되는 AcroForm 필드만 평면화됩니다. 기타 댓글, 하이라이트, 링크, 스탬프, 메타데이터 및 접근성 구조는 평면화되지 않거나 변경되지 않은 상태로 유지된다는 보장이 없습니다.

새 사본이 준비되었습니다.

병합된 사본 다운로드

이 브라우저에서는 오픈 소스 pdf-lib 라이브러리를 사용합니다. 원본 파일은 절대 수정되지 않습니다.

PDF 양식을 병합하면 어떤 작업이 수행됩니까?

지원되는 대화형 양식 필드 모양을 페이지 컨텐츠에 그리고 새 사본에서 해당 대화형 필드를 제거합니다. 일반 주석, 링크, 스탬프 또는 기타 마크업 주석은 평면화되지 않습니다.

자주 묻는 질문

PDF 양식을 병합하면 어떤 작업이 수행됩니까?

지원되는 대화형 양식 필드 모양을 페이지 컨텐츠에 그리고 새 사본에서 해당 대화형 필드를 제거합니다. 일반 주석, 링크, 스탬프 또는 기타 마크업 주석은 평면화되지 않습니다.

내 PDF가 업로드되었나요?

아니요. 이 브라우저에서 처리가 실행됩니다. 선택한 PDF는 서버로 전송되지 않거나 자동으로 저장되지 않습니다.

병합된 사본의 필드를 계속 편집할 수 있습니까?

아니요. 지원되는 필드는 페이지 모양의 일부가 되며 더 이상 대화형이 아닙니다. 나중에 편집해야 할 경우 원본을 보관하세요.

이렇게 하면 주석, 강조 표시 또는 디지털 서명이 병합됩니까?

아니요. 이 도구는 지원되는 AcroForm 필드만 대상으로 합니다. 다른 마크업 주석은 병합되지 않으며 편집을 통해 디지털 서명이 무효화되거나 제거될 수 있습니다. 인증되었거나 법적으로 서명된 문서에는 이 기능을 사용하지 마십시오.

페이지 텍스트는 계속 검색 가능합니까?

페이지 내용은 이미지로 변환되지 않으므로 기존 페이지 텍스트는 계속 검색 가능합니다. 양식 필드 모양은 페이지 콘텐츠로 병합됩니다.
