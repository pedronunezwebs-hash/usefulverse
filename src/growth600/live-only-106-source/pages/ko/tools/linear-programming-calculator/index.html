선형 프로그래밍 계산기

x와 y가 음수가 아닌 2변수 선형 계획을 풀려면 선형 목표와 최대 8개의 제약 조건을 입력합니다. 2단계 단순 방법은 최적, 실행 불가능성 또는 무한성을 보고하고 각 피벗을 표시합니다.

목적 계수(x, y)

한 줄에 하나씩: a,b <= rhs, a,b >= rhs 또는 a,b = rhs

±1,000,000 내에서 최대 8개의 제약 조건과 계수/우변을 사용합니다. 두 결정 변수 모두 x ≥ 0 및 y ≥ 0입니다. x와 y 계수 사이에 쉼표를 사용하세요. 한 줄에 부등식 또는 평등식을 하나씩 입력하세요.

두 변수에 대한 2단계 원문제 단순 솔버입니다. 부동 소수점 피벗에는 수치 허용오차가 사용됩니다. 거의 퇴화된 문제는 반올림에 민감할 수 있습니다. 고안된 최적값 대신 실현 불가능하고 무한하며 반복 제한적인 사례가 보고됩니다.

선형 프로그램 결과

결과는 입력한 수학적 모델에 대해서만 나타납니다. 목표, 제약 조건, 단위 또는 가정이 실제 결정에 적합한지 여부를 검증하지 않습니다.

    2변수 심플렉스 계산기는 어떻게 작동하나요?

    제약 조건을 실행 가능한 테이블로 변환하고 필요할 때 1단계 목표를 사용한 다음 원시 단순 피벗을 적용하여 요청된 목표를 최적화합니다. 변수 x와 y는 음수가 아니도록 제한됩니다.

    자주 묻는 질문

    2변수 심플렉스 계산기는 어떻게 작동하나요?

    제약 조건을 실행 가능한 테이블로 변환하고 필요할 때 1단계 목표를 사용한 다음 원시 단순 피벗을 적용하여 요청된 목표를 최적화합니다. 변수 x와 y는 음수가 아니도록 제한됩니다.

    내 목표와 제약 조건이 업로드되었나요?

    아니요. 솔버는 이 브라우저에서 실행됩니다. 목표와 제약 조건은 이 도구에 의해 서버로 전송되거나 저장되지 않습니다.

    제약조건에는 어떤 형식을 사용해야 합니까?

    1,1 <= 5 또는 2,1 >= 4와 같이 한 줄에 하나의 행을 입력하십시오. 첫 번째 숫자는 x를 곱하고 두 번째 숫자는 y를 곱하며 두 변수는 모두 음수가 아니어야 합니다.

    실현불가능과 무한은 무엇을 의미합니까?

    실행 불가능은 입력된 모든 제약 조건을 만족하는 점이 없음을 의미합니다. 무한함은 실행 가능한 방향이 유한 최적 조건 없이 요청된 목표를 계속 개선할 수 있음을 의미합니다.

    결과는 내 실제 모델이 정확하다는 것을 증명합니까?

    아니요. 입력한 방정식만 풉니다. 단위, 가정, 제약 조건이 결정을 적절하게 설명하는지 확인하세요.

    홈

    무료 브라우저 도구. 도구의 기능에 따라 데이터는 사용자의 기기에만 저장됩니다.
