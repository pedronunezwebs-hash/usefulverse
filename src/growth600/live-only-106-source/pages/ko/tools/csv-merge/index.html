QZCSVTTOkenX 병합

여러 CSV 파일을 하나의 테이블로 결합합니다. 순서가 달라도 일치하는 열 이름이 정렬되고 필요한 경우 빈 셀과 함께 추가 열이 추가됩니다. 파일은 이 브라우저에 유지됩니다.

2~20개의 파일을 선택합니다(각각 최대 2개의 MiB, 총 8개의 MiB). 처리 과정은 이 기기에 유지됩니다.

헤더를 사용하면 열이 정확한 이름과 일치하고 새 열은 처음 발견된 순서를 따릅니다. 헤더가 없으면 열은 위치별로 일치합니다. 더 안전한 스프레드시트 열기를 위해 수식과 유사한 헤더나 값 앞에 아포스트로피가 붙습니다. 구분 기호, 파일 인코딩 및 셀 텍스트는 그렇지 않으면 정규화되지 않습니다.

병합된 CSV

병합된 CSV를 다른 애플리케이션에서 사용하기 전에 검토하십시오.

CSV 파일을 다른 열 순서로 병합하려면 어떻게 해야 합니까?

두 개 이상의 CSV 파일을 선택하고 헤더 옵션을 켜진 상태로 유지합니다. 열은 처음 표시된 순서를 사용하여 정확한 헤더 텍스트와 일치됩니다. 누락된 열은 빈 셀이 됩니다. 일치하지 않는 열이 출력에 추가됩니다.

자주 묻는 질문

CSV 파일을 다른 열 순서로 병합하려면 어떻게 해야 합니까?

두 개 이상의 CSV 파일을 선택하고 헤더 옵션을 켜진 상태로 유지합니다. 열은 처음 표시된 순서를 사용하여 정확한 헤더 텍스트와 일치됩니다. 누락된 열은 빈 셀이 됩니다. 일치하지 않는 열이 출력에 추가됩니다.

QZCSVTTOKEX 파일이 업로드되었습니까?

아니요. 선택한 파일은 이 브라우저에서 로컬로 읽고 병합됩니다. 파일당 2개의 MiB 및 8개의 MiB 결합 입력 제한으로 최대 20개의 파일이 지원됩니다. 계정이나 서버 처리가 사용되지 않습니다.

열의 순서가 다른 경우 CSV 파일을 병합할 수 있습니까?

예. 헤더를 활성화하면 열은 위치가 아닌 정확한 헤더 텍스트를 기준으로 정렬됩니다. 새 헤더는 처음 표시된 순서대로 추가되며 누락된 값은 비어 있습니다.

CSV 파일에 헤더 행이 없으면 어떻게 됩니까?

헤더 옵션을 끕니다. 그런 다음 값은 열 위치에 따라 정렬되고 출력은 열 1과 같은 중립 이름을 사용합니다. 셀이 더 적은 입력 행은 CSV 구문 분석기에 의해 채워집니다.

수식이나 스프레드시트 명령이 변경되었습니까?

수식과 유사한 헤더와 값은 스프레드시트 소프트웨어에서 열 때 실행 위험을 줄이기 위해 출력 CSV에 아포스트로피가 앞에 붙습니다. 이는 의도적으로 해당 셀 값을 변경합니다.
