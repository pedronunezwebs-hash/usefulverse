메모리 테스트

3×3 격자에서 점점 늘어나는 숫자나 위치를 기억하는 연습을 하세요. 올바른 라운드마다 하나의 항목이 추가됩니다.

연습 전용입니다. 이것은 IQ 테스트, 진단 또는 검증된 인지 평가가 아닙니다. 결과에는 임상적 또는 집단적 의미가 없습니다.

스크린 리더의 경우 숫자 범위를 선택합니다. 각 숫자는 재생 중에 한 번씩 안내됩니다. 시각적 패턴 모드는 시력에 따라 다릅니다.

다음 시퀀스 길이: 3

시퀀스 항목: —

귀하의 답변

아직 입력된 항목이 없습니다.

올바른 반올림: 0

모드와 속도를 선택한 후 시작하세요.

테스트 결과

이 메모리 테스트는 어떻게 작동하나요?

숫자 또는 시각적 그리드와 표시 속도를 선택합니다. 시퀀스를 한 번 보거나 들은 후 동일한 순서로 입력하세요. 올바른 라운드는 최대 12개 항목까지 길어집니다. 이것은 표준화된 기억력 평가가 아닌 캐주얼 연습 게임입니다.

자주 묻는 질문

이 메모리 테스트는 어떻게 작동하나요?

숫자 또는 시각적 그리드와 표시 속도를 선택합니다. 시퀀스를 한 번 보거나 들은 후 동일한 순서로 입력하세요. 올바른 라운드는 최대 12개 항목까지 길어집니다. 이것은 표준화된 기억력 평가가 아닌 캐주얼 연습 게임입니다.

이 메모리 테스트를 하면 점수가 저장되나요?

아니요. 시퀀스와 점수는 이 페이지가 열려 있는 동안 그대로 유지됩니다. 아무것도 업로드되지 않으며, 계정이나 온라인 순위도 없습니다.

이 메모리 테스트는 무엇을 측정합니까?

캐주얼한 시퀀스 기억 연습 게임입니다. 표준화되지 않았으며 상태를 진단하거나 IQ를 측정할 수 없습니다.

숫자 범위와 패턴 모드는 어떻게 다릅니까?

숫자 범위는 한 번에 하나씩 숫자를 표시하고 화면 판독기 액세스를 위해 이를 알려줍니다. 패턴 모드는 3×3 그리드의 위치를 ​​깜박이며 시력이 필요합니다.

점수가 저장되나요, 아니면 다른 사람과 비교하나요?

아니요. 점수는 이 페이지가 열려 있는 동안에만 존재합니다. 리더보드, 계정 또는 서버 업로드가 없습니다.
